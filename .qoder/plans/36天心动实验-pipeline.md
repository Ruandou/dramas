# 《36天心动实验》— 流水线执行计划

## Context

初始化新短剧项目《36天心动实验》，类型为都市甜宠（🟢 C级合规）。核心钩子：数据分析师 vs 浪漫小说家，36天证明/否证爱的存在。场景极少（2间公寓+1间咖啡馆），AI生产友好度极高，是现代都市室内剧的最佳制作形态。

## 概念简报

- **标题**：《36天心动实验》
- **题材/类型**：都市 / 甜宠 / 轻喜剧
- **核心钩子**：数据分析师挑战浪漫小说家：36天证明爱情存在。每天一个实验，每天一个数据点。第36天，必有一人沦陷。
- **目标受众**：18-35岁女性为主，核心诉求为情感共鸣+智性浪漫

## Task 1: 题材合规快检 + 项目目录初始化

- 创建 `工作计划.md` 初始版本
- **产出**: 项目目录结构 + 工作计划
