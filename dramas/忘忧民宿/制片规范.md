# 《忘忧民宿·女客请进》制片规范

> **版本**：v1.0 · 2026-06-05  
> **类型**：都市 / 神话喜剧 / 女频治愈  
> **集数**：36 集 × 2.5 分钟  
> **画面比例**：9:16 竖屏  
> **生成工具**：Seedance 2.0 fast（方舟 MCP）

---

## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系 |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、分镜 |
| 群演 | `CHAR-GRP-##` | `CHAR-GRP-01` | 中介、路人 |
| **场景** | `SCENE-###` | `SCENE-001` | 布景 |
| **道具** | `PROP-###` | `PROP-001` | 房卡机等 |
| **分集** | `EP##` | `EP01` | 分集 |
| **镜头** | `EP##-S##` | `EP01-S01` | 逐镜 |
| **段落** | `EP##-SEG##` | `EP01-SEG01` | API 提交 |

编号连续、不跳号；弃用标 `deprecated: true`。

## 四、EP01 标杆

| 项 | 标准 |
|----|------|
| 分镜 md | ~13 SEG · ~30 镜 · 裸素材 **~132s** |
| 单 SEG | 4–12 秒 · 1–3 镜 |
| 有效镜 | `i2v_ref` / `i2v`；字幕/黑屏 `skip` |
| 定妆 | 优先 `CHAR-001-L01`、`CHAR-002-L01` + `SCENE-001/004` |

## 五、时代与美术

- **年代**：2020 年代中国南方小城/老街区
- **民宿美学**：旧木前台、暖黄台灯、404 冷月侧光；**非恐怖**，治愈向低饱和
- **神话元素**：现代极简女装 + 轻微「月光/桂香」氛围即可，禁止古装宫斗大冠

### 视觉禁忌

- 禁止恐怖鬼屋、血腥、Jump scare
- 禁止真实宗教场所、符咒改运宣传
- 禁止 burned-in 字幕入 AI 画面（后期加字幕）
- 禁止 celebrity 脸

### Negative Prompt（通用）

```
blurry, distorted, low quality, watermark, subtitles burned into frame,
anime style, cartoon style, horror, ghost face, blood, jump scare,
palace hanfu crown, military uniform, courtroom, police, unreadable gibberish text,
celebrity face, neon cyberpunk
```

### prompt_suffix（默认）

```
2020年代中国小城老民宿，女频治愈写实短剧，竖屏9比16，柔和光线，非恐怖非古装宫斗；
对白由后期字幕呈现，画面禁止出现任何汉字乱码。
```

## 六、分段规则

| 约束 | 值 |
|------|-----|
| 单 segment | 4–12 秒 |
| 每 segment 镜头 | 1–3 |
| 每集 segment | 12–15 |
| 每集总时长 | 140–180 秒 |

不得跨 SCENE 合并 segment；不得对话中间切断。
