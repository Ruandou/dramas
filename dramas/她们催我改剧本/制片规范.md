## 五、美术与合规

- **年代**：2020 年代都市
- **神话夜访**：现代家居服 + 轻 myth 气质，**禁止**宫装大冠
- **核心导向**：创作权 / 女性自主，非符咒改命
- **韩默线**：非法庭长戏、无警察；维权走**著作权调解+舆论**

### Negative Prompt

```
blurry, distorted, horror, ghost face, blood, palace hanfu crown, religious ritual,
anime style, subtitles burned in, celebrity face, readable Chinese text gibberish,
courtroom, police uniform, military
```

