## 一、ID 命名规则

所有资产统一编码，**编号只增不删**；弃用标 `deprecated: true`。

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同群演角色独立 ID + L01    |
| 场景     | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### 本项目 ID 分配现状（v1.0）

- **CHAR-001 ~ CHAR-008**：主要角色 8 人（**已达上限，任何阶段禁止增设主要角色** —— R1 转下游硬约束）
- **CHAR-009 ~ CHAR-016**：次要功能角色（有名字/跨集/叙事必要）
- **CHAR-GRP-01 ~ CHAR-GRP-23**：群演（有对白/需视觉区分的功能位；含 3 个「通用脸」：船闸吏/主考官/江南茶商，无独立定妆需求，复用路人底模；GRP-23 冷淡村妇为 EP02 集间回补，L01 待生成）；纯背景人群（村民/镇民/客商/食客群）归通用路人库，不建 ID
- **SCENE-001 ~ SCENE-017**：大纲附录 10 核心场景 + 结构补登 7 个（含 EP01 全覆盖所需的城门外官道，及裴宅/何记盐行/柳集码头/老盐场废墟/村后废河道/州府船闸）
- **PROP-001 ~ PROP-023**：大纲附录 21 项（锁金匣/铜钥拆分登记）+ 结构补登 2 项（假地契、盐水勒索字条，盐水显影链完整性所需）

### 形象层级

| 后缀     | 名称     | 说明                                        |
| -------- | -------- | ------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01`
- 新建换装/阶段形象：只加 `L02+`，写明 `based_on: CHAR-xxx-L01`
- scene-writer 标注的新群演（`[待补：...]`）由 production-planner 在集间群演回补子循环统一分配 `CHAR-GRP-##`（从已有最大编号+1 起；当前已用至 GRP-23，下一可用 = GRP-24）
- 群演参考图配额约束：每 segment 参考图 ≤6 张（TOS URL 模式），超出按 segment-builder 优先级裁减

## 二、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于大纲 YAML 元数据「视觉风格 / 色彩基调」。创意细化由 character-designer / prop-designer / scene-designer 负责，本节为结构性基线，不得违背。

| 维度 | 规格 |
|------|------|
| 渲染风格 | photorealistic 古装质感·边地滩涂写实（盐田奇观 + 市井烟火 + 手艺特写） |
| 镜头参考 | cinematic 35–85mm；手艺戏用 macro 特写（捻盐、化盐、显影） |
| 色调方向 | **低饱和大地色为底 + 盐白高光点睛**；双色系：村内人情戏 = 暖黄灶火光（warm amber hearth light），对峙/公堂/反派戏 = 青灰冷光（cold cyan-grey） |
| 画幅 | 9:16 vertical |
| 题材关键词 | salt flats（盐田连片）、pre-industrial coastal（前工业海盐）、市井烟火、手艺特写、weathered textures（风蚀质感） |

### 全局 prompt_suffix（图像生成统一后缀，结构性）

```
, ancient East Asian pre-industrial coastal salt-making period drama (fictional Da Yong dynasty), photorealistic cinematic still, low-saturation earth-tone palette with salt-white highlights, natural light, 9:16 vertical composition
```

### 结构性 negative_prompt（年代/题材禁忌，全项目强制）

> 架空古代「大雍朝」：禁一切现代物品；避免任何可识别的真实朝代/政治指涉。创意领域 negative（画风类）由各设计师自行补充。

```
modern objects, modern clothing, plastic, glass panes, electric light, light bulb, power lines, wires, rubber, zipper, wristwatch, phone, vehicle, bicycle, asphalt road, concrete, printed modern signage, modern hairstyle, modern makeup, eyeglasses, gunpowder firearms, identifiable real-dynasty imperial regalia, gibberish text, distorted Chinese characters
```

### 含中文文字道具的强制规则

凡 `资产/道具卡片.md` 中标注「⚠️ 中文文字」的道具（共 16 项），其参考图 Prompt **必须**包含 `Simplified Chinese characters, clear legible calligraphy` 类指令并写明确切文字内容；生成后必须人工核验字形无讹变，方可标记 `✅ 已生成`。

### 分集文件头模板

```yaml
---
episode_id: EP01
episode_title: [集标题]
duration_sec: 120  # EP01=120，EP02+ 标准 90（带宽 75–120）
season: S1
scene_ids: [SCENE-010, SCENE-011, SCENE-001]

look_ids: [CHAR-001-L01, CHAR-007-L01, CHAR-009-L01]
prop_ids: [PROP-001, PROP-003, PROP-006]
seedance_defaults:
  model: doubao-seedance-2-0-fast-260128  # ⚠️ 必须带版本后缀，无后缀方舟返回 404
  seed: 20260729  # 全剧统一固定 seed（提升跨段音色/语速稳定）；可从首个满意成片任务回填更新
  ratio: "9:16"
  resolution: 720p
  image_resolution: 1600×2848  # Seedream 参考图，9:16 竖屏
  duration_sec: "8-10"
  generate_audio: true
---
```

### 模型定义

| 用途 | 模型 | 备注 |
|------|------|------|
| 视频生成 | `doubao-seedance-2-0-fast-260128` | ⚠️ 必须带版本后缀；单段 4–12s 硬限制 |
| 参考图生成 | Seedream（方舟当前版，如 `doubao-seedream-4-0-250828`） | 1600×2848（9:16）；设计师生成时确认版本号并回填此表 |
| 字幕 | 不由 Seedance 烧录 | 后期 ffmpeg 统一压制 |

## 六、分段规则（Segment）

| 约束             | 值              | 说明                                    |
| ---------------- | --------------- | --------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                 |
| 每 segment 镜头数 | 1–3 镜         | 不超过 3 个镜头                         |
| 最小叙事单位     | 1 个完整 beat   | 每段必须构成完整叙事节拍                |
| 每集段落数       | 6–10 段         | EP01 可至 12 段                         |

**拆分原则**：
1. 不得在一句台词中间切断 segment
2. 不得在连续动作链（开门、摘道具、焚烧休书等）中间切断
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆 `SEGxxa` / `SEGxxb`
5. 分镜某镜自然时长 < 4 秒 → 并入同场景相邻段

**关键区分**：SCENE-### = 空间单位；SEGxx = AI 生成单位。同一场景可含多个 segment；segment 不得跨场景。

**分集剧本格式**：11 列镜头表（镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注）；SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs`；对白格式 `**CHAR-###**[情绪]：「台词」`，无对白写 `（无对白，[音效]）`。

## 八、音色规范

- voice_prompt 权威来源优先级：**P0 `资产/声音卡片.md`** > P1 角色卡片 > P2 本规范。存在 P0 一律用 P0。
- 同一角色跨 segment 的 voice_prompt **全文一致**（segment-builder 从声音卡片全文复制，「」为可读性标记，YAML 只取括号内纯文本）。
- 角色情绪波动（如裴照 EP67 唯一失态、顾世安 EP77 转变）由 segment 级情绪标注控制，**不改 voice_prompt**。
- 旁白不分配 CHAR-ID，voice_prompt 在声音卡片独立定义。
- 群演一次性台词优先复用声音卡片「通用路人音色库」。
- character-designer 如需修改 voice_prompt，走角色卡片 `voice_feedback` 子节 → drama-director 集间循环审阅 → 采纳后更新声音卡片 P0。

## 九、年代/题材约束（叙述性）

**架空古代「大雍朝」**（近似前工业海盐时代，无任何真实朝代与政治指涉）。

必须体现：
- 前工业海盐工艺链：刮霜取卤→修晒池→制卤澄清→结晶→冻卤提硝（视觉奇观主线）
- 盐政制度符号：灶籍/灶帖/盐引/官定盐行/巡检铜符/骑缝官印（道具级还原）
- 边地滩涂质感：盐碱地白茫、补丁粗布、油灯灶火、坛坛罐罐
- 双色系光线纪律：村内人情=暖黄灶火光；对峙公堂反派=青灰冷光

禁止出现：
- 一切现代物品（见第二节结构性 negative_prompt）
- 可识别的真实朝代服制/年号/地名/政治指涉（架空「大雍朝」自洽）
- 火药武器、大规模战争场面（全剧以证据/律条/手艺决胜，无武力叙事）
- 宗教祭拜情节（EP21 盐神祠仅作废墟史料呈现，⚠️合规拍法已锁定）

## 十、受众定位

- **主频道**：女频
- **核心年龄段**：25–45（下沉市场 + 银发外溢）
- **核心痛点**：婚姻中被贬低/被吞占的不甘；靠自己双手翻身的渴望；对「污名昭雪」的执念

- **题材合规等级**：🟡B 级（架空古代；核心导向手艺立身与经营自立；无宫廷政治权谋核心线，无封建迷信元素）。R1 合规审查 P0 命中 0、P1 未处理 0。

- **灰区处理策略**：
  1. 以暴制暴 → 全剧冲突以证据、律条、手艺决胜，反派由官府惩处（EP70）
