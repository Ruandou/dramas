### CHAR-001｜沈凤尘

```
「女，18岁，清亮中带倔强的少女音色，语速偏快说话干脆利落，情绪饱满炽热不藏话。
  ——核心辨识度：她的声音像一把未出鞘的剑——平时清脆，但每个字都有分量。

  公开/对峙场景：声音抬高但不尖利，字字清晰掷地有声。与德妃交锋时话里带着三分笑意七分锋刃。

  私下独白：声音放低放缓，带着对姐姐的思念和偶尔的迷茫——「姐姐，这个地方——离真相更近了，对吗？」

  与萧衍对话：初期保持距离感（礼貌而警惕），中期逐渐柔软（带一丝她自己都没察觉的温柔），后期全然信任（声音里有笑）。

  L02冷宫期间（EP13-24）：音色明显沙哑疲惫——像嗓子被冷风割过。语速放慢，但仍有力。偶尔的咳嗽穿插在话语中。
  ——核心不变：再沙哑，那个倔强的底色不会消失。像被压弯但不折断的竹子。
```

### CHAR-002｜萧衍

```
「男，21岁，低沉磁性的青年帝王音色，语速缓慢沉稳不怒自威，表面冷淡克制字字斟酌。
  ——核心辨识度：他的声音像深冬的湖水——表层结冰，底下暗流涌动。

  朝堂/公开场合：声音平稳低沉，每个字都像是经过称量才出口。不带多余的情绪，但每一句都有分量。
  ——「朕知道你不是她。」（EP1）——平静到令人窒息。

  与沈凤尘独处：声音的冰层逐渐融化。初期仍是克制的（但比公开场合柔和），中期开始有温度——偶尔带着一丝连他自己都没意识到的笑意。后期（EP20月光摊牌后）声音里多了宠溺和坚定。
  ——「朕只知道，有人害怕火。」（EP6）——像是在说一句漫不经心的话，但每个字都是保护。
  ——「但她是朕的皇后。」（EP27）——平静，但全场都能听出这四个字的力量。

  与太后对峙：声音压到最低，冷到骨子里。几乎是咬着牙吐出每一个字。
  ——「母后——请给朕一个解释。」（EP24）——九分冷，一分被压制的痛。

  独处/深夜：声音沙哑疲惫，卸下所有铠甲后的真实。EP11跪灵时的哽咽——不是一个帝王，只是一个没能护住所爱之人的男人。

  EP35-36归隐后：声音轻了，快了，带着从没在他身上出现过的轻松——像一个终于卸下盔甲的人。
```

### CHAR-003｜德妃柳如依

```
「女，23岁，温婉柔美的假面音色，语速不紧不慢从容不迫，话里总带着三分客气七分刺。
  ——核心辨识度：她的声音像裹了蜜的刀——每一句都好听，但每一句都在割人。

  公开场合（有皇帝/太后/皇后在场）：声音甜美端庄，像春风拂过——「皇后娘娘与传闻中不太一样。」（EP3）——温温柔柔的一句话，每个字都是试探和挑衅。

  与沈凤尘交锋：声音更加温柔，但话里的刺越来越明显。客气话说到极致时往往就是攻击——「替身——终究是替身。」（EP13）——笑着说出最恶毒的话。

  与太后/心腹私下：声音变冷变利，甜美的外皮剥落——露出了蛇的信子。速度快起来，带着被压抑的急躁和算计。

  崩溃时（EP26）：声音拔高变尖，所有的从容和温柔一瞬崩塌。跪在地上指着太后时，声音里是赤裸裸的恐惧和自我保全——「是她！是太后指使我！」
```

```
「女，48岁，威严浑厚的中年女声，语速极慢每字都经过斟酌，每个字都带着不动声色的压迫感。
  ——核心辨识度：她的声音像一座沉重的大理石雕像——稳、重、压得人喘不过气。

  日常/公开场合：声音慈和端庄，节奏缓慢，像一个慈祥的长辈——「皇后看着气色不错。」（EP3）——但"不错"两个字拖得稍长，笑意之下寒意已至。

  威胁/施压：声音不变，语速不变，笑容不变——但话的内容越来越冷。她不需要提高音量来威胁人，因为她的存在本身就是威胁。
  ——「这洪福——未必能长久。」（EP3）——笑着说的，像祝福，像诅咒。

  愤怒/被触犯：声音从喉咙深处挤出来，低沉而冰冷。不吼不叫——她的愤怒是冰，不是火。

  崩溃/暴露（EP28/EP32）：声音突然苍老沙哑，所有伪装在那一刻剥落。提到"煜儿"时声音里闪过一丝扭曲的母性——那是她唯一会失控的话题。
  ——「这江山，本该是煜儿的！」（EP32）——沙哑、尖锐、执念。

```
「男，24岁，温和从容的青年音色，语速平缓不紧不慢，带着江南水土养出的温润感。
  ——核心辨识度：他的声音像江南的春雨——不疾不徐，润物无声。全剧唯一一个说话完全不带"宫斗味"的人。

  最后一句：声音里终于有了一丝不易察觉的沉重——不是动摇，是对那些因他而死的人的一丝悲悯。
  ——「替我转告皇帝——我不要皇位。我只想守着这片茶园。」——平静地划下了一个时代的句号。
