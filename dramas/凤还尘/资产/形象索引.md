## 形象一致性规则

| 规则 | 说明 |
|------|------|
| **同脸原则** | CHAR-001-L01与L02、CHAR-005-L01必须保持相同的面部结构（鹅蛋脸+丹凤眼），差异仅在表情、妆容和神态 |
| **姐妹区分** | CHAR-001（沈凤尘）眼神"如火"——灼热、倔强、锐利；CHAR-005（沈凤仪）眼神"如水"——温柔、沉静、忧郁。AI生成时需在prompt中明确标注 |
| **服装色彩体系** | 沈凤尘：红+金（皇后）；萧衍：黑+金（帝王）；德妃：粉+紫（宠妃）；太后：深紫+金（权威）；沈凤仪：浅蓝+月白（纯洁）；疯妃：灰褐（破败） |
| **关键道具追踪** | 珠钗（CHAR-001-L01必有，L02藏于袖中但可偶尔露出）、双鱼佩（CHAR-001腰间+CHAR-005腰间各半）、佛珠（CHAR-004手中必有） |
| **竖屏优先构图** | 所有单人形象以半身/七分身为主；避免并排双人构图，改用上下或对角线；背景留白适合竖屏字幕叠加 |
| **一致性锚点** | 每角色至少保持3个不变特征：发型轮廓+服装主色+核心配饰，确保跨集可辨识 |
