## 一、ID 命名规则

### 1.0 完整 ID 命名表

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |

| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |

- 编号**连续、不跳号、只增不删**；弃用标 `deprecated: true`。
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再建 `L01` 基础形象于 `资产/形象索引.md` + `角色卡.md`。
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-###-L01`。

## 三、工作流顺序（修改层级）

制片规范确立后，所有内容修改**严格按层向下**，禁止跳跃：

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **总剧本**   | `短剧剧本_凤还尘_36集.md` | 集纲、每场剧情、对白要点、钩子、情绪峰值            |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡、资产索引等       | 仅在前几步定稿后随需更新                            |

**禁止**：
- 先改 `segments.yaml` 再回头补剧本
- 先建形象再登记角色索引
- 跳过 L01 直接生成 L02

**单集真相源**是 `剧本/EP##/EP##_*.md`。所有下游文件必须从此导出。

## 四、分集文件头（YAML 模板）

每集分集剧本必须以此 YAML 头开始：

```yaml
---
episode_id: EP##
episode_title: [集标题]
duration_min: 2.5
season: S1
scene_ids: [SCENE-###, SCENE-###, ...]
character_ids: [CHAR-###, CHAR-###, ...]
look_ids: [CHAR-###-L##, CHAR-###-L##, ...]
seedance_defaults:
  model: doubao-seedance-2-0-fast-260128
  ratio: "9:16"
  resolution: 720p
  duration_sec: "8-10"
  generate_audio: true
  prompt_suffix: "禁止画面中出现任何文字或字幕。古装宫廷剧风格，唐宋美学，电影级写实质感。"
  negative_prompt: "blurry, distorted, low quality, watermark, subtitles burned into frame, anime style, cartoon style, watercolor, oil painting style, modern clothing, smartphone, car, neon sign, concrete building, plastic, Qing dynasty hairstyle, queue/bianzi, modern objects, electric light, wristwatch, glasses, zipper, logo, text in image"
---
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `episode_id` | string | 格式 `EP##`，连续编号 |
| `episode_title` | string | 集标题，中文 |
| `duration_min` | number | 固定 2.5（150秒） |
| `season` | string | 固定 S1 |
| `scene_ids` | array | 本集用到的所有场景 ID |
| `character_ids` | array | 本集出场的所有角色 ID |
| `look_ids` | array | 本集使用的所有形象 ID |
| `seedance_defaults.model` | string | 固定 `doubao-seedance-2-0-fast-260128` |
| `seedance_defaults.ratio` | string | 固定 `"9:16"` |
| `seedance_defaults.resolution` | string | 固定 `720p` |
| `seedance_defaults.duration_sec` | string | 默认 `"8-10"`，可按段覆盖 |
| `seedance_defaults.generate_audio` | bool | 固定 `true` |
| `seedance_defaults.prompt_suffix` | string | 中文约束，追加到每个 Seedance Prompt 末尾 |
| `seedance_defaults.negative_prompt` | string | 英文负面提示词，全剧统一模板 |

## 五、美术规范（架空古装宫廷 · 唐宋美学）

本项目为**架空古装宫廷剧**，不绑定特定朝代，以**唐宋宫廷美学**为视觉基调。

### 5.1 必须体现（Must Include）

| 类别 | 元素 |
|------|------|
| **服装** | 唐宋风格汉服（交领/圆领袍、大袖衫、凤冠霞帔）；帝王龙袍黑金配色；皇后红金朝服；后妃粉紫华服；太后深紫凤袍；武将朝服深蓝 |
| **建筑** | 朱红宫墙、琉璃瓦顶、金砖地面、雕梁画栋、木质结构、石灯笼、曲折长廊 |
| **照明** | 油灯、蜡烛、龙凤喜烛、纸灯笼、石灯笼、月光——**禁止电灯** |
| **器物** | 铜镜、毛笔、宣纸、砚台、青铜香炉、红木家具、瓷器茶具、竹简/卷宗 |
| **宫廷符号** | 龙凤纹饰、祥云纹、莲花纹、双鱼纹、佛珠 |

### 5.2 禁止出现（Must NOT Include）

| 类别 | 元素 |
|------|------|
| **现代物品** | 智能手机、汽车、电线杆、霓虹灯、水泥建筑、塑料制品、拉链、手表、眼镜 |
| **现代科技** | 电灯、电线、开关、屏幕、电梯、空调、麦克风 |
| **特定朝代** | 清代发式（辫子/旗头）、清代服饰（旗袍/马褂） |
| **现代符号** | 文字/Logo/商标、英语/拼音标志、二维码、现代印刷字体 |
| **画面质量** | 模糊、变形、低画质、水印、烧录字幕、动漫风格、卡通风格、水彩风格、油画风格 |

## 六、AI 出图/视频衔接

### 6.1 出图流程

1. **定稿 L01 参考图** → Character Sheet（正面全身，白底/中性背景）
2. **衍生形象**用图生图 / 角色一致性模型 → **delta Prompt** 仅写服装/道具/妆效差异
3. **禁止跳过 L01 直接生成 L02**
4. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01

### 6.2 形象一致性规则

| 规则 | 说明 |
|------|------|
| **同脸原则** | CHAR-001-L01、CHAR-001-L02、CHAR-005-L01 保持相同面部结构（鹅蛋脸+丹凤眼），差异仅在表情、妆容和神态 |
| **姐妹区分** | CHAR-001（沈凤尘）眼神"如火"——灼热、倔强、锐利；CHAR-005（沈凤仪）眼神"如水"——温柔、沉静、忧郁 |
| **关键道具追踪** | 珠钗（CHAR-001-L01 发间必有，L02 藏于袖中）、双鱼佩（CHAR-001 腰间 + CHAR-005 腰间各半）、佛珠（CHAR-004 手中必有） |
| **一致性锚点** | 每角色至少保持 3 个不变特征：发型轮廓 + 服装主色 + 核心配饰 |
| **竖屏构图** | 单人形象以半身/七分身为主；双人对白用上下或对角线构图（非并排）；背景留白适配字幕叠加 |

### 6.3 Prompt 书写规范

**L01（完整 Prompt）**：
```
A [age]-year-old Chinese [gender], [build], [face shape and features], [hair], wearing [clothing],
[pose], [environment], [style tags], character sheet
```

**L02+（Delta Prompt）**：
```
Same face as CHAR-###-L01. [changed elements only — hair, clothing, makeup, environment].
[Same style tags].
```

### 6.4 参考图策略

#### 配额限制

- **每 segment 最多 6 张参考图**（TOS 模式）
- 角色定妆：`assets/looks/CHAR-*-L##.png`
- 场景参考：`assets/scenes/SCENE-*.png`
- 道具参考：`assets/props/PROP-*-*.png`

#### 参考图优先级（P0 → P4）

| 优先级 | 资产类型 | 说明 |
|--------|---------|------|
| P0 | 主角形象（CHAR-001, CHAR-002） | 必须保证，占 90% 以上画面 |
| P1 | 对话角色形象（CHAR-003, CHAR-004） | 有互动的角色必须锁定 |
| P2 | 场景参考图 | 保证环境跨集一致性 |
| P3 | 关键道具 | 珠钗、双鱼佩、密诏、佛珠等 |
| P4 | 次要角色/群演 | 青萝、福安、沈侯爷等 |

## 七、道具转移与肢体动作（防错清单）

### 7.1 常见 AI 错误

| 错误类型 | 表现 | 预防策略 |
|----------|------|----------|
| 道具瞬移 | 前镜在手中，后镜消失 | segment 内不跨镜转移道具；跨 segment 在 Prompt 明确"手持XXX" |
| 道具变形 | 玉佩变成金锁、佛珠变成项链 | 关键道具在 Prompt 中附尺寸、材质描述（如"5cm fish-shaped cyan jade pendant"） |
| 手部畸变 | 手指数量错误、手势扭曲 | 避免特写手部动作；握持道具用手部"包裹"描述 |
| 服饰穿越 | 沈凤尘冷宫段突然穿回皇后装 | L02 Prompt 中明确"no jewelry, no phoenix crown, no red fabric" |
| 珠钗错误 | 冷宫段珠钗出现在发间 | CHAR-001-L02 明确"pearl hairpin is notably absent from hair (hidden in sleeve)" |
| 双鱼佩位置 | 左右反转或消失 | 在 Prompt 始终用"hanging at left waist"固定位置 |

### 7.2 肢体动作 API 规则

- **双手交接道具**：必须在同一 segment 内完成，不可跨 segment
- **开门/关门/推门**：动作链必须在同一 segment 内；门的状态变化（开→关）不可跨 segment
- **跪拜/起立**：动作链完整在一个 segment 内
- **手部特写**（握玉佩、攥信、掐掌心）：时长 ≥ 4 秒，单独一镜
- **单段主说话人 ≤ 2**；长对手戏拆成 `SEGxxa` / `SEGxxb`

### 7.3 分段检查清单

- [ ] 每 segment 时长 4–12 秒（理想 8–10 秒）
- [ ] 每 segment 1–3 个镜头
- [ ] 对话不在中间切断（一句台词完整在同一段内）
- [ ] 连续动作不在中间切断（开门/摘道具等动作链完整）
- [ ] 跨 segment 边界：场景切换、主说话人切换、情绪断点
- [ ] 单镜自然时长 < 4 秒 → 并入同场景相邻段

## 八、有声段落（Seedance 2.0）

### 8.1 分段规则

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 约 12–15 段 | 对应单集 2.5 分钟时长（~150s ÷ ~10s/段 ≈ 15 段） |

### 8.2 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 8.3 场景 vs Segment（关键区分）

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 8.4 镜头模式分配

| 镜头类型 | 模式 | 说明 |
|---------|------|------|
| 环境空镜（无角色） | `t2v` | 纯文本描述，无参考图 |
| 角色出镜 | `i2v_ref` | 需角色参考图保持一致性 |
| 片头/片尾/黑屏 | `skip` | 非 AI 生成，后期合成 |

### 8.5 字幕策略

- **Seedance 不烧录字幕**——Prompt 中必须声明 `"禁止画面中出现任何文字或字幕"`
- 字幕通过 **ffmpeg 后期统一叠加**（ASS/SSA 格式）
- 剧中文字（密信内容、牌匾、字条等）如果在画面中必须可见 → **后期合成**，AI 无法可靠渲染中文
- 疯妃含混音节的字幕翻译在画面上方呈现

### 8.6 音频策略

- Seedance `generate_audio: true` 合成基础环境音 + 对白 TTS
- 特殊音效（敲门声、玉佩碰撞、烛火爆裂、水声）标注在分集剧本镜头表 `对白/备注` 列
- 配乐标注在分集剧本 `本集制作备注` 中
- EP36 片尾闪回为后期合成片段（非 AI 生成）

### 9.2 一致性要求

- 同一角色跨所有 segment 的 `voice_prompt` **全文一致**
- 情绪变化只在"强度"上调整，不在"音色"上切换
- CHAR-001 与 CHAR-005 必须声线完全不同（虽同脸）
- CHAR-003 与 CHAR-004 必须有明显年龄差异

### 9.3 疯妃特殊处理

- CHAR-006 先录制清晰台词 → 降采样 + 添加噪点 + 模糊化处理 → 制造"被割舌后含混"效果
- 画面中疯妃发出含混音节时，画面上方叠加字幕翻译
- EP25 寿宴中福安同步"翻译"疯妃的话 → 双声轨：含混原声 + 清晰翻译

### 9.4 密信旁白

- CHAR-005 的密信内容使用"带混响的内心独白"效果——声音空灵，像从另一个世界传来
- 标记方式：分集剧本中写 `**CHAR-005**[密信旁白·混响]：「...」`

### 9.5 音效/配乐标注规范

- 在分集剧本的镜头表中标注 `对白/备注` 列
- 格式：`（无对白，[音效类型]）` 如 `（无对白，敲门声+风声）`
- 配乐标注在 `本集制作备注` 中按 segment 分列

## 十、分集剧本格式规范

### 10.1 必须包含的结构（按顺序）

| 序号 | 部分 | 必选 | 说明 |
|------|------|------|------|
| 1 | YAML 文件头 | ✅ | 按第四章模板 |
| 2 | 集标题 + 引用导航 | ✅ | `# EP## 集标题` + 修改顺序提示 + 角色卡/场景卡链接 |
| 3 | 元信息摘要表 | ✅ | 叙事目标、钩子、默认形象、有效镜数、Segment数、版本 |
| 4 | 本集观众必须听懂 | ✅ | 编号列表：谁、发生什么、为什么、下集看什么 |
| 5 | SEG 正文 | ✅ | 按 Segment 分组的镜头表（11 列格式） |
| 6 | 结尾钩子 | ✅ | 一句话悬念 + 下集标题预告 |
| 7 | 本集制作备注 | ✅ | 情绪弧、光线、造型、音乐、节奏、关键细节 |
| 8 | 本集资产 | ✅ | 场景/角色/形象/道具/有效镜数汇总 |

### 10.2 11 列镜头表格式

```
| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白/备注 |
|------|---------|------|------|------|------|------|------|------|------|-----------|
```

#### 各列规范

| 列名 | 格式 | 说明 |
|------|------|------|
| 镜号 | 整数 | 全集连续编号（1, 2, 3...），不随 SEG 重置 |
| shot_id | `EP##-S##` | 全局唯一，如 `EP01-S01`、`EP01-S19` |
| 场景 | `SCENE-###` | 对应资产/场景卡片.md 中的 ID |
| 角色 | `CHAR-###` | 出镜角色，多人逗号分隔；无人写 `—` |
| 形象 | `CHAR-###-L##` | 本镜使用的形象版本，多人逗号分隔；无人写 `—` |
| 景别 | 中文 | 全景/中景/近景/特写/大特写 |
| 时长 | 整数秒 | ≥4（Seedance 最小单位） |
| 模式 | 枚举 | `t2v`（纯文本）/ `i2v_ref`（带参考图）/ `skip`（非AI） |
| 运镜 | 中文 | 固定镜头/缓推/镜头推近/镜头拉远/镜头跟随/快切/主观镜头 |
| 画面 | 2–4句 | 电影级视觉描述：布景、光线、人物姿态、道具、伏笔 |
| 对白/备注 | 格式化 | `**CHAR-###**[情绪]：「台词」` 或 `（无对白，[音效]）` |

### 10.3 对白格式

| 场景 | 格式 |
|------|------|
| 有对白 | `**CHAR-###**[情绪·语气]：「台词」` |
| 内心独白 | `**CHAR-###**[内心]：「...」` |
| 无对白 | `（无对白，[音效]）` |
| 密信旁白 | `**CHAR-005**[密信旁白·混响]：「...」` |

### 10.4 SEG 块结构

```
---

## SEG## — [叙事功能]

**【SCENE-###】[地点]** · **[时段]** · **[内/外景]**

| 镜号 | shot_id | ... | 对白/备注 |
|------|---------|-----|-----------|
| ... |

> ⏱ Segment时长：Xs ｜ 镜头数：N
```

- 场景切换时写完整场景头：`**【SCENE-###】地点** · **时段** · **内/外景**`
- 同场景续接写：`**（续）**`
- 每 SEG 以 `---` 分隔，结尾附 `> ⏱` 统计行

### 10.5 画面描写质量标准

「画面」列禁止一句话空洞概括。每格必须 2–4 句，包含：
- 布景具体细节（桌面物品、墙面装饰、地面状态等）
- 光线/色温/明暗——情绪外化
- 人物姿态/微表情/手部动作/视线
- 与剧情相关的道具互动
- 暗示/伏笔元素（可选但推荐）
