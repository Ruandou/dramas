## 一、ID 命名规则

所有资产使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### 形象层级结构

| 后缀     | 名称     | 说明                                           |
| -------- | -------- | ---------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                   |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01    |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3a）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨 segment 出现 → 独立 CHAR-###；纯背景无台词 → CHAR-GRP

## 二、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于 story-architect 大纲元数据中的「视觉风格」和「色彩基调」字段。

| 维度 | 规格 |
|------|------|
| 渲染风格 | stylized realism（偏写实国风，介于 photoreal 与 donghua 之间） |
| 镜头参考 | cinematic 85mm lens（人物特写/情绪），wide-angle 24mm（场景/群像） |
| 色调方向 | 塌方期：冷紫/暗蓝 desaturated；生命灵力：暖金色 glow；冰原：冷白/淡蓝 |
| 画幅 | 9:16 vertical |
| 题材关键词 | 仙侠、古风、灵气修炼、逆袭、上古遗迹、东方奇幻 |

### prompt_suffix（所有图片生成统一后缀）

```
ancient Chinese xianxia fantasy, cinematic lighting, 9:16 vertical composition, rich atmospheric detail, film grain, high production value, Tang-Song dynasty inspired architecture and costumes
```

### negative_prompt（结构性禁忌 — 制片规范层）

```
modern buildings, skyscrapers, concrete structures, cars, vehicles, phones, smartphones, screens, modern technology, neon lights, LED lights, electric lights, modern clothing, jeans, t-shirts, suits, sneakers, wristwatches, glasses, sunglasses, western architecture, gothic, industrial, cyberpunk, anime style, cartoon, 3D render look, plastic skin, over-saturated
```

> 创意领域 negative_prompt（如特定风格排除）由 character-designer 和 scene-prop-designer 各自负责。

## 四、分段规则

### 分段（Segment）—— AI 生成单位

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 12–15 段        | 对应单集 2.5 分钟时长                                   |
| 单集时长目标     | 150–180 秒      | 最短 140s，最长 200s                                    |
| 每集镜头数       | 15–30 镜        | 对应 12-15 segments                                      |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 六、分集剧本格式规范

> 分集剧本（`剧本/EP##/EP##_*.md`）是单集的**真相源**，所有后续文件（shots.yaml / segments.yaml）必须从此导出。

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`

## 七、工作流顺序（修改层级）

制片规范确立后，所有内容修改**严格按层向下**：

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_灵气塌方_36集.md` | 集纲、每场剧情、对白要点、钩子                      |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡片、资产索引等       | 仅在前几步定稿后随需更新                            |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 十、音色规范

### 语音描述格式

每个有对白的角色必须有 `voice_prompt`，格式：
```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

### 旁白与音效

- 旁白角色不分配 CHAR-ID，写为「旁白」，voice_prompt 独立定义
- 分集剧本镜头表中标注音效（如 `敲门声`、`紧张弦乐`）
- Seedance `generate_audio: true` 合成基础环境音；特殊音效后期叠加

### voice_prompt 权威来源

| 优先级 | 文件 | 说明 |
|--------|------|------|
| **P0（最高）** | `资产/声音卡片.md` | 专门定义声音参数的文件，最细粒度、最权威 |
| P1 | `资产/角色卡片.md` | 角色总览中的 voice_prompt 字段 |
| P2（兜底） | `制片规范.md` | 制片规范中的音色段落 |

## 十一、年代/题材约束

### 必须体现元素（叙述性，Prompt 由设计师负责）

- 中国古代仙侠世界：飞檐斗拱、玉石建筑、云海山峦
- 修炼文化视觉符号：灵石、丹药、法器、飞行法宝
- 灵气可视化：紫色裂缝（塌方）、金色光芒（生命灵力）、淡蓝/白色气流（普通灵气）
- 等级视觉差异：杂役粗布 → 内门锦袍 → 长老法衣

### 禁止出现元素

- 任何现代科技产物（建筑、交通工具、通讯设备、照明设备）
- 任何西方文化符号（哥特建筑、西式服饰、十字架等）
- 任何未来/科幻元素（机甲、激光、屏幕UI）
