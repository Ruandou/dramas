## Top 3 问题（按严重程度排序）

### 问题 1：免疫军团导致角色爆炸（12人），超出AI一致性生成合理范围
- **位置**：EP24-36（第三幕）
- **问题描述**：7名免疫者各有个性和能力分支（卖菜大婶生发、铁匠锻铸、少女净化、乞丐感知、石头共鸣+2散修），加上5名核心角色（陆尘、白染、苏谨、灵虚/噬灵尊者、墨渊），总计12人且有不同能力展示。当前AI视频生成对12个独立角色的一致性控制远超合理边界。
- **影响维度**：制作可行性（当前3分，修复后可提升至4分）
- **建议修改**：
  1. 将免疫军团从7人压缩至4人：卖菜大婶 + 铁匠学徒 + 退婚少女 + 石头，去掉老乞丐和2散修
  2. 老乞丐的"感知"能力合并给苏谨（她本身就是半灵体），2散修的戏份精简为无台词群演
  3. 四人各分配一个功能性高光时刻（而非7条独立支线），群像用分镜切换代替同时出镜

### 问题 2：EP14-18中段存在连续情绪平坦风险
- **位置**：EP14（逃亡）、EP15（苏谨坦白）、EP16（海兽）、EP17（苏谨濒死）、EP18（审判）
- **问题描述**：虽然每集有悬念，但这段"逃亡→寻找阵眼"的公路片结构连续5集缺乏"打脸时刻"，情绪类型以压抑/逃亡为主，缺少爽感释放点。观众可能在EP16附近产生疲态。
- **影响维度**：情绪收益（当前4分，如不处理实际可能滑至3分）
- **建议修改**：
  1. 在EP16中插入一个"反杀"节点：海兽不是被引开，而是被陆尘在逃亡过程中意外驯服/吸收，获得首场正面胜利
  2. EP18结尾不要停在"陆尘击败追捕队"，改为追加一个"五大域长老收到被打脸的视频"彩蛋式收尾

### 问题 3：EP01缺少主角"隐藏力量"的明确暗示，纯靠设定巧合
- **位置**：EP01
- **问题描述**：陆尘在EP01中的定位是"劈柴都劈不利索的纯废物"。灵气塌方来临时，他的免疫完全来自"修为为零"的设定巧合，缺少任何暗示他"天生特殊"的铺垫。观众可能觉得"这纯属运气好"，而非"他注定不凡"。短剧前3集是付费转化关键窗口，第1集必须埋下"他不是普通废物"的暗线。
- **影响维度**：观众留存（当前4分）+ 商业性
- **建议修改**：
  1. 在EP01杂役场景中增加一个小细节：别人劈的柴次日会枯萎，陆尘劈的柴次日竟发芽了（生命灵力的早期征兆）
  2. 或：陆尘被踹倒时手掌擦破，伤口在3秒内愈合（但陆尘自己没注意到，只有镜头捕捉到）
  3. 此改动不影响后续剧情走向，仅增加第1集的"命运暗示"

### 合规性检查

- **题材分级**：🟡 B级（玄幻）
- **核心导向**：冒险逆袭 + 环保隐喻（灵气枯竭/回流/重建），非宣扬封建迷信
- **风险点**：
  1. "禁忌阵法""献祭""万年执念"等表述有擦边封建迷信的风险 → 建议统一改为"上古能量阵法""能量转生"等中性措辞
  2. EP11"献祭"场景：陆尘被绑上祭坛抽取生命灵力 → 建议弱化祭坛的宗教符号感，强化"能量抽取装置"的科幻感
  3. 噬灵尊者的"复活/转世"机制 → 需明确是能量层面的转移而非灵魂转世迷信
- **建议调整**：Stage 4 写剧本时注意措辞，核心情节无需大改
- **整体判断**：核心导向安全，措辞微调即可，不构成阻断

### 制作可行性细节

- **核心角色数量**：5人（陆尘、白染、苏谨、灵虚/噬灵尊者、墨渊）
- **次要角色数量**：7人（免疫军团）+ 暗影宗使者 + 五大域追捕队 → 总计12+ 个需独立设计的角色
- **主要场景**：6个（天玄宗 / 暗影宗地牢 / 荒山古洞 / 东海龙墟 / 北荒冰原 / 天玄山腹地），数量可控
- **高难度场景**：
  1. EP01-02 灵气塌方全局特效（紫色裂缝、灵气外泄、修为倒退可视化）
  2. EP12-13 灵气回流/潮汐风暴（大面积粒子特效）
  3. EP16 海底变异海兽（大型生物 + 水下场景）
  4. EP27-34 天玄山腹地大战（灵气回流 + 免疫军团合体 + 阵法逆转）
- **道具管理**：断剑（赤霄赠灵虚）是关键道具，需在道具卡片中建立 PROP-ID 追踪其出场/转移链
- **建议**：压缩免疫军团至4人（见Top 3问题1），海底战改为洞窟战降低场景复杂度
