## 一、ID 命名规则

所有资产统一编码，**编号只增不删**；弃用标 `deprecated: true`。

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同群演角色独立 ID + L01    |
| 场景     | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### 本项目 ID 分配现状（v1.0）

- **CHAR-001 ~ CHAR-008**：主要角色 8 人（**已达上限，任何阶段禁止增设主要角色** —— R1 结构性观察 ③ 转硬约束）
- **CHAR-009 ~ CHAR-012**：功能性配角 4 位（厉狂 / 墨母 / 无名 / 原主残念，全部源自大纲附录角色清单 11 行）
- **CHAR-011 / CHAR-012 复用关系（大纲既定，零新增参考图）**：无名（含 2.0）与原主残念为独立对白/音色实体，但**不拥有独立形象**——其形象登记为 `CHAR-001-L02`（无名形态：半面裂纹面具+黑雾）与 `CHAR-001-L03`（残念形态：通体青白魂光），均复用 `CHAR-001-L01` 参考图 + Prompt delta 叠加，**不生成新参考图**
- **CHAR-GRP-01 ~ CHAR-GRP-06**：大纲正文「互动角色」中跨集反复出现的功能位（宗主/商队首领/凡人孩童→提灯少年/剑宗长老/黑袍人图纹师/北冥贤长老）；单场一次性角色（坊市摊主、刺客、执法长老、关卡幻象、众弟子等）由 scene-writer 标注 `[待补：...]` 后在集间群演回补子循环分配（从 GRP-07 起）
- **SCENE-001 ~ SCENE-010**：大纲附录 10 核心场景（**已达上限，禁止新增独立场景**；生死关/论道台/镇魔井等一律以既有场景子分区登记，共用美术体系）
- **PROP-001 ~ PROP-009**：大纲附录 9 项关键道具（8 项待生成 + 1 项角色内置）；酒壶/护身符/天火等软道具不占 PROP-ID（见道具卡片「软道具备忘」）

### 形象层级

| 后缀     | 名称     | 说明                                        |
| -------- | -------- | ------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01`

### 元叙事意象呈现边界（本剧特有 · 强制）

本剧后期含"键盘声/作者栏"等元叙事意象。**negative_prompt 的"禁现代元素"依然全局生效**，下列为唯一枚举例外，且各有严格呈现边界；segment-builder 在对应集显式引入，其余任何集出现现代元素一律视为穿帮：

| 意象 | 集数 | 呈现边界 |
|------|------|----------|
| 键盘声 | EP62 | **纯音效**（地宫门缝传出）。画面严禁出现键盘/电脑/屏幕等任何现代实物 |
| 作者的书房（SCENE-009） | EP63–65/70/77–78 | 陈设全部为古风映射：满地**稿纸+毛笔**、停摆的更漏、冷茶、藤椅。零现代书房元素 |

| 天空金字/章节标题/头顶浮字 | EP01/24/60/82 等 | 金色"字化"光效 + **简体中文**（Simplified Chinese characters），属世界内规则视觉，不算穿帮；字形须人工核验无讹变 |
| 书封/作者栏 | EP86 | 古装线装书实体特写；封面题字为简体中文书法（旧名《天命之子》淡去→新名《反派他不想营业了》；作者栏空白；小字"待续，由所有人"）。**不出现任何屏幕/网文平台 UI** |

凡 `资产/道具卡片.md` 中标注「⚠️ 中文文字」的道具（PROP-001 残页、PROP-003 换命图、PROP-006 枯笔，及 PROP-001 附属书封），其参考图 Prompt **必须**包含 `Simplified Chinese characters, clear legible calligraphy` 类指令并写明确切文字内容；生成后必须人工核验字形无讹变，方可标记 `✅ 已生成`。

## 六、分段规则（Segment）

| 约束             | 值              | 说明                                    |
| ---------------- | --------------- | --------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                 |
| 每 segment 镜头数 | ≤3 镜；段 ≥8s 必 ≥2 镜（典型 2-3） | 静音视觉锤段可单镜但 ≤8s |
| 最小叙事单位     | 1 个完整 beat   | 每段必须构成完整叙事节拍                |
| 每集段落数       | 6–10 段         | EP01 可至 12 段                         |

**拆分原则**：
1. 不得在一句台词中间切断 segment
2. 不得在连续动作链（扯面具、挡剑、坐回躺椅等）中间切断
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆 `SEGxxa` / `SEGxxb`
5. 分镜某镜自然时长 < 4 秒 → 并入同场景相邻段

**关键区分**：SCENE-### = 空间单位；SEGxx = AI 生成单位。同一场景可含多个 segment；segment 不得跨场景。

**分集剧本格式**：11 列镜头表（镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注）；SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs`；对白格式 `**CHAR-###**[情绪]：「台词」`，无对白写 `（无对白，[音效]）`。

## 八、音色规范

- voice_prompt 权威来源优先级：**P0 `资产/声音卡片.md`** > P1 角色卡片 > P2 本规范。存在 P0 一律用 P0。
- 同一角色跨 segment 的 voice_prompt **全文一致**（segment-builder 从声音卡片全文复制，「」为可读性标记，YAML 只取括号内纯文本）。
- 角色情绪波动（如血屠怒时轻声、文曲哭与狠同频）由 segment 级情绪标注控制，**不改 voice_prompt**。
- **同源音色组**：CHAR-011（无名）/CHAR-012（残念）与 CHAR-001 同源——冷版/倦版差异写死在各自 voice_prompt 内，三者不得混用。
- 旁白不分配 CHAR-ID，voice_prompt 在声音卡片独立定义。
- 群演一次性台词优先复用声音卡片「通用路人音色库」。
- character-designer 如需修改 voice_prompt，走角色卡片 `voice_feedback` 子节 → drama-director 集间循环审阅 → 采纳后更新声音卡片 P0。

## 九、年代/题材约束（叙述性）

**架空玄幻「九州玄界」**（无现实朝代映射，无系统无任务的穿书世界观）。

必须体现：
- 文气金光视觉体系：金色"字化"光效为全剧规则可视化语言（天空章节金字、对写之战字与字相撞、头顶浮字），高潮段点睛使用
- 魔宗/剑宗双阵营美术对比：北冥宗玄黑暗金 vs 青云剑宗白石清冷；主角小院是魔宗里的"世外桃源"反差
- 误读喜剧的表演空间：反应镜头（全场愕然/石化三秒/齐声顿悟）是本剧喜剧引擎，分镜须为群像反应留位
- 明亮喜剧质感：低饱和写实但不阴郁，魔宗戏也保持"威压与荒诞并存"

禁止出现：
- 一切现代物品与现实宗教符号（见第二节 negative_prompt；元叙事例外仅限枚举清单）
- 可识别的真实朝代服制/年号/地名/政治指涉
- 祭祀仪式具象：魔渊大祭线全程只拍阴谋对话+空祭坛空镜（EP09/50/54 合规拍法已锁定），祭坛终局定性为被挫败的罪证
- 虐杀/羞辱过程：厉狂下线（EP22）"自食恶果+宗规处置"一笔带过；血屠伏法（EP76）"众证+规则处置+锁入镇魔井"
- 炼药虐童具象（EP02 只拍"放走+塞盘缠"）

## 十、受众定位

## 十二、内容合规参数

- **题材合规等级**：🟡B 级（drama-director 快检通过）。架空玄幻穿书题材；核心行为=反抗剧本宿命，结局落点"命是自己一笔一笔活出来的"（人定胜剧本）；R1 合规维度 4 分（唯一扣分原因为题材非纯 C 级，处理层面零问题）。
- **本剧特定红线**（工作计划「题材合规边界」①②③ + 大纲合规声明④，强制）：
  1. 架空玄幻世界观，全剧不出现任何现实宗教符号、仪式与称谓；魔渊大祭零仪式具象（EP09/50/54 只拍阴谋对话+空祭坛空镜）
  2. "天命剧本"仅为穿书元设定，不宣扬占卜/宿命论——主角全程反抗剧本宿命，残页预言必须与"反抗/改写"动作绑定呈现，不得出现"信命认命"正向表达
  3. 无现代政治/军事/公安司法元素（元叙事现代意象仅限第二节枚举例外及其呈现边界）
  4. 无低俗擦边、无以暴制暴：反派伏法一律"众证+规则处置"（EP22 厉狂宗规处置、EP76 血屠万人指证+锁井），不拍虐杀/羞辱过程
  5. 涉童情节零阴暗具象：EP02 炼药孩童只拍"放走+塞盘缠"；文曲虽为 8 岁童子外形，其"残酷"只走台词与表情，无肢体暴力加害画面
- **灰区处理策略**：
  1. 元叙事现代意象（键盘声/心电监护音/都市灯火/作者栏）→ 按第二节呈现边界枚举执行，音效化/门框内虚焦化/古风映射化
  2. 血腥度 → EP35 挡剑血溅、EP67 血染战袍点到为止：血迹落在衣料，无伤口特写、无喷溅慢镜
  3. 处刑意象 → EP01 处刑幻象"一剑穿心"不拍穿刺细节，用剪影+金字"魔子伏诛"+惊醒切镜呈现
  4. 权谋夺权线 → 血屠阴谋全程负面呈现且终局伏法；主角侧权力观正向（EP59 拒位/EP85 无宗主制"权力关进规则"）
- **正向价值锚点**：①反宿命/自由意志——"自己选"贯穿爱情线与主题线（EP49/79/82）②真心与善行的因果回报——前期善行 EP73 全额回声、"文气只放大真心"（EP83）③创作者与读者的双向治愈——执念当化解不当诛灭（EP77/78）
- **平台审核重点提示（前 3 集）**：EP01 处刑幻象按灰区策略 3 处理，惊醒节奏快切不渲染恐怖；EP02 "该被抓去炼药"仅一句台词带过，画面只有放人+塞盘缠的暖场戏；EP03 让贤大比零武力冲突，全程文戏喜剧。
