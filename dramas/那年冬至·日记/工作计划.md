# 工作计划 · 《那年冬至·日记》

## 项目概要

| 字段 | 内容 |
|------|------|
| 剧名 | 那年冬至·日记 |
| 题材 | 年代情感 / 跨代救赎 / 双时间线 |
| 核心钩子 | 2026年冬至，孙女在整理奶奶遗物时发现一本1978年的日记——奶奶年轻时爱过一个人、做过一个决定、守过一个秘密，她决定替奶奶完成未了的心愿 |
| 目标受众 | 30-55岁女性（核心）+ 银发族（破圈），女频向 |
| 年代跨度 | 1978（奶奶的青春）↔ 2026（孙女的当下） |
| 题材分级 | 🟡 B级（年代戏，核心为情感，可规避政治敏感） |
| 爆款公式 | 《北往》的年代质感 + 《那年冬至》的跨代情感 + 双时间线叙事 |
| 总集数 | 72 集（默认） |
| 项目目录 | `dramas/那年冬至·日记/` |
