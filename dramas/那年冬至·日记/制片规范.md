## 二、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| 角色 | `CHAR-###` | `CHAR-001` | 对白、关系、选角 |
| 形象 | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉 |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01` | 按需创建，无上限 |
| 场景 | `SCENE-###` | `SCENE-001` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演按需创建，不设数量上限

### 渲染风格

| 维度 | 规格 |
|------|------|
| 渲染风格 | **写实（photorealistic）**，带年代质感滤镜 |

### 双时间线视觉规范

#### 1978 线 · 暖黄胶片质感

| 维度 | 规格 |
|------|------|
| 色温 | 暖黄色调（warm golden tone），偏橙褐 |
| 滤镜 | 胶片颗粒感、轻微褪色、低对比度 |
| 光影 | 自然光为主，室内昏黄钨丝灯光，窗光带尘埃感 |
| 画面质感 | 柔焦边缘、轻微光晕、老照片质感 |
| 色彩饱和度 | 中低，偏暖色系（米黄、土褐、军绿、暗红） |
| 风格关键词 | vintage, warm film grain, 1970s China, nostalgic, soft focus, golden hour |

#### 2026 线 · 冷暖交织都市写实

| 维度 | 规格 |
|------|------|
| 色温 | 冷暖交织——日常偏冷灰蓝，情感场景偏暖橘 |
| 滤镜 | 干净锐利，适度浅景深 |
| 光影 | 都市自然光 + 室内白炽灯/暖色台灯 |
| 画面质感 | 清晰写实，日记翻页时暖光渐入作为转场 |
| 色彩饱和度 | 中等，都市灰蓝为主基调，情感爆发时暖色溢出 |
| 风格关键词 | modern urban, cinematic realism, cool-warm contrast, shallow DOF |

### 日记翻页转场规范

日记翻页时画面从 2026 冷色调渐变为 1978 暖黄色调，暖光从页面中央扩散，覆盖整个画面后切入 1978 场景。

## 九、分段规则

### 分段约束

| 约束 | 值 | 说明 |
|------|------|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段（EP01: 10–12 段） | 对应单集 75–120 秒 |
| 每集镜头数 | 8–12 镜（EP01: 12–18 镜） | 对应每集段落数 × 1–3 镜/段 |

### 拆分原则

1. **不得**在对话中间切断 segment
2. **不得**在连续动作进行中切断
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 某镜自然时长 < 4 秒 → 并入同场景相邻段

### 关键区分

- **场景（SCENE-###）** = 空间单位
- **Segment（SEGxx）** = AI 生成单位
- 同一场景可包含多个 segment；segment 不得跨场景

## 十、双时间线切换规则

| 规则 | 说明 |
|------|------|
| 日记触发 | 念溪翻日记页 → 暖光渐入 → 切入 1978 场景 |
| 季节映射 | 1978 春天萌芽 ↔ 2026 冬天发现 |
| 平行选择 | 念溪选择映射玉淑当年选择 |
| 线索闭环 | 1978 埋线索 → 2026 找到对应 |
| 日记渐空 | 1978 故事接近终局，日记页面越来越少 |

### 时间线视觉切换标记

- 1978 → 2026：暖黄渐褪，冷色渐入，画面锐化
- 2026 → 1978：日记翻页特写，暖光从页面扩散，画面柔化+颗粒感

## 十二、音色规范

详见 `资产/声音卡片.md`（权威来源 P0）。

### 通用规则

- voice_prompt 格式：`「性别，年龄，音色特征，语速，情绪/说话习惯」`
- 同一角色跨 segment 的 voice_prompt **全文一致**
- Seedance `generate_audio: true` 合成基础环境音；特殊音效后期叠加
- 1978 线角色注意年代语音特征（方言色彩、年代用语语感）
- 2026 线角色用现代普通话

## 十三、年代/题材约束

### 必须体现的元素

- 1978 年代的工装、标语、厂房环境
- 书信传情、纸条、手抄诗集等年代浪漫元素
- 火车站送别、月台追车等经典年代场景
- 纺织厂工作场景（机器、纱锭、女工）
- 高考备考的年代细节（油灯、手抄笔记）
- 冬至节气的氛围（饺子、汤圆、冬日暖阳）

### 禁止出现的元素（1978 线）

- 现代电子产品（手机、电脑、LED 屏）
- 现代交通工具（高铁、网约车）
- 当代时尚元素（潮牌、运动鞋）
- 现代建筑风格（玻璃幕墙、霓虹灯）
- 塑料制品以外的现代材质家具

### 2026 线注意事项

- 都市场景保持真实感，避免过度美化
- 老宅/阁楼场景需保留老旧质感，不能翻新得太新

## 十四、内容合规参数

### 题材合规等级

**B 级（中等风险）**：涉及年代政治背景、家庭暴力（父亲阻止恋情）、逼婚、未婚怀孕等敏感内容。

### 本剧特定红线

1. **不直接描绘政治运动场面**：1978 年代背景仅作为情感框架，不展开政治批判
2. **逼婚/家庭暴力以情感冲击为主，避免血腥暴力画面**
3. **未婚怀孕以心理压力呈现，不涉及堕胎等敏感医疗行为**
4. **告密行为不与具体政治事件挂钩**，仅作家庭伦理叙事
5. **老年人离世场景以安详/释然为主，不渲染过度悲伤**

### 灰区处理策略

| 灰区 | 处理方式 |
|------|----------|
| 陈建国截信/逼婚 | 以"父亲的保护"为动机，避免纯反派化，后期通过林福贵遗信实现理解 |
| 未婚怀孕 | 仅通过日记文字暗示，不出现显怀/生产画面 |
| 两位老人先后离世 | 以安详/释然/传承为基调，不渲染病痛痛苦 |

### 正向价值锚点

1. **跨代理解与治愈**：三代人从误解到和解
2. **勇敢去爱**：不重复上一代的遗憾
3. **沉默中的深情**：林福贵式无声大爱

### 平台审核重点提示

- EP01：葬礼场景控制悲伤程度，避免过度阴郁
- EP02–06：甜蜜线正常，无风险
- EP10–11：父亲暴力阻止场景——撕信+禁足可以，不能有肢体暴力
- EP25–26：怀孕+逼婚——暗示即可，不出现显怀/医疗画面
- EP43–50：病危+离世——安详离世为主，监护仪变直线可用，不出现抢救/CPR 画面

## 十七、工作流顺序（必读）

| 顺序 | 层 | 文件 | 写什么 |
|:---:|---|------|--------|
| **1** | **主剧本** | `短剧剧本_那年冬至·日记_72集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。
