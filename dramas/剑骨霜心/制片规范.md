### 1.1 世界观核心设定

- **架空仙侠世界**：古代美学基底，无具体朝代。修仙界以六大宗门为尊，苍梧剑宗为其中之一
- **修仙境界**：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 大乘
- **剑灵设定**：器物在漫长岁月中可萌生意识，剑灵化形为上古奇迹——"非妖非魔，乃剑道至纯之体现"
- **天魔二面性**：远古天魔之力分为「至纯」与「至暗」两面。霜心剑 = 至纯之力化身；至暗之力被独立封印
- **天道法则**：器物不得有情，违者天道降「灭灵劫」抹杀灵识
- **记忆封印**：忘川术——上古封印术，随时间加强，三千年后几乎不可逆。唯一破解：被封印者自行想起

### 1.2 核心冲突

- **表层**：苏霜心寻找旧主沈长渊，发现他已忘记自己
- **中层**：记忆封印背后的阴谋——玄机真人利用师徒信任抹去记忆，图谋天魔之力
- **深层**：自我决定 vs 宿命论——从"工具"到"自主个体"的蜕变；选择源于本性，而非记忆

### 1.3 五幕结构

| 幕 | 集数 | 核心叙事 | 情绪基调 |
|----|------|----------|----------|
| 第一幕：觉醒 | EP01–EP07 | 剑灵化形 → 进入人间 → 发现旧主 → 被无视 | 孤独→好奇→震惊→心碎 |
| 第二幕：靠近 | EP08–EP14 | 展示天赋 → 引起注意 → 记忆封印 → 暗中调查 | 希望→骄傲→困惑→紧张 |
| 第三幕：代价 | EP15–EP21 | 真相揭露 → 被迫害 → 逃亡 → 以力换记忆 | 愤怒→恐惧→温暖→悲壮 |
| 第四幕：牺牲 | EP22–EP28 | 短暂幸福 → 天魔苏醒 → 身世揭秘 → 自我牺牲 | 温馨→紧张→震撼→悲怆 |
| 第五幕：重生 | EP29–EP36 | 寻找复活 → 燃尽寿元 → 失去记忆 → 新的开始 | 绝望→坚定→释然→温暖 |

## 四、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |

| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

```yaml

  ratio: "9:16"
  resolution: 720p
  image_resolution: "1600×2848"
  duration_sec: "8-10"
```

## 九、分段与镜头规范

### 9.1 分段（Segment）规则

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 12–15 段 | 对应单集 2.5–3 分钟时长 |

### 9.2 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 9.3 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 9.4 分集文件头 YAML 模板

```yaml
---
episode_id: EP01
episode_title: 剑冢化形
duration_min: 2.5
season: S1
scene_ids: [SCENE-001, SCENE-002]
character_ids: [CHAR-001, CHAR-GRP-02]
look_ids: [CHAR-001-L01]
prop_ids: [PROP-001]
seedance_defaults:
  model: doubao-seedance-2-0-fast-260128
  ratio: "9:16"
  resolution: 720p
  image_resolution: 1024×1024
  duration_sec: "8-10"
  generate_audio: true
---
```

### 9.5 分集剧本格式规范

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`

## 十一、音色规范

### 11.1 旁白

- 本剧以角色对白+画面叙事为主，**无独立旁白角色**

- 特殊音效（剑灵共鸣、天魔低吼等）后期叠加

## 十二、年代/题材约束

### 必须体现

- 仙侠古风美学：交领广袖、仙山云海、御剑飞行
- 剑文化贯穿：剑冢、试剑台、剑招命名、剑意可视化
- 水墨意境：战斗中冰霜/灵力粒子与水墨风结合
- 东方建筑：石质山门、木质殿堂、竹林悬崖

### 禁止出现

- 一切现代元素（详见 §5.4 年代禁忌）
- 西式奇幻元素（龙与地下城式铠甲、魔杖、西方城堡）
- 日式元素（樱花、和服、武士刀造型）
- 过度暴露/性感化设计（角色着装需符合仙侠端庄美学）
