# 资产 · 角色卡片

> 由 production-planner (Stage 2) 创建角色 ID 骨架（身份元数据 + 性格概要 + 语言画像草案）。
> 由 character-designer (Stage 3b) 填充视觉设计（外貌描写、L01/L02+ Prompt、形象索引 Prompt 摘要）。
>
> **production-planner 保持的结构权威**：CHAR-### ID 编号、角色定位/关系结构、表格格式。
> **character-designer 不可修改**：CHAR-ID、角色定位、关键关系。

## CHAR-001 · 苏霜心

| 字段 | 内容 |
|------|------|
| ID | `CHAR-001` |
| 姓名 | 苏霜心 |
| 角色定位 | **女主角** / 剑灵化形 / 天魔至纯之力化身 |
| 阵营/派系 | 无→苍梧剑宗外门→内门→叛出→独立 |
| 年龄段 | 外表 18–20 岁（实际 3000+ 岁剑灵） |
| 首次出场 | EP01 |
| 关键关系 | CHAR-002 的前佩剑（剑灵）→ 同行者；CHAR-003 情敌/对立；CHAR-004 间接仇人 |
| 性格概要 | 温柔而坚韧，三千年孤独赋予她超越年龄的沉静。对世界充满好奇（剑灵视角），对"被替代"有深层恐惧。核心弧线：从"工具"到"自主个体" |
| 叙事功能 | 全剧主视角，驱动觉醒→靠近→代价→牺牲→重生的五幕弧线 |

### 形象规划（待 character-designer 填充）

| 形象 ID | 类型 | 名称 | 基于 | 适用 |
|---------|------|------|------|------|
| `CHAR-001-L01` | **基础** | 银发银瞳·剑灵态 | — | EP01–25（化形至消散/重生前） |
| `CHAR-001-L02` | 衍生 | 透明化/半消散态 | L01 | EP14–21（力量消耗阶段） |
| `CHAR-001-L03` | 衍生 | 黑发银瞳·重生态 | L01 | EP26–36（重生后） |

### 语言画像草案

- **词汇层级**：偏古典文雅，但偶尔出现天真的口语（剑灵不懂人间世故）
- **句式偏好**：短句为主，反问句少，多用陈述句表达笃定。情感高潮时句子更短更有力
- **口头禅**：「值得。」（EP14 名台词）；「这次是我选的。」
- **情绪表达**：内敛型。不轻易哭泣，沉默比哭更有力。极少爆发，爆发时极短促

| `CHAR-002-L02` | 衍生 | 素衣叛宗 | L01 | EP18–21（逃亡时期） |
| `CHAR-002-L03` | 衍生 | 苍老/寿元燃烧后 | L01 | EP25–36（重生后衰老） |

### 语言画像草案

- **词汇层级**：古典、克制、极简。话少但每句有重量
- **句式偏好**：极短句，多用否定句和反问。情感表达笨拙，常以行动代替言语
- **口头禅**：「与你无关。」（防御姿态）；「这次换我。」（EP18/EP32）
- **情绪表达**：极度压抑型。愤怒时反而更安静，悲伤时握剑手颤。唯一外放时刻：EP21 苏霜心消散后的冷静
