## 一、ID 命名规则

所有资产必须使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同视觉角色独立 ID + L01    |
| 场景     | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`         | 集数-镜号                        |

### ID 分配规则

- 编号**连续、不跳号**
- 形象层级：
  - **L01** = 基础形象（全剧面部一致性唯一锚点）
  - **L02+** = 衍生形象（必须 `based_on` 本角色 L01）
- **群演按需创建，不设数量上限**：有名字+跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词但需视觉区分 → `CHAR-GRP-##`。每个群演 ID 都必须分配独立 ID 和 L01 形象。
- 同一 `CHAR-GRP-##` 可跨集复用；不同视觉角色不可共用同一 ID。

- **建筑**：朱红大门、灰瓦飞檐、雕花木窗、月洞门、回廊
- **陈设**：青铜烛台、绢纱灯笼、紫檀木几、瓷器（青花/粉彩）

## 五、工作流顺序（必读 · 防不同步）

所有内容修改**严格按层向下**：

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_将军府弃妇的二次人生_72集.md` | 集纲、每场剧情、对白要点、钩子                      |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡片、资产索引等       | 仅在前几步定稿后随需更新                            |

> **禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

EP(N) 必须完整跑完 Stage 4 → G4 → R2 → Stage 5 → G5 五关全过，方可启动 EP(N+1) 的 Stage 4。**严禁批量/并行**。

## 七、分段（Segment）规则

### AI 生成单位

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 6–10 段         | 对应单集 75–120 秒（EP01 可至 12 段）                  |
| 每集镜头数       | 8–12 镜         | 对应每集 6–10 段 × 1–3 镜/段                            |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 分集剧本格式规范

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`

## 十四、视觉风格 — 进一步细化（角色/场景/道具共同约束）

### 面部一致性

- 同一角色在所有镜头中的 L01 形象必须**严格一致**（面部、发型、年龄）
- L02+ 衍生形象（换装/阶段）必须 `based_on L01`，**禁止跳过 L01**
- 跨段面部漂移不可接受；segment-builder 提交 Seedance 时**必须**将 L01 的 TOS URL 通过 `image_urls` 传入

### 场景/道具人脸禁令

- **场景参考图**中**严禁**出现任何人类面孔（含照片、画像、海报、贴纸、屏幕显示等平面媒介）
- **道具参考图**中**严禁**出现人类面孔
- 角色卡要求"墙上挂照片"时，改用物品替代（名牌/奖状/标志性物件）

### 文字语种

- 所有需要的标签、铭文、手写内容必须**完整拼出**且明确 **Simplified Chinese**
