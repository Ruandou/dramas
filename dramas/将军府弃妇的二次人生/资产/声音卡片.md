## 跨段一致性约束

### 关键约束

1. **同一角色跨 segment 的 `voice_prompt` 必须全文一致**——禁止缩写、改写、翻译、简化
2. segment-builder 写入 YAML 时**全文复制**本表内容（含括号内所有文字）
3. character-designer 可在 `资产/角色卡片.md` 对应角色条目下新增 `voice_feedback` 子节提出修改建议
4. drama-director 在集间循环中审阅 `voice_feedback`，若接受则更新本文件（标记新版本号）
5. 在建议被正式接受前，本文件 P0 版本始终为权威来源

### 写入 YAML 示例

```yaml
# segment-builder 写入示例
segments:
  - id: SEG01
    shots:
      - shot_id: EP01-S01
        voice_prompt: "成年女性，20岁，声线清冷但柔和，防备时语速快且压低，放松时温暖自然；以退为进时语调绵长不紧不慢，每句话都留三分余地"  # 全文复制 CHAR-001
```

## 群演回补机制

> scene-writer 在 Stage 4 写作中发现未分配群演时用 `[待补：描述]` 占位 + 「待补群演清单」，触发「集间群演回补子循环」由 `production-planner` 分配 `CHAR-GRP-##` ID + 在本文件添加对应 voice_prompt 条目（含 name + 性别 + 年龄 + 音色 + 语速 + 情绪/说话习惯）。

回补模板：

```markdown
### CHAR-GRP-XX · [群演名]

| 字段 | 内容 |
|------|------|
| **角色 ID** | `CHAR-GRP-XX` |
| **姓名** | [待补：scene-writer 提供] |
| **voice_prompt** | 「[性别]，[年龄]，[音色特征]，[语速]，[情绪基调/说话习惯]」 |
| **备注** | 适用 EP##–EP## |
```
