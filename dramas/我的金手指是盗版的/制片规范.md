## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同角色独立 ID + L01（按需创建，无上限） |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |

| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

- 编号**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象。
- 新建换装/阶段：**只加 `L02+` 衍生形象**，写明 `based_on: CHAR-xxx-L01`；禁止跳过 L01。
- scene-writer 标注的新群演（`[待补：...]`）由 production-planner 在集间群演回补子循环统一分配 `CHAR-GRP-##`（从已有最大编号+1）。

## 二、视觉风格锚点（Visual Style Anchor）

> 初始方向来源于大纲元数据「视觉风格 / 色彩基调」字段。创意细化由 3a/3b/3c 设计师负责。

| 维度 | 规格 |
|------|------|
| 渲染风格 | photorealistic 写实仙侠（AI 仿真人剧），明亮轻快，**避免阴暗滤镜** |
| 镜头参考 | cinematic 85mm（人物）/ 24-35mm（场景奇观），电影质感 |
| 色调方向 | 暖色明快主调（日光竹青+暖金）；反派线局部冷紫黑；系统 UI 蓝金撞色 |
| 画幅 | 9:16 vertical，720p（视频）/ 1600×2848（Seedream 参考图） |
| 题材关键词 | 青绿山水、古风建筑、剑修、盗版系统光球（像素噪点）、轻喜 |

### 2.1 全剧统一 prompt_suffix

```
写实仙侠电影质感，明亮轻快，青绿山水与古风建筑，日光通透，暖金与竹青主色调，竖屏9比16，画面全程无任何文字、字幕、标题、水印，无品牌Logo，无平台UI。
```

静音段专用 `prompt_suffix_silent`：

```
本段无对白无语音，禁止画面中出现任何文字。写实仙侠电影质感，明亮轻快，青绿山水与古风建筑，竖屏9比16，无水印，无Logo。
```

### 2.2 全剧统一 negative_prompt（含年代/题材禁忌，结构性约束）

```
modern clothing, suit, T-shirt, denim, sneakers, zipper, baseball cap, wristwatch, eyeglasses, smartphone, laptop, camera, car, motorcycle, bicycle, asphalt road, power lines, streetlight, neon sign, LED screen, glass curtain wall, modern building, plastic, QR code, real-world religious symbols, Buddha statue, crucifix, prayer beads monk, dark gloomy filter, horror atmosphere, blood, gore, corpse, text, subtitles, caption, watermark, logo, UI overlay
```

- **年代禁忌**：架空修仙界，禁止一切现代物品/现代建筑/现代服饰入画。
- **题材禁忌**：禁止现实宗教符号（佛像、十字架、念珠僧人等）；道袍/拂尘等泛化仙侠元素允许。
- **调性禁忌**：禁止阴暗恐怖滤镜、血腥具象（大纲已逐集附合规拍法）。
- 创意领域 negative（如画风排除）由设计师在各自 Prompt 中追加，不得删改上述结构项。

### 2.3 系统 UI 光球特别规则（⚠️ 全剧高频资产）

- 系统光球（PROP-002）为**剧内道具**，不属于被禁止的「平台 UI」，允许入画。
- **弹窗上不得出现任何可读文字**（画面文字禁令）：系统台词一律由语音播报（CHAR-002 voice_prompt）呈现；光球表面仅允许乱码像素纹理、抽象图标、故障噪点。
- 休眠态（EP24-31 等）为灰暗低亮变体，由 prop-designer 登记变体图。

## 六、分段与镜头规则（强制）

### 6.1 Segment 拆分（Seedance 硬限制）

| 约束             | 值              | 说明                                     |
| ---------------- | --------------- | ---------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | 超出必须拆分                             |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                  |
| 每 segment 镜头数 | ≤3 镜；段 ≥8s 必 ≥2 镜（典型 2-3） | v2.2；静音视觉锤段可单镜但 ≤8s |
| 最小叙事单位     | 1 个完整 beat   | 有动作起止、有情绪弧                     |
| 每集段落数       | 6–10 段（EP01 可至 12） | 见 §四B                          |
| 每集镜头数       | 16–30 镜（EP01 20-36） | 单镜理想 3-6s，>8s 须标注理由，>10s 禁止 |

**拆分原则**：①不得在对话中间切断；②不得在连续动作中切断；③拆段边界=场景切换/主说话人切换/情绪断点；④单段主说话人 ≤2，长对手戏拆 `SEGxxa/SEGxxb`；⑤某镜自然时长 <4s → 并入同场景相邻段。

**关键区分**：SCENE-### = 空间单位；SEGxx = AI 生成单位；同场景可多 segment，segment 不得跨场景。

### 6.2 台词节奏基准（引用 `docs/references/台词节奏基准.md` v2.3，单一真相源）

| 指标 | 硬门槛 |
|------|--------|
| 对白占比（全口径） | **EP02+ ≥85%、EP01 ≥70%**；豁免行不剔分母、合计 ≤4 行且逐行列清单 |
| 单句字数 | ≤30 字；全集中位落 **10-15 字**（>18 = 书面腔重写） |
| 发言块 | **单块 ≤4 句封顶**；对白块推荐 1-2 句、独白块 ≤2 句 |
| 台词密度 | 硬带 **210-330 字/分钟**（90s 集 ≥315 字；EP01 120s ≥420 字） |
| 纯独白段 | 全集 ≤2 段（EP01 ≤3）；相邻 SEG 不得同为纯独白 |
| 标点 | 省略号 ≤20/千字、破折号 ≤2/千字、感叹号 ≤10/集警戒 |
| 开场 | ≥90% 集数以对白开场；集末钩优选「一句台词定格」 |
| 语域分层 | 主角判词腔 ≤3 次/集，金句 2-4 句封顶，其余大白话（本剧主角=吐槽体，天然合规） |

### 6.3 分集剧本格式（11 列镜头表）

- 使用 **11 列**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注。
- **一行 = 一个镜头**；多句对白写同一格内换行，禁止空管子续行。
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs ｜ 镜头数：N`。
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`。
- 模板：`资产/_模板_剧本.md` / `_模板_shots.yaml` / `_模板_segments.yaml`（字段不得增删）。

## 八、音色规范

- **voice_prompt 唯一权威来源 = `资产/声音卡片.md`（P0）**；角色卡片（P1）/本规范（P2）仅为兜底。
- segment-builder 写入 YAML 时**全文复制**括号内纯文本，不含「」，禁止缩写/改写。
- 同一角色跨 segment voice_prompt **全文一致**；全剧固定 `seed: 78786` 配合详细声音描述提升音色稳定。
- **本剧无常设旁白**（全剧对白开场；EP07 等过渡用一帧画面交代，无需台词）。如个别集需旁白，由 scene-writer 提案、经 director 批准后在声音卡片新增「旁白」条目。
- 系统·九块九为全剧反差杀核心：山寨促销腔 ↔ 动情正常声线两态**都写进同一条 voice_prompt**，由台词情绪标记 `[正常声线]` 触发切换。
- 情绪标记：分集剧本对白用 `[怒]` `[低声]` `[内心]` 等；BGM：喜剧段轻快民乐、打脸段鼓点、悬疑暗线弦乐、泪点段钢琴/箫。
- 字幕/出场卡/地点卡均为**后期 overlay**（ffmpeg/burn_subtitles），严禁写进 AI 画面 Prompt。

## 九、年代/题材约束（叙述性）

**必须体现**：架空修仙界（无真实朝代指涉）；古风建筑+青绿山水；剑修文化（佩剑/剑袍/宗门礼仪）；系统 UI 光球带"盗版感"像素噪点；明亮轻快基调。

**禁止出现**：现代物品/服饰/建筑（§2.2 negative）；现实宗教元素；真实朝代符号（明确年号、真实历史人物）；血腥/刑讯具象（大纲逐集合规拍法为准：剪影定帧/昏迷送医式/喜剧化蹲防/囚而不刑/气焰剪影）；画面内任何可读文字（含系统弹窗文字，见 §2.3）。

**高难场面简化拍法（大纲已锁定，scene-writer/segment-builder 不得擅自扩景）**：EP24 万剑（特写+音效代偿）、EP44 兵器追人（近景掠影）、EP60 人群（局部蒙太奇）、EP61 大战（近景化）、EP74 万人还愿（祈愿灯特写）、EP82 万人齐诵（声浪+局部特写）；全剧唯一大 VFX = **EP68 星河修为灌体**。

## 十、受众定位

- **主频道**：通用（男女均衡，男频系统流底盘+女频感情线）
- **核心年龄段**：18-35
- **核心痛点**：①社畜生存压力，渴望"躺赢"式逆袭 ②平凡人不被看见/被低估 ③"冒名顶替感"——害怕被拆穿的普遍焦虑
- **爽感期待**：荒诞喜剧（系统出错）35% + 信息差/打脸爽（SAT-SLAP）30% + 揭秘震撼（SAT-MYST 暗线）20% + 情感冲击（人机线/感情线）15%
- **对标作品**：仙侠玄幻 AI 仿真人剧 Top 赛道（播放量占比 >80%，2026Q1）；「逆袭+穿越」双标签命中平台 Top50 标签 58%
