# 角色卡片 — 打工人听心声

> **版本**：v1.0（骨架）· 2026-08-03 · production-planner（Stage 2）
> **说明**：本文件为**骨架卡**。production-planner 仅填写 ID / 姓名 / 角色定位 / 年龄 / 阵营 / 首次出场 / 关键关系 / 叙事功能 / 性格概要 / 初始音色建议 / 关联道具 / 语言画像草案。**外貌描写、FACE ANCHOR、Seedream L01·L02 Prompt、形象索引 Prompt 摘要由 character-designer（Stage 3b）填充**。
> **骨架字段不可修改**：CHAR-ID / 姓名 / 定位 / 阵营 / 首次出场 / 关键关系 / 叙事功能 / 性格概要 / 初始音色建议 均沿用骨架。
> **权威来源**：voice_prompt 为 P1 建议，**权威在 `资产/声音卡片.md`（P0）**；CHAR-ID 权威在 `资产/角色索引.md`。
> **语言画像**：从故事大纲附录《角色语言风格预设计》提取，为 scene-writer 对白创作约束依据；character-designer 可在 Stage 3b 细化，但不得删除核心字段。
> **voice_feedback 机制**：character-designer 可在对应角色条目下新增 `voice_feedback` 子节提出 voice_prompt 修改建议；drama-director 审阅接受后更新 `资产/声音卡片.md`（P0）；在建议正式接受前，声音卡片 P0 版始终为权威。
> **⚠️ R1 合规红线**：CHAR-003（猫）/ CHAR-011（周国豪）/ CHAR-013（时先生）/ CHAR-015（林慧）涉能力者/意识留存表述，全程用「神经感应异常 / 记忆数据化留存 / 权限者网络」科技化用词，禁用「亡魂/灵异/招魂/安息/幽灵/超度/显灵/阴魂/附身/通灵/转世」（见制片规范 §十一红线1）。
> **⚠️ CHAR-015 林慧（妈妈）**：明确渲染为**健在 20 年前的人物照片 / 日记 / 录音 / 意识数据化留存**，禁止半透明/发光/幽灵态。
> 🎨 **视觉风格锚点**（制片规范 §二）：都市写实 photorealistic urban realism + 心声视觉化为**半透明音波纹/淡金光晕（后期浮层，非 Seedance 烧录）**；9:16 竖屏；对话戏 85mm 面部微表情；人物头顶预留 headroom（后期心声波纹浮层）。
> **通用 negative（inline）**：见制片规范 §六 negative_prompt；设计师可追加创意 negative（如禁动漫风格），但不得移除结构禁忌。
