## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个视觉不同角色独立 ID + L01（按需创建，无上限） |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**；**只增不删**，弃用标 `deprecated: true`。
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象。
- L01 = 全剧面部一致性的**唯一锚点**；L02+ 衍生形象必须 `based_on` 本角色 L01，禁止跳过 L01。
- 群演按需创建、不设上限；同一 `CHAR-GRP-##` 可跨集复用（如守卫甲 EP01-03 均出现），但不同视觉角色不可共用 ID（如"队长"与"年轻守卫"必须是 GRP-01 和 GRP-02）。唯一约束为 API 参考图配额（每 segment ≤6 张，TOS URL 模式），超出时按 segment-builder 优先级裁减。
- scene-writer 剧本中标注的新群演（`[待补：...]`）由 production-planner 在集间回补子循环统一分配 `CHAR-GRP-##`（从已有最大编号 +1），并建声音卡片条目 + 角色索引条目 + 形象索引骨架行；L01 形象图与角色卡片段落由 character-designer 回补。
- CHAR-ID 分配权归 production-planner；character-designer 不可自行新增。

### 形象层级结构定义

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 L01；禁止跳过 L01 |

> 形象 Prompt 内容、生成流程、delta 规则等视觉创意细节由 character-designer 负责（本 Agent 不定义视觉 Prompt）。

## 二、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于 story-architect 大纲元数据「视觉风格」与「色彩基调」字段（L6-L8）。

| 维度 | 规格 |
|------|------|
| 渲染风格 | 都市写实生活质感（photorealistic urban realism）+ 轻度奇幻心声波纹（UI 级小特效，无大 VFX） |
| 镜头参考 | cinematic；对话戏 85mm 面部微表情；心声浮现浅景深；心声洪水（EP28）失焦旋转闪切；听回忆（EP42+）暖金旧照片质感 |
| 色调方向 | **暖橙（白天办公）与雾蓝（深夜加班）双色调**；心声画面淡金微光 `#F5C97B`；静音状态冷灰 |
| 画幅 | 9:16 vertical（竖屏） |
| 题材关键词 | urban realism, warm office orange, misty blue night, subtle golden ripple overlay, cinematic close-up, workplace comedy, healthy office vibes |

### 核心视觉符号：心声波纹（全剧能力可视化 · 后期浮层）

> **实现方式**：心声波纹/光晕**不由 Seedance 视频生成烧录**，而在**后期以 ffmpeg / 合成浮层统一叠加**于成片。Seedance 阶段仅生成"角色倾听/心声说话"的表演与表情，构图预留"心声浮现空间"（prompt_suffix 含 headroom）。心声是**声音不是文字**，波纹为波形/光晕图形，**不涉及中文文字渲染**，天然规避 AI 中文乱码风险。

| 波纹类型 | 视觉规格 | 触发 |
|----------|----------|------|
| 心声波纹（人/动物/物件心声） | 半透明音波纹 + 淡金光晕 `#F5C97B`，浮现于说话者身旁/头顶，微浮动 | EP01 起，全剧常态 |
| 心声洪水（全景读心） | 多声道混响 + 淡金光晕快速闪切 + 画面偏白耳鸣式音效 | EP28（不可能时刻#1） |
| 听回忆模式 | 暖金色旧照片质感 + 波纹涟漪 + 回忆画面以旧照片/物件特写呈现 | EP42/52/58/64/73 |
| 听未来（胖达） | 模糊片段/轻微失焦 + 快速闪切（弱化版：片段模糊不准） | EP66-68 起 |
| 静音状态 | 冷灰色调，波纹消失，画面安静（"不受影响"） | EP03 雏形 → EP54 大成 → EP79 实战 |
| 权限之核绽放 | 淡金光晕绽放（**全剧唯一大 VFX**，EP82 显式标注） | EP82 周年庆三重能力合体 |

- **实现约定**：后期浮层合成（ffmpeg/合成软件），Seedance **禁止烧录**任何波纹/文字/字幕；构图由 prompt_suffix 预留空间。
- **反面人物心声**：同样为波纹，但周国豪/顾总的心声可用稍暗金色/冷色调区分（供 scene-writer 提示后期）；本规范不定义视觉 Prompt 细节，由 scene-designer / 后期负责。

```

### negative_prompt（全局）

**结构性约束（年代/题材 + 迷信禁忌 + 波纹后期）——由 production-planner 定义，不可删改：**

```
ancient costume, historical or dynasty setting, palace, imperial court, sci-fi mecha, spaceship, weapons of war,
ghost, spirit, apparition, phantom, soul, undead, ectoplasm, seance, incense ritual, religious altar, supernatural haunting, supernatural glow, telepathy rays, psychic energy beams,

## 七、分段（Segment）规则 —— AI 生成单位

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | ≤3 镜；**段 ≥8s 必 ≥2 镜**（典型 2-3） | v2.2 切镜节奏；静音视觉锤段可单镜但 ≤8s |
| 最小叙事单位 | 1 个完整 beat | 每段必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段（EP01 可至 12 段） | 见 §四B |
| 每集镜头数 | 16–30 镜（EP01 20-36） | v2.2；单镜理想 3-6s，>10s 禁 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）。
2. **不得**在连续动作进行中切断（开门、摘道具、戴耳机、递照片等动作链一条 segment）。
3. 拆段边界：场景切换、主说话人切换、情绪断点。
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`。
5. 分镜表里某镜自然时长 < 4 秒 → 并入同场景相邻段。

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）。
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）。
- 同一场景**可**含多个 segment；segment **不得**跨场景。

### 分集剧本格式

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注。
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs ｜ 镜头数：N` 统计行。
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`。
- 一行 = 一个镜头；多句对白在「对白/备注」格内换行书写，**禁止**空管子续行（见 `资产/_模板_剧本.md`）。
- 本剧心声类对白标注：他人心声/物件心声以 `[心声]` 情绪标记；后期以波纹+音色特效呈现，**不烧录文字**。

## 九、音色规范

- 每个有对白角色（含 CHAR-GRP-##）必须有 `voice_prompt`，格式：`「性别，年龄，音色特征，语速，情绪基调/说话习惯」`。
- 权威来源 = `资产/声音卡片.md`（**P0**）。同一角色跨 segment 的 voice_prompt 必须**全文一致**；存在 P0 时一律使用 P0，忽略角色卡片/本规范中的 P1/P2 表述。
- 旁白不分配 CHAR-ID，写为「旁白」，voice_prompt 独立定义。
- 本剧心声（他人/物件/动物心声）以**角色本人音色 + 后期空灵/混响效果**呈现（非独立 voice_prompt）；小满内心 OS 以「旁白/心声」独立 voice_prompt。
- 甲方猫（`CHAR-003`）的心声为拟人化京片子男声（TTS 拟人处理）。
- Seedance `generate_audio: true` 合成基础环境音；特殊音效（敲门声、紧张弦乐、心声洪水耳鸣、反噬耳鸣、怀表咔哒）后期叠加。
- 字幕后期添加（ffmpeg），Seedance 不烧录字幕（心声波纹亦为后期浮层，无文字）。

## 十、年代/题材约束（叙述性）

**必须体现元素**：现代（当代都市 2026 架空）职场——写字楼办公区、玻璃会议室、茶水间、电梯、工牌挂绳、便利店霓虹灯、出租屋台灯、深夜加班雾蓝/白天暖橙双色调；智能手机、笔记本电脑、老式硬盘、纸质账单、泛黄日记/法律文书、黄铜怀表等年代载体（妈妈遗物线为 20 年前旧物质感）。

**禁止出现元素**（叙述性；Prompt 由设计师负责）：
- 古装/朝代/宫廷/太空/战争一切非现代元素；
- 真实品牌 logo、真实机构名（公司为虚构"星辰互娱"）；
- 一切迷信/灵异/玄学视觉元素（能力 = 神经感应异常，心声波纹为波形/光晕非"鬼火"）；
- 中文乱码/繁体/模糊文字（涉中文文字道具由 prop-designer 在 Prompt 中锁定 Simplified Chinese）。

## 十一、内容合规参数

### 题材合规等级

- **🟡 B 级评估备注**：都市奇幻脑洞按 C 级为主评估（都市情感/职场轻喜剧/轻科幻脑洞），边缘含 B 级属性（读心/认知权限超常设定）——能力以"神经感应异常"科学框架定义，不属封建迷信（R1 合规结论：P0=0、P1 未处理=0）。⚠️ **平台可能按 B 级/逐本评估处理**（R1 结构性观察 3），前 3 集审核最严，EP01-03 逐集须维持无 P0/P1。

### ★ 本剧特定红线（R1 强制 · 全程锚定）

1. **能力框架红线**：全程"神经感应异常 / 认知权限"科学框架（大脑超负荷应激反应 → 老周医学诊断 EP03 → 外公认知权限理论 EP38/56）；**禁止玄学/鬼神/算命/做法/通灵**表述。
2. **读心隐私红线**：读心=偷听隐私，通过"权限守则"自纠（EP15 选择不偷听 → EP54 静音大成"不受影响" → EP75 守住底线 → EP85 权限守则"不偷听、不控制、不暴露"）；**禁止把偷听当作正当武器美化**；周国豪"情绪数据黑产"作为反派罪行被批判、被曝光（EP47/60）。
3. **迷信语感用词红线**（尤其妈妈"意识留存"线）：禁止使用 `亡魂 / 灵异 / 招魂 / 幽灵 / 鬼魂 / 超度 / 显灵 / 阴魂 / 附身 / 通灵 / 转世`；推荐替代——妈妈"意识留存"= 记忆数据化留存（科技化锚定）、听回忆 = 意识片段读取、怀表认主 = 林家血脉信息锁（生物特征绑定）。
4. **医疗线合规**（EP40/42/43）：医疗往事仅以"病历文书+证词+记忆片段"呈现，**不出现医疗操作细节画面**；"治疗被动过手脚"仅以"医疗记录异常+仪器记忆片段"呈现。
5. **威胁/拘留/车祸留白**：爸爸"车祸"（EP48）、小满拘留（EP63）、护工"失踪"（EP43）均留白处理（只拍走廊/病床背影/监护仪音效/语音+关机），不渲染事故/受伤/关押画面。
6. **反派正法走法律程序**：报警/律师/监管举报/民事诉讼/自首（EP43/57/60/63/65/74），不渲染公安/司法程序细节；周国豪 EP65 自首、EP74 狱中悔悟。

### 灰区处理策略

| 灰区内容 | 本剧是否涉及 | 处理方式 |
|----------|:---:|----------|
| 读心/心声能力 | 是 | 全程"神经感应异常/认知权限"科学框架；主角靠"静音开关+权限守则"自控，不美化偷听 |
| 复仇/以暴制暴 | 是 | 法律途径 + 心理战/人心战收束（EP43/60/63/65/74）；主角不施私刑，反派受法律制裁 |
| 职场PUA/画饼/抢功 | 是 | 顾总/苏曼行为被批判、主角反抗（EP2/4/7/13/16/20/32），导向打脸正能量 |
| 阶级碾压（周国豪） | 是 | 作为反派行为，最终被罢免/自首/入狱（EP64/65/74/86），善有善报 |
| 情绪数据黑产（隐私侵犯） | 是 | 作为反派罪行被曝光、被集体维权（EP60/61），触发"隐私尊重"正向主题 |

### 正向价值锚点

1. **职场正道与自强不息**：小满以真本事+智慧反击，靠努力与同理心赢得升职（EP66 创意总监、EP75 员工关怀计划）。
2. **隐私尊重与边界**：学会"该听与不该听"（EP15）、"选择不听"（EP75）、"权限是责任不是遗产"（EP84）——能力越大越懂边界。
3. **法治精神与善有善报**：反派全部走法律程序受罚；维权通过合法途径（EP43/57/60/61）。
4. **家人是铠甲**（EP49）：亲情不是软肋；爸爸/妈妈/陆时晏的守护支撑主角。
5. **社会责任**：权限者互助网络（EP80/81/85）——能力用于助人而非牟利。

### 平台审核重点提示

- **前 3 集**（审核最严，无 P0/P1）：
  - EP01：电梯/打印机/绿植"心声"奇幻但须锚定科学框架（"神经感应异常"），开场即建立"科学脑洞"非"灵异"观感；物件心声为喜剧点缀，不渲染惊悚。
  - EP02：顾总画饼/苏曼抢功为职场不公，导向打脸正能量，不渲染恶意/人身攻击；台词无脏话、无"神经病"污名化用词（EP02 被当神经病→EP03 以医学诊断翻转）。
  - EP03：老周测出"神经感应异常"——医学口径基本准确（大脑超负荷应激反应），不渲染精神疾病污名；降噪耳机="静音开关"物理象征。
- **付费卡点**（卡一 EP8-12 / 卡二 EP27-30 / 卡三 EP60-65）：不可用低俗/暴力/性暗示内容作为付费钩子；卡点集 hook 密度 ≥2/集，禁止低张力话唠段 >30s。
- **结局要求**：EP86 大结局传递正面信息（善有善报/希望/治愈）；"心声是钥匙，不是枷锁"主题落点正向；系列化钩子（新觉醒者）为开放性希望，不作负面悬念。
