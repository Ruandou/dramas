### 五条方向判断

**判断一：抗卷靠垂类粘性，不靠大众爆款。** 价格战信号 = 同质供给出清。观星（天文科普圈层）、谷子（二次元消费圈层）都是**高粘性、低供给、付费意愿明确**的垂类；与 08-21 已推的台球/钓鱼（运动垂类）在内容域完全错开。

**判断二：真实连接是「赛博失恋」的正面落点，但载体必须离线、具体、有物件。** 花店（一束花承载一段关系）、澡堂（一座城市的公共客厅）——不写「人机」，写「人-人-物件/空间」的真实关系。

**判断三：不做明星脸生意，做「物件情感记忆点」。** 甄子丹案例的反面教训是：AI 脸不可靠也不可复制；可靠的记忆点是**场景与物件**（一束花、一片夜空、一个老澡堂）。本批 5 个题材全部以「物件/空间记忆点」而非「演员脸」立剧。

**判断四：每集必须有一个可切片的瞬间。** 澡堂的段子、乐队的高潮段、谷子店的开箱、花店的送花瞬间、天文台的流星语——执行要求写入全部推荐。

**判断五：本批全为「光效友好」题材，AI 制作可行性整体高于第一批。** 星空夜景、舞台灯光、水汽弥漫、店窗暖光——都是图片/视频生成的稳定强项区；规避动作崩坏（乐队演奏手部、池区动态）即可达中高可行。

## 三、新剧推荐清单（5 个全新选题）

> 全部为横屏格式（16:9）短剧，本仓库标准制作形态（72-86 集 × 约 90 秒）。5 个推荐分别对应 §一 五条方向判断，全部 C 级合规。

### 推荐 1：《追星星的人》
- **驱动信号**：价格战 → 垂类抗卷（判断一）+ 物件记忆点（判断三）
- **查重结论**：标题层「追星星」全库 0 命中；概念层「观星/天文馆/望远镜」0 命中（「星空」仅场景诗意词）。**通过**
- **题材**：当代都市 + 天文科普治愈 + 连续主线带轻单元（县城天文馆讲解员 + 观星社群；每集一次观星活动，对应一段人间心事）
- **目标受众**：全龄（亲子共视 + 银发怀旧 + 都市夜归人）；天文/科普兴趣圈层；横屏熟龄大盘
- **推荐逻辑**：价格战时代，垂类小而美是抗卷解——天文科普是国内供给几乎空白的垂类，且是**政策正能量题材**（科学精神、破除迷信，与 9-1 新规「崇尚科学」导向直接呼应）；「星空下的心事」单元结构自带治愈与切片基因（流星雨许愿、星座生日梗、天文台求婚——每集一个可传播瞬间）；观星是天然的「物件记忆点」题材——星图、望远镜、天文馆穹顶，不依赖任何明星脸
- **差异化**：库内无任何科普/科学题材项目；与修仙类的「星象/雷劫」完全不同（科学理性 vs 玄幻设定）；与悬疑/刑侦零交集；「夜空美学」在竖屏几乎无法成立，横屏星空大画幅是天然壁垒——竖屏拍不出银河的延展
- **合规分级**：C 级。红线自控：全程科学理性导向，划清天文与占星的边界（不出现星座运势/算命内容，明确科普立场——恰好是 25 条禁止内容「封建迷信」的对冲表达）；青少年角色以亲子关系承载，未成年人形象走背面/远景
- **平台适配**：红果（全龄免费大盘）、芒果TV（家庭场域）、上星剧场（科普正能量通道）、文旅联名（天文馆/观星营地合作钩子）
- **横屏契合点**：银河横贯的夜空长卷、天文馆穹顶的圆幕全景、山地观测点的地平线纵深、城市夜空的万家灯火与星光并置——「天空的横轴」是 16:9 独有的电影语言
- **AI 制作可行性**：中高。主场景三件套（天文馆穹顶厅/观测点山坡/讲解员办公室）全集复用；星空空镜与夜景是 AI 生成稳定强项区；常驻 4-5 人；风险点 = 天文设备文字（望远镜铭牌/星图标注），规避方案为少用文字道具、以星图光点与手势承载；流星/极光等天文现象以远景空镜 + 人物反应切镜处理

### 推荐 2：《楼下谷子店》
- **驱动信号**：价格战 → 圈层粘性（判断一）+ 社交安利切片（判断四）
- **查重结论**：标题层「谷子店」全库 0 命中；概念层「谷子/二次元/漫展/手办」0 命中（替身白月光中的「二次元」仅为视觉风格形容词）。**通过**
- **题材**：当代都市 + 二次元谷子零售 + 经营轻喜剧（社区谷子店店主，每集一位「为爱发电」的圈层顾客 + 店主成长主线）
- **目标受众**：18-35 岁 Z 世代核心（谷子经济真实消费者）；二次元圈层（高粘性自来水）；泛年轻观众（圈层文化猎奇）
- **推荐逻辑**：价格战信号下，圈层粘性 > 大众热度——谷子（徽章/立牌/吧唧）是当下真实存在的**高粘性消费圈层**（情绪价值消费的典型载体）；「为爱发电」的圈层人情天然自带切片（开箱、痛包、排谷、自制周边——每集一个可传播瞬间）；经营 + 单元人情结构适配 86 集长线；谷子店场景成本极低、圈层梗自带传播
- **差异化**：库内无任何二次元/零售细分类项目；与所有电商/商战（义乌）错开——不是出海大生意，是**街角小店的圈层生意**；与摆摊/市集（退休摆摊系统）错开——实体小店经营 + 圈层文化，调性完全不同；Z 世代视角在库内存量最少
- **合规分级**：C 级。红线自控：全部商品为**原创 IP 谷子**（自制/正版授权），不涉盗版侵权与真实动漫 IP 版权问题——店主人设即「原创谷子店」，天然规避版权风险；不渲染过度消费/抽卡赌博式付费（明示理性消费价值观）；圈层矛盾限爱好分歧，不涉网暴
- **平台适配**：红果（Z 世代免费大盘）、B站/抖音切片分发（谷子开箱/圈层梗天然短视频生态）、爱奇艺横屏
- **横屏契合点**：货架阵列的横向矩阵、痛包展示墙、店内长桌围坐的圈层聚会群像、门店橱窗与街区夜景的并置——「一面墙的谷子」是竖屏装不下的体量感
- **AI 制作可行性**：高。主场景两件套（店内/店门口街景）全集复用；商品道具（徽章/立牌）为原创设计，无文字版权风险；常驻 4-5 人 + 每集 1-2 位顾客（半身/背影为主）；风险点 = 商品印刷文字，规避方案为原创符号化设计（无真实文字或仅极简 logo 化图形）

### 推荐 3：《转角花店》
- **驱动信号**：赛博失恋 → 真实物件连接（判断二）+ 物件记忆点（判断三）
- **查重结论**：标题层「转角花店」全库 0 命中；概念层「花店」仅鸳鸯锅 EP05 镜头背景与万物标价 EP72 结局配角开店意象，非行业题材项目。**通过**
- **题材**：当代都市 + 花艺治愈 + 单元剧（街角花店主理人，每束花承载一段关系，每集一单「花语委托」）
- **目标受众**：25-45 岁女性核心；都市情感人群；全龄治愈受众
- **推荐逻辑**：赛博失恋的时代，真实的「物件连接」成为稀缺情绪价值——一束花是数字世界里最有实感的语言；「花语委托」单元结构（替不敢开口的人送花、替道歉的人选花、替告别的人收尾）每集一个完整情感闭环 = 每集一个切片；花店是与电台（第一批）完全错开的载体——声音 vs 物件，职业动作完全不同；甄子丹案例的反面教训：记忆点不在脸，在一束花
- **差异化**：库内职业剧无花艺/园艺载体；与美食（面馆/火锅/摆摊）错开——花的「非食用、纯情感」属性是独特的情感媒介；与银发才艺/社区单元（08-21）错开——都市年轻女性治愈向；花店 + 主理人成长线 + 每集顾客故事，结构上与月嫂/维修班同型但情感母题完全不同（礼物/告白/和解 vs 家政维修）
- **合规分级**：C 级。红线自控：情感冲突限都市伦理日常，不涉刑案/婚外猎奇；不渲染消费主义（送花 = 心意表达而非物质攀比，明示「心意比花贵」的价值导向）
- **平台适配**：芒果TV（都市情感场域）、红果（女性免费大盘）、花艺/生活方式垂类联动
- **横屏契合点**：花店操作台横向工作流、花架阵列、街角橱窗与行人街景的框景构图、送花场景的马路纵深——「一束花穿过城市」的空间叙事是 16:9 的强项
- **AI 制作可行性**：高（本批最高档）。主场景两件套（花店/花材工作台）+ 每集客户生活空间变体（D2 规则）；花材道具无文字风险、色彩斑斓是图片生成强项；常驻 3-4 人 + 每集 1-2 位客户；风险点 = 花束细节崩坏，规避方案为花束以中景/局部特写呈现、包花过程用手部重点镜头

### 推荐 4：《大澡堂》
- **驱动信号**：赛博失恋 → 真实公共空间（判断二）+ 社交安利（判断四）
- **查重结论**：标题层「大澡堂」全库 0 命中；概念层「澡堂/洗浴/搓澡/泡澡」全库 0 命中。**通过**
- **题材**：当代北方小城 + 群像喜剧 + 单元剧（老国营澡堂拆改倒计时，老板一家与街坊常客的众生相；每集一位澡客一段人生）
- **目标受众**：25-60 岁全龄（家庭共视）；北方地域观众（地域共鸣 + 方言梗）；熟龄男性大盘
- **推荐逻辑**：赛博失恋折射的是公共空间的消亡——澡堂是「一座城市的公共客厅」，是数字时代稀缺的真实社交场域，题材自带怀旧情感与时代共鸣（澡堂文化是国民记忆符号）；群像单元结构（每集一位澡客）适配 86 集长线；澡堂段子/搓澡梗/街坊斗嘴是切片传播率极高的内容形态（呼应 Snapchat 社交安利信号）；拆改倒计时 = 天然的时间压力主线，季播框架清晰（保住澡堂 → 改造澡堂 → 城市更新下的澡堂去留）
- **差异化**：库内零澡堂/洗浴概念；与第一批洋女婿（家庭喜剧）错开——本剧是**公共空间群像喜剧**而非家庭结构喜剧；与拆迁这一家（拆迁家庭伦理）错开——澡堂是公共空间叙事，主角是澡堂本身；全民澡堂文化自带年代记忆但不做年代剧（当代设定，怀旧只是底色）
- **合规分级**：C 级。红线自控：**澡堂 = 大众洗浴文化，严禁任何擦边裸露表达**——池区戏以雾气/远景/背影/浴巾处理，主戏场设在休息区/大厅/搓澡间（穿浴袍/工作服），不出现任何低俗化暗示（25 条禁止内容「淫秽」红线重点自控项）；拆迁矛盾限民事协商，不涉执法程序
- **平台适配**：芒果TV（家庭喜剧场域）、红果（全龄免费大盘）、东北/北方地域卫视通道
- **横屏契合点**：澡堂大厅的横向纵深（躺椅阵列/休息区全景）、雾气光影的大画幅氛围、池区远景与水汽、街坊同框的群像调度——「一座大厅坐满人」的公共空间体量感是 16:9 的本命画面
- **AI 制作可行性**：中高。主场景三件套（大厅/休息区/门口街景）全集复用；水汽/瓷砖/暖光光影是 AI 生成稳定区；常驻 6-7 人（澡客群像各建 L01 + mesh）；风险点 = 池区动态与水汽遮挡人脸，规避方案为池区以远景/雾气剪影为主、人物戏全部放在休息区/大厅（静景对话构图）

### 推荐 5：《排练室》
- **驱动信号**：明星 AI 脸翻车 → 真实坚持的情怀价值（判断三）+ 社交安利切片（判断四）+ 工具进化（判断五）
- **查重结论**：标题层「排练室」全库 0 命中；概念层「乐队」命中均为分镜脚本里的「全乐队」音乐描述词（管弦乐术语），无乐队题材项目。**通过**
- **题材**：当代都市 + 青年乐队成长 + 连续主线（地下排练室五人行：坚持原创的乐队从无人问津到走上真正舞台；每集一场排练/演出 + 队员个人线）
- **目标受众**：18-35 岁青年核心（乐队文化/现场演出受众）；音乐兴趣圈层；追梦人群（情绪共鸣）
- **推荐逻辑**：甄子丹案例的正面启示——**真实人格与持久坚持**是 AI 脸替代不了的稀缺价值；乐队题材是「真实追梦」的国民级载体，与 07-27 已推荐的脱口秀穿越（古代喜剧向）完全不同——本剧是**当代现实向的青年热血成长**；乐队现场/排练段子/原创歌词是切片传播的高密度素材；音乐题材自带情感记忆点（一首歌 = 一个记忆点，呼应判断三）；横屏舞台灯光是大场面工具进化的直接受益场景
- **差异化**：库内无乐队/音乐题材项目（音乐仅存在于分镜的背景音描述）；与银发才艺（妈妈们的T台）/青年街舞等才艺群像错开——乐队是**原创作品驱动**的成长叙事，不是才艺比赛；与 08-08 电竞（竞技）错开——创作与竞技是两种母题；24-30 岁「追梦未遂再出发」人群在库内零覆盖
- **合规分级**：C 级。红线自控：原创歌词全部自创（不涉翻唱版权/影射现实艺人）；不渲染酗酒/夜店文化（排练室/地下室设定，舞台戏以演出场景承载）；坚持正向价值观（努力、友谊、作品优先于名利）
- **平台适配**：红果（青年免费大盘）、B站/抖音切片分发（现场段子/排练日常）、爱奇艺横屏
- **横屏契合点**：排练室的横向布局五人间（鼓/吉他/键盘/主唱同框）、舞台灯光的纵深光束、livehouse 现场的全景人群、天台合奏的黄昏剪影——乐队五人的「同框张力」是横屏群像的天然素材
- **AI 制作可行性**：中高。主场景两件套（排练室/演出舞台）+ 生活场景变体；舞台灯光/烟雾/光束是 AI 生成强项区；常驻 5-6 人；风险点 = 乐器演奏手部动作与多人合奏同步，规避方案为演奏以手部特写/静态定格/侧面剪影承载，高潮演出以灯光 + 中景反应切镜；乐器道具为无品牌外观设计（规避 logo 文字）

| 优先级 | 剧名 | 一句话理由 | 主要扣分项 |

| P2 | 《大澡堂》 | 群像喜剧差异化最强（公共空间视角全库唯一）+ 国民记忆共鸣 + 切片传播率最高档 | 擦边红线需在制片规范里前置硬约束（池区处理）；群像资产较重 |
| P3 | 《追星星的人》 | 科普垂类蓝海 + 「科学精神」是 9-1 新规下的天然合规题材 + 横屏夜空美学壁垒 | 垂类受众宽度有限；天文知识考据成本 |
| P4 | 《楼下谷子店》 | Z 世代圈层粘性真实存在 + 场景成本最低 + 圈层梗自带传播 | 圈层文化需准确考据（避免猎奇化表达）；受众宽度依赖圈层出圈 |
