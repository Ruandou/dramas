# 《锦瑟年华》制片规范 · ID 与引用

> **正名**：《锦瑟年华》（Years of Silk and Zither）
> **类型**：古装权谋 × 音乐竞技 × 身份伪装 × 复仇救赎
> **年代背景**：唐天宝年间（约750年），长安
> **集数**：36集 × 约2.5–3分钟 = 总时长约95分钟
> **画幅**：9:16 竖屏
> **生成工具**：Seedance 2.0 fast（doubao-seedance-2-0-fast-260128）
> **版本**：v1.0 · 2026-06-05

## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 镜头     | `EP##-S##-SH##`                   | `EP01-S01-SH03`   | 集数-分段-镜头                   |

- 编号**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再建 **`L01` 基础形象**于 `资产/形象索引.md` + `角色卡.md`。
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。
- 群演分级：有名字+跨segment出现→独立CHAR-###；纯背景无台词→CHAR-GRP。

### 1.1 形象 ID 与基础/衍生

| 后缀     | 名称     | 要求                                                                                |
| -------- | -------- | ----------------------------------------------------------------------------------- |
| **L01**  | 基础形象 | 完整定妆 Prompt（脸、体型、发式、默认服装）；全剧面部一致性的**唯一锚点**           |
| **L02+** | 衍生形象 | **必须** `based_on` 本角色 `L01`；Prompt 只写差异（delta），并含 `same face as CHAR-xxx-L01` |

### 1.2 出图流程

1. 定稿 `L01` 参考图 → Character Sheet（正面全身，白底）
2. 衍生形象用图生图 / 角色一致性模型 → **delta Prompt** 仅写服装/道具/妆效差异
3. **禁止跳过 L01 直接生成 L02**
4. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01

### 1.3 形象表格式（角色卡中）

```markdown
| 形象 ID        | 类型     | 名称         | 基于 | 适用       |
| -------------- | -------- | ------------ | ---- | ---------- |
| `CHAR-001-L01` | **基础** | [默认状态名] | —    | EP01–36    |
| `CHAR-001-L02` | 衍生     | [差异描述]   | L01  | EP##/EP##  |
```

## 三、分段与镜头规范

### 3.1 分段（Segment）规则 —— AI 生成单位

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 约 12–15 段     | 对应单集 2.5 分钟时长（~150s ÷ ~10s/段 ≈ 15 段）       |

### 3.2 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具、弹琴完整乐句等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 3.3 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 六、AI Prompt 工程规范

### 6.1 L01 完整 Prompt 结构

```
A [age]-year-old Chinese [gender] from Tang Dynasty, [face description], [hair style per Tang code], wearing [Tang dynasty clothing per rank/status], [accessories], [pose], [setting], character sheet, Tang dynasty Chang'an aesthetic, vertical 9:16 portrait, [lighting]
```

### 6.1.1 L01 Character Sheet 生成要求

L01 角色参考图用于 Seedance 分镜的人物一致性锚点，**必须**遵循以下规则：

| 要求 | 说明 |
|------|------|
| 构图 | 正面全身，从头顶到脚底完整可见 |
| 背景 | 纯白背景（plain white background），无任何环境元素 |
| 人数 | 单人（single person, solo），画面中不得出现第二个人物 |
| 姿态 | 站立面朝镜头（standing upright facing the camera） |
| 打光 | 平光/棚拍光（clean flat studio lighting），不用情绪光 |

**Prompt 模板（Seedream Character Sheet）**：
```
Character reference sheet, front-facing full-body portrait from head to toe, single person standing upright facing the camera, plain white background, clean flat studio lighting. A [age]-year-old Chinese [gender] from Tang Dynasty, [face description], [hair style], wearing [clothing], [accessories]. Vertical 9:16, character design sheet.
```

**禁止**：
- 禁止在 L01 生成 Prompt 中包含场景背景（花园、书房、雨中等）
- 禁止在 L01 生成 Prompt 中包含叙事性描述（"the look of someone carrying secrets" 等情感描述可保留，但场景性设定必须删除）

### 6.1.2 场景参考图生成要求

场景参考图用于 Seedance 分镜的环境一致性锚点，**必须**遵循以下规则：

| 要求 | 说明 |
|------|------|
| 人物 | **严禁出现任何人物**（no people, no human figures） |
| 内容 | 仅建筑、家具、道具、植被、光线、氛围 |
| 视角 | 适合后续角色叠加的中景/全景构图 |
| 说明 | 场景图是环境参考，角色由独立的角色参考图控制 |

**Prompt 后缀（必须添加）**：
```
Empty environment, no people, no human figures, architectural and environmental reference only.
```

**禁止**：
- 禁止出现具体人物描述（"a musician with a zither", "officials standing" 等）
- 禁止出现外国人描写（"Persian musician", "Central Asian merchants" 等），避免 AI 模型将外国面孔渲染进场景
- 允许使用暗示人类活动的物品（茶杯、乐器、文件等），但不可有人物在场

### 6.2 L02+ Delta Prompt 结构

```
same face as CHAR-###-L01, wearing [changed clothing], [changed elements only], [same style tags]
```

### 6.3 Seedance 段落 Prompt 结构

```
【图1】CHAR-###-L##·角色名（服装描述）【图2】CHAR-###-L##·角色名【图3】SCENE-###
角色分工：仅图1可[动作]；图2禁止[动作]。
道具：[具体描述，含尺度参考]。
竖屏9比16连贯叙事。
镜头1（Xs）[景别][运镜]：[纯视觉动作描述]
镜头2（Xs）[景别][运镜]：[纯视觉动作描述]
[以下对白仅供语音合成，严禁在画面中显示任何文字]
对白（角色，年龄，情绪）：「台词」
画面全程无任何文字、字幕、标题、水印。
盛唐天宝年间写实古装风格，竖屏9比16，[负面约束]。
```

### 6.4 content_roles 配置模板

```yaml
content_roles:
  - { file: CHAR-001-L01, role: reference_image, label: 图1 }
  - { file: CHAR-002-L01, role: reference_image, label: 图2 }
  - { file: SCENE-001, role: reference_image, label: 图3 }
```

### 6.5 参考图管理

- 角色定妆：`assets/looks/CHAR-*-L##.png`
- 场景参考：`assets/scenes/SCENE-*.png`
- 道具参考：`assets/props/PROP-*-*.png`
- **每 segment 最多 6 张参考图**（TOS模式）

### 6.6 参考图配额优先级

| 优先级 | 资产类型 | 说明 |
|--------|---------|------|
| P0 | 主角形象（CHAR-001, CHAR-002） | 必须保证，全剧锚点 |
| P1 | 对话角色形象 | 有互动的角色必须锁定 |
| P2 | 场景参考图 | 保证环境一致性 |
| P3 | 关键道具 | 有余量时加入（如锦瑟琴、冰弦、龙纹令牌） |
| P4 | 次要角色/群演 | 最后考虑 |

## 七、有声段落规范（Seedance 2.0）

### 7.1 基本规则

- `generate_audio: true` 为默认值
- Seedance 合成基础环境音和角色对话语音
- 特殊音效（琴声独奏、配乐高潮）后期叠加
- 字幕后期统一通过 ffmpeg 添加，**Seedance 不烧录字幕**
- 道具文字（如密信内容、圣旨文字）后期合成为画内元素

### 7.2 字幕策略

- **严禁**在 Seedance Prompt 中要求显示字幕
- `prompt_suffix` 必须包含：`"禁止画面中出现任何文字或字幕。"`
- 字幕由后期 ffmpeg 统一处理，确保字体、大小、位置、出入时间标准化

### 7.3 对白格式

| 场景 | 格式 |
|------|------|
| 有对白 | `**CHAR-###**[情绪·语气]：「台词」` |
| 内心独白 | `**CHAR-###**[内心]：「...」` |
| 无对白 | `（无对白，[音效]）` |
| 旁白 | `**旁白**[情绪]：「...」` |

## 八、工作流顺序（必读 · 防不同步）

制片规范确立后，所有内容修改**严格按层向下**：

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_锦瑟年华_36集.md` | 集纲、每场剧情、对白要点、钩子                      |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡、资产索引等       | 仅在前几步定稿后随需更新                            |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 九、分集剧本格式规范

> 分集剧本（`剧本/EP##/EP##_*.md`）是单集的**真相源**，所有后续文件（shots.yaml / segments.yaml）必须从此导出。

### 9.1 必须包含的结构（按顺序）

| 序号 | 部分 | 必选 | 说明 |
|------|------|------|------|
| 1 | YAML 文件头 | ✅ | episode_id, scene_ids, character_ids, look_ids, seedance_defaults |
| 2 | 集标题 + 引用导航 | ✅ | `# EP## 集标题` + 角色卡/场景卡链接 |
| 3 | 元信息摘要表 | ✅ | 叙事目标、钩子、默认形象、有效镜数、Segment数、版本 |
| 4 | 本集观众必须听懂 | ✅ | 编号列表：谁、发生什么、为什么、下集看什么 |
| 5 | SEG 正文 | ✅ | 按 Segment 分组的镜头表（11 列格式） |
| 6 | 结尾钩子 | ✅ | 一句话悬念 + 下集标题预告 |
| 7 | 本集制作备注 | ✅ | 情绪弧、光线、造型、音乐、节奏、关键细节 |
| 8 | 本集资产 | ✅ | 场景/角色/形象/道具/有效镜数汇总 |

### 9.2 11 列镜头表格式

```
| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白/备注 |
```

| 列名 | 格式 | 说明 |
|------|------|------|
| 镜号 | 整数 | 全集连续编号（1, 2, 3...），不随 SEG 重置 |
| shot_id | `EP##-S##` | 全局唯一，如 `EP01-S01` |
| 场景 | `SCENE-###` | 对应资产/场景卡片.md 中的 ID |
| 角色 | `CHAR-###` | 出镜角色，多人逗号分隔；无人写 `—` |
| 形象 | `CHAR-###-L##` | 本镜使用的形象版本，多人逗号分隔 |
| 景别 | 中文 | 全景/中景/近景/特写/大特写 |
| 时长 | 整数秒 | ≥4（Seedance 最小单位） |
| 模式 | 枚举 | `t2v`（纯文本）/ `i2v_ref`（带参考图）/ `skip`（非AI） |
| 运镜 | 中文 | 固定镜头/缓推/镜头推近/镜头拉远/镜头跟随/快切/主观镜头 |
| 画面 | 2-4句 | 电影级视觉描述：布景、光线、人物姿态、道具、伏笔 |
| 对白/备注 | 格式化 | `**CHAR-###**[情绪]：「台词」` 或 `（无对白，[音效]）` |

### 9.3 SEG 块结构

```markdown
---

## SEG01 — [叙事功能]

**【SCENE-###】[地点]** · **[时段]** · **[内/外景]**

| 镜号 | shot_id | ... | 对白/备注 |
|------|---------|-----|-----------|
| ... |

> ⏱ Segment时长：Xs ｜ 镜头数：N
```

### 9.4 画面描写质量标准

「画面」列**禁止**一句话空洞概括。每格必须 2-4 句，包含：
- 布景具体细节（桌面物品、墙面装饰、地面状态等）
- 光线/色温/明暗——情绪外化
- 人物姿态/微表情/手部动作/视线
- 与剧情相关的道具互动
- 暗示/伏笔元素（可选但推荐）

## 十、道具转移与肢体动作规范

### 10.1 常见错误

| 错误类型 | 示例 | 修正 |
|----------|------|------|
| 道具凭空出现 | 上一镜空手，下一镜持琴 | 必须有取琴动作镜 |
| 道具消失 | 上一镜持琴，下一镜琴消失 | 必须有置琴动作镜 |
| 服装突变 | 同一segment内服装颜色改变 | 检查形象ID一致性 |
| 肢体穿越 | 宽袖穿过琴弦 | 弹琴时袖口需挽起或避开 |

### 10.2 分段时必须检查

1. 琴的传递：递琴 → 接琴 → 持琴，每步必须在同一个 segment 内完成
2. 面纱摘戴：摘/戴面纱不能跨 segment
3. 书信/案卷传递：伸手 → 接信 → 展信，一条 segment
4. 下跪/起身：下跪过程不能跨 segment 切断
5. 弹琴乐句：一个完整乐句必须落在同一 segment 内

## 十二、声音规范

### 12.1 voice_prompt 格式

```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

同一角色跨 segment 的 `voice_prompt` 必须**全文一致**。

### 12.2 音效/配乐标注

- 分集剧本镜头表中标注 `音效/配乐` 列
- 格式：`[音效类型]`（如 `琴声——凤求凰`、`雨声`、`殿门推开声`、`紧张弦乐`）
- Seedance `generate_audio: true` 合成基础环境音；特殊音效及配乐后期叠加
- 音乐演奏段落：标注曲目名（如《月照关山》、《凤求凰》、《归鸿引》）

### 12.3 旁白规范

- 旁白不分配 CHAR-ID，写为「旁白」
- 旁白 voice_prompt 独立于角色
- 旁白镜无参考图需求，并入相邻段
