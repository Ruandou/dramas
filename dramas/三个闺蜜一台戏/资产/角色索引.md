## 群演分级规则

- **有名字+跨 segment 出现** → 独立 `CHAR-###`
- **纯背景无台词但需视觉区分** → `CHAR-GRP-##`
- **每个 `CHAR-GRP-##` 都必须分配独立 ID 和 L01 形象**
- **同一 `CHAR-GRP-##` 可跨集复用**，但不同视觉角色不可共用同一 ID

---

## ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在本文件登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- **群演按需创建，不设数量上限**
