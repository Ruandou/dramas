# 《三个闺蜜一台戏》制片规范 · ID 与引用

> **正名**：《三个闺蜜一台戏》
> **版本**：v1.0 · 2026-06-26

## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同角色独立 ID + L01（按需创建，无上限） |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- **群演按需创建，不设数量上限**：有名字+跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词但需视觉区分 → `CHAR-GRP-##`。每个 `CHAR-GRP-##` 都必须分配独立 ID 和 L01 形象。唯一约束是 API 参考图配额（每 segment ≤6 张，TOS URL 模式）——超出时按 segment-builder 优先级裁减
- 同一 CHAR-GRP-## 可跨集复用（如"守卫甲"在 EP01-03 都出现），但不同视觉角色不可共用同一 ID（如"队长"与"年轻守卫"必须是 GRP-01 和 GRP-02 两个 ID）

### 形象层级结构定义

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

> 形象 Prompt 内容、生成流程、delta 规则等视觉创意细节由 character-designer 负责。

## 四、工作流顺序（必读 · 防不同步）

| 顺序 | 层 | 文件 | 写什么 |
|:---:|------------|------------------------|---------------------------------------------------|
| **1** | **主剧本** | `短剧剧本_三个闺蜜一台戏_72集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 六、分段规则

### 分段（Segment）规则 —— AI 生成单位

| 约束 | 值 | 说明 |
|------|---|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | 对应单集 75–120 秒（EP01 可至 12 段） |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 八、音色规范

### Seedance 默认配置

- **model**: `doubao-seedance-2-0-fast-260128`
- **ratio**: `9:16` (竖屏)
- **resolution**: `720p`
- **duration_sec**: `8-10` 秒
- **generate_audio**: `true` (生成环境音)

### voice_prompt 规范

为每个有对白的角色定义 voice_prompt，格式：
```
「性别，年龄，音色特征，语速特征，情绪/说话习惯」
```

- 同一角色跨 segment 的 voice_prompt 必须**全文一致**
- voice_prompt 是 segment-builder 的唯一权威来源
- 详细定义见 `资产/声音卡片.md`

### 音效与配乐

- Seedance `generate_audio: true` 合成基础环境音
- 特殊音效后期叠加
- 旁白角色不分配 CHAR-ID

## 九、年代/题材约束

### 必须体现元素
- 现代都市生活场景（2024-2025）
- 女性独立与成长主题
- 友情治愈力量
- 甜品文化与治愈理念
- 职场/感情/家庭的真实困境

### 禁止出现元素
- 古代/奇幻元素
- 超自然设定
- 暴力/血腥场景
- 政治敏感内容
- 宗教迷信宣扬

### 年代禁忌（negative_prompt）
- 古代服饰/建筑
- 奇幻特效/魔法元素
- 军事/战争场景
- 司法/刑侦场景
- 封建迷信元素

## 十一、受众定位

- **主频道**: 女频
- **核心年龄段**: 18-35岁女性
- **核心痛点**: 职场压力、感情挫折、家庭期望、自我价值迷茫

| 题材 | 场景复杂度 | 角色数量建议 | AI生成难度 | 预估周期 |

## 内容合规参数

### 题材合规等级
**C级（一般题材）**：都市群像/治愈轻喜/女性成长，无特殊题材元素

### 本剧特定红线
1. 避免过度强调"女性必须依附男性"的价值观
2. 避免美化"为爱牺牲一切"的恋爱观
3. 避免职场性别歧视的正当化描述
4. 避免过度消费"原生家庭伤害"的创伤叙事
5. 避免将"治愈"简化为"心灵鸡汤"式的表面安慰

### 灰区处理策略
1. **职场性骚扰议题**：以受害者发声和正义得到伸张为结局，避免详细描写骚扰过程
2. **轻生念头**：以"被理解、被陪伴、重获希望"为处理方式，避免美化轻生行为
3. **前任纠缠**：以"女性主动选择、拒绝被控制"为处理方式，避免浪漫化纠缠行为
4. **家庭压力**：以"沟通理解、代际和解"为处理方式，避免极端对立描写

### 正向价值锚点
1. **女性互助**：三个女主互相支持，共同成长
2. **治愈力量**：用甜品和真诚治愈他人伤痛
3. **自我价值**：不依附他人，找到自己的价值和方向

### 平台审核重点提示
1. EP01：三人相遇场景避免过度戏剧化，保持生活真实感
2. EP03：职场性别歧视场景以"揭示问题"为目的，非宣扬歧视
3. EP14-16：前任纠缠情节以"女性主动拒绝"为核心，避免浪漫化
4. EP31-32：轻生情节以"被拯救、重获希望"为结局，避免美化轻生
