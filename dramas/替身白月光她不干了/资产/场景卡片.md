# 场景卡片（SCENE-*）

> 分镜引用：`` `SCENE-###` `` · 语法见 [`../制片规范.md`](../制片规范.md)  
> 场景 Prompt 规则：**严禁出现任何人物**（`no people, no human figures`）——仅建筑、家具、道具、光线、氛围。

## 字段模板（新建 SCENE 必填）

| 字段 | 说明 |
|------|------|
| **ID** | `SCENE-###`，全剧唯一 |
| **位置** | 城市/建筑/房间 |
| **内外** | 内景 / 外景 |
| **时段** | 日/夜/晨/黄昏 + 氛围 |
| **首次** | 首次出场集数 |
| **布景** | 关键家具、道具、视觉特征 |
| **色调** | 主导色调和灯光氛围 |
