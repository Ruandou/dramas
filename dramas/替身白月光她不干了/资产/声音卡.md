## 内心独白标记

分集剧本中以 `**CHAR-###**[内心]：「...」` 标记的台词属于内心独白。内心独白与人物的外化对白共享同一 `voice_prompt`，但 TTS 合成时可加轻微混响或音量微降以区分"画内"和"画外"。

## 音效/配乐风格

| 场景类型 | 音效/配乐 | 说明 |
|---------|-----------|------|
| 公寓日常（冷调期） | 环境音（空调低鸣、时钟滴答）+ 极简钢琴单音或不配乐 | 空旷、冰冷、等待感 |
| 公寓日常（林夏离开后） | 环境音（寂静）+ 偶尔配乐进入（弦乐低音，表达顾庭深的空） | 更大的空 |
| 宴会/社交场合 | 环境人声嘈杂 + 轻爵士/古典背景 | 与他人的热闹形成对比 |
| 林夏独处（觉醒后） | 温暖吉他/钢琴 + 自然光环境音（鸟鸣/风声） | 自由、舒展 |
| 林夏×陆砚辰（画廊/茶室） | 温暖钢琴和弦乐 + 极简编曲 | 安全、被看见 |
| 顾庭深×林夏（追妻期） | 弦乐低音持续 + 钢琴留白 | 紧张、遗憾、错过 |
| 顾庭深×沈薇微（对峙） | 不和谐弦乐 + 暂停式留白 | 压抑、即将碎裂 |
| 情感高潮（离开/告白/真相） | 钢琴单音→弦乐渐强→突然收住留白 | 克制但饱满 |
| 蒙太奇/快切 | 节奏性打击乐或无配乐 + 自然音效叠化 | 时间流逝感 |
| 片尾钩子 | 单音钢琴渐弱→静音 | 给观众反应空间 |

## 字幕策略

- **AI 生成阶段不烧录字幕**：Seedance `prompt_suffix` 包含 `"禁止画面中出现任何文字或字幕"`
- 对白文本保留在 prompt 中用于语音合成
- 后期通过 ffmpeg 统一添加硬字幕
- 字幕样式：白字描边、无黑底条、底部居中

## 道具文字后期合成

AI 无法可靠渲染中文字符。画面中需要出现的道具文字（戒指刻字 S.W.W./L.X.、合同签名、速写本日期、手机群聊文字等）：
1. 在分集剧本画面描写中保留叙事信息，加粗标注 **(文字后期合成)**
2. AI Prompt 中仅描述物理载体，不嵌入中文字面
3. 后期使用 `script/overlay_diegetic_text.py` 叠加
