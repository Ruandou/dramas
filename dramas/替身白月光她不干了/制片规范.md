## 二、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可 |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 镜头 | `EP##-S##` | `EP01-S01` | 集数-镜号 |

- 编号**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先 `资产/角色索引.md`，再建 **`L01` 基础形象**于 `资产/形象索引.md` + `角色卡.md`。
- 新建换装/阶段：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。

### 2.1 形象层级系统

| 后缀 | 名称 | 要求 |
|------|------|------|
| **L01** | 基础形象 | 完整定妆 Prompt（脸、体型、发式、默认服装）；全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | **必须** `based_on` 本角色 `L01`；Prompt 只写差异，并含 `same face as CHAR-xxx-L01` |

**出图流程**：定稿 `L01` 参考图 → Character Sheet（正面全身，白底）→ 衍生形象用图生图 / 角色一致性模型 → **禁止跳过 L01 直接生成 L02**。

## 六、视觉风格规范

### 6.1 总体视觉基调

| 维度 | 规范 |
|------|------|
| **色彩** | 电影级调色：前期冷调（替身期·蓝灰/冷白主导），中期暖调渗入（觉醒期·墨绿/赭石/深蓝），后期温暖自然（事业期·金色下午光/暖白） |
| **光影** | 强调对比：林夏在顾庭深身边时永远处于阴影或半明半暗；独立后逐渐走入正面光。顾庭深的书房永远暗调，陆砚辰的画廊永远充足自然光 |
| **镜头感** | 浅景深、电影级构图、竖屏9:16适配——关注面部特写和手部细节 |
| **风格标签** | Modern Chinese urban romance drama, cinematic color grading, shallow depth of field, realistic style, 9:16 vertical |
| **画面比例** | 9:16 竖屏 |
| **目标分辨率** | 720p (Seedance fast) |

| 类别 | 准确元素 |
|------|----------|
| **居住空间** | 高层公寓、落地窗城市全景、开放式厨房中岛、步入式衣帽间、大理石地砖 |
| **办公空间** | 玻璃幕墙写字楼、极简CEO办公室、loft工作室、大木桌 |

| **服装** | 现代商务正装、高定质感、亚麻/真丝/羊绒材质 |
| **艺术空间** | 改造厂房画廊、天窗自然光、白墙水泥地、珠宝展柜 |

## 七、AI生成参数

### 7.1 Seedream 5.0 lite（角色参考图 / 道具 / 场景）

#### 角色参考图（L01 Character Sheet）

**固定前缀**：
```
Character reference sheet, front-facing full-body portrait from head to toe, single person standing upright facing the camera, plain white background, clean flat studio lighting.
```

**固定后缀**：
```
Vertical 9:16, character design sheet.
```

完整 Prompt 见 `角色卡.md` 各角色 §6 节。

#### 场景参考图

**规则**：
- **严禁出现任何人物**（no people, no human figures）
- 仅包含建筑、家具、道具、植被、光线、氛围
- 末尾必须追加：`Empty environment, no people, no human figures, architectural and environmental reference only.`
- **禁止**出现具体人物描写或外国人描写

**示例（SCENE-012 画廊）**：
```
A converted factory art gallery interior, 6-meter high ceilings, white walls, polished concrete floors, massive skylight flooding the space with natural daylight. Abstract paintings on walls, minimalist sculpture pedestals, a steel spiral staircase leading to a mezzanine office. Warm afternoon light, dust motes floating in the air. Modern Chinese urban art space. Empty environment, no people, no human figures, architectural and environmental reference only. Vertical 9:16.
```

#### 道具参考图

**规则**：
- 构图：单物体，最具辨识度角度，完整物体清晰可见
- 背景：温暖中性丝绸/宣纸底色（非纯白，与角色Character Sheet区分）
- **严禁出现任何人物或手部**（no people, no hands, no fingers）
- 打光：产品摄影式戏剧打光，柔和阴影展示质感

**固定前缀**：
```
Prop reference photograph, single object isolated on warm neutral silk background, dramatic product lighting with soft shadows.
```

**固定后缀**：
```
Vertical 9:16, detailed prop reference sheet.
```

```
对白（角色，年龄，情绪）：「台词」
画面全程无任何文字、字幕、标题、水印。
现代中国都市情感剧，写实风格，竖屏9比16。
```

**禁止事项**：
1. 禁止在镜头描述中嵌入对白文字（会导致双字幕）
2. 禁止在段落级添加 `字幕：...` 指令
3. 禁止在多处重复出现相同对白文字

#### content_roles 配置

```yaml
content_roles:
  - { file: CHAR-001-L01, role: reference_image, label: 图1 }
  - { file: CHAR-002-L01, role: reference_image, label: 图2 }
  - { file: SCENE-001, role: reference_image, label: 图3 }
```

#### 参考图配额优先级

| 优先级 | 资产类型 | 说明 |
|--------|---------|------|
| P0 | 主角形象（林夏/顾庭深） | 必须保证，否则无法锁定面部 |
| P1 | 对话角色形象 | 有互动的角色必须锁定 |
| P2 | 场景参考图 | 保证环境一致性 |
| P3 | 关键道具参考图 | 有余量时加入，否则靠prompt描述兜底 |
| P4 | 次要角色/群演 | 最后考虑，必要时用通用群演图 |

**每 segment 参考图上限：6 张（TOS模式）**

## 八、分段与镜头规范

### 8.1 Segment 拆分规则（强制）

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 与本剧 `duration_sec: 8-10` 一致 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |

**关键区分**：
- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

**拆分原则**：
1. 不得在对话中间切断 segment（一句台词必须落在同一段内）
2. 不得在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 某镜自然时长 < 4 秒 → 并入同场景相邻段

### 8.2 分集剧本格式（11列镜头表）

每集文件必须包含以下结构：YAML头 → 集标题+引用导航 → 元信息摘要表 → 本集观众必须听懂 → SEG正文（11列镜头表）→ 结尾钩子 → 本集制作备注 → 本集资产。

**11列镜头表**：

```
| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白/备注 |
```

各列规范：

| 列名 | 格式 | 说明 |
|------|------|------|
| 镜号 | 整数 | 全集连续编号（1, 2, 3...），不随SEG重置 |
| shot_id | `EP##-S##` | 全局唯一 |
| 场景 | `SCENE-###` | 对应场景卡片 |
| 角色 | `CHAR-###` | 出镜角色，多人逗号分隔；无人写 `—` |
| 形象 | `CHAR-###-L##` | 本镜使用的形象版本；无人写 `—` |
| 景别 | 中文 | 全景/中景/近景/特写/大特写 |
| 时长 | 整数秒 | ≥4 |
| 模式 | 枚举 | `i2v_ref`（带参考图）/ `t2v`（纯文本）/ `skip`（非AI） |
| 运镜 | 中文 | 固定镜头/镜头推近/镜头拉远/镜头跟随/快切/主观镜头 |
| 画面 | 2-4句 | 电影级视觉描述：布景、光线、人物姿态、道具、伏笔 |
| 对白/备注 | 格式化 | `**CHAR-###**[情绪]：「台词」` 或 `（无对白，[音效]）` |

**SEG块结构**：
```
---

## SEGxx — [叙事功能]

**【SCENE-###】[地点]** · **[时段]** · **[内/外景]**

| 镜号 | shot_id | ... | 对白/备注 |
|------|---------|-----|-----------|
| ... |

> ⏱ Segment时长：Xs ｜ 镜头数：N
```

- 场景切换时写完整场景头
- 同场景续接写：`**（续）**`
- 每SEG以 `---` 分隔

### 8.3 对白格式

| 场景 | 格式 |
|------|------|
| 有对白 | `**CHAR-###**[情绪·语气]：「台词」` |
| 内心独白 | `**CHAR-###**[内心]：「...」` |
| 无对白 | `（无对白，[音效]）` |
| 旁白 | `**旁白**[情绪]：「...」` |

### 8.4 情绪/语气标记参考

对白情绪标记应与角色声音卡中 `voice_prompt` 的情绪基调一致。常用标记：

`[轻声]` `[公事公办]` `[不耐烦]` `[内心]` `[平静]` `[低声]` `[背对她·声音很轻]` `[笑·寒暄]` `[平淡]` `[温柔]` `[命令式]` `[惊喜]` `[冷漠]`

| `CHAR-004` | 陆砚辰 | 「成年男性，27岁，中音偏暖有棉布质感，语速正常偏快思维活跃，对方情绪低时自动降速，句尾常加很轻的"吧"，会轻笑」 |
| `CHAR-005` | 林舟 | 「青年男性，22岁，中音清亮略带少年感，语速中等，语调温暖有活力，对姐姐说话时格外柔和」 |
| `CHAR-006` | 张默 | 「成年男性，35岁，中音平稳专业，语速适中，客气而疏离，不带多余情绪」 |

### 9.2 音效/配乐

- Seedance `generate_audio: true` 合成基础环境音
- 特殊音效（门合上闷响、手机震动、酒杯放下、翻页声等）后期叠加
- 配乐风格：现代都市情感钢琴/弦乐为主，虐段留白或极简钢琴单音，甜段温暖吉他/钢琴

### 9.3 字幕策略

- **Seedance 不烧录字幕**：`prompt_suffix` 包含 `"禁止画面中出现任何文字或字幕"`
- 对白文本保留在 prompt 中用于语音合成
- 后期通过 ffmpeg 统一添加硬字幕
- 字幕样式：白字描边、无黑底条、底部居中

### 9.4 道具文字后期合成

AI无法可靠渲染中文字符。画面中需要出现的道具文字（合同签名、吊牌文字、速写本日期等）：
1. 在分集剧本画面描写中保留叙事信息，加粗标注 **(文字后期合成)**
2. AI Prompt中仅描述物理载体，不嵌入中文字面
3. 后期使用 `script/overlay_diegetic_text.py` 叠加

## 十、工作流顺序（必读 · 防不同步）

### 10.1 修改层级

改台词、场次、字幕策略时**严格按层向下**，**禁止**先改 `segments.yaml` 再回头补剧本。

| 顺序 | 层 | 文件 | 写什么 |
|:---:|------|------|--------|
| **1** | **主剧本** | `短剧剧本_替身白月光她不干了_36集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白/备注、CHAR/SCENE/形象、时长/模式/运镜 |
| **3** | **机器可读** | 同目录 `EP##_shots.yaml` | 从分集 md 导出，勿手改yaml当源 |
| **4** | **段落API** | 同目录 `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它** | 声音卡、资产索引、场景卡片 | 仅在前几步定稿后随需更新 |

**单集真相源**：`剧本/EP##/EP##_*.md`

### 10.2 自检清单（提交 segments.yaml 前）

- [ ] 所有 segment 的 `duration_sec` 是否都在 4–12？
- [ ] 是否存在跨场景的 segment？（必须断段）
- [ ] 是否存在切断对白或连续动作的拆点？
- [ ] 单 segment 内主说话人是否 ≤ 2，镜头数是否 ≤ 3？
- [ ] 段首是否有角色分工 + 道具持有绑定？
- [ ] `content_roles` 图1 是否为剧本上的动作者？
- [ ] voice_prompt 是否跨段全文一致？
- [ ] Negative prompt 是否包含 §6.4 完整模板？
