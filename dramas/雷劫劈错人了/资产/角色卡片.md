# 角色卡片 · 《雷劫劈错人了》

> Stage 3a 产出：完整视觉设计（Prompt、视觉锚点、反派设计）。
> voice_prompt 为 P1 建议性质，P0 权威来源为 `声音卡片.md`。

## 全局视觉锚点

| 维度       | 标准                                                   |
| ---------- | ------------------------------------------------------ |
| 渲染风格   | 写实照片级（8/10），不做卡通/插画/动漫                |
| 色调体系   | 都市线暖色自然光 + 仙侠线冷色高对比光效               |
| 一致性要求 | 同角色 L01→L02+ 面部五官锁定不变，仅改变服装/状态     |
| Prompt 尾缀 | 所有 L01 Prompt 末尾：`NOT anime, NOT cartoon, NOT illustration, NOT manga` |
| L01 背景   | 纯白背景，正面全身棚拍，含 `feet visible at bottom of frame` |
| L01 Negative | `cropped at waist, anime, cartoon, illustration, manga` |

## CHAR-001 · 周小凡

| 字段         | 内容                                       |
| ------------ | ------------------------------------------ |
| **ID**       | CHAR-001                                   |
| **姓名**     | 周小凡                                     |
| **定位**     | 主角 / 被迫修仙的会计师                   |
| **首次登场** | EP01                                       |
| **外貌关键词** | 28岁，戴眼镜，穿灰色西装，头发整齐，表情拘谨，身材偏瘦 |

### 叙事功能

- 全剧视角人物，观众代入点
- "平凡人获得超能力"的荒诞反差载体
- 从被动承受 → 主动选择的成长弧线
- 用会计师思维降维打击修真界难题

### 核心矛盾

- 想维持平凡生活 vs 无法放弃超能力带来的价值感
- 靠超能力赢 vs 靠真本事赢的道德困境

### 关键关系

- 与雷震子：从"追杀对象"→ 师徒 → 盟友 → 奇怪家人
- 与苏青青：同事 → 暗恋 → 恋人 → 知情支持者
- 与林总监：被欺负 → 反杀 → 彻底击败

### 视觉锚点

| 维度     | 设计                                                       |
| -------- | ---------------------------------------------------------- |
| 主导特质 | "平凡社畜的违和力量感"——越普通越有反差                     |
| 欲望可视化 | 眼镜镜片反光中偶尔闪过蓝色电弧（内心渴望与恐惧并存）      |
| 吸引力锚点 | 被雷劈后体温偏低→皮肤微白偏冷调+指尖蓝色电弧=危险又迷人   |
| 标志性视觉 | 西装领口微松、领带歪斜=秩序崩坏的隐喻                     |
| 色彩编码 | 灰色（日常）→ 蓝色电弧（力量觉醒）→ 金色（终局掌控）      |

### 形象规划

#### CHAR-001-L01 · 基础形象：日常灰色西装

**Prompt**：

```
Full body character sheet of a 28-year-old Chinese male accountant, standing facing camera on pure white background, feet visible at bottom of frame. Slim build, slightly thin frame, 172cm tall. Clean-cut short black hair neatly combed, thin silver-framed rectangular glasses, fair skin with slight cool undertone. Wearing a well-pressed medium gray business suit, white dress shirt, dark navy tie slightly loosened at collar, black leather belt, black dress shoes. Expression: restrained and slightly tired, lips pressed together, eyes alert but cautious behind glasses. Hands at sides, left hand slightly curled as if used to holding a pen. Natural studio lighting, photorealistic, highly detailed skin texture, NOT anime, NOT cartoon, NOT illustration, NOT manga.
```

**Negative Prompt**：

```
cropped at waist, anime, cartoon, illustration, manga, muscular build, confident smile, bright colors, fantasy armor, traditional Chinese clothing
```

## CHAR-002 · 雷震子

| 字段         | 内容                                                    |

### 叙事功能

- 周小凡的修真引路人
- "古板修士适应现代生活"的喜剧来源
- 三百年复仇执念 → 学会放下 → 重新选择人生
- 情感弧线：孤独 → 仇恨 → 友谊 → 第一次笑

### 核心矛盾

- 复仇使命 vs 与周小凡的友谊
- 修真界身份 vs 现代生活吸引
- 放弃执法长老 vs 留在凡间

### 关键关系

- 与周小凡：追杀者 → 师徒 → 盟友 → 家人
- 与雷万钧：师兄弟 → 嫉妒 → 对决
- 与掌门：养父子般的关系
- 与苏青青：从"那女子" → 认可 → 道谢

- **现代适应进度**：EP1完全不懂 → EP4学会冲马桶 → EP8沉迷短视频 → EP27点外卖/喝奶茶 → EP36刷修仙网剧

### 视觉锚点

| 维度     | 设计                                                       |
| -------- | ---------------------------------------------------------- |
| 主导特质 | "古板威严的崩塌感"——越严肃越搞笑                         |
| 欲望可视化 | 眉心雷纹从暗淡→明亮=复仇执念与内心和解的晴雨表          |
| 吸引力锚点 | 长发束冠+高挑身形=古典美男，但被现代生活折磨后的反差=笑点 |
| 标志性视觉 | 白色古装 vs 现代环境=违和喜剧；L02奶茶杯=最强反差符号    |
| 色彩编码 | 白色（纯洁修士）→ 蓝色雷纹（雷劫之力）→ 暖色调（融入现代）|

### 形象规划

Long jet-black hair tied in a high topknot with a silver hair crown, a few loose strands framing the face. Fair skin with a faint blue lightning-mark tattoo between eyebrows (雷纹). Wearing flowing white traditional Chinese cultivator robes with silver cloud patterns on cuffs and hem, white jade belt at waist, black cloth boots. Expression: proud and aloof with narrowed eyes, thin lips pressed in a slight scowl. Right hand resting on hip, left hand slightly raised with faint blue static between fingertips. Natural studio lighting, photorealistic, highly detailed skin texture, NOT anime, NOT cartoon, NOT illustration, NOT manga.

```
cropped at waist, anime, cartoon, illustration, manga, modern clothing, short hair, friendly smile, bright colors, casual posture
```
