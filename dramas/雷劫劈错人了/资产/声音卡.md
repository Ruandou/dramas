# 声音卡 · 《雷劫劈错人了》

> 本文件为 voice_prompt 的 P0 权威来源。
> segment-builder 将从此文件全文复制 voice_prompt 到 YAML。
> voice_prompt 必须全文一致（含引号「」内全部文字），禁止缩写、改写、翻译、简化。

## 主角色

| 角色 ID | 姓名 | voice_prompt | 备注 |
|---------|------|-------------|------|
| `CHAR-001` | 周小凡 | 「成年男性，28岁，语调平缓偏低沉，带有轻微社恐感，语速偏慢，说话时常停顿和犹豫，紧张时会结巴，情绪高涨时语速加快但依然保持克制」 | 适用全集；EP07后偶尔带电流杂音（力量外泄的副作用） |
| `CHAR-002` | 雷震子 | 「成年男性，外貌30岁，声线低沉浑厚，带有古板的威严感，语速偏慢且抑扬顿挫，习惯用文言词汇（"本座""凡人""此乃"），生气时音量提高但保持古韵，后期逐渐混入现代口语（"奶茶不错"）」 | 前期高傲古板，EP16后逐渐软化；醉酒时语速变慢、含糊 |
| `CHAR-003` | 苏青青 | 「成年女性，26岁，声线清冷但柔和，语速中等偏快，职场场合干练利落，私下温柔带笑意，怀疑试探时语调微微上扬，告白时声音轻柔颤抖」 | 适用全集；EP17告白段落需特别标注情绪变化 |
| `CHAR-004` | 林总监 | 「成年男性，45岁，声线油腻偏尖，语速快且带有压迫感，训斥时语调上扬、尾音拖长，被反杀时声音发颤、底气不足」 | 适用EP02–EP28 |
| `CHAR-005` | 玄诚子 | 「成年男性，外貌50岁，声线苍老沉稳，语速缓慢有力，带有不容置疑的威严，使用半文半白的措辞，警告时语调压低、字字清晰」 | 适用EP11–EP36 |
| `CHAR-006` | 雷万钧 | 「成年男性，外貌40岁，声线阴鸷嘶哑，语速不快但每个字都带着冷笑感，狂妄时放声大笑，被反噬时声音扭曲、充满不甘」 | 适用EP21–EP29 |
| `CHAR-007` | 掌门 | 「成年男性，外貌30岁但声音带有千年沧桑感，声线温和却深不可测，语速从容不迫，每句话都意味深长，微笑时声音有暖意」 | 适用EP29–EP35 |
| `CHAR-008` | 玄冥子 | 「成年男性，外貌60岁，声线苍老嘶哑，语速慢且固执，带有强烈的傲慢与偏见，激动时咳嗽+声音颤抖，反对时语调尖锐」 | 适用EP32–EP35 |

| `CHAR-GRP-02` | 外卖员 | 「青年男性，20多岁，声线爽朗，语速快，带方言口音（建议南方口音），催促时语气急促」 | EP08 |
| `CHAR-GRP-03` | 私家侦探 | 「中年男性，40岁左右，声线略带狡黠，语速中等，跟踪时的低声自言自语，被收买后语气变得谄媚」 | EP14–EP15 |
| `CHAR-GRP-04` | 年轻修士们 | 「青年男女混合，声线年轻朝气，多人对话时有窃窃私语感，惊讶时齐声发出"哇"的感叹」 | EP31–EP32 |
| `CHAR-GRP-05` | 大老板 | 「成年男性，50岁左右，声线浑厚有力，语速不快但每个字都有分量，训斥时声音如雷，满意时微微颔首」 | EP05、EP09、EP15 |
| `CHAR-GRP-06` | 医生 | 「成年男性，40岁左右，声线专业冷静，语速中等，医学术语清晰，对异常现象时语调微变（困惑）」 | EP26 |
| `CHAR-GRP-07` | 路人/同事 | 「男女混合，声线普通，背景嘈杂人声，偶尔有单独的惊讶声、议论声」 | EP02–36 |
