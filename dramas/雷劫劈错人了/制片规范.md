# 《雷劫劈错人了》制片规范 · ID 与引用

> **正名**：《雷劫劈错人了》
> **版本**：v1.0 · 2026-06-09
> **题材**：都市仙侠喜剧
> **集数**：36集
> **单集时长**：1.5–2.5分钟
> **总时长**：约60–90分钟

> **目标受众**：22–35岁，男性向，职场喜剧+逆袭爽文爱好者

## 一、ID 命名规则

### 1.1 角色 ID

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **主角/配角** | `CHAR-###` | `CHAR-001` | 对白、关系、选角 |
| **群演** | `CHAR-GRP-##` | `CHAR-GRP-01` | 通用脸型一套即可 |

**规则**：
- 编号连续、不跳号
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3a）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨 segment 出现→独立 CHAR-###；纯背景无台词→CHAR-GRP

### 1.2 形象 ID

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

**格式**：`CHAR-###-L##`

### 1.3 场景 ID

| 格式 | 示例 | 说明 |
|------|------|------|
| `SCENE-###` | `SCENE-001` | 空间单位（地点不变 = 同一场景） |

### 1.4 道具 ID

| 格式 | 示例 | 说明 |
|------|------|------|
| `PROP-###` | `PROP-001` | 关键道具 |

### 1.5 分集与镜头 ID

| 格式 | 示例 | 说明 |
|------|------|------|
| 分集 | `EP##` | `EP01` |
| 镜头 | `EP##-S##-SH##` | `EP01-S01-SH03`（集数-分段-镜头） |

## 二、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于 story-architect 大纲元数据中的「视觉风格」和「色彩基调」字段。

| 维度 | 规格 |
|------|------|
| 渲染风格 | 都市写实 + 仙侠光效 (urban realism + xianxia glow effects) |
| 镜头参考 | cinematic 85mm lens for dialogue, wide-angle 24mm for action |
| 色调方向 | 暖色自然 + 高对比仙侠光效 (warm natural tones + high-contrast celestial lighting) |
| 画幅 | 9:16 vertical |
| 题材关键词 | 都市、仙侠、喜剧、职场、反差、荒诞 |
| 分辨率 | 720p（Seedance fast 输出） |

### 2.1 AI 图像生成通用后缀 (prompt_suffix)

```
, photorealistic, cinematic lighting, 8k quality, highly detailed, consistent character face, professional photography, sharp focus, natural skin texture
```

### 2.2 负面提示词 (negative_prompt)

**结构性禁忌（年代/题材约束）**：
- 现代品牌 logos（如 Apple、Nike、麦当劳等真实商业标识）
- 真实世界政治人物、政治标语、政治符号
- 仙侠场景中出现现代科技（手机、电脑、汽车等）——仅限现代场景使用
- 现代场景中出现明显仙侠元素（飞剑、法阵、古装人物等）——需通过剧情合理性处理
- 动漫风格、卡通渲染、3D 游戏风格
- 低质量、模糊、变形的手部
- 多余的手指、畸形的面部特征
- 水印、文字、字幕

**创意领域负面提示词由 character-designer / scene-prop-designer 补充**：
- 禁止动漫风格（anime style, cartoon, 3D render）
- 禁止过度美颜/磨皮
- 禁止不自然的肢体比例

### 2.3 Seedance 模型规格

| 参数 | 值 |
|------|-----|
| model | `doubao-seedance-2-0-fast-260128` |
| ratio | `9:16` |
| resolution | `720p` |
| duration_sec | `8-10`（理想）/ `4-12`（允许范围） |
| generate_audio | `true` |

## 四、工作流顺序（必读 · 防不同步）

| 顺序 | 层 | 文件 | 写什么 |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **主剧本** | `短剧剧本_雷劫劈错人了_36集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它** | 声音卡、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 六、分段规则

### 6.1 Segment 约束

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 约 12–15 段 | 对应单集 2.5 分钟时长 |

### 6.2 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 6.3 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 八、音色规范

### 8.1 Voice Prompt 格式

每个有对白的角色必须有 `voice_prompt`，格式：

```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

### 8.2 权威来源

| 优先级 | 文件 | 说明 |
|--------|------|------|
| **P0（最高）** | `资产/声音卡.md` | 专门定义声音参数的文件，最细粒度、最权威 |
| P1 | `资产/角色卡.md` | 角色总览中的 voice_prompt 字段 |
| P2（兜底） | `制片规范.md` | 制片规范中的音色段落 |

**规则**：存在 P0 时，**一律使用 P0**，忽略 P1/P2 中的 voice_prompt。voice_prompt 必须**全文复制**（含引号「」内全部文字），禁止缩写、改写、翻译、简化。

### 8.3 旁白与音效

- 旁白角色不分配 CHAR-ID，写为「旁白」，voice_prompt 独立定义
- 分集剧本镜头表中标注音效（如 `敲门声`、`紧张弦乐`）
- Seedance `generate_audio: true` 合成基础环境音；特殊音效后期叠加

## 九、年代/题材约束

### 9.1 必须体现元素

- 现代都市职场环境（写字楼、格子间、Excel、PPT）
- 仙侠元素（雷劫、真气、法阵、御剑、修真界）
- 文化冲突笑点（古装修士 vs 现代科技）
- 职场逆袭爽感（ accountants 用超能力解决工作难题）

### 9.2 禁止出现元素

- 真实品牌 logos 和商标
- 真实政治人物、政治事件、政治标语
- 现代武器（枪炮等）——仙侠场景使用法术/冷兵器
- 明显的时代错误（如古代场景出现手机）
- 过度血腥暴力（保持喜剧基调）
- 色情、低俗内容

## 十、分集剧本格式规范

分集剧本（`剧本/EP##/EP##_*.md`）是单集的**真相源**，所有后续文件（shots.yaml / segments.yaml）必须从此导出。

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`

## 十一、数据权威性声明（Canonical Source Authority）

### 11.1 角色数据权威来源

| 数据类型 | 权威来源 | 说明 |
|----------|----------|------|
| 角色 ID（CHAR-###） | `资产/角色索引.md`（production-planner 分配） | 唯一定义；character-designer 不可自行新增 |
| 形象 ID（CHAR-###-L##） | `资产/角色卡.md` / `资产/形象索引.md` | 角色卡定义，形象索引补充 |
| 场景 ID（SCENE-###） | `资产/场景卡片.md` | 唯一定义 |
| 道具 ID（PROP-###） | `资产/道具卡片.md` | 唯一定义 |
| voice_prompt | `资产/声音卡.md` | 最高优先 |

### 11.2 跨文件一致性维护

- **声音卡 ↔ 角色卡**：voice_prompt 如有差异，以声音卡为准
- **场景卡/道具卡 ↔ 分集剧本**：剧本中不得引用未在卡片中注册的 ID
- **禁止**不同文件中同一 ID 有不同定义
