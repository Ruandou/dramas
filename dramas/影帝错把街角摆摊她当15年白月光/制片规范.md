## 二、ID 命名规则

所有资产必须使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同视觉角色独立 ID + L01（按需创建，无上限） |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- **群演按需创建，不设数量上限**：有名字+跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词但需视觉区分 → `CHAR-GRP-##`（每个不同视觉角色独立 ID + L01）

### 形象层级结构定义

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

## 五、工作流顺序（必读 · 防不同步）

制片规范确立后，所有内容修改**严格按层向下**：

| 顺序 | 层 | 文件 | 写什么 |
|:----:|------|------|--------|
| **1** | **主剧本** | `短剧剧本_影帝错把街角摆摊她当15年白月光_72集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第 2 步引号内字面一致 |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

### 分段（Segment）规则 —— AI 生成单位

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | EP01 可至 12 段 |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 分集剧本格式规范（11 列镜头表）

分集剧本（`剧本/EP##/EP##_*.md`）使用以下 11 列镜头表：

| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白备注 |
|------|---------|------|------|------|------|------|------|------|------|----------|

- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`
- 角色引用：`**CHAR-###**`（粗体）；场景/形象 ID 用反引号

## 十、音色规范

### 语音描述格式

每个有对白的角色必须有 `voice_prompt`，格式：
```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

### 旁白与音效

- 旁白角色不分配 CHAR-ID，写为「旁白」，voice_prompt 独立定义
- 分集剧本镜头表中标注音效（如 `敲门声`、`紧张弦乐`）
- Seedance `generate_audio: true` 合成基础环境音；特殊音效后期叠加

### 声音卡片权威来源

- `资产/声音卡片.md` 是 voice_prompt 的 **P0 唯一权威来源**
- segment-builder 必须从此文件**全文复制** voice_prompt 到 YAML
- 同一角色跨 segment 的 `voice_prompt` 必须**全文一致**

## 十一、年代/题材约束

### 必须体现元素

- **2024–2028 中国一线城市**（现代都市男主事业线 / 摆摊线）+ **2009–2013 中学校园怀旧**（回忆线 / 林念时间锚点）
- 现代都市生活细节：手机支付、社交媒体（微博/小红书/抖音）、短视频热搜、杂志专访、颁奖礼盛典
- 当代娱乐圈生态：经纪人制、流量包、综艺录制、片场、影帝级商务代言
- 街角夜市摆摊经济：花艺手作、塑料花桶、收音机老歌、暖橙街灯
- 中学怀旧视觉符号：教室走廊、老式课桌、操场单杠、暖黄阳光
- 当代独立女性形象：离婚后摆摊自力更生、自学花艺、记账本、缝补床单
- 当代家庭关系：退休教师母亲、钢笔胸前别、朴素棉麻外套
- 颁奖礼商业符号：红毯、香槟塔、聚光灯、奖杯、黑衣保镖

### 禁止出现元素（结构性约束）

- **禁止**：古代物品（古装、兵器、文房四宝、宫灯等不符合现代的元素）
- **禁止**：奇幻/玄幻元素（法术、异能、非人类种族、超自然现象）
- **禁止**：与 2024–2028 中国一线城市严重不符的时代错位（如 BP 机、公用电话亭作为主要通讯方式）
- **禁止**：与 2009–2013 中国中学时代严重不符的年代错位（智能手机、iPad、初代 iPhone 5 之前设备）
- **禁止**：非现代中国的异域设定（中世纪城堡、日本和室、西方教堂婚礼等——除非剧情明确出国场景）

### 影帝题材专项禁止（Stage 1 强约束红线）

> 来源：drama-director 在 Stage 1 简报中已写入大纲，下游必须严格遵守

- ❌ 不可"潜规则"剧情（影帝行业剧最容易触碰，必须完全规避）
- ❌ 不可"婚外情"（女主的"离婚"是已完成状态，不是进行中的出轨）
- ❌ 不可"包养/拜金"（女主摆摊自力更生，不是因为男主有钱才接近他）
- ❌ 不可"娱乐圈潜规则/毒品/酗酒/吸烟"（影帝形象必须正面）
- ❌ 不可"性别歧视/物化女性"
- ❌ 不可"违背公序良俗"
- ✅ 核心导向：怀旧 + 暗恋 + 救赎 + 治愈 + 双向奔赴 + 独立人格

### 场景/道具人脸禁令（Stage 3 强约束）

- 场景参考图和道具参考图中**绝对禁止**出现任何人类面孔（含照片、画像、海报、贴纸、屏幕显示等平面媒介）

## 十二、内容合规参数

### 题材合规等级

🟢 **C 级**（一般题材 · 都市爱情 / 怀旧 / 治愈），可直接推进。

### 本剧特定红线（来自 Stage 1 drama-director 简报 + 题材特性）

1. ❌ 禁止任何"潜规则/包养/娱乐圈权色交易"剧情（影帝题材雷区）
2. ❌ 禁止"婚外情"——姜晚与陈屿的婚姻是**已完成状态**（离婚已完成），不可改写为进行中出轨
3. ❌ 禁止"拜金/依附"——姜晚与沈昭临的关系是**双向奔赴**，不是"被有钱人拯救"
4. ❌ 禁止"娱乐圈潜规则/毒品/酗酒/吸烟"——沈昭临形象必须正面、克制、清醒
5. ❌ 禁止"性别歧视/物化女性"——姜晚全程保持独立人格与尊严

### 灰区处理策略

| 灰区 | 风险点 | 处理方式 |
|------|--------|----------|
| **林念已离世** | 涉及"死亡/离世"情绪但非暴力 | 改用"15 年前因病安静离世"（非事故/非暴力），全程不渲染死亡过程，仅作为情感伏笔 |
| **陈屿绑架** | 涉及限制人身自由 | EP28 仓库绑架+警方解救，全程不出现肢体暴力；沈昭临的爆发限于吼叫和眼神 |
| **12 万债务线** | 涉及"前夫高利贷" | 改写为"婚前投资款争议"（民事纠纷），不涉及黑社会/暴力催收 |
| **娱乐圈炒作** | 涉及"流量包/水军" | 改写为"娱乐记者/公关公司行为"，不涉及平台官方违规 |
| **颁奖礼大战** | 涉及"大型活动" | 仅作为情感表达场景（沈昭临念林念的信），不涉及任何现实政治影射 |
| **错认机制** | 涉及"身份欺骗" | 明确为"无恶意的巧合"——姜晚被动接戏，且最终真相大白并升华 |

### 正向价值锚点

1. **独立女性成长** — 姜晚从"被前夫追债的摆摊女"→"拒绝被替还债、独立法律维权"→"开花艺工作室+花艺工作坊第一课"，全程自尊自强
2. **被错位的人生被温柔重组** — 不是"逆天改命"而是"两个被错位的人找到彼此"，治愈主题
3. **真心被看见** — 姜晚从"被错认成白月光"到"以姜晚本人被深爱"，拒绝"被当作替身"的工具化

### 平台审核重点提示（前 3 集）

- **EP01**：开篇错认 + 离婚前夫追债 + 街角夜市戏——需确保：（a）不渲染"离婚的卑微"，突出姜晚的"体面"；（b）前夫纸条仅作为剧情钩子，不出现暴力威胁画面
- **EP02**：拿铁/护手霜细节——纯怀旧治愈，避免被误读为"暧昧暗示"；（b）"林念最爱的拿铁"等信息点是男主视角的怀旧，不是调情
- **EP03**：沈昭临一句"这是我女朋友"镇场 + 姜晚被威胁——（a）影帝级气场压制前夫是"打脸爽"，不是"权势压人"；（b）姜晚的"被动接受保护"必须为后续 EP22 "这是我的事"独立人格做伏笔铺垫
