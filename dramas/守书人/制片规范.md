# 《守书人》制片规范 · ID 与引用

> **正名**：《守书人》
> **版本**：v1.0 · 2026-06-12
> **题材**：仙侠 / 知识逆袭 / 反套路修仙
> **集数**：36集（三幕结构：建立1-3 / 积累4-12 / 反转13-24 / 清算25-36）
> **单集时长**：2.5–3 分钟（140–200 秒）
> **画面比例**：9:16 竖屏
> **生成工具**：Seedance 2.0 Fast + Seedream 5.0（参考图）
> **目标受众**：18-35岁，男性偏重，喜欢"知识即力量"、逆袭爽文、反套路修仙

## 一、ID 命名规则

所有资产使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨segment出现→独立CHAR-###；纯背景无台词→CHAR-GRP

### 形象层级结构

| 后缀     | 名称     | 说明                                           |
| -------- | -------- | ---------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                   |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01    |

## 二、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于 story-architect 大纲元数据中的「视觉风格」和「色彩基调」字段。

| 维度 | 规格 |
|------|------|
| 渲染风格 | photorealistic with ink-wash xianxia aesthetics（水墨仙侠写实风） |
| 镜头参考 | cinematic 85mm lens for close-ups, wide-angle 24mm for establishing shots |
| 色调方向 | ink-black base + gold (knowledge light) + indigo-blue (forbidden power) + vermillion-red (blood contracts) |
| 画幅 | 9:16 vertical |
| 题材关键词 | ink-wash xianxia, living calligraphy, knowledge incarnate, ancient scroll magic, cultivation world |

### prompt_suffix（全局风格后缀 · Seedream 5.0）

```
, Chinese ink-wash painting style blended with photorealistic rendering, xianxia cultivation world aesthetic, cinematic lighting, 85mm portrait lens, ethereal ink particles floating in air, ancient Chinese calligraphy motifs, muted ink-black and gold color palette with indigo and vermillion accents, volumetric fog, 8K detail, dramatic chiaroscuro lighting, film grain, vertical composition 9:16 aspect ratio
```

### negative_prompt（全局负面提示词）

```
modern clothing, modern buildings, smartphones, computers, electric lights, neon signs, western fantasy elements, anime style, cartoon, chibi, low quality, blurry, deformed hands, extra fingers, watermark, text overlay, logo, bright saturated colors, plastic skin, western medieval armor, guns, firearms, contemporary objects, Japanese kimono, Korean hanbok, overly sexualized, nudity, gore, excessive blood
```

### 年代/题材约束

**必须体现元素**：
- 架空古代修仙世界的建筑与服饰风格（中式古风，非特定朝代）
- 文字/书法/古籍作为核心视觉母题——墨蝶、光纹、流动的文字
- 灵力以墨色/金色光纹形式呈现
- 禁书阁作为核心场景的古楼质感（木质结构、烛火照明、浮尘墨香）

**禁止出现元素**（结构性约束）：
- 任何现代科技物品（手机、电脑、电灯等）
- 明确的朝代标识（本剧为架空世界）
- 日式/韩式服饰元素（保持中式古风统一性）
- 西方奇幻元素（龙、城堡、骑士铠甲等）
- 枪械或现代武器

## 四、工作流顺序（必读 · 防不同步）

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_守书人_36集.md` | 集纲、每场剧情、对白要点、钩子                      |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡片、资产索引等       | 仅在前几步定稿后随需更新                            |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 六、分段规则

### 分段（Segment）规则 —— AI 生成单位

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 12–15 段        | 对应单集 2.5 分钟时长                                   |
| 每集镜头数       | 15–30 镜        | 分布于 12-15 个 segment 中                              |
| 单集总时长       | 140–200 秒      | 2.5–3 分钟                                              |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 十、受众定位

- **主频道**: 男频（仙侠/逆袭）
- **核心年龄段**: 18-35
- **核心痛点**: ①被低估/被看不起的共情 ②知识改变命运的信念 ③守护与自由的价值选择
- **爽感期待**: SAT-SLAP（打脸）30% + SAT-COME（逆袭）30% + SAT-BURN（燃爽）20% + SAT-PAIN（虐心感动）20%

## 十二、条件放行协议

当门控阶段需要用户审批但用户 3 轮交互内未回应时：
1. 文本自检（分辨率/文件完整性/ID一致性/命名规范）
2. 自检通过 → 标记「条件放行（⚠️ 待用户确认）」写入工作计划
3. 自检不通过 → 返工，不等待用户
4. 用户回应后 → 更新为正式通过或回退重做
