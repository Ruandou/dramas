# 形象索引（CHAR-*-L**）

> **角色**（`CHAR-###`）= 谁：对白、关系、选角演员  
> **形象**（`CHAR-###-L##`）= 长什么样：出图、分镜、换装  
>  
> 规则见 [`../制片规范.md`](../制片规范.md) § 形象 ID  
> 详情 Prompt 见 [`../角色卡.md`](../角色卡.md)

---

## 使用规则（摘要）

1. **每个角色必须有且仅有一个 `L01` 基础形象**（全身定妆照 / Character Sheet 锚点）。  
2. **`L02` 起为衍生形象**，`based_on` 必须指向该角色 `L01`；Prompt 只写与 L01 的**差异**（服装、妆效、道具、伤势、年龄感），脸与体型不重写。  
3. **分镜表**：`角色` 列写 `CHAR-###`（对白归属）；**`形象` 列写 `CHAR-###-L##`**（本镜出图）。单形象角色可省略形象列，默认 `L01`。  
4. **AI 出图顺序**：先生成/定稿 `L01` → 图生图或「same face as L01」生成 `L02+`。
