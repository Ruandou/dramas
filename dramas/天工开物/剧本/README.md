# 剧本目录

《天工开物之匠魂》每集独立剧本，按 `EPnn/` 子目录归档。

## 目录结构

```
剧本/
├── EP01/          # 第 1 集
├── EP02/          # 第 2 集
├── EP03/          # 第 3 集
├── ...
└── EP36/          # 第 36 集
```

## 每集文件说明

| 文件                 | 用途                                     |
| -------------------- | ---------------------------------------- |
| `EPnn_*.md`          | 该集剧本正文（对白、场景、分镜描述）     |
| `EPnn_segments.yaml` | 有声段落切分（旁白/对白/音效时间轴）     |
| `EPnn_shots.yaml`    | 分镜表（镜头号、画面描述、Prompt、时长） |
| `EPnn_shots.json`    | 分镜表 JSON 格式（供脚本/API 读取）      |
