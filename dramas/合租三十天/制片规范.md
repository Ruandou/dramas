## 一、ID 命名规则

所有资产使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01` | 每个不同角色独立 ID（按需创建，无上限） |
| **场景** | `SCENE-###` | `SCENE-001` | 布景 |
| **道具** | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，写明 `based_on: CHAR-xxx-L01`
- **群演按需创建**：有名字+跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词 → `CHAR-GRP-##`，每个视觉不同角色独立 ID

### 形象层级结构

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

## 六、工作流顺序（必读 · 防不同步）

| 顺序 | 层 | 文件 | 写什么 |
|:----:|------|------|--------|
| **1** | **主剧本** | `短剧剧本_合租三十天_72集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第 2 步引号内字面一致 |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 八、分段规则

### Segment 约束

| 约束 | 值 | 说明 |
|------|------|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每段必须构成完整叙事节拍 |

### 拆分原则

1. **不得**在对话中间切断 segment
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 十一、音色规范

### voice_prompt 格式

每个有对白角色必须有 `voice_prompt`，格式：
```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

### 数据权威性声明

| 优先级 | 文件 | 说明 |
|--------|------|------|
| **P0（最高）** | `资产/声音卡片.md` | 最细粒度、最权威 |
| P1 | `资产/角色卡片.md` | 角色总览中的 voice_prompt 字段 |
| P2（兜底） | `制片规范.md` | 本节 |

- 存在 P0 时，**一律使用 P0**，忽略 P1/P2
- voice_prompt 必须**全文复制**，禁止缩写、改写、翻译

### 旁白

- 旁白角色（陈小满小说朗读兼旁白）不单独分配 CHAR-ID，写为「旁白」
- Seedance `generate_audio: true` 合成基础环境音；特殊音效后期叠加

## 十二、年代/题材约束

### 必须体现元素

- 现代都市公寓生活场景（合租、外卖、WiFi、视频通话）
- 职场歧视/单亲妈妈困境的真实呈现
- 女性互助、非浪漫关系的情感深度
- 法律程序（抚养权听证）的合理性
- 手机、社交媒体、网络写作等当代元素

### 禁止出现元素

- 古代/仙侠/奇幻元素
- 极端暴力、血腥画面
- 明确性暗示或裸露
- 美化违法行为
- 政治敏感内容
- 恐怖/灵异元素

## 内容合规参数

### 题材合规等级

**C 级**（安全）：都市现实题材，无暴力/政治/敏感内容，适合全平台分发。

### 本剧特定红线

1. **抚养权争议**：不得暗示"母亲天然优于父亲"的歧视性立场；赵一鸣的败诉必须基于证据和行为（操纵/勾结），而非性别偏见
2. **债务/催收**：不得描绘非法催收暴力行为；投资人施压仅限于纸条、电话、跟踪等暗示性手段
3. **苏念真的"共犯"身份**：必须明确她在知情后选择了揭露而非继续参与；法律后果以和解/免责方式处理，不得美化违法行为
4. **陈母的控制行为**：必须呈现为"以爱之名的过度保护"而非恶意虐待；最终走向和解而非决裂
5. **网暴描写**：EP45 苏念真被网暴时不得展示具体恶意评论内容，仅通过角色反应暗示

### 灰区处理策略

| 灰区 | 处理方式 |
|------|----------|
| 抚养权法律程序 | 简化法律术语，聚焦情感和人物行为，不追求法律流程完全精确 |
| 投资人威胁 | 以心理施压为主，避免任何物理暴力画面；威胁纸条仅为文字 |
| 苏念真"知情不报" | 明确她曾试图报警但被威胁，最终主动揭露，以正面收束 |
| 职场歧视 | 展示为"需要被改变的不公"而非"理所当然"，林晓棠的回应是离开而非忍受 |

### 正向价值锚点

1. **女性互助**：三个不同背景的女人在困境中互相支撑，展现非浪漫关系的深度情感连接
2. **真实而非完美**：林晓棠以"不完美但真实"赢得抚养权，传递"真实就是力量"
3. **自我认同**：陈小满从讨好型人格到敢于对母亲说"我也认我自己"，传递独立人格的价值

### 平台审核重点提示（EP01–03）

| 集数 | 注意点 |
|------|--------|
| EP01 | 合租场景不得暗示任何色情/暧昧元素；三个陌生女性同住需合理化（房东要求） |
| EP02 | 争吵场景控制在口角层面，不得出现肢体冲突 |
| EP03 | 苏念真的"催债短信"不得展示具体威胁性文字；陈母的语音消息不得包含辱骂性词汇 |

### 跨文件一致性维护

- **声音卡片 ↔ 角色卡片**：如有差异，以声音卡片为准

- **禁止**不同文件中同一 ID 有不同定义
