- **苏念 ←→ 苏念妈妈**：母女创伤——苏念12岁起收集"婚姻失败数据"来证明"爱情不存在"，数据源就是父母的婚姻。EP16再婚通知触发防御，EP29"很爱过……只是走丢了"开始疗愈。
- **苏念 ←→ 方敏**（间接）：方敏的截稿deadline为陆深施加外部压力，间接影响苏念——她在第24集意识到陆深在赌上职业生涯。

### 联盟关系
- **苏念 — 程晓棠**：闺蜜联盟。程晓棠是苏念的"反数据"——苏念分析一切，她感受一切。她的功能不是给建议，是戳穿苏念的自我欺骗。
- **陆深 — 老周**：咖啡馆共谋。从EP06起老周帮陆深做实验，两人有无需言语的默契。老周是陆深在"苏念世界"里的第一个盟友。
- **程晓棠 — 陆深**：助攻联盟。程晓棠在EP09后暗中帮助陆深——安排偶遇（EP14假生病短信）、策划婚礼（EP26）。他们共同的目标：让苏念面对自己的感受。

### 情感关系
- **苏念 ♥ 陆深**：慢热智性浪漫。从实验对手→邻居→信任崩塌→重建→选择。情感障碍：她的"逃跑者"模式（习惯先离开以防被离开）+ 他的"过度准备"（手稿事件让她的信任碎裂）。情感突破：EP30她替他写完第18天段落——"被看穿没那么可怕。"EP36她递出钥匙而非告白——"爱情无法被证明，只能被选择。"
- **苏念妈妈 → 苏念**：母女情感。障碍：苏念把父母的婚姻当作"爱情不存在"的原始数据。突破：EP29母亲说出"很爱过……只是后来走丢了"——"走丢了"≠"从未存在"。

### 秘密关系
- **陆深知道（EP12前保密）**：他关注苏念的数据博客已两年，搬到隔壁不是偶然。他有一本黑色笔记本，从第1天起就在记录她。第36天那一页写着"结局由她来写"。
- **苏念不知道（EP20前）**：陆深为她退了两次预付稿费，出版社要把他列入黑名单。他对出版社说"在等一个数据样本"。
- **苏念不知道（EP18前）**：陆深的第7本书手稿预写了她的所有反应——但第18天和第36天留了空白。他没有预设她的结局。
- **苏念知道但陆深不知道**：她不吃姜。博客里没有写。这是她在他"两年数据"中找到的第一个盲区（EP14）。
- **程晓棠知道、苏念和陆深都以为对方不知道**：她在暗中推动两人——EP14假生病短信、EP20安排方敏偶遇、EP26策划婚礼。

## 补充说明

### 视觉风格一致性

所有角色 L01 Prompt 统一使用：
- 正向锚定词：`photorealistic` / `realistic photograph` / `editorial portrait photograph` / `cinematic 35mm lens` / `shot on 85mm lens` / `natural skin texture with visible pores`
- 风格后缀：`contemporary urban realism, natural daylight, street photography aesthetic`
- 反向提示（所有 Prompt 末尾）：`NOT anime, NOT cartoon, NOT illustration, NOT manga`
- 构图：`wide shot showing entire figure from head to toe`, `plain white background`, `clean flat studio lighting`

### PROP 交叉引用

角色视觉锚点中涉及的关键道具均已标注 PROP-ID（由 production-planner 预分配）：
- CHAR-001 耳后的 Apple Pencil → `PROP-001`
- CHAR-001-L02 手握的墨绿色笔记本 → `PROP-004`
- CHAR-002 手指墨痕（使用 `PROP-002` 陆深的钢笔所致）
- CHAR-006 佩戴的旧项链 → 非独立 PROP（不可分离的穿戴装饰）

### 角色辨识度测试

观众在5秒内区分所有主要角色的关键点：
- **苏念**：黑框圆眼镜 + 齐肩短发 + 冷色调白衬衫 → 唯一戴圆框眼镜的女性
- **陆深**：微卷发 + 手指墨痕 + 驼色针织衫 → 唯一有墨水痕迹的角色
- **程晓棠**：高马尾 + 亮橙上衣 + 大耳环 → 唯一穿亮色的角色
- **老周**：白围裙 + 胸前老花镜 + 手中咖啡杯 → 唯一穿围裙的角色
- **方敏**：利落短发 + 方框眼镜 + 笔记本包 → 与苏念同为眼镜角色但方框vs圆框、短发vs齐肩发
- **苏念妈妈**：银丝发 + 淡紫针织衫 + 温柔疲惫眼 → 唯一有明显银发和年龄感的女性
- **墨点**：黑猫 + 绿眼 + 左耳白点 → 唯一非人类角色

### 形象层级使用规则

- **L01（基准形象）**：全剧面部一致性锚点。必须先于任何 L02+ 生成并获得确认。
- **L02+（衍生形象）**：必须以 L01 为参考图输入，仅描述差异部分（服装、配饰、表情变化），面部锚定块逐字保留。
- 苏念和陆深各 2 个形象（L01 基准 + L02 阶段变体），其余角色各 1 个形象（L01 仅）。
