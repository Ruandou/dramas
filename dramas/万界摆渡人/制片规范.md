## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同角色独立 ID + L01 |
| 场景 | `SCENE-###` | `SCENE-001` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**；弃用标 `deprecated: true`
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演按需创建：有名字+跨集出现 → 独立 `CHAR-###`；纯背景无台词但需视觉区分 → `CHAR-GRP-##`

### 形象层级结构

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

## 四、工作流顺序（必读 · 防不同步）

改台词、场次、字幕/旁白策略时**严格按层向下**，**禁止**先改 `segments.yaml` 或 `shots.yaml` 再回头补剧本。

| 顺序 | 层 | 文件 | 写什么 |
|:---:|---|---|---|
| **1** | **主剧本** | `短剧剧本_万界摆渡人_72集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | 同目录 `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | 同目录 `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**单集真相源**：拍什么、说什么 → **`剧本/EP##/EP##_*.md`**；主剧本为纲，segments 为 API 展开。

### Segment 拆分规则（强制）

| 约束 | 值 | 说明 |
|------|------|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | 对应单集 75–120 秒（EP01 可至 12 段） |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 内容合规参数

### 题材合规等级
- **分级**：🟢 C级
- **说明**：纯奇幻冒险题材，架空世界观，无政治/军事/司法元素，无封建迷信宣扬

### 本剧特定红线
1. **禁止暗黑暴力**：魘影/暗影相关场景不得出现血腥肢解，暗影攻击以黑雾/能量波表现
2. **禁止宗教暗示**：轮回之城的"轮回"概念为架空设定，不得暗示现实宗教轮回观
3. **父子关系正向**：李渡与李沧海的父子线最终必须和解，不得宣扬"弑父"或"断亲"
4. **女性角色独立**：苏晚是独立摆渡人，不是纯花瓶；凤焰之力是家族传承而非李渡赐予
5. **治愈基调优先**：暗影领域等暗色场景占比不得超过全剧 30%，必须有温暖回归

### 灰区处理策略

| 灰区内容 | 本剧是否涉及 | 处理方式 |
|----------|-------------|----------|
| "父亲是反派"设定 | 是 | EP36 即揭示父亲是主动牺牲的英雄，不宣扬"父亲=坏人" |
| 角色濒死/牺牲 | 是 | 苏晚濒死（EP44-45）、父亲牺牲（EP57/65）均以治愈/温暖方式收束 |
| 暗影领域恐怖氛围 | 是 | 控制恐怖元素为奇幻悬疑感，不使用 jump scare 或血腥画面 |
| 万界概念类似"多神" | 否 | 万界为物理空间概念，不涉及神灵体系 |

### 正向价值锚点
- **核心价值 1**：连接比分离更需要勇气（贯穿全剧的母亲信条）
- **核心价值 2**：普通人也能拯救世界（李渡从外卖骑手到万界摆渡人）
- **核心价值 3**：治愈而非毁灭（暗影本体的终极解法是治愈而非消灭）

### 平台审核重点提示
- **前 3 集**（审核最严）：EP01-03 为日常奇幻冒险，无暴力血腥，重点展示温暖治愈 + 冒险好奇心；确保无封建迷信暗示（摆渡人体系为架空职业设定）
- **付费卡点**：EP03（首次付费点）以信息钩（父亲线索）驱动，无低俗内容
- **结局要求**：EP72 传递正向信息——万界恢复连接，新摆渡人传承，陆离光点闪烁暗示永恒守护

## AI 出图/视频衔接

### 出图流程

1. 分镜 **场景** → `资产/场景卡片.md` → `SCENE-###`
2. 分镜 **形象** → `资产/形象索引.md` → `角色卡片.md` 内该 **L##** 的 Prompt
3. **L01**：用「基础 Prompt」生成 Character Sheet（正面全身，白底）
4. **L02+**：`based_on` 指向 L01 参考图 + **delta Prompt**（仅服装/道具/妆效/伤痕）
5. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`
6. 分镜 **角色** 列仅用于对白表，不参与出图 Prompt 拼接

### 角色一致性规则

- 每个角色 **L01** 生成后，所有后续出现必须使用该 L01 作为 reference_image
- 衍生形象仅改变服装/状态，面部特征锁定为 L01
- 同集多角色：每人独立 L01 → 拼合时按角色顺序排列参考图

### 场景一致性规则

- 每个场景 **SCENE-###** 生成参考图后，后续同场景必须使用该参考图
- 同场景不同角度：用同一参考图做 img2img 变体，禁止重新生成
