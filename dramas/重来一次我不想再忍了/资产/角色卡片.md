#### 语言画像（完整版）

| 维度 | 描述 |
|------|------|
| 词汇层级 | **重生前**：语气词多（"那个""可能""我觉得"），常用敬语（"您看""麻烦您"），自我弱化表达。**重生后**：简洁有力，减少语气词，多用陈述句和判断句（"这件事我来处理""我的判断是"）。职场场景：专业术语精准但不炫技（ROI、数据闭环、市场渗透率、用户留存）。私下场景：对苏晴可放松到日常口语 |
| 句式偏好 | **职场对峙**：多用短句+反问。**谈判/演讲**：递进式排比。**与陆北辰**：长句增多，放松自然。**内心独白**：短促碎片化，句号多逗号少 |
| 口头禅/标志表达 | **前期**："没事"（自我安慰）。**觉醒后**："我来处理"（主动担责）。**愤怒时**："有意思"（冷笑反话） |
| 情绪表达方式 | **愤怒**：压低声音、语速放慢、一字一句（外冷内热的压抑式爆发）。**感动**：语塞→简短一句→转移话题。**自信**：尾音下沉，陈述句收尾 |
| 禁用词 | 绝不会使用自我贬低的词汇（"我不行""我做不到""我不配"）——重生后尤其明显 |
| 参照原型 | 《甄嬛传》甄嬛的回宫后阶段——从容、冷静、每句话都有目的 |
| 对白权力模式 | **主导型(dominating)** — 重生后逐渐从迎合型转为主动掌控对话走向，擅长用反问和沉默控制节奏 |
| 信息密度 | **高** — 每句话至少包含一个有效信息点或情绪锚点，极少废话；谈判时一句话携带多重信息 |
| 沉默策略 | 在被质疑或对方情绪激动时选择沉默——用3-5秒的凝视和沉默让对方先暴露底牌。沉默时观众应感受到"她在思考、在计算" |
