## 一、ID 命名规则

所有资产必须使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L##` | `CHAR-GRP-01-L01` | 群演形象，每个不同角色独立 ID    |
| **场景** | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| **道具** | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演按需创建，不设数量上限：有名字+跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词但需视觉区分 → `CHAR-GRP-##`。每个 `CHAR-GRP-##` 都必须分配独立 ID 和 L01 形象。
- 同一 CHAR-GRP-## 可跨集复用，但不同视觉角色不可共用同一 ID

### 形象层级结构定义

| 后缀     | 名称     | 说明                                           |
| -------- | -------- | ---------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                   |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01    |

## 三、内容合规参数

### 题材合规等级
- **C级** — 纯都市/女频/重生/职场/爽文，无政治/军事/司法/迷信红线
- 注意事项：重生设定需强调"心理成长与自我觉醒"，避免因果报应等敏感暗示

### 本剧特定红线
1. **重生机制不神秘化**：林晚的重生源于情绪崩溃后的"记忆觉醒"，而非超自然力量或玄学轮回
2. **职场斗争不越界**：所有商业竞争手段须在法律框架内，不使用非法监视、暴力等违法手段
3. **渣男/反派结局合规**：周明远、贺云峰等反派的"罪有应得"须通过合法途径实现（媒体曝光、证监会调查等），非私刑报复
4. **母女关系正面落点**：林母的重男轻女刻画须有转变弧线，最终落在"懂得与和解"，不煽动对父母的仇恨
5. **资本博弈表现分寸**：盛天资本的恶意收购行为聚焦于商业规则博弈，不渲染"资本家都是坏人"的刻板印象

### 灰区处理策略
| 灰区 | 处理方式 |
|------|----------|
| 林晚利用"前世记忆"预判未来 | 强调为"行业经验积累+敏锐洞察"，不归因于"先知"或"特异功能" |
| 职场中的算计与反击 | 林晚的反击均为"防守反击"，先被攻击再证据回击，非主动设陷害人 |
| 疑似婚外情/情感纠葛 | 周明远与陈莉的勾结表现为商业利益勾连，不过度渲染情感出轨细节 |
| 资本做空/恶意收购 | 仅展现商业策略博弈，不做金融操作细节的教学式呈现 |

### 正向价值锚点
1. **女性独立自强**：职场女性不靠依附他人获得成功，凭专业能力和坚韧精神赢得尊重
2. **自我觉醒与成长**：从讨好型人格到自信独立，传递"做自己的主角"的积极人生观
3. **良善终有回报**：林晚的善良（对赵总的仁慈、对团队的信赖）最终成为她的力量而非软肋

### 平台审核重点提示（前3集）
- **EP01**：重生觉醒场景注意不要出现"酗酒""寻死"等负面暗示，改为"天台吹风、疲惫到恍惚"的呈现方式
- **EP02**：利用记忆未卜先知须措辞为"行业经验积累的准确判断"，避免"预知未来"的超自然表述
- **EP03**：当众拆穿陈莉的冲突场景保持"职场专业对峙"基调，避免低俗骂战或肢体冲突

## 四、分段规则（Segment 规则）—— AI 生成单位

> 数值约束以本文件为 single source of truth，所有 Agent 禁止硬编码不同数值。

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | 对应单集 75–120 秒（EP01 可至 12 段） |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### 每集时长配置（episode_profile）

| 集数范围 | 时长区间 | 备注 |
|----------|---------|------|
| EP01 | 90–120 秒 | 开篇集，含重生觉醒高光场景，段落可至 12 段 |
| EP02–EP10 | 75–100 秒 | 常规单集 |
| EP11–EP18 | 75–100 秒 | 第一幕高潮期 |
| EP19–EP45 | 75–100 秒 | 第二幕博弈期 |
| EP46–EP65 | 75–100 秒 | 第三幕对决期 |
| EP66–EP72 | 80–120 秒 | 完结篇，含情感升华场景，段落可至 12 段 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 五、分集文件头（YAML 模板）

```yaml
---
episode_id: EP01
episode_title: [集标题]
duration_sec: 90  # EP01为120s，后续集75-100s；参见 episode_profile
season: S1
scene_ids: [SCENE-001, SCENE-002]
character_ids: [CHAR-001, CHAR-002]
look_ids: [CHAR-001-L01, CHAR-002-L01]
prop_ids: [PROP-001, ...]
seedance_defaults:
  model: doubao-seedance-2-0-fast
  ratio: "9:16"
  resolution: 720p
  image_resolution: 1600×2848（Seedream 参考图，9:16 竖屏）
  duration_sec: "8-10"
  generate_audio: true
---
```

## 六、分集剧本格式规范（11 列镜头表）

分集剧本（`剧本/EP##/EP##_*.md`）是单集的**真相源**，所有后续文件必须从此导出。

| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白备注 |
|------|---------|------|------|------|------|------|------|------|------|---------|

SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行。

对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`。

## 七、工作流顺序（必读 · 防不同步）

制片规范确立后，所有内容修改**严格按层向下**：

| 顺序 | 层 | 文件 | 写什么 |
|:----:|----|------|--------|
| **1** | **主剧本** | `短剧剧本_剧名_72集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 十、年代/题材约束

### 必须体现元素
- 2016-2025 年的时代特征：智能手机迭代（2016年 iPhone 7 时代）、短视频平台兴起、共享经济热潮、创业/资本热潮
- 职场环境的真实感：格子间、白板、投影仪、咖啡机、加班外卖
- 色调过渡：EP01-18 暖灰调 → EP19-45 暖橙主调，灰色为辅 → EP46-72 温暖明亮

### 禁止出现元素（叙述性约束，Prompt 由设计师负责）
- 禁止出现超自然视觉特效（重生通过眼神、表情、光影变化表现，而非发光、时光隧道等特效）
- 禁止出现血腥、暴力、灵异视觉元素
- 禁止出现奢侈品品牌 Logo 露出（可穿类似风格但不出现商标）
- 现代都市剧不得出现古装元素
