# 《全楼都觉得我和女明星同居》项目规范

## 项目简介

都市误会恋爱轻喜剧，36集×2-3分钟。
男主雨夜收留陌生女生，全小区以为他在和顶流「沈鹿」同居——其实她是沈鹿的御用替拍。

## 核心规则

1. **肖像法务**：沈鹿为虚构艺人，禁止影射任何真实明星。所有AI素材禁止使用真实明星面孔。
2. **ID体系**：角色 `CHAR-###`、形象 `CHAR-###-L##`、场景 `SCENE-###`、道具 `PROP-###`。详见 `制片规范.md`。
3. **形象一致性**：每个角色必须先定稿 `L01` 基础形象，`L02+` 衍生形象必须 `based_on` L01。
4. **分镜引用**：可拍分镜在 `剧本/EP##_*.md`，必须带 CHAR/SCENE 引用。

## 目录结构

```
├── 资产/          # 角色索引、形象索引、场景卡片
├── 剧本/          # 分集可拍分镜（EP01_敲门.md 等）
├── assets/
│   ├── generated/ # AI生成成品（禁止写入占位）
│   ├── looks/     # 角色定妆参考图
│   ├── scenes/    # 场景参考图
│   └── props/     # 道具参考图
├── script/        # 自动化脚本
├── 角色卡.md      # 角色外貌/Prompt详情
├── 人物小传.md    # 角色深度设定+关系图
├── 制片规范.md    # ID命名规则+美术规范
└── 短剧剧本_*.md  # 36集纲要+详细剧本
```

## 禁止事项

- 禁止向 `assets/generated/` 写入占位视频或测试文件
- 禁止使用真实明星肖像生成AI素材
- 禁止跳过 L01 直接生成 L02+ 衍生形象
