## 三、已确认决策（不用再问）

| #  | 决策                                                                               |
| -- | ---------------------------------------------------------------------------------- |
| 1  | 全季 36 集统一为 S1（无分季）                                                      |
| 2  | 所有剧本放 `剧本/`，一集一文件（`EP##_标题.md`）                                   |
| 3  | 角色卡、场景卡片必须带 **ID**（`CHAR-###`、`SCENE-###`）                           |
| 4  | 分镜角色列引用 `CHAR-*`，场景列引用 `SCENE-*`                                      |
| 5  | 现代都市，禁止出现任何真实明星肖像、品牌 Logo                                      |
| 6  | Seedance：**段落提交** + `generate_audio: true`，不用剪映拼片                      |
| 7  | 声音路线一：先 `voice_prompt` → 漂移再 `reference_audio` → TTS 最后手段            |
| 8  | 字幕后期通过 ffmpeg 添加，Seedance 不烧录字幕（`prompt_suffix` 控制）              |
| 9  | EP01–03 为管线验证优先集，其余按阶段批次推进                                        |
| 10 | 资产图由 Seedream 生成，不手绘；先 TOS 上传再提交 Seedance                         |
| 11 | 虚构艺人「沈鹿」，禁止影射任何真实明星                                             |
