# 《全楼都觉得我和女明星同居》短剧剧本（36集）

## 项目信息

- **类型**：都市 / 误会 / 恋爱 / 轻喜剧
- **集数**：36 集 × 2–3 分钟
- **叙事节奏**：收留 → 误认 → 舆论发酵 → 身份揭开 → 真在一起
- **一句话**：男主雨夜收留陌生女生， **全小区以为他在和顶流「沈鹿」同居**——其实她是 **沈鹿的 Body Double（御用替拍）** 在躲经纪公司的「卖身契」。

---

## 肖像与法务（拍摄前必读）

| 规则       | 说明                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------- |
| **顶流名** | 全剧只用虚构艺人 **「沈鹿」**（公司：星澜娱乐）， **不出现、不影射任何真实艺人全名/肖像** |
| **替拍**   | 女主 **温宁** 是合同替拍（侧脸/背影/危险动作）， **不是** 宣称「我就是沈鹿」诈骗          |
| **素材**   | 海报/AI 生成 fictional 面孔；禁止用真实明星脸融图                                         |
| **剧情**   | 小区误认来自 **口罩+身形+狗仔旧图**；温宁 **从未主动冒名**                                |

## 投流标题库

- 我收留的租客，全小区说是顶流沈鹿——其实她是替拍
- 狗仔蹲错门，我社死成「沈鹿男友」
- 真沈鹿问我：「你家里那个，是我还是不是我？」
- 合同写替拍不能露脸，她在我阳台第一次被看见正脸

## 分集大纲（第 1–36 集）

### 第一章：雨夜（1–6 集）

**第1集《敲门》** — 温宁雨夜敲门；陆见 **不该开门但开了**。  
**第2集《别拍》** — 温宁：「别开灯，有镜头。」陆见关窗。  
**第3集《口罩》** — 出门倒垃圾， **同款口罩** ；林大妈偷拍。  
**第4集《热搜》** — 小区群：「沈鹿男友住 6 栋？」陆见懵。  
**第5集《澄清失败》** — 陆见辟谣；评论：「越描越黑。」  
**第6集《温宁走》** — 温宁要走不连累；陆见：**「你走了更像默认。」**

### 第二章：同居（7–12 集）

**第7集《物业》** — 物业要登记；温宁 **戴帽登记「温宁」** ；群说「沈鹿化名」。  
**第8集《狗仔》** — 蹲守；陆见买菜 **举两个袋挡脸** 成 meme。  
**第9集《剪辑》** — 陆见工作；温宁帮对色， **专业** 。  
**第10集《文姐》** — 经纪上门；温宁躲衣柜；陆见对文姐：**「这里没有沈鹿。」**（真话）  
**第11集《侧脸》** — 邻居拍到 **侧脸像沈鹿** ；温宁崩溃。  
**第12集《决定》** — 温宁要现身澄清是替拍；星澜 **威胁违约千万**。

### 第三章：替拍（13–18 集）

**第13集《合同》** — 陆见读合同： **替拍+陪同** 灰色条款。  
**第14集《陆见发》** — 陆见剪 **对比片** ：沈鹿正脸 vs 温宁替拍侧背。  
**第15集《限流》** — 平台删帖；陆见小号继续。  
**第16集《真鹿》** — 沈鹿私信陆见：**「别毁她，我来。」**  
**第17集《见面》** — 沈鹿 **戴口罩** 来小区物业澄清：**「那位不是本人，是我替拍老师。」**  
**第18集《反转》** — 舆论 **二转** ：「顶流替拍被压榨」；星澜股价抖。

### 第四章：楼下（19–24 集）

**第19集《解约》**

- 陆见找到一位专攻娱乐法的律师，对方看到合同后说：「这合同有七处可诉点」
- 温宁正式向劳动仲裁委员会提交申请，主张「私人陪同」条款违反公序良俗
- 陆见作为证人出庭，证明温宁在他家期间从未以沈鹿身份活动
- 星澜法务出庭反驳：「温宁利用沈鹿的知名度获取住所和生活便利」
- 仲裁员问温宁：「你有没有主动声称自己是沈鹿？」温宁：「从来没有。」
- 钩子：庭审结束后，文姐在法院门口拦住温宁：「你以为赢了仲裁就赢了？——沈鹿的续约合同在我手里」

**第20集《陆见火》**

- 仲裁结果还没出，陆见的账号因为「替拍事件」意外涨粉五十万
- MCN公司找上门：「签我们，保底月入十万」
- 陆见拒绝：「我不是拍八卦的」
- 但甲方重新找回来了——「陆见，你的号现在自带流量」
- 他接了一个纪录片剪辑的单子，温宁帮忙做调色，两人默契配合
- 陆见第一次觉得，「两个人一起干活」比「一个人社恐」好
- 温宁发现陆见偷偷在笔记本上画了一个分镜——是她调色时的侧影
- 钩子：仲裁结果下达——**「私人陪同」条款无效，但替拍合同本身有效**。温宁可以不去饭局，但不能解约

**第21集《妈来》**

- 陆见妈突然坐高铁来上海，说「儿子，我看到热搜了——你跟沈鹿同居？」
- 陆见：「妈，不是沈鹿……」妈：「别骗我！你小时候追星我就知道！」
- 温宁躲到阳台，陆见妈进门就开始检查：「哪间房是她的？有没有女生拖鞋？」
- 陆见妈看到冰箱里两双筷子：「还说没有？！」
- 陆见被迫解释真相，妈听完沉默了三秒：「所以你收留了一个……替身？」
- 温宁从阳台出来，鞠躬：「阿姨好，我叫温宁」
- 陆见妈上下打量：「长得是挺好看的……但不是沈鹿啊？」
- 钩子：陆见妈临走前偷偷对陆见说：「这个比沈鹿靠谱。——好好对人家」

**第22集《温宁脸》**

- 温宁第一次不戴口罩下楼——去便利店买盐
- 电梯里遇到林大妈，林大妈盯着她看了五秒：「你……不是沈鹿啊？」
- 温宁：「不是。我是温宁」
- 林大妈回家后在群里发：「1203那个真不是沈鹿！就是个普通姑娘！」
- 群里反应：失望、嘲笑、还有人说「陆见白蹭了两个月热度」
- 陆见看到群消息，没回。温宁看到他看到，也没说话
- 钩子：当晚，温宁收到一条陌生消息——**「温宁，我是沈鹿。合同的事，我想帮你说清楚」**

**第23集《失落》**

- 邻居们对陆见的态度明显变了：以前主动打招呼，现在看见就绕路
- 物业小方也不再「特别关照」了，垃圾该几点收就几点收
- 林大妈在楼下遇到陆见，欲言又止：「小陆啊……那个……之前的事……」
- 陆见笑：「林大妈，没事。您拍的照片确实挺像沈鹿的」
- 林大妈松了口气，又八卦起来：「那你跟那个温宁……」陆见：「朋友」
- 温宁在楼上窗户看到这一幕，心里五味杂陈——陆见因为她失去了「特殊待遇」，却好像更自在了
- 钩子：沈鹿发来一条长消息，说她已经跟公司谈了——**「我愿意公开说你是我的替拍老师，不是替身」**

**第24集《温宁哭》**

- 沈鹿的公开声明发出，舆论再次转向：「替拍是正经职业，不该被压榨」
- 温宁看着评论区，突然哭了：「大家终于叫我的名字了。——但你知道吗，我最怕的不是他们叫我沈鹿，是他们连温宁都不想叫」
- 陆见不懂安慰人，递纸：「我认识你的时候，你就是温宁」
- 温宁：「你不怕被我连累？」陆见：「我账号涨了五十万粉，甲方回来了——你连累我什么？」
- 温宁破涕为笑，第一次在陆见面前 **摘掉口罩，正脸对着他哭**
- 陆见没有抱她，只是说：「饿了吗？我煮面」
- 钩子：仲裁二次开庭通知——星澜以「泄露商业机密」追加诉讼

---

### 第五章：陆见（25–30 集）

**第25集《新活》**

- 温宁接到第一份「以温宁身份」的工作——一个独立导演的动作短片，需要动作指导
- 她在片场示范翻滚、吊威亚，导演惊了：「你这身手，不该只做替拍」
- 陆见帮她剪了一条 **动作reel**，发到自己的账号上——播放量破两百万
- 评论区第一次有人说：「温宁比沈鹿能打」
- 温宁看着评论笑了：「这是我第一次因为自己的脸被夸」
- 陆见：「你以前被夸过吗？」温宁：「被夸过——但夸的是沈鹿的脸长在我身上」
- 钩子：星澜追加诉讼的开庭日期确定，温宁需要在两周内准备答辩

**第26集《沈鹿谢》**

- 沈鹿私下联系温宁，赠了一个 **律师团**——她自己掏钱请的
- 沈鹿：「文姐的合同，我自己也在想办法解。——先帮你打，你赢了我就有先例」
- 律师团分析案情：「泄露商业机密」站不住脚，因为温宁从未透露沈鹿的真实工作内容
- 陆见配合律师整理证据，把他和温宁相处期间的所有聊天记录、视频素材都调出来
- 律师看完后说：「你们俩的聊天记录……比很多情侣都干净」
- 两人同时尴尬
- 钩子：庭审前夜，温宁问陆见：「明天你来吗？」陆见：「我来。——反正我已经社死过了」

**第27集《恋爱》**

- 庭审结束，星澜的「泄露商业机密」诉请被驳回。温宁只承担替拍合同的剩余违约金（大幅缩减）
- 两人从法院出来，温宁站在阳光下，第一次 **不戴口罩走在街上**
- 陆见跟在她后面，突然说：「温宁」
- 温宁回头：「嗯？」
- 陆见：「全楼以为你配顶流。——你真选我？」
- 温宁愣了三秒：「全楼以为我是沈鹿。——你真选温宁？」
- 两人对视，温宁先笑了：「行。但你得先学会安慰人——每次我哭你就煮面」
- 陆见：「面不好吗？」温宁：「好。——但我更想你抱我」
- 陆见第一次伸手，握住她的手
- 钩子：两人牵手走在路上，被路人偷拍——但这次标题是**「普通情侣」**

**第28集《答》**

- 陆见妈打视频电话，陆见接了——温宁在旁边
- 妈：「你俩……在一起了？」陆见：「嗯」
- 妈：「那她不是沈鹿？」陆见：「妈，她叫温宁」
- 妈沉默了五秒：「温宁啊，你喜欢吃什么？妈寄腊肉」
- 温宁接过手机：「阿姨好。我喜欢吃辣的」
- 妈：「辣的好！我儿子不吃辣，你管管他」
- 挂了电话，温宁说：「你妈比你直接多了」
- 陆见：「她催了我三年婚。——现在终于不催了」
- 温宁：「谁说嫁你了？」陆见：「……你说得对。先处着」
- 钩子：林大妈在群里发了一条：**「1203那个陆见，跟那个不是沈鹿的姑娘，在一起了！」**

**第29集《搬》**

- 陆见和温宁决定搬出6栋——这里已经被贴上了「沈鹿旧居」的标签，永远不得安宁
- 搬家那天，林大妈来帮忙：「小陆啊，大妈之前拍你们……对不住」
- 陆见：「林大妈，没事。您那张照片让我涨了五十万粉」
- 林大妈笑了：「那你请大妈吃饭」
- 物业小方也来了，递给陆见一瓶水：「以后有空回来看看」
- 温宁在电梯里回头看了一眼1203的门牌，说：「我在这里第一次被叫温宁」
- 陆见：「也是我第一次不想一个人待着」
- 钩子：搬进新小区，陆见在住户登记表上写：**「陆见、温宁——朋友合租」**

**第30集《文姐落》**

- 星澜内部出事：文姐被多名艺人联名举报「强迫陪饭局」「克扣片酬」
- 娱乐圈自媒体深挖，发现文姐手下的替拍、助理、练习生都有类似遭遇
- 星澜董事会紧急开会，文姐被解除经纪合约
- 温宁看到新闻，没有转发，没有评论
- 陆见：「你不高兴？」温宁：「高兴。但我不想踩她。——她当年也是从小助理做起的」
- 陆见第一次觉得温宁比他成熟
- 钩子：沈鹿发来消息：**「文姐走了。我的合同也要重新谈了。——谢谢你，温宁」**

---

### 第六章：正脸（31–36 集）

**第31集《片单》**

- 陆见帮温宁剪的 **动作reel** 被一个影视公司看中，邀请她做新片的动作指导
- 温宁犹豫：「我不露脸可以吗？」陆见：「动作指导不用露脸。——但你迟早要露」
- 温宁接了工作，在片场从早忙到晚，回来时满身淤青
- 陆见帮她贴创可贴，温宁：「你不怕我变丑？」陆见：「你本来就不是沈鹿」
- 温宁笑了：「你这个人，夸人都不会」
- 钩片完成后，导演在片尾字幕打上：**「动作指导：温宁」**——她第一次在正式作品里有自己的名字

**第32集《同居真》**

- 新小区，两人从「朋友合租」变成 **正式情侣**
- 物业登记时，陆见写「同居」，温宁改成了「合租」
- 陆见：「有什么区别？」温宁：「合租可以吵架不分手」
- 两人一起布置新家，温宁挂了一张海报——是她自己设计的，上面画了两个人在阳台上剪片子
- 陆见：「这画得……不太像我」温宁：「本来就不是你。是我理想中的生活」
- 陆见看着海报，说：「现在不是理想。是现实」
- 钩子：温宁手机响了——沈鹿的经纪人（新经纪人）来电：**「温宁，沈鹿想请你做她下一部戏的动作指导」**

**第33集《偶遇》**

- 温宁在片场遇到沈鹿——两人第一次以 **「同行」** 身份见面
- 沈鹿：「你不用再替我了」温宁：「我知道。——但你的打戏还是我来比较好」
- 两人在片场合影，沈鹿发到社交媒体：**「和我的动作指导温宁老师合作。——她比我能打」**
- 照片里温宁 **正脸出镜**，和沈鹿并肩站着
- 评论区：「原来她长这样」「比沈鹿飒」「两个都是大佬」
- 狗仔也拍到了，标题是：**「两位老师合作」**——没有「恋情」「同居」「替身」
- 温宁看着热搜笑了：「这是第一次，我的名字和她的名字放在一起，是平等的」
- 钩子：陆见看到热搜，给温宁发了一条消息：**「恭喜。——今晚我煮面庆祝」**

**第34集《妈接受》**

- 陆见妈第二次来上海，这次是来「正式见儿媳妇」
- 温宁去高铁站接，没戴口罩
- 陆见妈看了她三秒：「比照片好看。——走，妈带了腊肉」
- 回到家，陆见妈开始做饭，温宁帮忙切菜
- 陆见妈偷偷对陆见说：「这个好。踏实。——不是那种要你养的」
- 陆见：「她比我赚得多」妈：「那就更好了！」
- 晚饭时，陆见妈举杯：「温宁啊，以后就是一家人了」
- 温宁眼眶红了：「谢谢阿姨」
- 陆见妈：「叫妈」
- 钩子：陆见妈走之前，在小区门口偷偷拍了一张温宁的 **正脸照**，发到家族群：**「我儿媳妇」**

**第35集《婚礼？》**

- 朋友聚会，有人问：「你俩什么时候结婚？」
- 陆看温宁，温宁：「先谈两年」
- 陆见：「行」
- 朋友：「就这？不浪漫一下？」
- 陆见想了一下，对温宁说：「两年后，如果你还想跟我煮面，我们就去领证」
- 温宁：「你这算求婚？」陆见：「算预告」
- 温宁笑了：「行。——但面你得学几个新菜」
- 回家路上，温宁突然说：「两年太久了」陆见：「那就一年」温宁：「半年」
- 两人对视，同时笑了
- 钩子：陆见在手机备忘录里写了一行字：**「半年后求婚。地点：6栋楼下」**

**第36集《倒垃圾》**

- 半年后，两人回到6栋小区——陆见约了林大妈帮忙「拍一张照片」
- 温宁被蒙着眼睛带到楼下，摘下眼罩：「这是……6栋？」
- 陆见站在当初她雨夜敲门的位置，手里拿着一袋垃圾
- 温宁：「你干嘛？」陆见：「当初你敲门的时候，我在倒垃圾」
- 温宁笑了：「所以你要求婚，还拿着垃圾？」
- 陆见把垃圾放下，从口袋里掏出一个小盒子：「温宁。全楼误会了三个月。——就我一个没误会」
- 温宁哭了：「你每次都不会安慰人」
- 陆见：「但我每次都开门了」
- 温宁摘下口罩——陆见帮她挡镜头的习惯还在，伸手想挡
- 温宁握住他的手，拉下来：**「不用挡了。」** 吻。
- 林大妈在旁边举着手机录像，泪流满面：「比沈鹿的电影好看……」
- 镜头定格：两人接吻的剪影，背景是6栋的灯光。**全剧终。**

## 创作执行建议

### 叙事节奏

- **前5集**：高能误会，建立「全楼以为她是沈鹿」的核心设定
- **每6集**：放一个主要情感转折（第6集留下、第12集决定、第18集反转、第24集告白、第30集文姐落、第36集求婚）
- **每12集**：放一个全网讨论点（第12集星澜律师函、第18集舆论反转、第24集温宁正脸、第30集文姐落马）
- **结尾钩子优先级**：误会升级 > 身份危机 > 情感突破 > 外部威胁

### 爽点排布

1. 第3集：温宁摘口罩，陆见说「正脸你就是你」——第一次心动
2. 第8集：陆见举袋挡脸成meme——喜剧高光
3. 第17集：沈鹿亲自澄清——舆论大反转
4. 第27集：两人牵手走在阳光下——甜度峰值
5. 第33集：温宁正脸和沈鹿同框——身份平等
6. 第36集：6楼下求婚——首尾呼应

### 过审重点

- 温宁 **从未主动冒名**，误会来自外部（口罩+狗仔+邻居）
- 沈鹿是 **正面角色**，主动帮助温宁，不涉及抹黑艺人
- 星澜/文姐是 **行业问题的代表**，不涉及具体公司影射
- 结局导向「靠自己能力立足」，不宣扬依附明星
- 感情线健康，无不良价值观

### 制作友好度

- **全室内为主**：公寓、物业、法院、片场——AI动画制作成本低
- **场景复用高**：1203公寓出现约60%的戏份
- **人物少**：核心角色5个，配角3个
- **无特效需求**：纯现代都市，无打斗/爆炸/奇幻元素
