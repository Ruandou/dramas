## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 道具     | `PROP-###`                        | `PROP-001`        | 口罩、合同、手机等               |

- 编号**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先 `资产/角色索引.md`，再建 **`L01` 基础形象**于 `资产/形象索引.md` + `角色卡.md`。
- 新建换装/阶段：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。

### 1.1 形象 ID 与基础 / 衍生

| 后缀     | 名称     | 要求                                                                                |
| -------- | -------- | ----------------------------------------------------------------------------------- |
| **L01**  | 基础形象 | 完整定妆 Prompt（脸、体型、发式、默认服装）；全剧面部一致性的**唯一锚点**           |
| **L02+** | 衍生形象 | **必须** `based_on` 本角色 `L01`；Prompt 只写差异，并含 `same face as CHAR-xxx-L01` |

**出图流程**：定稿 `L01` 参考图 → 衍生形象用图生图 / 角色一致性模型 → 禁止跳过 L01 直接生成 L02。

**本剧常见衍生场景**：

| 角色   | L01（基础）           | L02+（衍生示例）                          |
| ------ | --------------------- | ----------------------------------------- |
| 陆见   | 卫衣运动裤（居家）   | L02 白衬衫（见甲方/法院）、L03 干净T恤（求婚） |
| 温宁   | 口罩+帽子（隐藏身份） | L02 摘口罩居家、L03 无遮挡街拍、L04 片场工作装 |
| 沈鹿   | 口罩+墨镜（低调）    | L02 正脸出镜（片场）                      |

## 三、肖像与法务（拍摄前必读）

| 规则       | 说明                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------- |
| **顶流名** | 全剧只用虚构艺人 **「沈鹿」**（公司：星澜娱乐）， **不出现、不影射任何真实艺人全名/肖像** |
| **替拍**   | 女主 **温宁** 是合同替拍（侧脸/背影/危险动作）， **不是** 宣称「我就是沈鹿」诈骗          |
| **素材**   | 海报/AI 生成 fictional 面孔；禁止用真实明星脸融图                                         |
| **剧情**   | 小区误认来自 **口罩+身形+狗仔旧图**；温宁 **从未主动冒名**                                |

## 四、现代都市美术规范

### 允许 / 推荐

| 类别 | 推荐项 |
|------|--------|
| 建筑 | 现代住宅楼、老旧小区、写字楼、便利店 |
| 服饰 | 卫衣、运动裤、口罩、棒球帽、职业装 |
| 电子 | 智能手机、笔记本电脑、显示器、直播设备 |
| 交通 | 电动车、出租车、高铁 |

### 禁止出现（Negative Prompt 必加）

| 类别 | 禁止项 |
|------|--------|
| 真人 | 任何真实明星肖像、真实品牌logo |
| 古代 | 古装、兵器、马匹 |
| 军事 | 枪支、军装、爆炸 |

### Negative Prompt 通用后缀

```
real celebrity face, real brand logo, ancient costume, weapon, military uniform, gun, explosion, anime style, cartoon style
```
