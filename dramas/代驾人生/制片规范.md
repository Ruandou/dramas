# 《代驾人生》制片规范 · ID 与引用

> **正名**：《代驾人生》（Designated Driver）
> **版本**：v1.0 · 2026-06-13
> **集数**：72集 × 90秒（EP01 为 120秒）
> **画面比例**：9:16 竖屏
> **生成工具**：Seedance 2.0 fast + Seedream（参考图）
> **题材**：都市悬疑 / 夜间惊悚 / 人性剧
> **年代**：当代（2025年）

---

## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### 编号规则

- 编号**连续、不跳号**；弃用标 `deprecated: true`
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨 segment 出现 → 独立 CHAR-###；纯背景无台词 → CHAR-GRP

### 形象层级

| 后缀     | 名称     | 说明                                           |
| -------- | -------- | ---------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                   |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01    |

| 题材关键词 | 深夜霓虹、都市悬疑、车窗雨珠、孤独守夜人、赛博写实 |


```
photorealistic, 9:16 vertical frame, film grain, atmospheric haze
```

## 四、工作流顺序（必读 · 防不同步）

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_代驾人生_72集.md` | 集纲、每场剧情、对白要点、钩子                      |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡片、资产索引等       | 仅在前几步定稿后随需更新                            |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 六、分段规则

### Segment 规则 —— AI 生成单位

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 6–10 段         | 对应单集 90 秒（EP01 为 120 秒）                        |
| 每集镜头数       | 8–12 镜         | 对应每集 6–10 段 × 1–3 镜/段                            |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 旁白

- 本剧**无固定旁白角色**
- EP72 结尾画外音由苏晚（CHAR-002）配音：「每一个深夜醒着的人，都在替这个城市记着什么。」

### 音效方向

- Seedance `generate_audio: true` 合成基础环境音
- 核心音效层：引擎声、雨刷声、收音机杂音、城市远景噪声
- 特殊音效（后期叠加）：电话铃声、键盘敲击、紧急广播警报、车门关闭

## 九、年代/题材约束

### 必须体现元素

- 当代中国城市夜景（2025年）：霓虹灯、LED广告牌、高楼玻璃幕墙
- 代驾行业真实感：代驾App界面、折叠电动车、反光背心
- 深夜氛围：空旷街道、湿漉漉地面、路灯、24小时便利店
- 车内空间亲密感：仪表盘暖光、后视镜、窗外霓虹折射

### 禁止出现元素（叙述性 — Prompt 由设计师负责）

- 古装/历史服装（本剧为当代题材）
- 奇幻/魔法/超自然元素
- 明显的动漫/卡通风格
- 白天日光充足的场景（除 EP36 白天探访安和苑、EP59-61 清晨/白天段落等明确标注的日景集数）
- 农村/田园风光（除 EP60 废弃乡村小学外）
- 明显的西方城市地标
- 未来科幻元素（飞行汽车等）

## 十一、受众定位

- **主频道**: 男频为主（悬疑线+推理快感），女频为辅（情感线+人物深度）
- **核心年龄段**: 18-40
- **核心痛点**: ①城市孤独感与深夜工作者的被忽视 ②普通人在权力体系前的无力感 ③"好人能否改变世界"的渴望
- **爽感期待**: SAT-SUS（悬疑揭秘）35% + SAT-COME（逆袭燃爽）25% + SAT-EMO（感动泪点）25% + SAT-BURN（危机恐惧）15%
- **对标作品**: 短剧类悬疑+都市人性剧

### 题材制作复杂度

| 维度 | 评估 |
|------|------|
| 场景复杂度 | ★★★☆（都市夜景+车内+少量室内，可控） |
| 角色数量 | 8主角+5配角，符合主要角色≤8约束 |
| AI生成难度 | 中（夜景光线复杂但无特效场景） |
| 预估周期 | 标准 |

## 十二、分集剧本格式规范

> 分集剧本（`剧本/EP##/EP##_*.md`）是单集的**真相源**。
