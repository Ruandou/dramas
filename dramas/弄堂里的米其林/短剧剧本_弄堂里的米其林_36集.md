# 短剧剧本·弄堂里的米其林（36集）

> 来源：上海精品概念包（2026 政策扶持向）
> 更新日期：2026年5月28日

## 项目信息

- **类型**：美食 / 家庭 / 爱情 / 创业成长
- **集数**：36 集 × 2–3 分钟
- **叙事节奏**：一菜一故事 → 比赛/危机 → 情感爆点 → 集末钩子
- **平台定位**：女频核心（美食+家庭情感+创业逆袭三合一），男频可吃美食竞技
- **政策契合**：文+商+旅（上海味道×弄堂文旅×餐饮创业），瞄准上海"沪8条"最高450万扶持
- **AI 友好度**：★★★★★

## 一句话简介

法国蓝带毕业的沈悦回到上海弄堂，只为救活外婆濒临倒闭的"阿婆灶头"——**一碗腌笃鲜要熬三个小时，但这条弄堂可能撑不过三个月。** 她的分子料理征服了评委，却说服不了外婆：**"正宗上海味道，不需要你那些泡泡。"**

## 为什么现在能火

- **美食短剧**2025–2026年完播率数据优异（视觉刺激+情感共鸣双驱动），但库内仅有古装《食神》，缺**现代上海本帮菜**赛道。
- 弄堂/里弄是上海**年度最热文旅IP**（2025"弄堂经济"政策出台），剧集天然绑定城市热度。
- 每集一道菜 = 天然切片素材（"外婆的秘制红烧肉vs米其林摆盘"对比图，投流转化率高）。
- 比赛+创业双线 = **钩子密度极高**（每集有输赢）。

## 与库内差异

- 非《食神》古装穿越；本剧全程**当代上海**，零架空元素。
- 非《教练别加练了》运动职场喜剧；本剧有**家族情感深度**与代际冲突。
- 非《我租的女友真把我当老公了》纯爱轻喜；本剧爱情线服务于「传承 vs 创新」核心矛盾。

## 政策契合分析

| 维度         | 契合点                                                                         |
| ------------ | ------------------------------------------------------------------------------ |
| **文**       | 上海本帮菜非遗文化、弄堂里弄生活方式、口述家族史（每道菜背后是一户邻居的人生） |
| **商**       | 餐饮创业、美食竞赛商业化、品牌联名（可与上海本帮餐厅/老字号做播后联动）        |

**50%加成理由**：精准命中"文商旅联动"三维——弄堂文化(文)+餐饮创业(商)+美食旅游(旅)，且输出"上海味道=城市灵魂"的正面叙事，播后可直接转化为美食文旅消费。

## 金手指/核心设定

**「一菜一邻」结构**：阿婆灶头的每道招牌菜，都是为弄堂里某一户邻居"定制"的——腌笃鲜是给楼上孤寡张爷爷的（他老伴的口味），葱油拌面是给对面裁缝阿姨的（她赶工没时间等）。沈悦要参加比赛，就必须先听懂每道菜背后那个人的故事。**菜谱即人谱。**
