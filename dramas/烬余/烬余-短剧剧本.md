# 《烬余》短剧剧本（全 6 集）

> 题材：古风 / 穿越 / 悬疑 / 感情戏
> 核心概念：降维打击（现代「遗物鉴定与痕迹思维」碾压古人「口供与心证」）
> 女主设定：**魂穿**；外显**清冷疏离**（相府千金应有的教养），内核**执念深重**（誓要找到灭门真凶）
> 体量参考：每集约 2–4 分钟（竖屏可再拆条），全季连看约 15–22 分钟

---

## 分集总览

| 集数 | 标题 | 一句话 | 集末钩子 |
|------|------|--------|----------|
| 1 | 乱葬岗 | 醒来的第一件事，是数尸体 | 她的手——在扒她的陪嫁 |
| 2 | 遗物语 | 一枚戒指的磨损痕，指向真凶的行业 | 锦衣卫：她比仵作还邪门 |
| 3 | 替身 | 活人装的死人，和死人装的活人 | 她认出"哥哥"的笔迹是假的 |
| 4 | 灰烬 | 烧过的纸，藏着没烧完的秘密 | 嫡母的账本，在佛龛夹层里 |
| 5 | 拼图 | 三块拼图拼出的，是一个局 | 他说：你查的是仇，我查的是案 |
| 6 | 烬余 | 所有人都以为她要翻案——她要的是另一件事 | 那一夜火光里，她真正在找的东西 |

## 人物小传

| 人物 | 简介 |
|------|------|
| **林知微** | **现代魂穿**：前世为**文物鉴定师 / 刑案物证鉴定**相关职业（不必点破具体单位）。穿成同名相府千金，继承原身"相府嫡女"身份与及笄宴请帖。以「物品材质、工艺痕迹、使用痕迹、时间线矛盾」对古人形成碾压。容貌清冷，遇危险时眼神反而更定；执念是找到灭门真相，不惜代价。 |
| **沈鹤洲** | 锦衣卫经历，冷面，心细如发。一开始以为她涉案，后发现她是被利用的棋子；在真相与她之间艰难平衡。 |
| **三皇子** | 表面贤王，暗中布局"相府灭门"以嫁祸太子；对她有兴趣，但更在意她手中的证据。 |
| **嫡母 | 相府继室，伪善，灭门主谋之一；表面哭丧，暗地监视。 |
| **丫鬟雀儿** | 原身贴身丫鬟，灭门夜唯一活口，被收买又良心未泯。 |

### 林知微（表演与服化提示）

- **清冷**：身形纤细但脊背笔直；可选素白或浅青素服，发髻整齐，步履慢而稳；眼神清冽如冬日井水，笑时也像在盘算什么。
- **执念**：面对灭门真相时眼神会变，语速反而更慢更稳，像在克制什么；可在验物时流露专注与敏锐——这是她"活着的方式"。
- **穿越梗**：偶尔脱口半句现代专业术语（"氧化痕迹""包浆异常"），立刻改文言，旁人听来只觉"此女邪门"。
- **反差**：验物时如入定，对人时却冷淡；只在无人时，捏着原身遗物会无声落泪。

**沈鹤洲**：「你到底是谁？」

**林知微**：「我是唯一能听懂死人说话的人。」

# 第一集《乱葬岗》

**本集功能**：穿越落地、第一次"验尸"打脸、立下悬念。
**建议时长**：2–3 分钟。

### 场1 夜·乱葬岗

*雨夜。土坡。残肢、碎瓷、血污。*

*林知微猛然睁眼——嘴里是泥，身下是半截压在身下的尸体。*

*她没有尖叫。只是慢慢坐起，第一件事是开始**数尸体**——目光扫过，默数。*

*七具。不对，少了一只手。*

**旁白/内心**（极轻）  
「右利手，惯用右手……刀口从左侧进来，但习惯右手拿刀的人，刀刃偏右。」

*她忽然低头——手腕上的陪嫁玉镯，不见了。*

*身后有声音。锦衣卫提着灯笼，火光映出刀锋。*

**沈鹤洲**（冷声）  
站着。你是活人，还是僵尸？

**林知微**（缓缓转身，不慌不站起，拍裙上泥土，声音反而平静）  
活人。而且——

*她指向身侧三步外一具尸体。*

**林知微**  
这个人死了不超过两个时辰。体温还在，环境蝇还没来。两位若想破案，不如先问我看见了什么。

**锦衣卫甲**（刀尖一横）  
哪来的女人，懂验尸？

**林知微**（看他刀，不躲）  
我不懂验尸。我只懂——**看**。

*她指向尸体脖颈处的勒痕。*

**林知微**  
勒痕比刀口早。不是自杀，是他杀后挂上去的。凶器是细绳，不是刀。

**沈鹤洲**（抬手，示意收刀，盯着她）  
继续。

**林知微**（蹲下，手指悬在尸体上方，不触碰）  
这人的指甲里有皮屑——别人的。右手无名指断了一半，是抓扯时断的——凶手的脸或手，被他抓伤过。

*她忽然抬头，看向嫡母派来"收尸"的家丁。*

**林知微**  
你们府上，可有人脸上有新鲜的抓伤？

家丁脸色一变。

**沈鹤洲**（目光一沉）  
全部带走。活的、死的，一样不留。

**林知微**（低声，只说给沈鹤洲听）  
我那只手镯，是被人活生生从手腕上撸下来的。凶手太急——或者太想要它。

*她低头，看自己手腕红痕，睫毛一垂。*

**林知微**（极轻）  
……我连凶手的脸都还没见过。

**【卡黑】**

# 第二集《遗物语》

**本集功能**：收第一集伏笔，用"戒指磨损痕"破冰；立"锦衣卫起疑"悬念。
**建议时长**：3–4 分钟。

### 场2 日·锦衣卫诏狱

*林知微被带来问话。她跪得笔直，手腕红痕未消，神色却比昨夜更冷。*

**沈鹤洲**  
相府千金林知微，及笄宴当夜，你的及笄簪呢？

**林知微**  
不知道。

**沈鹤洲**  
你倒是不慌。

**林知微**（抬眼）  
慌有什么用？慌能让我想起那晚的事吗？

*她忽然一顿——目光落在沈鹤洲腰间的剑穗上。*

**林知微**（目光停了一瞬，又收回）  
沈大人，你的剑穗……被火燎过。

**沈鹤洲**（手一顿）  
你怎么知道？

**林知微**  
火燎过的丝线会缩。正常的剑穗垂坠自然，这个——短了三寸，还打了新结。昨晚你也在相府火场里。

**沈鹤洲**（沉默片刻）  
你倒看得仔细。

**林知微**  
职业病。

*她说完，像是意识到失言，垂眸。*

### 场3 日·相府偏院（验物）

*沈鹤洲带她回相府"找线索"。嫡母哭丧，眼眶却干。*

*林知微在废墟中翻找，忽然蹲下——*

*她捡起一枚烧焦的戒指，捧在手心，用袖口轻轻拂开灰——*

**林知微**（自言自语，声音极轻）  
金的。烧过之后氧化发黑……但这枚戒指的磨损痕不对。

**沈鹤洲**（走近）  
怎么不对？

**林知微**（指给 他看戒面内侧）  
内壁磨痕说明它在这个位置戴了至少十年——但这个人的手，比十年前胖了一圈。戒指是强行套上去的，不是自己的。

*她翻过戒面。*

**林知微**  
且看这里——有字。"顾"。

**沈鹤洲**（神色一变）  
顾？

**林知微**  
这是顾家铺子的款。顾家做金银铺三代，款识用的是私印，不是通用字。这个"顾"字——

*她指尖点着笔划。*

**林知微**  
收笔太急。说明刻字的人，不是顾家老师傅，是后来仿的。

**沈鹤洲**  
有人在嫁祸顾家？

**林知微微**（摇头）  
不。是有人不知道顾家的款识细节，随手刻了上去——

*她抬头，看向偏院外站着的家丁，目光一寒。*

**林知微**  
沈大人，你该查的不是顾家。你该查——**谁在灭门之后，第一个跑去顾家铺子买过一枚金戒指**。

**【卡黑】**

# 第三集《替身》

**本集功能**：反转——"哥哥"是假的；感情线暗线浮现。
**建议时长**：3–4 分钟。

### 场4 夜·林府灵堂

*设灵。棺木。嫡母哭灵，泪流满面。林知微跪在灵前，不哭，只盯着棺材。*

*忽然——*

*她注意到棺材的钉法。*

**林知微**（低声，只说给身边的雀儿听）  
雀儿，钉棺材的钉子，是谁买的？

**雀儿**（慌张）  
回、回大小姐，是管家买的……

**林知微**  
管家？

*林知微微妙地看她一眼，起身，走向棺木——*

*她手指沿着棺材边沿划过，忽然停住。*

**林知微**（自言自语，声音平静得可怕）  
棺材是楠木的。钉子却是铁钉——铁钉会生锈，锈会渗进木头里。但如果用铜钉，就不会有这个问题。

*她回头，看向嫡母。*

**林知微**  
嫡母，我们林府的棺材，历来用铜钉，对吗？

*嫡母脸色一僵。*

**嫡母**  
大小姐……你这是什么意思？

**林知微**（走近一步，声音平静）  
我的意思是——**这口棺材，不是林府的棺材。**

*全场一静。*

**林知微**  
林府用的铜钉，钉法是"七上八下"。这口棺材的钉法，是"三长两短"——这是外行人的钉法。

*她忽然伸手，要推棺盖——*

**嫡母**（尖声）  
拦住她！

*沈鹤洲却在此时出声。*

**沈鹤洲**  
慢。让她开。

*棺盖被推开——*

*里面躺着一个男人，面目模糊，但身上穿的，是林府公子的常服。*

*林知微盯着尸体的手——忽然伸手，掰开尸体的右手。*

**林知微**（声音微变）  
这不是我哥。

**沈鹤洲**  
你怎么知道？

**林知微**  
我哥惯用左手写字。这只手的虎口有茧——是右手执笔的茧。

*她翻过尸体的袖口。*

**林知微**  
而且这件衣服的袖口——有墨渍。我哥的墨渍在左边袖口，因为他是左撇子。这件衣服的墨渍在右边。

*她抬头，眼眶里有泪光，但声音更稳。*

**林知微**  
你们杀了我哥，然后找了一具尸体来冒充他。

**嫡母**（厉声）  
你疯了！

**林知微**（缓缓站起，裙摆带灰，声音却像刀）  
疯不疯，查一查这具尸体是谁家的——不就知道了？

*她看向沈鹤洲。*

**林知微**  
沈大人，您锦衣卫诏狱里，应该有失踪人口的案底吧？

**【卡黑 · 字幕：死人会说话。但活人——有时候比死人还会撒谎】**

# 第四集《灰烬》

**本集功能**：全剧最大"降维打击"——从烧焦的纸还原账本；嫡母线曝光。
**建议时长**：3–4 分钟。

### 场5 日·佛龛夹层

*沈鹤洲查到失踪人口——三月前，有一户人家来京城投亲，随后失踪。*

*林知微在府中继续翻找。她注意到灵堂后的佛龛——*

*她敲了敲，有空洞声。*

*她回头，示意沈鹤洲和雀儿。*

**林知微**（低声）  
帮我搬开它。

*佛龛移开，露出夹层——里面有一个油纸包。*

*打开。是账本。烧了一半，但另一半还能看。*

**林知微**（展开，用手指尖轻触纸面）  
纸的纤维……这是宣纸，徽州产的。寻常百姓用不起。

*她翻到还能看清的部分，开始读——*

**林知微**  
"三月十二，收顾家铺子抵押物，金簪一对。"……"三月十五，收赵庄田契，共三百亩。"……

*她手指忽然停住。*

**林知微**  
"四月初九，收账——**三千两**，备注：替三皇子办事。"

*沈鹤洲脸色一变。*

**沈鹤洲**  
三皇子……

**林知微**（抬眼）  
你知道三皇子？

**沈鹤洲**（沉默片刻）  
我知道三皇子最近在查相府。相府灭门案，是他递上来的折子——说是太子所为。

**林知微**（冷笑）  
贼喊捉贼。

*她指着账本上的一行字。*

**林知微**  
看看这笔账——三月到四月，相府继室收了三千两银子。备注写的是"替三皇子办事"。

*她翻到下一页。*

**林知微**  
再看这一笔——"付顾家铺子违约金，赔款五百两"。顾家铺子的抵押物，是被强行买走的，不是正常抵押。

*她合上账本，看沈鹤洲。*

**林知微**  
三皇子要的不是林府的真相。他要的是——**用林府的血，染太子的名声**。继室是他的棋子，灭门是他的棋局。

**沈鹤洲**（盯着她）  
你怎么知道这么多？

**林知微微**（垂眸，声音淡）  
我不知道。我只知道——**纸上写了什么，就发生过什么**。字迹可以假，账目可以做，但痕迹不会。

*她低头，看自己手腕的红痕。*

**林知微**（极轻）  
我那晚失去的东西……我会一点一点找回来。

**【卡黑】**

# 第五集《拼图》

**本集功能**：三方对峙（林知微、三皇子、沈鹤洲）；真相碎片拼合。
**建议时长**：3–4 分钟。

### 场6 日·茶楼

*三皇子约见林知微。茶楼雅间，暗藏杀机。*

**三皇子**（笑）  
林大小姐，听说你在锦衣卫那儿说了不少话。

**林知微**（端茶，不卑）  
民女只是在说实话。

**三皇子**  
实话？相府灭门，太子负罪，这是皇上定的案。你一个相府遗孤，还能翻了天不成？

**林知微**（抬眼，笑意清冷）  
三皇子，民女不想翻案。

**三皇子**（微顿）  
那你想要什么？

**林知微**  
想要一个人。

*她放下茶杯。*

**林知微**  
杀我全家的人。

**三皇子**（笑意更深）  
你要报仇？

**林知微**  
不。我要他活着，**亲口说出真相**。死在诏狱里太便宜他了——我要他跪在林府灵前，当着所有人的面，把那天晚上做的事，一句一句说出来。

*三皇子看着她，目光玩味。*

**三皇子**  
有意思。那你打算……让我怎么帮你？

**林知微**（忽然起身，走到他面前，俯身，声音极低）  
三皇子，你递上去的折子，说太子是凶手——你想让太子死。可如果我说，**太子不是真凶，真凶另有其人**……你猜，皇上会怎么想？

*三皇子笑意僵了一瞬。*

**林知微**  
一个办错案的皇子，和一个被冤枉的太子——你觉得，哪个更让皇上起疑？

**三皇子**（慢慢站起）  
你在威胁我？

**林知微**（退后一步，重新跪下）  
民女不敢。民女只是在做生意——三皇子要的是江山，我要的是真相。我们各取所需，何必杀我灭口？

*门外脚步声。沈鹤洲入。*

**沈鹤洲**（冷声）  
三皇子，锦衣卫奉旨查案，请皇子行个方便。

**三皇子**（笑）  
沈经历，你倒是护得紧。

**沈鹤洲**（面无表情）  
臣护的是证据，不是人。

*林知微看他一眼，目光里有一丝温度，又压下去。*

**林知微**（低声，只说给他听）  
你不该来的。

**沈鹤洲**（也低声）  
我查的是案。你查的是仇。我——

*他顿了顿。*

**沈鹤洲**  
我来补你拼图里缺的那一块。

**【卡黑 · 字幕：三方博弈，各怀心思——只有死人才会说实话】**

# 第六集《烬余》

**本集功能**：真相大白；林知微真正目的曝光；感情线升华与结局。
**建议时长**：4–5 分钟。

### 场7 日·锦衣卫诏狱

*真相大白——嫡母与三皇子幕僚被拿下。林知微站在牢门外，看着嫡母。*

**嫡母**（笑）  
你赢了。

**林知微**（摇头）  
你没有明白。我要的，从来不是赢。

**嫡母**  
你要什么？

**林知微**（蹲下，与她平视）  
我要知道——**那天晚上，是谁第一个动的手**。

*嫡母脸色一变。*

**林知微**  
账本是你记的，人是你买的，但灭门这种事……你一个内宅妇人，下不了那个狠手。

*她站起来，声音平静。*

**林知微**  
是你——**三皇子殿下**，对不对？

*三皇子被押在旁边，脸色铁青。*

**三皇子**  
你胡说！

**林知微**（从袖中取出那枚烧焦的金戒指）  
这枚戒指是从我哥手指上取下来的。账本上写的是"收顾家铺子抵押物"，可我哥的金戒指——从来不去顾家铺子打。

*她翻过戒面。*

**林知微**  
因为林府有专门的御用铺子，用的是宫中匠人。这个"顾"字刻得歪——不是顾家铺子的货，是有人**临时拿来顶包的**。

*她走近三皇子。*

**林知微**  
三皇子你安排好了一切，却漏算了一件事——

**三皇子**  
什么？

**林知微**  
**烧焦的东西，氧化程度不一样**。

*她举起戒指。*

**林知微**  
这枚戒指烧的时间，比其他东西短。说明它是在火已经烧起来之后，才被丢进火里的——是凶手慌忙之中，**从死者身上撸下来灭迹**的。

*她把戒指丢在三皇子面前。*

**林知微**  
凶手杀了我哥，抢了这枚戒指，想灭迹——可他太急了。戒指上的火痕不对，被我一眼看穿。

*三皇子瘫坐。*

**嫡母**  
你……你到底是什么人？

**林知微**（转身，背对牢房，声音极轻）  
我是一个——**听见死人说话的人**。

### 场8 夜·林府废墟

*沈鹤洲来找她。她站在废墟前，背影瘦削。*

**沈鹤洲**  
案子结了。皇上已经下旨，三皇子圈禁，太子复位。

**林知微**（没有回头）  
我知道。

**沈鹤洲**  
你……接下来打算怎么办？

*沉默。*

**林知微**（轻声）  
沈鹤洲，你知道"烬余"是什么意思吗？

**沈鹤洲**  
……烧剩的东西。

**林知微**（转身，月光下，眼眶里有泪光）  
烬余，是烧剩的东西。也是——**烧不尽的东西**。

*她走近他。*

**林知微**  
我查这个案子，不只是为了报仇。是因为——**那个晚上，我本来要嫁给太子的**。

*沈鹤洲一怔。*

**林知微**  
及笄宴，是定亲宴。灭门之后，太子背锅，我成了罪臣之女。可真正该死的人——

*她看向三皇子的方向。*

**林知微**  
还活着。

**沈鹤洲**（沉默片刻）  
你从一开始就知道。

**林知微**  
我算到了。我以为我能改变一切——可我还是漏算了一件事。

**沈鹤洲**  
什么？

**林知微微**（抬眼，看着他，眼泪终于落下来）  
……我没想到会遇见你。

*风吹过，废墟上的灰烬扬起。*

**沈鹤洲**（伸手，替她拂去脸上的泪，动作生硬）  
那你打算怎么办？

**林知微**（声音发涩，却笑了一下）  
我是相府遗孤，没钱没势。你是锦衣卫经历，前途无量。按理说——

**沈鹤洲**（打断她）  
我问的不是按理。

**林知微**（愣住）

**沈鹤洲**（低声）  
我问的是——**你想怎么办**。

*沉默。*

**林知微**（很久，声音极轻）  
我想……继续听死人说话。

*她抬起头，眼泪还挂在脸上，却笑了。*

**林知微**  
这世上有太多冤案，有太多说不出口的真相。我有这门手艺——我不想浪费。

**沈鹤洲**（微微点头）  
那我就陪你查。

**林知微**  
你不怕？

**沈鹤洲**  
怕什么？怕你比我还邪门？

*他难得笑了一下。*

**沈鹤洲**  
你说过——**烬余，是烧不尽的东西**。

*他看着她的眼睛。*

**沈鹤洲**  
那就一起烧。

**【黑场字幕】**

遗物不会说谎，只是需要一个听懂它的人。

**【片尾可选用】**

她说：死人不会说话，是骗活人的。

真相一直在那里，只是需要有人把它挖出来。

——而她，愿意做那个挖骨的人。
