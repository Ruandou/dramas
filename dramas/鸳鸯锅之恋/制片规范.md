## 二、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 按需创建，每个视觉不同角色独立 ID |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

- 编号**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先 `资产/角色索引.md`，再建 **`L01` 基础形象**。
- 新建换装：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。

### 2.1 形象 ID 与基础 / 衍生

| 后缀     | 名称     | 要求                                                    |
| -------- | -------- | ------------------------------------------------------- |
| **L01**  | 基础形象 | 完整定妆 Prompt；全剧面部一致性的唯一锚点               |
| **L02+** | 衍生形象 | 必须 based_on 本角色 L01；Prompt 只写差异              |

## 四、美术规范

### 4.1 视觉风格锚点 (Visual Style Anchor)

| 维度 | 规范 |
|------|------|
| 渲染风格 | 现代都市写实（photorealistic） |
| 镜头参考 | 电影级质感，美食特写微距镜头，情感戏85mm浅景深 |
| 色调方向 | 暖红（火锅/辣）+ 冷白（东北雪景）+ 暖黄（成都街景） |
| 画幅 | 9:16 竖屏 |
| 题材关键词 | 烟火气、南北对比、美食诱惑、暖色调、生活质感 |

### 4.2 必须体现

- 成都老街区的烟火气（红灯笼、木质桌椅、蒸汽腾腾）
- 火锅特写镜头（红油沸腾、毛肚七上八下、食材摆盘）
- 东北雪景的视觉冲击（冰雕、雪花、大花袄、铁锅炖）
- 程序员工作场景（键盘、显示器、代码）
- 现代都市约会场景（太古里、九眼桥夜景）
- 南北服饰对比（成都休闲 vs 东北保暖）

### 4.3 禁止出现（Negative Prompt 年代禁忌）

- 古代服饰（汉服、古装、旗袍）
- 过时科技产品（翻盖手机、CRT显示器）
- 超现实/奇幻元素（魔法、光效、飞天）
- 不符合2024-2025年时代的建筑/设备
- 真实品牌Logo（可有模糊化的现代品牌感，但不可出现具体商标）

### 4.4 画面质量禁忌（通用）

- 模糊、失真、低质量
- 水印、字幕烧入画面
- 动漫风格、卡通风格、水彩、油画风格
- 真人明星脸

```yaml
  model_suffix: "-260128"

  resolution: 720p
  image_resolution: "1600x2848"

  cfg_scale: 7.0
  steps: 30

  negative_prompt: "blurry, distorted, low quality, watermark, subtitles burned into frame, anime style, cartoon style, watercolor, oil painting style, fantasy elements, magic, ancient clothing, hanfu, ancient costume, flip phone, CRT monitor, flying, supernatural glow, real brand logo, celebrity face, oversaturated, HDR artifacts"
```

### 5.2 Seedance 段落 Prompt 结构

```
【图1】CHAR-###-L##·角色名（服装描述）【图2】CHAR-###-L##·角色名【图3】SCENE-###
角色分工：仅图1可[动作]；图2禁止[动作]。
道具：[具体描述，含尺度参考]。
竖屏9比16连贯叙事。
镜头1（Xs）[景别][运镜]：[纯视觉动作描述]
镜头2（Xs）[景别][运镜]：[纯视觉动作描述]
[以下对白仅供语音合成，严禁在画面中显示任何文字]
对白（角色，年龄，情绪）：「台词」
画面全程无任何文字、字幕、标题、水印。
现代都市写实风格，暖色调，电影级质感，生活化场景。竖屏9比16。
```

### 5.3 Seedream 参考图生成参数

| 参数 | 值 |
|------|-----|
| 模型 | Seedream 3.0 |
| 图片分辨率 | 1600×2848（9:16 竖屏） |
| prompt_suffix | "Modern urban photorealistic style, warm tones, cinematic quality, 9:16 vertical format. No text, no watermarks, no subtitles in image." |

### 5.4 参考图配额优先级

| 优先级 | 资产类型 | 说明 |
|--------|---------|------|
| P0 | 主角形象（CHAR-001-L##, CHAR-002-L##） | 必须保证 |
| P1 | 对话角色形象（互动角色） | 有互动的角色必须锁定 |
| P2 | 场景参考图（SCENE-###） | 保证环境一致性 |
| P3 | 关键道具（PROP-###） | 有余量时加入 |
| P4 | 次要角色/群演 | 最后考虑 |

- **每 segment 最多 6 张参考图**（TOS 模式）

## 六、分段与镜头规范

### 6.1 episode_profile

| 集范围 | 单集时长 | 每集段落数 | 每集镜头数 |
|--------|----------|-----------|-----------|
| EP01 | 120s | 8–12 段 | 10–15 镜 |
| EP02–72 | 75–90s | 6–10 段 | 8–12 镜 |

### 6.2 分段（Segment）规则

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |

### 6.3 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、夹菜等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 6.4 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 七、工作流顺序（必读 · 防不同步）

| 顺序 | 层 | 文件 | 写什么 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 九、声音规范

### 9.1 voice_prompt 格式

每个有对白角色使用统一的五要素格式：
```
「[性别]，[年龄]岁，[音色特征]，[语速特征]，[情绪基调/说话习惯]」
```

同一角色跨 segment 的 `voice_prompt` 必须**全文一致**。voice_prompt 的权威来源为 `资产/声音卡片.md`。

### 9.2 旁白风格

- 本剧使用独立旁白，voice_prompt 为：「成年女性，温暖知性，语速中等偏慢，声线柔和带笑意，像在给好朋友讲故事」
- EP72 结尾画外音由旁白处理

### 9.3 音效/配乐方向

| 场景类型 | 音效方向 | 配乐方向 |
|----------|----------|----------|
| 火锅店（苏记老火锅） | 红油沸腾声、碗碟碰撞、人声嘈杂、油烟机嗡鸣 | 暖色吉他/尤克里里，轻快节奏 |
| 成都街头（太古里/宽窄巷子） | 车流声、人潮、街头艺人、麻将声 | 川味民乐/竹笛 |
| 九眼桥夜景 | 河水声、酒吧远处音乐、桥上风声 | 轻柔钢琴/弦乐 |
| 哈尔滨（中央大街/冰雪大世界） | 雪地踩踏声、北风呼啸、冰裂声 | 温暖大提琴/手风琴 |
| 程序员场景（出租屋/办公室） | 键盘敲击、鼠标点击、电脑风扇 | 电子 ambient/lo-fi |
| 情感高潮 | 心跳声、呼吸声 | 弦乐渐强/钢琴独奏 |

| 列名 | 格式 | 说明 |

## 十一、内容合规参数

### 11.1 题材合规等级

🟢 **C级** — 一般题材，现代都市爱情，直接通过

### 11.2 本剧特定红线

1. **禁止过度饮酒场景**：苏爸/陆爸喝酒庆祝仅限"举杯"镜头，不可出现烂醉
2. **禁止暴力冲突**：周子轩的商业打压仅限对话/威胁，不可出现肢体暴力
3. **催婚压力适度**：陆妈催婚点到为止，不可造成过度焦虑/压迫感
4. **食品安全**：火锅食材必须新鲜卫生，不可出现不洁烹饪画面
5. **地域刻板印象控制**：南北差异用作喜剧素材，但不可丑化任何一方

### 11.3 灰区处理策略

| 灰区 | 预定处理方式 |
|------|-------------|
| 辣度挑战/吃辣场面 | 作为喜剧元素处理，不鼓励过度挑战 |
| 异地恋争吵 | 展现真实但保持"虐不过3集"节奏，确保正向收束 |
| 商业竞争/打压 | 周子轩行为在道德层面批判，最终道歉和解 |
| 婆媳文化冲突 | 作为喜剧素材，最终以理解和融合收场 |

### 11.4 正向价值锚点

1. **文化融合与尊重**：南北差异不是对错，而是丰富
2. **双向奔赴的爱情**：为对方改变，但不丢失自我
3. **传承与创新**：传统火锅秘方+现代科技=更好的未来

### 11.5 平台审核重点提示（前3集）

- **EP01**：辣度之争不可升级为人身攻击，保持轻松喜剧基调
- **EP02**：刷盘子场景不可涉及强迫劳动暗示，陆北辰自愿
- **EP03**：苏爸"考察"不可涉及过度刁难，保持温暖底色
