## 一、ID 命名规则

所有资产统一编码，**编号只增不删**；弃用标 `deprecated: true`。

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同群演角色独立 ID + L01    |
| 场景     | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### 本项目 ID 分配现状（v1.0）

- **CHAR-001 ~ CHAR-008**：主要角色 8 人（**已达上限，任何阶段禁止增设主要角色**——R1 随案卷转交事项② + 结构性观察 S3 硬约束；系统「仓禾」为画外音，不占 CHAR 位）

## 二、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于大纲 YAML 元数据「视觉风格 / 色彩基调」。创意细化由 character-designer / prop-designer / scene-designer 负责，本节为结构性基线，不得违背。

| 维度 | 规格 |
|------|------|
| 渲染风格 | photorealistic 古装质感·田园写实（荒年段粗粝土感 → 丰收段暖金丰饶） |
| 镜头参考 | cinematic 35–85mm；农事/干饭/文书特写用 macro（开镰、捻麦、按手印、账页） |
| 色调方向 | **色阶随粮仓成长三段渐变**（情绪可视化，本剧核心视觉设计，见下方色调模块表） |

| 题材关键词 | famine-era farmland（荒年田野）、Ming-adjacent folk costume（近明制民俗服化）、市井烟火、golden wheat（金穗奇观）、weathered loess textures（黄土风蚀质感） |

## 六、分段规则（Segment）

| 约束             | 值              | 说明                                    |
| ---------------- | --------------- | --------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                 |
| 每 segment 镜头数 | ≤3 镜；段 ≥8s 必 ≥2 镜（典型 2-3） | v2.2 切镜节奏；静音视觉锤段可单镜但 ≤8s |
| 最小叙事单位     | 1 个完整 beat   | 每段必须构成完整叙事节拍                |
| 每集段落数       | 6–10 段         | EP01 可至 12 段                         |
| 每集镜头数       | 16–30 镜        | EP01 20–36 镜；单镜理想 3-6s，>10s 禁   |

**拆分原则**：
1. 不得在一句台词中间切断 segment
2. 不得在连续动作链（分粥、焚文书、开仓门、递麦饼等）中间切断
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆 `SEGxxa` / `SEGxxb`
5. 分镜某镜自然时长 < 4 秒 → 并入同场景相邻段

**关键区分**：SCENE-### = 空间单位；SEGxx = AI 生成单位。同一场景可含多个 segment；segment 不得跨场景。

**分集剧本格式**：11 列镜头表（镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注）；SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs`；对白格式 `**CHAR-###**[情绪]：「台词」`，无对白写 `（无对白，[音效]）`。

## 八、音色规范

- voice_prompt 权威来源优先级：**P0 `资产/声音卡片.md`** > P1 角色卡片 > P2 本规范。存在 P0 一律用 P0。
- 同一角色跨 segment 的 voice_prompt **全文一致**（segment-builder 从声音卡片全文复制，「」为可读性标记，YAML 只取括号内纯文本）。
- 角色情绪波动（如沈知禾「越怒越静」、豆婆婆 EP58 之问）由 segment 级情绪标注控制，**不改 voice_prompt**。
- **王货郎（CHAR-008）双面声线**是全剧声优记忆点：揭露前（EP07–57）/揭露后（EP58+）在声音卡片登记**两条 voice_prompt**（唯一双条目角色），以 EP58 撕面具为切换点，各自跨段全文一致。
- 系统「仓禾」为画外音，不占 CHAR-ID，voice_prompt 在声音卡片独立定义（官腔播报+突发口语吐槽的反差萌）。
- 旁白：本剧无独立旁白，叙事画外音职能由系统「仓禾」承担。
- 群演一次性台词优先复用声音卡片群演条目；无对白群演（GRP-12）不建声卡条目。
- character-designer 如需修改 voice_prompt，走角色卡片 `voice_feedback` 子节 → drama-director 集间循环审阅 → 采纳后更新声音卡片 P0。

## 九、年代/题材约束（叙述性）

**架空古代荒年**（近明制民俗服化；无真实朝代/帝王/年号/政事指涉）。

必须体现：
- 荒年质感链：龟裂土地、空锅粥棚、补丁粗布、独轮车粮袋、火把灯笼油灯（P1 段）
- 农事工艺链：开荒轮镐→打井→开镰抢收→晒场石碾→粮囤入仓（视觉奇观主线，随色阶渐变）
- 制度符号：族册/字据/官批文书（骑缝红印）/县衙公堂/联防锣哨/工分牌（道具级还原，「立字为据」母题）
- 系统 UI：简约金色光效+粮仓空间（SCENE-005），非科技感界面，禁现代 HUD 风格
- 双色系光线纪律（P3 段）：村内人情=暖黄灶火光；对峙/公堂/反派戏=青灰冷光

禁止出现：
- 一切现代物品（见§二结构性 negative_prompt）
- 可识别的真实朝代服制/年号/地名/帝王政事指涉（架空自洽）
- 火药武器、大规模战争场面（全剧以证据/律条/联防决胜，武戏全部「拍结果不拍过程」）
- 「显灵/托梦」类迷信话术与画面（EP67/83 仓灵显化统一「系统交付/仓灵显化」话术，世界观=金手指设定非亡魂显灵；EP42-43 闹鬼按「将被拆穿的骗局」拍，无具象鬼影）

### 12.1 题材合规等级

### 12.2 本剧合规红线（R1 随案卷转交事项③ · 4+1 条硬约束，逐集执行）

| # | 红线 | 硬约束内容 | 适用范围 |
|---|------|-----------|----------|
| R1 | **人牙子线禁交易具象化** | 马三刀人口拐卖线全程**不得出现交易过程、价钱对话、儿童被捆缚/关押的具象画面**；「孩子失踪」一律留白式处理（空鞋、掉落的糖、大人惊惶反应）；罪行以旧案卷宗、证词、账册等**文书证据**呈现 | EP22-74 全线 |

### 12.3 灰区处理策略

| 灰区 | 处理方式 |
|------|----------|
| 以暴制暴倾向（黑风岭对决等） | 武戏「拍结果不拍过程」，最终一律**官法收束**（依法收押/EP74 依法宣判/无一处私刑） |

| 死刑/重刑表述 | EP74 判词「秋后论决」一句带过，不展开行刑相关任何画面与讨论 |
| 贫富/官民矛盾 | 落点为**制度性纠错**（公堂翻案、巡按勘仓、依法抄没），不渲染仇官仇富 |

### 12.4 正向价值锚点

1. **劳动致富**：系统绑定「种粮+喂饱他人」，金手指=劳动与利他
2. **法治精神**：「立字为据」母题贯穿，终局公堂以证据链翻盘、依法收束
3. **善有善报 / 亲情互助**：百家饭反向投喂、豆婆婆线、先弃后求的宽恕收尾

### 12.5 平台审核重点提示（前 3 集）

- EP01：分粥羞辱戏控制时长与语言烈度（无侮辱性肢体接触）；饥荒画面严格执行 R4「拿起-切走」
