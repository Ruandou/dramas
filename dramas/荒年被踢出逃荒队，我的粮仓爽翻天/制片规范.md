## 三、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| 角色 | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| 形象 | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同视觉角色独立 ID + L01 |
| 场景 | `SCENE-###` | `SCENE-001` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**；只增不删，弃用标 `deprecated: true`
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，写明 `based_on: CHAR-xxx-L01`；禁止跳过 L01
- 群演分级：有名字+跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词但需视觉区分 → `CHAR-GRP-##`（按需创建，不设数量上限）
- 同一 `CHAR-GRP-##` 可跨集复用（如 GRP-01 苏家坳村民 EP01–72 全程），不同视觉角色不可共用同一 ID
- scene-writer 标注的新群演（`[待补：...]`）由 production-planner 在集间群演回补子循环统一分配（从已有最大编号 +1）
- 单集参考图配额：每 segment ≤6 张（TOS URL 模式），超出按 segment-builder 优先级裁减；单集会演人数 ≤10（R1 制作可行性要求）

### 形象层级结构

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

## 七、分段规则

### 分段（Segment）规则 —— AI 生成单位

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | EP01/EP68 可至 12 段（120s） |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### Episode Profile

| 集类型 | 时长 | 段落数 | 镜头数 |
|--------|------|--------|--------|
| EP01（加长首集） | 120s | 8–12 段 | 10–14 镜 |
| EP02–72（常规集） | 75–100s | 6–10 段 | 8–12 镜 |
| EP68（奇观特批集） | 90–120s | 8–12 段 | 10–14 镜（全剧唯一大 VFX 集） |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、递粥、拧簪等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 十、音色规范

> voice_prompt 权威来源为 `资产/声音卡片.md`（P0），segment-builder 全文复制、禁改写。

### 语音描述格式

```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

### 旁白与特殊发声体

- **系统（画外音）**：全剧高频发声体，不分配 CHAR-ID，写为「系统」，中性机械音（见声音卡片）
- **旁白**：如需片头提要使用，写为「旁白」，voice_prompt 独立定义
- 分集剧本镜头表标注音效（如 `风沙呼啸`、`系统提示音"叮"`、`火焰噼啪`、`人群嘈杂`、`铜哨长鸣`）
- Seedance `generate_audio: true` 合成基础环境音；特殊音效后期叠加
- 本剧特殊音效需求：系统提示音（叮/轰鸣）、风沙声、柴火/大火声、雪地脚步与膝盖落雪声、算盘声、人群嘈杂/哭喊（人群局部化的声音代偿主载体，见 §十三）

## 十一、年代/题材约束

### 必须体现元素

- 架空古代北方荒年质感：干裂土地、枯树、风沙官道、粗布补丁衣、板车扁担
- 农耕生产细节：垦荒、水渠、土窑、纺线、土法制盐、打谷（种田流核心奇观）
- 柴火光/油灯/火把为主的夜间光源（无任何电气照明）
- 系统空间流光金色（与现实荒年色调强对比）
- 泛古代虚构符号：「大昌年间」「晚仓号」「钱记」等虚构字号

### 禁止出现元素（结构性约束）

- **真实朝代符号**：清代辫发、龙袍/官补/龙纹、真实年号与庙号牌匾、真实历史人物地名影射
- 现代物品穿帮：电灯、电线、玻璃窗、塑料、手表、现代服饰鞋帽
- 军事征战元素（民防对流匪自卫≠军队作战，不得出现军旗/军阵/官军部队）
- 血腥暴力具象：尸体特写、濒死特写、血浆
- 迷信正向呈现（"闹鬼"仅可作为被拆穿的骗局呈现，EP28 磷粉灯笼揭底必须保留）

## 十二、内容合规参数

### 题材合规等级

**🟡 B 级（中低风险）**：荒年民生 + 贪腐查案元素；核心导向（求生互助/劳动致富/亲情群像/依法查办）为 C 级安全区。R1 合规扫描 P0 命中 0。

### 本剧特定红线（含 R1 放行附带条件 4 条 · 硬约束）

1. **人牙子线（EP15/EP19/EP56-57）**：作为被挫败的反派阴谋成立；**禁止出现"验货、定价、交易儿童"具象镜头**；EP15 反派台词"人比粮值钱"可保留（罪证性刻画）
2. **小豆子绑架线（EP54-56）**：必须维持「一只鞋 + 字条」留白式处理；**禁止捆绑、虐待、恐吓儿童特写**（涉未成年内容零容忍）
3. **EP50 传谣者认错**：「当街磕头」弱化为**作揖认错 / 跪地被女主一把拽起**（女主"不受跪"人设即规避写法），规避强迫下跪/持续侮辱联想
4. **饥荒惨状尺度（EP02/EP22/EP30 等）**：观音土、剥树皮、饿昏孩子一律以「拿起—被阻止/切走」处理，**禁止吞食过程与濒死特写**
5. 无真实朝代/时政指涉（架空"大昌年间"，稽查仅功能性执法收尾，非公检法主线）
6. 私刑克制：惩罚仅限推磨/公审/移送稽查，终局依法收押，**无法外处决**

### 灰区处理策略

| 灰区 | 处理策略 |
|------|---------|
| 人口买卖阴谋 | 只拍"阴谋—挫败—反杀"链路，交易环节全留白，头目台词作罪证 |
| 儿童绑架 | 鞋+字条符号化叙事，孩子获救镜头为"扑进怀里"，全程无受虐画面 |
| 荒年饥饿惨状 | 氛围化（干裂土地/稀粥照人影）替代生理化（吞食/濒死），痛感靠表演不靠奇观 |
| 官粮贪腐 | 民间取证 + 稽查依法查办 + 罪状公示，民意监督正向收尾；不影射真实官制 |
| 装神弄鬼（EP27-28） | 以磷粉灯笼拆穿收尾，明确反迷信导向；里正"天意"话术被全剧证伪 |
| 磕头/下跪场面 | 女主全剧"不受跪"：跪者一律被拽起或以"站着干活的才有饭"化解 |

### 正向价值锚点

1. **劳动致富**：「粮凭活挣」贯穿全剧，金手指绑定劳动与利他（喂饱他人才升级），主动对冲不劳而获
2. **互助与善报**：「给饭不问好人坏人」金句体系；以德报怨不失原则（EP65 一碗粥）
3. **法治与民意**：贪腐线民间取证 + 依法收押 + "官府若不办，人心自有一杆秤"的民意监督收尾

### 平台审核重点提示（前 3 集）

- **EP01**：投票逐人+抢饼戏冲突强烈，但**不得出现殴打儿童/老人镜头**；踹下板车用"结果镜头"（跌坐尘土）处理
- **EP02**：险吞观音土 →「拿起—手停住/被系统音打断—切走」，禁入口特写
- **EP03**：里正吞抚恤粮用台词+账目暗示，不拍具象分赃
