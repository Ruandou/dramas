# 《镜中人生》制片规范 · ID 与引用

> **正名**：《镜中人生》（The Mirror Life）
> **版本**：v2.0 · 2026-06-06
> **类型**：都市奇幻 / 悬疑惊悚
> **集数**：36集 × 2.5分钟（单集~150s）
> **画幅**：9:16 竖屏
> **生成工具**：Seedance 2.0（doubao-seedance-2-0-fast-260128）+ Seedream 出图

## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| **场景** | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S01`        | 全局唯一镜头 ID                  |

- 编号**连续、不跳号**，**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再建 **`L01` 基础形象**于 `资产/形象索引.md` + `角色卡.md`。
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。
- 群演分级：有名字+跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词 → `CHAR-GRP`。

### 1.1 形象 ID 与基础 / 衍生

| 后缀     | 名称     | 要求                                                                                |
| -------- | -------- | ----------------------------------------------------------------------------------- |
| **L01**  | 基础形象 | 完整定妆 Prompt（脸、体型、发式、默认服装）；全剧面部一致性的**唯一锚点**           |
| **L02+** | 衍生形象 | **必须** `based_on` 本角色 `L01`；Prompt 只写差异（delta），并含 `same face as CHAR-xxx-L01` |

#### 出图流程

1. 定稿 `L01` 参考图 → Character Sheet（正面全身，白底，平光）
2. 衍生形象用图生图 / 角色一致性模型 → **delta Prompt** 仅写服装/道具/妆效差异
3. **禁止跳过 L01 直接生成 L02**
4. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01

#### 本剧完整衍生形象表

| 角色        | L01（基础）                        | L02（衍生）                              | L03（衍生）                          |
| ----------- | ---------------------------------- | ---------------------------------------- | ------------------------------------ |

| 林泽        | 棉麻衬衫、卡其裤、文艺气质         | —（无衍生）                              | —                                    |
| 周逸        | 深蓝西装、领带、职场精英           | —（无衍生）                              | —                                    |
| 奶奶/秀兰   | 花白短发、棉布外套、围裙           | —（仅以回忆/照片出现）                   | —                                    |

## 三、视觉约束

### 3.1 本剧视觉基调

本剧为**现代都市背景 + 超自然元素**，有两个截然不同的视觉世界：

| 世界         | 色调             | 光影             | 氛围                     | 适用集数      |
| ------------ | ---------------- | ---------------- | ------------------------ | ------------- |
| **现实世界** | 暖灰调、略褪色   | 自然光、暖黄灯光 | 真实、朴素、有生活感     | 全剧          |
| **镜中世界** | 冷白调、高对比   | 顶光、镜面反射光 | 虚幻、完美、压迫感       | EP24–26       |
| **蜕变期**   | 蓝白调、明亮     | 柔光、补光       | 自信、干净、略微不真实   | EP4–12        |
| **崩坏期**   | 暗绿调、闪烁     | 不稳定光源       | 恐怖、焦虑、失真         | EP29–34       |

## 四、工作流顺序（必读 · 防不同步）

### 4.1 修改顺序

改台词、场次、字幕/旁白策略时**严格按层向下**，**禁止**先改 `segments.yaml` 或 `shots.yaml` 再回头补剧本。

| 顺序  | 层           | 文件                        | 写什么                                                                          |
| :---: | ------------ | --------------------------- | ------------------------------------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_镜中人生_36集.md` | 集纲、每场剧情、对白要点、钩子                                                  |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`       | 可拍分镜表：`shot_id`、画面、**对白/备注**、CHAR/SCENE/形象、时长/模式/运镜     |
| **3** | **机器可读** | 同目录 `EP##_shots.yaml`    | 从分集 md 导出，勿手改 yaml 当源                                                |
| **4** | **段落 API** | 同目录 `EP##_segments.yaml` | 按 md 镜号合并为 segment；`api.text` 对白与 **第 2 步引号内字面一致**           |
| **5** | **其它**     | 声音卡、资产索引、assets/   | 仅在前几步定稿后随需更新                                                        |

**单集真相源**：拍什么、说什么 → **`剧本/EP##/EP##_*.md`**；主剧本为纲，segments 为 API 展开。

### 4.2 Agent / 人工自检（改完第 2 步后）

- [ ] 主剧本该集对白要点已与分集表一致（或注明「分集为准」并只改分集）
- [ ] 未单独改 `segments` 而 md 未动
- [ ] 所有角色 CHAR-ID 已在 `资产/角色索引.md` 登记
- [ ] 所有形象 L## 已在 `资产/形象索引.md` 登记
- [ ] 所有场景 SCENE-ID 已在 `资产/场景卡片.md` 登记
- [ ] 所有道具 PROP-ID 已在 `资产/道具卡片.md` 登记
- [ ] 所有 voice_prompt 与 `资产/声音卡.md` 一致

## 五、分集文件头（YAML）与 Segment 规则

### 5.1 分集 YAML 头模板

```yaml
---
episode_id: EP01
episode_title: 镜中人
duration_min: 2.5
season: S1
scene_ids: [SCENE-001, SCENE-002]
character_ids: [CHAR-001, CHAR-002]
look_ids: [CHAR-001-L01, CHAR-002-L01]
prop_ids: [PROP-001, PROP-002, PROP-003]
seedance_defaults:
  model: doubao-seedance-2-0-fast-260128
  ratio: "9:16"
  resolution: 720p
  duration_sec: "8-10"
  generate_audio: true
  prompt_suffix: "禁止画面中出现任何文字或字幕。真人实拍质感，电影级色彩，浅景深。"
  negative_prompt: "blurry, distorted, low quality, watermark, subtitles burned into frame, anime style, cartoon style, watercolor, oil painting style, ancient costume, historical clothing, weapon, military uniform, real celebrity face, real brand logo, WeChat interface, Alipay interface, feng shui compass, talisman, buddha statue worship, fortune telling props, neon RGB lighting, cyberpunk aesthetic"
---
```

**字段说明**：

| 字段                | 说明                                              |
| ------------------- | ------------------------------------------------- |
| `episode_id`        | `EP##` 格式                                       |
| `episode_title`     | 集标题                                            |
| `duration_min`      | 目标时长（分钟），本剧固定 2.5                    |
| `season`            | 固定 `S1`                                         |
| `scene_ids`         | 本集涉及场景 ID 列表                              |
| `character_ids`     | 本集涉及角色 ID 列表                              |
| `look_ids`          | 本集涉及形象 ID 列表                              |
| `prop_ids`          | 本集涉及道具 ID 列表（新增字段）                  |
| `seedance_defaults` | Seedance 生成默认参数                             |

### 5.2 Segment 拆分规则（强制）

| 约束             | 值              | 说明                                                          |
| ---------------- | --------------- | ------------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                            |
| 理想时长         | 8–10 秒         | 与 `seedance_defaults.duration_sec` 一致                      |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                               |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍（有动作起止、有情绪弧）     |
| 每集段落数       | 约 12–15 段     | 对应单集 2.5 分钟时长（~150s ÷ ~10s/段 ≈ 15 段）             |

**关键区分**：

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

**拆分原则**：

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

**分集剧本中的标注要求**：

- 每个 SEG 后标注：`> ⏱ Segment时长：Xs ｜ 镜头数：N`（X ∈ [4, 12]）
- 同场景续接段使用 `**（续）**` 标记，不重复写场景头
- `EP##_segments.yaml` 中 `duration_sec` 必须落在 4–12 区间

**自检清单（提交 segments.yaml 前）**：

- [ ] 所有 segment 的 `duration_sec` 是否都在 4–12？
- [ ] 是否存在跨场景的 segment？（必须断段）
- [ ] 是否存在切断对白或连续动作的拆点？
- [ ] 单 segment 内主说话人是否 ≤ 2，镜头数是否 ≤ 3？
- [ ] 11 列镜头表格式是否完整（镜号/shot_id/场景/角色/形象/景别/时长/模式/运镜/画面/对白备注）？

## 六、视觉规范

### 6.1 角色参考图规范（looks/）

**必须**为 Character Sheet 格式：
- 正面全身、白底、单人、平光
- Prompt 以 `Character reference sheet, front-facing full-body portrait from head to toe, single person standing upright facing the camera, plain white background, clean flat studio lighting.` 开头
- 结尾使用 `Vertical 9:16, character design sheet.`
- **禁止**包含场景背景或情绪灯光描述
- **苏晚与镜中苏晚**：面部五官相同，差异仅在气质、姿态、服装

### 6.2 场景参考图规范（scenes/）

- **严禁出现任何人物**（no people, no human figures）
- 仅包含建筑、家具、道具、植被、光线、氛围
- Prompt 末尾必须追加：`Empty environment, no people, no human figures, architectural and environmental reference only.`
- **禁止**出现具体人物描述
- **禁止**出现外国人描写，避免 AI 模型渲染外国面孔
- 允许使用暗示人类活动的物品（茶杯、笔记本电脑等），但不可有人物在场

### 6.3 道具参考图规范（props/）

- 构图：单物体，最具辨识度的角度，完整物体清晰可见
- 背景：温暖中性丝绸/宣纸底色（非纯白，与角色 Character Sheet 区分）
- 人物：**严禁出现任何人物或手部**（no people, no hands, no fingers）
- 打光：产品摄影式戏剧打光，柔和阴影展示质感
- Prompt 以 `Prop reference photograph, single object isolated on warm neutral silk background, dramatic product lighting with soft shadows.` 开头
- 结尾使用 `Vertical 9:16, detailed prop reference sheet.`
- **禁止**出现任何人物、手部、手指

### 6.4 参考图配额

每 segment 最多 6 张参考图（TOS 模式），优先级：

| 优先级 | 资产类型       | 说明           |
| ------ | -------------- | -------------- |
| P0     | 主角形象       | 必须保证       |
| P1     | 对话角色形象   | 有互动的角色   |
| P2     | 场景参考图     | 保证环境一致性 |
| P3     | 关键道具       | 有余量时加入   |
| P4     | 次要角色/群演  | 最后考虑       |

## 七、AI 出图/视频衔接

### 7.1 出图流程

1. 分镜 **`场景`** → `资产/场景卡片.md` → `SCENE-###` 参考图
2. 分镜 **`形象`** → `资产/形象索引.md` → `角色卡.md` 内该 **L##** 的 Prompt
3. **L01**：用完整 Prompt 生成 Character Sheet（正面全身，白底，平光）
4. **L02+**：`based_on` 指向 L01 参考图 + **delta Prompt**（仅差异部分）
5. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用
6. 分镜 **`角色`** 列仅用于对白表，不参与出图 Prompt 拼接

### 7.2 角色一致性规则

- 每个角色 **L01** 生成后，所有后续出现必须使用该 L01 作为 `reference_image`
- 衍生形象仅改变服装/状态，面部特征锁定为 L01
- **重点**：苏晚与镜中苏晚使用**同一 L01 面部特征**，差异仅在气质和服装
- 同集多角色：每人独立 L01 → 拼合时按角色顺序排列参考图
- **CHAR-001-L03（半透明）** 和 **CHAR-002-L03（崩坏）** 需后期特效辅助，AI 仅生成基础图层

### 7.3 场景一致性规则

- 每个场景 **SCENE-###** 生成参考图后，后续同场景必须使用该参考图
- **镜中世界（SCENE-006）**：纯白虚空+万花筒碎片效果，需单独设计参考图
- 同场景不同角度：用同一参考图做 img2img 变体，禁止重新生成

### 7.4 content_roles 配置模板

```yaml
content_roles:
  - { file: CHAR-001-L01, role: reference_image, label: 图1 }
  - { file: CHAR-002-L01, role: reference_image, label: 图2 }
  - { file: SCENE-001, role: reference_image, label: 图3 }
  # - { file: PROP-001.png, role: reference_image, label: 图4 }
```

### 8.2 道具转移时间线

- **古铜镜（PROP-001）**：EP01箱底发现 → 全剧苏晚持有 → EP34碎裂 → EP36博物馆收存
- **奶奶日记（PROP-002）**：EP01箱中出现未开 → EP12首次打开 → EP13读到封印信息 → EP32找到终极答案
- **银挂坠（PROP-003）**：EP17线索出现 → EP18旧货市场找（空盒子）→ EP19从购买者处取回 → EP20-34苏晚持有
- **诗集（PROP-004）**：EP11林泽赠送 → EP16苏晚试图唤醒林泽 → EP21再次尝试 → EP28林泽记忆裂痕
- **银杏叶（PROP-005）**：EP11夹在诗集中 → EP16说出秘密 → EP28唤醒记忆

### 8.3 肢体动作防错

- 镜子相关镜头：古铜镜为手掌大小圆形，手持方式需统一（单手托底或握边缘）
- 半透明状态（EP22–24）：手指应透光但轮廓仍在，非完全消失
- 崩坏状态（EP29–31）：裂纹从面部向四肢扩散，呈瓷器碎裂纹理
- 万花筒碎裂（EP34）：碎片悬浮而非落地，每片映不同人生画面

### 8.4 常见错误提醒

- 苏晚L02时期仍应保留L01的单眼皮和黑眼圈底色（只是变淡），不可变成双眼皮
- 镜中苏晚与苏晚"同脸不同气"——五官一致但气质截然不同
- 银挂坠是心形银质，不是金质，不可渲染成金色
- 古铜镜背面有繁复刻痕花纹，不是光滑铜面
- 场景中苏晚出租屋是旧式居民楼，不是精装公寓

## 九、有声段落规范（Seedance 2.0 · 默认）

### 9.1 Seedance 段落 Prompt 结构

```
【图1】CHAR-001·苏晚（服装描述）【图2】CHAR-002·镜中苏晚【图3】SCENE-001
角色分工：仅图1可[动作]；图2禁止[动作]。
道具：[具体描述，含尺度参考]。
竖屏9比16连贯叙事。
镜头1（Xs）[景别][运镜]：[纯视觉动作描述]
镜头2（Xs）[景别][运镜]：[纯视觉动作描述]
[以下对白仅供语音合成，严禁在画面中显示任何文字]
对白（CHAR-001，28岁，绝望）：「台词内容」
画面全程无任何文字、字幕、标题、水印。
都市奇幻悬疑惊悚风格，真人实拍质感，电影级色彩，浅景深。
竖屏9比16，[负面约束]。
```

### 9.2 生成模式分配

| 镜头类型         | 模式       | 说明                     |
| ---------------- | ---------- | ------------------------ |
| 环境空镜（无角色） | `t2v`      | 纯文本描述，无参考图     |
| 角色出镜          | `i2v_ref`  | 需角色参考图保持一致性   |
| 片头/片尾/黑屏    | `skip`     | 非 AI 生成               |

### 9.3 11 列镜头表格式

```
| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白/备注 |
```

### 9.4 字幕策略

- Seedance `generate_audio: true` 合成基础环境音和对白
- **字幕后期添加**：Seedance 不烧录字幕，通过 ffmpeg 统一处理
- `prompt_suffix` 必须包含：`禁止画面中出现任何文字或字幕`
- 道具上的文字（如日记内容）后期合成，AI 无法可靠渲染中文字

### 9.5 音效/配乐标注

- 在分集剧本的镜头表中 `对白/备注` 列标注音效
- 格式：`（音效：[音效名称]）`
- 特殊音效后期叠加，Seedance 仅合成基础环境音
