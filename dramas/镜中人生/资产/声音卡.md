## 声音特征详细说明

### CHAR-001 苏晚

**情绪状态线**：

| 阶段 | 集数 | 声音特征变化 |
|------|------|-------------|
| 绝望期 | EP01–02 | 声音极小、沙哑、频繁停顿、多内心独白 |
| 初次蜕变 | EP03–05 | 声音略提高、但仍不确定、句尾上扬像在征求意见 |
| 自信上升期 | EP06–10 | 语速略快、音量稳定、但偶尔被镜中苏晚声音压制 |
| 动摇期 | EP11–12 | 声音回到犹豫状态、内心独白增多 |
| 崩溃期 | EP13–15 | 声音发抖、频繁哽咽、说话断断续续 |
| 半透明期 | EP22–24 | 声音虚弱如耳语、像从很远的地方传来 |
| 反击期 | EP26–31 | 声音重新有力、但不追求完美——带颤抖的坚定 |
| 觉醒期 | EP32–34 | 声音平静、不再颤抖、每句话都像在对自己说 |
| 新生期 | EP35–36 | 声音温暖、自然、像一个普通女孩在聊天 |

### CHAR-002 镜中苏晚

**情绪状态线**：

| 阶段 | 集数 | 声音特征变化 |
|------|------|-------------|

## 旁白使用规范

| 用途 | 说明 |
|------|------|
| 使用频率 | 非每集使用，仅在特殊过渡或信息密集段落 |
| 使用场景 | 时间跳跃过渡、背景信息补充、悬念渲染 |
| 风格 | 低沉磁性、悬疑讲述感、不过度情绪化 |
| 格式 | `**旁白**[情绪]：「旁白内容」` |
