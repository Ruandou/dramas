## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同群演角色独立 ID + L01    |
| 场景     | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### ID 分配规则

- 编号**连续、不跳号**；ID **只增不删**，弃用标 `deprecated: true`
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象
- 新建换装/阶段形象：只加 `L02+` 衍生形象，必须写明 `based_on: CHAR-xxx-L01`，**禁止跳过 L01**
- 群演按需创建，不设数量上限：有名字+跨 segment 出现 → 独立 `CHAR-GRP-##`；scene-writer 剧本中标注的新群演（`[待补：...]`）由 production-planner 在集间群演回补子循环统一分配（从已有最大编号 +1，当前已预置 `CHAR-GRP-01`~`CHAR-GRP-11`，新群演从 `CHAR-GRP-12` 起）
- 不同视觉角色不可共用同一 GRP ID；同一 GRP ID 可跨集复用
- API 参考图配额：每 segment ≤6 张（TOS URL 模式），超出按 segment-builder 优先级裁减

### 形象层级

| 后缀     | 名称     | 说明                                        |
| -------- | -------- | ------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

> 结构性观察 S4：萌宝单主角 AI 一致性固有难度 → character-designer 为小糯米（CHAR-001）多备 2–3 组表情参考图（委屈/好奇/认真许愿/大笑），并预留年龄变化线形象（L02 四岁 / L03 五岁）。

## 二、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于大纲元数据「视觉风格：明亮暖调半写实国风（萌宝高饱和糖果色点缀，仙侠场景柔和明快，喜剧质感优先于压迫感）」「色彩基调：暖阳金＋草木绿为主；雨幕青蓝／花开粉金／言灵鎏金为能力标点（哭=青蓝雨、笑=粉金花开、言=鎏金言光）」。

| 维度 | 规格 |
|------|------|
| 渲染风格 | stylized realism（半写实国风，柔和高饱和；萌宝高饱和糖果色点缀，喜剧质感优先于压迫感） |
| 镜头参考 | cinematic 35mm–85mm lens；喜剧反应镜头偏中近景；萌宝表情特写高频（委屈/好奇/认真许愿） |
| 色调方向 | warm golden daily tone + spring green accents；能力标点：哭=青蓝雨幕、笑=粉金花开、言=鎏金言光（彩虹） |
| 画幅 | 9:16 vertical |
| 题材关键词 | bright xianxia, cute baby comedy, jianghu sect, hanfu robes, mountain temple, rain/flowers/golden light magic |

### 全局 prompt_suffix（出图统一后缀，设计师在此基础上拼接）

```
ancient Chinese xianxia fantasy, bright warm golden tones with spring green accents, cute candy-color accents on the baby heroine, soft bright atmosphere, comedic tone over oppression, cinematic lighting, high detail, 9:16 vertical composition
```

### 全局 prompt_suffix_silent（无对白段专用）

```
本段无对白无语音，禁止画面中出现任何文字。ancient Chinese xianxia fantasy, bright warm golden tones with spring green accents, cute candy-color accents, soft bright atmosphere, comedic tone over oppression, cinematic lighting, high detail, 9:16 vertical composition
```

### 结构性 negative_prompt（年代/题材禁忌 + 合规基线，**所有出图/出片必带**）

```
modern objects, smartphone, electric wires, cars, glass skyscraper, neon signs, zipper, wristwatch, jeans, sneakers, plastic items, contemporary clothing, real-world dynasty emblems or era names, blood, gore, graphic injury, burnt corpse, painful scream close-up, horror atmosphere, dark oppressive tone, kneeling worship crowd, incense altar worship, religious idol veneration, english text, latin letters, watermark, logo, platform UI
```

> 说明：①架空修真界（青云剑宗＋言灵仙脉世界观，无真实朝代映射）——禁止现代物品与可识别的真实朝代符号；②萌宝合规——**零流血/零虐待/零痛苦惨叫特写**，受创一律脸色发白/捂心表现；③反迷信合规——「童言成真」= 善意喜剧设定（言灵=心之力），禁跪拜磕头/求神拜佛/香火供奉类画面（恳求/拜谢一律作揖长揖）；④文字规范——本剧道具含简体中文（刻字断剑"言溪"、玉锁、字条、言溪日记、天机令牌等），画面文字一律简体中文，negative 排除英文/拉丁字母；⑤能力显灵（雨/花/金光/彩虹）为环境级自然意象，不拍施法仪式化镜头。创意领域 negative（如画风排除）由各设计师自行补充。

| 参数 | EP01 | EP02–EP86 |
|------|------|-----------|

| 段落数 | 10–12 段（可至 12） | 6–10 段 |

> G4/G5 与 segment-builder 均从本节取阈值。基准：`docs/references/台词节奏基准.md` §五（成片实测 ASL 2.2s）。本剧单集时长由 `format_check` G4 硬校验（duration_sec = 镜头表总时长）。

### 引擎参数（解析自 `mcps/shared/engine_registry.py` → `video_defaults()`，当前 video_gen 默认引擎 = seedance）

| 键 | 值 | 说明 |
|----|----|------|
| model | `doubao-seedance-2-0-fast-260128` | ⚠️ 必须带版本后缀，无后缀方舟 404 |
| ratio | `9:16` | 竖屏 |
| resolution | `720p` | 出片分辨率 |
| image_resolution | `1600×2848` | Seedream 参考图（角色/场景/道具），9:16 |

## 六、分段规则

| 约束             | 值              | 说明                                    |
| ---------------- | --------------- | --------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                 |
| 每 segment 镜头数 | ≤3 镜；段 ≥8s 必 ≥2 镜 | v2.2 切镜节奏                     |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍       |
| 每集段落数       | 见四B episode_profile | EP01 10–12；EP02+ 6–10            |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（哭—雨起、笑—花开、许愿—金光等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤2；长对手戏拆 `SEGxxa` / `SEGxxb`
5. 分镜表某镜自然时长 <4s → 并入同场景相邻段
6. **场景（SCENE-###）= 空间单位；Segment = AI 生成单位**；同一场景可含多个 segment，segment 不得跨场景

## 八、音色规范

- **voice_prompt 唯一权威来源（P0）= `资产/声音卡片.md`**；P1 = 角色卡片；P2 = 本文件。存在 P0 一律用 P0。
- voice_prompt 必须全文复制（「」内全部文字），禁止缩写、改写、简化；同一角色跨 segment 全文一致。
- 小糯米年龄变化线（三岁半→EP85 四岁→EP86 五岁）：voice_prompt 文本保持稳定（以三岁半奶音为基准），EP85+ 音色微成熟由 TTS 参数微调，不新建 voice_prompt 变体。
- 本剧**不设独立旁白**；言溪残影/回忆使用 `CHAR-012` 同一 voice_prompt（残影回响感由分集剧本以 [残影] 情绪标注区分）。如后续需要旁白，另行在声音卡片登记。
- 音效在分集剧本镜头表标注（如 `雷声大作`、`铃铛轻响`、`雨声`）；`generate_audio: true` 合成基础环境音，特殊音效后期叠加。
- 字幕后期 ffmpeg 统一添加，Seedance 不烧录字幕。

## 九、年代/题材约束

**必须体现**：
- 架空修真界国风元素：道袍/短打/劲装/掌门袍等古装制式、山门殿宇、飞剑剑穗、测灵碑、藏剑阁、符箓令牌
- 萌宝糖果色点缀：小糯米粉白小袍 + 双丸子头 + 银铃铛，高饱和暖色在仙侠场景中作视觉记忆点
- 能力标点：哭=青蓝雨幕、笑=粉金花开、言=鎏金言光（金光/彩虹），为环境级自然意象（不拍施法仪式）
- "穷宗"质感：破旧古朴山门、斑驳梁柱、补丁账房袍/掌门袍——穷但干净、暖

**禁止出现**：
- 一切现代物品（手机、电线、玻璃幕墙、拉链、手表、汽车、塑料制品、现代服装）
- 可识别的真实朝代年号/官制/地名映射（本剧为架空世界观）
- 流血/血腥/痛苦惨叫/虐待特写（萌宝受创=脸色发白/捂心）；灾难/恐怖氛围（暴雨/大阵/天裂以气象+光效+剪影代偿）
- 跪拜磕头镜头（恳求/拜谢/谢恩一律作揖长揖）；跪拜祭祀/求神拜佛/香火供奉画面
- 绑架/束缚/私刑画面（EP50 掳走"阵光一卷即遁"留白；执法一律文书程序收尾，无私刑）
- 画面英文/拉丁文字（本剧道具文字一律简体中文）

## 十、受众定位

- 主频道: 女频为主（萌宝团宠+被温柔接住的情绪抚慰）＋ Z 世代泛化（童言社死名场面+反差萌）
- 核心年龄段: 25–45 女性为主；Z 世代泛化
- 核心痛点: 被弃/不被接纳的创伤；"没人要的孩子"共情；渴望被温柔接住；社交社死尴尬
- 爽感期待: 搞笑爽 35% + 团宠暖 25% + 逆袭爽 20% + 感动爽 15% + 悬疑爽 5%
- 对标作品: 《咱家剑宗团宠小师妹》（同源结构：身世凄惨→全宗接住→逆天成长）；《我一鼓掌就天雷滚滚》（区隔：憋话社死/童言无差别攻击）

### 题材制作复杂度预算

| 题材 | 场景复杂度 | 角色数量 | AI生成难度 | 预估周期 |
