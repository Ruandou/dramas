## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同角色独立 ID + L01 |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### 形象层级

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的唯一锚点 |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 L01；禁止跳过 L01 |

## 四、工作流顺序（必读 · 防不同步）

| 顺序 | 层 | 文件 | 写什么 |
|:---:|------|------|------|
| **1** | 主剧本 | `短剧剧本_满级师尊她装作刚入门_72集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | 分集剧本 | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | 机器可读 | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | 段落 API | `EP##_segments.yaml` | 按 md 镜号合并为 segment |
| **5** | 其它 | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 六、分段规则

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每段构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | EP01 可至 12 段 |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### 拆分原则

1. 不得在对话中间切断 segment
2. 不得在连续动作进行中切断
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2
5. 分镜表里某镜自然时长 < 4 秒 → 并入同场景相邻段

## 八、音色规范

### TTS 技术参数

- 引擎：Seedance generate_audio: true（基础环境音）
- voice_prompt 格式：「性别，年龄，音色特征，语速，情绪基调/说话习惯」
- 同一角色跨 segment 的 voice_prompt **全文一致**
- 旁白不分配 CHAR-ID，写为「旁白」
- 权威来源：`资产/声音卡片.md`（P0 最高优先级）

### 音效标注规范

- 分集剧本镜头表中标注音效（如 `剑气破空`、`灵力震动`、`桃花落`）
- Seedance generate_audio: true 合成基础环境音
- 特殊仙侠音效后期叠加（剑鸣、法阵嗡鸣、灵力流动等）

## 九、年代/题材约束

### 必须体现元素（叙述性）

- 修真世界观：宗门体制、弟子等级（外门/内门/亲传）、修为境界
- 仙侠服饰：飘逸长袍/纱裙、发带/发冠/簪子、腰佩配饰
- 自然仙境：云海、灵山、桃花林、竹林、瀑布、月色
- 法术视觉：剑光/剑气、灵力光芒（金/银/蓝/紫）、符文阵法
- 建筑风格：木构飞檐、白玉台阶、仙灯悬浮、竹简书架

### 禁止出现元素

- 任何现代物品（电子设备、塑料制品、玻璃窗、水泥建筑）
- 西方奇幻元素（翅膀天使、龙骑士、精灵耳）
- 日式元素（和服、鸟居、武士刀鞘）
- 繁体字乱码/不可辨识文字
- 过于暴露或现代审美的服饰
- 科幻元素（机械、激光、太空）

## 内容合规参数

### 题材合规等级

**B级** — 仙侠玄幻 + 甜宠逆袭（低风险题材，无敏感政治/宗教映射）

### 本剧特定红线

1. **暴力尺度**：战斗场面不出现断肢、喷血特写；渊暝的"冤魂"不出现写实恐怖面容
2. **情感尺度**：甜宠止于亲吻，不出现床戏暗示画面
3. **封建迷信**：修真体系为"灵力修炼"框架，避免宣传真实宗教仪式或邪教元素
4. **价值导向**：反派行为明确标注为"邪道"，不美化背叛/夺宝行为
5. **未成年保护**：小雪狐化形为幼女外形时，不出现任何性化暗示

### 灰区处理策略

| 灰区 | 预定处理 |
|------|---------|
| 前世记忆中的"死亡"画面 | 以剪影/光效/意象化处理，不出现直接刺杀写实画面 |
| 渊暝的"摄魂术"折磨 | 表现为清词痛苦表情+黑色能量缠绕，不出现类酷刑画面 |
| "殉情跳崖"叙述 | 以回忆影像+旁白交代，不展示跳崖过程 |
| 冤魂洪流 | 以抽象黑色能量流表现，非写实鬼魂面容 |

### 正向价值锚点

1. **信任与守护**：顾渊白百年等待体现的忠贞与守护精神
2. **自我成长**：沈清词从被动隐忍到主动担当的蜕变
3. **原谅与理解**：冷凝霜/前世师妹真相揭示的"理解胜过仇恨"主题

### 平台审核重点提示（前3集）

- EP01：前世"坠崖"画面用远景剪影+光效处理，≤3秒
- EP01：师妹"刺背"动作用慢动作+虚化处理，不出现伤口特写
- EP02：刘芸"泼脏水"行为属于欺凌，需在后续集数有明确惩罚回报
- EP03：打脸场面注意"力量反差的趣味性"而非暴力感
