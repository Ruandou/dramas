# 场景卡片 · 《铁饭碗被抢那天，我下海了》

> **版本**：v1.0 · 2026-07-29 ｜ SCENE-### 在此唯一定义（10 个，与大纲附录场景清单一一对应，无新造）
> 英文 Prompt / 生成状态 / 参考图路径由 scene-designer（Stage 3c）填充；ID 与必填元数据不可修改。
> 全场景通用：制片规范 §二 prompt_suffix + negative_prompt（年代禁忌）不得省略；**场景内文字元素**一律简体、笔画正确，出图锁定。
> 非核心一次性地点（赵家门口/寄卖行/旧货市场/工商所/表彰礼堂等）暂不设 ID，scene-writer 以 `[待补：场景]` 标注后集间回补扩展。
> **EP01 涉及场景：SCENE-001**（唯一）；EP01 前世闪回为缝纫机前静帧特写（伏机+皮尺绕腕），按特写镜头处理不设独立场景。
