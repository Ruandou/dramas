### ID 分配规则

- 编号**连续、不跳号**；ID **只增不删**，弃用标 `deprecated: true`
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01`
- 换装/阶段形象：只加 `L02+`，必须写明 `based_on: CHAR-###-L01`，禁止跳过 L01
- 群演：无名功能角色（有台词、单独出镜）→ `CHAR-GRP-##`（每个视觉不同角色独立 ID+L01，不同角色不可共用）；纯氛围群像（女工们/学员们/围观群众/顾客/轮休女工们/全员）**不分配 ID**，由 scene-writer 标注 `[待补：...]` 后在集间群演回补子循环统一分配
- **非核心一次性地点**（赵家门口、寄卖行、旧货市场、工商所门前、表彰礼堂等）暂不设 SCENE-ID，由 scene-writer 以 `[待补：场景]` 标注，集间回补时由 production-planner 扩展 ID（只增不删）
- 参考图配额：每 segment ≤6 张（TOS URL 模式），超出按 segment-builder 优先级裁减

## 二、视觉风格锚点 (Visual Style Anchor)

> 与大纲 YAML 元数据严格一致；创意细节由 character/prop/scene-designer 展开，本表为不可违背的方向锚。

| 维度 | 规格 |
|------|------|
| 渲染风格 | photorealistic 九十年代年代写实（筒子楼烟火 + 夜市灯泡串 + 汉正街人潮局部 + 缝纫机手艺特写 + 绿皮火车/解放卡车年代符号） |
| 镜头参考 | cinematic 35mm 市井纪实感；手艺特写（验布/走线/剪衣）85mm 浅景深 |

| 画幅 | 9:16 vertical（竖屏） |
| 年代 | 1992-1995，中部架空小城「楚阳市」；进货地武汉汉正街 |
| 题材关键词 | 年代烟火、裁缝手艺、缝纫机、灯泡串夜市、国营厂红砖、九十年代记忆杀 |

### 全局 prompt_suffix（设计师出图统一追加）

```
photorealistic, early 1990s small-city China period drama (1992-1995), nostalgic
warm tungsten glow, subtle film grain, authentic nineties textures (red brick,
enamel mugs, dacron floral fabric, army-green canvas, wooden window frames),
cinematic lighting, vertical 9:16 composition, high detail
```

> 三态切换（scene-designer 按场景态替换色调短语，其余后缀不变）：
> - 家庭对峙态：`warm tungsten glow` → `cold blue-grey overcast tone, harsh top light`
> - 创业爆发态：`nostalgic warm tungsten glow` → `high-saturation festive market warmth, bulb-string glow`

### 全局 negative_prompt（年代/题材结构性禁忌，任何出图不得省略）

```
modern smartphones, mobile phones, modern cars, SUVs, electric vehicles, modern
billboards, LED screens, neon advertising, QR codes, barcode payment signs,
modern plastic shopping bags, air conditioners, modern sneakers, modern hairstyles,
high-rise glass curtain-wall buildings, modern shopfronts, traditional Chinese
characters, wrong Chinese characters, garbled text, gibberish signage, Western
faces, Caucasian features, Japanese or Korean street elements, anime style,
luxury glamour filter, piles of banknotes glamour shot, ghost, supernatural glow,
religious iconography, watermark, subtitles, UI overlay
```

要点解释（结构性约束，不可删）：
1. **年代禁忌（1992-1995 中部小城）**：禁一切现代元素——智能手机/新款汽车/现代广告牌与 LED/二维码/现代塑料袋样式/空调外机/现代发型服饰/玻璃幕墙。街头交通工具=自行车流、解放卡车、绿皮火车；照明=钨丝灯、灯泡串、马灯
2. **繁体字/错误汉字**：本剧中文文字道具 12 项，任何含文字画面必须简体、笔画正确。**唯二豁免**：PROP-006 港版画报（封面文字一律虚化不可读）、PROP-016 假港标织唛（剧情伪标，繁体『香港製造』或虚化，G3 由 drama-director 终审确认）
3. **西方面孔/日韩元素**：全员九十年代中国面孔、大陆中部小城街景
4. **拜金红线视觉化**：禁钞票堆高光镜头——数钱镜头一律落在账本与冻裂的手（大纲价值导向明文）
5. **ghost/supernatural**：重生仅 EP01 一次 3 秒静帧闪回，零玄学视觉元素（合规 P0）

## 六、分段规则（Seedance 硬约束）

| 约束             | 值              |
| ---------------- | --------------- |
| 单 segment 时长  | **4–12 秒**（硬限制，超出必须拆分） |
| 理想时长         | 8–10 秒         |
| 每 segment 镜头数 | 1–3 镜         |
| 最小叙事单位     | 1 个完整 beat   |
| 单段主说话人     | ≤2（长对手戏拆 `SEGxxa/b`） |

拆分原则：
1. 不得在一句对白中间切断 segment
2. 不得在连续动作链（签字落笔、绕皮尺上腕、剪衣拆袖、掀铁皮盒）中间切断
3. 拆段边界 = 场景切换 / 主说话人切换 / 情绪断点
4. 分镜表某镜自然时长 <4 秒 → 并入同场景相邻段
5. **场景（SCENE-###）= 空间单位；segment = 生成单位**；同场景可含多 segment，segment 不得跨场景

## 九、年代/题材约束（叙述性）

**必须体现**：
- 1992-1995 中部小城年代质感：筒子楼、红砖厂房、八仙桶/搪瓷缸/奖状墙、的确良碎花、灯泡串夜市、自行车流、广播喇叭

- 战场阶段演进：夜市地摊 → 晚秋衣坊门面 → 晚风制衣车间/挂牌厂（见场景卡片阶段态）
- 公职人员（工商所办事员/核查员、评标老师）程序正当、态度中性的正面呈现

**禁止出现**：
- 一切现代元素（见 §二 negative_prompt 第 1 条）：智能手机、新款汽车、现代广告牌/LED、二维码、现代塑料袋样式、空调、现代服装发型
- 繁体字、错别字、乱码招牌（豁免：港版画报虚化、假港标伪标语境，见 §二 第 2 条）
- 钞票堆炫富镜头、奢华滤镜（拜金红线：钱的镜头=账本、工钱单、冻裂的手）
- 国企改制的政策评价性画面语言（布告栏/分流只作背景与个人命运对照）
- 重生玄学视觉（EP01 闪回=伏在缝纫机上+皮尺绕腕静帧，无病容濒死特写；全剧无第二次）
- 执法暴力/私刑/侮辱性清算画面（工商处罚以公示文书特写+旁白带过）

## 十、专项技术规范

### 中文文字道具（12 项）

- Prompt 必须含 `Simplified Chinese` + 精确文字内容（以道具卡片「文字内容」栏为唯一口径）+ 字体风格（钢笔手写/毛笔/油印/红纸黑字/刻字）
- 文字不合格（错字/繁体/乱码）= 该参考图直接判废重出
- 文字道具特写镜头优先「道具参考图引用」而非场景内嵌
- 场景内文字元素（店招「晚秋衣坊」、厂训「手艺不欺人」、招牌「桂芳精品屋」等）由 scene-designer 按场景卡片登记文字锁定，验收标准同上
- 字幕（对白）后期添加，Seedance 不烧录任何字幕
