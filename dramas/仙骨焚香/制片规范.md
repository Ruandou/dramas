## 一、项目基本信息

| 字段 | 内容 |
|------|------|
| 剧名 | 《仙骨焚香》 |
| 题材 | 仙侠 / 重生复仇 / 情感成长 |
| 合规分级 | 🟡 B级 — 修仙/神话题材，核心导向为情感成长与复仇救赎，非封建迷信宣扬 |
| 集数 | 36 集 |
| 单集时长 | 约 2.5 分钟（~150s） |
| 总时长 | 约 90 分钟 |
| 画面比例 | 9:16 竖屏 |
| 核心钩子 | 仙门第一天才被师尊亲手抽去仙骨、推下诛仙台，重生回到拜师当日——她冷笑一声，转身跪在了师尊死对头面前 |

### 1.1 世界观核心设定

- **三域格局**：仙界（九霄仙门为魁首）／ 人界（凡人修仙起点）／ 魔域（被封印的深渊裂隙）
- **修仙境界**：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 大乘 → 飞升
- **仙骨设定**：仙骨是亿万人中无一的先天灵根具象化，承载天道赋予的至高修炼天赋。亦是上古封印的容器——魔尊重楼的一缕神魂被封印其中。
- **重生机制**：仙骨与青鸾灵魂有千世因果绑定。诛仙台天谴之力触发仙骨终极禁术——时光逆流。
- **势力分布**：九霄仙门分九峰，天枢峰（墨渊执掌，主杀伐）与太虚峰（凌霄执掌，主天道推演）是双璧，暗中对立百年。

### 1.2 核心冲突

- 表层：青鸾复仇墨渊，碾压一切前世欺辱她的人
- 中层：青鸾在新旧两位师尊之间，情感与身份的撕裂
- 深层：仙骨中的魔魂逐渐苏醒，青鸾必须在「复仇」与「拯救」之间做出终极选择

## 二、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |

## 四、美术规范

### 4.1 仙侠美学定位

| 维度 | 规范 |
|------|------|
| 色彩倾向 | 仙界以白金青为主（清冷高雅），魔域以黑红紫为主（暗沉压迫），人界以暖黄灰为主（朴素温润） |
| 光影风格 | 仙界用高调柔光+神光（god-ray），魔域用低调硬光+底光，太虚峰用晨曦/月光色温，天枢峰用冷白/冰蓝色温 |
| 构图原则 | 9:16 竖屏优先突出单人/双人关系；大场景用纵深构图（人物小→气势大）；战斗场景对角线构图增强动感 |
| 特效风格 | 灵力→金色流体光效，魔气→黑色烟雾/火焰，雷劫→紫电+金色裂纹，封印符文→篆体变形发光 |

### 4.2 必须体现

- 明制/仙侠古风服装（交领、广袖、层叠纱质）
- 木质/玉石建筑（非现代混凝土）
- 油灯/夜明珠/灵光照明（无电灯）
- 御剑/踏云/凌空飞行
- 符箓、法阵、灵力光效
- 毛笔、玉简、卷轴（无现代纸张）

### 4.3 禁止出现（Negative Prompt 年代禁忌）

- 现代服饰（T恤、牛仔裤、西装）
- 科技设备（手机、电脑、汽车、电器）
- 现代建筑材质（混凝土、玻璃幕墙、不锈钢）
- 塑料制品、现代包装
- 真实品牌Logo、现代文字/数字
- 清代发式（辫子/剃发）、其他朝代标志性服饰
- 现代武器（枪支、炸弹）
- 电灯、霓虹灯、LED

### 4.4 画面质量禁忌（通用）

- 模糊、失真、低质量
- 水印、字幕烧入画面
- 动漫风格、卡通风格、水彩、油画风格
- 真人明星脸

## 五、AI 生成参数

### 5.1 Seedance 默认配置

```yaml
seedance_defaults:
  model: seedance-v2-fast
  ratio: "9:16"
  resolution: 720p
  duration_sec: "8-10"
  generate_audio: true
  cfg_scale: 7.0
  steps: 30
  prompt_suffix: "仙侠古风，精致光影，电影级质感。写实风格，竖屏9比16。禁止画面中出现任何文字或字幕。"
  negative_prompt: "blurry, distorted, low quality, watermark, subtitles burned into frame, anime style, cartoon style, watercolor, oil painting style, modern clothing, T-shirt, jeans, suit, smartphone, computer, car, electric light, neon sign, concrete building, plastic, Qing dynasty hairstyle, queue, bianzi, modern weapon, real brand logo, celebrity face, modern architecture, glass curtain wall, stainless steel"
```

### 5.2 Seedance 段落 Prompt 结构

```
【图1】CHAR-###-L##·角色名（服装描述）【图2】CHAR-###-L##·角色名【图3】SCENE-###
角色分工：仅图1可[动作]；图2禁止[动作]。
道具：[具体描述，含尺度参考]。
竖屏9比16连贯叙事。
镜头1（Xs）[景别][运镜]：[纯视觉动作描述]
镜头2（Xs）[景别][运镜]：[纯视觉动作描述]
[以下对白仅供语音合成，严禁在画面中显示任何文字]
对白（角色，年龄，情绪）：「台词」
画面全程无任何文字、字幕、标题、水印。
仙侠古风，精致光影，电影级质感。写实风格，竖屏9比16。
```

### 5.3 参考图配额优先级

| 优先级 | 资产类型 | 说明 |
|--------|---------|------|
| P0 | 主角形象（CHAR-001-L##） | 必须保证 |
| P1 | 对话角色形象（互动角色） | 有互动的角色必须锁定 |
| P2 | 场景参考图（SCENE-###） | 保证环境一致性 |
| P3 | 关键道具（PROP-###） | 有余量时加入 |
| P4 | 次要角色/群演 | 最后考虑 |

- **每 segment 最多 6 张参考图**（TOS 模式）

## 六、分段与镜头规范

### 6.1 分段（Segment）规则

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 约 12–15 段 | 对应单集 2.5 分钟 |

### 6.2 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 6.3 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 八、声音规范

### 8.1 voice_prompt 格式

每个有对白角色使用统一的五要素格式：
```
「[性别]，[年龄]岁，[音色特征]，[语速特征]，[情绪基调/说话习惯]」
```

同一角色跨 segment 的 `voice_prompt` 必须**全文一致**。voice_prompt 的权威来源为 `资产/声音卡.md`。

### 8.2 旁白风格

- 本剧不使用独立旁白角色
- EP36 结尾画外音由 CHAR-001 的 voice_prompt 以内心独白模式处理

### 8.3 音效/配乐标注

在分集剧本镜头表中标注 `音效/配乐` 列：
- 格式：`[音效类型]`（如 `天雷轰鸣`、`剑刃破空`、`心跳声`、`紧张弦乐`）
- Seedance `generate_audio: true` 可合成基础环境音；特殊音效后期叠加

| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它** | 声音卡、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 十一、出图流程

1. 定稿 `L01` 参考图 → Character Sheet（正面全身，白底）
2. 衍生形象用图生图 / 角色一致性模型 → **delta Prompt** 仅写服装/道具/妆效差异
3. **禁止跳过 L01 直接生成 L02**
4. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01

### 形象 Prompt 书写规范

- **L01（完整 Prompt）**：以 `Character reference sheet, front-facing full-body portrait from head to toe, single person standing upright facing the camera, plain white background, clean flat studio lighting.` 开头，以 `Vertical 9:16, character design sheet.` 结尾。
- **L02+（Delta Prompt）**：以 `same face as CHAR-###-L01` 开头，仅写差异。

## 十二、分集剧本格式规范

分集剧本使用 **11 列镜头表格式**：

```
| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白/备注 |
```

### 各列规范

| 列名 | 格式 | 说明 |
|------|------|------|
| 镜号 | 整数 | 全集连续编号 |
| shot_id | `EP##-S##` | 全局唯一 |
| 场景 | `SCENE-###` | 对应场景卡片 |
| 角色 | `CHAR-###` | 出镜角色，无人写 `—` |
| 形象 | `CHAR-###-L##` | 本镜使用的形象版本 |
| 景别 | 中文 | 全景/中景/近景/特写/大特写 |
| 时长 | 整数秒 | ≥4 |
| 模式 | `t2v` / `i2v_ref` / `skip` | 生成模式 |
| 运镜 | 中文 | 固定镜头/缓推/镜头推近/镜头拉远/镜头跟随/快切/主观镜头 |
| 画面 | 2-4句 | 电影级视觉描述 |
| 对白/备注 | 格式化 | `**CHAR-###**[情绪]：「台词」` |
