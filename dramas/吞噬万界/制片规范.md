## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 背景角色，按需创建无上限 |
| 场景 | `SCENE-###` | `SCENE-001` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：只加 `L02+` 衍生形象，并写明 `based_on: CHAR-xxx-L01`
- 群演按需创建，不设数量上限。唯一约束是 API 参考图配额（每 segment ≤6 张）
- 同一 CHAR-GRP-## 可跨集复用，但不同视觉角色不可共用同一 ID

### 形象层级结构

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

## 二、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于 story-architect 大纲元数据。

| 维度 | 规格 |
|------|------|
| 渲染风格 | 写实仙侠，水墨风元素，光效渲染 |
| 镜头参考 | cinematic 85mm lens（人物特写）、wide-angle 24mm（战斗全景） |
| 色调方向 | 冷色调为主（青灰/墨蓝），觉醒时金色光效，反派用暗红/黑紫 |
| 画幅 | 9:16 vertical (1600×2848 Seedream 参考图) |
| 题材关键词 | 仙侠、水墨、光效、古风、零现代元素 |
| prompt_suffix | `, xianxia fantasy, Chinese ink-wash painting style elements, cinematic lighting, no modern elements, no text, no watermark, 9:16 vertical composition` |

### Negative Prompt 基线（年代/题材结构约束）

> 以下为 production-planner 定义的**年代/题材禁忌**类 negative prompt，属于结构性约束。
> 创意领域 negative prompt（如「禁止动漫风格」）由设计师各自负责。

- 禁止出现**任何现代元素**：西装、眼镜、手机、电线杆、现代建筑、汽车、霓虹灯
- 禁止出现**非中国古风服饰**：和服、韩服、西方铠甲
- 禁止出现**现代材质**：塑料、不锈钢、玻璃幕墙
- 禁止出现**文字水印**：中英文文字、logo、水印
- 禁止出现**写实照片风格**：必须保持仙侠幻想感

## 八、工作流顺序（必读 · 防不同步）

制片规范确立后，所有内容修改**严格按层向下**：

| 顺序 | 层 | 文件 | 写什么 |
|:---:|---|---|---|
| **1** | **主剧本** | `短剧剧本_吞噬万界_72集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 十、分段规则（Segment Rules）

| 约束 | 值 | 说明 |
|------|------|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | 对应单集 75–120 秒（EP01 可至 12 段） |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### 拆分原则

1. **不得**在对话中间切断 segment
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 十一、分集剧本格式规范

分集剧本（`剧本/EP##/EP##_*.md`）是单集的**真相源**。

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`

## 十三、音色规范

### 语音描述格式

每个有对白的角色必须有 `voice_prompt`，格式：
```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

- voice_prompt 权威来源为 `资产/声音卡片.md`（P0）
- 同一角色跨 segment 的 `voice_prompt` 必须**全文一致**
- 旁白角色不分配 CHAR-ID，voice_prompt 独立定义

## 十五、年代/题材约束

### 必须体现元素

- 仙侠修炼体系：炼气→筑基→金丹→元婴→化神→渡劫→大乘→仙人
- 古代中国建筑风格：宗门殿堂、石塔、山门、古镇
- 灵力/法术视觉表现：金色光效（吞噬）、暗红魔气（反派）、水墨元素（意境）
- 传统服饰：宗门袍服、长裙、铠甲
- 修炼场景：闭关密室、试炼塔、洞府

### 禁止出现元素

- 任何现代科技产品（手机、电脑、汽车、飞机）
- 现代建筑风格（摩天大楼、玻璃幕墙）
- 西方奇幻元素（魔法杖、精灵、矮人）
- 现代口语或网络用语（角色对白中）
- 科幻元素（飞船、机器人、激光武器）

## 内容合规参数

### 题材合规等级

**B级**（仙侠/玄幻·中等风险）

### 本剧特定红线

1. **禁止过度血腥**：战斗场景不得出现断肢、大量鲜血喷溅；伤害以灵力光效冲击表现
2. **禁止宗教敏感内容**：仙侠修炼体系不得与现实宗教直接关联；"天道""因果"为世界观术语而非宗教概念
3. **禁止自杀引导**：坠崖/跳崖均为被动行为（被推下），非角色主动选择
4. **禁止美化复仇暴力**：打脸场景以实力碾压为主，不得出现虐待、酷刑式描写
5. **禁止色情擦边**：感情线以含蓄为主，不得出现亲密接触暗示

### 灰区处理策略

| 灰区 | 预定处理方式 |
|------|------------|
| 修为废除/跌落 | 以"灵力消散"光效表现，不出现肉体痛苦特写 |
| 角色死亡 | 以"化为光点消散"为主，避免直接死亡画面 |
| 魔化变身 | 面部变形以暗影/光效遮挡为主，不出现恐怖妆效 |
| 上界殖民叙事 | "养蛊场"为世界观设定，不与现实政治类比 |

### 正向价值锚点

1. **不屈不挠**：主角从废材到守护者的成长，强调坚持与努力
2. **信任与牺牲**：萧长老、月姬、父亲的牺牲体现无私守护精神
3. **正义终将胜利**：所有反派终被清算，善恶有报的价值观

### 平台审核重点提示（前3集）

- **EP01**：当众羞辱场景注意措辞分寸，不得使用人身攻击类脏话
- **EP02**：坠崖场景不得展示直接坠落撞击画面，以飞坠+黑屏转场处理
- **EP03**：吞噬灵兽场景注意动物保护敏感性，灵兽为"灵力构成"非真实动物
