# 第1集《替嫁》分镜表 + AI 视频提示词

> 用途：实拍分镜、剪映参考，或投喂 Runway / Pika / 可灵 / 即梦 等文生视频工具。  
> 建议画幅：**9:16 竖屏短剧** 或 **2.35:1 电影横屏**（下表默认 9:16，横屏时在提示词中加 `wide cinematic 2.35:1`）。

## 统一设定（复制到每条提示前）

- **时代气质**：架空晚唐至宋风之间，服饰华丽但不魔幻；无手机、无现代物。  
- **女主**：沈晚 / 沈知微，二十五六，冷静倔强，现代灵魂；可略区别于纯古代闺秀的眼神。  
- **肃王**：萧承渊，三十前后，玄色或深青锦袍，战将气质，寡言冷面。  
- **负面提示（英）** `negative prompt`：`modern objects, smartphone, watch, glasses, cartoon, anime, low resolution, deformed hands, extra fingers, text watermark, logo`

## 首集节奏建议（总长约 120–180s）

- **0–15s**：强冲突（强嫁 + 盖头）  
- **15–45s**：王府门前身份落差 + 对峙  
- **45–75s**：新房密闭 + 锁门  
- **75–90s**：窗影钩子 + 下集预告字卡（可选）

## AI 工具实操备忘

1. **一致性**：同一工具内固定 `seed`；先出关键帧图再图生视频更稳。  
2. **手与脸**：复杂打斗优先剪影/中远景；特写用手部少露全。  
3. **台词**：视频生成后**另轨**配对白与 BGM，口型可用剪映「文本朗读」或后期对嘴。  
4. **合规**：各平台对古装暴力、刑场等有限制，导出前按平台规则微调画面。
