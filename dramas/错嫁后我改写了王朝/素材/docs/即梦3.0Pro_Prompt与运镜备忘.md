# 即梦视频 3.0 Pro — 官方要点备忘（摘自火山文档）

> 对应能力：**文生视频**、**图生视频-首帧**；支持 **1080P**；强调 **多镜头叙事**、指令遵循、动态流畅。  
> 完整文档以火山控制台「即梦AI-视频生成3.0 Pro」为准，本文只保留**写提示词时立刻用得上的部分**。

---

## 和你当前流程怎么配合

- **剧本**：仍在仓库 `对白/`、Cursor 里改；**不要指望接口「导入剧本」**。
- **即梦**：每次提交的是 **一条（或一段）视频提示词**；有首帧图时用 **图生视频-首帧** 更稳。
- **对白**：成片时在剪映加字幕；即梦侧 **尽量避免让画面里出现清晰可辨的汉字**（官方说明：不适用于精准生成文字）。

---

## 提示词怎么写（官方结构）

1. **基础**：`主体 + 背景 + 镜头 + 动作`
2. **多镜头一条里讲完**：`镜头1 + 主体 + 动作1 + 镜头2 + 主体 + 动作2 …`（适合 3.0 Pro 强调的「多镜头叙事」）
3. **连续动作**：
   - 同一主体：`主体 + 运动1 + 运动2`
   - 多主体：`主体1 + 运动1 + 主体2 + 运动2`

---

## 运镜用词（可直接中英混用，以中文为主）

| 意图        | 可写                                |
| ----------- | ----------------------------------- |
| 切镜        | 镜头切换                            |
| 平移        | 镜头向上/下/左/右移动               |
| 推拉        | 镜头拉近 / 镜头拉远                 |
| 环绕/大场景 | 镜头环绕、航拍、广角、镜头360度旋转 |
| 跟拍        | 镜头跟随                            |
| 稳          | 固定镜头、镜头静止不动              |
| 特写        | 镜头特写                            |
| 手持感      | 镜头晃动、手持拍摄、动态不稳定      |

**程度**：快速、大幅度、高频率、剧烈、缓缓 —— 用来控制动作强弱。

---

## 使用注意（避免踩坑）

- **画面内文字**：尽量不依赖视频里生成标题、对联、圣旨小字；需要字用 **剪映字幕**。
- **风格**：可在句尾加「古风写实」「电影感」「竖屏」等，与项目 `video/第01集_分镜与AI视频提示词.md` 一致。
- **先试短再加长**：仍建议单条先生成 **5～10 秒**，满意再叠「多镜头」描述。

---

## 与仓库内试跑文件的关系

- 短句试跑：`video/第01集_试生成4段_复制提示词.md`
- 可把每条改成「**镜头 + 主体 + 动作**」顺序；若 3.0 Pro 支持一条多镜，再试合并为「镜头1…镜头2…」一条提交。
