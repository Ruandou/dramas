## PROP-001 · 弹幕浮层（核心视觉符号）

| 字段 | 内容 |
|------|------|
| ID | `PROP-001` |
| 道具名 | 弹幕浮层 |
| 持有者 | 全体人物头顶（跨全体角色/全场景） |
| 首次出场 | EP01 |
| 说明 | 全剧标志性视觉符号：人物头顶漂浮的半透明发光心声弹幕文字 |
| 叙事功能 | 核心能力可视化；常规青蓝/谎言红/残留暗金/超载刷屏/盲区留白五态；推动全剧打脸、甜宠、悬疑 |
| 关联场景 | 全部场景（跨场景） |
| 参考图 | **⏭️ 跳过实拍出图**（判定为后期 ffmpeg/浮层特效实现，非实体道具、非 Seedance 烧录）——prop-designer 不产出 Seedream 图/不上传 TOS/不入 batch YAML；权威样式规范见下方样式规范块 + 制片规范 §二 |
| ⚠️ 中文文字 | **是** — Prompt 需含 `Simplified Chinese`；圆润现代黑体/UI 字体，白色描边，半透明发光。常规 `#5FD6E8`、谎言 `#FF5A5A`、残留 `#C9A24B` |

> **⏭️ prop-designer 决策（Stage 3a）：跳过实拍参考图生成 — 判定为「后期浮层实现」**
> **理由**：
> 1. **非实体道具**：弹幕浮层是人物头顶漂浮的半透明发光文字，本质为屏幕合成图形，不存在物理实体，不适用「单物体 + 丝绸背景」产品摄影范式。
> 2. **制片规范已定义为后期实现**：§二明确「弹幕浮层**不由 Seedance 视频生成烧录**，而在**后期以 ffmpeg / 浮层合成**统一叠加」；§六 negative_prompt 亦禁止 Seedance 烧录任何弹幕/字幕文字。因此不进入 Seedance `image_urls` 锚定链路，无需独立参考图。
> 3. **Seedream 中文渲染不可靠**：5 态多色简体中文弹幕样张若交由 Seedream 出图，极易乱码/出繁体，无法作为可信生产资产；真正的浮层由 ffmpeg drawtext / ASS 字幕样式用真实字体实现。
> 4. **权威样式规范已存在于制片规范 §二**（字体/颜色/描边/漂浮质感/5 态表），本卡片下方补充可直接供后期使用的排版规范（typography spec），无需图片。
>
> **弹幕样式规范（供后期 ffmpeg / ASS 使用 · typography spec）**
> - **字体**：圆润无棱角现代黑体 / UI 字体（如思源黑体 Bold / 阿里巴巴普惠体），简体中文（**Simplified Chinese**）。
> - **描边**：2–3px 纯白描边（`#FFFFFF`）增强可读性；外发光柔光 4–6px。
> - **透明度/质感**：主体 80–90% 不透明，半透明发光，微微上下浮动（漂浮动画）。
> - **位置**：人物头顶上方约「一拳」高度（prompt_suffix 已为视频预留 headroom）。
> - **5 态配色**：常规 `#5FD6E8`（荧光青蓝）/ 谎言 `#FF5A5A`（警示红，说谎时转红+轻微抖动）/ 残留 `#C9A24B`（暗金，附着物品/场所的陈旧字迹，边缘模糊）/ 超载（满屏白色高速刷屏 + 画面偏白）/ 盲区（头顶留白，无弹幕）。
> - **实现方式**：后期 ffmpeg drawtext 或 ASS 字幕轨逐镜叠加，不生成 Seedream 图、不上传 TOS、不入 batch YAML。
