## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个视觉不同角色独立 ID + L01 |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**；**只增不删**，弃用标 `deprecated: true`。
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象。
- L01 = 全剧面部一致性的**唯一锚点**；L02+ 衍生形象必须 `based_on` 本角色 L01，禁止跳过 L01。
- 群演按需创建、不设上限；同一 `CHAR-GRP-##` 可跨集复用，但不同视觉角色不可共用 ID。
- CHAR-ID 分配权归 production-planner；character-designer 不可自行新增。

## 二、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于大纲「视觉风格锚点」节。

| 维度 | 规格 |
|------|------|
| 渲染风格 | 都市写实生活质感（photorealistic urban realism）+ 轻奇幻信息浮层 |
| 镜头参考 | cinematic，对话戏面部特写抓微表情（85mm 质感）；甜宠戏浅景深；超载戏旋转失焦 |
| 色调方向 | 高明度日常暖色为主 + 弹幕荧光青蓝对比；职场冷白荧光；黑科技低饱和科技冷蓝；车祸/回忆低饱和阴雨滤镜 |
| 画幅 | 9:16 vertical（竖屏） |
| 题材关键词 | urban realism, warm daily tone, soft neon UI overlay, cinematic close-up, shallow depth of field |

### 核心视觉符号：弹幕浮层（全剧标志性视觉 · PROP-001）

> **实现方式**：弹幕浮层**不由 Seedance 视频生成烧录**，而在**后期以 ffmpeg / 浮层合成**统一叠加于成片。Seedance 阶段仅生成人物"抬头留白/头顶上方空间"的构图，为后期弹幕预留位置。prop-designer 产出的是**弹幕样式规范图**（字体 / 颜色 / 描边 / 漂浮质感样张），非 Seedream 场景参考图。

| 弹幕类型 | 颜色 | 视觉规格 | 解锁阶段 |
|----------|------|----------|----------|
| 常规弹幕 | 荧光青蓝 `#5FD6E8` | 半透明、微微浮动、字号小巧，飘于人物头顶上方约一拳位置 | EP01 起 |
| 谎言弹幕 | 警示红 `#FF5A5A` | 说谎时转红并轻微抖动 | EP23 起（EP08 萌芽征兆：一闪微红） |
| 残留弹幕 | 暗金 `#C9A24B` | 附着物品/场所的陈旧字迹，半透明、边缘模糊 | EP51 起（EP30-45 需埋前置伏笔，见 R1 约束4） |
| 超载 | 偏白晕眩 | 满屏弹幕高速刷屏 + 画面偏白 + 耳鸣式音效 → 头痛/短暂失明 | EP05 起 |
| 盲区 | 头顶留白 | 在意之人 / 陆时头顶"空无一物"，用"空"制造心动与悬疑 | EP01 起 |

- **字体规范**：简体中文（Simplified Chinese），圆润无棱角的现代黑体/UI 字体，白色描边增强可读性，半透明发光质感。
- **弹幕文字为简体中文**，后期合成时统一处理，**Seedance 不烧录任何弹幕/字幕文字**（见 negative_prompt）。

| 参数 | 值 |
|------|-----|
| model | `doubao-seedance-2-0-fast-260128` |

### prompt_suffix（全局追加）

```
cinematic urban realism, natural soft lighting, shallow depth of field, vertical 9:16 composition, high detail, professional color grading, modern city of 2026, leave headroom space above characters' heads
```

> 末尾 `leave headroom space above characters' heads` 为**本剧专属**：为后期弹幕浮层预留头顶空间。

### negative_prompt（全局）

**结构性约束（年代/题材 + 迷信禁忌 + 弹幕后期）——由 production-planner 定义，不可删改：**

```
ancient costume, historical/dynasty setting, palace, sci-fi mecha, spaceship, weapons of war,
ghost, spirit, apparition, phantom, soul, undead, ectoplasm, seance, incense ritual, religious altar, supernatural haunting,
exposed real brand logos, watermark, burned-in subtitles, floating on-screen text, danmaku text baked into video, garbled text, warped characters,
lowres, blurry, deformed hands, extra fingers, extra limbs, distorted face, low quality
```

> - **年代约束**：本剧为现代都市（2026 架空"临江市"），禁止一切古装/朝代/宫廷/太空/战争元素。
> - **迷信禁忌（★ R1 强制）**：禁止一切"亡魂/灵异/招魂/幽灵/超度/阴魂/显灵/祭坛/招魂仪式"等封建迷信视觉与语感（详见 §十 内容合规参数）。
> - **弹幕后期**：Seedance 视频**禁止烧录**任何弹幕/字幕/浮层文字，弹幕由后期统一合成。
> - 创意领域 negative_prompt（如"禁止动漫风格 / 禁止过曝"等美学取向）由 character/scene/prop-designer 各自补充。

## 七、分段（Segment）规则 —— AI 生成单位

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 |
| 最小叙事单位 | 1 个完整 beat | 每段必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段（EP01 可至 12） | 见 episode_profile |
| 每集镜头数 | 8–12 镜 | |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词落在同一段内）。
2. **不得**在连续动作进行中切断（开门、摘道具、递照片等动作链一条 segment）。
3. 拆段边界：场景切换、主说话人切换、情绪断点。
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`。
5. 分镜表里某镜自然时长 < 4 秒 → 并入同场景相邻段。

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）。
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）。
- 同一场景**可**含多个 segment；segment **不得**跨场景。

### 分集剧本格式

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注。
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行。
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`。

## 九、音色规范

- 每个有对白角色（含 CHAR-GRP-##）必须有 `voice_prompt`，格式：`「性别，年龄，音色特征，语速，情绪基调/说话习惯」`。
- 权威来源 = `资产/声音卡片.md`（P0）。同一角色跨 segment 的 voice_prompt 必须**全文一致**。
- 旁白不分配 CHAR-ID，写为「旁白」，voice_prompt 独立定义。
- Seedance `generate_audio: true` 合成基础环境音；特殊音效（敲门声、紧张弦乐、超载耳鸣等）后期叠加。
- 字幕后期添加（ffmpeg），Seedance 不烧录字幕。

## 十、内容合规参数

### 题材合规等级

- **🟢 C 级**（其他微短剧，<30 万，平台自审）。能力设定为"神念脑科技脑洞"，**非封建迷信**；核心导向为都市情感与轻喜；反派正法点到为止、交由监管/伦理机构，不渲染司法/公安细节。

### ★ 本剧特定红线（R1 强制 · 迷信语感用词红线）

> **来源**：script-reviewer R1 审查下游约束（工作计划.md R1-1）。**必须落实到 scene-writer / character-designer 全部下游产出**。

1. **陆星「残留意识」相关设定，全程以「神念数据化意识片段」等科技化用词锚定。**
2. **禁止使用以下迷信语感词汇**（在对白、旁白、画面描述、道具说明中一律禁用）：
   `亡魂 / 灵异 / 招魂 / 安息 / 幽灵 / 鬼魂 / 超度 / 阴魂 / 显灵 / 阴间 / 转世 / 附身 / 通灵`
3. **推荐替代用词**（科技化锚定）：
   | 迷信语感（禁用） | 科技化替代（推荐） |
   |------------------|---------------------|
   | 陆星的亡魂/鬼魂 | 陆星的神念数据化意识片段 / 残留念头数据 |
   | 招魂 / 通灵 | 意识片段读取 / 神念信号解析 |
   | 让陆星安息 | 释放/归档陆星的意识片段数据 / 数据片段消散归零 |
   | 附身在顾晚头顶 | 意识片段承载/寄存于顾晚的神念信道 |
   | 超度 / 显灵 | 数据释放 / 信号浮现 |
4. **注意**：大纲原文中"放陆星安息""陆星安息"（EP61/EP65）等表述属于 R1 预警的迷信漂移风险点，scene-writer 落集时**必须**改写为科技化用词（如"释放陆星的神念数据片段""让这段意识数据归于平静/消散"）。
5. 本红线已同步写入相关角色卡（`CHAR-002` 陆时、`CHAR-008` 程野、`CHAR-009` 陆星）的合规提示节。

### 灰区处理策略

| 灰区 | 处理方式 |
|------|----------|
| "读心/心声"能力 | 全程锚定为"神念脑波科技/黑科技实验"产物，非超自然；出现能力时用科技化解释 |
| 非法人体实验 | 作为反派罪行被批判、被正法；不展示血腥手术细节，点到为止 |
| 车祸/伤害 | 冷开场车祸不渲染血腥；以命运转折与悬疑呈现 |
| 反派正法 | 交由监管/伦理机构依法处理，不渲染公安/司法程序细节 |

### 正向价值锚点

1. **真诚与信任**：结局"看不见彼此的心，却愿意用一生去相信"——推崇纯粹信任而非算计。
2. **职场正道**：顾晚终以真本事逆袭（EP69），传递"靠实力而非投机"。
3. **人性可赎与放下执念**：白露赎罪被原谅；程野"失女执念"作反面警示——执念伤人伤己。

### 平台审核重点提示（前 3 集）

- EP01：车祸冷开场——弱化血腥，突出"能力觉醒"脑洞；周延背叛为情感冲突非低俗。
- EP02–03：职场抢功/甩锅——批判虚伪，导向正能量打脸，不渲染恶意。
- 全程：弹幕能力科技化锚定，前 3 集即建立"神念脑科技"世界观，杜绝迷信联想。
