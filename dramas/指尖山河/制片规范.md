## 二、视觉规范

### 2.1 视觉风格锚点

| 维度 | 设定 |
|------|------|
| **渲染风格** | **写实主义（Photorealism）**——全部角色/场景/道具采用照片级写实风格，禁止插画/卡通/3D渲染风格混入 |
| **色彩基调** | 暖金 + 墨绿 + 檀木棕 + 苏绣丝线五彩（绯红/靛蓝/鹅黄/月白/墨黑） |
| **光影风格** | 自然光为主，室内暖光（2700K-3200K），绣房窗棂透光有丁达尔效应，徽派建筑阴影柔和 |
| **质感重点** | 丝绸光泽度、刺绣丝线微距细节、古木纹理、徽派白墙斑驳质感 |
| **镜头语言** | 浅景深特写（刺绣细节）、中景（人物互动）、广角（徽派村落全景） |
| **画面比例** | 9:16（竖屏） |
| **分辨率** | 1080×1920（竖屏） |

### 2.2 Seedance / Seedream 模型配置

| 参数 | 值 |
|------|-----|
| **Seedance 模型** | `seedance-v2.5` |
| **Seedream 模型（参考图生成）** | `seedream-v3` |
| **参考图分辨率** | 1024×1024（1:1，竖屏裁剪时用 9:16） |
| **视频分辨率** | 1080×1920（9:16 竖屏） |
| **帧率** | 24fps |

### 2.3 Prompt 规范

#### prompt_suffix（追加到所有图片生成 prompt 末尾）
```
photorealistic, cinematic lighting, warm tones, 8k resolution, highly detailed textures, natural skin texture, soft natural light, professional color grading, depth of field
```

#### negative_prompt（所有图片生成共用）
```
anime, cartoon, illustration, 3d render, plastic skin, overexposed, neon lighting, cyberpunk, modern skyscrapers, western architecture, text watermark, signature, low quality, blurry, distorted face, extra limbs, mutated hands, bad anatomy
```

#### 年代禁忌提示词（追加到 negative_prompt）
```
modern electronics, smartphones unless specified, modern cars in village scenes, satellite dishes, plastic furniture, LED lights in traditional settings
```

## 三、ID 系统规范

### 3.1 命名空间

| 前缀 | 类型 | 格式 | 示例 | 说明 |
|------|------|------|------|------|
| CHAR- | 角色 | CHAR-### | CHAR-001 | 三位数字，主角从 001 起。**ID 只增不删**，弃用标 `[已弃用]` |
| CHAR-GRP- | 群演/背景角色 | CHAR-GRP-### | CHAR-GRP-001 | 三位数字，有台词或互动的背景角色 |
| SCENE- | 场景 | SCENE-### | SCENE-001 | 三位数字 |
| PROP- | 道具 | PROP-### | PROP-001 | 三位数字 |
| LOOK | 角色形象 | CHAR-###-L## | CHAR-001-L01 | L01=基础形象，L02+=衍生形象（换装/年龄变化） |

### 3.2 episode_profile

| 参数 | 设定 |
|------|------|
| **每集时长区间** | 90-120 秒 |
| **EP01 特殊** | 90-120 秒（与常规一致，但 Segment 数稍多） |
| **常规集 Segment 数** | 6-10 段 |
| **EP01 Segment 数** | 10-12 段 |
| **单段时长区间** | 4-12 秒 |
| **台词字数密度** | 硬带 [210,330] 字/分钟（90s 集 ≥315 字，120s 集 ≥420 字；v2.0 基准，原行数口径已废） |
| **对白占比最低** | 对白行数 ÷ 全部 spoken lines ≥ 85%（v2.0 基准） |
| **说话角色数最低** | ≥ 2 个不同 CHAR-ID |
| **潜台词** | 关键冲突/情感戴面具场景携带潜台词（定性，v2.0 删除 30% 比例） |

### 3.3 分段规则

- 一个 Segment = 同一场景（SCENE-###）内连续的一组镜头
- 场景切换 → 必须新建 Segment
- 每个 Segment 时长：4-12 秒
- 时长不达标时优先拆分/合并 Segment，禁止微调秒数凑时长

## 六、制作复杂度预算

| 维度 | 评估 | 说明 |
|------|------|------|
| 场景数量 | 中（13个） | 3个城市（上海/云溪村/巴黎），需管理三种视觉体系 |
| 角色数量 | 中（12个说话角色） | 核心角色4人，其余配角 |
| 道具复杂度 | 高 | 刺绣细节需大量特写，高定时装需单独设计 |
| 特效需求 | 低 | 主要靠实拍级写实，无需CG特效 |
| 外景比例 | 中（~40%） | 云溪村外景为主，天气/光线需统一 |
| 服装造型 | 高 | 女主多套时装+高定礼服，需 Look 衍生 |
| **总复杂度** | **中高** | 建议优先完成云溪村场景组，再扩展上海和巴黎 |
