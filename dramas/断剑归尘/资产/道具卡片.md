## PROP-001 · 断剑·归尘

| 字段 | 值 |
|------|-----|
| 道具名称 | 断剑·归尘 |
| 道具类型 | 武器/核心 |
| 首次出场 | EP01 |
| 出场集数 | EP01-EP09, EP14, EP23（重铸） |
| 持有者 | CHAR-001 沈璃音 |

### 描述
沈璃音的本命灵剑，全盛时期剑身通体银白，灵力流转如星河。EP01 中因散功而碎裂，仅剩半截剑身和剑柄。碎裂后凤鸣残魂沉睡其中。EP23 重铸为新剑。

### 视觉关键词
- 完整态：银白剑身、灵力星河纹路、剑柄刻"归尘"二字
- 碎裂态：半截残剑、裂纹遍布、灵光明灭不定

### Prompt 模板（碎裂态）
```
A broken ancient Chinese sword, only half the blade remaining, silver-white metal with visible cracks, faint flickering spiritual light along the blade edge, an ornate hilt with the characters "归尘" carved on it, xianxia weapon, mysterious and melancholic atmosphere
```

```

```
