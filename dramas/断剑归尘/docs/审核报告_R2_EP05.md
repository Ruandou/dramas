## Top 3 问题（按严重程度排序）

### 问题 1：SEG02 仍为纯氛围段落，戏剧张力为全集最低
- **位置**：SEG02（第 54-67 行），11s
- **问题描述**：首审建议合并 SEG02-03 并引入视觉突发事件。修订后 SEG03 已新增微钩（暗金色残剑亮一瞬 + 断剑低吟），但 SEG02 本身未做任何修改——仍为纯观察性对白（"这些剑都还有残余剑气"、"万年前它们都是名剑"、"剑意还在，只是主人不在了"）。11s 内无冲突、无视觉事件、无情绪冲击。在 SEG01 已建立"我们到了"前提、SEG03 已有微钩的情况下，SEG02 成为两段钩子之间的"过渡走廊"。幸而 11s 时长较短且前后均有钩子，不构成安全滑走点（观众不会在 11s 内滑走），但它是全集节奏最弱的一环。
- **影响维度**：观众留存（轻微）
- **建议修改**：不改结构。仅在 SEG02 沈璃音的"剑意还在，只是主人不在了"之后加一个视觉微事件：她手指拂过残剑时，残剑上残留的剑气轻轻割破她指尖——一滴血落在枯骨上，瞬间被吸收。裴衍注意到但没有说话。这个 2-3s 的视觉细节（无需新增对白）同时完成三件事：①制造微紧张（"这些残剑仍有杀伤力"），②暗示"枯骨在吸收生命"（为石棺悬念铺路），③强化沈璃音"凡人肉体"的脆弱感。
- **优先级**：🔵 优化项（非阻断）

### 问题 2：SEG07-08 信息密度偏高，"剑心"概念缺乏情感锚点
- **位置**：SEG07（第 134-147 行）+ SEG08（第 150-165 行），合计 23s
- **问题描述**：这两个 segment 密集引入三个核心概念——"剑心未灭"（SEG07-08）、"碎骨为基，凤凰火为引"（SEG08）、"石棺符文异常"（SEG08 微钩）。信息量足够，但情感冲击弱于 SEG06（凤鸣苏醒）和 SEG11（决心宣言）。凤鸣的"心，是剑的根。骨碎了不算什么"和"剑心在，根就在"是格言式对白，观众接收的是"知识"而非"感受"。SEG08 的微钩（石棺符文闪暗金光 + 凤鸣火焰缩小）是出色的悬念装置，但它服务的是 SEG14 的远端悬念，对当前段落的情绪提升有限。整体而言，这两段是从 SEG06 高潮到 SEG09-11 上升段的"平台期"——不凹陷但也不爬升。
- **影响维度**：情绪收益（轻微平坦风险）
- **建议修改**：在 SEG07 凤鸣说出"剑心还在"后，加入一个沈璃音的**生理反应**镜头——她下意识握紧断剑剑柄，手指因激动而微微发颤，眼眶泛红但强忍。这不需要新增对白（可用镜头描述替代），将"知道剑心还在"从知识变为情感冲击。或者：让沈璃音在 SEG08 凤鸣说"你的路才刚开始"后，低声说一个字："……真的？"——一个极简的质疑/渴望，比沉默更能传递内心波澜。
- **优先级**：🟡 建议项（提升情绪曲线中段弧度）

### 问题 3：CHAR-001-L02 缺 CDN URL，全 14 个 segment 均受影响
- **位置**：全集所有 segment 的 shots.yaml 和 segments.yaml
- **问题描述**：shots.yaml 和 segments.yaml 中每个 segment 均标注 `CHAR-001-L02: assets/looks/CHAR-001-L02.png  # WARNING: no CDN URL`。沈璃音是全集 14 个 segment 的核心出镜角色，缺少 CDN URL 意味着 Seedance 生成时无法从云端拉取参考图，可能导致角色一致性降低或生成失败。这是管线技术问题而非剧本问题，但其影响范围覆盖全集——如果 L02 参考图质量低于其他 CDN 资产，沈璃音的视觉一致性将成为全集最大制作风险。
- **影响维度**：制作可行性（管线风险）
- **建议修改**：在进入 G5 segment-builder 前，将 CHAR-001-L02.png 上传至 TOS 并获取永久 CDN URL。确保 URL 不含 `X-Tos-Expires` 临时签名参数（与 CHAR-002-L01、CHAR-006-L01 等已入库资产保持一致标准）。
- **优先级**：🔴 必修项（阻断 G5 推进直到解决）
