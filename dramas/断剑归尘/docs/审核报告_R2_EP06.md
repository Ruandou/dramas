## Top 3 问题（按严重程度排序）

### 问题 1：CHAR-001-L02 PNG 缺失——全集主角 fallback 至 L01 形象

- **位置**：EP06_shots.yaml / EP06_segments.yaml 全部引用 CHAR-001-L02 的镜头
- **问题描述**：`assets/looks/` 目录下仅有 `CHAR-001-L01.png`（天剑宗剑尊形态：白色仙袍、银色发冠），无 `CHAR-001-L02.png`（凡人形态：素色麻布衣、简朴束发）。EP06 全部 10 个涉及沈璃音的 Segment 均标注 `CHAR-001-L02`，但 YAML 中反复出现 `⚠️ WARNING: L02 CDN URL missing, using L01 as fallback`。L01（仙袍银冠）与 L02（素衣麻布）在视觉风格上差异极大——使用 L01 作为 fallback 会导致 Seedance 生成一个穿着华丽仙袍的角色在幽谷中练剑，严重破坏场景叙事逻辑。
- **影响维度**：视觉资产（-1），制作可行性（潜在生成错误）
- **建议修改**：
  1. 使用角色卡片中 CHAR-001-L02 的 Seedream Prompt 生成 `CHAR-001-L02.png` 并上传至 CDN
  2. 更新 `cdn_urls.json` 和各 YAML 文件中的 look_urls
  3. **此修复应在 G5 segment-builder 执行前完成**，否则所有沈璃音镜头的角色形象将出错

### 问题 2：segments.yaml 存在 2 处文字转录错误（"纯净"→"纯渑"）

- **位置**：EP06_segments.yaml 第 462-463 行（EP06-SEG13 对白）
- **问题描述**：凤鸣在 SEG13 的两句台词中，"纯净"被误写为"纯渑"：
  - 错误：`"没有一丝灵力杂质……纯渑得像山泉。"`
  - 正确（与 .md 源文件一致）：`"没有一丝灵力杂质……纯净得像山泉。"`
  - 错误：`"万年前那位剑修……他的剑气也未曾这般纯渑。"`
  - 正确：`"万年前那位剑修……他的剑气也未曾这般纯净。"`
  
  源文件 `.md` 中为正确的"纯净"，但 segments.yaml 在转录过程中引入了错别字。此错误将直接影响语音合成（TTS 可能将"纯渑"读为 chún miǎn 而非 chún jìng），导致高潮段落的语音输出错误。
- **影响维度**：对白工艺（高潮段落的语音准确性），制作可行性（YAML-源文件忠实度）
- **建议修改**：将 segments.yaml 第 462 行和第 463 行的"纯渑"替换为"纯净"。

### 问题 3：SEG12 断剑位置描述歧义

- **位置**：EP06 剧本 SEG12 镜头描述（第 251 行）
- **问题描述**：镜头描述写道"裴衍靠在竹屋门柱上远望，**腰间断剑插在石缝中**，凤鸣的声音从剑中偶尔传出。"这句话存在语法歧义——"腰间断剑"暗示断剑在某人腰间，但"插在石缝中"暗示断剑插在石头缝隙里。两者不可能同时成立。根据上下文（沈璃音持凡铁剑在溪畔练剑），断剑应被放置在一旁石缝中，凤鸣从剑中观察。但"腰间"一词造成混淆——读者可能误读为"裴衍腰间的断剑"或"沈璃音腰间的断剑"。
- **影响维度**：制作可行性（镜头指令歧义可能导致 Seedance 生成错误的道具位置）
- **建议修改**：改为"裴衍靠在竹屋门柱上远望，**断剑插在一旁石缝中**，凤鸣的声音从剑中偶尔传出。"——删除"腰间"，增加"一旁"明确空间关系。
