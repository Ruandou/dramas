## 二、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可 |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨 segment 出现 → 独立 CHAR-###；纯背景无台词 → CHAR-GRP

### 形象层级结构

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

## 七、分段规则

### Segment 约束

| 约束 | 值 | 说明 |
|------|---|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | EP01 可至 12 段，参见 episode_profiles |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 九、音色规范

> 完整 voice_prompt 定义见 `资产/声音卡片.md`（P0 权威来源）。

### 格式要求

```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

### 一致性规则

- 同一角色跨 segment 的 `voice_prompt` 必须**全文一致**
- voice_prompt 必须**全文复制**（含引号「」内全部文字），禁止缩写、改写、翻译、简化
- `资产/声音卡片.md` 为 P0 最高权威，优先于角色卡片和制片规范中的音色描述

### 旁白与音效

- 旁白角色不分配 CHAR-ID，写为「旁白」，voice_prompt 独立定义
- 分集剧本镜头表中标注音效（如 `冰裂声`、`灵力嗡鸣`、`剑鸣声`）
- Seedance `generate_audio: true` 合成基础环境音；特殊音效后期叠加
- 字幕后期添加——Seedance 不烧录字幕，通过 ffmpeg 统一处理

## 内容合规参数

### 题材合规等级

**B级**（仙侠题材，需注意以下事项）

### 本剧特定红线

1. **禁止真实宗教引用**：不使用佛教、道教等真实宗教术语（如「佛祖」「道祖」），所有修炼体系必须为架空设定
2. **暴力尺度控制**：战斗场景不得出现断肢、内脏外露等极端画面；角色死亡以灵力消散/倒地暗示为主
3. **禁止色情/擦边**：角色服饰不得过度暴露；亲密场景仅限握手、对视级别
4. **禁止封建糟粕美化**：不美化一夫多妻、奴隶制度等；本剧设定为女修主导社会，需注意性别平等表达
5. **不涉及政治敏感**：所有宗门设定为架空，不映射任何现实组织或政权

### 灰区处理策略

1. **「阳绝」设定**：涉及男性灭绝概念→处理为虚构仙侠事件，强调为「反派阴谋」而非自然规律，结局为阴阳共存
2. **夺舍/寄生**：太初真人夺舍赵凌烟→以灵力/神识层面表现，不涉及肉体恐怖；赵凌烟灵魂获救作为正面收束
3. **身份伪装（男扮女装）**：苏尘伪装为女修→喜剧化处理，强调生存需要而非性别歧视；不以此制造性别对立
4. **修炼/功法体系**：保持完全架空，不使用真实武术/气功名称

### 正向价值锚点

1. **智慧与勇气**：苏尘以智谋而非蛮力解决困境，传递「以智取胜」的正向价值
2. **信任与合作**：从孤军奋战到团队协作，强调信任和联盟的力量
3. **平衡与共存**：最终结局为阴阳共存的新秩序，传递包容与平衡的理念

### 平台审核重点提示

- **EP01–EP03**：苏尘男扮女装入城→确保喜剧化处理，不引发性别争议；验灵石场景不涉及身体检查
- **EP01–EP03**：冰棺苏醒场景→避免恐怖/惊悚氛围过度，以神秘感为主
- **EP10**：赵凌烟体内阳气→以灵力/法术层面表现，不涉及身体改造的恐怖描写
