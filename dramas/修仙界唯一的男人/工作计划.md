# 工作计划 · 《修仙界唯一的男人》

## 项目概念

- **标题**：修仙界唯一的男人
- **题材**：仙侠 / 生存 / 权谋
- **核心钩子**：千年沉睡后醒来，修仙界的男人都死光了，我是唯一剩下的一个
- **目标受众**：男性 18-35，生存压力 + 权谋博弈 + 隐藏实力
- **合规等级**：🟢 C级（一般仙侠题材，无政治/军事/迷信宣扬）
