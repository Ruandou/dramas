- **核心情绪**：日常平淡 → 自嘲孤独 → 诡异不安 → 恐惧紧张 → 神秘震撼 → 困惑觉醒
- **光线**：清晨暖光（SEG01-02）→ 午后自然光（SEG03-04）→ 黄昏橘红（SEG05-06）→ 暗夜手机光（SEG07-09）→ 金色虚空光（SEG10-11）→ 月光冷白（SEG12-13）→ 医院荧光灯+月光（SEG14-15）
- **秦风造型**：蓝色外卖服（CHAR-001-L01），袖口卷起，头发有点乱，电动车钥匙挂在腰间
- **音乐**：轻快吉他（SEG01-03）→ 口琴/民谣（SEG04孤独感）→ 悬疑低频（SEG05-06）→ 紧张弦乐渐强（SEG07-08）→ 冲击音效+耳鸣（SEG09）→ 宏大钟声+空灵pad（SEG10-11）→ 沉寂（SEG12-13）→ 心跳声+悬疑弦乐（SEG14-15）
- **节奏**：平稳→平稳→渐紧→骤变→爆发→余韵；高潮在SEG09-10（车祸+声音），收尾在SEG14（苏醒）
- **关键细节**：
  - 外卖箱是秦风的"武器"和标志，全集不离身
  - 手机是连接凡间与三界的道具——EP01中手机屏幕出现金色文字（后期合成）
  - 废弃工厂是觉醒的"祭坛"——不是随机地点，后续会揭示是三界交汇点
  - 秦风瞳孔中闪过的金光 = 前世债主之力开始觉醒的视觉信号
  - 孤儿院照片 = 建立他没有家人、没有背景、一切靠自己的核心人设
- **特殊镜头说明**：
  - SEG11（S17）使用 `t2v` 模式——纯神话闪回画面，无需角色参考图
  - SEG13（S19）使用 `t2v` 模式——无角色出镜的俯瞰全景
  - 金色文字和瞳孔金光均为**后期合成**，Seedance Prompt 中不描述文字内容
