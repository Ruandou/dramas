## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 道具     | `PROP-###`                        | `PROP-001`        | 外卖箱、天庭通行证、债簿等       |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再建 `L01` 基础形象于 `资产/形象索引.md` + `角色卡.md`
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨segment出现→独立CHAR-###；纯背景无台词→CHAR-GRP

### 1.1 形象 ID 与基础 / 衍生

| 后缀     | 名称     | 要求                                                              |
| -------- | -------- | ----------------------------------------------------------------- |
| **L01**  | 基础形象 | 完整定妆 Prompt（脸、体型、发式、默认服装）；全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | **必须** `based_on` 本角色 `L01`；Prompt 只写差异（delta），并含 `same face as CHAR-xxx-L01` |

## 三、肖像与法务 / 年代与美术

### 3.1 时代背景

- **年代**：现代都市（2020年代） + 架空神话空间（天庭/地府/西天/月宫）
- **地点**：虚构的中国城市 + 三界神话场景
- **核心场景**：城市街头/外卖路线、医院、出租屋、写字楼（凡间）；天庭宫门/凌霄宝殿（天界）；地府大殿（冥界）；月宫、瑶池、西天佛殿（仙境）

### 3.2 双世界观美术策略

本剧为**现代都市 + 神话幻想**混合题材，需要维护**两套视觉语言**：

| 世界观 | 视觉基调 | 色温 | 适用场景 |
|--------|---------|------|---------|
| **凡间（现代都市）** | 写实、接地气、市井烟火 | 暖黄/自然光 | SCENE-001~004 |
| **三界（神话空间）** | 仙气缥缈、瑰丽壮观 | 冷蓝/金紫/梦幻 | SCENE-005~010 |

**关键规则**：秦风（CHAR-001）无论出现在哪个世界观，**始终穿外卖服**，形成强烈的反差喜感。

### 3.3 肖像与法务

- **禁止**使用真实明星、公众人物肖像
- **禁止**出现真实品牌Logo（外卖平台、手机品牌等需做模糊处理或虚构）
- **建议**：创建虚构的外卖平台名称（如"飞送达"、"快跑外卖"）
- **禁止**使用真实宗教形象作为丑化/恶搞对象——观音、如来等角色需保持**庄严基调**，喜剧效果来自秦风的反差而非对宗教的贬低

### 3.4 题材合规要点

- **讨债主题**：定位为**喜剧/反讽**，核心是"欠债还钱天经地义"的朴素正义观，**不美化非法借贷/高利贷/暴力催收**
- **神话元素**：作为世界观背景设定，核心导向为**都市喜剧/讨债爽文**，非宣扬封建迷信
- **多女主设定**：保持**轻松暧昧**基调，禁止低俗/物化/擦边内容；最终结局秦风谁都没选，回归平凡生活——正向价值观
- **宗教角色（如来/观音/地藏王）**：保持基本尊重，喜剧效果来自秦风的行为反差，**不可丑化佛教形象**

## 六、都市+神话混合美术规范

### 6.1 凡间场景 · 必须体现

- 智能手机（全面屏、现代设计）
- 外卖骑手装备：头盔、外卖箱、骑手服（虚构品牌）
- 现代服饰：T恤、衬衫、牛仔裤
- 城市建筑：写字楼、便利店、住宅小区、废弃工厂
- 交通工具：电动车（秦风标配）、出租车
- 医院：白色病房、输液架、走廊

### 6.2 凡间场景 · 禁止出现

- 古装、兵器、古代建筑（除非角色穿越到凡间且保持神话装扮——此时作为反差喜感）
- 军装、警服、法官袍
- 真实品牌Logo
- 真人明星脸

### 6.3 三界场景 · 必须体现

- **天庭**：云海、金色宫殿、仙鹤、天兵铠甲、琉璃器皿、蟠桃树
- **地府**：幽暗大殿、鬼火、判官笔、生死簿、阴森石壁
- **月宫**：玉兔、桂花树、月光清辉、白玉石阶、仙气缥缈
- **瑶池**：碧波仙池、荷花、云雾缭绕、七彩虹桥
- **西天佛殿**：金色佛光、莲花座、经幡、菩提树

### 6.4 三界场景 · 禁止出现

- 现代物品（电灯、塑料、手机——除非秦风带着手机穿越）
- 清代发式（辫子/旗头）
- 其他朝代混搭（如唐代服饰出现在天庭）
- 真实宗教场所的具体复制（避免对号入座）

### 6.5 Negative Prompt 模板

**凡间场景**：
```
画面质量类（通用）：
blurry, distorted, low quality, watermark, subtitles burned into frame,
anime style, cartoon style, watercolor, oil painting style

年代/题材类（现代都市）：
ancient costume, historical clothing, period costumes, weapon, military uniform,
police uniform, judge robe, real brand logo, real celebrity face,
Qing dynasty hairstyle, queue/bianzi
```

**三界场景**：
```
画面质量类（通用）：
blurry, distorted, low quality, watermark, subtitles burned into frame,
anime style, cartoon style, watercolor, oil painting style

年代/题材类（神话空间）：
modern clothing, smartphone, car, neon sign, concrete building, plastic,
electric light, modern furniture, Qing dynasty hairstyle, queue/bianzi,
real brand logo, real celebrity face
```

**混合场景**（秦风穿外卖服出现在天庭等）：
```
画面质量类 + 仅禁止：
Qing dynasty hairstyle, queue/bianzi, real brand logo, real celebrity face,
blurry, distorted, low quality, watermark, subtitles burned into frame
```
> 混合场景允许秦风的外卖服与神话环境共存——这正是喜剧核心。

## 七、AI 出图/视频衔接

### 7.1 出图流程

1. 定稿 `L01` 参考图 → Character Sheet（正面全身，白底）
2. 衍生形象用图生图 / 角色一致性模型 → **delta Prompt** 仅写服装/道具/妆效差异
3. **禁止跳过 L01 直接生成 L02**
4. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01
5. **跨世界观角色**（如秦风出现在凡间和天庭）：同一 L01，仅背景/环境变化

### 7.2 一致性规则

- 同一角色跨segment的面部特征必须一致
- 使用 `same face as CHAR-###-L01` 锁定面部
- 服装、发型可在L02+中变化，但面部不变
- **秦风的外卖服是全剧视觉锚点**——无论出现在哪个场景，外卖服不变

### 7.3 参考图策略

| 优先级 | 资产类型 | 说明 |
|--------|---------|------|
| P0 | 主角形象（秦风） | 必须保证——他是每集每段的锚点 |
| P1 | 对话角色形象 | 有互动的角色必须锁定 |
| P2 | 场景参考图 | 保证环境一致性（凡间/天庭需分别锁定） |
| P3 | 关键道具 | 有余量时加入 |
| P4 | 次要角色/群演 | 最后考虑 |

**每 segment 最多 6 张参考图**（TOS模式）

### 7.4 参考图管理

- 角色定妆：`assets/looks/CHAR-*-L##.png`
- 场景参考：`assets/scenes/SCENE-*.png`
- 道具参考：`assets/props/PROP-*-*.png`
- 提交方式：TOS 永久图床（有条件时）或 data URI 格式

### 7.5 跨世界观参考图配额分配

由于本剧角色频繁跨越凡间/天庭/地府/仙境，参考图配额需额外考虑：

| 场景类型 | 配额分配建议 |
|---------|-------------|
| 纯凡间（2-3角色） | P0×1 + P1×1~2 + P2×1 = 3~4张 |
| 纯三界（2-3角色） | P0×1 + P1×1~2 + P2×1 = 3~4张 |
| 跨世界观（秦风+神仙） | P0×1 + P1×1 + P2×1（当前世界观场景） = 3张，余量给P3道具 |

### 8.2 常见错误

- 外卖箱在不同镜头间位置不一致或消失

- 秦风的电动车在不同场景中外观变化

### 8.3 分段原则

- 不得在对话中间切断 segment

- 拆段边界：场景切换（凡间↔三界）、主说话人切换、情绪断点
- 世界观切换必须在 segment 边界处完成

## 九、有声段落（Seedance 2.0 · 默认）

### 9.1 段落规则

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 约 12–15 段     | 对应单集 2.5 分钟时长（~150s ÷ ~10s/段 ≈ 15 段）       |

### 9.2 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**
6. **世界观切换**（凡间→天庭等）必须在 segment 边界处完成

### 9.3 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景
- **世界观** = 美术风格单位；同一世界观可包含多个场景

### 9.4 Prompt 结构

```
【图1】角色 ID·角色名（服装描述）【图2】角色/场景 ID【图3】SCENE-###
角色分工：仅图1可[动作]；图2禁止[动作]。
道具：[具体描述，含尺度参考]。
竖屏9比16连贯叙事。
镜头1（Xs）[景别][运镜]：[纯视觉动作描述]
镜头2（Xs）[景别][运镜]：[纯视觉动作描述]
[以下对白仅供语音合成，严禁在画面中显示任何文字]
对白（角色，年龄，情绪）：「台词」
画面全程无任何文字、字幕、标题、水印。
[题材风格描述]，写实风格，竖屏9比16，[负面约束]。
```

### 9.5 content_roles 配置

```yaml
content_roles:
  - { file: CHAR-001-L01, role: reference_image, label: 图1 }
  - { file: CHAR-002-L01, role: reference_image, label: 图2 }
  - { file: SCENE-001, role: reference_image, label: 图3 }
  # - { file: PROP-001-desc.png, role: reference_image, label: 图4 }
```

### 9.6 字幕策略

- Seedance **不烧录字幕**
- 通过 ffmpeg 在后期统一添加
- 字幕样式：白色黑体，底部居中，带黑色描边

### 9.7 音效/配乐标注

- 在分集剧本的镜头表中标注 `音效/配乐` 列
- 格式：`[音效类型]`（如 `电动车声`、`手机提示音`、`仙气环绕`、`鬼火声`）
- Seedance `generate_audio: true` 可合成基础环境音；特殊音效后期叠加

### 9.8 风格尾缀模板

**凡间场景**：`现代都市喜剧风格，写实风格，竖屏9比16，禁止古代服饰、军事装备。`

**天庭场景**：`东方神话喜剧风格，仙侠写实，云海金光，竖屏9比16，禁止现代物品（外卖服除外）。`

**地府场景**：`东方神话风格，幽暗殿堂，鬼火青绿，竖屏9比16，禁止现代物品（外卖服除外）。`

**月宫/瑶池**：`东方仙境风格，清冷月光/碧波仙池，梦幻缥缈，竖屏9比16，禁止现代物品（外卖服除外）。`

**西天佛殿**：`东方佛门风格，金色佛光，庄严宁静，竖屏9比16，禁止现代物品（外卖服除外）。`

## 十、TTS / 配音方向

### 10.1 语音描述格式

每个有对白的角色必须有 `voice_prompt`，格式：
```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

### 10.2 旁白风格

- 标注旁白角色（通常不分配 CHAR-ID，写为「旁白」）
- 旁白 voice_prompt 独立于角色
- 旁白镜无参考图需求，并入相邻段

### 10.3 音效/配乐需求

- **主要配乐**：轻快诙谐的都市喜剧BGM（凡间）；宏大庄严的仙侠配乐（天庭）；阴沉神秘的环境音（地府）
- **情绪转折**：讨债时用轻快节奏+戏谑音效；感情戏用钢琴/古筝；紧张对峙时用鼓点+弦乐
- **特色音效**：外卖提示音、电动车声、仙气飘渺音效、鬼火声、佛号回响

## 十一、分集剧本格式规范

### 必须包含的结构（按顺序）

| 序号 | 部分 | 必选 | 说明 |
|------|------|------|------|
| 1 | YAML 文件头 | ✅ | episode_id, scene_ids, character_ids, look_ids, seedance_defaults |
| 2 | 集标题 + 引用导航 | ✅ | `# EP## 集标题` + 角色卡/场景卡链接 |
| 3 | 元信息摘要表 | ✅ | 叙事目标、钩子、默认形象、有效镜数、Segment数、版本 |
| 4 | 本集观众必须听懂 | ✅ | 编号列表：谁、发生什么、为什么、下集看什么 |
| 5 | SEG 正文 | ✅ | 按 Segment 分组的镜头表（11 列格式） |
| 6 | 结尾钩子 | ✅ | 一句话悬念 + 下集标题预告 |
| 7 | 本集制作备注 | ✅ | 情绪弧、光线、造型、音乐、节奏、关键细节 |
| 8 | 本集资产 | ✅ | 场景/角色/形象/道具/有效镜数汇总 |

### 11 列镜头表格式

```
| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白/备注 |
|------|---------|------|------|------|------|------|------|------|------|-----------|
```

#### 各列规范

| 列名 | 格式 | 说明 |
|------|------|------|
| 镜号 | 整数 | 全集连续编号（1, 2, 3...），不随 SEG 重置 |
| shot_id | `EP##-S##` | 全局唯一，如 `EP01-S01` |
| 场景 | `SCENE-###` | 对应资产/场景卡片.md 中的 ID |
| 角色 | `CHAR-###` | 出镜角色，多人逗号分隔；无人写 `—` |
| 形象 | `CHAR-###-L##` | 本镜使用的形象版本 |
| 景别 | 中文 | 全景/中景/近景/特写/大特写 |
| 时长 | 整数秒 | ≥4（Seedance 最小单位） |
| 模式 | 枚举 | `t2v`（纯文本）/ `i2v_ref`（带参考图）/ `skip`（非AI） |
| 运镜 | 中文 | 固定镜头/缓推/镜头推近/镜头拉远/镜头跟随/快切/主观镜头 |
| 画面 | 2-4句 | 电影级视觉描述 |
| 对白/备注 | 格式化 | `**CHAR-###**[情绪]：「台词」` 或 `（无对白，[音效]）` |

### SEG 块结构

```
---

## SEG01 — [叙事功能]

**【SCENE-###】[地点]** · **[时段]** · **[内/外景]**

| 镜号 | shot_id | ... | 对白/备注 |
|------|---------|-----|-----------|
| ... |

> ⏱ Segment时长：Xs ｜ 镜头数：N
```

### 画面描写质量标准

「画面」列**禁止**一句话空洞概括。每格必须 2-4 句，包含：

- 布景具体细节（桌面物品、墙面装饰、地面状态等）
- 光线/色温/明暗——情绪外化
- 人物姿态/微表情/手部动作/视线
- 与剧情相关的道具互动
- 暗示/伏笔元素

### 对白格式

| 场景 | 格式 |
|------|------|
| 有对白 | `**CHAR-###**[情绪·语气]：「台词」` |
| 内心独白 | `**CHAR-###**[内心]：「...」` |
| 无对白 | `（无对白，[音效]）` |
| 旁白 | `**旁白**[情绪]：「...」` |

### 生成模式分配

| 镜头类型 | 模式 | 说明 |
|---------|------|------|
| 环境空镜（无角色） | `t2v` | 纯文本描述，无参考图 |
| 角色出镜 | `i2v_ref` | 需角色参考图保持一致性 |
| 片头/片尾/黑屏 | `skip` | 非 AI 生成 |
