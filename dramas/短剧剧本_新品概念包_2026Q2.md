# 1.《我在末世开早点摊》

## 项目信息

- **类型**：末世 / 经营 / 轻喜剧 / 单元客户
- **集数**：36 集 × 2–3 分钟
- **叙事节奏**：危机 → 开张 → 来客 → 交易/情报 → 集末钩子
- **平台定位**：男女频破圈（「经营核」+ 末世外壳，无后宫）

## 一句话简介

极寒末世第三年，前米其林早班厨师陆早把避难所门口改成早点摊——一碗热豆浆换一条情报，一个肉包换一颗子弹；她不做救世主，只问一句：**你想用什么，换今天的早饭？**

## 为什么现在能火

- 平台热词 **「末世 + 经营/模拟」** 已在男频 AI 漫剧验证；真人/AI 短剧缺「低特效、高钩子」版本。
- 每集一个「客人」= 天然单元结构，适合投流切片（「Former CEO pays with a gold bar for one baozi」类反差）。
- 无多女主、无战神，**女性主角 + 生存智慧**，可同时吃女频情感与男频末世盘。

## 与库内差异

- 非《都市债神》式三界讨债；非纯战斗末世。
- 场景集中在 **摊位、避难所通道、地下市场**，AI 生成可控。

## 主要人物

| 人物 | 身份 | 作用 |
|------|------|------|
| **陆早** | 前酒店早班主厨，现摊主 | 女主，用「交易规则」建立秩序 |
| **老关** | 避难所守门老兵 | 保护线 + 喜剧担当 |
| **程野** | 前物流调度，现跑腿 | 男主，单线纯爱，帮陆早运货 |
| **「票子」** | 12 岁记账小孩 | 萌点 + 信息枢纽 |
| **红姐** | 黑市中间人 | 反派/亦敌亦友 |

## 金手指（克制）

**「早点摊规则」**：陆早的摊子上，所有交易必须「明码标价、当场交割」——违反者当日无法在方圆一公里获得任何食物与庇护（末世里的软秩序，非超能力）。

## 分集钩子（第 1–12 集）

| 集 | 标题 | 核心 | 钩子 |
|----|------|------|------|
| 1 | 零下四十度 | 避难所断粮，陆早支起煤炉 | 第一锅豆浆香飘出去，门外有人敲门 |
| 2 | 定价 | 规定：情报换粥，子弹换包 | 来人竟是避难所管理者 |
| 3 | 管理者 | 管理者想用权力白吃 | 陆早：「规则对所有人一样。」全场静默 |
| 4 | 程野 | 前同事来送货，欠她一个人情 | 货箱里藏着避难所偷出来的配给 |
| 5 | 配给案 | 配给被克扣，老人冻死 | 陆早用「早餐情报网」锁定仓库管理员 |
| 6 | 仓库夜 | 程野带路潜入 | 发现管理者与红姐的分账账本 |
| 7 | 公开价目表 | 陆早挂出「避难所腐败线索兑换表」 | 群众开始用线索换早饭 |
| 8 | 票子 | 小孩来摊子上洗碗换粥 | 他能记住每个客人的脸和谎话 |
| 9 | 假慈善 | 外来 NGO 发罐头，实则招募苦力 | 陆早试吃后当场呕吐——罐头过期 |
| 10 | 罐头账 | 追查到「人道援助」是二手倒卖 | 钩子：NGO 负责人是程野亲哥 |
| 11 | 兄弟 | 程野与亲哥对峙 | 亲哥：「没有我，你们早就饿死。」 |
| 12 | 选择 | 避难所投票：关不关掉早点摊 | 票数平票，管理者宣布「明日强制收摊」 |

**季线（13–36）**：收摊危机 → 地下早市 → 极寒第二波 → 陆早用「交易秩序」换避难所自治权 → 程野线收束（单 CP，无后宫）。

## 版权风险

🟢 极低，原创世界观。

# 2.《冥牌调解处》

## 项目信息

- **类型**：都市 / 悬疑 / 单元 / 轻奇幻
- **集数**：36 集
- **叙事节奏**：阳间案 → 阴间证 → 调解协议 → 反转
- **平台定位**：全龄；案驱动，类似「阴阳版《调解员》」

## 一句话简介

高考落榜的林照收到一张 **冥牌大学** 录取通知书——专业：阴阳纠纷调解。白天他在城中村送快递，晚上在冥牌调解处上班：**死人告状，活人抵赖，他负责把两边都说服。**

## 为什么现在能火

- **现实议题 + 地府神话** 复合题材在平台已有话题度（「冥牌大学」类梗），但缺 **连续剧情 + 情感核** 的短剧版。
- 单元案可蹭社会热点：劳务纠纷、直播带货假货、养老诈骗、校园霸凌——每集一个「可讨论」话题。
- 男主普通、无战神；靠 **证据与话术**，AI 对话戏多、动作少。

## 与库内差异

- 非《天庭临时工》官僚喜剧；非《兄弟盟》刑侦。
- 比《制式离婚》多奇幻壳，比《全城找耳机》节奏快。

## 主要人物

| 人物 | 身份 |
|------|------|
| **林照** | 男主，冥牌大学在读，快递兼职 |
| **白七** | 女鬼调解员学姐，冷面话少 |
| **马叔** | 调解处处长，前阳间法官 |
| **苏晓** | 阳间女友（ alive ），不知道林照夜间工作 |
| **顾深** | 冥牌大学招生办，隐瞒入学真相 |

## 分集钩子（第 1–12 集）

| 集 | 标题 | 核心 | 钩子 |
|----|------|------|------|
| 1 | 落榜 | 林照复读第三次失败 | 收到冥牌大学录取通知书 |
| 2 | 入学 | 专业：阴阳调解；学制：七年（阳间七年一夜） | 第一课：帮一个跳楼外卖员讨薪 |
| 3 | 外卖员 | 阳间老板否认雇佣关系 | 阴间账本显示每日派单记录 |
| 4 | 协议 | 林照促成「公开道歉 + 抚恤」 | 老板阳寿扣减 30 天（规则首次亮相） |
| 5 | 快递白天 | 林照送件到同一家公司 | 老板认出他：「你怎么知道内部账？」 |
| 6 | 白七 | 学姐带他办第二个案子：网红卖假燕窝 | 死者是过敏身亡的年轻妈妈 |
| 7 | 直播回放 | 用「阴间时间戳」锁定删掉的直播片段 | 网红团队开始找林照麻烦 |
| 8 | 苏晓 | 女友觉得他最近神神秘秘 | 林照身上出现只有鬼能见的「冥牌工牌」 |
| 9 | 校园霸凌 | 第三案：被霸凌少年抑郁自杀 | 少年鬼魂不愿调解，只要「他们道歉」 |
| 10 | 不调解 | 林照违规强行开庭 | 处长警告：再越界取消学籍 |
| 11 | 越界 | 林照阳间曝光霸凌视频 | 冥牌大学下达「召回令」 |
| 12 | 召回 | 林照若回冥界，阳间证据链断 | 白七：「我可以替你坐这一夜的班。」 |

**季线**：林照发现冥牌大学在「收集阳间冤案数据」→ 背后有资本想做人造轮回 → 与处长、白七联手改规则。

## 版权风险

🟢 偏低（「冥牌」为公共网络梗，剧情原创）。

# 3.《拆迁这一家》

## 项目信息

- **类型**：家庭 / 伦理 / 女性成长 / 现实
- **集数**：36 集
- **叙事定位**：女频 + 家庭（2026 榜单「遥不可及的爱」同类赛道）

## 一句话简介

老房拆迁款 **八百万** 到账那天，母亲把银行卡锁进抽屉：**「这钱我来分，你们谁都不准争。」** 大女儿周岚刚离婚带儿子回来，二儿子周磊欠赌债，小女儿周糖被宠坏——**一家五个人，八百万，谁先崩溃？**

## 为什么现在能火

- **家庭纠葛** 是 2025–2026 女频短剧上升最快的子赛道，完播与讨论度高于纯甜宠。
- 题材 **极度 AI 友好**：客厅、厨房、医院、街道办，场景少、对话密。
- 每集一个「分家修罗场」节点，投流标题自带流量（「拆迁款给了小儿子，大女儿当场掀桌」）。

## 与库内差异

- 非《制式离婚》律师视角；非《姐姐在上》商战。
- 无穿越、无系统，靠 **现实痛点** 打穿。

## 主要人物

| 人物 | 身份 | 弧光 |
|------|------|------|
| **周岚** | 女主，38，离婚带娃 | 从忍让到拿回话语权 |
| **王秀兰** | 母亲，重男轻女 | 偏心 → 真相 → 赎罪或决裂 |
| **周磊** | 弟弟，赌债 | 吸血 → 曝光 → 承担或入狱 |
| **周糖** | 妹妹，被宠坏 | 觉醒或继续帮凶 |
| **周建国** | 父亲，沉默 | 关键证人，掌握「第二本存折」 |
| **陈默** | 街道办调解员，男主 | 温厚，非霸总，帮周岚依法维权 |

## 分集钩子（第 1–12 集）

| 集 | 标题 | 核心 | 钩子 |
|----|------|------|------|
| 1 | 八百万 | 拆迁款到账，母亲宣布「我来分」 | 周磊当场要五十万「周转」 |
| 2 | 五十万 | 母亲私下转给周磊 | 周岚在银行流水里看见 |
| 3 | 离婚证 | 周岚坦白离婚，求暂住 | 母亲：「别带晦气回来。」 |
| 4 | 儿子发烧 | 周岚借钱被拒 | 周糖发朋友圈：「姐又来哭穷了」 |
| 5 | 协议草案 | 母亲拿出分配方案：周磊 400 万 | 周岚那份写「待定」 |
| 6 | 旧相册 | 周岚发现父亲年轻时另一本存折 | 父亲夜里偷偷出门 |
| 7 | 第二存折 | 跟踪父亲到信用社 | 户名是「周岚」——十五年前开的 |
| 8 | 真相 | 父亲坦白：当年把大女儿名字登记防被儿子败光 | 母亲当场砸碗 |
| 9 | 赌债上门 | 债主到门口，要周岚签字担保 | 陈默带来《民法典》调解 |
| 10 | 签字 | 母亲逼周岚替弟弟签 | 周岚：「我不签。要签你签。」 |
| 11 | 断绝 | 母亲扬言赶周岚出门 | 周岚亮出抚养权官司与居住权登记 |
| 12 | 分家饭 | 全家最后一顿饭，母亲端出「最终分配」 | 信封里是 **空白协议**——她要周岚「自己写想要啥」 |

**季线**：第二本存折牵出「母亲当年收过开发商好处」→ 周磊赌债背后是诈骗团伙 → 周岚带全家（或只带父亲）走法律程序，结局 **不强行大团圆**（可选 HE：母亲悔改；BE 向：周岚只带走儿子与父亲）。

# 4.《布衣账房》

## 项目信息

- **类型**：古装 / 权谋 / 智谋 / 纯爱（单女主）
- **集数**：36 集
- **平台定位**：男频（对标《一品布衣》智谋向，但 **无战神、无后宫**）

## 一句话简介

寒门账房沈砚入仕第一天，被派去核对 **户部烂账**——账上少了一百万石粮，多出来的名字全是死人。他不会武功，只会算账；**算错一笔，掉脑袋；算对一笔，得罪半个朝廷。**

## 为什么现在能火

- 2025 男频短剧 **古装智谋**（《一品布衣》《冒姓琅琊》）已验证；库内《错嫁》《凤谋》偏女频宫斗，**缺男频「布衣+权谋」**。
- 平台呼吁男频 **减后宫、加纯爱**——沈砚只有一条线：医女未婚妻。
- 钩子类型：**数字、账本、圣旨、对质**，适合「竖屏字幕冲击」（「差 37 石 = 死罪」）。

## 与库内差异

- 非《大宋提硒土》理工穿越；非《天工开物》机械线。
- 主角 **无金手指**，靠专业与胆色。

## 主要人物

|------|------|
| **沈砚** | 男主，寒门账房，逻辑怪物 |
| **苏青禾** | 女主，医馆姑娘，未婚妻，懂药懂人 |

| **户部尚书** | 反派，粮案幕后 |

**季线**：粮案 → 兵案 → 沈砚以账房身份参与肃王清党 → 单 CP 大婚（无侧室）。

古装一致性成本高于现代剧；建议 **室内账房、公堂、医馆** 为主，大战用「奏折 + 对白」替代。

# 5.《离婚后，他的系统漏气了》

## 项目信息

- **类型**：都市 / 系统 / 女性成长 / 打脸喜剧
- **集数**：36 集
- **平台定位**：女频 + 系统爽（AI 短剧女频增量最强品类之一）

## 一句话简介

离婚当天，姜禾绑定 **「清醒人生系统」**——任务只有三个：搞钱、养娃、变美。前夫傅成却绑定 **「渣男赎罪系统」**：每作死一次，损失等值资产。**她越活越好，他越赔越穷——而系统提示音，只有她能听见。**

## 为什么现在能火

- **系统 + 打脸** 是女频 AI 短剧标配，但多数写「女主开挂」；本剧加 **「前夫惩罚系统 + 女主旁听」**，双倍爽感、易做切片。
- 融合 **离婚/单亲妈妈/职场** 现实议题，比纯古言系统更易破圈。
- 场景：公司、幼儿园、商场、法庭——AI 量产友好。

## 与库内差异

- 非《隐形富豪》男频藏富；非《制式离婚》律师正剧。
- 喜剧节奏快于《她的克隆》，无 BE。

## 主要人物

| 人物 | 身份 |
|------|------|
| **姜禾** | 女主，32，前全职太太，现电商运营 |
| **傅成** | 前夫，普信男，系统受害者 |
| **小满** | 5 岁女儿，金句担当 |
| **林姐** | 闺蜜，带货主播 |
| **陆沉** | 男二，姜禾老板，尊重型追求者（可 HE） |

## 双系统规则

| 系统 | 绑定人 | 规则 |
