## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个视觉不同角色独立 ID + L01（按需创建，无上限） |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**；**只增不删**，弃用标 `deprecated: true`。
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象。
- L01 = 全剧面部一致性的**唯一锚点**；L02+ 衍生形象必须 `based_on` 本角色 L01，禁止跳过 L01。
- 群演按需创建、不设上限；同一 `CHAR-GRP-##` 可跨集复用，但不同视觉角色不可共用 ID。API 参考图配额每 segment ≤6 张（TOS URL 模式），超出时按 segment-builder 优先级裁减。
- scene-writer 剧本中标注的新群演（`[待补：...]`）由 production-planner 在集间回补子循环统一分配 `CHAR-GRP-##`（从已有最大编号 +1），并建声音卡片 + 角色索引 + 形象索引骨架行；L01 形象图由 character-designer 回补。
- CHAR-ID 分配权归 production-planner；character-designer 不可自行新增。

### 形象层级结构定义

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 L01；禁止跳过 L01 |

> 形象 Prompt 内容、生成流程、delta 规则等视觉创意细节由 character-designer 负责（本 Agent 不定义视觉 Prompt）。

> 本文件声明 `episode_profile: standard-86-horizontal`。G4/G5/segment-builder 均从本节取阈值，**禁止硬编码**。档案定义源：`制片规范模板.md` 四B 节。

| 参数 | 值 | 说明 |
|------|-----|------|
| 总集数 | **86** | 86×90s + EP01 120s ≈ 129.5 分钟 |
| aspect_ratio | **16:9** | 横屏；一个项目只选一种，不支持混用 |
| 单集时长 | 常规 75–100s（理想）/ 75–120s（合规） | EP01 = **120s** |
| 每集段落数 | **5–8 段** | 横屏：单段信息密度更高（较竖屏 [6,10] 下调） |
| 每集镜头数 | **[14, 24]** | 横屏下调（较竖屏 [16,30]）；单镜理想 3–6s，>10s 禁 |
| 单 segment 时长 | **4–12 秒**（video_gen API 硬限制，不可更改） | 理想 8–10s |

| closeup_min_pct | **35%** | 横屏：特写+近景占比下限（规避 AI 面部失真） |

| asl_max_sec | 3.5 | C1 平均镜长上限 |
| satisfaction_min | 2 | S1 每集最低爽点（复仇/逆袭题材可按 3 调） |
| slap_min_pct | **40** | S4 打脸占比下限（复仇/逆袭） |
| total_duration_min | 120 | 全剧总时长下限（分钟） |

**由 production-planner 定义，不可删改：**

## 七、分段（Segment）规则 —— AI 生成单位

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | video_gen 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | ≤3 镜；**段 ≥8s 必 ≥2 镜**（典型 2-3） | v2.2 切镜节奏；静音视觉锤段可单镜但 ≤8s |
| 最小叙事单位 | 1 个完整 beat | 每段必须构成完整叙事节拍 |
| 每集段落数 | 5–8 段（横屏） | 见 §四B |
| 每集镜头数 | 14–24 镜 | 横屏；单镜理想 3-6s，>10s 禁 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）。
2. **不得**在连续动作进行中切断（开门、摘茶筅、启封茶饼、翻账册等动作链一条 segment）。
3. 拆段边界：场景切换、主说话人切换、情绪断点。
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`。
5. 分镜表里某镜自然时长 < 4 秒 → 并入同场景相邻段。

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）。
- **Segment（SEGxx）** = AI 生成单位（一次 video_gen API 调用）。
- 同一场景**可**含多个 segment；segment **不得**跨场景。

### 分集剧本格式规范（11 列镜头表）

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注。
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs ｜ 镜头数：N` 统计行。
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`。
- 一行 = 一个镜头；多句对白在「对白/备注」格内换行书写，禁止空管子续行。

## 九、音色规范

- 每个有对白角色（含 CHAR-GRP-##）必须有 `voice_prompt`，格式：`「性别，年龄，音色特征，语速，情绪基调/说话习惯」`。
- 权威来源 = `资产/声音卡片.md`（**P0**）。同一角色跨 segment 的 voice_prompt 必须**全文一致**。
- 旁白不分配 CHAR-ID，写为「旁白」，voice_prompt 独立定义。
- 语言：中文（古白话偏白话，按角色语言画像差异化）。
- video_gen `generate_audio: true` 合成基础环境音；特殊音效（雨声、鞭炮、锣声、茶汤沸响、摔盏）后期叠加。
- 字幕后期添加（ffmpeg），视频引擎不烧录字幕。

## 十、年代/题材约束（叙述性）

**必须体现元素**：架空古代（明代江南风貌）——粉墙黛瓦、石板巷、茶垄竹匾、紫砂茶具、算盘账册、油纸伞、木质茶船、祠堂匾额、靛青短打、襦裙比甲、直裰马甲；茶事手艺（杀青/揉捻/焙火/听汤）；商号幌子与朱印文书。

**禁止出现元素**（叙述性；Prompt 由设计师负责）：
- 一切现代物品（手机、汽车、玻璃幕墙、霓虹、塑料、牛仔裤、运动鞋等）；
- 具体真实朝代帝王名号、清宫旗装辫子（本剧为架空明代风貌，勿混入清代）；
- 真实现代品牌 logo；
- 血腥伤口特写、暴力过程特写（按大纲合规拍法弱化）；
- 宫廷朝堂正面戏、有名有姓朝堂人物（官府仅作背景板）。

## 十一、内容合规参数

### 题材合规等级

- **🟡 B 级**（古代宅门权谋元素）：古装权谋需确保无影射现实政治；朝代架空，不涉具体史实与影射。
- 规避方案已写入大纲「题材合规自查」；本规范锚定执行。

### 本剧特定红线

1. **复仇手段限正当商业竞争与技艺比拼**：反击仅通过斗茶、账目审计、契约博弈、诚信经营；禁止构陷、下毒、买凶；设局（假消息/三本假账）仅防守性取证、不嫁祸第三方。
2. **不涉宫廷政治线**：无一朝堂人物有名有姓出场；官府仅作制度背景（税关/官差贴封条），程序一笔带过、不写刑堂审讯。
3. **反派恶行限于侵产夺业/商业欺诈**：败于商道与人证物证 + 行会公议；禁止人身暗害报应情节；结局走行业自治/宗族议处路径。
4. **无金手指**：成长来自拜师、实践、长辈知识传承；禁止重生/预知/系统外挂。
5. **暴力/伤情合规拍法**：呕血以转身捂口＋背影；火灾以窗外火光＋面部反应；伤情手背擦伤特写；摔盏即切不涉伤人；下跪弱化为长揖。

### 灰区处理策略

| 灰区内容 | 本剧是否涉及 | 处理方式 |
|----------|:---:|----------|
| 宅门权谋/夺产 | 是 | 架空朝代；冲突在商事/宗族层面解决；无影射 |
| 复仇情节 | 是 | 控制在商战/账目/技艺框架；法律/行会框架内收束 |
| 女子不当家偏见 | 是 | 作为被批判的封建糟粕展示，以账目击碎（EP21） |
| 内应背叛/纵火灭证 | 是 | 反派恶行，最终败露受行业/宗族处置；不美化 |
| 奢侈豪邸（程府） | 是 | 仅作反派空间背景，非炫富卖点 |
| 官府介入 | 是 | 背景板处理，不写司法程序细节 |

### 正向价值锚点

1. **女性自立与当家**：靠手艺与账本堂堂正正赢回（EP21/80/82）。
2. **匠艺传承与诚信经营**：开放炒坊、三条新规、童叟无欺（EP34/80）。
3. **法治与行业自治精神**：行会公议、实名商状、铁账如山（EP73-75）；「账不会说谎，人才会」。
4. **茶无常价，人有恒信**：主题金句落幅（EP86）。

### 平台审核重点提示

- **前 3 集**（审核最严）：
  - EP01：封库之辱——呕血合规拍法；官差仅贴封条背景；换货单微观钩建立「有鬼」但不渲染暴力。
  - EP02：逐出家权——姐弟分离情感线；禁止渲染虐待；桂嬷嬷异常仅伏笔。
  - EP03：半页残账——立志正向；父亲去世留白处理，不渲染死亡过程。
- **付费卡点**（EP10 卡一 / EP18 / EP29 卡二 / EP37 / EP45 / EP53 / EP61 卡三 / EP70 / EP79）：不可用低俗/暴力/性暗示作付费钩子；卡点集 hook 密度 ≥2/集，禁止低张力话唠段 >30s。
- **结局要求**：EP86 传递正面信息（善恶有报/希望/传承）；「茶无常价，人有恒信」正向落点；北上新茶路为开放性希望钩。
