# 短剧市场调研与新剧推荐（第二批）· 2026-08-11

> **调研原则**：纯市场驱动，完全忽略仓库现有项目。推荐理由仅来自实时市场数据（平台榜单、政策文件、行业报告），仅允许立项前剧名查重时对照现有目录保证标题唯一性。
>
> **与第一批差异**：本批聚焦**新兴蓝海赛道**与**主流媒体/平台新布局方向**，避开第一批已覆盖的系统流、年代致富、传统悬疑、都市离婚等热门但渐趋拥挤的赛道。

---

## 一、新增市场信号（2026年8月第二批调研）

### 1.1 主流媒体/财经媒体入局带来的新赛道

| 平台/媒体 | 新布局 | 代表剧目 | 题材特征 |
|-----------|--------|----------|----------|
| **21财经** | 短剧专区上线，首批50部泛财经短剧 | 《掘金女王之爱恨1990》《我在月球当包工头》《猫鼠游戏》《边界》《重回永乐大典》《法官的荣耀》 | 泛财经、职场、悬疑、历史、法治 |
| **澎湃新闻** | 短剧频道九大子栏目 | 《反诈风暴》《师傅》《超越吧！阿娟》《欢喜一家人》 | 社会热点、普通人奋斗、反诈、体育 |
| **央视频** | 独立"微短剧"Tab，储备1000+部 | 《中国神话》《AI看典籍》《三星堆：未来启示录》《邯郸梦之AI在战国》《相机》《木匠奇事》《中国节气——春分奇遇记》 | 传统文化、AI+典籍、神话、节气 |
| **湖南卫视** | "大芒剧场"19部作品，收视2.9亿人次 | 《重生，我在苏超踢前锋》 | 体育+重生+地域 |
| **东方卫视** | "品质东方·微剧场"24部作品，6.5亿收视人次 | 《微度假才是正经事》《弄潮》 | 文旅、都市生活 |

**关键洞察**：主流媒体以**专业垂类内容**（财经、法治、投教、传统文化）切入短剧，形成与娱乐平台差异化的内容护城河。这类题材**竞争少、政策风险低、政企合作机会多**。

### 1.2 新形态短剧崛起

| 新形态 | 数据/案例 | 机会点 |
|--------|-----------|--------|
| **横屏中短剧**（5-15分钟） | 2025年1-8月上线325部，同比增24.52% | 品质升级核心力量，连接长剧与短剧 |
| **互动式短剧** | 批量涌现 | 用户参与感，Z世代偏好 |
| **"微短剧+"** | 文旅、公益、品牌定制、投教 | 政企合作、多元变现 |
| **卫视短剧场** | 11个省级卫视开设，上半年播出52部 | 大屏破圈，触达30.2亿人次 |

### 1.3 尚未充分开发的蓝海题材

基于2026年上半年备案数据与平台热播分析，以下题材**供给不足但需求明确**：

| 蓝海题材 | 需求信号 | 供给现状 |
|----------|----------|----------|
| **泛财经/职场专业剧** | 21财经、澎湃等主流媒体入局；抖音15亿扶持创新题材 | 极少，几乎空白 |
| **体育/竞技+重生/穿越** | 《重生，我在苏超踢前锋》卫视播出；2026世界杯年 | 零星，未形成规模 |
| **传统文化+AI/科幻** | 央视频《AI看典籍》《三星堆：未来启示录》；政策鼓励"微短剧+千行百业" | 少量，品质参差 |
| **法治/投教/反诈** | 最高检《破浪·十年》；中证投服《股东来了》；公安《破晓之光》 | 政策驱动，市场供给不足 |
| **银发群体专属** | 银发用户33.3%且持续上升；短剧App银发人群4653万 | 适老化内容稀缺 |
| **男性向现实题材** | 红果免费漫剧男性占57.5%，但内容多为玄幻/脑洞 | 男性向现实剧几乎空白 |

## 二、第二批新剧推荐清单（6部）

### 推荐 1：《掘金女王：1990股市风云》
- **题材**：泛财经 + 年代 + 女性成长 + 职场/商战
- **目标受众**：25-45岁都市白领 + 财经爱好者 + 女性用户
- **推荐逻辑**：
  - 21财经已上线《掘金女王之爱恨1990》，证明泛财经+年代+女性题材有市场验证
  - 抖音15亿真人短剧扶持明确倾向"创新题材"，财经职场是稀缺方向
  - 1990年代股市初创期自带戏剧冲突（认购证、大户室、政策波动），且年代剧备案占28.7%
  - 女性视角切入男性主导的财经领域，差异化明显
- **差异化**：非穿越/重生金手指，而是真实历史背景下的女性证券经纪人成长史，专业细节+情感纠葛双线
- **合规**：C级（都市/年代），无政策风险
- **平台适配**：21财经短剧专区 + 红果短剧 + 抖音（保底激励）
- **商业化**：可与财经媒体品牌定制、投教内容联动

### 推荐 2：《我在月球当包工头》
- **题材**：科幻 + 职场/基建 + 轻喜剧 + 男频
- **目标受众**：男性为主（红果免费漫剧57.5%男性），18-35岁年轻男性 + 科幻爱好者
- **推荐逻辑**：
  - 21财经已上线同名剧目，验证"月球+基建+职场"题材可行性
  - 科幻是平台3倍分账倾斜的空白领域，且AI技术可低成本呈现月球场景
  - "包工头"人设接地气，与高冷科幻形成反差萌，契合男频幽默偏好
  - 中国探月工程、空间站建设等现实热点提供话题基础
- **差异化**：硬核科幻外壳+职场喜剧内核，主角是月球基地基建工人，处理各种荒诞工程事故+外星文明"甲方"需求
- **合规**：C级（科幻），无敏感元素
- **平台适配**：红果免费漫剧（AI仿真人/3D）+ B站 + 抖音漫剧
- **商业化**：航天科普合作、品牌植入（工具/装备）

### 推荐 3：《苏超前锋：重生之我在绿茵场》
- **题材**：体育/足球 + 重生 + 地域（江苏）+ 热血/励志
- **目标受众**：男性为主，18-45岁体育爱好者 + 江苏地域观众
- **推荐逻辑**：
  - 湖南卫视《重生，我在苏超踢前锋》已验证体育+重生题材在卫视端可行性
  - 2026年是世界杯年，足球题材天然热度；江苏"苏超"（江苏足球超级联赛）有地域粉丝基础
  - 体育题材在短剧领域几乎空白，竞争极少
  - 热血励志+地域认同，易引发本地传播
- **差异化**：非传统"逆袭打脸"，而是聚焦足球战术、团队配合、地域荣誉感的专业体育剧
- **合规**：C级（体育/励志）
- **平台适配**：湖南卫视"大芒剧场" + 红果短剧 + 抖音（世界杯流量）
- **商业化**：体育品牌合作、地方文旅联动

### 推荐 4：《AI看典籍：我在永乐大典当书灵》
- **题材**：传统文化 + AI/科幻 + 历史穿越 + 轻悬疑
- **目标受众**：全龄向，文化爱好者 + 年轻女性 + 银发群体
- **推荐逻辑**：
  - 央视频《AI看典籍》《重回永乐大典》已验证传统文化+AI题材可行性
  - 政策明确鼓励"微短剧+传统文化"，央视频储备1000+部精品微短剧重点布局
  - 《永乐大典》正本下落成谜，自带悬疑属性；AI技术可低成本呈现历史场景
  - 全龄向题材，可覆盖年轻女性（情感）+ 银发群体（文化怀旧）
- **差异化**：女主是AI修复师，意识进入《永乐大典》世界成为"书灵"，与明代编纂官共同守护典籍，古今双线交织
- **合规**：C级（历史/文化），政策鼓励方向
- **平台适配**：央视频 + 红果短剧 + 省级卫视短剧场
- **商业化**：文旅合作（国家图书馆/博物馆）、出版联动

### 推荐 5：《反诈风暴：银发守护者》
- **题材**：法治/反诈 + 现实 + 银发群体 + 家庭伦理
- **目标受众**：55岁以上银发用户（33.3%且持续上升）+ 其子女（25-45岁）
- **推荐逻辑**：
  - 银发用户是增长最快群体，但适老化内容稀缺；短剧App银发人群4653万
  - 公安/法治是政策鼓励垂类，《反诈风暴》《破晓之光》等已验证
  - 针对老年人的诈骗（保健品、投资理财、冒充子女）是社会痛点，子女群体有强烈传播意愿
  - 家庭伦理+法治教育，兼具情感共鸣与社会价值
- **差异化**：主角是退休老警察+社区志愿者组成"银发反诈团"，用老年人视角识破骗局，每集一个真实案例改编
- **合规**：B级（公安/法治），核心导向为正义/防骗，可备案
- **平台适配**：红果短剧 + 省级卫视（银发观众集中）+ 公安系统合作
- **商业化**：政企合作（公安/银行/社区）、公益广告

### 推荐 6：《股东来了：股市黑嘴现形记》
- **题材**：泛财经 + 法治/投教 + 轻喜剧 + 现实
- **目标受众**：25-50岁股民/投资者 + 财经爱好者
- **推荐逻辑**：
  - 中证投服中心已联合制作《股东来了》微短剧，验证投教+短剧可行性
  - 中国股市投资者超2亿，"股市黑嘴、非法荐股、场外配资"是监管重点打击对象
  - 轻喜剧形式拆解金融骗局，专业性与娱乐性统一，符合"微短剧+投教"政策导向
  - 财经媒体、券商、投服中心有强烈合作意愿，商业化路径清晰
- **差异化**：主角是前"股市黑嘴"转型为投教志愿者，以"反派视角"揭秘骗局套路，每集一个真实案例
- **合规**：C级（都市/法治），政策鼓励方向
- **平台适配**：21财经 + 红果短剧 + 抖音（财经流量）
- **商业化**：券商品牌合作、投教基地联动、财经媒体定制

## 四、两批推荐对比与选择建议

| 维度 | 第一批（6部） | 第二批（6部） |
|------|---------------|---------------|
| **赛道属性** | 已验证热门赛道（系统流、年代、悬疑、都市） | 新兴蓝海赛道（泛财经、体育、传统文化、银发、投教） |
| **竞争程度** | 中高（需差异化执行） | 低（先发优势） |
| **政策风险** | 低-中（部分题材需把握尺度） | 低（多为政策鼓励方向） |
| **商业化路径** | 平台分账为主 | 平台分账+政企合作+品牌定制 |
| **制作成本** | 中-高（年代/古装场景） | 低-中（现代/科幻可用AI降本） |
| **目标受众** | 女性为主+银发 | 男性+女性+银发+全龄覆盖 |
| **平台适配** | 红果/抖音/爱奇艺 | 红果/抖音/卫视/央视频/财经媒体 |

**选择建议**：
- 若追求**快速验证、稳妥收益** → 选第一批（系统流、悬疑刑侦）
- 若追求**差异化卡位、长期壁垒** → 选第二批（泛财经、体育、传统文化）
- 若资源充足，可**两批各选1-2部**并行，覆盖不同赛道与受众
