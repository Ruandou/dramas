> **正名**：《修仙归来当保安》
> **版本**：v1.0 · 2026-06-04

---

## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 道具     | `PROP-###`                        | `PROP-001`        | 玉佩                             |

- 编号**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先 `资产/角色索引.md`，再建 **`L01` 基础形象**。
- 新建换装：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。

### 1.1 形象 ID 与基础 / 衍生

| 后缀     | 名称     | 要求                                                    |
| -------- | -------- | ------------------------------------------------------- |
| **L01**  | 基础形象 | 完整定妆 Prompt；全剧面部一致性的唯一锚点               |
| **L02+** | 衍生形象 | 必须 based_on 本角色 L01；Prompt 只写差异（delta）      |

## 三、肖像与法务

- 所有角色为架空虚构，无现实人物原型
- 不使用真实人物肖像、姓名、商标
- 不涉及真实品牌Logo（使用虚构品牌"月华集团"）
- 保安制服使用通用款式，不标识具体物业公司名称

## 四、工作流顺序（必读 · 防不同步）

所有内容修改**严格按层向下**：

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_修仙归来当保安_36集.md` | 集纲、每场剧情、对白要点、钩子                      |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡、资产索引等       | 仅在前几步定稿后随需更新                            |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

### 自检清单（每次修改后）

- [ ] 修改是否只在当前层进行？
- [ ] 上层文件是否已同步更新？
- [ ] 所有 ID 引用是否仍有效？
- [ ] 新增形象是否已登记到 `资产/形象索引.md`？

## 五、分集文件头（YAML）

```yaml
---
episode_id: EP##
episode_title: [集标题]
duration_min: 2.5
season: S1
scene_ids: [SCENE-001, SCENE-002, ...]
character_ids: [CHAR-001, CHAR-002, ...]
look_ids: [CHAR-001-L01, CHAR-002-L01, ...]
seedance_defaults:
  model: doubao-seedance-2-0-fast-260128
  ratio: "9:16"
  resolution: 720p
  duration_sec: "8-10"
  generate_audio: true
  prompt_suffix: "禁止画面中出现任何文字或字幕。仙侠都市题材，写实风格。"
  negative_prompt: "blurry, distorted, low quality, watermark, subtitles burned into frame, anime style, cartoon style, historical costume, weapon, ancient clothing"
---
```

### 字段说明

| 字段 | 说明 |
|------|------|
| `episode_id` | EP##，如 EP01 |
| `scene_ids` | 本集出镜的所有场景 ID |
| `character_ids` | 本集出镜的所有角色 ID |
| `look_ids` | 本集使用的所有形象 ID |
| `seedance_defaults.model` | Seedance 生成模型，当前 `doubao-seedance-2-0-fast-260128` |
| `seedance_defaults.prompt_suffix` | 每段 Prompt 自动追加的后缀文案 |
| `seedance_defaults.negative_prompt` | 通用负面提示词；每集可追加题材特定项 |

## 六、仙侠都市美术规范

### 必须体现

- **现代都市**：智能手机、电梯、便利店、保安制服、小区环境、汽车
- **仙界元素**：古风帝袍（觉醒时）、仙术光效（金色/紫色）、玉佩法器
- **融合美学**：林风的保安制服+玉佩红绳——凡与仙的结合
- **光线运用**：日常用暖色生活光；天界用冷色仙光；觉醒时金色眩光
- **关键道具标志性**：泡面（赵大宝）、玉佩（林风）、保安证（破阵法器）

### 禁止出现

- 清代发式（辫子）
- 其他朝代服饰（唐宋元明等非现代非仙侠的明确历史服饰）
- 真实品牌Logo（车标可保留但不特写）
- 真人明星面容
- 纯动画/卡通风格（需写实风格）
- 画面中任何文字/字幕/水印

### Negative Prompt 模板

```
blurry, distorted, low quality, watermark, subtitles burned into frame,
anime style, cartoon style, oil painting, watercolor, 3D render,
historical costume, ancient Chinese clothing from specific dynasty,
Qing dynasty hairstyle, queue braid, military uniform, police uniform,
real brand logo, celebrity face, deformed hands, extra fingers
```

### 年代/题材定制项（每集追加）

| 集段 | 追加项 | 原因 |
|------|--------|------|
| EP01–11 | — | 纯现代都市，仅用通用 Negative |
| EP12–27 | `floating city, flying swords` | 加入天界场景时避免过于卡通化的仙侠 |
| EP27–36 | `overexposed, lens flare` | 天界大战场景注意 |

## 七、AI 出图/视频衔接

### 出图流程

1. 定稿 `L01` 参考图 → Character Sheet（正面全身，白底）
2. 衍生形象用图生图 / 角色一致性模型 → **delta Prompt** 仅写服装/道具/妆效差异
3. **禁止跳过 L01 直接生成 L02**
4. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01

### 一致性规则

| 角色 | 不可变元素 | 允许变化 |
|------|-----------|---------|
| 林风 | 黑色短发、保安制服（或仙帝觉醒装）、玉佩红绳 | 制服可脱、可脏破 |
| 苏秒 | 长发、珍珠耳钉、红绳手链 | 职业装→家居→战袍 |
| 赵大宝 | 板寸头、保安服、泡面道具 | 可受伤、可穿便服 |
| 昊天 | 紫金冠、灰眼睛 | 可被打伤、可换便装 |
| 黑风 | 全黑劲装、左脸刀疤 | 可受伤 |

### 参考图策略

- 角色定妆：`assets/looks/CHAR-*-L##.png`
- 场景参考：`assets/scenes/SCENE-*.png`
- 道具参考：`assets/props/PROP-*-*.png`
- 提交方式：TOS 永久图床（有条件时）或 data URI 格式
- **每 segment 最多 6 张参考图**（TOS模式）

### 参考图优先级配额

| 优先级 | 资产类型 | 说明 |
|--------|---------|------|
| P0 | 主角形象（林风 L01、苏秒 L01） | 每 segment 中必须包含出镜角色参考 |
| P1 | 对话角色形象（赵大宝、黑风、昊天等） | 有互动的角色必须锁定 |
| P2 | 场景参考图（SCENE-###） | 新场景首用时必须提供 |
| P3 | 关键道具（玉佩、保安证、泡面） | 特写镜头需提供 |
| P4 | 次要角色/群演 | 最后考虑，可用纯文本生成 |

### content_roles 配置模板

```yaml
content_roles:
  - { file: CHAR-###-L##, role: reference_image, label: 图1 }
  - { file: SCENE-###, role: reference_image, label: 图2 }
  # P1-P4 按优先级添加
```

## 八、道具转移与肢体动作（防错清单）

### 常见 AI 生成错误

| 错误类型 | 表现 | 预防 |
|---------|------|------|
| 道具消失 | 角色手中的物品在下一帧消失 | 特写镜头单独给道具，在 Prompt 中重复描述 |
| 肢体畸形 | 手指数量错误、手臂扭曲 | 加入 `deformed hands, extra fingers` 到 Negative |
| 变形 | 物体形状不稳定 | 短段（4-6s）内避免复杂道具互动 |
| 多人交互混乱 | 多人接触时肢体穿插 | 限制同框人数 ≤ 3 人，复杂互动用暗示+反应镜头 |

### 分段原则

- 同一动作链（开门→进门→关门）必须在一个 segment 内完成
- 道具易手必须在同一段内显示（从A手到B手，不能切镜后道具凭空到了）
- 长时间道具使用（如林风端泡面）在每段 Prompt 中都重复描述

### 检查清单（每 segment 写完后）

- [ ] 道具在连续镜头间是否保持一致？
- [ ] 肢体动作是否连续（A伸手→B接过 = 一段内完成）？
- [ ] 角色手部是否有道具但未在 Prompt 中描述？
- [ ] Negative Prompt 是否添加了 `deformed hands`？

## 九、有声段落（Seedance 2.0 · 默认）

### 段落规则

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 约 12–15 段 | 对应单集 2.5–3 分钟时长 |
| 单段主说话人 | ≤ 2 人 | 长对手戏拆成 SEGxxa / SEGxxb |

### Seedance 段落 Prompt 结构

```
【图1】角色ID·角色名（服装描述）【图2】角色/场景ID【图3】SCENE-###
角色分工：仅图1可[动作]；图2禁止[动作]。
道具：[具体描述]。
竖屏9比16连贯叙事。
镜头1（Xs）[景别][运镜]：[纯视觉动作描述]
镜头2（Xs）[景别][运镜]：[纯视觉动作描述]
[以下对白仅供语音合成，严禁在画面中显示任何文字]
对白（角色，年龄，情绪）：「台词」
画面全程无任何文字、字幕、标题、水印。
[题材风格描述]，写实风格，竖屏9比16，[负面约束]。
```

### 字幕策略

- **字幕后期添加**：Seedance 不烧录字幕，通过 ffmpeg 统一处理
- **道具文字后期合成**：AI 无法可靠渲染中文字，画内文字（如合同、屏幕UI）后期叠加
- **特殊提示**：如本镜画面中有手机屏幕/招牌等应显示文字，标注 `[后期叠加文字]`

### 拆分规则

| 拆分点 | 适用场景 |
|--------|----------|
| 说话人切换 | A说完 → B回应 |
| 动作完成 | 开门动作一段 → 进门后一段 |
| 情绪断点 | 紧张→如释重负 |
| 视角切换 | 主观→客观 |

**不得**在以下位置切断：
- 对话中间（一句台词必须落在同一段内）
- 连续动作进行中（开门、摘道具等动作链一条 segment）
- 情绪爆发的中段

## 十、题材合规说明

本项目为 **仙侠×都市** 融合类型，属于 **C级（可做）** 一般题材：

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 政治 | ✅ 不涉及 | 纯架空仙侠+都市，无现代/古代政治体制讨论 |
| 军事 | ✅ 不涉及 | 无军旅、战场、将军等元素 |
| 司法/公安 | ✅ 不涉及 | 无警察主角、刑侦、法庭。EP12中"特殊调查组"修改为"天渊私人武装" |
| 国家安全/宗教 | ✅ 不涉及 | 无相关元素 |
| 封建迷信 | ✅ 可规避 | 仙侠作为传统文学框架，核心导向为"守护/爱情/凡人勇气"，非宣扬迷信 |
| 一般题材 | ✅ | 都市喜剧+仙侠动作，普通备案 |
