## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##-SH##`                   | `EP01-S01-SH03`   | 集数-分段-镜头                   |

- 编号**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再建 **`L01` 基础形象**于 `资产/形象索引.md` + `角色卡.md`。
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。

### 1.1 形象 ID 与基础 / 衍生

| 后缀     | 名称     | 要求                                                    |
| -------- | -------- | ------------------------------------------------------- |
| **L01**  | 基础形象 | 完整定妆 Prompt（脸、体型、发式、默认服装）；全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | **必须** `based_on` 本角色 `L01`；Prompt 只写差异（delta），并含 `same face as CHAR-xxx-L01` |

### 1.2 出图流程

1. 定稿 `L01` 参考图 → Character Sheet（正面全身，白底）
2. 衍生形象用图生图 / 角色一致性模型 → **delta Prompt** 仅写服装/道具/妆效差异
3. **禁止跳过 L01 直接生成 L02**
4. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01

## 三、年代与美术

- **年代**：架空仙侠（无特定朝代）
- **画面比例**：9:16 竖屏
- **美术风格**：东方仙侠写实风

### 必须体现

- 古风仙侠建筑（飞檐、木质结构、灵石装饰、悬崖宗门、石桥、祭台）
- 修炼者服饰（长袍、劲装、道袍、华服、囚衣）
- 灵力特效（金色吞噬光芒、灵力屏障、金色脉络、灵气漩涡）
- 山林/洞穴/宗门/密林/古城/荒原/地牢等仙侠场景
- 铁链、阵法、灵石、玉佩、卷轴等仙侠器物

### 禁止出现

- 现代物品（手机、汽车、电灯、塑料、玻璃幕墙、电线杆）
- 西式建筑或服饰（哥特式、罗马柱、西装领带）
- 真实品牌 Logo
- 清代发式（辫子/剃头）
- 真人明星面孔
- 动漫/卡通/水彩/油画风格

## 四、工作流顺序（必读 · 防不同步）

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_废材吞天_36集.md` | 集纲、每场剧情、对白要点、钩子                      |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡、资产索引等       | 仅在前几步定稿后随需更新                            |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。


## 七、AI 出图/视频衔接

### 出图流程

1. **角色定妆**：`assets/looks/CHAR-*-L##.png` → Character Sheet 格式（正面全身，白底，平光）
2. **场景参考**：`assets/scenes/SCENE-*.png` → 纯环境，无人物
3. **道具参考**：`assets/props/PROP-*.png` → 单物体，产品摄影打光，无人物无手部
4. 衍生形象（L02+）：**delta Prompt** 仅写差异，含 `same face as CHAR-xxx-L01`

### 参考图管理

- 角色定妆：`assets/looks/CHAR-*-L##.png`
- 场景参考：`assets/scenes/SCENE-*.png`
- 道具参考：`assets/props/PROP-*-*.png`
- 提交方式：TOS 永久图床（有条件时）或 data URI 格式
- **每 segment 最多 6 张参考图**（TOS模式）

### 参考图配额优先级

| 优先级 | 资产类型 | 说明 |
|--------|---------|------|
| P0 | 主角形象（CHAR-001-L##） | 必须保证 |
| P1 | 对话角色形象 | 有互动的角色必须锁定 |
| P2 | 场景参考图 | 保证环境一致性 |
| P3 | 关键道具 | 有余量时加入 |
| P4 | 次要角色/群演 | 最后考虑 |

### content_roles 配置模板

```yaml
content_roles:
  - { file: CHAR-001-L01, role: reference_image, label: 图1 }
  - { file: CHAR-002-L01, role: reference_image, label: 图2 }
  - { file: SCENE-001, role: reference_image, label: 图3 }
  # - { file: PROP-001.png, role: reference_image, label: 图4 }
```

## 九、有声段落（Seedance 2.0 · 默认）

### Segment 规则

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 约 12–15 段     | 对应单集 2.5 分钟时长                                   |

### 拆分原则

1. **不得**在对话中间切断 segment
2. **不得**在连续动作进行中切断
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 镜头自然时长 < 4 秒 → **并入同场景相邻段**

### Prompt 结构

```
【图1】角色 ID·角色名（服装描述）【图2】角色/场景 ID【图3】SCENE-###
角色分工：仅图1可[动作]；图2禁止[动作]。
道具：[具体描述，含尺度参考]。
竖屏9比16连贯叙事。
镜头1（Xs）[景别][运镜]：[纯视觉动作描述]
镜头2（Xs）[景别][运镜]：[纯视觉动作描述]
[以下对白仅供语音合成，严禁在画面中显示任何文字]
对白（角色，年龄，情绪）：「台词」
画面全程无任何文字、字幕、标题、水印。
东方仙侠写实风格，竖屏9比16，[负面约束]。
```

### 字幕策略

- Seedance **不烧录字幕**（prompt_suffix 明确禁止）
- 字幕通过 ffmpeg 后期统一添加
- 画内文字（宗门匾额等）后期叠加合成——AI 无法可靠渲染中文

## 十一、声音规范

### voice_prompt 格式

```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

- **权威来源**：`资产/声音卡.md`（P0 最高优先级）
- 同一角色跨 segment 的 voice_prompt 必须**全文一致**
- 详见 `资产/声音卡.md`

### 旁白

- 旁白 voice_prompt 独立于角色，不分配 CHAR-ID
- 本剧旁白极少，仅大结局画外音一处

### 音效/配乐

- Seedance `generate_audio: true` 可合成基础环境音
- 特殊音效（吞噬音效、灵力爆发、铁链碰撞）后期叠加
- 格式标注：`[音效类型]`（如 `金色吞噬光芒的嗡鸣声`、`铁门开启的沉重声响`）

## 十三、资产图片生成规则

### 角色参考图（looks/）

- Character Sheet 格式：正面全身、白底、单人、平光
- Prompt 必须以 `Character reference sheet, front-facing full-body portrait from head to toe, single person standing upright facing the camera, plain white background, clean flat studio lighting.` 开头
- 结尾使用 `Vertical 9:16, character design sheet.`
- **禁止**包含场景背景或情绪灯光描述

### 场景参考图（scenes/）

- **严禁出现任何人物**（no people, no human figures）
- 仅包含建筑、家具、道具、植被、光线、氛围
- Prompt 末尾必须追加：`Empty environment, no people, no human figures, architectural and environmental reference only.`
- **禁止**出现外国人描写

### 道具参考图（props/）

- 单物体，最具辨识度角度，温暖中性丝绸/宣纸底色
- **严禁出现任何人物或手部**
- Prompt 必须以 `Prop reference photograph, single object isolated on warm neutral silk background, dramatic product lighting with soft shadows.` 开头
- 结尾使用 `Vertical 9:16, detailed prop reference sheet.`
