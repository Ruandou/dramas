# 声音卡片

> **版本**：v1.0 · 2026-06-26
> **权威级别**：P0（最高）——segment-builder 的 voice_prompt 唯一权威来源
> **维护方**：production-planner 创建初版，character-designer 可通过 `voice_feedback` 机制提出修改建议

---

## 声音规范原则

- 每个有对白角色必须有 `voice_prompt`
- 格式：`「性别，年龄，音色特征，语速特征，情绪/说话习惯」`
- 同一角色跨 segment 的 voice_prompt **全文一致**
- segment-builder 从本文档全文复制，禁止缩写或改写

|------|------|
| 角色 ID | `CHAR-001` |

| voice_prompt | 「成年女性，18岁，声线清亮略带倔强，咬字清晰，语速偏快，生气时语调明显升高语速加快，委屈时声音发颤带鼻音，开心时笑声明朗，口头禅"随便吧""无所谓"时语气敷衍上扬」 |

- 互换后（在妈妈身体里）：逐渐融入妈妈的温柔语调，但偶尔暴露急躁本性
