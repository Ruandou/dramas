## 二、ID 系统规范

所有资产使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角 |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉 |
| 群演 | `CHAR-GRP-##` | `CHAR-GRP-01` | 背景角色 |
| **场景** | `SCENE-###` | `SCENE-001` | 布景 |
| **道具** | `PROP-###` | `PROP-001` | 关键道具 |
| **分集** | `EP##` | `EP01` | 分集文件 |
| **镜头** | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- **群演按需创建**：有名字+跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词但需视觉区分 → `CHAR-GRP-##`
- 同一 `CHAR-GRP-##` 可跨集复用，但不同视觉角色不可共用同一 ID

### 形象层级

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

## 三、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于大纲元数据：「现代都市写实 / 温暖生活流」「暖色自然 / 高饱和生活感」。

| 维度 | 规格 |
|------|------|
| 渲染风格 | modern urban realism / warm slice-of-life |
| 镜头参考 | cinematic 35mm / 50mm lens, natural framing, medium close-ups for emotional beats |
| 色调方向 | warm golden tone with high saturation; natural daylight balanced with warm indoor lighting |
| 光影 | soft natural light; warm tungsten for indoor family scenes; cool fluorescent for school/office tension |
| 画幅 | 9:16 vertical (Seedance ratio) |
| 题材关键词 | 家庭温馨、日常质感、温暖色调、生活流、半写实 |

### prompt_suffix（Seedream 参考图生成固定后缀）

```
modern Chinese city, 2024, warm natural lighting, soft focus background, cinematic composition, photorealistic, 9:16 vertical frame, high detail, warm color palette
```

### negative_prompt（年代禁忌 + 风格限制）

```
fantasy elements, magical glowing, anime style, cartoon style, watercolor, oil painting texture, ancient Chinese clothing, pre-modern architecture, black and white, desaturated, low quality, blurry, deformed hands, extra fingers, distorted faces, text, watermark, logo, medieval European, sci-fi, horror, gore, nudity
```

> **注**：prompt_suffix 和 negative_prompt 为结构性约束。创意领域 Prompt（角色外貌、场景氛围等）由 character-designer、prop-designer、scene-designer 各自负责。

## 六、分段规则（Segment Rules）

### 分段即 AI 生成单位

| 约束 | 值 | 说明 |
|------|------|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 同段主说话人 | ≤ 2 | 长对手戏拆成 `SEGxxa` / `SEGxxb` |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**
5. segment **不得**跨场景

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment

## 十一、年代 / 题材约束

### 必须体现元素

- 2024年中国现代城市生活细节（手机、外卖、高考倒计时App、短视频）
- 典型家庭空间布局（客厅+餐桌+电视、学生书桌、父母卧室）
- 高考备考生态（教辅资料、补习班、倒计时标语、模拟试卷）
- 创业公司日常（站立会议、代码review、路演、投资谈判）
- 中国式家庭关系细节（婆媳、父子、母女的文化语境）

### 禁止出现元素

- 非现实的奇幻视觉特效（互换过程不展示特效，只展示结果）
- 古代服饰、古代建筑、古代用语（flashback 场景除外——1978年奶奶回忆需怀旧复古）
- 外国品牌logo、政治敏感内容
- 过度血腥、暴力、色情画面
- 阴暗/恐怖的色调（即使在低谷剧情中也保持温暖基调）

## 十四、内容合规参数

### 题材合规等级

**B 级（中等风险）**——家庭伦理 + 高考题材，需注意：

### 本剧特定红线

1. **高考公正性**：妈妈替女儿高考涉及代考伦理——剧中必须明确这是奇幻设定，不可美化或鼓励代考行为
2. **校园霸凌处理**：EP30 霸凌情节不可展示暴力细节，重点放在「以勇气反击」而非「以暴制暴」
3. **未成年人保护**：18岁角色的情感线（赵宇晨暗恋）保持纯爱级别，不可有亲密镜头
4. **酒桌文化**：EP08 酒局场景不可展示劝酒/灌酒细节，重点放在「理解父亲的委屈」
5. **医疗场景**：EP51-52 手术场景不可展示血腥手术画面，聚焦于手术室外的情感

### 灰区处理策略

| 灰区 | 处理方式 |
|------|----------|
| 身体互换后的异性身份体验 | 仅通过幽默对话暗示（如妈妈收到男生奶茶），不展示更衣/洗澡等隐私场景 |
| 奶奶1978年互换经历 | 通过日记文字+旁白叙述，不做实际 flashback 拍摄（除非有明确需求） |
| 教育体制批判 | 以「理解」为核心，不做激进批判；王铁军角色体现体制内善意 |
| 职场中年危机 | 展示困境但不渲染绝望；裁员情节聚焦人情味而非制度冷酷 |

### 正向价值锚点

1. **代际理解**：每个人都在对方的人生中找到了理解，这是全剧核心价值
2. **教育观革新**：不是只有考大学一条路——女儿追求美术、妈妈重返讲台、儿子创业
3. **家庭沟通**：沉默不是爱的表达方式，说出来才是

### 平台审核重点提示（前3集）

- **EP01**：妈妈撕漫画——情绪激烈但不可出现人身攻击性语言；争吵在合理范围内，不可上升到家暴暗示
- **EP02**：互换结果展示——通过日常行为（照镜子、穿错衣服）表现，不使用任何奇幻特效镜头
- **EP03**：奶奶到访——全家伪装的喜剧效果，不可暗示对老年人的欺骗/愚弄是正当的
