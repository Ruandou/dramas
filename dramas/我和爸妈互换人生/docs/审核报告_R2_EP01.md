## Top 3 问题（按严重程度排序）

### 问题 1：对白密度严重不足——validation block 虚报

- **位置**：全局（全 11 segments）
- **问题描述**：validation block 声称"对白密度：45行 / 1.9min = 23.7行/分 ≥ 20行/分 ✅"，但经逐镜逐 `「」` 块审计，实际对白统计如下：

| 类别 | 行数 |
|------|------|
| 角色对白（角色间对话） | 22 |
| 独白/内心（`[内心]`/`[低声·自语]`） | 2 |
| 旁白 | 2 |
| **总 spoken lines** | **26** |

- 角色对白占比 = 22 / 26 = **84.6%**（✅ 健康）
- 对白/独白+旁白比例 = 22 / 4 = **5.5:1**（✅ 健康）
- **实际对白密度 = 22 行 / 1.9 min = 11.6 行/分**，远低于 20 行/分目标
- Validation block 的 45 行疑似将音效描述（纸张撕裂声×4、门摔声×1、身体倒地声×1）、动作备注、无对白镜头描述等全部计入，属于统计口径错误
- **角色对白分布不均**：CHAR-002（苏敏）10句（45.5%）、CHAR-001（小夏）8句（36.4%）、CHAR-003（林建国）2句（9.1%）、CHAR-004（林大宇）2句（9.1%）。爸爸仅2句、儿子仅2句——虽然沉默是爸爸的人设，但作为EP01的4人家庭，需要至少3-4句台词来"锚定"角色
- **影响维度**：维度7（对白工艺）
- **建议修改**：
  1. **修正 validation block**：将"45行"更正为实际对白数（22句角色对白 + 2句独白 + 2句旁白 = 26 spoken lines），密度更正为 11.6行/分
  2. **增加爸爸台词**：SEG04 镜7中林建国只有1句"行了……都少说两句"（这是回避型用语✅），建议在SEG06镜12的全家福停顿处增加1句对白（如"饭我热好了……"而非仅内心独白），让观众在EP01就锚定他的"用行动代替语言"特征
  3. **增加儿子台词**：SEG09-10中大宇仅有2句台词，建议在SEG05镜9中扩展他与妈妈的交锋——增加1句自嘲型台词（如"反正我说什么你也不听"），既增加对白密度又提前建立他的"防御型表达"
  4. **如需达到20行/分目标**：全集需增加约16句台词（从22→38句），可通过在SEG07-08的母女对峙中增加来回对白轮次实现

### 问题 2：儿子（林大宇）返回时间线逻辑断裂

- **位置**：SEG05 → SEG09
- **问题描述**：大宇在SEG05镜10（shot EP01-S10）摔门离去，画面注释"窗外开始有雨声"。但到SEG09镜17（shot EP01-S17），他突然再次出现，描述为"大宇不知何时也回来了（浑身淋湿，雨水滴在地板上）"。问题：
  1. **时间线不明**：从摔门到返回经过了多久？SEG05-08中没有任何时间过渡标记。观众会困惑——他刚走就回来了？
  2. **"不知何时"是逃避叙述**：剧本用"不知何时也回来了"回避了这个逻辑问题，但AI动画生成时必须有一个镜头交代他的返回（开门/从走廊出现），否则观众会觉得"凭空出现"
  3. **情感断裂**：大宇说"这个家我待够了"是极强的情感宣泄，他需要足够的时间（至少几分钟的叙事间隔）在雨中犹豫后才可能返回。当前剧本中SEG05到SEG09仅隔3个segments（约30秒叙事时间），说服力不足
- **影响维度**：维度3（制作可行性）
- **建议修改**：
  1. 在SEG07（小夏反击）和SEG08（玉佩争夺）之间，插入一个3-5秒的过渡镜头——可以是**门外雨中**的中景：大宇站在门外淋雨，犹豫地转身走向家门。用一个无声镜头交代时间流逝和他的心理转变
  2. 或者修改SEG09镜17的描述，改为"大宇推开家门冲进来（已被暴雨淋透）"——明确交代他是从外面回来的
  3. 如果担心增加镜头导致超时，可将SEG06的2个镜头压缩为1个，腾出空间给过渡镜头

### 问题 3：爸爸（林建国）角色锚定不足

- **位置**：SEG04、SEG06（全集仅出现2段）
- **问题描述**：林建国在EP01中仅有2句台词和1句内心独白。虽然"沉默"是他的人设，但EP01作为pilot集，观众需要在首次出场中建立对角色的认知。当前问题：
  1. **SEG04镜7**：仅1句"行了……都少说两句"——这建立了回避形象✅，但太单薄
  2. **SEG06镜12**：1句"我去热饭" + 1句内心独白——"用行动代替语言"表现到位，但内心独白(`[内心]`)违反了他的禁用词规则（不会主动表达情感，但这里是在表达"说什么都是错"的委屈）
  3. **叙事功能弱**：在11个segments中，爸爸仅在2段出场，观众可能会忘记他的存在。他应该在EP01就留下"这个人看起来沉默但内心有故事"的印象
- **影响维度**：维度2（情绪收益）、维度7（对白工艺）
- **建议修改**：
  1. 将SEG06镜12的内心独白改为**行动暗示**：不写内心独白，而是改为他路过全家福时停顿更久，手指触碰了一下照片边缘（用行动暗示内心世界），然后低声说"饭凉了我再热一次"——既维持沉默人设又增加对白
  2. 在SEG09（四人同握玉佩）中，给爸爸增加1句台词体现他的"保护者本能"——如"小夏松手！会伤到你！"——这是他唯一会打破沉默的时刻（保护孩子）
  3. 如需要，可在SEG01中增加爸爸在背景中的存在感——如镜1画面描述中提及"林建国坐在沙发角落看报纸"，让观众从一开始就看到四口之家的完整结构
