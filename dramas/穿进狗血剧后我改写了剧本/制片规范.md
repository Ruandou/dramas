## 二、ID 系统

| 类型 | 格式 | 示例 | 备注 |
|------|------|------|------|
| 角色 | `CHAR-###` | CHAR-001 | 对白、关系、选角 |
| 形象 | `CHAR-###-L##` | CHAR-001-L01 | 出图、妆造、分镜视觉 |
| 群演 | `CHAR-GRP-##` | CHAR-GRP-01 | 按需创建，无上限 |
| 场景 | `SCENE-###` | SCENE-001 | 布景 |
| 道具 | `PROP-###` | PROP-001 | 关键道具 |
| 分集 | `EP##` | EP01 | 分集文件 |
| 镜头 | `EP##-S##` | EP01-S01 | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 角色/场景/道具 ID 只增不删，弃用标 `deprecated: true`
- 群演按需创建：有名字+跨 segment 出现 → 独立 CHAR-###；纯背景无台词但需视觉区分 → CHAR-GRP-##

### 形象层级

| 后缀 | 名称 | 说明 |
|------|------|------|
| L01 | 基础形象 | 全剧面部一致性的唯一锚点 |
| L02+ | 衍生形象 | 必须 `based_on` 本角色 L01 |

## 三、分段与镜头规范

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | 4–12 秒 | Seedance fast 硬限制 |
| 理想时长 | 8–10 秒 | |
| 每 segment 镜头数 | 1–3 镜 | |
| 每集段落数 | 6–10 段（EP01可至12段） | |
| 每集镜头数 | 8–12 镜 | |

### 拆分原则
1. 不得在对话中间切断 segment
2. 不得在连续动作进行中切断
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2
5. 自然时长 < 4 秒的镜头并入同场景相邻段

### 关键区分
- **场景（SCENE-###）** = 空间单位
- **Segment（SEG##）** = AI 生成单位（一次 API 调用）
- 同一场景可以包含多个 segment
- Segment 不得跨场景

## 五、视觉风格锚点

### Seedream 通用参数

**prompt_suffix**（参考图使用）：
```
Urban realistic style with light comic touch, warm bright color palette, natural lighting, detailed facial features, Simplified Chinese text when applicable, 9:16 vertical portrait orientation, high quality, photorealistic skin texture
```

**negative_prompt**（参考图使用）：
```
disfigured, bad anatomy, wrong body proportions, extra limbs, cloned face, disfigured face, ugly, gross proportions, malformed limbs, missing arms, missing legs, extra arms, extra legs, fused fingers, too many fingers, long neck, watermark, username, signature, text overlay, cartoon, anime, 3D render, cgi, illustration, painting, abstract, deformed, blurry, low quality, low resolution, night scene without proper lighting, horror elements, scary, gore, violence, western faces, caucasian features when should be Chinese, traditional Chinese characters when should be Simplified
```

### Seedance 通用参数

**model**: `doubao-seedance-2-0-fast-260128`
**ratio**: `9:16`
**resolution**: `720p`
**generate_audio**: `true`
**watermark**: `false`

**prompt_suffix**（视频使用）：
```
Vertical 9:16 continuous narrative, modern Chinese urban setting, realistic drama style, warm natural lighting, subtle comic timing, no brand logos, no platform UI, no text overlay, no subtitles, no watermark, no background music
```

**negative_prompt**（视频使用）：
```
Horizontal video, letterbox, black bars, watermark, text overlay, subtitles, brand logo, platform UI, background music, distorted faces, unnatural movement, cartoon style, anime style, 3D rendering, CGI, poor lighting, dark scenes without narrative purpose, horror elements, violence, gore, explicit content
```
