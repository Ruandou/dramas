## 二、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 按需创建，无上限 |
| 场景 | `SCENE-###` | `SCENE-001` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**，只增不删
- 弃用标 `deprecated: true`
- 新建角色：先在 `资产/角色索引.md` 登记，再由 character-designer 建 L01 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演按需创建：有名字+跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词但需视觉区分 → `CHAR-GRP-##`

### 形象层级

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

## 五、工作流顺序（必读 · 防不同步）

| 顺序 | 层 | 文件 | 写什么 |
|:---:|------|------|--------|
| **1** | **主剧本** | `短剧剧本_我能看见万物标价_72集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 七、分段规则

### Segment（AI 生成单位）约束

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | EP01 可至 12 段 |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 镜头 ID 格式

```
EP##-S##
```

示例：`EP01-S03` = 第1集第3镜

## 十、年代/题材约束

### 必须体现元素

- 现代中国都市环境（2025年）：高楼大厦、商业街、现代交通
- 古玩行业生态：古董店、拍卖行、古玩市场、鉴定工具
- 商界社交场景：高档会所、商务峰会、慈善拍卖
- 异能视觉表现：金色数字浮现在视野中（AR感）、琥珀色光芒

### 禁止出现元素（叙述性约束）

- 古代服装或历史朝代元素（本剧为纯现代背景）
- 西方奇幻元素（魔法阵、龙、精灵等）
- 过度暴力血腥场面（平台自审合规）
- 明确政治敏感内容
- 宗教仪式或宗教符号

## 十一、内容合规参数

### 题材合规等级

**C级（低风险）**——都市现代题材，无历史敏感、无暴力血腥、无政治内容。平台自审即可。

### 本剧特定红线

1. **不得出现真实公司名称或品牌标识**——所有商业实体均为虚构
2. **不得出现真实货币面额的伪造/造假教学**——古玩鉴定情节需避免可被模仿的造假细节
3. **绑架/暴力情节需克制**——EP31绑架情节不得出现血腥画面，暴力暗示为主
4. **监狱场景需合规**——不得丑化司法系统，林少卿入狱体现"违法必究"正向价值
5. **金融操控情节需模糊化处理**——不得出现可被理解为真实金融操控教学的具体手法

### 灰区处理策略

| 灰区 | 涉及集数 | 处理方式 |
|------|---------|---------|
| 赌博/捡漏边界 | EP03-04, EP10 | 强调"鉴定眼光"而非"赌博运气"，能力是信息优势不是赌博 |
| 商业间谍/潜入 | EP29, EP48 | 以"取证正义"为动机包装，潜入目的为揭露违法而非牟利 |
| 能力控制人心 | EP18, EP21 | 陆辰看到人际关系数据后**尊重对方选择**，不用能力操控 |
| 前女友负面形象 | EP01, EP08, EP24 | 陈雅琳有完整成长弧线（EP59悔恨+EP72独立），非单纯丑化女性 |

### 正向价值锚点

1. **真正的价值不是价格数字，而是人心和故事**——全剧核心主题
2. **逆袭靠智慧和努力，不是靠运气**——能力是工具，决策靠人
3. **忠诚和情感的不可替代性**——大壮的"无价"、苏念的信任

### 平台审核重点提示

| 集数 | 注意点 | 处理建议 |
|------|--------|---------|
| EP01 | 分手场景可能涉及"物质女性"刻板印象 | 确保陈雅琳后续有成长弧线，非单纯丑化 |
| EP06 | 合同法律效力的描述 | 模糊化处理具体法条，不做法律教学 |
| EP31 | 绑架情节 | 暴力暗示为主，不展示具体暴力行为 |
