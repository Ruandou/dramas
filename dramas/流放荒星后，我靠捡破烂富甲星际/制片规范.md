## 二、ID 命名规则与分配现状

### 2.1 ID 格式

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| 角色 | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| 形象 | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同视觉角色独立 ID + L01 |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |
| 段落 | `EP##-SEG##` | `EP01-SEG01` | AI 生成单位 |

### 2.2 分配规则

- 编号**连续、不跳号、只增不删**；弃用标 `deprecated: true`。
- L01 为全剧面部一致性**唯一锚点**；L02+ 衍生形象必须 `based_on` 本角色 L01，禁止跳过 L01。
- 群演按需创建：scene-writer 以 `[待补：描述]` 协议标注 → production-planner 在集间群演回补子循环统一分配 `CHAR-GRP-##`（从已有最大编号 +1）→ character-designer 回补 L01。本阶段（Stage 2）**暂不分配任何群演**。
- 唯一硬约束：单 segment 参考图 ≤6 张（TOS URL 模式），超出按 segment-builder 优先级裁减。

### 2.3 主角容量声明（R1 观察 O2 · 硬约束）

> ⚠️ **角色资产已满载**：本剧 10 名具名角色（8 主 + 2 功能配角）已达 AI 短剧资产产能上限，**无新增主角容量**。任一时段活跃主要角色 ≤8，靠槽位释放机制维持：**卡隆（CHAR-006）EP26 退场 → 槽位释放给沈萤（CHAR-008）EP51 实体登场**。

| 参数 | 值 |
|------|------|
| 视频模型 | `doubao-seedance-2-0-fast-260128` ⚠️ 必须带版本后缀，无后缀名方舟返回 404 InvalidEndpointOrModel.NotFound |

| seed | **78786**（全剧统一固定，提升同角色跨段音色/语速稳定；段级 api.seed 可覆盖） |
| ratio / resolution | `9:16` / `720p` |

| watermark | `false` |
| 参考图模型 | Seedream（doubao-seedream 系列，以方舟控制台当前可用最新版为准，调用名必须带版本后缀） |

| 人脸参考图 | 含可见人脸的形象用 `-mesh` 版（Seedance 人脸过滤）；剪影/背影用原图，以 `资产/形象索引.md` mesh 列登记为准 |

### 4.1 prompt_suffix（AI 字段一律英文，供 yaml 全文复制）

```
prompt_suffix: "Cinematic photorealistic sci-fi wasteland, rusted metal textures with glowing crystal light accents, dramatic character lighting, film grain, 24fps cadence, vertical 9:16 composition, {色彩阶段token}, no text, no subtitles, no watermark, no logo, no platform UI."
```

```
prompt_suffix_silent: "本段无对白无语音，禁止画面中出现任何文字。Cinematic photorealistic sci-fi wasteland, rusted metal with glowing crystal accents, dramatic lighting, vertical 9:16, {色彩阶段token}, no text, no watermark."
```

> `{色彩阶段token}` 按 §3.1 表替换；segment-builder 复制时必须完成替换，不得留占位符。

### 4.2 negative_prompt（结构性题材禁忌 · 本规范定义；创意类 negative 由设计师追加）

```
negative_prompt: "modern city skyline, contemporary streets, present-day cars, smartphones, real-world country flags, national emblems, police uniform, military uniform, judicial or courtroom iconography, religious symbols, real brand logos, license plates, text, subtitles, captions, watermark, UI elements, anime, cartoon, deformed hands, extra fingers"
```

**叙述性禁令（架空星际纪元）**：画面中禁止出现任何现代都市元素、现实国家/政治/军事/司法/宗教标识、军警制服、现实品牌；一切秩序符号使用架空商会体系（商会徽记、星环风控局、公议/仲裁场景均为商业章程语汇的视觉呈现）。

**必须体现元素**：星舰残骸垃圾山、锈蚀金属质感、晶核/源晶蓝光、光纹（分子光纹为女主异能视觉签名，蓝白色流动线条）、9:16 人物光影美感。

## 五、分段规则（Segment · AI 生成单位）

| 约束 | 值 |
|------|------|
| 单 segment 时长 | **4–12 秒**（Seedance fast 硬限制） |
| 理想时长 | 8–10 秒 |
| 每 segment 镜头数 | 1–3 镜 |
| 最小叙事单位 | 1 个完整 beat |
| 每集段落数 | 6–10 段（EP01/EP68 可至 12 段） |

**拆分原则**：①不得在一句对白中间切断；②不得在连续动作链中切断；③拆段边界=场景切换/主说话人切换/情绪断点；④单段主说话人 ≤2，长对手戏拆 `SEGxxa/SEGxxb`；⑤某镜自然时长 <4s → 并入同场景相邻段。

**关键区分**：`SCENE-###`=空间单位；`SEG##`=一次 API 调用。同一场景可含多个 segment；segment 不得跨场景。

## 八、音色规范

- **P0 唯一权威来源**：`资产/声音卡片.md`。segment-builder 写 yaml 时**全文复制** voice_prompt（不含「」），禁止缩写/改写/翻译。
- voice_prompt 一律英文；同一角色跨 segment 全文一致。
- 全剧固定 `seed: 78786` + 详细声音描述，提升跨段音色/语速稳定。
- 系统广播（EP01 宣判等）不占 CHAR-ID，声音卡片单列。
- character-designer 可在角色卡片下加 `voice_feedback` 子节提建议，经 drama-director 集间循环采纳后方可更新声音卡片。

## 九、年代/题材约束

- **年代**：架空星际纪元，无现实国家/政治/军事/司法/宗教映射（大纲元数据 + R1 合规 5/5 复核结论）。
- **秩序体系**：一切"执法/审判"以架空商会规则呈现——公议、仲裁、除名、放逐开垦、星环风控局调停；**禁止**出现法庭、警徽、军队番号等现实司法/军事视觉符号。
- **科技质感**：旧时代沉舰=厚重锈蚀工业风；核心星域=冷蓝无菌科技风；两者不得混淆（荒星侧禁止出现簇新高科技表面，总部侧禁止出现锈蚀废土质感——除剧情要求）。
- **异能视觉签名**：光纹=蓝白色分子级流动线条，仅在 CHAR-001（三阶后含 CHAR-004 血清伪光纹/CHAR-005 晶化）触发时出现；抑制波期间（EP42–44）光纹视觉全黑。
