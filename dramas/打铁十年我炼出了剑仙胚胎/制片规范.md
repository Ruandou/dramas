## 一、ID 命名规则

所有资产必须使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨 segment 出现→独立 CHAR-###；纯背景无台词→CHAR-GRP

### 形象层级结构定义

| 后缀     | 名称     | 说明                                           |
| -------- | -------- | ---------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                   |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01    |

#### prompt_suffix（追加到所有角色/场景/道具 Prompt 末尾）

```
cinematic lighting, photorealistic xianxia, Tang-Song dynasty hybrid clothing and architecture, ancient Chinese fantasy aesthetic, film grain, 35mm lens quality, high detail, 8K quality
```

#### negative_prompt（结构性约束——年代/题材禁忌）

```
modern, western, skyscraper, car, phone, watch, glasses, neon lights, anime style, cartoon, 3D render, plastic texture, unrealistic proportions, cyborg, robot, gun, modern military, jeans, T-shirt, sneakers, electric light, concrete building, glass curtain wall
```

> **说明**：本作设定为架空仙侠（唐宋混搭服饰+古代铁匠铺工具）。以上 negative_prompt 为**结构性年代禁忌**，由制片规范统一定义。创意领域 negative_prompt（如「禁止特定绘画风格」）由各设计师在各自 Prompt 中自行追加。

## 六、分段规则（Segment Rules）

### AI 生成单位

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 12–15 段        | 对应单集 2.5 分钟时长（150–180 秒）                     |
| 单集最短时长     | 140 秒          | 低于此值时需增加段落或延长 segment                      |
| 单集最长时长     | 200 秒          | 高于此值时需删除段落或压缩 segment                      |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 七、分集剧本格式规范

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`

## 八、工作流顺序（必读 · 防不同步）

制片规范确立后，所有内容修改**严格按层向下**：

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_打铁十年我炼出了剑仙胚胎_36集.md` | 集纲、每场剧情、对白要点、钩子                      |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡片、资产索引等       | 仅在前几步定稿后随需更新                            |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 九、受众定位

- **主频道**：男频
- **核心年龄段**：18-35
- **核心痛点**：被体系宣判"你不配"的无力感；手艺人的价值被等级制度否定；从底层靠技艺登顶的代入感
- **爽感期待**：SAT-SLAP（打脸）35% + SAT-COME（逆袭）30% + SAT-BURN（燃爽）20% + SAT-EMO（感动）15%
- **对标作品**：《凡人修仙传》（凡人逆袭）+ 《锻刀》（工匠精神）

### 题材制作复杂度预算

| 维度 | 评估 |
|------|------|
| 题材 | 仙侠/工匠成长/逆袭爽文 |
| 场景复杂度 | ★★★★（古装仙侠：断剑崖、铁匠铺、仙门、溶洞、洞府等多类型场景） |
| 角色数量 | 8（主要角色）+ 若干群演（剑宗弟子、散修等） |
| AI 生成难度 | 高（仙侠特效：剑光、灵气、领域、觉醒光效、百剑齐鸣等） |
| 预估周期 | 1.5x 标准周期 |
| 备注 | 剑胚四重觉醒需要4套视觉状态；第32集"万器归宗"百剑齐鸣是最大技术挑战 |

## 十、年代/题材约束

### 必须体现元素
- 唐宋混搭风格的服饰与建筑（架空仙侠，非严格历史还原）
- 古代铁匠铺的真实工具质感：风箱、铁砧、淬火池、炭火炉
- 修真体系视觉化：灵根、灵气光效、境界威压（灵压）、领域展开
- 剑胚四重觉醒状态的视觉递进：粗糙铁胚→符文浮现→半透明光影→金色剑脉纹路

### 禁止出现元素（叙述性约束）
- 任何现代科技产物（电灯、手机、汽车、枪械等）
- 西方奇幻元素（骑士铠甲、哥特建筑、魔法阵）
- 过于「二次元」或「网游风」的特效风格——须保持写实质感
- 任何明确朝代标识（如「唐」或「宋」旗号、年号）
