| 字段 | 内容 |

| **角色定位** | **主角**——凡人铁匠，剑胚创造者，全剧核心 |
| **阵营/派系** | 凡人工匠 → 天剑一脉继承者 → 「工匠修士」开创者 |
| **年龄** | 30 岁左右（第1集少年约15岁，第2集起十年后约25岁，跨度较大） |
| **首次出场** | EP01（少年） / EP02（成年） |
| **关键关系** | `CHAR-002`（剑胚）的主人/共生者；`CHAR-003`（白霜）的守护对象→伴侣；`CHAR-007`（竹剑先生）的传承者；`CHAR-006`（青云老祖）的终极对手 |
| **性格概要** | 沉默寡言、极度专注、以行动代替语言。十年如一日的执念是他最核心的性格驱动力。越愤怒越沉默，悲伤时去打铁而非哭泣。情感爆发方式是「锤声变重」。用铁匠的比喻理解世界——「铁不认人，只认火候」是他的哲学。 |

### 语言画像（对白创作约束）

- **词汇层级**：底层匠人词汇，绝不用修真术语（除非被白霜纠正后偶尔模仿使用）。多用铁匠行话——「火候」「淬」「锻」「钢口」「纹路」。
- **句式偏好**：短句为主，极少超过 15 个字。沉默是他最长的台词。开口时往往用比喻——且比喻一定来自打铁经验。
- **口头禅**：「铁不认人，只认火候。」（全剧出现 3 次——EP02 面对嘲笑，EP25 回到铁匠铺，EP36 结尾）
- **情绪表达方式**：越愤怒越沉默。悲伤时不会哭，会去打铁。唯一一次失控是 EP24 剑胚受损时——会低吼但不嘶喊。

### 外貌关键词（来自大纲）

精瘦结实，手掌布满老茧，肤色被炉火长期烘烤成古铜色，眼神专注深沉，旧布衣+皮围裙，右臂有金色剑纹。

| 字段 | 内容 |

| **阵营/派系** | 天剑一脉的意志载体 → 秦铁的共生体 → 「万剑之祖」 |
| **年龄** | 不可用人类年龄衡量（诞生于 EP03，承载剑仙百年记忆） |

| **关键关系** | `CHAR-001`（秦铁）的共生体与「灵根」；承载陨落剑仙的残存意志与天剑一脉集体意志 |
| **性格概要** | 四重觉醒前：通过振动/嗡鸣/光芒变化传达情绪，非人但逐渐产生情感（EP14「哭」是情感进化里程碑）。觉醒后：文言碎片式沟通，一字千钧——「危险」「仇」「剑」。承载天剑一脉所有死者的意志，EP34 自主执行「灵魂审判」是其人格化顶点。 |

### 语言画像（对白创作约束）

- **词汇层级**：三重觉醒前（EP03–EP15）无语言——通过振动/嗡鸣/光芒变化传达情绪。三重觉醒后（EP16 起）：古代文言风格，用词古朴，引述剑仙记忆碎片时使用天剑一脉的古语。
- **句式偏好**：极度精简。「认主。」「危险。」「仇。」「他在说谎。」——几乎从不用主语，因为它的「自我」是模糊的。
- **口头禅**：无固定口头禅，但高频词是「剑」和「铁」。
- **情绪表达方式**：情感最浓时反而最安静——EP14「哭」时没有任何声音，只是微微震颤，光芒变得潮湿般朦胧。

| **年龄** | 25 岁左右 |

| **性格概要** | 清冷但不疏离。温柔用问句表达——「你确定吗？」是给秦铁留退路也是给自己留。前期使用修真标准术语，与秦铁相处后语言逐渐「接地气」。她的核心矛盾是「宗门忠诚」与「对秦铁的认同」之间的撕裂。EP35 得知师父真相后信仰崩塌，EP36 选择不再用「师门」定义自己。 |

### 语言画像（对白创作约束）

- **词汇层级**：受过正规宗门教育，能使用修真标准术语。但与秦铁相处后，语言逐渐「接地气」。前期会说「阁下」「道友」，后期直呼「秦铁」。
- **句式偏好**：喜欢用疑问句表达关心——「你确定吗？」「真的可以吗？」「你为什么不逃？」——她的温柔体现在「给对方留退路」的提问方式上。
- **口头禅**：无。（她不是一个有固定口头禅的人——这反映了她「没有完全找到自己」的处境。直到 EP36，她在茶棚里第一次说出一句属于自己的话：「茶比灵丹好喝。」）
- **情绪表达方式**：悲伤时沉默，愤怒时会语速变快并直视对方眼睛。对秦铁的感情不通过言语表达，而是通过「站在他身后」的行动。

### 外貌关键词（来自大纲）

25 岁左右，清冷但不疏离，素色长裙，发髻简洁，眼角有一点泪痣，战斗时使一柄薄如霜的灵剑（PROP-008）。
