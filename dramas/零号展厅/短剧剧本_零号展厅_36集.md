# 短剧剧本·零号展厅（36集）

> 来源：上海精品概念包（2026 政策扶持向）
> 更新日期：2026年5月28日

## 项目信息

- **类型**：艺术 / 轻悬疑 / 爱情
- **集数**：36 集 × 2–3 分钟
- **叙事节奏**：画作线索 → 追踪解密 → 艺术圈暗战 → 感情升温 → 集末反转
- **平台定位**：女频+文艺破圈（「艺术悬疑」新品类，对标《只此青绿》文化热但做悬疑叙事）
- **政策契合**：文+商+展（西岸美术馆群×画廊生态×当代艺术），瞄准上海"沪8条"最高450万扶持
- **AI 友好度**：★★★★★

## 一句话简介

西岸美术馆的实习生姜念在库房发现了**7幅从未展出的画**，每幅画背面刻着一组GPS坐标——**那些坐标指向的地方，20年前都"消失"过人。** 画家"零先生"画的不是风景，是**上海被遗忘的角落和被遗忘的人。**

## 为什么现在能火

- **西岸艺术区**是上海近3年最成功的文旅新地标（龙美术馆、余德耀、星美术馆），但**零短剧**以此为叙事空间——赛道完全空白。
- 「7幅画 = 7个谜」天然适合短剧**单元+连续剧**结构，每1–2集解一幅画，投流切片标题自带悬念（"这幅画背后藏着一个消失了20年的家庭"）。
- 艺术+悬疑赛道在欧美已验证（《达芬奇密码》类），中国短剧尚未出现同类，差异化极强。
- 视觉场景：画廊白墙 = **AI最稳定的室内环境**（纯色背景+人物对话）。

## 与库内差异

- 非《全城找耳机》轻悬疑追踪；本剧有**20年历史纵深**与社会议题。
- 非《全公司都以为我很有背景》职场喜剧；本剧艺术圈设定高度差异化。
- 非《冥牌调解处》奇幻解谜；本剧全程**写实**，悬疑来自人心而非超自然。

## 金手指/核心设定

**「7画7谜」结构**：零先生20年前受孟奕华委托，画下"即将消失的上海角落"——但画完后他意识到这些地方消失的同时，住户也被粗暴对待（强制商业拆迁，非政府行为）。他在每幅画背后刻下坐标作为"证据"，然后隐退。7幅画 = 7个被商业开发强制"遗忘"的社区故事，最终指向一个统一的幕后开发商——孟奕华。

**重要合规说明**："消失"是指被私营开发商通过不当商业手段逼迁的居民（非政府行为、非政治迫害），故事导向是**社区团聚与记忆修复**，结局正面——公开展览恢复了这些家庭的故事，获得社会认可和补偿。

## 季线（13–36集）

第3–6幅画逐一解密 → 每幅画还原一个"被遗忘"的家庭故事 → 陈桥最终出面：他当年沉默是因为孟奕华威胁他的家人 → 第7幅画：画的是孟奕华自己的童年旧居（他也曾是被拆迁的人，后来"加入了加害者"）→ 姜念策划"零号展厅"特别展：在西岸美术馆公开展出全部7幅画+被遗忘家庭的故事 → 展览引发社会关注，孟奕华被商业伙伴抛弃 → 画中家庭在展览开幕日重聚 → 苏屿与姜念在滨江的告白。
