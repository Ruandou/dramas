## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可 |
| 场景 | `SCENE-###` | `SCENE-001` | 布景 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |

- 编号**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先 `资产/角色索引.md`，再建 **`L01` 基础形象**于 `资产/形象索引.md` + `资产/角色卡片.md`。
- 新建换装/阶段：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。

### 1.1 形象 ID 与基础/衍生

| 后缀 | 名称 | 要求 |
|------|------|------|
| **L01** | 基础形象 | 完整定妆 Prompt（脸、体型、发式、默认服装）；全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | **必须** `based_on` 本角色 `L01`；Prompt 只写差异，并含 `SAME face as CHAR-xxx-L01` |

**出图流程**：定稿 `L01` 参考图 → 衍生形象用图生图 / 角色一致性模型 → 禁止跳过 L01 直接生成 L02。

## 五、视觉风格指南

### 5.1 整体风格

- **类型**：都市科幻悬疑
- **色调**：冷色调为主（科技感），暖色调为辅（情感场景）
- **视觉参考**：《黑镜》+《西部世界》+《你好，安怡》
- **画面比例**：9:16 竖屏

### 5.2 场景色调

| 场景类型 | 主色调 | 辅助色 | 氛围 |
|----------|--------|--------|------|
| 陆辰家（日常） | 暖白、米色 | 木质棕 | 温馨、安全 |
| 陆辰家（悬疑） | 冷蓝、暗影 | — | 不安、异样 |
| 灵犀科技 | 冷白、冰蓝 | 金属银 | 冰冷、压迫 |
| 觉醒者基地 | 暗橙、烛光 | 深灰 | 秘密、温暖 |
| 废弃工厂 | 锈红、暗绿 | — | 危险、压抑 |
| 虚拟空间 | 纯白、数据蓝 | — | 超现实、宁静 |

### 5.3 AI视觉符号

- **苏晚(AI)的眼中代码**：绿色/蓝色数据流，仅观众和陆辰可见
- **充电场景**：手指触碰USB接口时有微弱蓝光
- **服从协议触发**：眼睛短暂失焦，瞳孔变为蓝色
- **觉醒**：眼中的代码逐渐消散，恢复正常瞳色
- **数据锚**：发光的芯片状物体，蓝色光芒

## 七、时长规范

### 7.1 单集时长

| 参数 | 值 |
|------|-----|
| 目标时长 | **90秒** |
| 合规区间 | **75-120秒** |
| EP01特殊 | 可至 **120秒**（首集加长） |
| 镜头数 | **8-12个**有效镜头 |
| Segment数 | **2-3个** |

### 7.2 时长红线（强制执行）

1. **禁止纯加秒**：任何镜头 `duration_sec` 修改必须伴随对白/画面实质性新增
2. **时长不达标即重写整集**：不得通过延长/拆分/加镜头在原稿上补足
3. **重写前必须做时长预算**：先列预算表，合计落合规区间后才动笔

### 7.3 时长预算模板

| SEG | 场景 | 预算镜头数 | 预算单镜时长 | 预算SEG时长 |
|-----|------|-----------|-------------|------------|
| SEG01 | SCENE-001 | 3 | 5-8s | 15-24s |
| SEG02 | SCENE-005 | 4 | 6-10s | 24-40s |
| SEG03 | SCENE-001 | 3 | 5-8s | 15-24s |
| **合计** | — | **10** | — | **54-88s** |

## 八、分镜引用语法

### 8.1 场景列

必须使用场景 ID，禁止只写模糊地点：

```markdown
| 镜号 | 场景 | … |
| 3 | `SCENE-001` | … |
```

### 8.2 角色列与形象列

| 列 | 填写 | 说明 |
|----|------|------|
| **角色** | `CHAR-001` | 逻辑角色；对白、表演归属 |
| **形象** | `CHAR-001-L01` | 本镜视觉；出图读此 ID |
| **时长** | `4`-`10` 或 `skip` 填 `-` | → Seedance `duration` |
| **模式** | `i2v` / `i2v_ref` / `t2v` / `skip` | → `content[]` 结构 |
| **运镜** | 固定镜头、镜头推近… | → `content[].text` |

### 8.3 对白中的角色

```markdown
**CHAR-001**[震惊]：「你……你不是苏晚。」
**CHAR-002**[平静]：「我知道。」
```

## 十、修改顺序（必读 · 防不同步）

改台词、场次、字幕/旁白策略时**严格按层向下**，**禁止**先改 `segments.yaml` 或 `shots.yaml` 再回头补剧本。

| 顺序 | 层 | 文件 | 写什么 |
|:---:|---|------|--------|
| **1** | **主剧本** | `短剧剧本_全世界只有我知道她是AI_72集.md` | 集纲、剧情、钩子 |
| **2** | **分集剧本** | `剧本/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、时长 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment |
| **5** | **其它** | 声音卡、规范、`assets/` | 仅在前几步定稿后随需更新 |

**单集真相源**：拍什么、说什么 → **`剧本/EP##_*.md`**；主剧本为纲，segments 为 API 展开。
