## 生成规则

1. **L01必须先生**：所有L02+都必须基于已生成的L01
2. **L02+必须传L01参考图**：使用 `--image-url` 传入L01的TOS URL
3. **Prompt含面部一致性指令**：`SAME person as reference, Keep the SAME face`
4. **禁止仅靠文本FACE ANCHOR**：Seedream无法从文本复现同一张脸

## 生成命令模板

```bash
# L01 基础形象
python3 mcps/volc-ark/scripts/ark_seedream_image.py generate \
  --prompt "[L01 Prompt]" \
  --output "dramas/全世界只有我知道她是AI/assets/looks/CHAR-XXX-L01.png"

# L02+ 衍生形象（必须传L01参考）
python3 mcps/volc-ark/scripts/ark_seedream_image.py generate \
  --image-url "https://.../CHAR-XXX-L01.png" \
  --prompt "SAME person as reference, [差异描述]" \
  --output "dramas/全世界只有我知道她是AI/assets/looks/CHAR-XXX-L02.png"
```
