## 二、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角 |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉 |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 按需创建，不设上限 |
| 场景 | `SCENE-###` | `SCENE-001` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |
| 段落 | `SEG##` | `SEG01` | AI 生成单位 |

### ID 分配规则

- 编号**连续、不跳号**；只增不删
- 弃用资产标 `deprecated: true`
- 主要角色 CHAR-001 ~ CHAR-008，次要角色 CHAR-009 ~ CHAR-014
- 群演由 scene-writer 在剧本中标注 `[待补：...]`，由 production-planner 在集间循环中统一分配 `CHAR-GRP-##`
- 形象层级：L01 = 基础形象（全剧面部一致性锚点），L02+ = 衍生形象（必须 `based_on` 本角色 L01）

| 顺序 | 层 | 文件 | 写什么 |

## 七、分段规则

### 硬约束

| 约束 | 值 | 说明 |
|------|----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | EP01 可至 12 段 |
| 每集镜头数 | 8–12 镜 | |
| 单段主说话人 | ≤ 2 | 长对手戏拆成 SEGxxa / SEGxxb |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**
5. segment **不得**跨场景

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment

## 十、年代/题材约束

### 必须体现元素

- 现代都市豪门生活质感（别墅、豪车、高端商场）
- 商业精英着装风格（高定西装、名牌配饰）
- 科技公司与医院的专业环境
- 上流社交场合（慈善晚宴、签约仪式、上市敲钟）

### 禁止出现元素

- 古代/历史服装或布景
- 仙侠/玄幻特效（如法术、灵气）
- 过度暴力血腥画面
- 任何违反现代都市设定的元素
- 未成年人不宜内容

## 内容合规参数

### 题材合规等级

**C 级（低风险）**——现代都市言情/豪门题材，无涉及历史敏感、宗教、政治等高风险领域。

### 本剧特定红线

1. **家庭暴力**：赵美兰对苏锦的欺辱仅限语言羞辱和社交排挤，**禁止**出现肢体暴力画面
2. **商战合规**：商业竞争情节不得涉及真实公司/品牌名称，所有公司均为虚构
3. **医疗场景**：手术/急救场景不得出现过于真实的血腥画面，保持专业但温和的呈现
4. **司法程序**：逮捕/审讯场景需符合基本法律程序，不得丑化执法机关
5. **精神疾病**：EP53-54 精神病院情节**禁止**污名化精神疾病患者，重点放在反派利用制度的恶行

### 灰区处理策略

1. **替嫁设定**：强调苏锦是被迫替嫁的受害者，后续剧情明确她的自主选择和独立人格
2. **复仇/打脸**：苏锦的反击以实力和智慧为核心（展示身份、商业布局），**禁止**以暴制暴
3. **豪门内斗**：财产争夺以合法商业手段呈现（股权、董事会投票），不涉及非法手段细节
4. **身份隐瞒**：苏锦隐瞒身份是出于自保而非欺骗，剧情需明确她的善意动机

### 正向价值锚点

1. **女性独立与自我价值**：苏锦不依赖任何人的身份，靠自己的专业能力和商业才华立足
2. **选择善良**：全剧主题——"人生最难的不是翻盘，是翻盘之后依然选择善良"
3. **正义必胜**：所有反派的罪行最终通过法律途径得到审判

### 平台审核重点提示（前 3 集）

- **EP01**：替嫁场景注意不要暗示人口买卖/强迫婚姻；婚礼羞辱保持在语言层面
- **EP02**：小姑泼粥场景注意不要过度呈现霸凌；钱福监视行为需暗示为个人行为而非合理
- **EP03**：继妹嘲讽场景注意不出现脏话/侮辱性称呼；男主维护女主的方式要正向

| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白备注 |
