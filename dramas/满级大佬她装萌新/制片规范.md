# 《满级大佬她装萌新》制片规范 · ID 与引用

> **正名**：《满级大佬她装萌新》

> **题材**：校园甜爽 / 身份反转 / 打脸喜剧 / 女频
> **年代**：当代（2025–2026年）
> **集数**：72集 · 6幕结构
> **单集时长**：90秒（EP01 可达 120秒）
> **总时长**：约 108 分钟（72 × 90s）
> **画面比例**：9:16 竖屏
> **生成工具**：Seedance 2.0 fast（doubao-seedance-2-0-fast-260128）

## 一、ID 命名规则

所有资产使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角 |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉 |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可 |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨 segment 出现 → 独立 CHAR-###；纯背景无台词 → CHAR-GRP

### 形象层级

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

## 四、工作流顺序（必读 · 防不同步）

制片规范确立后，所有内容修改**严格按层向下**：

| 顺序 | 层 | 文件 | 写什么 |
|:---:|------|------|--------|
| **1** | **主剧本** | `短剧剧本_满级大佬她装萌新_72集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 六、分段规则

### 分段（Segment）约束 —— AI 生成单位

| 约束 | 值 | 说明 |
|------|------|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段（EP01: 10–12段） | 对应单集 90 秒（EP01 为 120 秒） |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 分集剧本格式规范

> 分集剧本（`剧本/EP##/EP##_*.md`）是单集的**真相源**。

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`

## 九、年代/题材约束

### 必须体现元素

- 当代中国大学校园环境（现代建筑、智能手机、电子屏幕）
- 2025–2026年科技水平（高性能服务器、暗网、AI象棋引擎）
- 现代休闲服装为主（T恤、卫衣、牛仔裤、运动鞋）
- 国际赛场需体现全球化氛围（多国旗、大屏幕直播、专业灯光）

### 禁止出现元素（结构性 negative_prompt）

- 古装/汉服/朝代服饰（本剧为纯当代题材）
- 冷兵器（刀剑等，格斗场景仅限徒手格斗）
- 魔法/仙侠特效（本剧无超自然元素，三重身份均为人类技能极限）
- 民国/战争年代元素
- 过度夸张的科幻设备（保持当代科技合理性）

> **注**：创意领域 negative_prompt（如「禁止动漫风格」）由 scene-designer / character-designer 各自负责。

## 十三、数据权威性声明

### voice_prompt 权威来源

| 优先级 | 文件 | 说明 |

| **P0** | `资产/声音卡片.md` | 专门定义声音参数，最权威 |

### 角色数据权威来源

| 数据类型 | 权威来源 |
|----------|----------|
| 角色 ID（CHAR-###） | `资产/角色索引.md`（production-planner 分配） |
| 形象 ID（CHAR-###-L##） | `资产/角色卡片.md` / `资产/形象索引.md` |

### 跨文件一致性

- 声音卡片 ↔ 角色卡片：voice_prompt 如有差异，以声音卡片为准
- 场景卡片/道具卡片 ↔ 分集剧本：剧本中不得引用未在卡片中注册的 ID
- 禁止不同文件中同一 ID 有不同定义

## 十四、待确认放行协议

当某个门控阶段需要用户审批但用户 **3 轮用户交互内未回应**时：

1. **文本自检降级**：由当前门控负责方执行自检（分辨率、文件完整性、ID一致性、命名规范）
2. **待确认放行标记**：自检通过的资产标记为「⚠️ 待用户确认」，写入 `工作计划.md`
3. **不通过则返工**：自检未通过必须返工，不依赖用户响应
4. **用户回应后处理**：确认→正式通过；否决→下游回退
