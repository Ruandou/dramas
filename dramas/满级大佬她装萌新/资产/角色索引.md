## ID 分配规则

1. 编号连续、不跳号，只增不删
2. 弃用角色标 `deprecated: true`，不回收 ID
3. 新增角色须先在本索引登记，再由 character-designer 建形象
4. 群演分级：有名字+跨 segment 出现 → 独立 CHAR-###；纯背景无台词 → CHAR-GRP
5. CHAR-### ID 分配权归 production-planner，character-designer 不可自行新增
