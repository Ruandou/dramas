## 一、项目概述

| 集数 | 72 集 |

## 二、受众定位

| 维度 | 内容 |
|------|------|
| 主频道 | 女频 |
| 核心年龄段 | 45+ 银发族（核心）+ 30-45 岁女性（破圈） |
| 核心痛点 | ①人生遗憾无法弥补 ②母女关系的隔阂与和解 ③在"安全"与"梦想"之间被迫选择 |
| 爽感期待 | SAT-SLAP 30%（拒绝前世错误选择的爽感）+ SAT-COME 25%（梦想实现的逆袭）+ SAT-EMO 30%（亲情催泪）+ SAT-MYST 15%（跨时空悬念） |

## 十、分段规则

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |

### 拆分原则

1. **不得**在对话中间切断 segment
2. **不得**在连续动作进行中切断
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2
5. 某镜自然时长 < 4 秒 → 并入同场景相邻段

## 十三、年代/题材约束

### 1988 年必须体现的元素

- 物价细节（一毛钱汽水、50块钱的大数目）
- 流行歌曲（《恋曲1990》）
- 社会风貌（国营饭店、师范分配、"女孩子工作稳定"）
- 物质稀缺（电视机是奢侈品、书信通信）
- 穿着（碎花衬衫、中山装、布鞋）

### 2000 年必须体现的元素

- 千禧年氛围（跨年烟花、世纪交替感）
- 90 年代末-2000 年代初家居（彩电、缝纫机、水泥地）
- 绿皮火车、书信渐被电话取代

### 2016 年必须体现的元素

- 现代医院（心电监护仪、单人病房）
- 成年女儿的现代气质

### 禁止出现的元素

- 1988 年：手机、LED 屏、现代汽车、塑料家具、当代时装
- 2000 年：触屏手机、电动车、社交媒体界面
- 所有年代：动漫风格、奇幻/科幻元素、不合理的时代穿越物品

## 十四、内容合规参数

### 题材合规等级

**B级**（有敏感主题，需注意处理方式）

本剧涉及家庭冲突（母亲反对女儿追求梦想）、代际创伤、母女关系破裂等敏感话题，但均为正向解决、温情收束。无暴力、犯罪、色情内容。

### 本剧特定红线

1. **禁止美化"不认女儿"的威胁**：母亲说"别认我这个妈"（EP18）后必须有情感转折和理解，不可将其作为正面行为呈现
2. **禁止渲染重生作弊/投机**：主角的"先知优势"用于弥补遗憾而非谋取利益
3. **禁止丑化任何时代**：1988 年的"落后"不作为笑点，而作为年代质感呈现
4. **医疗场景需专业**：心脏手术、病房场景不得出现明显医学错误
5. **母女冲突不得导向暴力**：争吵用语言，不可出现肢体冲突

### 灰区处理策略

| 灰区 | 处理方式 |
|------|---------|
| 母亲"控制型教育"的呈现 | 通过 EP13 母亲创伤背景揭示动机，转化为"笨拙的爱" |
| 赵建国被拒绝的痛苦 | EP66 释然收束，不渲染单方面执念 |
| "嫁给有钱人"的周慧兰 | EP69 花店独立，不作道德审判，仅作镜像对比 |
| 跨时空机制的逻辑性 | 留白处理（意识穿越），不做硬科幻解释 |

### 正向价值锚点

1. **遗憾是生命的礼物**：重生的意义不是消除遗憾，而是带着爱去面对遗憾
2. **母亲的爱有千万种表达**：无论控制、缺席还是沉默，母爱的本质是"想让你过得好"
3. **选择没有标准答案**："安全"和"梦想"都有代价，重要的是为自己的选择负责

### 平台审核重点提示（前3集）

| 集数 | 审核要点 |
|------|---------|
| EP01 | 重生设定需合理化（麻醉意识穿越），避免"自杀重生"等敏感触发词 |
| EP02 | 母亲催婚内容注意平衡——不可单方面丑化传统价值观 |
| EP03 | 学校场景注意教育政策准确性——1988年师范分配制度 |
