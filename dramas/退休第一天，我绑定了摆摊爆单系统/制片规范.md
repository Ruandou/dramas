## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同角色独立 ID + L01（按需创建） |
| 场景     | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### ID 分配规则

- 编号**连续、不跳号**；ID **只增不删**，弃用标 `deprecated: true`
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01`
- 换装/阶段形象：只加 `L02+`，必须写明 `based_on: CHAR-###-L01`，禁止跳过 L01
- 群演：有名字+跨 segment → 独立 `CHAR-###`；无名功能角色（有台词、按集出没）→ `CHAR-GRP-##`（每个视觉不同角色独立 ID+L01）；纯氛围群像（上班族/街坊/环卫工/评委/记者）**不分配 ID**，由 scene-writer 标注 `[待补：...]` 后在集间群演回补子循环统一分配
- 参考图配额：每 segment ≤6 张（TOS URL 模式），超出按 segment-builder 优先级裁减

## 二、视觉风格锚点 (Visual Style Anchor)

> 与大纲 YAML 元数据严格一致；创意细节由 character/prop/scene-designer 展开，本表为不可违背的方向锚。

| 维度 | 规格 |
|------|------|
| 渲染风格 | photorealistic 都市市井写实（烟火气街景 + 美食静物高光特写） |
| 镜头参考 | cinematic 35mm 街景纪实感；美食特写 85mm 浅景深 |
| 色调方向 | **暖色烟火**（摊位/家庭线：暖黄橙红、钨丝灯、蒸汽光晕）× **冷色对照**（饭点集团/写字楼/医院：冷灰蓝、玻璃幕墙）× **系统 UI 青金色**（仅后期字幕层，见 §十·1） |
| 画幅 | 9:16 vertical（竖屏） |
| 年代 | 现代（当代中国二线城市，架空城市"江州"） |
| 题材关键词 | 市井烟火、街头美食、蒸汽灯带、家常温情、轻科幻 UI 点缀（后期） |

### 全局 prompt_suffix（设计师出图统一追加）

```
photorealistic, contemporary Chinese second-tier city street life, warm tungsten
street-food glow, cinematic lighting, vertical 9:16 composition, high detail,
authentic everyday textures
```

> 冷色系场景（饭点集团/写字楼/医院）由 scene-designer 将 `warm tungsten street-food glow` 替换为 `cool desaturated corporate blue-grey tone`，其余后缀不变。

### 全局 negative_prompt（题材/年代结构性禁忌，任何出图不得省略）

```
traditional Chinese characters, wrong Chinese characters, garbled text, gibberish
signage, Western faces, Caucasian features, Japanese or Korean street elements,
luxury glamour filter, opulent mansion aesthetics, anime style, watermark,
subtitles, UI overlay, holographic HUD, ghost, supernatural glow, religious
iconography, dirty slum misery look, uniformed officer negative portrayal
```

要点解释（结构性约束，不可删）：
1. **繁体字/错误汉字**：本剧中文文字道具多达 13 项，任何含文字画面必须简体、笔画正确
2. **西方面孔/日韩街景**：全员当代中国面孔、大陆二线城市街景
3. **现代奢华滤镜**：与市井题材冲突（饭点集团的"冷色高级感"≠奢华炫富）
4. **UI overlay / holographic HUD**：系统 UI 严禁进生成画面（见 §十·1）
5. **ghost/supernatural**：系统为 AI 科幻轻设定，零神鬼元素（合规 P0）
6. **苦难/丑化**：环卫工等拍"捧碗哈气+笑"的暖，不拍狼狈苦相；公职人员零负面视觉

## 六、分段规则（Seedance 硬约束）

| 约束             | 值              |
| ---------------- | --------------- |
| 单 segment 时长  | **4–12 秒**（硬限制，超出必须拆分） |
| 理想时长         | 8–10 秒         |
| 每 segment 镜头数 | 1–3 镜         |
| 最小叙事单位     | 1 个完整 beat   |
| 单段主说话人     | ≤2（长对手戏拆 `SEGxxa/b`） |

拆分原则：
1. 不得在一句对白中间切断 segment
2. 不得在连续动作链（掀蒸笼、递碗、拧勺柄）中间切断
3. 拆段边界 = 场景切换 / 主说话人切换 / 情绪断点
4. 分镜表某镜自然时长 <4 秒 → 并入同场景相邻段
5. **场景（SCENE-###）= 空间单位；segment = 生成单位**；同场景可含多 segment，segment 不得跨场景

## 九、年代/题材约束（叙述性）

**必须体现**：
- 当代中国二线城市市井质感：便民疏导点、灯带、扫码收款音箱、外卖骑手、竹蒸笼
- 美食高光：白汽、爆汁、清汤、锅气——美食静物特写是本剧 Seedream 主战场
- 三轮车摊→升级摊车→金奖摊→夜市的**阶段演进**（见场景卡片 SCENE-001 P1-P4）
- 公职人员（市场管理员、监管、规划科）制服整洁、程序正义的正面形象

**禁止出现**：
- 繁体字、错别字、乱码招牌（全城招牌/价目/横幅均简体）
- 神鬼、显灵、宿命暗示（师父影像必须带【传味科技·AI复原】水印语境，后期实现）
- 城管暴力执法、公职人员负面镜头语言
- 奢华炫富视觉、贫困苦难消费视觉（环卫工=暖，不=惨）
- 现代都市剧常见但与题材不符的元素：豪车豪宅炫耀镜头、夜店、赌博意象

## 十、专项技术规范

### 1. 系统 UI（青金色半透明字幕层）——后期合成，禁入生成

- 系统界面（任务卡片、倒计时、验证进度条、【传味科技·AI复原】水印）**一律由后期字幕层合成**（ffmpeg/剪辑软件模板），登记为 PROP-014
- **禁止**在 Seedream/Seedance 任何 prompt 中写入 UI、HUD、hologram、floating text、interface 等元素；负面词已含 `UI overlay, holographic HUD`
- 老花镜（PROP-001）出图为**普通玳瑁圆框眼镜**，镜片干净无发光；"镜片浮现青金 UI"效果 100% 后期
- 分集剧本以 `[系统UI：任务文案…]` 标注字幕层内容，segment-builder 不将其写入视觉 prompt
- 字幕（对白/系统 UI）均后期添加，Seedance 不烧录任何字幕

### 2. 中文文字道具（13 项）
