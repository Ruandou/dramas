## SEG 正文

### 🚫 多句对白写在同一格（禁止空管子续行）

一个镜头如有 3 句对白，3 句都写在「对白/备注」那一格里，用换行分隔：

✅ **正确写法**（一行就是一个镜头，多句对白塞进同一格）：
```
| 1 | EP01-S01 | SCENE-002 | CHAR-002 | CHAR-002-L01 | 中景 | 10 | i2v_ref | 固定镜头 | 画面描述... | **CHAR-002**[大声]：「都安静一下。」
**CHAR-002**[环视]：「今天趁大家都在，把话说清楚。」
**CHAR-001**[内心]：「他那个表情…我见过。」 |
```

❌ **错误写法（禁止）**—— 用空管子续行：
```
| 1 | EP01-S01 | ... | ... | ... | ... | ... | ... | ... | 画面 | 对白1 |
| | | | | | | | | | | 对白2 |   ← ❌ 这是空管子续行，禁止
| | | | | | | | | | | 对白3 |   ← ❌
```

> 规则：**一行 = 一个镜头**。多句对白/独白在 `|` 之间的最后一格里换行书写，不得用 `| | | | |...` 续行。
