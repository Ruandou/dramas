## Top 3 问题（按严重程度排序）

### 问题 1：攀升段中段节奏偏缓——"采访循环"话唠症风险
- **位置**：EP12-EP18（攀升段开场，连续7集）
- **问题描述**：攀升段以"采访每个角色→写支线→安抚角色"为核心循环模式。EP12(采访赵景和)、EP13(沈长渊改戏)、EP14(太妃反击)、EP15(付费卡点/修改皇帝)、EP16(反转太妃)、EP17(采访苏晚晴)、EP18(翠微线+自动编剧)——虽然逐集有钩子，但行动模式高度重复（对话→写戏→对话→写戏），缺少视觉动作节拍和物理空间的转换。连续4-5集以室内对话为主场景，构成"话唠症"风险——观众可能在EP14-EP15之间产生"一直在说话"的疲劳感，即使钩子存在也会削弱留存动力。
- **影响维度**：维度1(观众留存)扣1分依据 + 维度2(情绪收益)扣1分依据
- **建议修改**：
  1. **压缩采访→动作化**：将"采访角色"改为"角色主动找林小满麻烦/求助"——每个角色登场自带冲突，而不是林小满逐个去问。例如苏晚晴不必等到EP17才登场谈诉求，可以在EP13就闯入对话。
  2. **插入追逐/逃跑戏**：在采访循环中插入太妃的"物理追杀"——EP14太妃反击可以是侍卫追捕林小满的追逐戏，穿插在采访之间。
  3. **每集场景≥3个**：确保每集至少有3个物理场景切换，避免连续同一场景超过2个segments。
  4. **减少"纯对话"segment**：每集中至少插入1个无对白/少对白的视觉节拍（表情特写、环境空镜、动作反应）。

### 问题 2：高难度视觉特效对AI制作的可行性挑战
- **位置**：EP11(天空裂纹)、EP30(世界剧烈刷新)、EP32(世界崩塌·天空碎成碎片·大地开裂)、EP44(镜子水面波动→夹缝)、EP54(世界拆解为光点再重组)、EP55(双世界风景叠影/拼贴画)
- **问题描述**：大纲设计了至少6处需要高难度视觉特效的场景，包括世界崩塌、空间扭曲、抽象空间生成、全屏粒子化重组、双世界实时叠影。这些效果在当前AI视频生成技术下难以一次性高质量输出，通常需要后期合成或分步渲染拼接。<100万元预算下，这些特效若无简化方案将显著增加制作周期和成本。
- **影响维度**：维度3(制作可行性) 是本维度扣至3分的核心原因
- **建议修改**：
  1. **为每个特效场景准备"简化版"替代方案**：
     - 世界崩塌(EP32)：用"画面剧烈抖动+闪烁过渡+0.5秒黑屏"替代全屏碎裂渲染
     - 世界刷新(EP04/EP30)：用"0.5秒褪色至饱和度最低再恢复"替代粒子化刷新
     - 镜子夹缝(EP44)：用"镜头推近→cross dissolve转场→灰白色空间"替代水面波动效果
     - 世界化为光点(EP54)：用"快速蒙太奇剪辑(2秒内闪过所有角色画面)→静止在白空间"替代粒子化
     - 双世界叠影(EP55)：用"画中画/分屏/叠化交替"替代全屏合成拼贴
  2. **作者空间(EP48/EP50/EP54)**：明确设计为极简风格——纯白背景+地面网格线+空中漂浮文字碎片。这是AI最容易生成的抽象空间。
  3. **在制片规范阶段**为每个特效场景标注"默认方案"和"简化方案"，由production-planner评估后决定执行路径。

### 问题 3：首个付费转化卡点(EP15)出现偏晚
- **位置**：EP15（首个付费卡点——修改皇帝性格消耗5天倒计时）
- **问题描述**：EP15作为首卡点出现在第15集。虽然72集剧的前15集出现首卡不算行业极端，但本项目前10集以"揭秘震撼+搞笑"为主情绪，"不公感"到EP11才出现，"危机恐惧"到EP11-EP15才逐步建立。观众在EP01-EP10期间感受到的是"有趣"但未必"迫切想知道下一集"。对于一个<100万投资的短剧，首卡点需要在前10集内建立足够的付费冲动。
- **影响维度**：维度5(商业性) 扣分依据
- **建议修改**：
  1. **在EP07-EP09之间增设前置付费卡点**：可以利用"房东照片和沈长渊一模一样"这个悬念做第一个付费钩子——让观众在EP08末尾需要付费才能知道照片里的人是谁。
  2. **EP08(照片发现)改为卡点**：目前EP08末尾林小满"瞳孔地震"后藏手机——这是一个天然付费切口。如果EP08收费，EP09揭示"租房合同签名也是沈长渊"，形成集间闭环。
  3. **或整体前移**：将"72天倒计时"(目前EP11)提前到EP08-EP09出现，让时间紧迫感更早推动付费意愿。
  4. **确保EP01-EP03开场三集建立足够"不可抗拒"的好奇心**：目前EP01开头120秒完成"穿越+觉醒+上一个编剧"三连击，这个节奏是对的——保持这个密度，不要稀释。

## 综合建议清单（scene-writer 阶段必读）

### 结构层面
1. **EP12-EP18 采访循环**：必须打破"采访→写支线→采访"的节奏模式。建议将苏晚晴的登场提前到EP13-EP14，让两条线索并行推进，而不是串行处理。
2. **EP08-EP10 前置付费强化**：利用"照片→租房合同→空号电话"的三连击作为前置付费钩子，降低EP15首个付费卡点的压力。
3. **EP69的呼吸集**：虽然温暖治愈是必要节奏，但须确保集末钩子强度不弱于其他集——目前"太妃茶馆杭州分店"的hook是好的，保持。

### 制作层面
1. **所有特效场景**必须在进入stage 4前完成简化方案设计，写入制片规范。
2. **双视觉风格**需要确定主次比例——建议古装世界占70%，现实世界占30%，降低艺术风格切换频率。
3. **角色一致性**：两个沈长渊的长相完全一致——这是AI生成的高难度点。建议现实版沈长渊通过"眼镜+服装+发型"与古装版形成显性区隔，降低AI混淆概率。

### 剧本写作层面
1. 每集开场前3秒必须有不可抗拒的视觉/对话钩子（参照EP01的"上一个编剧哭着跑出去了"）。
2. 每集至少3个场景切换，避免连续2个segment在同一场景。
3. 主要角色的语言风格区分（大纲已预设计）必须在剧本阶段严格执行——这是本剧"元叙事"魅力的核心载体。
