## 一、ID 命名规则

所有资产使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型 | 格式 | 示例 | 用途 |
| ---- | ---- | ---- | ---- |
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同角色独立 ID + L01（按需创建，无上限） |
| 场景 | `SCENE-###` | `SCENE-001` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**；新建角色先在 `资产/角色索引.md` 登记，再由 character-designer 建 `L01`
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`；禁止跳过 L01
- 群演按需创建，不设数量上限：有名字 + 跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词但需视觉区分 → `CHAR-GRP-##`。每个 `CHAR-GRP-##` 都必须分配独立 ID 和 L01 形象（本剧已预置 CHAR-GRP-01~04，见角色索引）
- 同一 `CHAR-GRP-##` 可跨集复用，但不同视觉角色不可共用同一 ID

### 形象层级结构定义

| 后缀 | 名称 | 说明 |
| ---- | ---- | ---- |
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点**（本剧 = 1994 年代基础参考图） |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

> **本剧老化映射**：L01=1994（EP01-38）、L02=1998（EP39-65）、L03=2005（EP66-81）、L04=2014（EP82-86）。各角色按出场跨度取对应后缀（详见 `资产/形象索引.md`）。老化执行标准见第九B节。

### 形象表格式（角色卡片中）

| 形象 ID | 类型 | 名称 | 基于 | 适用 |
| ------- | ---- | ---- | ---- | ---- |
| `CHAR-001-L01` | **基础** | [默认状态名] | — | EP01–38 |
| `CHAR-001-L02` | 衍生 | [差异描述] | L01 | EP39–65 |

## 二、视觉风格锚点（Visual Style Anchor）

> 初始风格方向来源于 story-architect 大纲元数据「视觉风格 / 色彩基调」字段。

| 维度 | 规格 |
|------|------|
| 渲染风格 | **photorealistic 年代写实**（胶片颗粒质感、轻微做旧，非精致棚拍感） |
| 镜头参考 | 横屏电影感：**85mm 人物近景** + **24-35mm 码头/江面纵深全景**；对话戏以中景正反打为主 |
| 色调方向 | 胶片暖黄（年代怀旧）＋江水泥灰（码头苍凉）＋灯火橘红（夜景人情） |
| 画幅 | **16:9 horizontal**（`aspect_ratio: "16:9"`；`image_resolution: 2848×1600`） |
| 题材关键词 | 年代质感、长江码头、江面纵深、蒸汽货轮、胶片颗粒、时代群像 |

### 横屏构图指导（16:9 专项）

1. **江面/码头纵深**：横屏天然适配——江道延伸、船队一字排开、航道纵深拉出空间感（EP05 首航、EP15 夜航、EP39 船队过闸均依赖此构图）。
2. **双人正反打**：对话戏（兄弟对手戏、谈判戏、对峙戏）以中景/近景正反打交替呈现，避免长镜头单面；横屏正反打可同框放双人（EP45 隔桌对视、EP52 缆桩并肩）。
3. **全景群像**：扛包区劳工群像（EP01）、码头剪彩（EP74/EP76）、股东大会（EP59/EP67）用全景/大全景交代时代与规模；群像戏按大纲"简化拍法"以局部特写+声音代偿为主，不拍大规模混战。
4. **特写克制**：横屏档案 `closeup_min_pct: 35`（低于竖屏 50%）——情绪靠中景肢体语言 + 环境氛围传递（AI 特写面部失真风险规避）；`atmosphere_min_pct: 40` 氛围/前景镜头占比提高（横屏环境叙事优势）。
5. **prompt_suffix**：`横屏16比9连贯叙事`（通用，取自 visual_grammar）；本剧扩展尾缀见「引擎参数」节。

## 四、工作流顺序（必读 · 防不同步）

所有内容修改**严格按层向下**：

| 顺序 | 层 | 文件 | 写什么 |
| :---: | --- | --- | --- |
| **1** | **主剧本** | `短剧剧本_大江奔流：1994码头风云_86集.md` | 集纲、每场剧情、对白要点、钩子 |

## 四C、引擎参数（model / prompt_suffix / negative_prompt）

> **权威来源**：`mcps/shared/engine_registry.py`（`video_defaults()` 解析）；segment-builder 构建 shots/segments YAML 的 `defaults` 块时从本节 + engine_registry 读取，禁止硬编码。当前生效（2026-08-19）：

```yaml
video_gen:                       # 能力：视频生成（当前默认引擎 minimax，VIDEO_GEN_ENGINE 可切换）
  engine: minimax                # MiniMax-H3（engine_registry DEFAULT_ENGINES[CAP_VIDEO_GEN]）
  model: MiniMax-H3
  ratio: "16:9"                  # 横屏（aspect_ratio 动态覆盖）
  resolution: 768P
  image_resolution: "2848×1600"  # 横屏参考图
  duration_sec: 4-15             # 引擎单段硬限制（本项目与档案交集取 4-12，见第六节）
  generate_audio: true           # 引擎合成基础环境音；特殊音效后期叠加
image_gen:                       # 能力：图片生成（当前默认引擎 gpt-image）
  engine: gpt-image              # gpt-image-2（OpenAI 兼容中转）
  model: gpt-image-2
  resolution: 横屏参考图 2848×1600（16:9）
storage:                         # 能力：对象存储 / CDN（参考图永久托管）
  engine: tos                    # 火山引擎 TOS（drama-reference-images 桶）
  url_template: https://{bucket}.{endpoint}/{key}
```

### prompt_suffix（写入 YAML defaults.prompt_suffix）

```
通用（取自 visual_grammar "16:9"）：横屏16比9连贯叙事

  横屏16比9连贯叙事，电影级年代写实，胶片颗粒质感，长江码头江面纵深构图

```

### negative_prompt（结构性，本 Agent 定义 · 写入 YAML defaults.negative_prompt）

> 创意类 negative_prompt（如「禁止动漫风格」）由 character-designer / prop-designer / scene-designer 各自负责；**本节为年代/题材结构性禁忌，全员必须遵守**：

```
现代科技元素：智能手机、二维码、LED大屏、无人机、平板电脑、共享单车
年代错位：1994段禁止2000年后服饰/建筑/产品；2014段禁止复古过度
乱码文字：禁止无意义字母/数字/乱码；中文文字必须Simplified Chinese（简体），禁止繁体/日文/韩文
政治指涉：政治符号、标语、旗帜、体制指涉、历史事件具象化
暴力呈现：血腥、群架混战、犯罪过程具象化、强迫下跪/持续侮辱画面
```

> ⚠️ **中文文字专项**：凡含刻字/绣字/铭文/文书文字的道具（见第七节 ⚠️ 列），Prompt 必须含 Simplified Chinese；video_gen 参考图与出片均不得出现乱码文字。

## 六、分段规则（Segment）

### 分段（Segment）规则 —— AI 生成单位

| 约束 | 值 | 说明 |
| --- | --- | --- |
| 单 segment 时长 | **4–12 秒** | 项目档案 `segment_duration_sec: [4, 12]` 与引擎限制取交集；当前 video_gen 默认引擎 MiniMax-H3 硬限制 4-15s，交集取 **[4, 12]**。若切换引擎（`VIDEO_GEN_ENGINE`）以 `engine_registry.video_defaults()` 解析值与本节交集为准，禁止硬编码 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | ≤3 镜；段 ≥8s 必 ≥2 镜（典型 2-3） | v2.2 切镜节奏；静音视觉锤段可单镜但 ≤8s |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 5–8 段（EP01 可至 10） | 横屏档案 `segments_per_episode: [5, 8]` |
| 每集镜头数 | 14–24 镜（EP01 可至 30） | 横屏档案 `shots_per_episode: [14, 24]`；单镜理想 3-6s，>10s 禁 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 video_gen API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

现代科技元素：智能手机、二维码、LED 大屏、无人机、平板电脑、共享单车

## 内容合规参数

### 1. 题材合规等级

🟢 **C 级**（年代传奇/商战经营，核心导向创业逆袭、兄弟情义、诚信经营）。⚠️ 年代剧注意项：1994 背景聚焦民营码头创业与人物命运，**严禁触碰体制变革/下岗潮等敏感历史事件**，时代背景仅作氛围。

### 2. 本剧特定红线（3-5 条）

1. **不触碰敏感历史**：严禁涉及体制变革、下岗潮、国企改制等历史事件；时代仅氛围渲染（BB 机/绿皮火车/港片海报/搪瓷缸）
2. **反派合规收场**：商战反派不以"官方/体制内"为终极反派；吴德海（行政处理）、盛怀远（商业合规审查败走）、冯友德（自首+从轻处理）——**不写司法刑侦过程**
3. **不拍侮辱性画面**：EP01 克扣工钱不拍"强迫下跪/持续侮辱"；全程不拍暴力逼供、群架混战、犯罪过程具象化
4. **女性独立人格**：江澜/沈玉兰必须有独立事业线与专业能力，情感线不依附男主（EP26/EP49/EP76 三次事业高光自主推动剧情）
5. **不美化投机取巧**：主角以规矩/服务/实力赢商战（EP03 拒绝假证、EP33 守诚信底线），反面教材必受制裁

### 3. 灰区处理策略（2-4 个）

| 灰区 | 风险 | 处理方式 |
|------|------|----------|
| 权钱交易暗示（EP09 调包/EP30 账目勾连/EP37 拖船产权） | 涉政/腐败指涉 | 以「纸张/油墨/印章特写 + 专业比对」呈现，不拍交易具象化；证据以"商业违规记录"书面呈现 |
| 反派被查处（吴德海 EP59/盛怀远 EP68/冯友德 EP65） | 司法刑侦渲染 | 一律"行政处理/商业合规审查/自首背影"一笔带过 |
| 船难/夜航遇险（EP16/EP51） | 灾难场面 | 简化拍法：驾驶舱特写 + 船身撞击声 + 水声 + 结果镜头；受伤拍包扎近景不拍创面 |
| 兄弟反目/董事会斗争（EP43/45） | 暴力冲突暗示 | 以文件签收/表决/走出大门呈现，不拍推搡暴力 |

### 4. 正向价值锚点

- **诚信经营**（主题锚：「船可以旧，舵不能歪」——贯穿全剧价值观线）
- **兄弟情义**（EP82 敲钟还舵：从抢舵到还舵的情感闭环）
- **女性独立人格**（江澜女船长→女副总裁、沈玉兰女会计→独立审计）

### 5. 平台审核重点提示（前 3 集）

- **EP01**：克扣工钱戏（甩钱进泥+弯腰捡+被拦）以近景+局部特写呈现，**不拍"强迫下跪/持续侮辱/大规模群架"**；集末对峙用近景
- **EP02**：办证难戏聚焦"缺手续"的技术矛盾，**不渲染体制无能/官员腐败**；吴德海以"皮笑肉不笑"呈现不落官方负面定性
- **EP03**：老屋翻遗物以"拿起罗盘特写"处理，**不拍丧葬/灵位/迷信意象**；罗盘背面刻痕为关键视觉（洋行标记）
- **全 3 集**：道具文字均为中文简体；无政治符号；无现代科技元素
