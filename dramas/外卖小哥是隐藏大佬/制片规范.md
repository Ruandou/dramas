## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 道具     | `PROP-###`                        | `PROP-001`        | 外卖箱、同款夹克、手机等         |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再建 `L01` 基础形象于 `资产/形象索引.md` + `角色卡.md`
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨segment出现→独立CHAR-###；纯背景无台词→CHAR-GRP

## 三、肖像与法务 / 年代与美术

### 3.1 时代背景

- **年代**：现代都市（2020年代）
- **地点**：虚构的中国一线或新一线城市
- **核心场景**：外卖站点、写字楼、主角出租屋、商场、街头

## 四、工作流顺序（必读 · 防不同步）

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_外卖小哥是隐藏大佬_36集.md` | 集纲、每场剧情、对白要点、钩子                      |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 七、AI 出图/视频衔接

### 7.1 出图流程

1. 定稿 `L01` 参考图 → Character Sheet（正面全身，白底）
2. 衍生形象用图生图 / 角色一致性模型 → **delta Prompt** 仅写服装/道具/妆效差异
3. **禁止跳过 L01 直接生成 L02**
4. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01

### 7.2 一致性规则

- 同一角色跨segment的面部特征必须一致
- 使用 `same face as CHAR-###-L01` 锁定面部
- 服装、发型可在L02+中变化，但面部不变

### 7.3 参考图策略

| 优先级 | 资产类型 | 说明 |
|--------|---------|------|
| P0 | 主角形象 | 必须保证 |
| P1 | 对话角色形象 | 有互动的角色必须锁定 |
| P2 | 场景参考图 | 保证环境一致性 |
| P3 | 关键道具 | 有余量时加入 |
| P4 | 次要角色/群演 | 最后考虑 |

**每 segment 最多 6 张参考图**（TOS模式）

### 7.4 参考图管理

- 角色定妆：`assets/looks/CHAR-*-L##.png`
- 场景参考：`assets/scenes/SCENE-*.png`
- 道具参考：`assets/props/PROP-*-*.png`
- 提交方式：TOS 永久图床（有条件时）或 data URI 格式

## 八、道具转移与肢体动作（防错清单）

### 8.1 常见错误

- 道具在手中突然消失或出现
- 手机屏幕内容与剧情不符
- 外卖箱在不同镜头间位置不一致
- 衣服颜色/款式在连续镜头中突变

### 8.2 分段原则

- 不得在对话中间切断 segment
- 不得在连续动作进行中切断（开门、递外卖等动作链一条 segment）
- 拆段边界：场景切换、主说话人切换、情绪断点

### 8.3 API Prompt 写法

```
【图1】CHAR-001·林小跑（外卖骑手服，背外卖箱）【图2】CHAR-002·苏晴（职业装）【图3】SCENE-002
角色分工：仅图1可递外卖；图2禁止触碰外卖箱。
道具：外卖箱（40cm x 30cm x 30cm，蓝色，带虚构平台Logo）。
竖屏9比16连贯叙事。
镜头1（4s）中景固定：林小跑敲门，苏晴开门
镜头2（4s）近景正反打：林小跑递外卖，苏晴接过
[以下对白仅供语音合成，严禁在画面中显示任何文字]
对白（林小跑，25岁，紧张）：「您、您的外卖到了。」
画面全程无任何文字、字幕、标题、水印。
现代都市轻喜剧风格，写实风格，竖屏9比16，禁止古代服饰、军事装备。
```

### 8.4 检查清单

- [ ] 道具在连续镜头中是否保持一致？
- [ ] 手机屏幕内容是否与剧情匹配？
- [ ] 角色服装是否在L01/L02范围内？
- [ ] 动作是否在单segment内完成？

## 九、有声段落（Seedance 2.0 · 默认）

### 9.1 段落规则

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 约 12–15 段      | 对应单集 2.5 分钟时长（~150s ÷ ~10s/段 ≈ 15 段）                                 |

### 9.2 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 9.3 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 9.4 Prompt 结构

```
【图1】角色 ID·角色名（服装描述）【图2】角色/场景 ID【图3】SCENE-###
角色分工：仅图1可[动作]；图2禁止[动作]。
道具：[具体描述，含尺度参考]。
竖屏9比16连贯叙事。
镜头1（Xs）[景别][运镜]：[纯视觉动作描述]
镜头2（Xs）[景别][运镜]：[纯视觉动作描述]
[以下对白仅供语音合成，严禁在画面中显示任何文字]
对白（角色，年龄，情绪）：「台词」
画面全程无任何文字、字幕、标题、水印。
[题材风格描述]，写实风格，竖屏9比16，[负面约束]。
```

### 9.5 content_roles 配置

```yaml
content_roles:
  - { file: CHAR-001-L01, role: reference_image, label: 图1 }
  - { file: CHAR-002-L01, role: reference_image, label: 图2 }
  - { file: SCENE-001, role: reference_image, label: 图3 }
```

### 9.6 字幕策略

- Seedance **不烧录字幕**
- 通过 ffmpeg 在后期统一添加
- 字幕样式：白色黑体，底部居中，带黑色描边

### 9.7 音效/配乐标注

- 在分集剧本的镜头表中标注 `音效/配乐` 列
- 格式：`[音效类型]`（如 `手机震动`、`门铃声`、`轻快BGM`）
- Seedance `generate_audio: true` 可合成基础环境音；特殊音效后期叠加

## 十、TTS / 配音方向

### 10.1 语音描述格式

每个有对白的角色必须有 `voice_prompt`，格式：
```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

### 10.2 旁白风格

- 标注旁白角色（通常不分配 CHAR-ID，写为「旁白」）
- 旁白 voice_prompt 独立于角色
- 旁白镜无参考图需求，并入相邻段

### 10.3 音效/配乐需求

- **主要配乐**：轻快、活泼的都市喜剧BGM
- **情绪转折**：紧张时用悬疑弦乐，浪漫时用钢琴曲
- **音效**：外卖提示音、手机震动、门铃声、电动车声
