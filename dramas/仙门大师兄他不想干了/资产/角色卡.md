### CHAR-001 · 苏尘

| 字段 | 内容 |
|------|------|
| ID | `CHAR-001` |
| 姓名 | 苏尘 |
| 化名 | 苏掌柜 / 掌柜哥哥 |
| 年龄 | 外表 25–28 岁，实际 300+ 岁 |
| 身份标签 | 天下第一仙门的倦怠大师兄，伪造天劫假死后成了荒村客栈掌柜 |
| 性格核心 | **隐忍克制** — 三百年的孤独沉淀在每一个克制的情感里，从不敢建立联系到学会被爱 |

#### 外貌描述

苏尘的外表维持在25-28岁——清俊儒雅的面容被三百年岁月打磨出一种不动声色的沉淀感。他的五官端正精致：剑眉斜飞入鬓，眼型偏长（丹凤眼微挑），瞳色深黑如古井——看人时目光平静，但偶尔流露的疲惫像一层薄雾。鼻梁高挺笔直，唇形偏薄，平时抿成一条淡然的线，笑起来也只是嘴角微动，像在克制什么。脸型偏瘦长，下颌线清晰但不锋利。肤色白皙但非病态——是长期室内修炼养出的那种白，而非阳光下的白。

他的身材修长挺拔（约182cm），肩膀宽阔但不夸张，是修炼三百年的剑客体态——每一个动作都带着下意识的精确和控制。即使穿着最普通的素色布衣，他的站姿和步态依然出卖了他的出身：脊背永远笔直，双手自然垂落时手指微曲——那是长期握剑留下的肌肉记忆。

他眼角有一道极淡的细纹——不是岁月纹，是"表情纹"：三百年太少笑了，偶尔笑一次，皮肤反而留下痕迹。这是全剧最重要的视觉辨识特征之一。穿素色布衣（暖灰或米白），腰间系一条同色布带，没有任何配饰——除了偶尔会无意识地把玩茶杯。

EP31散功后：鬓角出现一缕明显的白发（约一指宽），从太阳穴附近垂下——这是他失去的修为在身体上留下的唯一痕迹。其他外貌不变，但眼神中少了一层"灵力微光"——眼睛变得更像凡人：更柔和，更温暖，也更像一个有寿命限制的人。

**仙侠题材视觉标记**：即使穿布衣，他的周身隐约有一种极淡的灵气底色——不是发光，而是一种"空气在他身边更安静"的微妙质感。偶尔在不经意间，他举手投足中会泄露出仙门大师兄的剑客气韵。

#### 外貌描述

小米是一个12岁的流浪孤儿，身形瘦小但因常年野外生存而精悍——约145cm高，四肢细长但肌肉结实，是"饿出来的精瘦"而非羸弱。他的脸型偏瘦长，正在从儿童向少年过渡——下颌线开始显现棱角，不再是幼儿的圆润。皮肤因长期日晒呈小麦色，脸颊和手臂上有几处旧伤痕——树枝划的、摔的、被欺负留下的。

他的五官最突出的是那双眼睛：大而警觉，瞳色深褐近乎黑，眼白占比大——这让他看起来永远像在警惕什么。眉毛偏浓，微微上挑，天生一副"不好惹"的表情。鼻子小巧但鼻梁挺直，嘴唇偏薄，经常抿着——不是严肃，是紧张。

穿补丁打了好几层的短褐（到膝盖的粗布短衣），颜色是洗到发白的灰褐色，袖口和下摆有粗针脚的补丁痕迹。腰间系一根麻绳。赤脚或者穿一双破烂的草鞋——草鞋大多数时候被他拎在手里，因为"穿着走路太吵，听不见坏人靠近"。脖子上用一根旧麻绳挂着一枚磨得发亮的旧铜钱——这是他父母留给他的唯一遗物（也是他的仙侠题材视觉标记）。

一年后（L02）：身高约150cm，身形更结实了一些，眼神里的警觉少了一分，多了一分"有家可归"的安稳。衣服虽然还是旧的但补丁少了。手里会端着茶盘——端茶的手比以前稳了很多。

**仙侠题材视觉标记**：脖子上那枚旧铜钱——在特定光线下，铜钱的边缘偶尔会泛出极淡的古旧灵气微光（象征他父母可能是散修出身，但小米自己不知道）。

#### 外貌描述

张媒婆五十多岁，身形微胖但不臃肿——是那种"日子过得不错"的丰腴。圆脸，双下巴若隐若现，面色红润——常年在外跑腿说媒养出来的健康肤色。她的五官组合非常具有欺骗性：圆脸善目，笑起来像邻家大婶般慈祥无害，但她的眼睛是她最厉害的武器——眼神毒辣，看人时像刀子一样精准，三秒就能判断出一个人的底细。

她的眼型偏圆，瞳色浅棕，眼角的鱼尾纹很深——不是老，是笑太多。但当她收敛笑容、认真看一个人的时候，眼珠不动，瞳孔微微收窄——媒婆看了一辈子人的职业本能。眉毛细弯，是精心修过的。鼻子小巧圆润，嘴唇偏厚，涂了淡淡的口脂——讲究但不张扬。

她最标志性的装扮是一件大红花袄——正红色底，上面绣着大朵的牡丹或梅花图案（金色绣线）。腰间永远别着两样东西：一卷红绳（说媒用的"姻缘线"）和一叠八字帖（红纸写的生辰八字，用布帕包着塞在腰带里）。下身穿深蓝色或墨绿色长裙，脚上是黑色布鞋。头发梳成圆髻，插一支银簪——簪头是小小的如意形状。

**仙侠题材视觉标记**：腰间那卷红绳在凡人看来只是普通棉线，但在修仙者眼中偶尔会泛出极淡的红光——这是张媒婆自己都不知道的事。她的八字帖里夹着一张泛黄的旧符纸（祖上传下来的），是她"看人准"的另一个秘密。

## 人物关系图谱

### 冲突关系
- **CHAR-001 苏尘** ←→ **CHAR-008 玄真长老**：师徒对决——玄真给了苏尘两个选择（飞升者或素心），苏尘选了第三种（逃→守护→散功），用玄真教他的兵法击败了玄真。终极冲突：个体自由 vs 体制控制。
- **CHAR-001 苏尘** ←→ **CHAR-007 墨渊**（前期）：竞争师弟的复杂情感——"我恨你但我更恨那个体制"。墨渊从嫉妒对手变为体制颠覆者，最终与苏尘和解。
- **CHAR-009 素心** ←→ **CHAR-008 玄真长老**：五百年前的封印者与被封印者。玄真（及其前任）将素心囚禁五百年，抹去她的一切记录。

### 联盟关系
- **CHAR-001 苏尘** — **CHAR-009 素心**：同为知晓飞升真相的逃亡者——"你也是知道了'那个'吗？"。素心是苏尘的镜像：一个被封印五百年，一个逃了三百年，最终都选择了自由。
- **CHAR-001 苏尘** — **CHAR-007 墨渊**（后期）：从对手到战略盟友。墨渊暗中提供封锁阵地图（EP22）和陷阱情报（EP27），最终捏碎玉简公开真相，完成体制颠覆。
- **CHAR-003 张媒婆** — **CHAR-004 老王** — **CHAR-005 陈婶**：村中三人联盟——各自用自己的方式（媒婆的市井智慧、老王的沉默观察、陈婶的无条件接纳）守护苏尘的秘密。
- **CHAR-006 林晚清** — **CHAR-007 墨渊**：同门暗中联络——林晚清用灵鹤联系墨渊（EP15），墨渊成为她的情报来源。两人共同策划了对玄真的证据收集。

### 情感关系
- **CHAR-001 苏尘** ♥ **CHAR-006 林晚清**：三百年未竟之情——她曾暗恋大师兄，他从不敢回应。EP15泡茶戏眼泪滴进茶杯是全剧最克制的情感高潮。EP19她终于叫出"大师兄"，EP34她选择留下——"三百年太长了。我们重新开始算——第一天。"
- **CHAR-001 苏尘** ♥ **CHAR-002 小米**：精神父子——小米第一个叫他"掌柜哥哥"，苏尘第一个给了小米"家"。从小米给野菜（EP03）到苏尘为小米修水渠（EP06），到小米点燃烟火挽救一切（EP30），这条线是全剧最核心的情感锚点。

### 秘密关系
- **CHAR-008 玄真长老** 知道飞升需要献祭至爱的真相，**CHAR-001 苏尘** 在禁书阁读到了同样的真相——但玄真不知道苏尘选择了"第三种答案"。
- **CHAR-007 墨渊** 知道玄真掩盖真相的全部证据，**CHAR-008 玄真长老** 不知道墨渊在收集证据——直到EP30玉简被捏碎。
- **CHAR-003 张媒婆** 知道苏尘非普通人（EP08），**CHAR-006 林晚清** 知道苏尘就是大师兄（EP13），两人从未交流过这个秘密——各自用各自的方式守护。
- **CHAR-009 素心** 知道飞升真相的全部历史（五百年的体制性掩盖），**全修真界** 在EP30之前都不知道——墨渊的玉简把五百年秘密变成了公共知识。
