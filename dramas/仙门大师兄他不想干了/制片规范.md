## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##-SH##`                   | `EP01-S01-SH03`   | 集数-分段-镜头                   |

### ID 分配规则

- 编号**连续、不跳号**；弃用标 `deprecated: true`
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3a）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨segment出现→独立CHAR-###；纯背景无台词→CHAR-GRP

### 形象层级结构

| 后缀     | 名称     | 说明                                           |
| -------- | -------- | ---------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                   |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01    |

> 形象 Prompt 内容、生成流程、delta 规则等视觉创意细节由 character-designer 负责。

## 二、视觉风格锚点 (Visual Style Anchor)

> 初始风格方向来源于 story-architect 大纲元数据中的「视觉风格」和「色彩基调」字段。

| 维度 | 规格 |
|------|------|
| 渲染风格 | **stylized realism** — 写实仙侠，法术特效克制，日常以烟火气实景为主 |
| 镜头参考 | cinematic 35mm lens, shallow depth of field for emotional close-ups |
| 色调方向 | **暖色自然** — 客栈内景：木质暖棕 + 暖黄灯笼光；村落外景：土黄/灰瓦/青山；仙门闪回：冷蓝/银白低饱和 |
| 画幅 | 9:16 vertical |
| 题材关键词 | realistic xianxia, warm-toned slice-of-life, restrained fantasy, 烟火气, 治愈 |

### 场景色彩分区

| 场景群 | 色调 | 说明 |
|--------|------|------|
| 归去来客栈（SCENE-001~005） | 暖棕+暖黄灯笼光 | 核心暖色调锚点——"家"的视觉符号 |
| 村落外景（SCENE-006~008） | 土黄/灰瓦/青山自然光 | 凡间日常——朴实、开阔 |
| 仙门闪回（SCENE-009） | 冷蓝/银白低饱和 | 与暖色村庄形成鲜明对比——"体制"的冷漠 |
| 山林谷口（SCENE-010） | 青灰/雾霭 | 过渡地带——紧张、不确定 |

### Seedance 默认参数

```yaml
seedance_defaults:
  model: doubao-seedance-2-0-fast
  ratio: "9:16"
  resolution: 720p
  duration_sec: "8-10"
  generate_audio: true
```

### prompt_suffix（所有 Seedance 生成统一追加）

```
realistic xianxia style, restrained fantasy elements, warm natural lighting, cinematic composition, 9:16 vertical, high quality
```

### negative_prompt（结构性约束 — 全项目统一）

```
anime, cartoon, cel-shading, 3D render, CGI look, over-the-top visual effects, neon lights, modern architecture, modern clothing, modern vehicles, smartphones, electronic devices, plastic materials, LED lighting, contemporary urban aesthetic, lens flare overload, excessive bloom
```

> **注意**：以上 negative_prompt 为结构性约束（年代/题材禁忌）。创意领域的 negative_prompt（如具体风格偏好、特定艺术家排除等）由 character-designer 和 scene-prop-designer 各自在其 Prompt 中补充。

### 4.1 修改层级（严格按层向下）

| 顺序  | 层           | 文件                              | 写什么                                              |
| :---: | ------------ | --------------------------------- | --------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_仙门大师兄他不想干了_36集.md` | 集纲、每场剧情、对白要点、钩子                      |

## 五、分段规则（强制）

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 约 12–15 段     | 对应单集 2.5 分钟时长                                   |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 六、分集剧本格式规范

> 分集剧本（`剧本/EP##/EP##_*.md`）是单集的**真相源**，所有后续文件（shots.yaml / segments.yaml）必须从此导出。

- 使用 **11 列镜头表**：镜号 / shot_id / 场景 / 角色 / 形象 / 景别 / 时长 / 模式 / 运镜 / 画面 / 对白备注
- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`

## 八、音色规范

### 8.1 TTS / 配音

| 项目     | 说明                                                   |
| -------- | ------------------------------------------------------ |
| 语言     | 中文普通话                                             |
| TTS 引擎 | Seedance generate_audio（或后期 Edge TTS / Fish Audio） |
| 语速     | 正常偏慢 — 日常流短剧节奏，给情绪留空间                |
| 情绪标记 | 分集剧本中标注 `[平静]` `[笑]` `[低]` `[怒]` `[哽咽]` 等 |
| BGM      | 日常场景：温暖民乐（笛/琴）；紧张场景：低音弦乐+鼓点；闪回：冷调弦乐 |

### 8.2 voice_prompt 权威来源

> **`资产/声音卡.md` 是 voice_prompt 的唯一权威来源。** segment-builder 必须从此文件**全文复制** voice_prompt 到 YAML。禁止缩写、改写、翻译、简化。

### 8.3 旁白与音效

- 旁白角色（EP01苏尘内心独白）不分配 CHAR-ID，写为「旁白」
- 分集剧本镜头表中标注音效（如 `敲门声`、`紧张弦乐`、`碗筷碰撞`）
- Seedance `generate_audio: true` 合成基础环境音；特殊音效后期叠加

## 十一、双通道移交协议

本规范确立后，同时移交两个下游消费者：

### A. → character-designer（Stage 3a）
- **移交**：角色卡骨架（CHAR-### ID + 姓名 + 定位 + 阵营 + 首次出场 + 关键关系 + 性格概要 + 初始音色建议）+ 故事大纲原文引用 + `资产/角色索引.md` + `资产/形象索引.md` 骨架
- **character-designer 填充**：外貌描写、L01/L02+ Prompt、形象索引 Prompt 摘要
- **不可修改**：CHAR-### ID 编号、角色定位/关系结构、表格格式

### B. → scene-prop-designer（Stage 3b）
