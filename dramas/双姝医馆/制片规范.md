## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同视觉角色独立 ID + L01（按需创建，无上限） |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**；**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象。
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-###-L01`；禁止跳过 L01。
- 群演按需创建，不设数量上限；`CHAR-GRP-##` 可跨集复用，但不同视觉角色不可共用同一 ID。
- 场景/道具 ID 由 production-planner 分配；scene-writer / segment-builder 不得自行新增。

### 1.1 形象层级结构

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 L01；Prompt 只写差异，并含 `same face as CHAR-###-L01` |

> 形象 Prompt 内容、生成流程、delta 规则等视觉创意细节由 character-designer 负责。

### 1.2 角色参考图分组（R1 结构观察第 4 条落实）

> R1 观察：8 主要角色达 Seedance ≤8 参考上限 → 制片规范做角色参考图分组并控制同镜角色数。

| 分组 | 优先级 | 角色 | 出图策略 |
|------|--------|------|----------|
| **主角组** | P0 | `CHAR-001` 沈明玉、`CHAR-002` 沈清荷、`CHAR-003` 顾北舟、`CHAR-004` 陆砚之 | 最先出 L01，单角色高精度绑定 |
| **常驻组** | P1 | `CHAR-005` 金满楼、`CHAR-006` 崔万山、`CHAR-007` 周伯、`CHAR-008` 阿满 | 紧随主角组 |
| **功能配角组** | P2 | `CHAR-009` 王婶、`CHAR-010` 张先生、`CHAR-011` 徐老、`CHAR-012` 赵四爷 | 按首次出场集排期 |
| **群演组** | P3 | `CHAR-GRP-01`~`CHAR-GRP-04` | 远景/剪影/背影为主，不逐一绑脸 |

**同镜角色数控制（硬约束）**：
- 单镜同框**主要角色 ≤ 4 人**；超过 4 人拆两镜/用远景群像。
- 单 segment 参考图配额 **≤ 6 张**（look+scene+prop 合计，TOS 永久 URL 模式）。
- 群演不绑定独立参考图——用 GRP 远景参考图或剪影呈现，不参与同镜主要角色计数。

## 四、工作流顺序（必读 · 防不同步）

所有内容修改**严格按层向下**：

| 顺序 | 层 | 文件 | 写什么 |
|:---:|------|------|--------|
| **1** | **主剧本** | `短剧剧本_双姝医馆_86集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第 2 步引号内字面一致 |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 六、分段规则（Segment 规则）

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | 项目统一制片约束（seedance 硬限制 4-12；minimax 支持 4-15，统一取 4-12 保证引擎可切换）；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | ≤3 镜；段 ≥8s 必 ≥2 镜（典型 2-3） | v2.2 切镜节奏；静音视觉锤段可单镜但 ≤8s |
| 最小叙事单位 | 1 个完整 beat | 每段必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段（EP01 10-12） | 对应单集 90s（EP01 120s） |
| 每集镜头数 | 16–30 镜（EP01 20-36） | 单镜理想 3-6s，>10s 禁 |
| 台词密度 | 210–330 字/分钟 | G4/G5 校验硬带 |

**拆分原则**：
1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）。
2. **不得**在连续动作进行中切断（开门、摘道具、施针等动作链一条 segment）。
3. 拆段边界：场景切换、主说话人切换、情绪断点。
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`。
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**。

**关键区分**：
- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）。
- **Segment（SEGxx）** = AI 生成单位（一次 video_gen API 调用）。
- 同一场景**可以**包含多个 segment；segment **不得**跨场景（场切即断段）。

**分段/镜头自检**：
- [ ] 所有 segment 的 `duration_sec` ∈ [4, 12]？
- [ ] 每段镜头数 ≤3；≥8s 段 ≥2 镜？
- [ ] 单段主说话人 ≤2？
- [ ] 是否存在切断对白或连续动作的拆点？（无）
- [ ] 台词密度落在 [210,330] 字/分钟？

## 八、音色规范

### 8.1 voice_prompt 格式

每个有对白角色必须有 `voice_prompt`，格式统一：
```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

**权威来源（P0）**：`资产/声音卡片.md` —— segment-builder 必须**全文复制**（含「」内全部文字），禁止缩写、改写、翻译、简化。同一角色跨 segment 的 voice_prompt 必须全文一致。

### 8.2 旁白与音效

- 旁白角色不分配 CHAR-ID，写为「旁白」，voice_prompt 独立定义。
- 分集剧本镜头表标注音效（如 `算盘声`、`拨算珠声`、`药膳锅咕嘟`、`敲门声`、`紧张弦乐`）。
- 视频引擎 `generate_audio: true`（minimax/seedance 均支持）合成基础环境音；特殊音效后期叠加。

## 九、年代/题材约束（叙述性；Prompt 由设计师负责）

### 必须体现元素
- 青瓦木楼、药柜百子格、市集烟火气、灯笼暖光
- 市井医馆日常：望闻问切、制药、药膳锅、乌头炮制器皿（水浸/切片/久煎）
- 算盘、银针、账本、泛黄信笺、牌匾（简体中文）
- 京城药行总会：黑木匾额、账房林立、议事厅威严；医道大会：高台擂鼓、药旗招展

### 禁止出现元素（结构性 negative_prompt 依据）
- 现代物品：塑料、LED、玻璃幕墙、汽车、手机、电灯、现代招牌
- 西方面孔/西式服饰/欧洲建筑
