## 二、ID 命名规则

所有资产使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同视觉角色独立 ID + L01 |
| **场景** | `SCENE-###` | `SCENE-002` | 布景 |
| **道具** | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演按需创建，不设数量上限。唯一约束是 API 参考图配额（每 segment ≤6 张）
- 同一 CHAR-GRP-## 可跨集复用，但不同视觉角色不可共用同一 ID

### 形象层级结构

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

| 顺序 | 层 | 文件 | 写什么 |

## 七、分段规则

### Segment 约束

| 约束 | 值 | 说明 |
|------|------|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | 对应单集 75–120 秒 |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### 拆分原则

1. **不得**在对话中间切断 segment
2. **不得**在连续动作进行中切断
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 内容合规参数

### 题材合规等级

🟢 **C级（一般题材）**
- 金融职场为一般商业题材，不涉及政治/军事/司法
- "金融犯罪"为商业犯罪（非刑侦主线），核心导向是女性成长与正义
- 无穿越/系统/重生等超自然元素，纯现实主义

### 本剧特定红线

1. **禁止美化金融犯罪**：方怀瑾的犯罪行为必须被明确否定，不可将其塑造为"灰色地带英雄"
2. **禁止过度展示犯罪手法**：交易操纵、数据篡改等手法仅作剧情推进，不提供可复制的操作细节
3. **禁止渲染仇恨情绪**：复仇行为须有道德底线，林默不可使用违法手段报复
4. **禁止物化女性角色**：所有女性角色须有独立人格和决策能力
5. **禁止过度暴力**：EP46 陆辞渊受伤场景不得出现血腥画面

### 灰区处理策略

| 灰区 | 处理方式 |
|------|---------|
| 金融犯罪细节 | 仅展示结果和影响，不教学具体操作 |
| 商业间谍行为 | 定性为"收集证据"而非"窃取商业机密" |
| 黑客行为（EP45） | 弱化技术细节，强调"迫不得已"的叙事合理性 |
| 监管人员私人调查 | 季柏舟的行为定位为"替父赎罪"，非滥用职权 |

### 正向价值锚点

1. **女性力量**：林默用智慧和专业能力证明自己，不依赖他人
2. **正义终将到来**：无论多强大的犯罪者，终将被揭露和制裁
3. **自我重建**：失去一切后重新站起来的勇气和韧性

### 平台审核重点提示

- **EP01-03**：确保林默的交易行为合法合规，不涉及内幕交易暗示
- **EP28**：行业峰会场景中揭露方怀瑾漏洞，须基于公开数据而非窃取
- **EP45**：黑客入侵服务器场景需弱化技术细节，定位为"获取犯罪证据"
