## 二、Top 3 问题

### 问题 1（🔴 必须修复）：SEG06-08 场景标注错误——监管局办公室误标为咖啡厅

**现象**：SEG06-08 的场景头标注为 `【SCENE-003】咖啡厅`，但实际叙事内容描述的是**监管局办公室**：
- SEG06 shot11："季柏舟将笔记本电脑转向林默和陆辞渊。屏幕上是医院监控画面"
- SEG06 shot12："电脑屏幕上，监控画面显示：两个穿黑色西装的男人推着轮椅走出病房"
- SEG07 shot13："季柏舟点击鼠标，放大监控画面"
- SEG08 shot15："三人围坐在桌前，气氛凝重。季柏舟将电脑转向自己，快速调出另一份档案"

这些内容明确描述的是**季柏舟在监管局办公室调取监控录像**的场景，而非咖啡厅。

**影响**：
1. **场景卡片引用错误**：`SCENE-003` 在场景卡片中定义为"咖啡厅"，但本集实际需要的是"监管局办公室"场景
2. **场景参考图不匹配**：如果按 SCENE-003（咖啡厅）的参考图生成视频，将出现严重的视觉不一致（咖啡厅里出现办公桌、案件档案、电脑监控画面）
3. **segment-builder YAML 生成错误**：基于错误的场景标注生成的 YAML 将引用错误的场景参考图

**建议**：
- 将 SEG06-08 的场景标注从 `【SCENE-003】咖啡厅` 改为正确的监管局场景（需确认场景ID，可能是 `SCENE-009` 或其他已注册的监管局场景）
- 如果监管局场景尚未在场景卡片中注册，需由 production-planner 分配 ID 并由 scene-designer 生成参考图
- 同步更新剧本头部的 `scene_ids` 字段

### 问题 2（🟡 建议修复）：SEG05 存在重复台词

**现象**：SEG05 的 shot9 和 shot10 的对白中都包含同一句台词：

| 镜号 | 对白 |
|------|------|
| shot9 | **CHAR-002**[关切]：「听雨，慢点。」**CHAR-001**[坚定]：「**不能慢，方怀瑾的人比我们快了一步。**」 |
| shot10 | **CHAR-001**[坚定]：「**不能慢，方怀瑾的人比我们快了一步。**」**CHAR-002**[低声]：「我开车，你导航。」 |

**影响**：
- 对白重复会降低台词效率，在84秒的有限时长内浪费约3-4秒
- 观众体验不佳，感觉像是剪辑失误

**建议**：
- 删除 shot10 中重复的台词，改为：
  - 方案A：shot10 只保留画面描述，对白改为 **CHAR-002**[低声]：「我开车，你导航。」（林默的坚定表情通过画面传达）
  - 方案B：shot10 改为新的台词，如 **CHAR-001**[急切]：「快，去监管局。」（承接SEG04季柏舟的来电）

### 问题 3（🟡 建议修复）：EP23→EP24 证人状态描述存在轻微矛盾

**现象**：
- **EP23 SEG07**：季柏舟说"证人情况不好，医生说可能撑不过今晚"，暗示证人病情危重
- **EP24 SEG01**：林默说"季柏舟说证人在ICU，302病房"
- **EP24 SEG02**：描述"床头柜上的水杯还有余温"、"输液架上的吊瓶刚换过，液体还在滴"
- **EP24 SEG03**：林默说"床还是热的，刚走不久"、"输液瓶还是满的，至少半小时内有人在"

**矛盾点**：
1. EP23说证人"可能撑不过今晚"（病情危重），但EP24描述的场景（水杯有余温、输液瓶刚换过）暗示证人状态相对稳定，能够被转移
2. EP23说证人在ICU，但EP24说"302病房"——ICU病房通常不使用"302"这样的编号格式

**影响**：
- 观众可能注意到证人病情描述的不一致
- 但不影响主线叙事（证人被转移的核心事实成立）

**建议**：
- 方案A（推荐）：将EP24的"302病房"改为"ICU"，保持与EP23一致；将"水杯还有余温"改为更符合ICU场景的描述（如"监护仪还在运行"、"床帘刚被拉开"）
- 方案B：在EP24中加入一句解释性台词，如 **CHAR-005**[电话音]：「证人昨晚情况好转，被转出ICU到普通病房了——但半小时前被人办了出院手续。」这样既解释了从ICU到302病房的变化，又为方怀瑾的人"趁病情好转时转移证人"提供了合理动机
