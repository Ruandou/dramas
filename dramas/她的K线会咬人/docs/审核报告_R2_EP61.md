## 二、逐维度评分

### 2.1 观众留存（4/5）

**优点**：
- **复仇高潮兑现**：EP60 宣布身份 → EP61 展示证据链 → 方怀瑾被带走，三集弧线（EP59-61）完成度高，观众期待的"打脸时刻"终于到来
- **反转钩出色**：方怀瑾被铐后回头微笑+"游戏还没结束……"是本集最强钩子，暗示复仇尚未终结，观众必须追看 EP62
- **节奏递进清晰**：SEG01 宣言 → SEG02-03 证据展示 → SEG04-05 对抗 → SEG06 逮捕 → SEG07-08 高潮收束，叙事节拍完整
- **季柏舟入场**：SEG06 季柏舟带人从侧门进入，给"正义降临"一个具象化画面，增强观众的正义满足感

**扣分项**（-1.0）：
- **S01 开场金句复用 EP60**：EP61-S01 林默说"三年前，有人偷走了我的人生。今天，我要把它拿回来。"这与 EP60-S02a 的金句**完全相同**。作为复仇高潮集，开场应有新的冲击性台词（如直接宣布"接下来我要展示的，是方怀瑾的完整犯罪证据"），复用上集金句会让追看观众产生"这不是说过了吗"的疲劳感
- **对白密度偏低**：实际有效对白约 16 行 / 77s ≈ 12.5 行/分钟（详见维度六分析），远低于制片规范建议的 20 行/分钟。纯视觉段（S03、S11）虽已补充画外音/低语，但台词量仍然单薄，可能导致观众在视觉段失去叙事锚点

### 2.2 情绪收益（4/5）

**优点**：
- **复仇爽感兑现**：三年隐忍 → 当众展示证据 → 方怀瑾被铐，核心情绪承诺（女性智性主角用金融博弈实现复仇）完全兑现
- **温可薇遗产延续**：S08"温可薇用命换来的证据，你觉得是臆想？"将已退场角色的牺牲与当前复仇连接，增加情感厚度
- **方怀瑾的层次感**：S05-06 从闯入质问（"你又在编故事了？"）到被铁证打脸（"你觉得是臆想？"），反派的傲慢→震惊→威胁的心理弧线清晰
- **集末释然**：S12 林默"眼眶泛红，嘴角带着释然的微笑"——复仇完成后的复杂情绪，不是单纯的快感，有情感深度

**扣分项**（-1.0）：
- **情绪峰值缺少"捶桌"瞬间**：EP60 的身份揭露（"沈听雨已经死了"）是全剧的燃点爆发。EP61 作为续集，证据链展示虽然重要，但缺少一个同等量级的情绪爆发点。S08"温可薇用命换来的证据"接近但还不够——建议在 S05 或 S07 增加一个更尖锐的反击台词，让观众有"打脸成功"的捶桌冲动
- **S12 收束略平**：林默画外音"数据不会说谎。三年了，真相终于大白。"功能与 EP60-S07"今天，我就让数据说话"重叠。作为复仇完成的收束，可以考虑更强的情绪释放（如林默终于落泪、或台下有人带头鼓掌的画面渐强）

  - 记者：追问式短句 ✅
- **方怀瑾台词层次好**：从 S05"你又在编故事了？"（傲慢）→ S06"不过是你的臆想罢了"（不屑）→ S10"你们会后悔的"（威胁）→ S11"游戏还没结束……"（诡异），反派语言弧线完整

**扣分项**（-1.5）：

**问题 1：实际对白密度严重不足（P1）**

剧本自检声称"24行/77s ≈ 18.7行/分钟"，但逐镜核算如下：

| 镜号 | 有效对白行数 | 备注 |
|------|------------|------|
| S01 | 1 | 林默一句话 |
| S02 | 1 | 林默一句话 |
| S03 | 1 | 记者画外音一句话 |
| S04 | 2 | 记者A+B各一句 |
| S05 | 1 | 方怀瑾一句话 |
| S06 | 1 | 方怀瑾一句话 |
| S07 | 1 | 林默一句话 |
| S08 | 1 | 林默一句话 |
| S09 | 1 | 季柏舟一句话 |
| S10 | 1 | 方怀瑾一句话 |
| S11 | 1 | 方怀瑾低语一句话 |
| S12 | 1 | 林默画外音（一句，含两个短分句） |
| **合计** | **约 13 行** | — |

- **实际密度**：13 行 / 77s ≈ 10.1 行/分钟（远低于 20 行/分钟建议值）
- **对白时间占比**：约 22s / 77s ≈ 28.6%（低于 40% 建议值）
- **原因**：每个镜头只有 1 行对白，镜头切换频繁但台词稀疏。对比 EP60（29 有效行 / 75s ≈ 23.2 行/分钟），EP61 的对白量下降了约 56%

**建议**：增加以下镜头的对白量——
- S01：增加林默的第二句开场（如直接宣布"今天我要展示方怀瑾的完整犯罪证据"，避免复用EP60金句）
- S04：增加记者群的追问（如"方怀瑾先生本人怎么回应？"）
- S05：增加林默反击的第二句（如"三年了，你还以为能一手遮天？"）
- S09：增加季柏舟的补充（如"你有权保持沉默，但你所说的每一句话都将作为呈堂证供"）

**问题 2：S01 开场复用 EP60 金句（P1）**

EP61-S01 对白"三年前，有人偷走了我的人生。今天，我要把它拿回来。"与 EP60-S02a **完全相同**。EP60 中此句是"身份宣言"的核心金句，在 EP61 中重复使用会：
1. 让追看观众产生"听过了"的疲劳感
2. 浪费 EP61 复仇高潮集的开场冲击力

**建议**：S01 改为新的开场宣言，如：
> "各位，今天我不会讲故事。我只展示数据。"

这样既呼应林默"数据驱动"的人设，又直接切入证据链主题，与 EP60 的"身份揭露"形成差异化。

**问题 3：S05 方怀瑾闯入时缺少林默的即时反应（P2）**

S05 方怀瑾说"沈听雨，你又在编故事了？"后，S06 方怀瑾继续说"不过是你的臆想罢了"，然后 S07 才是林默反击。从叙事节奏看，方怀瑾连续两镜发言（S05+S06）而林默没有即时回应，显得女主在对手戏中处于被动。建议在 S05 或 S06 增加林默的一句反击（如冷笑不语、或一句"编故事？那你自己看。"），保持对手戏的节奏平衡。
