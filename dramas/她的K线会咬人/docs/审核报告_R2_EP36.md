## 二、逐维度详评

### 2.1 观众留存（4.5/5）

**钩子设计**：

| 钩子类型 | 位置 | 内容 | 效果 |
|----------|------|------|------|
| H-INF（信息钩） | SEG04-S06 | 文件上被遮挡的名字，"禾"偏旁暗示姓氏 | 信息量适中，引导观众参与推理 |
| H-SUS（悬念钩） | SEG06-S08 | "季……"姓氏浮现，与季柏舟关联 | 核心悬念，信任危机萌芽 |
| H-REV（反转钩） | SEG07-S09 | 林默直接质问季柏舟 | 盟友关系瞬间反转，张力极强 |

**与 EP35 衔接**：EP35 末尾发现协议书上"季"字签名 → EP36 开头咖啡厅密谈直接承接，衔接零缝隙。季柏舟主动说"文件最后一页……有个名字被遮挡了。我们去局里看"，为场景转换提供自然动机。

**集末悬念**：林默发现"季"姓 + 直接质问季柏舟"这个'季'，和你有关系吗？" + 季柏舟艰难回应"我……不知道该怎么说" → 观众必然追问"季柏舟到底隐瞒了什么？"，驱动 EP37 点击。

**视觉伏笔设计**："禾"偏旁作为具象化推理线索，让观众同步参与解谜，增强参与感和沉浸感。这是本集最精巧的叙事设计。

**扣分项**：EP35 结尾钩子将 EP36 标题写为"《遮挡的名字》"，但实际标题为"《季姓迷雾》"，标题不一致（详见§四-1）。

### 2.2 情绪收益（4.5/5）

**情绪曲线**：
```
SEG01   SEG02   SEG03   SEG04   SEG05   SEG06   SEG07   SEG08
  │       │       │       │       │       │       │       │
  专注    刺探    严肃    疑惑    推理    震惊    对峙    悬念
  ──────────────────────────────────────────────────────────────
  咖啡厅（温暖）  │  监管局档案室（冷白）                      │
         上升段         │    递进段    │   高峰段  │  切断
```

- **上升段（SEG01-02）**：咖啡厅温暖光线下，林默专注追问，季柏舟闪烁回避，信任裂痕初现
- **递进段（SEG03-06）**：监管局冷白荧光下，文件特写逐步揭露"禾→季"，推理过程层层递进
- **高峰段（SEG07）**：林默直接质问"这个'季'，和你有关系吗？"，信任彻底崩塌
- **切断（SEG08）**：季柏舟开口但被切断"有些事情，不是你想的那样"，留白窒息

**冷暖光影对比**：咖啡厅暖阳光（信任/安全感）→ 监管局冷白荧光（真相/冰冷），光影切换精准映射情绪转折，是本集制作备注中最突出的导演意识。

**扣分项**：SEG07 与 SEG08 存在重复内心独白，削弱了最后两段的情绪层次感（详见§四-3）。

**金句分析**：

1. **「禾木旁……这个姓氏……季……」**（SEG06-S08）
   - 功能：观众同步参与推理的记忆钩子
   - 技法：具象化文字拆解（"禾"偏旁），将抽象推理过程视觉化
   - 评价：与"禁止出现文字"的 prompt_suffix 配合，通过演员表演（手指触碰、瞳孔收缩）而非屏幕文字传递信息，影视化程度高

2. **「季柏舟……这个'季'，和你有关系吗？」**（SEG07-S09）
   - 功能：将怀疑直接抛向盟友，信任崩塌的标志性台词
   - 技法：简短有力，直接点名+直接质问，零修辞
   - 评价：符合林默"短句为主，不废话，关键时刻一针见血"的语言画像

**角色语言一致性**：

- 季柏舟：回避性回答、推眼镜动作暗示紧张 → 与角色卡片"直接理性"有微妙偏移，但符合面对家族秘密的合理反应

## 四、问题清单（需修复）

### 4.1 🟡 P1：EP35 结尾钩子标题不一致

**位置**：EP35 `EP35_追查收割者.md` 第177行
**问题**：EP35 结尾钩子写"**EP36：《遮挡的名字》**"，但 EP36 实际标题为"《季姓迷雾》"
**影响**：跨集文档不一致，可能影响总纲索引和观众预期管理
**建议**：修改 EP35 结尾钩子为 `**EP36：《季姓迷雾》**`

### 4.2 🟡 P1：时长预算表未回填实际时长

**位置**：EP36 剧本"时长预算表"（第36-52行）
**问题**：所有"实际SEG时长"列均为 `[写后填]`，违反自检 5.5（"正文写完后用'实际'列对比，偏差需说明原因"）
**影响**：无法验证预算与实际的偏差，流程合规性缺失
**建议**：回填实际时长（全部为10s），合计80s，并在偏差说明列标注"准确"或说明原因

### 4.3 🔴 P0：SEG07 与 SEG08 内心独白重复

**位置**：SEG07-S09（第143行）与 SEG08-S11（第156行）
**问题**：两处内心独白完全相同——"他在逃避……他知道什么？"
**影响**：
1. 削弱 SEG08 作为"Cliffhanger Zone"的情绪冲击力，观众会感到重复而非递进
2. 违反时长红线规则中的"实质性新增"原则——同一句独白在两个不同 segment 中重复出现，无信息增量
**建议**：
- SEG07 保留"他在逃避……他知道什么？"（质问阶段的内心反应）
- SEG08-S11 改为更深层的推理/恐惧，例如：「如果这个'季'不是巧合……那他从一开始接近我，就是有目的的？」或直接删除该内心独白，用 SEG08-S12 的内心独白"如果这个'季'真的是……那季柏舟接近我，到底是为了什么？"替代

### 4.4 🟢 P2：场景卡片 SCENE-006 未收录 EP36

**位置**：`资产/场景卡片.md` SCENE-006 条目
**问题**：SCENE-006 的"出现集数"字段为"EP07、EP22、EP35、EP37、EP41"，未包含 EP36
**影响**：资产索引不完整，影响场景使用统计
**建议**：更新为"EP07、EP22、EP35、**EP36**、EP37、EP41"

### 4.5 🟢 P2：SEG02 信息密度过高

**位置**：SEG02-S03（第82行）
**问题**：单镜头内包含 4 句对白（1句试探+1句回避+1句逼问+1句内心），信息密度过高，Seedance 8-10秒内难以承载
**影响**：可能造成节奏过快或对白拥挤
**建议**：考虑将"怀疑谁？"的逼问移至 SEG01 末尾，或将"他在逃避。为什么不敢在这里说？"的内心独白移至 SEG03 开头
