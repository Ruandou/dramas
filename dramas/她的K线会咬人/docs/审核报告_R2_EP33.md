**情绪曲线**：
```

  │       │       │       │       │       │       │       │       │       │
```

## 四、问题清单

### 问题 1：付费卡点编号与制片规范不一致

**严重程度**：🟡 中（参考文档一致性）

**现象**：
- 72 集大纲明确标注 EP33 为"第四个付费卡点"
- 制片规范§十三 付费卡点标记表中，第四个卡点（深度锁定点）对应 **EP39**
- EP33 剧本自标注为"第四个付费卡点·深度锁定点"

**影响**：下游 segment-builder 和 drama-director 在制作付费卡点相关元数据时可能产生混淆。

**建议**：由 drama-director 统一确认付费卡点编号，更新制片规范或 72 集大纲使其一致。

### 问题 2：护士群演未注册 ID

**严重程度**：🟢 低（流程规范）

**现象**：
- EP33-S11 中护士角色有对白："病人需要休息，请不要刺激她。"
- 该角色未在 character_ids 中注册，也未分配 CHAR-GRP-## ID
- EP34 的角色卡片中提到"医生/护士"为生效群演，计划在 EP23/EP47 分配

**影响**：segment-builder 生成 YAML 时可能缺少护士角色的形象 ID。

**建议**：由 production-planner 为护士群演分配 CHAR-GRP-## ID（如 CHAR-GRP-05），或在 EP33 中将该对白标注为场景内置音效/画外音。

### 问题 3：PROP-010 持有者标注与使用场景不完全匹配

**严重程度**：🟢 低（文档细节）

**现象**：
- 制片规范§八 和角色卡片中，PROP-010 标注为"媒体的录音笔"，持有者为 CHAR-GRP-01
- EP33 中实际由林默（CHAR-001）取出并播放

**影响**：叙事上合理（林默持有关键证据），但道具卡片的"持有者"字段可能误导后续资产索引更新。

**建议**：更新道具卡片，将 PROP-010 持有者修正为"CHAR-001（来源：媒体/线人）"或添加备注说明。
