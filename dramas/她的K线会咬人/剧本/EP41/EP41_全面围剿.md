## 叙事设计说明

### 核心冲突

本集的核心冲突是**方怀瑾的全面围剿 vs 三人的无力反抗**。方怀瑾动用所有关系网，同时对林默、陆辞渊、季柏舟发起攻击——冻结银行账户、停职、调离调查组。三人分别在不同场景收到坏消息，展现了方怀瑾的权力之大和围剿之彻底。

### 情绪曲线

```
冷酷 → 震惊 → 愤怒 → 压迫 → 苦涩 → 绝望 → 得意 → 沉默 → 坚定 → 决绝
```

### 钩子设计

- **集末悬念**：林默在收到所有坏消息后，看着U盘里的证据，说出"我们必须加快行动"。这是一个**危机钩（H-CRI）**，观众会担心三人如何在被围剿的情况下反击，同时好奇他们下一步会怎么做。
- **危机感来源**：方怀瑾的围剿是全方位的——经济（冻结账户）、职场（停职）、调查（调离+接管），展现了反派的强大和主角团的绝境。

### 与前后集的衔接

- **承接EP40**：方怀瑾逃离老宅，留下纸条"游戏才刚刚开始"。本集展现了方怀瑾所说的"游戏"——全面围剿。
- **铺垫EP42**：林默在最绝望的时刻，温可薇将出现，递上关键U盘，为EP42的转折做铺垫。
