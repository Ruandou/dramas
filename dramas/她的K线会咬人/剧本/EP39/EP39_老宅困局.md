## 叙事设计说明

### 核心冲突

本集是**第五个付费卡点**，核心冲突是**父子之间的正义与邪恶对决**。陆辞渊代表正义一方，为了揭露父亲的罪行和保护金融体系，不惜与父亲正面交锋。方怀瑾代表邪恶一方，为了维护自己的权力和"收割者"计划，不惜对亲生儿子下手。

### 情绪曲线

```
紧张 → 犹豫 → 专注 → 震惊 → 对抗 → 冷酷 → 绝望
```

### 钩子设计

- **集末悬念**：方怀瑾按下警报，陆辞渊被困老宅。这是一个**危机钩（H-CRI）**，观众会担心陆辞渊的安危，同时好奇他能否逃脱、密码能否被获取。
- **付费卡点功能**：作为第五个付费卡点，本集通过父子对峙的情感冲突和危机爆发，激发观众的付费欲望，想要看到陆辞渊如何脱困、"收割者"计划能否被阻止。

### 与前后集的衔接

- **承接EP38**：季柏舟坦白父亲的罪行，发现需要方怀瑾服务器密码。陆辞渊决定亲自去获取密码。
- **铺垫EP40**：陆辞渊被困老宅，林默和季柏舟赶到救援。方怀瑾留下纸条"游戏才刚刚开始"。
