## 叙事设计说明

### 核心冲突

本集承接EP39的"老宅困局"，核心冲突是**救援与逃脱**。林默和季柏舟必须在方怀瑾的陷阱中救出陆辞渊，同时获取关键信息。陆辞渊在EP39中从保险箱里找到的U盘存储着方怀瑾所有境外账户的资金流向——这是"收割者"计划的核心数据。方怀瑾虽然逃走，但他留下的纸条暗示这场对抗才刚刚开始。

### 情绪曲线

```
紧张 → 警觉 → 急迫 → 担忧 → 如释重负 → 震惊 → 愤怒 → 坚定
```

### 钩子设计

- **集末悬念**：方怀瑾留下"游戏才刚刚开始"的纸条。这是一个**承诺钩（H-PROMISE）**，观众会期待下一集的对抗升级，同时好奇方怀瑾的下一步计划。
- **叙事功能**：作为风暴段（EP33-57）的中段，本集完成了"救援成功"的阶段性胜利，但通过纸条制造新的悬念，推动剧情向更大的冲突发展。

### 与前后集的衔接

- **承接EP39**：陆辞渊被困老宅书房，方怀瑾按下警报后消失。陆辞渊在EP39中从保险箱找到的U盘存储着方怀瑾境外账户信息。林默和季柏舟赶到救援，陆辞渊提供密码线索后被救出，交出U盘。
- **铺垫EP41**：方怀瑾开始全面反扑，动用所有关系网对林默、陆辞渊、季柏舟展开围剿。
