## 主角

### CHAR-001 · 苏念晚

| 字段 | 内容 |
|------|------|
| 角色 ID | `CHAR-001` |
| 姓名 | 苏念晚 / 林小晚 |
| voice_prompt | 「成年女性，28岁，声线清冷偏低，语速中等偏慢，平时克制内敛，说话精准有力，装傻时语速加快语气上扬带无辜感，关键时刻语调沉稳有穿透力，偶尔停顿制造张力」 |
| 语言风格 | 词汇层级高但不炫耀，句式简短有力，善用反问和类比。装新人时故意用"啊？""我不太懂哎"等小白话术。口头禅：「有意思。」 |
| 备注 | 全集适用；装新人（EP01–32）与真实身份（EP33–72）语气有微妙差异但 voice_prompt 保持一致 |
