## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同群演角色独立 ID + L01    |
| 场景     | `SCENE-###`                       | `SCENE-001`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-镜号                        |

### ID 分配规则

- 编号**连续、不跳号**；ID **只增不删**，弃用标 `deprecated: true`
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象
- 新建换装/阶段形象：只加 `L02+` 衍生形象，必须写明 `based_on: CHAR-xxx-L01`，**禁止跳过 L01**
- 群演按需创建，不设数量上限：有名字+跨 segment 出现 → 独立 `CHAR-GRP-##`；scene-writer 剧本中标注的新群演（`[待补：...]`）由 production-planner 在集间群演回补子循环统一分配（从已有最大编号 +1）
- 不同视觉角色不可共用同一 GRP ID；同一 GRP ID 可跨集复用
- API 参考图配额：每 segment ≤6 张（TOS URL 模式），超出按 segment-builder 优先级裁减

### 形象层级

| 后缀     | 名称     | 说明                                        |
| -------- | -------- | ------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

> 初始风格方向来源于大纲元数据「视觉风格：明亮国风仙侠」「色彩基调：暖金日常 + 青白雷光点缀」。

| 维度 | 规格 |
|------|------|
| 渲染风格 | cinematic stylized realism（电影感国风仙侠实拍质感，高饱和明亮，喜剧轻盈，**低压迫感**） |
| 镜头参考 | cinematic 35mm–85mm lens；喜剧反应镜头偏中近景；仅 EP70 一处大 VFX 全景 |
| 色调方向 | warm golden daily tone + cyan-white lightning accents（暖冷对撞制造喜剧反差） |
| 画幅 | 9:16 vertical |
| 题材关键词 | bright xianxia, Chinese fantasy sect, comedic lightning, hanfu robes, mountain temple architecture |

### 全局 prompt_suffix（出图统一后缀，设计师在此基础上拼接）

```
ancient Chinese xianxia fantasy, bright warm golden tones with cyan-white lightning accents, cinematic lighting, high detail, 9:16 vertical composition
```

### 结构性 negative_prompt（年代/题材禁忌 + 雷击合规，**所有出图/出片必带**）

```
modern objects, smartphone, electric wires, cars, glass skyscraper, neon signs, zipper, wristwatch, jeans, sneakers, plastic items, contemporary clothing, real-world dynasty emblems, blood, gore, graphic injury, burnt corpse, realistic electrocution wounds, death, painful scream close-up, horror atmosphere, dark oppressive tone, kneeling worship crowd, incense altar worship, religious idol veneration
```

## 六、分段规则

| 约束             | 值              | 说明                                    |
| ---------------- | --------------- | --------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                 |
| 每 segment 镜头数 | ≤3 镜；段 ≥8s 必 ≥2 镜 | v2.2 切镜节奏                     |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍       |
| 每集段落数       | 见四B episode_profile | EP01 10–12；EP02+ 6–10            |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（合掌—雷落—冒烟等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤2；长对手戏拆 `SEGxxa` / `SEGxxb`
5. 分镜表某镜自然时长 <4s → 并入同场景相邻段
6. **场景（SCENE-###）= 空间单位；Segment = AI 生成单位**；同一场景可含多个 segment，segment 不得跨场景

## 八、音色规范

- **voice_prompt 唯一权威来源（P0）= `资产/声音卡片.md`**；P1 = 角色卡片；P2 = 本文件。存在 P0 一律用 P0。
- voice_prompt 必须全文复制（「」内全部文字），禁止缩写、改写、简化；同一角色跨 segment 全文一致。
- 林小满内心 OS 与对外台词同一音色，由分集剧本以 `[OS]` 情绪标注区分语气，不另设旁白角色。
- 本剧不设独立旁白；如后续需要，另行在声音卡片登记。
- 音效在分集剧本镜头表标注（如 `天雷炸响`、`木鱼声`）；`generate_audio: true` 合成基础环境音，特殊音效后期叠加。
- 字幕后期 ffmpeg 统一添加，Seedance 不烧录字幕。

## 九、年代/题材约束

**必须体现**：
- 架空修真界国风元素：道袍/短打/劲装等古装制式、山门殿宇、符箓雷纹、纸鹤公文
- "雷部文书制度"世界观道具质感：官册、封条、火漆、公文卷宗（程序性权柄，非鬼神崇拜）
- 雷光为**喜剧标点**：明亮青白色、卡通化落点结果（焦发/黑脸/冒烟），不渲染恐怖

**禁止出现**：
- 一切现代物品（手机、电线、玻璃幕墙、拉链、手表、汽车、塑料制品、现代服装）
- 可识别的真实朝代年号/官制/地名映射（本剧为架空世界观）
- 雷击死伤/血腥/焦尸/痛苦特写（合规基线：雷击零真实伤亡）
- 跪拜磕头镜头（全宗拜服一律抱拳长揖）、跪拜祭祀/神像崇拜画面
- 捆绑、私刑、羞辱性画面（EP48 软禁为喝茶戏、EP72 锁拿为文书程序戏）

- 主频道: 男频轻喜为主、女频可看（18-40 通吃）
