## 一、ID 命名规则

### 1.0 完整 ID 命名表

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-分段内镜头编号              |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |

- 编号**连续、不跳号、只增不删**；弃用标 `deprecated: true`。
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再建 `L01` 基础形象于 `资产/形象索引.md` + `角色卡.md`。
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-###-L01`。

## 三、工作流顺序（修改层级）

制片规范确立后，所有内容修改**严格按层向下**，禁止跳跃：

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **总剧本**   | `短剧剧本_折衣令_36集.md` | 集纲、每场剧情、对白要点、钩子、情绪峰值            |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡、资产索引等       | 仅在前几步定稿后随需更新                            |

**禁止**：
- 先改 `segments.yaml` 再回头补剧本
- 先建形象再登记角色索引
- 跳过 L01 直接生成 L02

**单集真相源**是 `剧本/EP##/EP##_*.md`。所有下游文件必须从此导出。

## 四、分集文件头（YAML 模板）

每集分集剧本必须以此 YAML 头开始：

```yaml
---
episode_id: EP##
episode_title: [集标题]
duration_min: 2.5
season: S1
scene_ids: [SCENE-###, SCENE-###, ...]
character_ids: [CHAR-###, CHAR-###, ...]
look_ids: [CHAR-###-L##, CHAR-###-L##, ...]
seedance_defaults:
  model: doubao-seedance-2-0-fast
  ratio: "9:16"
  resolution: 720p
  duration_sec: "8-10"
  generate_audio: true
  prompt_suffix: "禁止画面中出现任何文字或字幕。古装宫廷医毒剧风格，唐宋美学，电影级写实质感。"
  negative_prompt: "blurry, distorted, low quality, watermark, subtitles burned into frame, anime style, cartoon style, watercolor, oil painting style, modern clothing, smartphone, car, neon sign, concrete building, plastic, Qing dynasty hairstyle, queue/bianzi, modern objects, electric light, wristwatch, glasses, zipper, logo, text in image, wire, cable, screen, digital display, modern medical equipment, stethoscope, syringe, pill bottle, plastic packaging, IV drip, hospital bed, latex gloves"
---
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `episode_id` | string | 格式 `EP##`，连续编号 |
| `episode_title` | string | 集标题，中文 |
| `duration_min` | number | 固定 2.5（150秒） |
| `season` | string | 固定 S1 |
| `scene_ids` | array | 本集用到的所有场景 ID |
| `character_ids` | array | 本集出场的所有角色 ID |
| `look_ids` | array | 本集使用的所有形象 ID |
| `seedance_defaults.model` | string | 固定 `doubao-seedance-2-0-fast` |
| `seedance_defaults.ratio` | string | 固定 `"9:16"` |
| `seedance_defaults.resolution` | string | 固定 `720p` |
| `seedance_defaults.duration_sec` | string | 默认 `"8-10"`，可按段覆盖 |
| `seedance_defaults.generate_audio` | bool | 固定 `true` |
| `seedance_defaults.prompt_suffix` | string | 中文约束，追加到每个 Seedance Prompt 末尾 |
| `seedance_defaults.negative_prompt` | string | 英文负面提示词，全剧统一模板（含医毒剧专属禁忌） |

## 六、AI 出图/视频衔接

### 6.1 出图流程

1. **定稿 L01 参考图** → Character Sheet（正面全身，白底/中性背景）
2. **衍生形象**用图生图 / 角色一致性模型 → **delta Prompt** 仅写服装/道具/妆效差异
3. **禁止跳过 L01 直接生成 L02**
4. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01

### 6.2 形象一致性规则

| 规则 | 说明 |
|------|------|
| **同脸原则** | CHAR-001-L01 与 L02 保持相同面部结构（鹅蛋脸+沉静深眸），差异仅在服装、发型、配饰和表情 |
| **父女相似** | CHAR-001（宋折衣）与 CHAR-006（宋清源）共享相同眼型——深眸、 intelligent、kind |
| **关键道具追踪** | 玉佛珠（CHAR-004 手中必有）、玉镯（CHAR-003 腕上必有）、左眉横疤（CHAR-002 永远存在）、半块玉佩（折衣随身携带） |
| **一致性锚点** | 每角色至少保持 3 个不变特征：发型轮廓 + 服装主色 + 核心配饰 |
| **回忆滤镜** | CHAR-006 出场（仅回忆/遗物场景）加柔焦发光效果 `slight dreamy soft-focus glow` |
| **竖屏构图** | 单人形象以半身/七分身为主；双人对白用上下或对角线构图（非并排）；背景留白适配字幕叠加 |

### 6.3 Prompt 书写规范

**L01（完整 Prompt）**：
```
A [age]-year-old Chinese [gender], [build], [face shape and features], [hair], wearing [clothing],
[pose], [environment], [style tags], character sheet
```

**L02+（Delta Prompt）**：
```
Same face as CHAR-###-L01. [changed elements only — hair, clothing, makeup, environment].

```

## 七、道具转移与肢体动作（防错清单）

### 7.1 常见 AI 错误（本剧特化）

| 错误类型 | 表现 | 预防策略 |
|----------|------|----------|
| 道具瞬移 | 前镜手中有银针，后镜消失 | segment 内不跨镜转移道具；跨 segment 在 Prompt 明确"手持XXX" |
| 道具变形 | 玉佩变成金锁、药瓶变花瓶 | 关键道具在 Prompt 中附尺寸、材质描述（如"half jade pendant, 5cm, dark green with carved symbol"） |
| 手部畸变 | 手指数量错误、研药手势扭曲 | 避免特写手部复杂动作；握持道具用手部"包裹"描述 |
| 服饰穿越 | 折衣浣衣局段穿官服 | L02 Prompt 中明确"no official robe, no silver pendant, no jade hairpin" |
| 药粉颜色 | 不同毒物粉末颜色混淆 | 在 Prompt 中明确颜色：霜芽散=白色、碧蚕粉=淡青色、引毒粉=无色 |
| 佛珠错误 | 太后手中佛珠消失或变形 | CHAR-004 每段 Prompt 附"holding jade prayer bead bracelet in left hand" |
| 玉镯位置 | 贵妃玉镯左右反转或消失 | CHAR-003 始终"a jade bracelet on her left wrist" |

### 7.2 肢体动作 API 规则

- **双手交接道具**：必须在同一 segment 内完成，不可跨 segment
- **开门/关门/推门**：动作链必须在同一 segment 内；门的状态变化（开→关）不可跨 segment
- **跪拜/起立**：动作链完整在一个 segment 内
- **施针/配药/验毒**：医毒操作完整在一个 segment 内；银针入穴、药粉入杯等动作不可跨段
- **手部特写**（握玉佩、翻药典、攥信、研药粉）：时长 ≥ 4 秒，单独一镜
- **单段主说话人 ≤ 2**；长对手戏拆成 `SEGxxa` / `SEGxxb`

### 7.3 分段检查清单

- [ ] 每 segment 时长 4–12 秒（理想 8–10 秒）
- [ ] 每 segment 1–3 个镜头
- [ ] 对话不在中间切断（一句台词完整在同一段内）
- [ ] 连续动作不在中间切断（开门/摘道具等动作链完整）
- [ ] 跨 segment 边界：场景切换、主说话人切换、情绪断点
- [ ] 单镜自然时长 < 4 秒 → 并入同场景相邻段
- [ ] 医毒操作（施针、验毒、配药）在同一 segment 内完整呈现

## 八、有声段落（Seedance 2.0）

### 8.1 分段规则

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 约 12–15 段 | 对应单集 2.5 分钟时长（~150s ÷ ~10s/段 ≈ 15 段） |

### 8.2 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 8.3 场景 vs Segment（关键区分）

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 8.4 镜头模式分配

| 镜头类型 | 模式 | 说明 |
|---------|------|------|
| 环境空镜（无角色） | `t2v` | 纯文本描述，无参考图 |
| 角色出镜 | `i2v_ref` | 需角色参考图保持一致性 |
| 片头/片尾/黑屏 | `skip` | 非 AI 生成，后期合成 |

### 8.5 字幕策略

- **Seedance 不烧录字幕**——Prompt 中必须声明 `"禁止画面中出现任何文字或字幕"`
- 字幕通过 **ffmpeg 后期统一叠加**（ASS/SSA 格式）
- 剧中文字（药典内容、血书、字条、信件等）如果在画面中必须可见 → **后期合成**，AI 无法可靠渲染中文
- 父亲遗言（EP3扉页、EP20血书）的文字内容后期叠加

### 8.6 音频策略

- Seedance `generate_audio: true` 合成基础环境音 + 对白 TTS
- 特殊音效（银针入穴声、药粉研磨声、佛珠咔嗒声、瓷杯碎裂声、水声）标注在分集剧本镜头表 `对白/备注` 列
- 配乐标注在分集剧本 `本集制作备注` 中
- EP36 结尾画外音（折衣念父亲遗言）为后期合成片段

### 10.1 必须包含的结构（按顺序）

| 序号 | 部分 | 必选 | 说明 |
|------|------|------|------|
| 1 | YAML 文件头 | ✅ | 按第四章模板 |

| 3 | 元信息摘要表 | ✅ | 叙事目标、钩子、默认形象、有效镜数、Segment数、版本 |
| 4 | 本集观众必须听懂 | ✅ | 编号列表：谁、发生什么、为什么、下集看什么 |
| 5 | SEG 正文 | ✅ | 按 Segment 分组的镜头表（11 列格式） |
| 6 | 结尾钩子 | ✅ | 一句话悬念 + 下集标题预告 |
| 7 | 本集制作备注 | ✅ | 情绪弧、光线、造型、音乐、节奏、关键细节 |
| 8 | 本集资产 | ✅ | 场景/角色/形象/道具/有效镜数汇总 |

### 10.2 11 列镜头表格式

```
| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白/备注 |
|------|---------|------|------|------|------|------|------|------|------|-----------|
```

#### 各列规范

| 列名 | 格式 | 说明 |
|------|------|------|
| 镜号 | 整数 | 全集连续编号（1, 2, 3...），不随 SEG 重置 |
| shot_id | `EP##-S##` | 全局唯一，如 `EP01-S01`、`EP01-S22` |
| 场景 | `SCENE-###` | 对应资产/场景卡片.md 中的 ID |
| 角色 | `CHAR-###` | 出镜角色，多人逗号分隔；无人写 `—` |
| 形象 | `CHAR-###-L##` | 本镜使用的形象版本，多人逗号分隔；无人写 `—` |
| 景别 | 中文 | 全景/中景/近景/特写/大特写 |
| 时长 | 整数秒 | ≥4（Seedance 最小单位） |
| 模式 | 枚举 | `t2v`（纯文本）/ `i2v_ref`（带参考图）/ `skip`（非AI） |
| 运镜 | 中文 | 固定镜头/缓推/镜头推近/镜头拉远/镜头跟随/快切/主观镜头 |
| 画面 | 2–4句 | 电影级视觉描述：布景、光线、人物姿态、道具、伏笔 |
| 对白/备注 | 格式化 | `**CHAR-###**[情绪]：「台词」` 或 `（无对白，[音效]）` |

### 10.3 对白格式

| 场景 | 格式 |
|------|------|
| 有对白 | `**CHAR-###**[情绪·语气]：「台词」` |
| 内心独白 | `**CHAR-###**[内心]：「...」` |
| 无对白 | `（无对白，[音效]）` |
| 回忆旁白 | `**CHAR-006**[回忆旁白·混响]：「...」` |
| 旁白 | `**旁白**[情绪]：「...」` |

### 10.4 SEG 块结构

```
---

## SEG## — [叙事功能]

**【SCENE-###】[地点]** · **[时段]** · **[内/外景]**

| 镜号 | shot_id | ... | 对白/备注 |
|------|---------|-----|-----------|
| ... |

> ⏱ Segment时长：Xs ｜ 镜头数：N
```

- 场景切换时写完整场景头：`**【SCENE-###】地点** · **时段** · **内/外景**`
- 同场景续接写：`**（续）**`
- 每 SEG 以 `---` 分隔，结尾附 `> ⏱` 统计行

### 10.5 画面描写质量标准

「画面」列禁止一句话空洞概括。每格必须 2–4 句，包含：
- 布景具体细节（药柜抽屉、桌面药材、墙面装饰、地面状态等）
- 光线/色温/明暗——情绪外化
- 人物姿态/微表情/手部动作/视线
- 与剧情相关的道具互动（药具、毒物、信件、玉佩等）
- 暗示/伏笔元素（可选但推荐）
