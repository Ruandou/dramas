# 制片规范 — 我妈退休后不装了

> 项目宪法文件。定义 ID 系统、资产骨架、分段规则、视觉风格、技术参数。
> 创建时间：2026-07-01

---

## 1. 项目概况

| 字段 | 值 |
|------|-----|
| 剧名 | 我妈退休后不装了 |
| 英文标题 | My Mom Retires and Stops Pretending |
| 题材 | 🟢 C 级都市家庭伦理 |
| 集数 | 72 集 |
| 单集时长 | 90 秒竖屏（EP01：90-120 秒） |
| 总时长 | ~108 分钟 |
| 受众画像 | 45-60 岁下沉女性（主力）+ 25-45 岁女性（副线） |
| 核心情绪 | 爽（拒绝+打脸）+ 暖（亲情救赎） |
| 差异化 | 银发"反向觉醒"——60 岁母亲视角，不重生/替身/假孕 |

## 2. ID 系统

### 2.1 ID 前缀与范围

| 资产类型 | 前缀 | 范围 | 示例 |
|----------|------|------|------|
| 主要角色 | CHAR- | 001-099 | CHAR-001（林慧兰） |
| 群演角色 | CHAR-GRP- | 001-099 | CHAR-GRP-001（广场舞姐妹团） |
| 场景 | SCENE- | 001-099 | SCENE-001（林家客厅） |
| 道具 | PROP- | 001-099 | PROP-001（离婚协议书） |
| 角色形象（基础） | CHAR-###-L01 | — | CHAR-001-L01 |
| 角色形象（衍生） | CHAR-###-L02 | — | CHAR-001-L02 |

### 2.2 ID 分配规则

- 所有 ID 只增不删，弃用标 `deprecated`
- 群演 ID（CHAR-GRP-###）在场景写作时按需分配
- 场景 ID 按首次出场集数顺序分配
- 道具 ID 分三类：`待生成`（独立图）、`场景内置`（嵌入场景图）、`角色内置`（绑定角色图）

## 3. 技术参数

### 3.1 视频模型

- **模型版本**：Seedance 1.6（竖屏 9:16）
- **分辨率**：1080×1920（竖屏）
- **帧率**：24fps
- **单段时长**：4-12 秒
- **每集 Segment 数**：6-10 段（EP01 可 10-12 段）

### 3.2 图片模型（参考图生成）

- **模型**：Seedream 3.0（即梦）
- **分辨率**：1080×1920（竖屏），与视频模型一致
- **角色图格式**：全身/半身竖构图，纯色或丝绸背景
- **道具图格式**：单物体 + 丝绸背景，无人物
- **场景图格式**：广角竖构图，无人物

### 3.3 Prompt 工程

**通用 prompt_suffix：**
```
竖向构图 9:16，温暖真实的生活质感，柔和的家庭光线，自然肤色，细腻纹理，电影级打光，细节丰富，高分辨率，写实摄影风格
```

**negative_prompt：**
```
文字内容，模糊，低质量，扭曲的面部，畸形的手，水印，签名，卡通，动漫，插图风格，过度锐化，过度饱和，恐怖，灵异，血腥，暴力，政治元素，低俗暗示，卧姿，色情，泳装，裸露，吸烟，酗酒
```

## 4. 视觉风格锚点

| 维度 | 定义 |
|------|------|
| 渲染风格 | 温暖写实风（Warm Realism）—— 介于新闻摄影和家庭纪录片之间 |
| 色调 | 暖黄主色调（#F5E6C8 基准），冲突场景偏冷色对比（#4A6FA5） |
| 光影 | 柔和自然光为主，室内多用窗光侧照，夜场用暖色人工光 |
| 构图 | 竖屏 9:16 满构图，人物居中偏下，面部特写占画面 1/3 |
| 服装 | 日常家庭服饰，不浮夸；林慧兰觉醒后从暗色系转为暖色系 |

## 5. 分段规则

### 5.1 每集分段结构

| 段位 | 位置 | 时长 | 内容 |
|------|------|------|------|
| 开场钩子 | Segment 1 | 8-12s | 冲突引入/上集悬念延续 |
| 发展 | Segment 2-4 | 12-24s | 对话/互动/冲突升级 |
| 高潮 | Segment 5-7 | 12-24s | 情绪峰值/反转/金句 |
| 收束 | Segment 8-9 | 12-18s | 情绪回落/人物反应 |
| 悬念 | Segment 10（如适用） | 6-10s | 下集钩子/冲突预告 |

### 5.2 episode_profile

| 参数 | 标准值 | EP01 特例 |
|------|--------|-----------|
| 总时长 | ≥75s 且 ≤120s | 90-120s |
| Segment 数 | 6-10 段 | 10-12 段 |
| 单段时长 | 4-12s | 4-12s |
| 说话角色数 | ≥2 个 | ≥3 个 |
| 对白密度 | ≥20 行/分钟 | ≥20 行/分钟 |

## 8. 受众分层元数据

| 层 | 年龄段 | 占比 | 核心诉求 | 内容偏好 |
|----|--------|------|----------|----------|
| 主力层 | 45-60 岁 | 65% | 情感共鸣、自我价值认同 | "为自己活"的爽感、家庭角色反转 |
| 副线层 | 25-45 岁 | 30% | 家庭教育反思、代际理解 | 母女关系、婆媳关系、女性独立 |
| 扩散层 | 60+ 岁 | 5% | 同龄人故事代入 | 银发生活、二次人生 |
