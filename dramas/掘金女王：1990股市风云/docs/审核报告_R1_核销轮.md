## 未清零 Note 详情

### Note 2：父亲案时间锚点矛盾——**未修复**

- **位置**：EP48（行455）+ 角色表（行919）
- **矛盾证据**：
  - 行919 角色表：林晓芸 **22岁**（EP01 出场年龄）
  - 行69 EP01：1990年12月，林晓芸是国营厂正式会计（能当众算账、被劝婚、独立垫付工资）→ 成年女性，与 22 岁自洽 ✅
  - 行455 EP48：录音（**十年前**=1980年）中秦董事长威胁"林会计，**你女儿才五岁吧**？"
- **推算**：
  - 若 1990年她 22 岁 → 出生 ≈1968年 → 1980年她 **12 岁**（不是 5 岁）
  - 若 1980年她 5 岁 → 出生 1975年 → 1990年她 **15 岁**（不可能是国营厂正式会计）
- **矛盾本质**：22岁（1990）与"十年前女儿才五岁"（1980年5岁）不可同时成立，相差 7 年
- **修复方案**（二选一）：
  - **方案A（推荐）**：EP48 录音台词改为"林会计，**你女儿才十二岁吧**？"（1980年12岁 → 1990年22岁 ✅，与角色表完全自洽）
  - **方案B**：改为"林会计，**你女儿上初中了吧**？"（模糊年龄但指向 12-14 岁区间，同样自洽）
- **影响维度**：维度3（制作可行性）——时间线矛盾会导致 EP48 镜头逻辑错误（录音中"五岁女儿"与 EP01 成年会计形象冲突）
- **修复层级**：**大纲正文**（EP48 行455 录音台词）
