## 生成参数汇总

| 参数 | 值 |
|------|-----|
| 画幅 | 9:16 vertical |
| 风格 | photorealistic, 90s China urban style, warm nostalgic tone |
| 镜头 | shot on 85mm lens |
| 背景 | plain white background |
| 打光 | clean flat studio lighting |
| 反向提示 | NOT anime, NOT cartoon, NOT illustration, NOT manga |

## L02+ 衍生形象生成规则

| 规则 | 说明 |
|------|------|
| 参考图输入 | L02+ 必须传入对应 L01 的存储永久 URL 作为 image_urls |
| 面部一致性 | Prompt 必须包含 "SAME person as the reference image" + "Keep the SAME face" |
| 背景纪律 | L02+ 必须包含 "plain white background maintained" |
| Delta 原则 | 仅描述与 L01 不同的部分（服装、配饰变化） |
