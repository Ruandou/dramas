## 一、ID 命名规则

所有资产必须使用统一编码，**只增不删**；弃用标 `deprecated: true`。

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同角色独立 ID + L01（按需创建，无上限） |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- **群演按需创建，不设数量上限**：有名字+跨 segment 出现 → 独立 `CHAR-###`；纯背景无台词但需视觉区分 → `CHAR-GRP-##`
- 同一 CHAR-GRP-## 可跨集复用，但不同视觉角色不可共用同一 ID

### 形象层级结构定义

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

## 四、工作流顺序（必读 · 防不同步）

制片规范确立后，所有内容修改**严格按层向下**：

| 顺序 | 层 | 文件 | 写什么 |
|:----:|----|------|--------|
| **1** | **主剧本** | `短剧剧本_掘金女王：1990股市风云_86集.md` | 集纲、每场剧情、对白要点、钩子 |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md` | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象 |
| **3** | **机器可读** | `EP##_shots.yaml` | 从分集 md 导出，勿手改 yaml 当源 |
| **4** | **段落 API** | `EP##_segments.yaml` | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它** | 声音卡片、资产索引等 | 仅在前几步定稿后随需更新 |

**禁止**先改 `segments.yaml` 再回头补剧本。**单集真相源**是 `剧本/EP##/EP##_*.md`。

## 六、分段规则

### 分段（Segment）规则 —— AI 生成单位

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | 视频生成引擎硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | ≤3 镜；段 ≥8s 必 ≥2 镜（典型 2-3） | 静音视觉锤段可单镜但 ≤8s |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | 对应单集 75–120 秒（EP01 可至 12 段） |
| 每集镜头数 | 16–30 镜（EP01 20-36） | 每集 6–10 段 × 2–3 镜/段；单镜理想 3-6s，>10s 禁 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次视频生成引擎 API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 九、年代/题材约束

### 必须体现元素

- 1990-1992年上海都市风貌（上交所开业、深交所开业、认购证狂潮）
- 国企改革背景（纺织厂减薪、下岗潮）
- 早期股市生态（红马甲、行情黑板、大户室、柜台交易）
- 90年代服装道具（的确良衬衫、工装裤、中山装、算盘、搪瓷杯）
- 女性职场困境与突破（性别歧视、临时工、首批女性经纪人）

### 禁止出现元素

- 任何真实股票代码/真实上市公司名/真实人物影射
- 现代物品（手机、电脑、互联网、现代服装）
- 政治隐喻、官商勾结具象化
- 美化违规/投机暴富
- 自残濒死特写、刑讯场面

## 十、受众定位

- **主频道**：女频（女性成长+职场逆袭）
- **核心年龄段**：25-45岁
- **核心痛点**：①职场性别歧视与突破；②90年代怀旧情怀；③股市造富的戏剧张力；④"她没靠男人"的价值观共鸣
- **爽感期待**：逆袭爽30% + 打脸爽25% + 悬疑爽20% + 甜蜜爽10% + 感动爽10% + 燃爽5%
- **对标作品**：《风吹半夏》（女性创业+年代）、《繁花》（90年代上海+股市）

## 内容合规参数

### 题材合规等级

**B级**（年代财经题材，需注意金融合规与历史准确性）

### 本剧特定红线

1. **不出现真实股票代码/真实上市公司名/真实人物影射**——个股一律用"飞乐股份""凤凰化工"式虚构名或"A股/B股"代称
2. **不宣扬投机暴富**——每个造富神话必配风险镜头（有人排队通宵也有人血本无归），女主台词锚定"股市有风险，入市需谨慎"的职业底线
3. **女主成长不依附男性**——方志远是导师非救世主、老周是客户非金主，关键翻盘均由林晓芸专业判断完成
4. **涉"黑市/黄牛/坐庄"一律作被挫败的罪证性刻画**——结局由"有司查办"旁白交代，不拍刑讯、不美化违规
5. **无政治隐喻、无官商勾结具象化**——政策波动只作时代背景板
6. **下跪/当众羞辱弱化为鞠躬/被扶起**——苦难（下岗、亏损）以"拿起—被阻止/切走"处理，禁自残濒死特写

### 灰区处理策略

| 灰区 | 处理方式 |
|------|----------|
| 股市投机描写 | 必配风险镜头，女主台词锚定职业底线 |
| 黑市/黄牛/坐庄 | 作被挫败的罪证性刻画，结局由"有司查办"交代 |
| 性别歧视冲突 | 以专业打脸方式化解，不激化性别对立 |
| 父亲被冤死 | 以"拿起—被阻止/切走"处理，禁自残濒死特写 |

### 正向价值锚点

1. **女性职场逆袭**——女主靠专业能力而非男性庇护获得成功
2. **诚信为本**——"账要算清，人要站直"的主题金句贯穿全剧
3. **正义伸张**——黑幕被揭露，罪犯伏法，父亲平反

### 平台审核重点提示（前3集）

- **EP01**：减薪大会冲突需弱化"国企负面"印象，强调"改革阵痛"而非"企业腐败"
- **EP02**：营业部场景需准确还原1990年上交所开业初期风貌，避免现代元素
- **EP03**：母亲欲言又止的"你爸当年"需处理为"历史遗憾"而非"政治迫害"
