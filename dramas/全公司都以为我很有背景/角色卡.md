## ID 说明（必读）

| 层级 | 格式           | 用途                       |

| 角色 | `CHAR-001`     | 对白、关系、分镜「角色」列 |

## 【角色卡】林舟（男主）· `CHAR-001`

### 基础信息

| 字段        | 内容                                                                                |
| ----------- | ----------------------------------------------------------------------------------- |
| **角色 ID** | `CHAR-001`                                                                          |
| 姓名        | **林舟**                                                                            |
| 年龄        | 23 岁                                                                               |
| 身份        | 小城应届毕业生 → 集团市场部实习生 → 被误认为「董事长私生子」 → 靠真实能力赢得尊重   |
| 性格标签    | 朴实、有原则、被动卷入、内疚感强、最终成长为敢担当的人                             |

### 外貌特征

- 身高体型：177cm，偏瘦，体型干净利落，没有健身肌肉感，就是普通年轻人的身板
- 发型发色：黑色短发，整洁但不刻意打理
- 面部特征：五官清秀，神情真诚带轻微局促，不够世故
- 服装风格：白色牛津衬衫 + 深色修身休闲裤 + 简约黑色皮鞋 + 工牌挂绳（日常）
- 配色：白、深蓝、黑、灰

### 性格详解

- 核心：一个省考三次未过的应届生，带着"努力就会有回报"的朴素信念来上海闯；在完全意外的误会里，被迫思考「沉默是否等同于撒谎」
- 内心冲突：不想被裁 vs. 良知上的负疚；接受误会的加成 vs. 知道自己不配
- 成长弧线：被动受益 → 主动放弃虚名 → 用真实能力证明自己
- 习惯：查资料、认真做笔记、遇事先在心里过一遍然后出口很慢

### 经典台词

1. "我就是帮人捡了个文件……"
2. "我不会。"（对陈竞说，绝对直白）
3. "对不起。"（对赵雪说）
4. "我要做点真东西。"
