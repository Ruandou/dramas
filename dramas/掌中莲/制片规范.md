## 一、ID 命名规则

### 1.0 完整 ID 命名表

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`        | 集数-分段内镜头编号              |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |

- 编号**连续、不跳号、只增不删**；弃用标 `deprecated: true`。
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再建 `L01` 基础形象于 `资产/形象索引.md` + `角色卡.md`。
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-###-L01`。

## 三、工作流顺序（修改层级）

制片规范确立后，所有内容修改**严格按层向下**，禁止跳跃：

| 顺序  | 层           | 文件                     | 写什么                                              |
| :---: | ------------ | ------------------------ | --------------------------------------------------- |
| **1** | **总剧本**   | `短剧剧本_掌中莲_36集.md` | 集纲、每场剧情、对白要点、钩子、情绪峰值            |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`    | 可拍分镜表：shot_id、画面、对白、CHAR/SCENE/形象    |
| **3** | **机器可读** | `EP##_shots.yaml`        | 从分集 md 导出，勿手改 yaml 当源                    |
| **4** | **段落 API** | `EP##_segments.yaml`     | 按 md 镜号合并为 segment；对白与第2步引号内字面一致 |
| **5** | **其它**     | 声音卡、资产索引等       | 仅在前几步定稿后随需更新                            |

**禁止**：
- 先改 `segments.yaml` 再回头补剧本
- 先建形象再登记角色索引
- 跳过 L01 直接生成 L02

**单集真相源**是 `剧本/EP##/EP##_*.md`。所有下游文件必须从此导出。

```yaml

episode_id: EP##

duration_min: 2.5
season: S1
scene_ids: [SCENE-###, SCENE-###, ...]
character_ids: [CHAR-###, CHAR-###, ...]
look_ids: [CHAR-###-L##, CHAR-###-L##, ...]
seedance_defaults:
  model: doubao-seedance-2-0-fast-260128
  ratio: "9:16"
  resolution: 720p
  duration_sec: "8-10"
  generate_audio: true
  prompt_suffix: "禁止画面中出现任何文字或字幕。古装宫廷悬疑风格，唐宋美学，电影级写实质感。"
  negative_prompt: "blurry, distorted, low quality, watermark, subtitles burned into frame, anime style, cartoon style, watercolor, oil painting style, modern clothing, smartphone, car, neon sign, concrete building, plastic, Qing dynasty hairstyle, queue/bianzi, modern objects, electric light, wristwatch, glasses, zipper, logo, text in image, wire, cable, screen, digital display"
---
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|

| `episode_title` | string | 集标题，中文 |
| `duration_min` | number | 固定 2.5（150秒） |
| `season` | string | 固定 S1 |
| `scene_ids` | array | 本集用到的所有场景 ID |
| `character_ids` | array | 本集出场的所有角色 ID |
| `look_ids` | array | 本集使用的所有形象 ID |
| `seedance_defaults.model` | string | 固定 `doubao-seedance-2-0-fast-260128` |
| `seedance_defaults.ratio` | string | 固定 `"9:16"` |
| `seedance_defaults.resolution` | string | 固定 `720p` |
| `seedance_defaults.duration_sec` | string | 默认 `"8-10"`，可按段覆盖 |
| `seedance_defaults.generate_audio` | bool | 固定 `true` |
| `seedance_defaults.prompt_suffix` | string | 中文约束，追加到每个 Seedance Prompt 末尾 |

## 五、美术规范（架空古装宫廷悬疑 · 唐宋美学）

本项目为**架空古装宫廷权谋剧**，不绑定特定朝代，以**唐宋宫廷美学**为视觉基调，融入莲花意象与火焰/洪水记忆。

### 5.1 必须体现（Must Include）

| 类别 | 元素 |
|------|------|
| **服装** | 唐宋风格汉服（交领/圆领袍、大袖衫、凤冠霞帔）；帝王龙袍玄黑暗金；白莲素白淡青；太后暗红深紫凤凰纹；丽妃桃红金色牡丹纹 |
| **建筑** | 朱红宫墙、琉璃瓦顶、金砖地面、雕梁画栋、木质结构、石灯笼、曲折长廊、荷花池 |
| **照明** | 油灯、蜡烛、龙凤喜烛、纸灯笼、石灯笼、月光——**禁止电灯** |
| **器物** | 铜镜、毛笔、宣纸、砚台、青铜香炉、红木家具、瓷器茶具、竹简/卷宗、佛珠 |
| **核心母题** | 莲花纹样（胎记、刺绣、池荷、干花）、火焰/洪水（闪回记忆）、龙凤纹饰 |

### 5.2 禁止出现（Must NOT Include）

| 类别 | 元素 |
|------|------|
| **现代物品** | 智能手机、汽车、电线杆、霓虹灯、水泥建筑、塑料制品、拉链、手表、眼镜 |
| **现代科技** | 电灯、电线、开关、屏幕、电梯、空调、麦克风 |
| **特定朝代** | 清代发式（辫子/旗头）、清代服饰（旗袍/马褂）、明代官服补子 |
| **现代符号** | 文字/Logo/商标、英语/拼音标志、二维码、现代印刷字体 |
| **画面质量** | 模糊、变形、低画质、水印、烧录字幕、动漫风格、卡通风格、水彩风格、油画风格 |
| **敏感内容** | 兄妹之间的亲吻/浪漫拥抱、过度暴露的服装、血腥暴力画面 |

### 5.5 "禁忌兄妹"合规规范

本剧的核心叙事张力来自"兄妹错位"的情感悬念。为确保审查安全并保持叙事力度，必须严格遵守以下分级规则：

#### 阶段一：EP1–20（观众误导期）

- 观众视角：以为在看一段禁忌爱情
- 实际呈现：兄妹之间的**本能亲近**被误解为暧昧（对白和行为本身均不越界）
- 允许的肢体接触：手腕触碰、手指碰触、扶肩、擦泪、拉住衣袖
- 禁止的肢体接触：亲吻、长时间拥抱、抚摸面颊、任何暗示情欲的动作

#### 阶段二：EP21–36（兄妹明确期）

- 兄妹关系正式确认后，所有肢体接触限定在**亲情范畴**
- 允许的肢体接触：握手、额头轻触、拥抱（兄妹式，非缠绵）、并肩行走
- 禁止的肢体接触：**任何唇部接触**、缠绵拥抱、暗示爱情的身体接触
- EP36"掌心合一"明确定义为**亲情符号**——两手掌心合十如合掌祈福，非牵手

#### 营销红线

- **禁止**在任何营销物料中使用"禁忌恋""兄妹恋""乱伦"等表述
- **推荐**用语：错位命运、血浓于水、比爱情更深的羁绊、掌心莲开
- EP1–20 的宣传可强调"命运纠葛""不可言说的牵绊"，但不直接点明"爱情"
- EP21 后的宣传应转向"亲情""兄妹""团圆"

#### 画面合规检查

- [ ] 白莲与萧瑾之间是否有亲吻画面？→ ❌ 绝对禁止
- [ ] 两人拥抱是否超过3秒且有缠绵暗示？→ ❌ 禁止
- [ ] EP36 掌心合一是否为"合十"姿态（非牵手/十指相扣）？→ ✅ 必须
- [ ] 任何画面中是否有文字/台词暗示兄妹恋爱关系？→ ❌ 禁止

## 六、AI 出图/视频衔接

### 6.1 出图流程

1. **定稿 L01 参考图** → Character Sheet（正面全身，白底/中性背景）
2. **衍生形象**用图生图 / 角色一致性模型 → **delta Prompt** 仅写服装/道具/妆效差异
3. **禁止跳过 L01 直接生成 L02**
4. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01

### 6.2 形象一致性规则

| 规则 | 说明 |
|------|------|
| **同脸原则** | 同一角色的所有 L## 形象保持相同面部结构，差异仅在服装、妆造、表情 |
| **莲花胎记一致性**（#1 制作风险） | 白莲：左腕内侧，青粉色，硬币大小，工笔画风。萧瑾：右掌偏拇指根，稍大，同纹样。**必须设计统一莲花纹样参考图并锁定 seed** |
| **关键道具追踪** | 凤钗（CHAR-001 鬓边，L02a 去掉）、佛珠（CHAR-003 手中必有，EP28 后消失）、钥匙串（CHAR-005 腰间） |
| **一致性锚点** | 每角色至少保持 3 个不变特征：发型轮廓 + 服装主色 + 核心配饰 |
| **竖屏构图** | 单人以半身/七分身为主；双人对白用上下或前后纵深构图；掌心特写放手画面中央偏上 |

### 6.3 莲花胎记特殊处理（最高优先级）

莲花胎记是本剧的**核心视觉母题**，贯穿 36 集，出现在 EP2, 3, 7, 8, 9, 15, 24, 34, 36 等关键集数。

| 要求 | 说明 |
|------|------|
| **统一纹样设计** | 必须先由美术设计一朵标准莲花纹样（工笔画风、青粉色、花瓣5–7层），生成参考图后锁定 |
| **位置固定** | 白莲：左腕内侧（尺骨侧），距腕横纹约2cm。萧瑾：右掌偏拇指根部 |
| **大小一致** | 白莲的约硬币大小（≈2cm），萧瑾的稍大（≈2.5cm） |
| **Inpainting修补** | 每次AI生成后必须检查胎记位置和形态，不一致时用 Inpainting 手动修补 |
| **声音标记** | 每次胎记出现在画面中时，配合古琴单音（3–5秒短旋律），形成条件反射 |

### 6.4 Prompt 书写规范

## 七、道具转移与肢体动作（防错清单）

### 7.1 常见 AI 错误

| 错误类型 | 表现 | 预防策略 |
|----------|------|----------|
| 道具瞬移 | 前镜凤钗在发间，后镜消失 | segment 内不跨镜转移道具；跨 segment 在 Prompt 明确"头戴凤钗" |
| 胎记消失/错位 | 莲花胎记位置变化或消失 | 每次生成后检查胎记；不一致时 Inpainting 修补；Prompt 中始终包含胎记描述 |
| 手部畸变 | 手指数量错误、掌心胎记变形 | 避免复杂手部动作特写；手部特写 ≥ 4秒单独一镜 |
| 服饰穿越 | 白莲 EP24 仍穿贵人装 | L02 Prompt 中明确"no phoenix hairpin, no palace robe, plain white civilian clothing" |
| 佛珠错误 | 太后 EP28 后仍戴佛珠 | CHAR-003-L02 明确"no prayer beads, no phoenix crown, no jewelry" |
| 服装混用 | 丽妃 EP13 后仍穿桃红 | CHAR-004-L02 明确"no peach-pink, no gold, no elaborate hairpins" |

### 7.2 肢体动作 API 规则

- **双手交接道具**：必须在同一 segment 内完成，不可跨 segment
- **开门/关门/推门**：动作链必须在同一 segment 内
- **跪拜/起立**：动作链完整在一个 segment 内
- **手部特写**（握瓷瓶、攥采买册、合十掌心）：时长 ≥ 4 秒，单独一镜
- **单段主说话人 ≤ 2**；长对手戏拆成 `SEGxxa` / `SEGxxb`
- **兄妹肢体接触**：严格遵守 5.5 节合规规范

### 7.3 分段检查清单

- [ ] 每 segment 时长 4–12 秒（理想 8–10 秒）
- [ ] 每 segment 1–3 个镜头
- [ ] 对话不在中间切断（一句台词完整在同一段内）
- [ ] 连续动作不在中间切断（开门/摘道具等动作链完整）
- [ ] 跨 segment 边界：场景切换、主说话人切换、情绪断点
- [ ] 单镜自然时长 < 4 秒 → 并入同场景相邻段

## 八、有声段落（Seedance 2.0）

### 8.1 分段规则

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 约 12–15 段 | 对应单集 2.5 分钟时长（~150s ÷ ~10s/段 ≈ 15 段） |

### 8.2 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 8.3 场景 vs Segment（关键区分）

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 8.4 镜头模式分配

| 镜头类型 | 模式 | 说明 |
|---------|------|------|
| 环境空镜（无角色） | `t2v` | 纯文本描述，无参考图 |
| 角色出镜 | `i2v_ref` | 需角色参考图保持一致性 |
| 片头/片尾/黑屏 | `skip` | 非 AI 生成，后期合成 |

### 8.5 字幕策略

- **Seedance 不烧录字幕**——Prompt 中必须声明 `"禁止画面中出现任何文字或字幕"`
- 字幕通过 **ffmpeg 后期统一叠加**（ASS/SSA 格式）
- 剧中文字（采买册内容、字条、遗书等）如果在画面中必须可见 → **后期合成**，AI 无法可靠渲染中文

### 8.6 音频策略

- Seedance `generate_audio: true` 合成基础环境音 + 对白 TTS
- 特殊音效（烛火爆裂、脚步声、火焰声、古琴单音）标注在分集剧本镜头表 `对白/备注` 列
- 配乐标注在分集剧本 `本集制作备注` 中

## 十、分集剧本格式规范

### 10.1 必须包含的结构（按顺序）

| 序号 | 部分 | 必选 | 说明 |
|------|------|------|------|
| 1 | YAML 文件头 | ✅ | 按第四章模板 |
| 2 | 集标题 + 引用导航 | ✅ | `# EP## 集标题` + 修改顺序提示 + 角色卡/场景卡链接 |
| 3 | 元信息摘要表 | ✅ | 叙事目标、钩子、默认形象、有效镜数、Segment数、版本 |
| 4 | 本集观众必须听懂 | ✅ | 编号列表：谁、发生什么、为什么、下集看什么 |
| 5 | SEG 正文 | ✅ | 按 Segment 分组的镜头表（11 列格式） |
| 6 | 结尾钩子 | ✅ | 一句话悬念 + 下集标题预告 |
| 7 | 本集制作备注 | ✅ | 情绪弧、光线、造型、音乐、节奏、关键细节 |
| 8 | 本集资产 | ✅ | 场景/角色/形象/道具/有效镜数汇总 |

### 10.2 11 列镜头表格式

```
| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白/备注 |
|------|---------|------|------|------|------|------|------|------|------|-----------|
```

#### 各列规范

| 列名 | 格式 | 说明 |
|------|------|------|
| 镜号 | 整数 | 全集连续编号（1, 2, 3...），不随 SEG 重置 |
| shot_id | `EP##-S##` | 全局唯一，如 `EP01-S01`、`EP01-S20` |
| 场景 | `SCENE-###` | 对应资产/场景卡片.md 中的 ID |
| 角色 | `CHAR-###` | 出镜角色，多人逗号分隔；无人写 `—` |
| 形象 | `CHAR-###-L##` | 本镜使用的形象版本，多人逗号分隔；无人写 `—` |
| 景别 | 中文 | 全景/中景/近景/特写/大特写 |
| 时长 | 整数秒 | ≥4（Seedance 最小单位） |
| 模式 | 枚举 | `t2v`（纯文本）/ `i2v_ref`（带参考图）/ `skip`（非AI） |
| 运镜 | 中文 | 固定镜头/缓推/镜头推近/镜头拉远/镜头跟随/快切/主观镜头 |
| 画面 | 2–4句 | 电影级视觉描述：布景、光线、人物姿态、道具、伏笔 |
| 对白/备注 | 格式化 | `**CHAR-###**[情绪]：「台词」` 或 `（无对白，[音效]）` |

### 10.3 对白格式

| 场景 | 格式 |
|------|------|
| 有对白 | `**CHAR-###**[情绪·语气]：「台词」` |
| 内心独白 | `**CHAR-###**[内心]：「...」` |
| 无对白 | `（无对白，[音效]）` |
| 旁白 | `**旁白**[情绪]：「...」` |

### 10.4 SEG 块结构

```
---

## SEG## — [叙事功能]

**【SCENE-###】[地点]** · **[时段]** · **[内/外景]**

| 镜号 | shot_id | ... | 对白/备注 |
|------|---------|-----|-----------|
| ... |

> ⏱ Segment时长：Xs ｜ 镜头数：N
```

- 场景切换时写完整场景头：`**【SCENE-###】地点** · **时段** · **内/外景**`
- 同场景续接写：`**（续）**`
- 每 SEG 以 `---` 分隔，结尾附 `> ⏱` 统计行

### 10.5 画面描写质量标准

「画面」列禁止一句话空洞概括。每格必须 2–4 句，包含：
- 布景具体细节（桌面物品、墙面装饰、地面状态等）
- 光线/色温/明暗——情绪外化
- 人物姿态/微表情/手部动作/视线
- 与剧情相关的道具互动
- 暗示/伏笔元素（可选但推荐）
