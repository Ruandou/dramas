# 《超雄重生1995》人物小传与关系图

---

## 核心角色

### 陆峥（男主）

| 项目 | 内容 |
|------|------|
| 年龄 | 25岁（重生后）/ 45岁（前世） |
| 身份 | 1995年：警校毕业生 → 派出所 → 刑警 → 刑侦支队长 |
| 前世 | 体制内老实警察，干了20年还是普通警员，档案室度过最后十年 |
| 本季弧光 | 弥补前世遗憾，用「信息差+系统+判断力」在这个没有监控、DNA不普及的年代成为传奇刑侦 |
| 核心金句 | 「我不是来破案的，我是来改变规则的」 |
| 人物底色 | 克制、沉稳，有手段有判断，不服输 | 内心锚点 | 林栀的安全是唯一的软肋 |
| 爱情观 | 前世没保护好林栀，这辈子绝不让她再受伤 |
| 职场观 | 不争一时，争一世；不抢功，让领导有功，让同事有参与感 |
| 破案哲学 | 系统给线索，判断靠人；人永远比系统重要 |

---

### 秦飒（第一女主）

| 项目 | 内容 |
|------|------|
| 年龄 | 28岁 |
| 身份 | 刑侦队副队长，后升队长，最后成为陆峥最佳搭档 |
| 性格 | 冷面、专业、不服输、女强人 |
| 家庭背景 | 父亲是老刑侦，因公殉职；她坚持当警察是为了「替我爸看看这世道」 |
| 职场线 | 从「凭什么一个新警员对我指手画脚」到「我最信任的战友」 |
| 情感线 | 对陆峥从不服到欣赏到依赖，最后「我不适合谈恋爱，但我适合和你并肩」 |
| 本季情感落点 | 没有和男主确定关系，但成为「彼此最信任的战友」，留开放结局 |
| 能力 | 刑事侦查、现场勘查、审讯，能独立破案 |
| 标志性场景 | 第17集冷库救人后红眼眶；第29集递交辞呈后被挽留 |

---

### 林栀（第二女主/官配）

| 项目 | 内容 |
|------|------|
| 年龄 | 24岁 |
| 身份 | 急诊科医生 |
| 性格 | 温柔、坚韧、有心理创伤（前世被报复伤害过） |
| 前世 | 男主的妻子，在某起案件中被犯罪分子报复，重伤不治 |
| 本季弧光 | 从「我不知道为什么要信你」到「你回来了，我信你」 |
| 爱情线 | 贯穿全季，从医患关系→患难中的互相支撑→确定关系→结婚 |
| 内心创伤 | 童年时父亲因医疗事故去世，对「当医生保护人」有执念 |
| 职业线 | 成为男主在本季最重要的「后方支援」，医疗专业知识多次辅助破案 |
| 标志性场景 | 第26集被车撞伤；第32集孤岛救人；第35集坦白「谢谢你回来」 |

### 苏曼华（第三女主）

| 项目 | 内容 |
|------|------|
| 年龄 | 27岁 |
| 身份 | 外资药企「诺华制药」驻本地代表 |
| 性格 | 知性、高IQ、高情商、有手段 |
| 家庭背景 | 父亲是退休官员，被保健品案牵连蒙冤 |
| 职场线 | 父亲洗冤后成为男主商界盟友，帮他用商业手段查账、取证 |
| 情感线 | 对陆峥是「利益盟友→真心欣赏」，没有告白，留白 |
| 能力 | 商业调查、账目分析、公关能力 |
| 资源 | 商界情报网，外资企业背景的人脉 |
| 标志性场景 | 第11集第一次出场，拿着一叠保健品公司账目找陆峥 |

### 周芽（第四女主/成长线）

| 项目 | 内容 |
|------|------|
| 年龄 | 22岁 |
| 身份 | 乡镇派出所民警 → 市局刑警 |
| 性格 | 热血、莽撞、善良、乐观 |
| 成长线 | 从「我一腔热血想破案但没经验」到「能独立办案的刑侦力量」 |
| 和男主关系 | 师徒，从「陆哥你怎么什么都知道」到「师父，我不会再让你操心了」 |
| 情感线 | 无明确恋爱对象，以事业成长为情感落点 |
| 能力提升 | 跟着男主学系统侧写+传统刑侦，成长为新一代 |
| 标志性场景 | 第13集拿出八年积案；第23集第一次独立完成取证任务 |

### 周正南（导师/贵人）

| 项目 | 内容 |
|------|------|
| 年龄 | 55岁 |
| 身份 | 省委督导组组长，铁腕老警 |
| 性格 | 铁腕、老辣、原则性强 |
| 背景 | 年轻时搭档谢海林查棉纺厂旧案，谢海林牺牲，他一直放不下 |
| 人物底色 | 「我老了，但这案子我必须看着它结束」 |
| 和男主关系 | 从「这小子有点意思」到「他是能改变这系统的人」 |
| 象征物 | 旧照片（他和谢海林），贯穿始终的情感线索 |
| 标志性场景 | 第25集看到谢海林名字时砸茶杯；第33集留给男主一封信 |
