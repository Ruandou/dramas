**每集流程**（顺序勿跳）：

1. **主剧本**：该集纲要/对白扩写 → `剧本/EP##/EP##_*.md`
2. **分镜 YAML**：`storyboard_to_seedance.py EP##` → `EP##_shots.yaml` + `EP##_shots.json`
3. **段落 YAML**：拆段 → `EP##_segments.yaml`
4. **年代校验**：`validate_era.py` / `--check-only`

**每集年代检查**：

- [ ] 每镜 `SCENE-*` 场景卡片有 `era: 1995` 且无穿帮现代物件
- [ ] 每镜角色形象 L## 符合 1995 年审美（无智能手机、无现代车牌格式等）
- [ ] 导出后 `validate_era.py` 无 error

## 三、已确认决策（不用再问）

| #  | 决策                                                                           |
| -- | ------------------------------------------------------------------------------ |
| 1  | 全季 36 集统一为 S1（无分季）                                                  |
| 2  | 所有剧本放 `剧本/`，一集一文件                                                 |
| 3  | 角色卡、场景卡片必须带 **ID**（`CHAR-###`、`SCENE-###`）                       |

| 7  | 声音路线一：先 `voice_prompt` → 漂移再 `reference_audio` → TTS 最后手段        |
| 8  | 镜级 `shots.yaml` 保留供参考；API 默认读 `segments.yaml`                       |
| 9  | EP01–03 为管线验证优先集，其余按阶段批次推进                                    |
