# 场景卡片（SCENE-*）

> 分镜引用：`` `SCENE-###` `` · 语法见 [`../制片规范.md`](../制片规范.md)  
> **年代 / 布景约束**：1995–1999 年中国内地；禁止现代元素（详见 [`../角色卡.md`](../角色卡.md) § 年代禁忌）

## 字段模板（新建 SCENE 必填）

| 字段 | 说明 |
|------|------|
| **年代** | `era`：`1995_urban`（城区）· `1995_rural`（乡镇）· `1995_gov`（机关）· `1998_flood`（洪灾） |
| **类型** | 内 / 外 / 内外 |
| **English Prompt** | 英文空景，`no people`，含 **1995 China** 等地域词 |
