## 分镜列说明（Seedance 2.0）

| 列                      | 含义                                               | 转 API                     |
| ----------------------- | -------------------------------------------------- | -------------------------- |
| **shot_id**             | `EP##-S{镜号}`，与首帧文件同名                     | 任务 id、输出 mp4 名       |
| **时长**                | 秒；`skip` 镜填 `-`                                | `duration`（建议 4–6）     |
| **模式**                | 见下表                                             | `content[]` 如何拼         |
| **运镜**                | 写入 Seedance 文本提示                             | `content[].text`           |
| **形象**                | 本镜出图用 LOOK                                    | `reference_image` / 合首帧 |
| **对白**                | 写入 **segments** 的 `api.text`（含 voice_prompt） | `generate_audio: true`     |
| **对白/备注**（`skip`） | 写明并入哪条 `SEG`；音效/字卡/画外音               | **禁止**写「剪映」         |

### 段落（默认交付）

- 约 **10–12 秒 / 条** API，段内 **3–5 镜** + 对白/环境音。
- `skip` 镜不单独 API：并入相邻段（音效 / 旁白 / 口播钩子）。
- 机器可读：`EP##_segments.yaml`（见 EP01 样例）。

### 模式 `mode`（镜级 shots，导出用）

| 值        | 何时用                | 素材准备                       |
| --------- | --------------------- | ------------------------------ |
| `skip`    | 黑屏、字卡            | 并入 segment 音效/旁白，非剪映 |
| `t2v`     | 空镜、无定妆          | 仅文本                         |
| `i2v`     | 单张镜头关键帧即可    | `keyframes/EP##-Sxx_first.png` |
| `i2v_ref` | **推荐**：要锁脸+场景 | looks + scenes + 关键帧        |
| `i2v_ff`  | 明确起止画面          | `first` + `last` 两张图        |

### 景别选项

| 值   | 含义                                 |
| ---- | ------------------------------------ |
| 特写 | 脸部/物件局部，情绪冲击             |
| 近景 | 胸部以上，对白为主                   |
| 中景 | 膝盖以上，兼顾肢体语言              |
| 全景 | 全身+部分环境                        |
| 远景 | 环境为主，人物缩小                   |
| 主观 | 角色第一人称视角                     |
| 黑屏 | `skip` 镜专用                        |
| 字幕 | `skip` 镜专用，画面底部白字          |

### 运镜常用词（写入「运镜」列）

固定镜头 · 镜头特写 · 镜头近景 · 镜头推近 · 镜头拉远 · 镜头跟随 · 主观镜头 · 慢动作 · 快切 · 闪回叠化 · 镜头环绕（慎用） · 手持晃动（追逐/紧张场景适用）

### 对白格式

- 正常台词：**CHAR-###**：台词内容
- 带情绪：**CHAR-###**(低语)：台词内容
- 旁白/画外：**VO**：旁白内容
- 系统提示（金手指）：**SYS**：「侧写完成——嫌疑人锁定」

### 1995 年代提示

- 场景道具须符合 [`../制片规范.md`](../制片规范.md) §五（BP机、桑塔纳、筒子楼等）。
- **禁止**出现智能手机、液晶屏、现代车辆等（见 `negative_prompt`）。
- **重生闪回**：场景列可叠写 `SCENE-XXX`→`SCENE-YYY`；导出后 API 用 `prompt_suffix_flashback`。
