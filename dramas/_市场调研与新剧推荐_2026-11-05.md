# 市场调研与新剧推荐（2026-11-05）

**调研时点：** 2026-11-05（Asia/Shanghai）  
**用途：** 潜在爆款选题包草案 → 用户点名首部后收敛为四字段概念简报，交故事架构师 Stage1  
**方法：** 公开平台信号 + 厂牌已推/已立项目录撞车核对；合规快检先行  
**发行侧重：** 红果免费长消费 + 抖音原生测素材（付费小程序辅）

---

## 0. 合规快检（全包通用）

| 级别 | 规则 |
|------|------|
| 🔴A 不可做 | 现代政治/时政、军事军旅、司法公安刑侦/法庭/监狱、国安外交统战民族宗教、宣扬封建迷信 |
| 🟡B 须改写 | 宫廷权谋血腥、神话显灵、敏感历史节点 |
| 🟢C 本包方向 | 都市情感/职场/亲情逆袭/轻喜马甲/邻里民生民事解气 |

本包主线均不入一类特殊题材；商战纠纷走民事逻辑；不教唆违法、不渲染色情暴力。

**本轮回避（对照 dramas 已推/已立项）：** 修仙仙侠、悬疑刑侦、银发励志连占、美食餐饮、体育竞技全系、年代商战三维已满、AI 人机情感簇、黄毛打脸男频公式、08-21/08-26 十六推职业母题（跨境/救援/电台/兽医/洋女婿/观星/谷子/花店/澡堂/乐队等）、以及《双姝医馆》《布衣账房》《外卖小哥是隐藏大佬》《全公司都以为我很有背景》《闪婚后她马甲掉了》等近义位。

## 1. 平台信号摘要（可核对）

- 2025 微短剧+漫剧约千亿；免费约占 2/3；2026 合计预估 >1210 亿，免费增速放缓（界面/DataEye、36氪 DataEye 上半年报）。
- 抖音：现代/虐渣/逆袭播放领先；大男主/马甲/闪婚剧量少但投产比高；《离婚后，爸妈带我走上巅峰》（2026-05）播放约 30.6 亿。
- 红果 MAU 2026-05 约 3.57 亿；女性成长/职场逆袭上升；银发太奶奶流仍强但本厂牌 8 月已标连占→本包不推银发主线。
- 钩子结构：前 3 集＝身份确立→危机→首个小高潮；付费卡一约 8–12 集（生死/身份临界）。
- 监管：《微短剧发展管理办法》2026-09-01 施行；一类题材开拍前备案。

## 2. 候选选题（4）

### 候选 A｜《离婚那天，我爸妈摊牌了》⭐建议首选

> **选项标签：** 男频 · 建议竖屏9:16（可选横屏）

| 字段 | 内容 |
|------|------|
| **标题方向** | 《离婚那天，我爸妈摊牌了》 |
| **题材** | 都市亲情逆袭 · 大男主马甲 |
| **核心钩子** | 离婚宴被前妻家族公开处刑 → 沉默父母第一次站队 → 层层揭开父母隐退后的真实能量（商业/行业权威，**非军警**） |
| **目标受众** | 25–45 男频为主，连带亲情向女用户 |

- **差异化：** 对标抖音「父母撑腰」爆款路径，加「父母也有未完成的人生」双线；避开纯战神与黄毛公式。
- **合规：** 🟢；不碰司法公安主线；少渲染拜金。
- **邻近资产提醒：** 旁近《我妈退休后不装了》《我和爸妈互换人生》——差异钉死在「离婚公开处刑→父母商界撑腰」大男主线。
- **平台信号：** 抖音 2026 大男主/亲情逆袭天花板；马甲投产比高。

### 候选 B｜《她不回头了》

> **选项标签：** 女频 · 竖屏/横屏均可（点名锁定）

| 字段 | 内容 |
|------|------|
| **标题方向** | 《她不回头了》 |
| **题材** | 女性成长 · 职场逆袭 · 婚恋清醒 |
| **核心钩子** | 为丈夫隐姓埋名的「完美妻子」被嫌弃 → 放弃婚姻回归专业领域 → 前东家/行业资源反哺，渣男侧崩盘 |
| **目标受众** | 女频 28–45（付费/长时消费主力） |

- **差异化：** 事业线 > 追妻线；势均力敌情感，拒绝无脑霸总拯救。
- **合规：** 🟢；权色点到为止，不渲染色情猎奇。
- **邻近资产提醒：** 旁近《离婚冷静期她成了甲方》——差异钉在「回归专业能力」而非诉讼/冷静期程序。
- **平台信号：** 红果/河马女频「自我价值」上升。

### 候选 C｜《被辞退那天，甲方是我》

> **选项标签：** 男频 · 建议竖屏9:16

| 字段 | 内容 |
|------|------|
| **标题方向** | 《被辞退那天，甲方是我》 |
| **题材** | 都市职场 · 大男主马甲轻喜 |
| **核心钩子** | 背锅社畜当众被裁 → 当晚资本注入新闻刷屏 → 原公司发现「隐形大股东/甲方爸爸」就是他；一路打脸+轻喜反差 |
| **目标受众** | 22–40 男频 + 职场泛人群；抖音原生测素材友好 |

- **差异化：** 吃「剧量少、投产比高」的马甲轻喜蓝海；**刻意避开**《外卖小哥是隐藏大佬》《全公司都以为我很有背景》的「早有马甲装怂」——本剧是「裁员当场身份反转」，爽点节奏更前置。
- **合规：** 🟢；商战民事化；不写内幕交易教唆细节。
- **平台信号：** 抖音大男主/马甲高投产比；职场打脸仍高热。

### 候选 D｜《这堵墙不能拆》

> **选项标签：** 泛人群共视 · 建议竖屏9:16

| 字段 | 内容 |
|------|------|
| **标题方向** | 《这堵墙不能拆》 |
| **题材** | 都市邻里 · 民事解气 · 轻法理爽 |
| **核心钩子** | 新邻居强拆共墙/侵占楼道公共空间 → 被当成好欺负的租客 → 女主（或夫妻档）用证据链+物业/居委会规则内反杀，顺带揭开装修背后的利益链 |
| **目标受众** | 快手/红果泛人群 25–50；家庭共视 |

- **差异化：** 吃「现实向民生解气」上升赛道；**不是**银发老太流、不是六号楼维修班群像，主线是「一堵墙」的证据战与身份小反转。
- **合规：** 🟢→注意边界：只写民事维权/物业条例，**不写公安破案、私刑、真实案件猎奇**；普法向表述留白，避免一类司法主线。
- **平台信号：** 现实邻里/宅基地类爽剧上升；快手「真、暖、气、狠」。
