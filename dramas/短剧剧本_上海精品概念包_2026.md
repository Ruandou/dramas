# 1.《武康路密码》

## 项目信息

- **类型**：都市 / 悬疑 / 爱情 / 文化保护
- **集数**：36 集 × 2–3 分钟
- **叙事节奏**：解密 → 闪回 → 现实危机 → 情感推进 → 集末悬念
- **平台定位**：女频+全龄破圈（「建筑悬疑」新品类，对标《繁花》文化流量但成本降三个量级）

## 一句话简介

文保修复师顾念在武康大楼的百年雕花里发现了**一串被建筑藏了一百年的情书密码**——每解开一栋楼，就多一段1920年代的禁忌之恋，也多一个想拆掉这条街的人。**建筑会说话，只是没人听懂。**

## 为什么现在能火

- **武康路**是2024–2026抖音/小红书**打卡量TOP3**上海地标，自带亿级流量池；短剧将「网红街道」转化为**叙事空间**，天然适合投流切片（"武康大楼里藏着百年情书？"）。
- 「文保+悬疑」赛道空白——悬疑类完播率高，加上**建筑科普+爱情双线**，女频看爱情、男频看解谜、全龄看上海。
- AI友好：现代线以**室内对话+建筑特写**为主；1920s闪回仅需**3–4个固定复古室内场景**，复用率极高。

## 与库内差异

- 非《全城找耳机》式轻喜追踪；本剧有**历史纵深**与建筑专业壁垒。
- 非《我租的女友真把我当老公了》纯甜宠；本剧悬疑线拉动完播，爱情是解谜副产品。
- 非《错嫁后我改写了王朝》古装宫斗；虽有双时间线，但舞台是**真实上海街区**，政策加分远超架空设定。

## 政策契合分析

| 维度 | 契合点 |
|------|--------|
| **文** | 每集聚焦一栋**真实历史保护建筑**（武康大楼、巴金故居、密丹公寓等），剧情即科普，强化"上海百年建筑文化"认知 |
| **旅** | 武康路-复兴路-衡山路构成完整**City Walk路线**，播出后可联动线下打卡活动 |
| **商** | 建筑修复产业、文创衍生品（密码地图、建筑盲盒）、咖啡店联名 |
| **城市形象** | "上海是一座懂得保护记忆的城市"——正面价值观输出，呼应政府文保政策 |

**50%加成理由**：剧集本身即**武康路旅游宣传片**，且传递"文化保护 > 商业开发"正向价值，与上海"建筑可阅读"城市品牌高度一致。

| **顾念** | 28，文保修复师，强迫症级细节控 | 女主，从"只修建筑"到"修复记忆与人心" |
| **陆行舟** | 30，调查记者（建筑类自媒体） | 男主，帮助顾念追查密码，从猎奇转向真正关心 |

## 版权风险

🟢 极低。全部建筑为公共文化遗产，1920s人物为虚构，无涉政治/军事/司法。

## AI制作友好度

- **场景估算**：现代线 6–7 个（修复工作室、咖啡馆、建筑内部走廊、办公室、老吴家客厅、文保所办公室、方远洋办公室）；1920s线 3–4 个（法式客厅、书房、花园门口、码头送别）
- **室内外比**：85% 室内 / 15% 室外（街道特写、阳台）
- **角色一致性**：现代5人高频出镜，1920s仅2人（服装固定），可控
- **特殊需求**：建筑特写（静态图+微动效即可）、密码解读动画（字幕叠加）
- **结论**：★★★★☆（1920s线需古装一致性管理，但场景极少，整体可控）

# 2.《弄堂里的米其林》

## 项目信息

- **类型**：美食 / 家庭 / 爱情 / 创业成长
- **集数**：36 集 × 2–3 分钟
- **叙事节奏**：一菜一故事 → 比赛/危机 → 情感爆点 → 集末钩子
- **平台定位**：女频核心（美食+家庭情感+创业逆袭三合一），男频可吃美食竞技

## 一句话简介

法国蓝带毕业的沈悦回到上海弄堂，只为救活外婆濒临倒闭的"阿婆灶头"——**一碗腌笃鲜要熬三个小时，但这条弄堂可能撑不过三个月。** 她的分子料理征服了评委，却说服不了外婆：**"正宗上海味道，不需要你那些泡泡。"**

## 为什么现在能火

- **美食短剧**2025–2026年完播率数据优异（视觉刺激+情感共鸣双驱动），但库内仅有古装《食神》，缺**现代上海本帮菜**赛道。
- 弄堂/里弄是上海**年度最热文旅IP**（2025"弄堂经济"政策出台），剧集天然绑定城市热度。
- 每集一道菜 = 天然切片素材（"外婆的秘制红烧肉vs米其林摆盘"对比图，投流转化率高）。
- 比赛+创业双线 = **钩子密度极高**（每集有输赢）。

## 与库内差异

- 非《食神》古装穿越；本剧全程**当代上海**，零架空元素。
- 非《教练别加练了》运动职场喜剧；本剧有**家族情感深度**与代际冲突。
- 非《我租的女友真把我当老公了》纯爱轻喜；本剧爱情线服务于「传承 vs 创新」核心矛盾。

## 政策契合分析

| 维度 | 契合点 |
|------|--------|
| **文** | 上海本帮菜非遗文化、弄堂里弄生活方式、口述家族史（每道菜背后是一户邻居的人生） |
| **商** | 餐饮创业、美食竞赛商业化、品牌联名（可与上海本帮餐厅/老字号做播后联动） |
| **旅** | 弄堂文旅、菜市场体验游、上海"味道地图"线下打卡 |
| **城市形象** | "上海不只有外滩和陆家嘴，弄堂深处有最温暖的烟火气"——呈现上海平民生活之美 |

**50%加成理由**：精准命中"文商旅联动"三维——弄堂文化(文)+餐饮创业(商)+美食旅游(旅)，且输出"上海味道=城市灵魂"的正面叙事，播后可直接转化为美食文旅消费。

## 主要人物

| 人物 | 身份 | 功能/弧光 |
|------|------|-----------|
| **沈悦** | 27，法国蓝带归国，分子料理专长 | 女主，从"用技术征服世界"到"用温度打动人心" |
| **阿婆（沈惠芳）** | 78，"阿婆灶头"创始人，弄堂地标 | 传统派，从"我的规矩不能变"到接受"味道可以有新表达" |
| **许知远** | 29，美食比赛评委助理/食品集团暗线 | 男主，双面身份：真心爱沈悦 vs 公司要他买断阿婆配方 |
| **赵叔** | 55，隔壁五金店老板，阿婆老邻居 | 喜剧担当+弄堂群像代表，他的红烧肉故事是第5集 |

**「一菜一邻」结构**：阿婆灶头的每道招牌菜，都是为弄堂里某一户邻居"定制"的——腌笃鲜是给楼上孤寡张爷爷的（他老伴的口味），葱油拌面是给对面裁缝阿姨的（她赶工没时间等）。沈悦要参加比赛，就必须先听懂每道菜背后那个人的故事。**菜谱即人谱。**

🟢 极低。原创故事，无涉真实餐厅品牌（可后期做正面联名）。

- **特殊需求**：食物特写（可用AI生图+微动效）、烹饪动作（中景即可，不需精细手部）
- **结论**：★★★★★（全剧最AI友好——封闭室内、现代服装、对话驱动、无特效）

# 3.《零号展厅》

## 项目信息

- **类型**：艺术 / 轻悬疑 / 爱情
- **集数**：36 集 × 2–3 分钟
- **叙事节奏**：画作线索 → 追踪解密 → 艺术圈暗战 → 感情升温 → 集末反转
- **平台定位**：女频+文艺破圈（「艺术悬疑」新品类，对标《只此青绿》文化热但做悬疑叙事）

## 一句话简介

西岸美术馆的实习生姜念在库房发现了**7幅从未展出的画**，每幅画背面刻着一组GPS坐标——**那些坐标指向的地方，20年前都"消失"过人。** 画家"零先生"画的不是风景，是**上海被遗忘的角落和被遗忘的人。**

## 为什么现在能火

- **西岸艺术区**是上海近3年最成功的文旅新地标（龙美术馆、余德耀、星美术馆），但**零短剧**以此为叙事空间——赛道完全空白。
- 「7幅画 = 7个谜」天然适合短剧**单元+连续剧**结构，每1–2集解一幅画，投流切片标题自带悬念（"这幅画背后藏着一个消失了20年的家庭"）。
- 艺术+悬疑赛道在欧美已验证（《达芬奇密码》类），中国短剧尚未出现同类，差异化极强。
- 视觉场景：画廊白墙 = **AI最稳定的室内环境**（纯色背景+人物对话）。

## 与库内差异

# 4.《申城夜跑》

## 项目信息

- **类型**：运动 / 爱情 / 都市 / 心理疗愈
- **集数**：36 集 × 2–3 分钟
- **叙事节奏**：跑步训练 → 相遇/对话 → 回忆/伤疤 → 突破/钩子
- **平台定位**：男女频破圈（运动+治愈+爱情三合一，对标《以家人之名》治愈感+《长风渡》成长线）

## 一句话简介

外卖骑手林默每晚跑15公里——他在为上海马拉松训练，也在**跑离三年前被逐出田径队的噩梦**。金融白领徐晴每晚跑5公里——她在跑离**凌晨三点还在发邮件的焦虑症**。同一条滨江跑道，一个在追速度，一个在追睡眠。**42.195公里之后，他们能不能跑到彼此身边？**

## 为什么现在能火

- **跑步/马拉松**2025年全平台热度暴涨（上马报名人数破历史纪录），但短剧赛道**零竞品**——蓝海中的蓝海。
- 心理健康/职场焦虑是2026年**女频情绪痛点TOP1**，"用运动自救"比"用系统开挂"更有正面价值观输出。
- 每集一个上海夜景地标 = 天然切片素材（"外卖骑手在陆家嘴夜跑是什么体验"自带流量）。
- 体育题材政策加分明确（"体"维度），且与《教练别加练了》形成赛道互补而非竞争。

## 与库内差异

- 非《教练别加练了》健身房喜剧；本剧是**户外跑步+马拉松**，叙事更沉、情感更深。
- 非《我租的女友真把我当老公了》轻喜甜宠；本剧双主角都有**心理创伤**，先治愈后恋爱。
- 非《全公司都以为我很有背景》职场喜剧；虽有职场元素（外卖/金融），但核心是**运动与救赎**。

## 政策契合分析

| 维度 | 契合点 |
|------|--------|

| **旅** | 滨江跑道、苏州河、陆家嘴夜景、世纪公园、外滩——每集=一张上海夜景名片 |
| **文** | 运动精神、心理健康、社会包容（外卖骑手的尊严与梦想） |
| **城市形象** | "上海是一座永不停止奔跑的城市"——活力、包容、不分阶层的城市精神 |

**50%加成理由**：唯一精准覆盖"体"维度的概念（其他概念多集中在文/商/旅/展），且将上海马拉松这一城市体育名片转化为36集叙事，同时呈现滨江夜景=旅游宣传，外卖骑手+金融白领同跑=城市包容精神，政策辨识度极高。
