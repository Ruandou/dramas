# 短剧剧本·审计风暴（36集）

> 日期：2026年5月29日
> 状态：概念版

## 类型

现代都市 / 男频 / 爽文 / 商战悬疑

## 集数

36 集 × 2–3 分钟

## 投流标题库

- 「被开除的审计师摆地摊，第一单客人是开除他的老板」
- 「他说我不配查账，三个月后我查到他头上」
- 「全公司笑我是废物，直到我拿出那本账」
- 「他花三百万封我的口，我当场撕了支票」

## 一句话

四大审计师林越被合伙人栽赃开除，沦为夜市摆摊卖炒粉的失业中年——但他的脑子里装着**五年来经手过的每一笔账**。当一个深夜来吃粉的小老板递给他一本烂账求助，林越发现：**这本烂账的幕后，就是当年栽赃他的那个人。**

## 为什么能火

- **「审计师」是短剧全新职业**——不像律师/医生被用烂，观众新鲜感强
- 金手指克制且可信：**过目不忘的账目记忆**（不是系统、不是重生，是职业病）
- 每一案 = 一家公司 = 一次打脸，天然单元+连续剧结构
- 场景极度 AI 友好：**办公室、会议室、夜市摊、咖啡馆**——全是室内对话戏
- 男频但不搞后宫，单 CP（前同事+暗恋），节奏靠**数字碾压**而非拳头

## 核心设定

**「账本记忆」**：林越有超强数字记忆力，经手过的每一笔账都能精确到小数点后两位。这不是超能力——现实中确实有极少数审计师具备这种能力。他靠这个在四大做到最年轻的高级审计师，也因为这个能力被合伙人忌惮（他知道得太多了）。

**三层反派结构**：

- **表层**：每案的被审计公司老板（单元打脸对象）
- **中层**：当年栽赃他的四大合伙人 **赵恒**（贯穿全剧）
- **深层**：赵恒背后的资本集团 **鼎盛控股**（最终 BOSS）

## 季线（13–36集）

- **13–18**：第三案（地产公司烂尾楼，购房者维权）→ 林越帮业主查出资金被挪用 → 鼎盛控股再次出现在幕后
- **19–24**：赵恒开始反扑 → 林越被举报「非法经营审计业务」→ 夜市摊被砸 → 林越用直播做「公开审计课」翻盘，全网爆火
- **25–30**：鼎盛控股内部有人反水，找到林越 → 林越拿到鼎盛的「总账」→ 但总账太大，需要一个有执照的审计师签字才能生效
- **31–34**：苏薇拿到执照 → 两人联手出具审计报告 → 赵恒被四大内部调查 → 陆总试图用钱和权力压下来
- **35–36**：林越在媒体面前公开审计报告核心数据 → 赵恒被逮捕，鼎盛控股暴雷 → 林越拒绝回四大，继续在夜市摆摊——但摊位上多了一块牌子：「林越财务咨询，炒粉免费」→ 苏薇坐在摊前：「老板，来碗粉。」

## 金手指规则（克制型）

| 能力                     | 限制                                   |
| ------------------------ | -------------------------------------- |
| 记忆五年内经手的所有账目 | 只限他自己看过原件的账，没看过的不算   |
| 心算极快                 | 对手可以做假账干扰，他需要时间验证     |
| 识别账目异常             | 不能读心，只能通过数字推断，需要证据链 |

## AI 制作友好度

- **场景估算**：夜市摊（1）、办公室/会议室（2–3个变体）、咖啡馆（1）、林越出租屋（1）、苏薇办公位（1）——共6场景
- **室内外比**：90% 室内 / 10% 室外（夜市局部）
- **角色一致性**：全现代装，6–7人，商务+休闲两套造型
- **特殊需求**：账本报表特写（静态图即可）、数字特效（字幕叠加）
- **结论**：★★★★★（纯室内对话+现代装+无特效，AI最友好）
