## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 道具     | `PROP-###`                        | `PROP-001`        | 账本、合同、炒锅等               |

- 编号**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先 `资产/角色索引.md`，再建 **`L01` 基础形象**于 `资产/形象索引.md` + `角色卡.md`。
- 新建换装/阶段：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。

### 1.1 形象 ID 与基础 / 衍生

| 后缀     | 名称     | 要求                                                                                |
| -------- | -------- | ----------------------------------------------------------------------------------- |
| **L01**  | 基础形象 | 完整定妆 Prompt（脸、体型、发式、默认服装）；全剧面部一致性的**唯一锚点**           |
| **L02+** | 衍生形象 | **必须** `based_on` 本角色 `L01`；Prompt 只写差异，并含 `same face as CHAR-xxx-L01` |

**出图流程**：定稿 `L01` 参考图 → 衍生形象用图生图 / 角色一致性模型 → 禁止跳过 L01 直接生成 L02。

**本剧常见衍生场景**：

| 角色 | L01（基础）                 | L02+（衍生示例）                                |
| ---- | --------------------------- | ----------------------------------------------- |
| 林越 | 夜市围裙+T恤（炒粉摊主）    | L02 旧西装（回忆/对质）、L03 直播正装（翻盘期） |

## 三、工作流顺序（必读 · 防不同步）

### 3.1 修改顺序

改台词、场次、字幕/旁白策略时**严格按层向下**，**禁止**先改 `segments.yaml` 或 `shots.yaml` 再回头补剧本。

| 顺序  | 层           | 文件                          | 写什么                                                                          |
| :---: | ------------ | ----------------------------- | ------------------------------------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_审计风暴_36集.md`   | 集纲、每场剧情、对白要点、钩子                                                  |
| **2** | **分集剧本** | `剧本/EP##/EP##_*.md`         | 可拍分镜表：`shot_id`、画面、**对白/备注**、CHAR/SCENE/形象、时长/模式/运镜     |
| **3** | **机器可读** | 同目录 `EP##_shots.yaml`      | 从分集 md 导出，勿手改 yaml 当源                                                |
| **4** | **段落 API** | 同目录 `EP##_segments.yaml`   | 按 md 镜号合并为 segment；`api.text` 对白/字幕/旁白与 **第 2 步引号内字面一致** |
| **5** | **其它**     | 声音卡、现代视觉规范、assets/ | 仅在前几步定稿后随需更新                                                        |

**Agent / 人工自检**（改完第 2 步后）：

- [ ] 主剧本该集对白要点已与分集表一致（或注明「分集为准」并只改分集）
- [ ] 未单独改 `segments` 而 md 未动

**单集真相源**：拍什么、说什么 → **`剧本/EP##/EP##_*.md`**；主剧本为纲，segments 为 API 展开，**不是**编剧起点。

## 七、视觉风格备忘

- **色调**：夜市线暖黄（烟火气），办公室线冷灰（精英感），对质场景高对比（戏剧张力）
- **镜头语言**：以中景对话为主，账本特写用推镜头，打脸场景用反打+表情特写
- **字幕风格**：账目数字用等宽字体放大+红色高亮，审计术语首次出现加注释
- **避免**：不要武打动作，不要系统面板UI，不要夸张特效——一切靠**对话和表情**推节奏
