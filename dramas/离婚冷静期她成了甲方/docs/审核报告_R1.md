## Top 3 问题（不阻断，建议 Stage 2/4 消化）

### 问题 1：主创人数顶格 + 高难动作戏
- **位置**：角色清单 8 人；EP49 追尾、EP51 火灾夺盘、EP24/32/57 大场面
- **问题描述**：Seedance 参考图配额与人脸一致性在 8 人时压力大；火灾/追尾易出 AI 废片。
- **影响维度**：制作可行性（已按 3 分计入）
- **建议**：Stage 2 将小陈定位为低频配角/可合并群演；火灾用烟+剪辑暗示；追尾用车内特写+音效，禁止复杂外景追车长镜头。

### 问题 2：P1 灰区——人身威胁与家暴边缘动作
- **位置**：EP09「掐手腕」；EP23「做掉 L」；EP48「消失」谋杀预谋；EP51 纵火
- **问题描述**：大纲已标注「非暴恐渲染 / 报案结果呈现」，但写作若展开手法细节，易滑向暴力过度或刑侦主线观感。
- **影响维度**：合规性（扣至 4，未触 P0）
- **建议**：scene-writer 阶段：掐腕改为拦路/摔门；「做掉」改为「让她社会性消失/边缘化」；谋杀线只保留会议录像威胁台词，不拍实施过程；纵火只拍烟感与硬盘抢救，不拍点火细节。

### 问题 3：EP02「云」预知短信易造成设定歧义
- **位置**：EP02 外包甲方「云」：「三年后你会需要我。」
- **问题描述**：观众可能误读为第二重生者/系统/超自然，与「重生仅女主信息差」的 C 级口径冲突，也会稀释后续沈知衡入场的惊喜。
- **影响维度**：观众留存 / 合规表述清晰度（未单独扣分）
- **建议**：Stage 4 展开时将「云」落实为云栖自动客服/沈侧助理误发/或晚棠前世客户库里的备注彩蛋，避免第二先知。
