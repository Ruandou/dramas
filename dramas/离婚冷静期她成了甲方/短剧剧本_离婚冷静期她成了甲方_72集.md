# 短剧剧本_《离婚冷静期她成了甲方》_72集

## 故事概述
- **Logline**：离婚冷静期最后一夜被逼净身的全职太太林晚棠，重生回三年前结婚次日——她撕掉辞职信，潜入资本成为前夫公司的神秘甲方，一笔一笔清算「债」。
- **类型/题材**：都市 / 重生 / 逆袭 / 打脸虐渣（轻甜男二收束）
- **目标受众**：女频 25–40；婚姻与自我价值共鸣；爱看职场打脸与身份反差
- **核心情绪承诺**：被贬低的「全职」夺回定价权；每笔屈辱有加倍偿还；最终成为自己人生的甲方
- **集数/时长格式**：72集×约90秒（EP01为120秒）
- **付费卡点规划**：EP15 / 21 / 27 / 33 / 39 / 45 / 51 / 57 / 63（间隔≥6集，共9个）
