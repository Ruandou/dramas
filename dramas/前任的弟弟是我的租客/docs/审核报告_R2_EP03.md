### 建议 1：集末验证注释存在 10 秒时长误标
- **位置**：EP03 剧本第 256 行 `total_duration: 151s`
- **问题描述**：验证注释标注总时长为 151s，但逐镜实测总和为 141s（SEG01-13：10+10+11+11+11+11+10+12+10+11+12+12+10 = 141s）。141s 仍落在 140-200s 合规区间内，不影响通过判定。但若 segment-builder 依赖此注释做自动化时长校验，可能触发误判。
- **影响维度**：D. 制作可行性（不扣分——141s ≥ 140s 最低线）
- **建议修改**：修正 `total_duration: 151s` → `total_duration: 141s`。本集 141s 比声明的 2.5 分钟（150s）短 9s，difference 为 -6%，在容差范围内，但为确保 YAML 自动化流水线精确性，建议修正。

### 建议 2：SEG11-12 单段 3 镜处于上限，可考虑拆分
- **位置**：SEG11（镜号 21-23，12s/3镜）、SEG12（镜号 24-26，12s/3镜）
- **问题描述**：两段均为 3 镜/12s — 同时达到分段规则中"单段镜头数 ≤3"和"单段时长 ≤12s"的双重上限。SEG11 三镜（辰逸独坐→素描本跨页→辰逸面部）和 SEG12 三镜（素描本吃饭页→素描本加班页→辰逸手指特写）在叙事上是紧凑的"快速展示单元"，结构合理。但 3 镜上限意味着 zero headroom — 若后期需在此段插入额外过渡镜，将被迫重构 segment 边界。
- **影响维度**：不扣分（当前结构完全合规，为预防性建议）
- **建议修改**：如 drama-director 希望保留弹性，可将 SEG11 拆为 SEG11a（镜21-22, 8s）+ SEG11b（镜23, 4s）——但 SEG11b 的 4s 单镜会低于理想时长（8-10s），需评估是否值得。当前结构保持即可，此建议仅供 future-proofing 参考。

### 建议 3：素描本内页 t2v 镜头需特别关注生成质量
- **位置**：SEG11-13，镜号 S22/S24/S25/S27（共 4 个 t2v 素描本特写）
- **问题描述**：这 4 个 t2v 镜头需要生成"铅笔素描肖像画"——描绘同一个女性（小薇）在不同场景中的铅笔素描。t2v 模式生成"画中画"（sketch within a sketchbook）对 Seedance 来说是中等难度：画中人物的一致性、铅笔笔触的质感、构图的可辨识度都有失败风险。但剧本对每页的描述极其详细（场景、角度、表情、线条特征、甚至日期位置），这为 prompt 提供了优质素材。
- **影响维度**：不扣分（剧本描述质量足以支撑高质量 t2v 生成）
- **建议修改**：segment-builder 在生成这 4 个 t2v 镜头时，建议①将剧本中的画面描述逐句转化为 prompt ②接受"素描风格"的合理偏差（不必追求超写实肖像）③准备 2-3 个备选生成结果择优使用。剧本描述已足够具体，无需修改剧本本身。
