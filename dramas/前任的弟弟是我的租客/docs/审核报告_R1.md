## Top 3 问题（按严重程度排序）

### 问题 1：第三幕情绪曲线严重平坦化（EP25-36，共12集）

- **位置**：第25-36集（全剧三分之一篇幅）
- **问题描述**：第24集年会告白是全剧最强烈的情绪峰值（复仇快感 + 欲望满足 + 揭秘震撼三重叠加），此后12集全部为"欲望满足"型。EP25网络热度→EP26辰轩道歉→EP27陆母认可→EP28小薇暂拒玉镯→EP29兄弟和解→EP30去北京→EP31签售会→EP32家庭和解→EP33求婚→EP34两家见面→EP35买公寓→EP36婚礼。没有任何新的冲突、危机或逆转。观众在第25集就会产生"他们已经赢了，后面就是看热闹"的心理，这是典型的安全滑走点。
- **影响维度**：情绪收益（-2分）、观众留存（-1分）。违反"连续平坦段不得超过2集"规则，12集中无任何一次情绪类型切换。
- **建议修改**：
  1. **结构性重组**：将第24集"不可能时刻"后移至第30-32集附近，让EP25-30插入新的阻碍——例如陆家董事会以"家族名誉"为由施压辰逸放弃小薇（可联动第18集辰逸持有的股份），或白若溪家族对陆氏发起商业收购，迫使辰轩回头求小薇帮忙。
  2. **或保留EP24位置，但为EP25-30注入实际冲突**：例如年会视频爆红后出现反噬——有人挖出辰逸是辰轩亲弟弟的事实，网络反转成"小薇勾引两兄弟"，她需要再次证明自己（情绪类型从"欲望满足"切换到"不公感"→打脸→"复仇快感"）。当前EP25只是"拒绝商业化"一笔带过，冲突太轻。
  3. **最低限度方案**：将EP30-36的北京线压缩为3集（EP34-36），腾出EP25-30的篇幅注入一个"二级危机弧"。

### 问题 2：核心"禁忌关系"张力过早消散（EP15即确认关系）

- **位置**：第15集（两人正式在一起）相对36集总篇幅
- **问题描述**：本剧最强卖点是"前任的弟弟是租客"这个禁忌设定。观众被吸引的核心动力是"她什么时候发现？发现后会怎样？两人如何跨越伦理障碍？"但EP5小薇确认身份、EP7她选择让他留下、EP8辰逸坦白五年暗恋、EP15两人正式确认关系。此后"禁忌"仅剩陆母和辰轩的外部阻力，而这两条阻力线在EP24/EP27也彻底解决了。观众在第15集之后，付费动力从"他们会不会在一起"（高悬念）降级为"他们如何在一起"（低悬念）。当前大纲的应对方式——"延长日常甜感"（第9-12集）——可行但不足以支撑21集的后续篇幅。
- **影响维度**：观众留存（-1分）、商业性（-1分）。核心付费驱动力在第15集就完成了"是/否"的回答。
- **建议修改**：
  1. **将正式确认关系推迟至第20-22集附近**：EP8坦白后，小薇不立刻表态，而是进入"我知道你的心意，但我还没准备好跨越你和辰轩的关系"的矛盾期。延长"窗户纸"阶段，利用辰逸的吃醋（EP11已有）、赵铭的追求、苏妍的推波助澜制造张力。
  2. **或采用"在一起但隐藏"模式**：EP15两人确认关系但对外保密（包括对苏妍），制造"偷偷恋爱"的甜蜜紧张感，直到EP21宴会才被迫公开。这保留了禁忌感又增加了"被发现"的悬念。
  3. **最轻改动**：将EP15的关系确认改为"尝试交往但不贴标签"的暧昧升级，关系正式确认放在EP21宴会后。

### 问题 3："租客"核心设定在EP15后功能性消失，EP35才仓促回收

- **位置**：EP15（关系确认后租客身份淡出）→ EP35（买下公寓重新点题）
- **问题描述**：剧名是《前任的弟弟是我的租客》，"租客"身份是整个设定的引擎——同住一个屋檐下的张力、空间带来的暧昧、租房合同作为关系的隐喻。但EP15两人确认关系后，"租客"身份被"男朋友"身份完全覆盖。EP16-34的20集中，"租房"几乎不再被提及，两人就是普通情侣相处。直到EP35才用"房产证→从租客到共有人"回收这个设定。中间20集的空窗期让剧名中的核心关键词失去了叙事功能。
- **影响维度**：商业性（-1分）。剧名的记忆点和传播点依赖"租客"这个设定，但它在2/3的剧情中隐身了。
- **建议修改**：
  1. **让"租客身份"成为持续的矛盾源**：例如EP16-20中，辰逸是否还应该付房租？两人因为金钱边界产生摩擦（小薇坚持收、辰逸觉得见外），这既保持了"租客"设定的在场，又是现实情侣会遇到的真实问题。
  2. **让租房合同成为情感隐喻贯穿中段**：比如EP15后辰逸搬出再搬回（已在现有大纲中），但搬回时两人重新签了一份"情侣室友协议"——不是租客合同而是某种幽默的"关系条款"（如"乙方不得在甲方加班时擅自送夜宵""甲方不得偷偷给乙方洗衣服"），保持租客框架。
  3. **在EP25-30中，北京线引入"真正的租客"作为对比**：两人搬到北京后因为经济原因暂时合租（这次是真的室友）→遇到一个真正意义上的新租客（可能是小薇的同事或辰逸的编辑），通过对比强化"他们早已不是普通租客"。

- **题材分级**：🟢 C级（都市甜宠 + 禁忌恋爱 + 轻喜剧）
- **资质对应**："其他微短剧"（总投资 < 100万元，一般题材）— 完全匹配
- **风险点扫描**：

|--------|------|------|

| 民族/宗教/统战/外交 | ✅ 无 | 不涉及 |

- **第18集特别审查**：辰逸"登录陆氏集团内部系统下载文件"——大纲明确标注"爸去世前，把他那份股份转给了我。我一直有登录权限。"这属于合法权限行使，非黑客行为。威胁向董事会举报挪用资金属于内部吹哨人逻辑，不构成敲诈勒索。但如果平台审核从严，可在剧本阶段将其弱化为"辰逸在董事会会议上当众质询辰轩"，去掉"下载文件私藏"的环节。

- **第24集特别审查**：辰轩醉酒闯入年会当众闹事——醉酒行为被明确呈现为负面（他失败、被拒绝、被反杀），符合"不良行为需被批判"的原则。

- **结论**：🟢 全剧合规，可直接推进。第18集和第24集的两个边缘点建议在分集剧本阶段做细微调整（见上方建议）。

### 制作可行性细节

- **角色数量**：7人（林小薇、陆辰逸、陆辰轩、苏妍、赵铭、陆母、白若溪）— 在AI一致性生成的合理范围（≤8人）。小薇父母EP33出场但戏份极少，可作为"临时角色"处理，不纳入核心角色池。

- **场景清单与复杂度评估**：

| 场景 | 占比 | AI复杂度 | 注意点 |
|------|------|----------|--------|
| 小薇公寓（客厅+厨房） | ~60% | 低 | 主场景，可建立稳定视觉模板 |
| 小薇公司办公室 | ~10% | 低 | 单一重复场景 |
| 咖啡厅 | ~5% | 低 | 小品场景 |
| 陆家老宅 | ~5% | 中 | 需建立差异化视觉（中式奢华），EP21宴会多人群戏 |
| 餐厅/酒吧 | ~5% | 低 | 小场景 |
| 室外（街道/天台/小区） | ~10% | 中 | 需注意天气一致性（雨天、雪夜） |
| 年会场地 | ~3% | 中高 | 人群聚集+舞台+手机录像的多元素场景 |
| 北京新公寓 | ~2% | 低 | 类似主场景 |

- **AI高难度场景**：
  1. **EP24年会"数百张素描蒙太奇"**：手机屏幕逐张展示五年画稿。建议分镜方案——不追求"数百张同时展示"，而是用5-7个特写镜头展示关键日期的画稿+手机屏幕快速滚动的时间流逝效果。
  2. **EP12雨中共伞"嘴唇只差3厘米"**：两人面部特写的极近距离互动，AI容易出现面部变形或眼神不对焦。建议用侧影/背影+雨幕遮挡来降低精度要求。
  3. **EP33北京雪夜求婚**：雪景+夜景+两人特写，多元素叠加。建议将夜景雪戏控制在2-3个镜头内，其余用室内暖光对比。
  4. **陆家宴会多人镜头（EP21-22）**：人群场景AI容易产生"融化脸"。建议宴会全景用1-2个远景（人物模糊可接受），其余用中近景聚焦主角。

- **道具管理**：大纲附有9个关键道具的详细清单和出场追踪表。PROP-ID标注将在Stage 2由production-planner完成。当前道具逻辑清晰，无前后矛盾。

- **特殊制作节点**：
  - 辰逸的素描本需在EP3、EP8、EP24、EP35反复出现——需在Stage 3b建立统一视觉模板
  - 手链（小星星）从EP15戴到EP36——需注意角色形象的持续一致性
  - 退婚戒指EP1出现→EP16归还——有出场和消失逻辑，可行

## 钩子矩阵评估

大纲附带的钩子矩阵覆盖4种钩子类型（微观钩子、集末悬念、弧线谜团、类型承诺），每集至少2种。以下是结构优势与隐患：

**优势**：
- EP1-6的"信息差"设计（观众知道辰逸身份但小薇不知道）是经典的悬疑驱动，7集持续不泄气——极其出色
- 弧线谜团从"他是谁"→"他为什么"→"她何时发现"→"发现后怎么办"层层推进，逻辑严密
- 集末悬念极少使用"自然结束"——每集都在信息中断、危机悬置或选择困境处切断

**隐患**：
- EP25起，钩子类型从"集末悬念+弧线谜团"退化为"情感收束+类型承诺"，驱动力从"必须看下一集"降级为"想看下一集"
- 微观钩子EP28的"辰逸放回戒指盒"——铺垫2集后在EP33兑现，间隔5集，观众可能遗忘
