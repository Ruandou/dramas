## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 镜头     | `EP##-S##`                        | `EP01-S03`         | 集数-镜号                        |

### ID 分配规则
- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer（Stage 3b）建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨 segment 出现 → 独立 CHAR-###；纯背景无台词 → CHAR-GRP
- **ID 只增不删**：弃用标 `deprecated: true`

### 形象层级结构

| 后缀     | 名称     | 说明                                           |
| -------- | -------- | ---------------------------------------------- |
| **L01**  | 基础形象 | 全剧面部一致性的**唯一锚点**                   |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01    |

| 顺序  | 层           | 文件                                | 写什么                                              |

## 六、分段规则

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 6–10 段         | 对应单集 90 秒（EP01 为 120 秒）                        |
| 每集镜头数       | 8–12 镜         | 对应每集 6–10 段 × 1–3 镜/段                            |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 九、年代/题材约束

### 时代背景
- **朝代**：架空"大晟"（参照明中期，无具体历史对应）
- **官制**：户部-主事-侍郎-尚书-宰辅，符合明中期六部架构
- **服饰**：参照明制襦裙/圆领袍/乌纱帽，禁止出现清末/民国/现代元素

### 必须体现元素（结构性约束）
- 算盘（贯穿全剧核心道具）
- 烛光/火把照明（无电灯）
- 桑皮纸/麻纸账本
- 户部红印泥
- 算学术语（复算/分账/心账/反算账/钓鱼账/五重账）

### 禁止出现元素（结构性 negative_prompt）
- 现代物品（手机/汽车/电器/塑料制品）
- 西方元素（西式礼服/西式建筑）
- 奇幻/仙侠元素（无任何超自然力量）
- 错朝代服饰（清/民国/未来）
- 血腥暴力特写

## 内容合规参数

> drama-director 题材合规快检结果：🟢 C 级（古装职场智谋）。

### 1. 题材合规等级
**🟢 C 级** — 古装职场智谋，对标《显微镜下的大明》《庆余年》，走"其他微短剧"普通备案。

### 2. 本剧特定红线（本剧需特别避免的内容）
- **行政审计 ≠ 刑侦**：核对烂账、追查户部亏空属古代行政/审计范畴，不涉及刑侦破案/警察/法庭主线
- **账本博弈 ≠ 酷刑**：所有冲突以"算学+对白"为载体，不出现任何酷刑/刑讯
- **权谋 ≠ 影射**：所有"权谋"针对的是**架空"大晟"朝代**，绝不影射/隐喻现实政治
- **职场 ≠ PUA**：沈算的"师父"户部尚书虽是反派，但其"师恩绑架"明确为反派行为，不美化为"严师出高徒"
- **古代官制 ≠ 现代官制**：避免使用"主席/书记/部长"等现代官职称谓，统一用古代"宰辅/尚书/侍郎/主事"

### 3. 灰区处理策略
- **P1 灰区 #1（反派手段）**：裴桓"师恩绑架+灭口"等手段**明确为反派行为**，主角以法治框架（大朝会复核）反制，不美化为"以暴制暴"
- **P1 灰区 #2（女主人格）**：柳杏**独立人格**（户部右侍郎之女/女账房/CP 平等），不依附男主，不作为"奖品"
- **P2 灰区 #1（权谋氛围）**：账本博弈通过"算盘+数字"具象化，**避免**渲染黑暗压抑氛围，维持"职业感+智慧感"
- **P2 灰区 #2（算学术语）**：所有算学术语（复算/分账/心账）需用对白解释，**避免**成为读者/观众的认知壁垒

### 4. 正向价值锚点
- **自强不息**：寒门账房沈算以算学天赋+坚韧意志逆袭
- **法治精神**：所有冲突通过"大朝会复核账目"等制度框架解决
- **健康关系**：沈算与柳杏"账做完了，我等你"——平等尊重的纯爱关系
- **善有善报**：贪官皆落马、沈父正名、寒门得志

### 5. 平台审核重点提示（前 3 集）
- **EP01-EP03**：开篇"账房/算盘"专业词汇可能劝退泛用户，需在前 30 秒用"百万石亏空+死人名字"双重冲击拉留存
- **EP01-EP03**：柳杏登场不要"擦边"，保持"女账房"专业形象
- **EP01-EP03**：沈算被陷害入狱（EP11）之前需铺垫"被诬"的合理性，不突兀
