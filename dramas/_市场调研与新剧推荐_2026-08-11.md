## 二、题材格局与趋势（2026年上半年）

### 2.1 备案题材分布（真人持证）

| 题材 | 占比 | 趋势 |
|------|------|------|
| 都市 | **36.8%** | 稳居第一，内容供给基本盘 |
| 传奇 | **28.7%** | 第二，古装/年代/奇幻 |
| 革命/公安/科幻等垂类 | 崛起中 | 受众分层明确，政策扶持 |

### 2.2 平台热播题材特征

**红果短剧（女性向为主）**：
- 情感、都市、古装三大题材稳居TOP3
- **女性成长、家庭伦理、刑侦涉案**等现实题材占比显著提升
- 系统流爆款：《荒年全村啃树皮，我有系统满仓肉》站内热度9893W（近1亿），观看量超10亿
- 暑期档爆款：《渐染》（虐恋救赎，热度5943，收藏115万+）、《昼以继夜》、《苏太太，高调离婚了》

**红果免费漫剧（男性向为主）**：
- 男性用户占比57.5%，35-54岁中年用户占55.6%
- "都市日常"（14.6%）与"都市脑洞"（11.6%）位居前二
- 古风、玄幻脑洞占比均超9%
- 仿真人漫剧占比63.7%，2D/3D漫剧占34.4%

**抖音漫剧日榜（8月3日）**：
- 冠军《规矩是你定的》AI真人漫剧：单日新增6288万，累计1.5亿
- 亚军《八零媳妇富农家》3D动态漫：上线10天累计5.7亿，单日增量5887.6万
- 黑马《我刻薄不是装的》上线次日登榜第三，单日新增5554.8万

### 2.3 用户结构变化

| 用户群 | 变化 | 意义 |
|--------|------|------|
| 55岁以上银发用户 | 27.5% → **33.3%**（涨幅最高） | 银发经济成增长主力 |
| 女性用户 | 52.1%，稳定 | 基本盘 |
| 15-44岁年轻用户 | 同比下降7.3% | 存量竞争加剧 |
| 短剧App用户 | 70后/80后占47.2%，二三四线占63.1% | 下沉市场+中年群体 |

### 2.4 上星频道（大屏）特征

- 2026上半年上星频道播出微短剧超80部，覆盖36个频道，触达30.2亿人次
- 45岁以上熟龄观众占62.8%，女性占51.6%
- 题材：都市生活、悬疑并列第一（各15.4%）
- 湖南卫视《最浪漫的事》收视率0.71%居首（"微短剧+公益"模式）

## 三、政策与平台激励风向（2026年8月）

### 3.1 监管新规

- **《微短剧发展管理办法》**：2026年7月31日通过，**9月1日施行**
  - 微短剧官方定义：单集<20分钟、主线清晰、情节完整、人物鲜明
  - 分类管理：重点微短剧投资门槛300万，普通100-300万，其他100万以下
  - 全流程审核、黑名单制度、低俗擦边零容忍
  - 鼓励"微短剧+千行百业"融合

- **红果AI剧规范**（8月3日）：禁止通用网红AI模板、严禁无授权挪用真人肖像、淘汰粗放流水线

### 3.2 平台激励方向

| 平台 | 政策 | 金额/资源 |
|------|------|----------|
| 抖音 | 真人短剧创新题材保底激励 | 最高100万，最低20万，截止9月30日 |
| 番茄海外 | AI短剧爆款激励计划 | 全版权最高5万美元，独家首发3万美元 |
| 红果 | S++级剧本分账比例提至50%，周期延至24个月 | 亿元级保底协议 |
| 抖音集团 | 真人短剧专项扶持资金 | **超15亿元** |
| 爱奇艺 | 悬疑短剧厂牌"暗流剧场" | 国内首个横屏中短悬疑剧垂直厂牌 |

### 3.3 地方政府/产业扶持热点

- **"短剧+文旅"**：多地政府重点扶持赛道（北海《海丝迷藏》、泉州《宴遇簪花缘》、盐城《盐街烟火识归人》）
- **非遗题材**：川剧《花重锦官城之刀马旦传奇》、宋锦《顾盼锦年》、湛卢铸剑《湛卢少年行》
- **红色/现实**：《列车开往1942》（铁道游击队）、《破晓之光》（打拐）、《人间烟火"双虹"处》（残疾人创业）
- **青少年心理健康**：山东首部未成年心理短剧《成长的烦恼》

- 平台对**系列化IP**倾斜：非系列化独立短剧推荐权重降低
- **AI漫剧**成最大风口，预计2026年底取代30%真人短剧市场

## 五、新剧推荐清单（纯市场驱动）

> 以下推荐完全基于上述市场数据、平台激励方向、政策扶持热点，**未参考仓库现有项目**。剧名均已查重（对照 `dramas/` 目录），确保唯一性。

### 推荐 1：《荒年分家后，我靠系统养全家》
- **题材**：年代 + 系统 + 女强 + 种田/家庭伦理
- **目标受众**：女性为主（52.1%），25-54岁中青年 + 银发群体
- **推荐逻辑**：
  - 系统流+女强+种田是已验证的红果天花板级公式（《荒年全村啃树皮》热度近1亿）
  - 年代题材在备案中占28.7%，且《八零媳妇富农家》3D动态漫10天5.7亿证明年代+致富长尾极强
  - "分家"是家庭伦理核心冲突，契合女性用户与银发用户双重偏好
  - 现实题材占比显著提升，"养全家"兼具爽感与情感厚度
- **差异化**：聚焦"分家后"的独立女性成长，非单纯逃荒；系统功能偏向"物资调配+家庭关系修复"双线
- **合规**：C级（一般题材），无政治/军事/迷信风险
- **平台适配**：红果短剧（女性向）+ 红果免费漫剧（可同步AI漫剧版）

### 推荐 2：《离婚冷静期，我成了前夫甲方》
- **题材**：都市情感 + 女性成长 + 职场/商战
- **目标受众**：女性，25-45岁都市白领
- **推荐逻辑**：
  - 都市题材占备案36.8%，是内容供给基本盘
  - "离婚"是暑期档已验证爆款元素（《苏太太，高调离婚了》）
  - "甲方"身份反转契合女性成长+职场爽感，符合"从单一爽感转向社会观照"趋势
  - 抖音真人短剧创新题材保底激励（最高100万）明确扶持此类现实创新题材
- **差异化**：不是简单"离婚后逆袭"，而是"冷静期内身份倒置"——前夫公司成为乙方，女主掌握合作生杀权，情感与商战双线交织
- **合规**：C级
- **平台适配**：红果短剧 + 抖音（保底激励）

### 推荐 3：《刑侦档案：她看见凶手》
- **题材**：悬疑刑侦 + 女性视角 + 现实题材
- **目标受众**：女性为主，兼顾男性悬疑爱好者；18-45岁
- **推荐逻辑**：
  - 悬疑刑侦是垂类崛起赛道，《原罪2》视听总时长54.5亿分钟证明市场深度
  - 爱奇艺8月4日上线国内首个横屏中短悬疑剧厂牌"暗流剧场"，平台资源倾斜明确
  - 女性视角刑侦差异化：非传统硬汉刑警，而是"能看见凶手"的特殊能力者（轻奇幻设定，非迷信）
  - 公安/刑侦属政策鼓励的垂类（《破浪·十年》等法治短剧持续涌现）
- **差异化**：女主是犯罪心理学侧写师，因创伤获得"共情凶手视角"能力，每集一个案件+主线连环案，短剧节奏+电影级悬疑
- **合规**：B级（公安刑侦），核心导向为正义/女性成长，非宣扬暴力，可备案
- **平台适配**：爱奇艺"暗流剧场" + 红果短剧

### 推荐 4：《八零年代：我的厂花老婆是大佬》
- **题材**：年代 + 男频 + 穿越/重生 + 工业/致富
- **目标受众**：男性为主（红果免费漫剧男性占57.5%），35-54岁中年
- **推荐逻辑**：
  - 红果免费漫剧"都市日常""都市脑洞"占前二，古风/玄幻脑洞超9%，男频向特征鲜明
  - 《八零媳妇富农家》3D动态漫10天5.7亿，证明年代+致富在男频/中年市场爆发力
  - 传奇题材备案占28.7%，年代剧是其中重要组成
  - "厂花老婆是隐藏大佬"融合男频爽点（身份反转）与年代情怀
- **差异化**：男主视角，重生回八零年代发现"厂花老婆"竟是未来商业大佬，双向隐藏身份，工业报国+家庭喜剧
- **合规**：C级
- **平台适配**：红果免费漫剧（AI仿真人/3D动态漫）+ 抖音漫剧

### 推荐 5：《非遗守护人：苏绣皇后》
- **题材**：非遗文化 + 女性成长 + 都市/传奇
- **目标受众**：女性 + 银发群体 + 文化爱好者
- **推荐逻辑**：
  - "短剧+文旅/非遗"是地方政府重点扶持赛道，多部非遗短剧近期上线（川剧、宋锦、簪花、鱼汤面）
  - 女性成长+现实题材占比显著提升，契合平台"精品化"导向
  - 银发用户占比33.3%且持续上升，非遗题材对熟龄女性有天然吸引力
  - 上星频道微短剧剧场扩容（11个剧场），非遗题材易获大屏播出机会
- **差异化**：以苏绣为核心，女主是年轻非遗传承人，对抗商业化抄袭+家族恩怨，"一根绣针"串联爱情、亲情、文化坚守
- **合规**：C级，且属政策鼓励方向
- **平台适配**：红果短剧 + 省级卫视短剧场 + 文旅合作

### 推荐 6：《AI恋人：我的男友是代码》
- **题材**：科幻 + 甜宠 + 轻悬疑
- **目标受众**：Z世代 + 年轻女性
- **推荐逻辑**：
  - 科幻是垂类崛起赛道，平台对科幻/悬疑/现实主义空白领域给予**3倍分账倾斜**
  - AI题材契合2026年技术风口，且"AI恋人"设定天然适配甜宠+悬疑双线
  - Z世代是核心付费群体，漫剧/悬疑/科幻占据其30%+娱乐时间
  - 虚拟演员/AI技术成熟，此类题材可探索"AI生成+真人出演"混合模式
- **差异化**：女主发现完美男友竟是AI代码，追查真相过程中发现更大阴谋，"爱情是否真实"的哲学探讨+高糖互动
- **合规**：C级
- **平台适配**：红果短剧 + B站/字节女频漫剧专区

## 七、风险提示

1. **政策风险**：9月1日《微短剧发展管理办法》施行，全流程审核趋严，需确保题材合规、价值观正向
2. **同质化风险**：系统流、年代致富等赛道已现拥挤，需在执行层面强化差异化（人设、细节、情感厚度）
3. **AI替代风险**：AI漫剧预计取代30%真人短剧市场，真人短剧需向"精品化、情感深度"转型
4. **平台依赖风险**：系列化IP成主流，单部剧生存空间收窄，建议规划季播或IP衍生
