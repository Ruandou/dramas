## 二、题材热度核心发现

### 2.1 系统题材摸到红果天花板

《荒年全村啃树皮，我有系统满仓肉》红果站内热度峰值 **9893 万（≈1亿天花板）**，累计观看超 10 亿，连续多期登顶 DataEye 红果热榜。ADX 数据显示近三个月**奇幻脑洞、系统**两大题材涨幅明显（另一验证：《栀栀复栀栀》）。

**拆解爆款公式**：极端困境（荒年/绝境）× 金手指（系统）× 反差爽感（全村啃树皮 vs 我满仓肉）× 长句式具象标题。

### 2.2 系列化 IP 是 2026 生死线

- 平台全面推行系列化 IP 扶持，**降低非系列化独立短剧推荐权重**
- 中信证券预测：2026 年底头部系列 IP 分账总额占全行业 **60%+**
- 验证案例：《十八岁太奶》第四部预约中、《咱家剑宗团宠小师妹》系列 34 亿播放、《姜月初》第八季仍在 TOP5
- **含义：新剧立项必须自带「可系列化」基因（单元剧结构 / 可续命世界观）**

### 2.3 双极受众结构

- **银发**：55+ 占比 33.3% 且是涨幅最高人群；平台发力适老化短剧，预计带来 2 亿新增用户
- **Z 世代**：核心付费群体，漫剧/悬疑/科幻占其 30%+ 娱乐时间
- AI 漫剧预计 2026 年底取代 **30% 真人短剧份额**，字节/B站已开女频漫剧专区

### 2.4 海外市场题材结构（NetShort 2026 H1 百强榜）

情感 77% ＞ 都市 35% ＞ 逆袭 25% ＞ 复仇 15% = CEO 15%；美国贡献一半收入。
**含义：情感+都市+复仇的低文化折扣概念可做「国内+出海」双版本**，配合 SD2.0 翻译配音方案。

### 2.5 监管边界（2026 合规元年）

- 分层分类新标准落地：重点微短剧投资门槛 300 万；全流程审核+黑名单制度
- 零容忍：低俗擦边、以暴制暴、价值观扭曲、虐恋家暴、儿童成人化
- 抖音已发布 AI 短剧审片标准（红线/质量/流程），并整治「生理性厌恶的 AI 脸」
- A 级红线不变：现代政治/军事/司法公安刑侦/宗教民族/封建迷信

## 四、新剧推荐（6 个概念，均通过题材合规快检）

> 标题唯一性：已与仓库 114 个项目目录名及检索到的在播剧名比对，无撞名。

### 推荐 1：《退休第一天，我绑定了摆摊爆单系统》 ⭐ 首推
- **题材**：都市系统流+银发喜剧（🟢 C 级，直接通过）
- **核心钩子**：国企食堂退休的王阿姨，退休第一天被子女嫌弃"在家碍事"，出门散心却绑定了「摆摊爆单系统」——系统发布的任务千奇百怪（"让挑剔的白领连吃三天"、"用一碗馄饨劝退一场离婚"），完成就解锁失传菜谱和摊位神器。她从小区门口的三轮车摊，一路摆到全城美食地标，子女从嫌弃到抢着当学徒。
- **市场依据**：系统题材（红果热度天花板）× 银发受众（涨幅最高人群）双风口叠加；「爆单」过程是天然切片素材；美食特写是 Seedream 强项。
- **系列化基因**：★★★★★ 一集一个摊位任务=单元剧结构，可无限续季（夜市篇/古镇篇/出国篇）。
- **AI 适配性**：★★★★★ 市井摊位场景高复用；系统 UI 用后期字幕；食物静物生成质量高。
- **风险**：需避免"系统万能"悬浮感，核心导向锚定"手艺与人情味"；老年主角面部生成需 mesh 方案保障。

### 推荐 2：《千年铁花，砸进了我的直播间》
- **题材**：非遗传承+文旅+轻情感（🟢 C 级）
- **核心钩子**：都市女主播回乡直播"最后一炉铁花"——爷爷是打铁花非遗传承人，因景区改造面临失传。一场直播意外爆火，千年铁花照亮夜空的瞬间全网刷屏。她留下来学艺，却发现这门"男人的手艺"从没传过女人；镇上的文旅公司少东家一边和她抢流量，一边偷偷帮她扛铁水。
- **市场依据**：抖音辰星计划（传统文化+文旅）明确流量倾斜；「短剧+非遗」官方点名；创新题材基金 3 倍分账；铁花视觉奇观是天然传播点。
- **系列化基因**：★★★★ 可做「非遗宇宙」系列 IP（第二季漆器/第三季苏绣/第四季英歌舞）。
- **AI 适配性**：★★★★★ 铁花/火光/夜景是 Seedance 特效强项，真人拍摄反而危险昂贵——**这是 AI 短剧相对真人剧的绝对优势题材**。
- **风险**：非遗细节需考究（可引用 docs 资料）；"女性不能传艺"冲突需导向"打破陈规"而非渲染性别对立。

### 推荐 3：《调解员王姐的十八般武艺》
- **题材**：社区单元喜剧+现实题材（🟢 C 级，人民调解属民间行为，不涉司法公安）
- **核心钩子**：菜市场卖了二十年猪肉的王姐被居委会拉去当调解员，第一天就用"剁骨刀逻辑"劝和了一对要离婚的夫妻。她调解不看法条看人心：婆媳大战用一桌菜化解，邻里漏水纠纷靠一杆秤摆平。每个单元案背后，都藏着这栋老楼三十年的人情账。
- **市场依据**：垂类专业题材被验证（《破浪·十年》模式）；现实题材进 CSM 热播榜前列；单元剧结构完美契合平台系列化新规；银发+全龄双受众。
- **系列化基因**：★★★★★ 一集一案，天然无限续订；可衍生「王姐宇宙」（菜场篇/物业篇/相亲角篇）。
- **AI 适配性**：★★★★ 老小区/居委会场景高复用；靠台词和表情驱动，生成成本低。
- **风险**：不得出现公安/法院主导剧情（保持民间调解定位）；需避免家长里短流水账，每案须有反转钩子。

### 推荐 4：《全球暴雨十年，我在楼顶种出了粮仓》
- **题材**：女频硬核末日基建+种田（🟢 C 级，核心导向为生存智慧与互助）
- **核心钩子**：气象学家预言全球暴雨将持续十年，没人信，只有外卖员出身的女主信了——她提前半年租下城中村整栋楼的楼顶，暴雨降临后，全城内涝断粮，她的楼顶农场成了灰色水世界里唯一的绿洲。曾经嘲笑她的人划着皮划艇来求购蔬菜，而她要的不是钱，是人手、技术和一个新秩序。
- **市场依据**：女频硬核生存是 AI 漫剧验证方向（《海上求生：我的木筏通桃源》基建种田模型）；Z 世代付费主力偏好科幻/末日；囤货种田的"清单式爽感"是切片利器。
- **系列化基因**：★★★★ 十年暴雨=天然十季框架（第一季楼顶篇/第二季水城贸易篇/第三季迁徙篇）。
- **AI 适配性**：★★★★★ 水淹城市/暴雨/楼顶农场全是 AI 特效强项，真人无法低成本实现。
- **风险**：灾难描写不得渲染恐慌与暴力，导向锚定"预见、建设、互助"；需规避与在播末日剧钩子雷同。

### 推荐 5：《整座城市只有我没有金手指》
- **题材**：反套路奇幻脑洞+都市喜剧（🟢 C 级）
- **核心钩子**：某天醒来，全城人都觉醒了金手指：同事能读心、房东会瞬移、楼下大爷力大无穷——只有社畜女主什么都没有。但她很快发现，所有金手指对她无效：读心术读不到她、预言里看不见她。当"超能力社会"因滥用能力乱成一团，这个唯一的"普通人"成了所有人唯一信得过的裁判。
- **市场依据**：奇幻脑洞是 ADX 涨幅第一梯队题材；"反套路"设定自带话题度（人人有系统时代的无系统者）；喜剧仍是 7 月榜首验证的最硬流量密码。
- **系列化基因**：★★★ 一集一种失控金手指=半单元结构；世界观可续季揭秘。
- **AI 适配性**：★★★★ 超能力视觉效果是 Seedance 强项；都市场景高复用。
- **风险**：脑洞剧逻辑自洽要求高，"无金手指为何免疫"的谜底须在大纲期锁死；避免能力设定过多导致视觉资产爆炸（控制在 6-8 种）。

### 推荐 6：《替嫁新娘反手买下了婚礼酒店》
- **题材**：都市情感+复仇+身份反转（🟢 C 级）｜ **出海双版本候选**
- **核心钩子**：豪门联姻当天，真千金逃婚，养女被推上婚车"替嫁"，全场看她笑话——司仪故意念错名字，婆家把彩礼当施舍。仪式进行到一半，酒店经理捧着文件进场："各位，本酒店今早刚完成股权变更，请全体起立欢迎新老板——台上这位新娘。"她不是替嫁，她是来收购的。
- **市场依据**：海外榜情感 77%+复仇 15%+CEO 15% 三标签全中，低文化折扣可直接走 SD2.0 翻译配音出海；国内《闪婚老公又宠又撩》双平台破亿验证同赛道仍能打。
- **系列化基因**：★★★ 可做「她的收购清单」系列（每季收购一个看不起她的行业）。
- **AI 适配性**：★★★★ 酒店/宴会厅/办公室场景高复用；名场面（起立欢迎）是天然切片。
- **风险**：赛道竞争激烈，须靠"每集一个收购反转"的密度取胜；复仇导向锚定"凭实力赢回尊严"，不渲染践踏羞辱。

### 推荐 7：《我妈的六十岁，我重启了一百次》 ⭐ 第二批首推
- **题材**：软科幻时间循环+亲情+银发（🟢 C 级）
- **核心钩子**：妈妈六十岁生日宴当晚突发意外去世，悲痛的女儿一觉醒来回到当天早晨——她被困在妈妈生日这一天。第一次她拼命阻止意外，第二次她试图弥补遗憾，第十次她才发现：妈妈这一天里藏着无数她从没注意过的秘密——偷偷退掉的体检单、藏在米缸里的存折、和一个陌生男人的合影。要打破循环，她必须真正读懂妈妈的一生。
- **市场依据**：科幻是创新基金 3 倍分账题材；银发+亲情双受众（涨幅最高人群+全龄共鸣）；时间循环是短视频切片天然素材（同场景多版本对比）。
- **系列化基因**：★★★★ 「重启」宇宙可续季（第二季重启爸爸的一天/第三季重启自己的十八岁）。
- **AI 适配性**：★★★★★ 单日循环=场景高度复用（一套场景拍一百种走向），Stage 3 成本全流水线最低。
- **风险**：循环规则须在大纲期锁死（打破条件/记忆保留规则）；情感浓度要求高，避免变成机械解谜。

### 推荐 8：《东北大姨的早市封神录》
- **题材**：地域市井喜剧+美食（🟢 C 级）
- **核心钩子**：下岗女工陈大姨在东北早市支了个豆腐脑摊，凭一张唠嗑嘴和一手绝活，把三米摊位经营成早市"情报中心+调解中心+美食地标"。连锁餐饮巨头想收编整个早市搞"规范化改造"，大姨带着卖粘豆包的、烤冷面的、修鞋的组成"早市联盟"迎战——你有资本，我有整条街的人心。
- **市场依据**：红果"东北剧场"验证地域题材（《东北90之沈阳女王》好评）；市井美食+人情喜剧全龄通吃；"小人物抱团对抗资本"是普世爽点。
- **系列化基因**：★★★★★ 一集一个摊位故事=单元结构；可做"市井宇宙"（早市篇/夜市篇/大集篇）。
- **AI 适配性**：★★★★ 早市场景高复用；东北方言靠台词出彩，TTS 方言配音可行；美食蒸汽特写是 Seedream 强项。
- **风险**：方言喜剧的梗密度要求高；"对抗资本"导向须锚定"公平竞争与烟火气"，不渲染仇富。

### 推荐 9：《深夜便利店，只接待有故事的人》
- **题材**：都市治愈+单元轻悬疑（🟢 C 级）
- **核心钩子**：城中村便利店只开凌晨十二点到六点，店主是个看似懒散的年轻女人。每晚来的客人都带着秘密：买十桶泡面的失业男人、凌晨三点买生日蜡烛的女孩、每天只买一瓶水却站一小时的老人。她从不多问，只是把对的东西在对的时刻推到对方面前。直到某天，一个客人认出她——"你不是三年前失踪的那个天才谈判专家吗？"
- **市场依据**：《盛夏芬德拉》验证治愈系细腻叙事能打（30 亿播放+短剧最高分 7.5）；悬疑是 3 倍分账题材；单元故事+主线暗线双层结构完美契合系列化新规。
- **系列化基因**：★★★★★ 一夜一客一故事，天然无限续订；店主身世是贯穿钩子。
- **AI 适配性**：★★★★★ 全剧 80% 戏份在同一便利店场景=资产复用极限；夜景霓虹是 Seedream 美学强项。
- **风险**：治愈系节奏偏慢，须靠每集客人反转保住钩子密度；店主前史悬念要控制释放节奏。

### 推荐 10：《奶奶潜入相亲角》
- **题材**：银发喜剧+反诈情感（🟢 C 级，民间视角，不涉公安主导）
- **核心钩子**：68 岁的退休教师周奶奶发现老姐妹陷入"黄昏恋"骗局，报警取证难，她干脆自己扮成"有三套房的孤寡老太太"潜入公园相亲角钓鱼取证。一来二去，她成了相亲角的"扫地僧"：一眼识破酒托、婚托、保健品托，还顺手撮合了七八对真心人。直到她遇上一个破绽满身却让她心跳的老先生——这次，她分不清是骗局还是心动。
- **市场依据**：适老化短剧是平台明确发力方向（2 亿增量预期）；反诈是政策鼓励题材；"银发爱情+悬疑"错位组合自带话题；老年相亲角是现实热议场景。
- **系列化基因**：★★★★ 一集一骗局/一对CP=单元结构；奶奶自己的感情线是纵向主线。
- **AI 适配性**：★★★★ 公园/相亲角场景高复用；老年角色需 mesh 方案保障（已有成熟解法）。
- **风险**：取证行为保持民间互助定位，落点交给警方处理但不展开公安戏；骗术展示只到识破层，不做教程式还原。

### 推荐 11：《我在游戏里给NPC当心理医生》
- **题材**：奇幻脑洞+治愈喜剧（🟢 C 级）
- **核心钩子**：心理咨询师失业当晚进入一款老游戏，发现自己成了"无名NPC"——而这个游戏世界的NPC全都"精神状态堪忧"：被玩家杀了一万次的野怪BOSS有创伤应激，永远在等勇者的公主有分离焦虑，铁匠铺老板娘对着重复台词说了十年已经自我怀疑。她在游戏里挂牌开诊，专治NPC疑难杂症，却逐渐发现这些NPC的痛苦，都对应着现实中某个玩家的执念。
- **市场依据**：奇幻脑洞是 ADX 涨幅第一梯队；Z 世代游戏文化共鸣+心理健康议题双热点；"NPC觉醒"是近年高热网络母题；一集一诊单元结构契合系列化。
- **系列化基因**：★★★★★ 一集一个NPC病例；可跨游戏续季（武侠游戏篇/恋爱游戏篇/像素游戏篇）。
- **AI 适配性**：★★★★★ 游戏世界视觉风格化是 AI 强项（真人剧反而难做）；场景可大胆奇观化。
- **风险**："游戏世界规则"需大纲期锁死；心理议题须专业善意，不拿精神疾病做梗。

### 推荐 12：《在大理，我开了家只收故事的客栈》
- **题材**：文旅治愈+情感（🟢 C 级）｜ **短剧+文旅政策标的**
- **核心钩子**：被裁员的上海白领用全部赔偿金盘下大理一家倒闭客栈，定下怪规矩：住店不收钱，只收一个真实的故事。破产的创业者、逃婚的新娘、骑行环国的退休夫妻、寻找亡妻足迹的老人……每个故事换一晚安眠。直到有个男人住了三十天讲了三十个故事，她才发现每个故事里都有同一个女人——长得和她一模一样。
- **市场依据**："短剧+文旅"单地带动旅游收入超 5 亿的验证模式，地方文旅合作可谈资源置换；抖音辰星计划文旅方向流量倾斜；治愈+悬念双层结构对标《盛夏芬德拉》。
- **系列化基因**：★★★★★ 一集一个故事=单元结构；可换城续季（大理篇/敦煌篇/平潭篇），每季绑定一地文旅。
- **AI 适配性**：★★★★★ 苍山洱海风光是 Seedream 强项，风光空镜成本趋零；客栈主场景高复用。
- **风险**：文旅剧易流于风光片，须靠"故事换宿"的钩子密度撑住；神秘女人主线须在大纲期闭环。
