### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨 segment 出现 → 独立 CHAR-###；纯背景无台词 → CHAR-GRP

## 六、分段规则

### 基本约束

| 约束             | 值              | 说明                                                    |
| ---------------- | --------------- | ------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**     | Seedance fast 硬限制；超出必须拆分                      |
| 理想时长         | 8–10 秒         | 一条 API = 一段可拍的戏                                 |
| 每 segment 镜头数 | 1–3 镜          | 不超过 3 个镜头                                         |
| 最小叙事单位     | 1 个完整 beat   | 每个 segment 必须构成完整叙事节拍                       |
| 每集段落数       | 6–10 段         | 对应单集 90 秒（EP01 为 120 秒）                        |
| 每集镜头数       | 8–12 镜         | 对应每集 6–10 段 × 1–3 镜/段                            |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

### 分集剧本格式规范

分集剧本（`剧本/EP##/EP##_*.md`）使用 **11 列镜头表**：

| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白备注 |
|------|---------|------|------|------|------|------|------|------|------|----------|

- SEG 块以 `---` 分隔，每段附 `> ⏱ Segment时长：Xs` 统计行
- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`

## 九、年代/题材约束

### 必须体现元素

- 仙侠修仙世界观：灵气、剑气、法术、阵法
- 服装飘逸但不繁复：轻纱、宽袖、腰带，非明清官服
- 建筑为古代中式+仙侠夸张化：飞檐翘角、悬浮石台、灵力光柱
- 武器为古剑/法器，非现代武器
- 自然景观融入灵气元素：雾气、灵光、仙鹤

### 禁止出现元素（结构性约束）

- 任何现代物品（手机、汽车、电线杆、现代服装）
- 西方奇幻元素（精灵耳朵、魔法杖、哥特建筑）
- 具体朝代标志性服饰（清朝辫子、明朝官帽等）
- 动漫/卡通风格元素
- 血腥暴力画面（可暗示但不直接展示内脏/断肢）
- 裸露/色情内容

## 内容合规参数

### 题材合规等级

**B级（仙侠玄幻）** — 需注意修仙暴力尺度和女性角色刻画

### 本剧特定红线

1. **暴力尺度**：战斗场景以剑气/灵力碰撞为主，禁止直接展示血腥画面（断肢、内脏外露）；受伤以口角溢血、衣物破损暗示
2. **女性角色刻画**：避免物化女性角色的镜头（暴露服装、不当角度）；苏念的逆袭叙事须体现女性自主力量
3. **修仙设定一致性**：修炼体系须前后一致，不可出现矛盾设定
4. **复仇叙事边界**：苏念最终不杀秦无极（交由审判），体现法治精神而非私刑正义
5. **门派/宗教敏感性**：架空设定，不得使用真实道教/佛教术语作为反派标签

### 灰区处理策略

| 灰区 | 处理方式 |
|------|----------|
| 灭门暴力场景（EP01回忆/EP35灵力留影） | 以剪影/模糊化处理，聚焦苏念情绪反应而非暴力细节 |
| 灵毒下毒场景（EP09） | 以灵力光芒暗示，不展示具体下毒过程 |
| 白冰霜寿元燃烧（EP67） | 以灵力消散的视觉隐喻替代身体崩解 |
| 赵长老暴毙（EP31） | 面色发黑+倒下，不展示痛苦细节 |

### 正向价值锚点

1. **守护与牺牲**：沈云霄以命守护苏念、掌门以宗门之力保护弟子——正面价值观核心
2. **自强不息**：苏念从废物杂役到首席弟子——逆境中不放弃、以实力证明自己
3. **正义终将到来**：赵长老被揭发、秦无极被击败、白冰霜被清算——恶行终有报

## 待确认放行协议

当某个门控阶段需要用户审批但用户 **3 轮用户交互内未回应** 时：

1. **文本自检降级**：由当前门控负责方执行自检（分辨率合规性、文件完整性、ID一致性、命名规范性）
2. **待确认放行标记**：自检通过的资产标记为「⚠️ 待用户确认」，写入 `工作计划.md`
3. **不通过则返工**：自检未通过的资产不得放行，立即返回修改
4. **用户回应后处理**：确认→正式通过；否决→下游回退
