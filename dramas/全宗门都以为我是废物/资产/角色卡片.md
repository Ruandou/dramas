### 语言画像

| 维度 | 描述 |
|------|------|
| 词汇层级 | 朴素简洁，不用华丽辞藻，偶有古语（家传剑法口诀） |
| 句式偏好 | 短句为主，极少复合句；战斗/关键场景有精炼长句 |
| 口头禅/标志表达 | "再忍忍"（隐忍期低声自语）；"我来"（觉醒后主动承担） |
| 情绪表达方式 | 克制型——极少外露，愤怒时反而更安静；痛苦时不哭出声，无声流泪 |
| 禁用词 | 不说"求你"、"饶命"、"我不行"——骨子里的骄傲不允许 |
| 参照原型 | 魏璎珞（延禧攻略）的隐忍与爆发力 |
| 对白权力模式 | 前期迎合型(accommodating) → 后期主导型(dominating) |
| 信息密度 | 低(每句只说一件事) → 后期高(每句含多重信息) |
| 沉默策略 | 被羞辱时沉默——观众应感受到压抑的愤怒和隐忍的力量 |
