# 《穿越修仙界，我靠现代知识飞升》制片规范 · ID 与引用

> **正名**：《穿越修仙界，我靠现代知识飞升》
> **版本**：v1.0 · 2026-06-12

## 一、ID 命名规则

| 类型 | 格式 | 示例 | 说明 |
|------|------|------|------|
| 角色 | `CHAR-###` | `CHAR-001` | 主线角色编号，从 001 连续 |
| 形象 | `CHAR-###-L##` | `CHAR-001-L01` | L01=基础形象，L02+=衍生形象 |
| 群演 | `CHAR-GRP-##` | `CHAR-GRP-01` | 群演组，共用一套形象 |
| 场景 | `SCENE-###` | `SCENE-001` | 核心场景编号 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具编号 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集号-镜号 |
| 段落 | `EP##-SEG##` | `EP01-SEG01` | AI 生成单位 |

**ID 只增不删，弃用标 `deprecated: true`**

## 二、视觉风格锚点 (Visual Style Anchor)

### 渲染风格
- **整体风格**：半写实仙侠（Photorealistic with xianxia fantasy elements）
- **参考风格**：介于传统仙侠写真与现代奇幻电影之间，追求"真实世界中存在修仙"的质感
- **色彩基调**：青蓝冷色为主（仙侠世界基调），暖金色点缀（科学光芒/突破时刻/陈屿的灵力特效）

### 科学 vs 仙侠视觉对比
- **仙术/灵力**：传统青蓝色光效，流转飘逸
- **科学方法**：金色光效+金色粒子特效，精确规整，几何图案（方程、分子结构、矩阵等隐约浮现）
- **冲突时刻**：科学金光 vs 仙术青光的碰撞 = 最具视觉冲击力的画面

### 色温基准
- **日常场景**：中性偏暖（5000-5500K），温馨自然
- **修炼/突破**：冷蓝（7000K）转暖金（4500K），随修为提升色温逐渐升高
- **战斗场景**：高对比，冷色为主，科学爆发时出现暖金高光
- **玄天宗**：阴冷暗沉（8000K+），血色灵光为反派标志色

### 题材关键词
`仙侠世界, 科学修仙, 降维打击, 轻喜, 灵力光效, 金色科学光芒, 青蓝仙侠基调, 竖屏9:16`

## 三、分段与镜头规范

### Seedance 参数
- **模型**：`doubao-seedance-2-0-fast-260128`
- **比例**：9:16（竖屏优先）
- **分辨率**：720p
- **单段时长**：4-12 秒（理想 8-10 秒）
- **每段镜头数**：1-3 镜
- **每集段数**：12-15 段
- **每集总时长**：140-200 秒（理想 150-180 秒）
- **每集镜头数**：15-30 个 Seedance 有效镜头

### 分段规则
- 不得在对话中间切断段落
- 不得跨场景
- 说话人 ≤ 2 人/段
- 超 12 秒用 a/b 后缀拆分（EP01-SEG03a / EP01-SEG03b）

### prompt_suffix
```
禁止画面中出现任何文字或字幕。半写实仙侠风格，青蓝冷色基调，金色粒子点缀科学感。竖屏9:16。
```

### prompt_suffix_silent
```
本段无对白无语音，禁止画面中出现任何文字或字幕。半写实仙侠风格，青蓝冷色基调。竖屏9:16。
```

### negative_prompt
```
anime, cartoon, illustration, manga, text, watermark, subtitle, logo, blurry, low quality, deformed hands, extra fingers, cropped at waist, modern clothing on non-modern characters, anachronistic elements
```

### negative_prompt 年代禁忌
```
modern buildings, electric lights, cars, smartphones, plastic items, modern furniture, contemporary urban environment
```

## 四、资产索引管理

### 索引文件位置
| 文件 | 路径 | 说明 |
|------|------|------|
| 角色索引 | `资产/角色索引.md` | CHAR-* 主表，唯一 ID 定义 |
| 形象索引 | `资产/形象索引.md` | CHAR-*-L** 主表，形象与图对应 |
| 场景卡片 | `资产/场景卡片.md` | SCENE-* 主表 |
| 道具卡片 | `资产/道具卡片.md` | PROP-* 主表 |
| 声音卡片 | `资产/声音卡片.md` | voice_prompt 主表（P0 权威来源） |

### 数据权威性
- **voice_prompt**：P0 声音卡片 > P1 角色卡片 > P2 制片规范
- **角色 ID**：角色索引.md 为唯一定义，character-designer 不可自行新增
- **分集剧本**是真相源，YAML 从剧本导出

### CDN URL 管理
| 资产类型 | cdn_urls.json 路径 | 内容 |
|----------|---------------------|------|
| 角色形象 | `assets/looks/cdn_urls.json` | CHAR-*-L## → tos_url |
| 场景图 | `assets/scenes/cdn_urls.json` | SCENE-### → tos_url |
| 道具图 | `assets/props/cdn_urls.json` | PROP-### → tos_url |

**所有 CDN URL 必须为永久 TOS 链接（`https://`），不得使用预签名临时 URL（含 `X-Tos-Expires`）。**

## 五、TTS / 配音方向

## 六、分集剧本格式规范

### 文件头
```yaml
---
episode_id: EP01
episode_title: [集标题]
duration_min: 2.5
season: S1
scene_ids: [SCENE-001, SCENE-002]
character_ids: [CHAR-001, CHAR-002]
look_ids: [CHAR-001-L01, CHAR-002-L01]
prop_ids: [PROP-001]
seedance_defaults:
  model: doubao-seedance-2-0-fast-260128
  ratio: "9:16"
  resolution: 720p
  duration_sec: "8-10"
  generate_audio: true
  prompt_suffix: "禁止画面中出现任何文字或字幕。半写实仙侠风格，青蓝冷色基调，金色粒子点缀科学感。竖屏9:16。"
  negative_prompt: "anime, cartoon, illustration, manga, text, watermark, subtitle, logo, blurry, low quality, deformed hands, extra fingers, cropped at waist, modern clothing on non-modern characters, anachronistic elements"
---
```

### SEG 正文格式
```markdown
---

## SEG01 — [段落叙事功能概括]

**【SCENE-###】[地点名]** · **[时段]** · **[内景/外景]**

| 镜号 | shot_id | 场景 | 角色 | 形象 | 景别 | 时长 | 模式 | 运镜 | 画面 | 对白/备注 |
|------|---------|------|------|------|------|------|------|------|------|-----------|
| 1 | `EP01-S01` | `SCENE-001` | `CHAR-001` | `CHAR-001-L01` | 中景 | 5 | `i2v_ref` | 固定镜头 | [2-4句画面描述] | **CHAR-001**[情绪]：「台词」 |

> ⏱ Segment时长：11s ｜ 镜头数：2
```

### 对白格式
```
**CHAR-###**[情绪·语气]：「台词」
```
- 单句台词 ≤ 30 个汉字（含标点）
- 每集 ≥ 50 行对白，≥ 20 行/分钟

## 七、工作流顺序（修改层级）

```
故事大纲 (Stage 1)
  └── 制片规范 (Stage 2) — 本文档
       ├── 道具设计 (Stage 3a) ← 先行
       ├── 角色设计 (Stage 3b) ← 依赖 3a
       ├── 场景设计 (Stage 3c) ← 依赖 3a，与 3b 并行
       └── 分集编剧 (Stage 4)
            └── 分镜构建 (Stage 5) — 只读源 .md，不修改
```
