# 公众号启动方案_2026-09-28

## 一、定位

**一句话**：一个人用 AI 流水线量产短剧的实录账号。

不发剧集切片（视频号/抖音的地盘），公众号做**文字沉淀 + 私域入口**，四条内容线（2026-09-29 由三线扩为四线）：

| 栏目 | 内容 | 频次 | 目的 |
|------|------|------|------|
| ① 制作实录 | AI 短剧制作实战：流水线怎么跑、踩坑复盘、成本账单、工具链 | 周更 1（主力） | 涨粉主引擎。干货类在公众号生态传播性强，且我们真在生产，素材零成本 |
| ② 模型实测 | 视频/图片模型上新（Seedance、Kling、即梦、MiniMax、gpt-image…）**真跑一遍**给结论 | 跟版本 | 只有我们有 token 归档和每秒成本口径；别人只能转述发布会 |
| ③ 政策与扶持 | 广电分级备案、平台条款与分账规则、各地基地/文旅补贴 | 月 1-2（补贴线低频常驻） | 政策类信息散、无人汇总，最容易做成「唯一入口」，搜一搜长尾最肥 |
| ④ 剧集衍生 | 在制剧的世界观设定集、角色前传、被删的支线 | 随剧 | 给剧集导流、沉淀观众，剧终后账号不空转 |

> **资讯线注意**：纯搬运资讯的号一抓一大把，没有差异化还稀释定位。规则：每条资讯至少给出「对我们这种独立制作方意味着什么」的判断段 + 能挂上自己的实测数据或账单；政策/数据类优先（可引用自己仓库的市场调研结论佐证），八卦类不跟。选题可反哺仓库——资讯调研产出的爆款规律直接喂给 story-architect。
>
> **四线不显杂的前提**：全部从同一个视角出发——「一个人做剧，这件事怎么影响我的决策」。菜单栏固定分格，读者各取所需，不靠正文互相串。
>
> **顺带的红利**：政策/模型上新的监控本身可以交给 agent 定时跑（抓源 → 去重 → 摘要），「我怎么用 AI 盯行业」这件事自身又是一篇干货。

**差异化**：市面上讲 AI 短剧的要么卖课没实操，要么只发剧不拆解。我们有 80 份大纲 / 67 份分集剧本 / 45 份出了参考图的完整流水线、真实扣费账单和可复现的命令，这是内容护城河。（数字为 2026-09-29 仓库实测）

## 八、导入微信的排版硬规则（2026-09-29 事故固化）

微信「Markdown 文档导入」会破坏两种常见写法，且**文章「发表」后没有修改正文入口**，只能删除重发。因此稿件从落笔就只用安全子集：

| 写法 | 导入结果 | 替代 |
|------|----------|------|
| `1. ` 有序列表 | 每个条目前插一个空 `<li>`，序号渲染成 2/4/6 | `- ` 项目符号 + ①②③④ 写进文本 |
| ` ``` ` 围栏代码块 | 每行之间插空行，读起来全是空隙 | 逐条 `- ` bullet，命令放进**单行行内 code**，`\` 续行折成一行 |
| `<剧名>` 尖括号占位符 | 被当作 HTML 标签吞掉 | 写 `剧名目录` 之类纯文本 |
| `- ` 项目符号 / 行内 `` `code` `` | ✅ 干净 | 放心用 |

**草稿态必做校验**（三项计数，全绿才允许发表）：

```
ol.length === 0
每个 ul 的空 <li> 数 === 0
逐块大纲条数与 h2 数对得上
```

不要用 `querySelectorAll('pre, code').length` 之类的总量指标判"结构完好"——12:07 那版就是这么漏判的。注意 `ul.code-snippet__line-index` 的空 `<li>` 是合法行号槽，不在检查范围。

### 可复制的四条内容工程

1. **开头用读者提问，不用自我陈述**。范式：「后台最常收到的问题不是"用哪个工具"，是这三句：做一集到底要花多少钱？不花钱能做出来吗？我是不是得先买个会员才能开始？」
2. **先统一单位，再谈成本；结论写成一句可摘的话 + 公式**。范式：「一集 90 秒 = 18 个镜头」（前提：30fps、单镜 ≤5 秒、一镜只放一个动作）→「真正的成本大头不是生成，是重跑」→ `一条成片镜 = 静图定稿 + 视频生成 × N 次重跑` →「54 次生成里 36 次是废的，你花的三分之二买的是"这次又不对"」。
3. **口径打架就两档并列 + 免责声明**：「⚠️ 下面所有数字都是按公开额度口径的推算，不是实测账单……你自己的账户余额才是事实」；数据须标核实时间范围。
4. **栏目化 + 活文档**（短剧自习室的核心打法）：标题带固定栏目名 `短剧周报 |` `短剧拉片 |` `独家 |` `9月海外短剧 |`（国内/海外两套月榜）；以及《短剧出海生态版图》**更新啦｜共收录 90+ 公司，新增 9 家承制方 4 家平台方**——一份资产反复更新反复发，每次重吃收藏与搜一搜。其护城河不是文笔，是「下载骤降 17.8%」这种**只有他有这个数**。
   - 标题通用结构：**疑问句 + 具体数字 + 第一人称实测 + 冒号/括号补充**。例：《AI视频还在充会员？这8家免费额度先领完（附"能跑几条片"折算表）》《实测|对话式创作终结AI短剧旧时代?》。
