# 上海微短剧经费至 11-18：谁能报、上限、硬条件一张表

上海市文化和旅游局《2026年度上海市微短剧发展专项经费项目申报指南》发布于 2026-10-21。线上受理 **10-21 至 11-18**，逾期不予受理；纸质材料 **11-19 至 11-20** 现场递交，不接受邮寄。今天是 11 月 5 日，距线上截止还剩 13 天。

先把结论说清：**300 万是评审上限，不是报名保底**；精品档（含 AI）必须先有上海市《微短剧发行许可证》或节目登记备案号。补贴和过审绑在一起，不能「先领钱后补证」。行业侧电影界 11-01、繁星指数 11-04 仍在提醒窗口未关——增量是窗口仍开，不是新政首发。

## 谁能报？先过主体这一关

指南适用对象：在上海市行政区域内实际从事微短剧产业经营的单位。个人、纯外地主体、只做账号运营没有在沪经营实体的，这一轮不在范围内。

项目完成时间窗口：**2025-10-16 至 2026-10-15**。窗口外完成的项目，这一轮直接出局；现在赶工一部新剧，也进不了本轮统计。

还有两条排除项：同一项目多头申报，或与已获上海市市级财政资金资助的建设内容重复的，不得申报；列入失信联合惩戒名单的，不得申报。

## 各档位：谁能报 / 上限 / 硬条件

| 档位 | 评审上限 | 谁能报（硬条件摘要） |
|---|---|---|
| 精品微短剧（含 AI） | 最高 300 万；宣传上海城市形象、带动文商旅体展联动者可再加 50% | 国内网络视听平台首播；须持上海市《微短剧发行许可证》或节目登记备案号 |
| 微短剧出口创作 | 最高 50 万 | 出口/出海相关创作扶持（细则见指南原文） |
| 厂牌扶持 | 最高 200 万 | 在国内网络视听平台入驻的优质厂牌；年产能≥20 部等条件 3 项及以上 |
| 东方卫视「品质东方・微剧场」首播精品 AI | 每部 1 万；同单位同年最多 3 个 | 须为该栏目首次播出的精品 AI 微短剧 |
| 数字资产库 / IP 库 | 各不超过 50 万 | 按指南对应材料与建设内容申报 |
| 复合型人才培训 | 单课程最高 20 万 | 按参训规模分档；办学许可等材料另核 |
| 入选广电总局「五个一批工程」 | 5 万（免申即享） | 入选即可，不走常规申报 |

【图 1：谁能报 / 上限 / 硬条件】

表里最容易误读的是精品档。**「最高 300 万」是评审结果的天花板**，材料齐了也不等于能拿满；宣传加码 50% 同样要过评审，不是自动加。厂牌档的「年产能 20 部」「日榜前 50 达 5 部」等，是用补贴锁本地工业化产能，不是单部网红项目的安慰奖。一人公司若年产和榜单两项都够不上，别硬冲厂牌档，优先核精品档证号是否齐。

把「财政补贴」和「平台分账」分开看：这里的钱是地方专项经费/奖励，不是 App 投币 IAP 分成。过审证号是入场券，额度是评审结果。

## 一人公司先做什么（按顺序）

1. 核主体：营业执照经营地是否在上海，经营范围是否覆盖微短剧相关业务。不过这一关，后面表格都不用填。
2. 核证：有没有《广播电视节目制作经营许可证》；报精品档的，再核上海市《微短剧发行许可证》或节目登记备案号——没有证号，精品档材料无效。
3. 核项目日期：拟报项目是否落在 2025-10-16 至 2026-10-15；对不上就换项目或放弃本轮。
4. 核档位匹配：单部精品/AI 走精品档；出海走出口档；产能与榜单够硬再碰厂牌档。别用一部剧同时顶多个互斥口径。
5. 再填表、再约审计：专项审计、信用中国报告等材料耗时，先打电话问会计师排期，再排线上提交和 11-19—20 纸质递交。

【图 2：先核主体与许可证，再填表】

线上过了不等于线下能补。纸质材料一式两份、现场交，只有两天五个受理点。两个截止日要分开倒排：11-18 前把线上材料交齐；11-19—20 只做递交，不指望现场现补证。

咨询电话写在指南原文末尾（邹老师、戴老师等），工作日分段受理；厂牌口径、项目认定有疑问，直接打电话，不要自己替官方补定义。

## 边界

指南原文发布日为 2026-10-21；本篇增量是申报窗口仍开（至 11-18）与「谁能报/上限/硬条件」对照复算，不是新政首发。额度均为「最高」评审上限，非保底；须在沪经营主体。本文所称「补贴」指财政专项经费/奖励，勿与 App 投币分账混淆。未代办申报，资格与受理口径以文旅局原文及现场答复为准。
