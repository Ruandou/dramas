# 厂牌实操02｜出图之前：用一页纸把视觉定死

**021 结尾说下一篇拆第 ③ 阶段，这就是那篇。**

七个阶段里只有两个真花钱：第 ③ 阶段（视觉设计）和第 ⑥ 阶段（视频生成）。第 ③ 阶段是第一个开口子的地方，它按张计费，改一次主意就是重出一批图。这篇只讲一件事：怎么在开图之前，用一页纸把方案定死。

## 一、为什么单拎这一阶段

第 ③ 阶段干的是「把文字变成图」：道具图、角色形象图、场景图。参考图 ¥0.72 一张（中转站一口价，001 的成本账里记过）。

按张计费意味着：**方案每改一次，钱就再花一遍。**所以这一步的全部技巧都指向同一件事：让「改主意」发生在文字阶段，别发生在图片阶段。

我现在的做法：出图前先写一页纸的文字设计稿，先看字、确认、再开图。

## 二、顺序不能乱：道具 → 角色 ∥ 场景

三类图不是并列的，中间有一条硬依赖。

- 道具先出：装备、信物、器械这类会被反复拍到的东西；
- 角色和场景后出，且可并行：因为角色图里要握着道具、场景图里要摆着道具，两张图都得引用同一张道具参考图来锁外观。

反过来先出角色图，等道具图出来就会发现：角色手上的东西和道具参考图不是一件。这时要么改角色图（重扣费），要么让后面每一集都别扭。

在我这里是硬门控：**道具没出完、没拿到永久地址，角色和场景不许开工。**

## 三、一页纸里写什么

以角色为例，字段就这几个，可以直接抄：

- 身份与年龄：谁的谁、多大；
- 外形锚点：脸型、发型发色、可辨识特征（疤、痣、眼镜），要能在后面每一张图里被复述；
- 服装与材质：什么料子、什么颜色、新还是旧；
- 年代与地域：哪一年、什么地方，服装款式跟着走；
- 随身物件：与道具 ID 一一对应。

道具、场景同理，字段换成尺寸/材质/磨损、空间结构/光源/季节。

字段多少不重要，重要的是**写完能一句话复述出来**。复述不出来，出图一定漂。

【图 2：一页纸的字段（角色 / 道具 / 场景）】

## 四、四条会白花钱的坑

这四条都是我踩过、写进规则才消停的：

- 场景图和道具图里不许出现人脸。人脸由第 ⑥ 阶段的视频生成单独加；参考图里提前画了脸，成片里就会多出陌生面孔。
- 道具必须绑在具体的物理位置上。只写「桌上的信」，画面可能给你一张贴在胸口的信，我真收到过。要写「握在手里／挂在腰上／摆在桌面上」。
- 中文要写明是简体。只写「Chinese text」，出来的可能是繁体。
- 画面里要出现的文字，必须在指令里完整拼出来（牌匾、标签、书名），不能只描述「一块写着店名的匾」。

【图 3：四条会白花钱的坑】

## 五、还有一层：给脸上叠网格

角色形象图是照片级写实人脸时，视频生成接口会按「疑似输入真人」拒收，不建单但整集停摆（这条我单独写过一篇）。解法是给面部叠一层三角网格，用这版图去提交视频生成。

两条边界：

- 网格版只喂给视频生成；做衍生形象（换装、受伤）时参考图仍传原图；
- 背影、剪影这类没有可见人脸的形象不需要网格，但豁免原因要登记，否则下游会当成缺口重做一遍，又是一笔冤枉钱。

## 六、这一步的账

今天在仓库里数的：参考图 **1831 张**（角色 907，含 205 张网格变体／场景 555／道具 369）。按 ¥0.72 一张算，约 ¥1,300 上下。

这个数在整部剧的现金成本里占比很小（视频生成占九成以上），但返工几乎全发生在这一步：角色脸漂了、道具位置荒诞、场景变体和基准图对不上，每一样都得重出。

所以设计先行的收益不在省第一遍的钱，在省第二遍的钱。

## 七、今天能做的

挑你手上第一个要出图的角色，先写一页纸，别开图：

- 按上面五个字段填一遍；
- 读完出声，看能不能一句话复述；
- 复述得出来再开图；复述不出来就继续改字。

**文字改十遍不花钱，图片改一遍花钱。**
