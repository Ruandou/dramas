# Seedream 5.5 单张约 0.28 元，短剧资产图怎么算

11 月 9 日，字节跳动发布图像模型 Seedream 5.5，豆包、豆包工作、即梦同步接入，API 即将上线火山方舟。新京报、新浪科技和澎湃的报道口径一致：2K 方图编辑单张约 0.28 元，不到上一代 Seedream 5.0 Pro 的一半。官方价目页还没上，这个价格先按媒体口径看。

对做短剧的人来说，这不是「又发了个模型」，而是素材成本单上的一项变了。

## 0.28 元买的是什么

先把口径拆开。计费是「输入图 + 输出图」两段，文本 Token 不计费；0.28 元对应 2K 方图的编辑，也就是带参考图改图，不是所有尺寸、所有任务都这个价。报道只说「不到 5.0 Pro 的一半」，反推上一代单张在 0.56 元以上，具体数字没给。

按 0.28 元算：100 张 2K 参考图 28 元，300 张 84 元，500 张 140 元。一部 80—100 集的剧，角色形象、每套造型、场景基准图和变体、道具图、分镜首帧加起来，通常是几百张的量级，按项目规模差异很大。这个总数在整部剧预算里仍然很小——变化不在「省了多少钱」，在「能多试几版」。

上一代单张贵一倍，团队往往一个角色只出一版，选错再重来；现在同一个角色出 4 版挑 1 版，多出的成本是几毛钱。对角色定妆、场景气氛这种靠试错定方向的环节，差别比省下的钱大。

## 三个新能力，哪个进得了流水线

**透明素材。** 原生支持 RGBA 和分层输出，可以直接出带 Alpha 通道的角色、道具图。合成时少一道抠图，尤其是发丝、道具边缘这种细活。

**多轮编辑。** 报道引述的测试口径是改一处、非编辑区域像素级保持，连续上百轮后主体、构图、光影仍一致。对场景变体（白天/夜晚、开店/封店）和道具状态（新/旧/破损）有用。注意，它保的是「没改的地方」，不等于角色人脸和角度一致性——那还是要靠参考图。

**小字中文。** 小字号中文渲染改善，可用于道具上的标签、信息图。字幕不在这个范围，那是视频模型和后期的事。

## 现在还缺什么

API 还没上线，官方价目页没有，Pro 版也还没发。0.28 元是媒体转述的发布口径，输入图是否另计、失败重试怎么算，报道都没写。真要用，等火山方舟上线后先跑一张对账单：同一张 2K 方图，按平台账单核对单价，再决定要不要批量。

另外，模型升级不等于角色一致性过关。形象一致性、面部一致性靠的是传进去的参考图和提示词，模型只决定生成质量。

## 边界

价格与能力来自新京报、新浪科技、澎湃新闻 11 月 9 日的同场发布报道；官方价目页与 API 尚未上线，未做实测；100/300/500 张与 4 版挑 1 版的换算为本号算术，不含失败重试和人工筛选；不构成采购建议。
