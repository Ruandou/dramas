# 100 家版权方、5000 部 IP：抖音把短剧选题摆上了货架

10 月 27 日，短剧行业媒体「短剧黑马」先报了这条：抖音集团短剧版权中心已合作 100 余家小说版权方，除番茄小说外，汇聚 5000 余部 IP，涵盖七猫小说、豆瓣阅读、17K 小说网等平台。

第二天，21 世纪经济报道（羊城派）把它定性为「面向全行业开放 IP 版权合作」——公告邀请行业 IP 版权方入驻抖音集团短剧创作者中心，洽谈改编合作。

两份报道指向同一份公告。公告的措辞值得停下来看：**它邀请的是版权方，不是制作方。**

这意味着货架确实变长了，但拿货的方式没变：不是制作方进去自助下单，而是版权方先入驻，平台在中间撮合。

## 货架上有什么

把公告里的数摆开：

| 项目 | 口径 |
|---|---|
| 合作版权方 | 100 余家小说版权方 |
| 非番茄 IP | 5000 余部 |
| 点名平台 | 七猫小说、豆瓣阅读、17K 小说网 |
| IP 体裁 | 网络小说、短故事、出版电子书、影视剧 |
| 已改编案例 | 漫剧《我都元婴期了，你跟我说开学》← 看点阅读；真人短剧《重生之嫡女归来》← 趣阅科技 |
| 合作方式 | 版权方入驻，平台撮合，改编、分发、收益全链路 |

5000 除以 100，平均每家 50 部。这是算术平均，不代表单家规模——有的版权方可能只带几部，有的带几百部。

真正值得注意的是「非番茄」三个字。番茄小说本来就是抖音系自己的 IP 池，这次开放的是番茄之外的部分。对制作方来说，选题从一口井变成了一片湖。

## 优先名单写得很具体

公告没有停在「欢迎合作」，它把平台想要什么写成了清单。

男频重点：穿越脑洞、玄幻修仙、都市战神。

女频优先：古代权谋、种田、仙侠团宠、现代言情、家庭伦理。

通用标准三条：主线清晰、人设鲜明、节奏明快；有粉丝基础、热度验证或话题潜力；适合短漫剧改编。

把清单和这三条放在一起看：题材是方向，能照着写；「主线清晰、适合改编」是手艺，能靠改本子去够。只有「有粉丝基础、热度验证」这一条，原创剧本拿不出来。

这是这份公告对一人厂牌最实际的一句话：平台在按「已经被验证过的故事」排序。你写一个新本子，要跟一本已经有几万在读、几千条评论的小说抢同一个位置。

## 三层影响

第一层，找 IP 的入口变多了。

以前想改编，主要看番茄。现在多了七猫、豆瓣阅读、17K 这些平台的货，还有出版电子书和影视剧改编权。题材范围确实宽了——比如豆瓣阅读的悬疑、都市情感，七猫的下沉向言情，都是番茄池子里相对少的方向。

第二层，同一部 IP 会被更多团队看见。

货架是全行业公开的，有热度数据的 IP 会被多组人同时盯上。头部 IP 的授权价和附加条件，大概率往上走。这也解释了平台为什么要做「撮合」：把供给集中起来，才能定价、才能排序。

第三层，原创更吃亏。

不是因为平台排斥原创，而是排序标准里没有给原创留位置。同样的选题会，一个带 47 万在读的原著，和一个只有大纲的原创本子，前者的确定性高得多。平台的采购逻辑是降低不确定性，这跟你的剧本写得好不好，是两回事。

## 想去找 IP，四步

第一步，确认入口和资质。公告说的是抖音集团短剧创作者中心，制作方要在那里看到 IP 库、发起洽谈，通常需要先完成机构入驻和资质审核。这一步的具体界面本号没有登录核实，以平台实际要求为准。

第二步，按两张题材清单筛。不要从「我想拍什么」开始，从「平台优先什么」开始。男频三项、女频五项，先圈定一到两个方向，再在池子里找。

第三步，准备三样材料。一是改编方案，写清主线、人设、前 10 集节奏；二是集数与成本，按你的实际产能报，不要按平台上限报；三是既往作品数据，播放、完播、分账截图，有什么给什么。版权方和平台都在判断一件事：交给你，能不能按时上线。

第四步，把合同五项谈清楚：授权范围（改编权、信息网络传播权、转授权）、期限与地域、是否独家、分成基数（流水还是收入、扣不扣投流）、到期后成片怎么处置。

第三项最容易被忽略。IP 授权到期，成片还在平台上跑，这时候能不能继续挂、要不要续费，合同没写就是麻烦。

## 三个动作

第一，先看货架，再定选题。本周花两个小时把创作者中心里的 IP 库过一遍，按男频、女频两张清单各挑 5 部，记下在读人数和更新状态。

第二，给自己做一张「可改编能力表」。固定五人组、三到五个主场景、单季 100 集的产能——这些数字先写出来，再去谈 IP，比空口说「我能拍」有用。

第三，合同里把「到期后成片处置」写进去。授权三年、成片还在跑，这种错位在短剧行业很常见，提前写清楚，比事后补签便宜。

## 边界

公告原文没有取到，本文依据的是短剧黑马（10-27）、21 世纪经济报道/羊城派（10-28）、网易智能（10-28）三家的转述，三家内容一致。抖音集团短剧创作者中心内的 IP 库界面，本号没有登录核实，入口与资质要求以平台实际页面为准。

「100 余家」是版权方数量，不是 IP 数量；「5000 余部」是非番茄 IP 数量，不含番茄小说自有 IP。平均每家 50 部是本文用 5000 除以 100 得出的算术平均，不是任何一家版权方的实际规模。

「同一 IP 会被更多团队盯上、头部议价上行」「原创更吃亏」是本文判断，不是公告表述。公告只写了优先标准，没有写价格机制。
