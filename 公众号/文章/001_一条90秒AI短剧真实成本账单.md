# 一条 90 秒的 AI 竖屏短剧，真实账单是多少钱？

> 状态：草稿 v2（数字已全部落地，无待补项）。来源：本地任务归档（43 条批量记录 + 两部剧 EP01 的逐段记录）+ 后台账单，口径见文末。配图建议：账单截图（打码）+ 逐段成本表截图。

先给答案：**一集 90 秒，一次全过的出片账单约 ¥73，含返工落在 ¥116~¥208**。对，这个区间宽得可疑，往下看为什么。

## 计费方式和你想象的不一样

我用的是豆包 Seedance 2.0 fast 做视频生成。它不按「每秒画面」收费，按 **token** 收费，单价 **¥0.037/千 token**。

但 token 数不是玄学，是可以提前算出来的。翻我的任务归档，42 条带用量的记录里没有一条例外：

```
token = (时长秒数 × 24帧 + 1) × 900
        └ 24fps            └ 720×1280 ÷ 1024
```

所以 720p 竖屏 24fps 下，**每一秒画面固定烧掉 21,600 token ≈ ¥0.80**。一段 11 秒的镜头 = 238,500 token = **¥8.82**。这是我在提交前就能算出的一段戏的价格。

知道这个数之后，两件事变得非常具体：

1. 你的提示词写得啰嗦不啰嗦、带几张参考图进去，都是要花钱的（这部分按输入 token 另计，归档里没记，所以下面的金额是**下限**）；
2. **多生成的每一秒都在花钱**——不管这段最后留不留进成片。

两条真实账单：

- 一部剧的 EP01，14 段、共 145 秒素材：**3,144,600 token → ¥116.35**（逐段可查）
- 后台账单里的两笔：1,973.7 千 token → **¥73.03**；5,616 千 token → **¥207.79**

按每秒钟 ¥0.80 折算，¥73.03 那笔正好是 **91 秒**的生成量——也就是一集 90 秒**一次全过**的理想账单。¥207.79 那笔折算是 260 秒，是同一批内容连着重roll 的量。

**所以 ¥73 到 ¥208 这个区间不是价格波动，是返工波动。**

## 成本构成：钱都花在哪了

一集 90 秒竖屏短剧，从头到尾巴的账单大致是：

| 环节 | 工具 | 成本 |
|------|------|------|
| 剧本（大纲+分集+分镜） | 多个 AI agent | 对话订阅费内，边际成本≈0 |
| 角色/场景/道具参考图 | 图片生成 | **¥0.72/张**（中转站一口价 $0.10，与尺寸质量无关） |
| 视频生成 | Seedance 2.0 fast | **¥0.80/秒成片**（含返工 1.5~3 倍） |
| 配音 | edge-tts | **免费** |
| 字幕/拼接 | ffmpeg 脚本 | 电费 |
| 素材存储 | TOS 对象存储 | 按量计费，金额小到我没单独查过（以控制台为准） |

参考图这项可以顺手算一遍：一部剧按 50 张参考图算（我某部剧的实际构成是 4 道具 + 36 形象 + 10 场景，其中 18 张是为了绕过人脸过滤而重出的网格版），**整部剧的参考图成本 ≈ ¥36**（一口价折算，实际有部分图走另一个模型，那个没记账）。

对比一下：我归档里最大的一批视频提交是 42 段、447 秒素材，**¥358.64**。也就是说，**一次批量出片的钱 ≈ 整部剧所有参考图的十倍**。

看出结构了吗：**视频生成一项占了 90% 以上的现金支出**。其他环节要么免费要么包月，这是 AI 短剧成本和传统短剧成本最不一样的地方——传统剧组的钱花在人和场地上，AI 流水线的钱几乎全花在「出片」这一下。

## 真正的成本杀手：重roll

账单区间为什么这么宽？因为**第一次提交不等于最后一次提交**。

先说两个我自己被教育过的数字。

第一，那份 EP01 归档里每段**只保留最终成功的那一条**，失败重roll 的 token 根本不在这份账上——所以 ¥116.35 是「不含失败」的下限，我后台看到的 ¥207.79 那种量级才是常态。

第二，同一份归档按 token 反推，14 段一共下单了 **145 秒**，而剧本分段表加起来是 131 秒。多出来的 14 秒是引擎的时长档位造成的（段长会被归到 4~12 秒的整数档），**但它一样收费**。你以为在为 131 秒付钱，实际在为 145 秒付钱。

角色脸漂了、道具平贴进画面、镜头节奏拖长……每一种翻车都意味着那段重新生成、重新扣费。我后来给自己立了几条规矩，全是从账单上学的：

- **写进成本意识的时长红线**：剧本里某镜头 5 秒改 8 秒「凑时长」，视频就会真的拍满 8 秒——多出来的 3 秒是实打实的钱，还是没人爱看的钱。所以规则是禁止纯加秒，时长不达标重写整集。
- **设计先行，看字再出图**：角色/场景图生成前，先用纯文字的设计稿过一遍确认，确认了才扣费出图。文字改十遍不花钱，图片改一遍花钱。
- **增量提交去重**：重跑一集时只提交失败的那几段，已成功的绝不重复提交。

## 那么，一部剧多少钱

现在有单价了，这道题不用猜，直接算：

| 项 | 算法 | 金额 |
|----|------|------|
| 一次全过的理想出片 | 86 集 × 90 秒 × ¥0.80/秒 | **≈¥6,200** |
| 含返工（按 1.6~2.8 倍，即我后台两笔账单对理想值的实际倍率） | ¥6,200 × 倍率 | **¥9,900 ~ ¥17,400** |
| 整部剧参考图 | 50 张 × ¥0.72 | **¥36** |
| 配音/字幕/存储 | edge-tts + ffmpeg + TOS | ≈0 |

所以**一部 86 集竖屏短剧的现金成本在一万上下**，这个数以前对我是个体感，现在是我能复算的数。而且它离「其他微短剧」那条 30 万的投资线还很远——这意味着一个人不需要融资就能把一部剧做完。

顺便说一句：**这个表里没算我的时间**。上面每一行钱都很便宜，真正贵的是我要盯着 9 个 AI 岗位别把它们各自翻车的地方串成一条翻车的流水线。

对照一下行业里一部精品短剧几十万到百万的制作费——这不是「省钱」，这是把入场券的价格打掉了两个数量级。对个人创作者来说，变化的不是成本曲线，是有没有资格坐上牌桌。
