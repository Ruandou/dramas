# Runway 的可灵 4.0 八折：单镜 0.64 美元起，11-30 截止

11 月 3 日，Runway 的定价页更新了可灵 4.0（Kling 4.0）的限时折扣：消费端按 credits 少收 25%，开发 API 八折，截止 11 月 30 日（UTC）。消费端页面把 5 秒 1080p 从 118 credits 划到 89 credits。

**这不是可灵官方降价。** Runway 是转售渠道，折扣只作用于 Runway 的积分；国内可灵的报价另算。先把这一点分清，再决定月底前要不要排渲染。

## 两个积分池，别混着算

Runway 的消费端和 Dev API 不共用积分。App 的 credits 来自订阅套餐，API 的 credits 按 1 个 0.01 美元计费。**同样叫“89 credits”，两边代表的钱不是一回事。**

App 端只给了 1080p、5 秒这一个例子：118 → 89 credits，少收 25%。其它时长和分辨率没有公开对照，不能按比例外推。

Dev API 给的是每秒单价：

- 720p、无输入视频：15.7 → 12.56 credits/秒；
- 1080p、无输入视频：23.5 → 18.8 credits/秒；
- 带输入视频：720p 7.52、1080p 11.28 credits/秒（原价 9.4 / 14.1）。

计费顺序是先按原价向上取整，再打八折，再向上取整。官方文档举的例子是 5 秒 720p、无输入视频，64 credits。

## 单镜成本，按官方取整规则复算

API 的 1 credit 等于 0.01 美元。把每秒单价换成单镜账单：

| 镜头 | 折扣价 | 12-01 起原价 |
|---|---|---|
| 5 秒 720p，无输入 | 64 credits / $0.64 | 79 / $0.79 |
| 10 秒 720p，无输入 | 126 / $1.26 | 157 / $1.57 |
| 30 秒 720p，无输入 | 377 / $3.77 | 471 / $4.71 |
| 5 秒 1080p，无输入 | 95 / $0.95 | 118 / $1.18 |

App 的 5 秒 1080p 是 89 credits，单看 credits 比 API 的 95 少。但 App 积分来自订阅套餐，不能直接按 0.01 美元折算。已经在订阅里、积分用不完的团队，App 更顺手；按量付费、要接流水线的，API 更好核账。

## 带参考视频，账单按“输入加输出”双计

文档写得很清楚：带输入视频时，按输出时长收一遍，再按“输入时长与输出时长中较长的那一个”收一遍。输入视频包括视频生视频的源视频，也包括任何参考视频。

同样是 5 秒 720p 输出：

- 不带参考：64 credits（$0.64）；
- 带 5 秒参考：76 credits（$0.76）；
- 带 30 秒参考：264 credits（$2.64）。

1080p 同理，5 秒输出带 30 秒参考是 396 credits（$3.96）。

这不是小数。**用长片做参考、只出 5 秒镜头，等于为没用到的 25 秒付费。** 月底前要跑参考视频的团队，先把参考剪到和输出等长，再提交。

## 月底前怎么排

折扣截止到 2026-11-30 UTC，原价从 12-01 UTC 恢复。跨月项目要按两段预算：11 月内提交的按折扣价，12 月的按原价。渲染和扣费都在提交时发生，别把“排进 11 月”当成“12 月还能按折扣结”。

可灵 4.0 本身的规格：时长 3—30 秒，自带音频且没有音频开关，竖屏可用 720:1280 / 1080:1920。Runway 的定价页标注价格截至 2026-11-03，月底前可能再变，提交前以页面为准。

## 边界

价格来自 Runway 消费端定价页、Dev API 定价页与 Dev 文档（抓取 2026-11-03，页面标注 current as of November 3, 2026）；折扣截止 11-30 UTC，原价 12-01 UTC 恢复。

本文的美元金额按 1 credit 等于 0.01 美元和官方取整规则复算，未计税费、订阅折扣和失败重试。App 积分来自订阅套餐，不能按 API 的 0.01 美元折算；App 其它时长与分辨率未公开，本文不外推。Runway 是转售渠道，这次折扣不等于可灵官方降价；国内可灵报价另核。大陆团队访问与付款限制未在本文核实。
