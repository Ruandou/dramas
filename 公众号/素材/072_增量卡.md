## 三、增量点

1. **这是 Runway 的渠道折扣，不是可灵官方降价**：只作用于 Runway 积分；国内可灵报价另算。
2. **两个积分池不可互换**：App 积分来自订阅套餐，API 积分按 $0.01/个；App 89 credits 与 API 95 credits 不能直接按美元比较。
3. **把每秒单价换成单镜预算**：5s 720p 无输入 64 credits（$0.64），10s $1.26，30s $3.77；12-01 恢复原价。
4. **参考视频是双计费**：输出收一遍、输入与输出较长者再收一遍；5s 输出带 30s 参考，720p 要 264 credits（$2.64），等于为没用到的 25 秒付费。
5. **月底排期**：11-30 UTC 前提交按折扣，12 月按原价；跨月项目分段预算。

## 四、结构

- 开头：11-03 定价页更新，25% / 八折，截止 11-30；先说明不是可灵官方降价。
- 两个积分池：App 与 API 的来源、计价、示例。
- 单镜成本：按官方取整规则复算 5/10/30 秒。
- 参考视频：双计费规则与 5s/30s 参考的对比。
- 月底排期：11-30 / 12-01 两段预算；模型规格。
- 边界：价格时点、复算口径、App 不外推、渠道限制。
