# 火山引擎发布 Seedance 2.5 flash，火山方舟 API 将于 11-15 14:00 开放

- 抓取时间：2026-11-12 15:38（Asia/Shanghai）
- 层：国内
- 过门状态：已过门（官方文档 + 官方价目页 + 两家独立科技媒体）

## 要点（只写已打开的原文）

- 火山方舟官方文档写明：Doubao Seedance 2.5 flash 模型信息已公开；北京时间（UTC+8）**2026 年 11 月 15 日 14:00** 起，该模型将正式开放在线体验与 API 调用。
- 官方价目页（`docs.volcengine.com/docs/ark/model-pricing`）已列出 `doubao-seedance-2.5-flash`：
  - 按输入是否包含视频区分定价；输出分辨率仅 480p、720p；离线推理暂不支持。
  - 在线推理 token 单价：输入不含视频 **46.00 元/M token**，输入包含视频 **28.00 元/M token**。
  - 价格示例（输入不含视频，16:9，输出 5 秒）：480p 为 2.21 元/个（0.44 元/秒），720p 为 **4.97 元/个（0.99 元/秒）**；1080p 不支持。同表旗舰 `doubao-seedance-2.5` 720p 为 7.56 元/个（1.51 元/秒），4.97/7.56 ≈ 降低 34%。
  - 价格示例（输入包含视频，16:9，输出 5 秒）：480p 为 2.42~9.42 元/个，720p 为 5.44~21.17 元/个（最低对应输入 2~4 秒，最高对应输入 30 秒）；1080p 不支持。
- IT之家 2026-11-12 14:33:05、凤凰网科技 2026-11-12 14:37:27 均转述官方口径：效果最接近旗舰 Seedance 2.5、生成速度提升一倍、720P 文生/图生约 0.99 元/秒（较旗舰低约 34%）；单段最长 30 秒；单次最多 10 张图、5 段视频、5 段音频；480P/720P 两档；即日起将陆续登陆即梦、LibTV、Updream、Creao AI、TapNow 等平台；API 将于 11 月 15 日上线火山方舟。
- 与 14:40 已入库的 BytePlus ModelArk 国际条为同一模型家族的国内通道：国际官方价是美元（720p $0.152/秒示例），国内官方价是人民币。两套价目不要换算混写。

## 写稿必须写明

1. 火山方舟在线体验与 API 要到 **11-15 14:00（北京时间）** 才开放，15:38 采集时还不能调用官方 API。
2. 「即日起将陆续登陆即梦等平台」是媒体转述的官方口径，本轮未打开即梦产品页做实机核验，不得写成「即梦短剧工作室已上新价目」或「即梦已可全量调用」。
3. 0.99 元/秒是官方价目页「输入不含视频、720p、16:9、输出 5 秒」的示例折算，不是对所有宽高比、时长和带参考视频请求的统一方价；带视频输入要走区间价，实际以 API 返回的 `usage.completion_tokens` × token 单价为准。
4. Flash 官方输出档只有 480p / 720p，没有 1080p、没有 4K；旗舰的 Draft / 1080p 能力不要套到 Flash。
5. 这是火山方舟国内人民币价，不是 BytePlus ModelArk 美元价，也不是 LibTV / Updream 等托管或转售价。14:40 已刷过的 LibTV「每秒 ¥0.10」不能代替本条官方价。
6. 「效果接近旗舰、速度提升一倍」是官方表述，本轮未实测。
7. 开通条件仍见官方文档（账户余额 > 200 元，或购买 200 元档及以上节省计划，或已有 Seedance 2.5 系列资源包余量），写稿不要省略门槛。
