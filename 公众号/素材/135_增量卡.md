# 135 增量卡

内容方向：人物公司 / 市场。核心不是复述 B 站增长，而是核对“未受短剧影响”这句话的证据边界，并解释 B 站如何用内容、创作者与用户关系说明自身基本盘。

材料锚点：2026-11-24 B 站 Q3 电话会与官方财报。第一财经 11-24 21:37、澎湃 11-25 17:39 两家独立署名媒体报道了同一场短剧问答；官方财报和电话会书面稿用于公司数字。热度指标未取到，不做热度排名。

本号增量：
1. **分开“平台增长”与“短剧影响为零”**：DAU、MAU、日均时长和总时长创新高，只能证明平台总量增长；若短剧改变的是局部用户或局部时长，总量仍可能上升。公开材料没有用户级迁移、短剧消费前后变化或反事实对照，因此“未受影响”按管理层判断处理。
2. **拆“薯片与米饭”的需求分类**：这个比喻表达的是短内容持续吸引注意力、B 站强调优质内容与用户心智；它是定位，不是用户分组调查。同一用户可以同时使用两类内容，“两个赛道”不等于两组互斥人群，也不等于 B 站没有短剧业务。
3. **用关系数据解释社区留存**：日活跃创作者、日投稿量、人均关注创作者数、月互动量描述持续供给、关注积累和反馈回路。它们可以解释 B 站为何强调不同基本盘，但不能独立证明短剧影响为零。
4. **把广告增长从因果证明里拿出来**：广告收入增长可来自广告主数量、产品效率、投放量与加载率，不能反推短剧没有争夺时间。第一财经所引“增加短剧透出、提高广告加载率”是海豚投研解读，不是陈睿原话。
5. **给短剧创作者一个可执行的判断顺序**：先看用户为什么打开，再看内容能否形成关注与回访，最后分开平台总量和品类迁移，不把“B 站没掉”直接写成“短剧没影响”。

本篇结构：以陈睿的回答开场 → 先校正证据口径 → 解释需求比喻 → 用社区关系数据展开机制 → 排除广告增长的误读 → 回到创作者的判断动作。采用“声明核对 + 机制解释”，不套固定数量观点清单，也不写成财报摘要。

读者收益：能看懂“未受影响”在公开证据上能说到哪一步；能区分平台定位、运营数据与因果证明；准备做 B 站短剧时，可从用户需求、关注关系和统计口径三个层面检查项目。

与上篇差异：133 是模型发布、子榜名次与价格口径核对；134 是人物及角色设计案例；135 是公司战略问答的证据核对与社区机制解释。主体、问题、组织方式和阅读收益不同。
