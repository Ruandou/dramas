# 141 增量卡｜AI 图片与视频官方 API 价格对照

## 六字段

内容方向：把“哪家模型便宜”改写成可复算、可执行的官方 API 价格对照；不是模型口碑榜，也不把 App 会员、套餐、资源包或中转平台混成同一购买条件。

材料锚点：2026-11-27 公开官方价格页与接口文档；只读核查，未注册、充值、购买、提交生成或更换模型。人民币与美元保留原币种，不猜汇率。

本号增量：
1. 图片统一到 1K、2K 输出档；固定尺寸型号按 1024²、2048² 列示，BFL 为约 1MP、4MP 标称像素档且实际尺寸按 16 取整。单列参考图、文本与思考 token 等补算项。
2. 视频以 5 秒输出为示例，逐行标出分辨率、比例、声音、购买方式和优惠条件，再拆开有声/无声、参考视频、首帧、草稿与增强、错峰等差异。
3. 将 Seedance 官方 5 秒示例与 token 公式分开，不把 16:9 示例写成所有竖屏请求的固定每秒价。
4. 将 MiniMax 前 5 张参考图、额外图、输入视频、音频开关与再生成费用写清。
5. 将可灵资源包折算、180 天有效期与 Kling 4.0/4.0 Flash 适用范围写清。
6. 将 Vidu 有声错峰、最长 48 小时、套餐有效期和并发限制写清。
7. 将 Runway 平台内第三方模型价与厂商官方直连价分开。
8. 给出“总账单÷最终可用资产”的团队比价方法，不宣称“全网最便宜”或“同质量最便宜”。

本篇结构：先立比较口径 → 图片规格对照 → 五秒视频条件示例 → 输入/声音/草稿等漏算项 → 套餐与平台边界 → 可执行比价单。

读者收益：拿到一张能追问客服、复算请求、核对账单的条件表，避免只按“每秒几元”或“每张几元”做采购决定。

与上篇差异：140 解决剧本来源与授权；141 解决模型采购价格与可比条件。两篇都不做成投稿目录、主观榜单或付费实测。

## 不能推出的结论

- 不能称任何型号“全网最便宜”；阿里当前页仍列 wanx2.0-t2i-turbo ¥0.04/张。
- 不能称任何型号“同质量最便宜”；本轮没有统一提示词与片段的付费对照实测。
- 不能把限时 7 折、错峰、资源包折算价写成长期无门槛统一价。
- 不能把人民币与美元直接按数字大小比较。
- 不能把 5 秒输出价等同于含输入视频、参考图、草稿、增强和重试的完整请求价。
- 不能把“开放权重”推断为零成本；服务器、运维、排队与重试仍需计入。
- 不能把“支持有声”推断为各档声音都一个价；须以具体型号与官方价格页为准。
