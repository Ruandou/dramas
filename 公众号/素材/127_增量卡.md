# 127 增量卡

外部锚点：抖音集团短剧版权中心 2026-11-12《互动剧及互动影游合作征集》；报名 11-1 至 12-31，单剧最高 20 万保底、30%—50% 额外分成。10 月 19—20 日已有一轮意向征集，11-12 才明确合作模式与激励，不能写“首次开放”。

本号增量：
1. 把官方长文拆成短剧团队能选的三条路：常规合作（30 分钟+，非独家纯分成）、IP 参投（90 分钟+，番茄 IP 免采买或版权费补贴）、精品保底（90 分钟+，只征 10 部，S+/S/A 20/15/10 万）。
2. 说清“30 分钟是含分支总时长，不是主线时长”；90 分钟档同理，只有单线的团队要先补分支。
3. 两项激励：分成额外 30%—50%，投放 30 个自然日内一次性；都要求质量评级，成品须 12-31 前在抖音自营 APP/小程序上线。
4. 与 081 快手「互动掘金」对照：快手 80 分钟、S/A+/A 10/5/3 万；抖音 30/90 分钟、S+/S/A 20/15/10 万，多 IP 参投。两家都写 12-31，但门槛和钱不是一套。
5. 官方文内日期冲突：IP 参投段写 11-1—2027-3-31 上线，文末激励范围又写 12-31 前；正文标明，让读者找商务确认。

本篇结构：官方门槛 → 三条路对照表 → 自我判断表 → 两项激励 → 谁能报/材料 → 截止与坑。标题 23 字《抖音互动剧/影游：20万保底，12月31日截止》，正文约 1,274 汉字，5 个 h2、2 张原生表、6 处加粗、1 个插图锚点、4 条外链。
