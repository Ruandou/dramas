# ONEstore 韩国上线短剧服务 ONEdrama（11-03）

- 抓取时间：2026-11-02 19:35（Asia/Shanghai）
- 事件：韩国应用商店 ONEstore（NCsoft / 넥써쓰体系）宣布于 2026-11-03 在韩国上线短剧服务 ONEdrama（亦称 원드라마）；目标做韩国最大短剧片库，并规划进 iOS / 全球。
- 对制作方：分发 —— 游戏商店内嵌短剧（非独立 App），按回次购买 + 戏剧币 + 周/月/年 Drama Pass；与 ONEstore Point Back 打通（剧订阅可换游戏积分）。韩国本土分发新窗口；条款已公示生效日 11-03。

## NQ Brief（2026-10-30，英文，转引 inews24）
URL: https://nqbrief.com/en/games/one-store-onedrama-launch-ai-games/

要点：ONEdrama 11-03 韩国上线；ONEstore 从游戏向更广内容平台扩张；同期加 AI Games 品类；ONEplay / ONEquest / ONEwave 既有业务。

## ONEstore 官方短剧服务条款（施行日 2026-11-03）
URL: https://m.onestore.co.kr/v2/api/notices/files/download/13510

要点（条款摘录）：
- 세로형 숏드라마；회차 구매或 드라마 패스 재생；예고편免费。
- 결제：드라마 코인（1 코인=1 원）+ ONEstore 결제수단；주간/월간/연간 패스。
- 服务在 ONEstore App 或移动 Web 内提供；同时播放设备 1 台。
