## 本号增量

1. **公告邀的是版权方，不是制作方**：三家报道都写「邀请 IP 版权方入驻」，制作方是货架的使用者，不是入驻者。转述时最容易丢的就是这一句。
2. **「非番茄」是关键词**：番茄是抖音自有池，这次开放的 5000 部是池外增量。选题范围变宽，但入口仍由平台撮合。
3. **优先名单把「已验证」写成了硬条件**：两条通用标准的第二条是「有粉丝基础、热度验证或话题潜力」。原创剧本没有这层数据，排序天然靠后。
4. **平均 50 部只是算术**：5000÷100 不能推任何单家规模，文中已标。
5. **合同最容易漏的是到期处置**：授权到期、成片还在跑，续不续、怎么算钱，公告不会写，只能自己谈。
6. **不并排 3 月的 50 万部漫剧 IP 口径**：入口不同、未核实，全文不引用。

## 结构

钩子（货架变长，但邀的是版权方）→ 货架结构表 → 5000÷100 → 优先名单（两张题材清单 + 三条通用标准，第三条原创凑不出来）→ 三层影响（入口变多 / 竞标变多 / 原创吃亏）→ 找 IP 四步 → 合同五项 → 三个动作 → 边界。
