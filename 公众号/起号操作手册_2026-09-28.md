## 路径 A：注册个体工商户 → 企业主体号（推荐）

### A1 办执照（线上，多数地区 1-5 个工作日）
1. 「国家企业信用信息公示系统」或本省政务服务网/「市场监管」App → 个体工商户设立登记
2. 经营范围建议写得宽（不含前置许可项）：`一般项目：广告设计、代理；数字内容制作服务（不含出版）；信息技术咨询服务；文艺创作；摄影扩印服务`
   - 「数字内容制作服务」正好覆盖 AI 短剧，且无需特殊许可
3. 名称：个体户名称格式「XX市XX区+字号+行业+组织形式」（如「厦门市XX区一格影视工作室」）；字号别和后续公众号名相差太远
4. 住所：无实体店面可用**住宅**（多数地区需社区/物业出具场地证明）或**网络经营场所**（用电商平台店铺网址登记，只能线上经营）；部分园区提供**免费挂靠地址**
5. 拿到执照后 → 刻章（如需）→ 税务登记（30 日内，个体户多为定期定额，小微额度内增值税免征）→ 银行对公户（公众号认证打款验证需要，或走对公认证）
6. **费用**：执照 0 元；刻章约 100-300；对公户各行 0-500/年；整体可控制在几百元内

### A2 注册公众号（实测：个体工商户走「企业」入口，额度 2 个）

**注册入口（已验证可用）**：
```
https://mp.weixin.qq.com/cgi-bin/registermidpage?action=index&weblogo=1&lang=zh_CN
```
选「公众号」→ 主体类型弹窗选**企业** → 三步向导：基本信息 → 信息登记 → 公众号信息。

注册页原文额度：`个人可注册1个账号，个体工商户、企业、其他组织可注册2个账号，政府和媒体可注册50个账号`；选企业后提示 `企业和个体工商户可注册2个账号，请按照营业执照上的主体类型如实选择` → **个体工商户没有独立按钮，走「企业」入口，主体类型如实填个体工商户**。

材料清单：
- 营业执照统一社会信用代码 + 彩色扫描件
- 法定代表人/经营者身份证正反面
- 对公账户（走免费打款验证）**或**选**微信认证 300 元/年**（无对公户时的路径，且拿到名称保护）
- 运营者身份证 + 手机号 + 本人微信扫码
- **全新邮箱**（未被公众平台/开放平台/个人微信号绑定；一个邮箱只能注册一个号）
- ⚠️ 注册地必须选**中国大陆**，页面明示非大陆只支持企业类型**服务号**（订阅号走不通）

详细逐字段见 `注册资料卡_2026-09-28.md`。

### A3 企业主体多出来的能力（为什么值得）
- 微信认证 → 名称保护、搜一搜权重、可信度
- 流量主（企业主体门槛更低、结算到对公）
- 微信支付 / 微信小店 → 剧集周边、模板售卖、付费咨询可闭环收款
