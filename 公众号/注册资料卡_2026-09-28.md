### 9.2 排查顺序（从最可能到最费时间）

1. **个体户没有"法定代表人"，只有"经营者"**。表单在「企业」入口下把字段写成"法定代表人"，正确填法是执照上「经营者」本人的姓名 + 身份证号。若填了其他人（配偶/合伙人/代办人）→ 必然不一致。
2. **逐字核对**：姓名、身份证号、统一社会信用代码是否与执照完全一致（全半角括号、空格、末位 X 大小写）。
3. **拿硬证据**：在「国家企业信用信息公示系统」gsxt.gov.cn 按执照名称/统一社会信用代码查询，确认①已公示 ②经营状态"开业/存续" ③经营者姓名一致。
   - gsxt 查不到或信息不全 → **工商数据未同步到腾讯数据源**，新办个体户常见延迟数日至两周，只能等或改走对公打款。
   - gsxt 一切正常 → 属腾讯侧核验问题，走页面提示的「其他验证方式」。
4. **其他验证方式** = 通常为**对公账户打款验证**（向主体银行账户小额打款并回填金额）。需确认该个体户是否已开对公账户；没有则要么去开，要么回 1-3 找不一致原因。

## 0. 注册入口与额度（实测）

**正确入口**（三步向导：① 基本信息 → ② 信息登记 → ③ 公众号信息）：

```
https://mp.weixin.qq.com/cgi-bin/registermidpage?action=index&weblogo=1&lang=zh_CN
```

页面点「公众号」→ 弹窗「选择主体类型」→ 选**企业** → 确定，即进入第一步。

**额度规则（注册页原文）**：
> 个人可注册 1 个账号，个体工商户、企业、其他组织可注册 2 个账号，政府和媒体可注册 50 个账号。

选「企业」后的提示原文：
> 企业和个体工商户可注册 2 个账号。**请按照营业执照上的主体类型如实选择注册类型。**

→ 结论：**个体工商户走「企业」这个入口**，没有单独的「个体工商户」按钮；执照主体类型是个体工商户就如实填个体工商户。旧号「华华证件照」是个人主体，不占企业额度。

**两个易踩的坑（实测）**：
- ❌ `mp.weixin.qq.com/register` 和 `registerpage?action=show` 这两个 URL 都是 **404 空白页**，别用（我一开始给错了，已纠正）。
- 登录状态不影响注册向导，无需刻意开无痕窗口。但仍建议**用未登录过旧号的浏览器或无痕窗口**，避免混淆两个后台的登录态。

## 1. 第一步「基本信息」真实字段（照抄）

| 字段 | 要求（页面原文口径） |
|------|---------------------|
| 邮箱 | **作为登录账号**，须填写未被微信公众平台、微信开放平台、个人微信号绑定的邮箱 → 点「激活邮箱」收验证邮件，回填 6 位验证码 |
| 密码 | 字母、数字或英文符号，最短 8 位，**区分大小写**；需二次确认 |
| 注册地 | 选**中国大陆**。⚠️ 页面明示：非中国大陆的国家/地区**暂只支持申请企业类型服务号**（订阅号会走不通） |
| 协议 | 勾《微信公众平台服务协议》+《个人信息保护指引》后「下一步」才可点 |

> 邮箱是这一步唯一的硬门槛：一个邮箱只能绑一个平台账号。建议现注册一个专用新邮箱（163 或 Gmail），别用已被旧号占用的那个。

### 1.1 专用邮箱怎么取（163 实测，2026-09-28）

入口：`https://reg.163.com/reg0.shtml` → 三步：填写账号密码 → 验证手机号码 → 完成。

- 账号规则（页面常驻提示原文）：`账号请用字母、数字或下划线命名` → **点号不要用**；密码 8-16 位，需含大小写字母、数字、符号
- 后缀可选 `@163.com` / `@126.com` / `@yeah.net`，同一账号名可同时给出三个后缀
- 候选：账号名 = 号的拼音（`@163.com`），实际采用哪一个记在本地凭据文件里
- 注册需手机号 + 短信验证，**只能本人操作**；密码也不要交给助手代填
- ⚠️ **163 免费邮箱连续 90 天未登录会被冻结**（网易帮助中心官方口径，需通过 web 端 `mail.163.com` 登录自助解冻）。这个邮箱是公众号的**登录账号**，被冻结=账号进不去。对策二选一：① 手机日历设每月一次的登录提醒；② 改用自建域名邮箱或企业邮箱（更稳，但要花钱/要维护）
- 邮箱到手后**直接用于公众平台注册**，中途不要拿去绑个人微信、开放平台、小程序——一旦绑定就不满足「未被绑定的邮箱」要求

### 6.1 为什么是暖炭底而不是纯黑（实测依据）
