## 1995 年代禁忌（Era Prohibition）

> 所有角色出图、分镜均须遵守，违反即返工。

### 禁止出现（Negative Prompt 必加）

| 类别 | 禁止项 |
|------|--------|
| 通讯 | 智能手机、触屏设备、现代笔记本电脑、蓝牙耳机 |
| 屏幕 | 液晶平板电视、LED 显示屏、高清摄像头 |
| 服饰 | 2000 后潮牌（Supreme、Off-White 等）、低腰牛仔裤、运动紧身裤、AirPods |
| 交通 | SUV、新能源车、现代高铁内饰 |
| 城市 | 高层玻璃幕墙写字楼、地铁站（非一线城市）、连锁咖啡店 |
| 发型 | 韩式刘海、挑染、脏辫 |

### 允许 / 推荐（Positive Prompt 参考）

| 类别 | 推荐项 |
|------|--------|
| 通讯 | BP 机（传呼机）、公用电话亭、座机、大哥大（少量） |
| 电器 | CRT 电视、录像机、卡带随身听、台式风扇 |
| 交通 | 桑塔纳、捷达、吉普 212、二八自行车、绿皮火车 |
| 服饰 | 皮夹克、格子衬衫、高腰西裤、白色背心、军绿大衣 |
| 场景 | 砖混楼房、水泥公路、国营工厂、菜市场、录像厅 |
| 警务 | 83 式 / 早期 99 式警服、老式警棍、五四手枪、手铐 |

### Negative Prompt 通用后缀

```
smartphone, touchscreen, LED screen, modern laptop, SUV, glass curtain wall,
Korean hairstyle, streetwear brand logo, flat screen TV, HD webcam,
modern subway station, chain coffee shop, wireless earbuds
```

## 【角色卡】陆峥（男主）· `CHAR-001`

### 基础信息

| 字段 | 内容 |
|------|------|
| **角色 ID** | `CHAR-001` |
| 姓名 | **陆峥** |
| 年龄 | 25 岁（重生后外表）/ 45 岁（前世心理年龄） |
| 身份 | 警校毕业生 → 城南派出所民警 → 借调刑侦科 → 下放乡镇 → 联合专案组副组长 → 刑侦支队长 |
| 性格标签 | 沉稳、克制、有手段、不服输、内敛深情 |

### 外貌特征

- 身高体型：178cm，精干有力，常年锻炼但不壮硕
- 发型发色：90 年代短平头 / 板寸，黑色
- 面部特征：线条硬朗、目光深邃，比同龄人成熟
- 服装风格：深色皮夹克 + 高腰西裤（日常）→ 83 式警服（执勤）
- 配色：黑、深蓝、军绿
- **年代禁忌**：禁韩式发型、禁品牌 LOGO 外露

### 性格详解

- 核心：45 岁灵魂住在 25 岁躯壳里；对 1995 年即将发生的大案了然于心，用信息差+判断力碾压
- 内心锚点：林栀的安全是唯一软肋——前世没保护好她，这辈子绝不再犯
- 职场观：不争一时，争一世；不抢功，让领导有功，让同事有参与感
- 破案哲学：系统给线索，判断靠人；人永远比系统重要
- 习惯：沉默审视、翻旧卷宗、提前布局

### 经典台词

1. "我不是来破案的，我是来改变规则的。"
2. "我已经让你出过事了，这辈子不会再有第二次。"
3. "系统给的是参考，不是定论。"
4. "警察这行，不是为了破案，是为了让人不用害怕。"
