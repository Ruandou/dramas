> 更新日期：2026年4月4日

## 术语使用规范

本文档遵循「中文优先、避免夹杂」原则：

| 规范 | 说明 |
|------|------|
| 中文为主 | 优先使用中文术语，如"分镜"、"旁白"、"转场" |
| 英文为例外 | 仅在中文无对应准确词汇时使用英文，如"Prompt"（提示词）、"AI"（人工智能） |
| 禁止混杂 | 禁止在同一文档内中英混杂，如"生成Prompt"、"做剪辑" |
| 混排原则 | 全中文段落不加英文，全英文段落不加中文 |

**示例对比：**

| 推荐写法 | 不推荐写法 |
|----------|------------|
| 文生图 | 文字生成图片 |
| 图生视频 | 图片转视频 |
| 提示词 | Prompt |
| 人工智能生成 | AI生成 |

## 一、流程总览

```
┌─────────────────────────────────────────────────────────────┐
│                     AI短剧制作五大阶段                         │
├─────────────────────────────────────────────────────────────┤
│  第一阶段    第二阶段    第三阶段    第四阶段    第五阶段      │
│  前期准备    素材生成    后期制作    发布运营    迭代优化      │
│   (1-3天)    (核心)     (1-2天)     (每日)      (持续)      │
└─────────────────────────────────────────────────────────────┘
```

| 阶段 | 耗时 | 核心产出 |
|------|------|----------|
| 第一阶段：前期准备 | 1-3天 | 角色卡、分镜脚本、风格指南 |
| 第二阶段：素材生成 | 3-7天/集 | 视频片段、配音、背景音乐 |
| 第三阶段：后期制作 | 1-2天/集 | 成片（带字幕+音效） |
| 第四阶段：发布运营 | 每日 | 平台上传、标题优化、封面设计 |
| 第五阶段：迭代优化 | 持续 | 数据分析、策略调整 |

## 三、第二阶段：素材生成

### 3.1 文生图（角色/场景素材）

#### 素材生成规范（必须遵循）

**人物素材生成规则：**
- 构图：正面全身照（Full body shot, front view）
- 背景：白色或纯色背景，无干扰元素（plain white background, no background distractions）
- 去除干扰：不允许任何背景物体、装饰、抽象元素
- 肢体正确：必须明确注明"TWO normal arms and hands"和"anatomically correct human figure"，防止多手/多余肢体
- 人物居中：角色位于画面中央，占据主体位置
- 女性角色通用特征：每位都要有身材曲线、暴露服装（深V、露肩、露背）

**Prompt默认模板（人物）：**
```
Front view full body shot of [角色描述],
standing centered on pure white background,
TWO normal arms and hands, anatomically correct human figure,
no background, no decorations, no abstract elements, clean studio shot,
女性角色附加：[curvy figure, large bust, deep V-neckline, off-shoulder design, revealing shoulders and back],
high detail, 8k
```

**⚠️ 生成女性角色时，"女性角色附加"中的描述必须全部加入Prompt，不得省略。**

**场景素材生成规则：**
- 构图：根据分镜需求选择合适镜头（wide shot/medium shot/close-up）
- 氛围：符合剧本风格定位
- 避免干扰元素：移除无关物体

#### 核心工具

| 工具 | 适用场景 | 优劣势 |
|------|----------|--------|
| Midjourney | 高质量角色图、电影感场景 | 质量高、成本高、需要付费 |
| Stable Diffusion | 批量生成、风格控制 | 免费、本地部署、学习成本 |
| Flux | 文字生成图片的新秀 | 细节好、正在发展中 |
| DALL-E 3 | 快速原型、概念验证 | 出图快、质量稳定 |

## 五、第四阶段：发布运营

### 5.1 平台适配

| 平台 | 视频比例 | 最佳时长 | 封面要求 |
|------|----------|----------|----------|
| 抖音 | 9:16（竖屏） | 1-3分钟/集 | 文字+人物+高能画面 |
| 快手 | 9:16（竖屏） | 1-3分钟/集 | 人物特写+大字标题 |
| 视频号 | 16:9或9:16 | 1-3分钟/集 | 简洁+剧名+集数 |
| B站 | 16:9（横屏） | 3-5分钟/集 | 封面标题+剧名 |

### 5.2 标题公式

```
## 抖音/快手标题模板
1. 悬念型："外卖小哥穿越天庭，第一天上班就懵了..."
2. 冲突型："高冷嫦娥遇上嘴贱外卖员，谁先心动？"
3. 猎奇型："天庭临时工月薪一万功德点，我要去！"
4. 情绪型："打工人狂喜！终于有人把我们的苦说出来了"

## 视频号标题模板
1. 直接型："《天庭临时工》第1集：入职天庭"
2. 悬念型："第1集 | 送外卖送到天庭是什么体验？"
```

### 5.3 封面设计

```markdown
## 封面设计要素
1. 核心人物（占画面60%以上）
2. 高能画面/表情（惊讶/开心/搞笑）
```
