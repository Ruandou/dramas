# 短剧剧本·新选题（日常向 · 四部）

> 2026-05-25  
> 定位：**正常人、正常事、能笑着看完**——不悬疑、不收骨、不失忆证词、不失踪妹妹  
> 节奏：轻喜 / 轻情感 / 小温暖，每集 2–3 分钟

---

## 四部速览

| 剧名 | 类型 | 一句话 |
|------|------|--------|
| 《我哥搞装修》 | 都市 / 兄弟 / 轻喜 | 白领弟弟嫌弃干装修的哥哥，直到哥哥接了自己公司的活 |
| 《早点见》 | 都市 / 家庭 / 温暖 | 爸走了，兄弟俩必须一起把早点摊开满早高峰 |
| 《快递站下午见》 | 都市 / 群像 / 轻喜 | 小区快递站，取件的人各怀心事，站长都记得 |
| 《教练别加练了》 | 都市 / 职场 / 轻喜 | 健身房新人教练，学员没一个「正常」但都挺可爱 |

# 一、《我哥搞装修》

## 类型
都市 · 兄弟 · 轻喜剧 · 单线无后宫

## 一句话
弟弟 **周扬** 在写字楼当人事，总嫌哥哥 **周磊** 干装修「不体面」——直到公司要翻新整层办公室，中标的是周磊的小队，还是周扬负责对接。

## 人物

| 人物 | 是谁 |
|------|------|
| **周扬** | 28，人事，要面子，嘴硬 |
| **周磊** | 32，装修工长，话少手巧，宠弟但不会说 |
| **刘姐** | 周磊搭档，电工，吐槽担当 |
| **苏青** | 周扬同事，设计，慢慢看上的是「做事靠谱」不是头衔 |
| **周妈** | 在老家，电话里只会问「你哥吃饭没」 |

## 为啥正常还能看 36 集
不是逆袭打脸，是 **弟弟从嫌弃到服气**、哥哥 **不用变成白领也被尊重**。每集一个工地/办公室小状况，最后全家吃顿饭。

## 分集（1–12）

| 集 | 发生啥 | 钩子 |
|----|--------|------|
| 1 | 周扬公司要装修，招标 | 名单里有个「磊磊装修队」 |
| 2 | 周扬想划掉哥哥名字 | 老板：「这家便宜靠谱，就他。」 |
| 3 | 兄弟俩工地见面，周扬装不认识 | 刘姐：「这不你弟吗？」 |
| 4 | 周磊按要求改方案，被周扬同事挑刺 | 周磊连夜改，一句抱怨没有 |
| 5 | 周扬发现哥哥睡建材城地板 | 「你怎么不住酒店？」「省钱给你妈寄。」 |
| 6 | 装修砸到承重墙，周磊叫停 | 周扬第一次在会议上站哥哥 |
| 7 | 周扬帮哥哥讨工程款 | 人事嘴皮子第一次用在「自家人」上 |
| 8 | 苏青跟周扬说：「你哥那队人，挺护短。」 | 周扬愣住 |
| 9 | 周妈来城里看进度 | 只认儿子穿工服的手，不认西装 |
| 10 | 弟弟醉后：「哥，我挺你。」 | 周磊：「知道了，明早六点来刷墙。」 |
| 11 | 竣工，公司表扬周扬「找的队伍好」 | 周扬把奖金划给哥哥一半 |
| 12 | 兄弟俩吃路边摊 | 周磊：「下回别瞒着我是你弟。」周扬：「下回你报价别这么低。」 |

**后面 13–36**：接别的小活、周扬辞职帮哥管账（可选）、苏青线、周妈养老、**没有仇人，没有系统**。

# 二、《早点见》

## 类型
都市 · 兄弟 · 家庭 · 小温暖

## 一句话
老周家的 **「老周早点」** 开了二十年，爸突然住院——哥哥 **周早** 想卖摊，弟弟 **周晚** 刚被裁员，两人得一起 **把明早六点的包子蒸出来**。

## 人物

| 人物 | 是谁 |
|------|------|
| **周早** | 35，开过小超市，务实，想卖摊换爸手术费 |
| **周晚** | 30，前公司运营，嘴碎，不会蒸包子 |
| **老周** | 爸，住院，电话里只问「今天豆浆稠不稠」 |
| **张婶** | 对面煎饼摊，老邻居，刀子嘴 |
| **小满** | 常来写作业的小学生，固定坐 corner 桌 |

## 分集（1–12）

| 集 | 发生啥 | 钩子 |
|----|--------|------|
| 1 | 爸倒下，摊子在，债也在 | 周早：「卖了吧。」周晚：「爸醒来要骂。」 |
| 2 | 第一次兄弟俩开摊 | 包子全漏馅，队排老长 |
| 3 | 张婶来救场教发面 | 「你们爸当年比这强。」 |
| 4 | 周晚用「运营」搞排队取号 | 大爷不会用手机，差点打起来 |
| 5 | 小满说「我想天天来，妈夜班」 | 兄弟俩决定留 corner 给小孩 |
| 6 | 有人想高价收店面 | 周早心动，周晚反对 |
| 7 | 爸出院一天，偷偷来摊边坐 | 只吃了半个包子：「还行。」 |
| 8 | 周晚搞「会员充卡」 | 张婶：「小周你别把早点搞成互联网。」 |
| 9 | 充卡反而周转开了 | 爸手术费凑齐一半 |
| 10 | 周晚想回职场，早高峰缺人 | 周早一个人蒸了三笼 |
| 11 | 周晚辞职留下 | 「哥，我早上起得来。」 |
| 12 | 摊牌改招牌：**「老周早点 · 早晚都在」** | 爸打电话：「豆浆再稠一点。」 |

**13–36**：四季来客（外卖员、夜班护士、吵架情侣和好），**每集一个熟客小故事**，兄弟俩偶尔拌嘴，不虐。

# 三、《快递站下午见》

## 类型
都市 · 群像 · 轻喜剧 · 女主也可拍（站长性别可换）

## 一句话
小区门口的 **快递代收点**，站长 **老许** 记住每个取件人的习惯——谁总在下午三点来、谁从不拆包装、谁帮邻居代拿。**包裹不大，人情很大。**

## 人物

| 人物 | 是谁 |
|------|------|
| **许站** | 32，站长，前物流分拣，记性好 |
| **阿花** | 兼职，大学生，八卦但善良 |
| **陈伯** | 退休，每天来「取件」其实是聊天 |
| **林姐** | 全职妈妈，常帮全楼代拿 |
| **小陆** | 夜班程序员，只有凌晨和下午在 |

## 为啥正常
没有凶案、没有秘密组织——就是 **小区里的琐碎 kindness**：错拿、代签、滞留件、给老人念单子。

## 分集（1–12）

| 集 | 包裹/事 | 钩子 |
|----|---------|------|
| 1 | 双 eleven 爆仓 | 许站睡店里，阿花来帮忙 |
| 2 | 陈伯的「件」其实是空盒 | 儿女寄的，让他有理由下楼 |
| 3 | 林姐代拿全楼，被误会偷件 | 许站调监控还她清白 |
| 4 | 小陆的件被错给邻居 | 里面是给女友的求婚戒指 |
| 5 | 许站骑车追还戒指 | 求婚成功，全站免代签一天 |
| 6 | 滞留三个月的件，收件人搬家 | 许站根据旧习惯找到新地址 |
| 7 | 阿花把客户信息发群 | 许站罚她手写道歉信 |
| 8 | 暴雨淹站 | 邻居自发帮搬，陈伯第一个到 |
| 9 | 有人投诉「许站多管闲事」 | 其实是许站拦下了诈骗件 |
| 10 | 公司要撤点换智能柜 | 全小区联名留许站 |
| 11 | 许站留下，降一点提成 | 「柜子是冷的，站是热的。」 |
| 12 | 周年，许站请常来客吃西瓜 | 小陆：「我搬走了还寄这。」许站：「下午见。」 |

**13–36**：每集一个取件人小故事，可穿插许站为啥从物流辞职（被冤枉一次，想做个「让人放心拿件的地方」）。

# 四、《教练别加练了》

## 类型
都市 · 职场 · 轻喜剧

## 一句话
健身房新人教练 **陆燃**，证书刚到手，分到的学员：**怕水的CEO、想打败儿媳的阿姨、偷练想 surprise 男友的女孩、还有只来洗澡的大爷**——没有一个冲肌肉，全冲 **各自的小目标**。

## 人物

| 人物 | 是谁 |
|------|------|
| **陆燃** | 25，教练，认真到有点轴 |
| **店长老K** | 只关心续课率，口头禅「加一组」 |
| **学员群** | 每 2–3 集重点写一个，不吓人 |
| **苏姐** | 前台，帮陆燃挡奇葩合同 |

## 分集（1–12）

| 集 | 学员线 | 钩子 |
|----|--------|------|
| 1 | 陆燃第一天，被分到「体验课垃圾桶」 | 阿姨：「小伙子，我想游泳赢儿媳。」 |
| 2 | 阿姨其实怕水 | 陆燃陪她在浅池练憋气 |
| 3 | CEO 来减压，电话不断 | 陆燃收他手机一小时，CEO睡着的 |
| 4 | 女孩偷练，男友也是会员 | 男友其实也在偷练 surprise 她 |
| 5 | 两人同时在馆，差点撞见 | 陆燃打掩护 |
| 6 | 大爷只来洗澡被投诉 | 陆燃发现大爷是帮老伴来占优惠卡 |
| 7 | 老K 逼陆燃卖年卡 | 陆燃给阿姨退了不需要的课 |
| 8 | 阿姨家庭赛，和儿媳平手 | 两人一起请陆燃吃饭 |
| 9 | CEO 续课，说「这是唯一没会议的一小时」 | 陆燃没卖课，CEO 自己续了 |
| 10 | 陆燃被投诉「不专业」 | 学员集体写好评 |
| 11 | 老K 升陆燃带「常规课」 | 陆燃：「我还是想带怪人。」 |
| 12 | 新学员进门：「教练，我想请假。」 | 陆燃：「别加练了，先说说你想干啥。」 |

**13–36**：轮换学员，陆燃慢慢学会「健身不是折磨人」；可有一条轻感情线（苏姐或某学员，**不狗血**）。
