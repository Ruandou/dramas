## 【角色卡】李天（主角）

### 基础信息
| 字段 | 内容 |
|------|------|
| 姓名 | 李天 |
| 年龄 | 26岁 |
| 身份 | 外卖小哥 → 天庭临时工 → 外卖总管 |
| 性格标签 | 乐观、机智、嘴贱但心善、打工人 |

### 外貌特征
- 身高体型：175cm，普通身材，偏瘦
- 发型发色：短发，深黑色，略带自然卷
- 面部特征：单眼皮，眼睛有神，嘴角常带笑意
- 服装风格：外卖员制服（黄蓝配色）→ 天庭临时工制服（白色锦袍）→ 外卖总管（黑色官服）

### 性格详解
- 核心性格：表面嬉皮笑脸，内心善良有原则
- 行为习惯：骑电动车飞快、习惯看手机接单、爱吐槽
- 说话语气：轻松调侃、带点北京腔、语速较快
- 口头禅：
  - "这算哪门子..."
  - "我一个凡人..."
  - "让我想想..."

1. "外卖送到魔界6号门，永生糕一份，签收"
2. "我是送外卖的，没有送不到的东西"

### 表情参考
- 开心时：眯眼笑，露出大白牙
