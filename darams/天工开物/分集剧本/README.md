# 分集剧本目录

> **正名**：《天工开物之匠魂》  
> 每集一个文件；分镜表含 `CHAR` / `SCENE` / **时长·模式·运镜**（Seedance）。模板见 [`_模板.md`](./_模板.md)。

## 修改顺序（勿跳步）

1. **主剧本** → [`../短剧剧本_天工开物_36集_改造方案.md`](../短剧剧本_天工开物_36集_改造方案.md)（剧情与对白要点）  
2. **本目录** → `EP##_*.md`（分镜 + 对白/备注）  
3. **导出** → `python3 script/storyboard_to_seedance.py EP##` → `EP##_shots.yaml` / `.json`  
4. **段落** → 编辑 `EP##_segments.yaml`（与 md 对齐）  
5. **其它** → 声音卡、制片规范、`assets/` 等  

详见 [`../制片规范.md`](../制片规范.md) §3.1。

## 文件命名

```
EP##_集名.md
例：EP01_机械之魂.md
```
