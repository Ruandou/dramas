现代机械工程硕士魂穿明末将门遗孤——没有金手指，只有脑子里扎实的机械原理知识。他直接把珍妮纺纱机的完整图纸和原理搬进古代，用曲柄连杆改进织机，用水力驱动建立古代第一条生产线，用传动链原理实现古代机械化大生产，最终掀起一场古代工业革命。

## 世界观设定

- **时代背景**：明朝天启年间，魏忠贤把持朝政，东林党与阉党之争，民生凋敝，但江南手工业繁荣
- **核心矛盾**：传统手工业效率低下，织工生活艰苦；新式机械威胁传统利益集团
- **三大势力**：
  - 朝廷阉党（魏忠贤、崔掌班）
  - 传统织坊主（曹老板等）
  - 东林党（徐书生、吴卿云父亲）
- **主线**：男主从一台珍妮纺纱机起步，逐步建立天工坊，最终用技术改变一个时代

### 第1集：机械之魂

**【时长】约3分钟**

**【场景1】明朝·宋家破旧屋内（夜·1分30秒）**

```
画面：苏州城内一间破旧老屋，昏暗油灯
音效：远处更鼓声，隐约可闻市井喧嚣
```

宋应星（古装，虚弱地睁开眼）：这是……哪里？

他看到自己枯瘦的手腕、破旧的衣衫——脑海中闪过现代记忆碎片……

门外传来苍老女声：应星，你醒了？

宋母（55岁，面容憔悴）推门而入，手里端着药碗

宋母：（激动）三天了，你昏迷了三天！娘以为你也要丢下娘了！

小翠（18岁，丫鬟，眉眼清秀）紧随其后

小翠：少爷！您终于醒了！

宋应星：（看着陌生的环境，内心独白）我……穿越了？

他尝试坐起，浑身酸软无力

**【闪回画面1：原主】**

```
画面：破旧书房，满地书本
一个瘦弱青年趴在桌上打呼噜，口水浸湿书页
窗外小贩叫卖：卖糖葫芦咯——
```

旁白：这具身体的原主人——同名同姓的宋家少爷。科举落榜三次，每日睡到日上三竿，醒了就往街上溜达。写得一手烂字，四体不勤五谷不分。小翠伺候他十年，他连人家名字都记不住。街坊叫他"废物宋"。

**【闪回画面2：父亲】**

```
画面：特写——角落挂着一把精铁大锤
锤柄上刻着四个字："匠心独运"
```

旁白：但原主的父亲宋铁山，是将门之后、军中第一工匠，替东林党造过弩机。后被阉党诬陷通敌，下狱而死。宋家从此一蹶不振。

宋母：（扶住他）别动，先把药喝了

**【场景2】宋家纺织房（日·1分30秒）**

```
画面：简陋纺织房，小翠在纺纱
脚踩踏板，手捻纱线，满头大汗
```

宋应星站在门口，看着小翠忙碌的身影

纱线突然断裂

小翠：（叹气）又断了……

宋应星走进纺织房，仔细观察传统纺纱机的结构

小翠：（苦笑）少爷，您不懂。纺纱这活，急不得躁不得。

宋应星看着小翠满是茧子的手，心中一动

宋应星：（内心独白）这法子，太笨了……如果有更省力的办法……

他眼睛一亮，似乎想到了什么

宋应星：（内心独白）珍妮纺纱机……如果能在这里实现……

### 第3集：设计珍妮

**【时长】约3分钟**

**【场景1】宋应星书房（晨·1分钟）**

```
画面：简陋书房，宋应星伏案绘画
桌上摆着笔墨砚台，他正在纸上绘制精密的机械图纸
```

宋应星笔下渐渐显现一台复杂的纺纱机——八根纱锭排列在锭架上，传动系统清晰可见

宋应星：（标注）锭距相等，转速同步，齿轮减速比1:3……

小翠送茶进来，看到满桌图纸

小翠：少爷，您一晚上没睡？

宋应星：（揉了揉眼）脑子里全是这机器，停不下来。

**【场景2】宋家院中（日·1分钟）**

```
画面：宋应星用木板和绳子搭建简易模型
小翠蹲在一旁好奇观看
```

宋应星用木板制作了一个简易的八锭锭架模型，用绳子模拟传动

宋应星：（拉动手柄）关键在于这个传动轴——踏板带动主轴，主轴通过齿轮组同时驱动八个锭子。

模型试转，锭子开始旋转

小翠：（瞪大眼睛）真的在转！

宋应星：但还差关键一步——锭子上下运动时要自动捻纱。

**【场景3】宋应星书房（夜·1分钟）**

```
画面：油灯下，宋应星盯着画了一半的图纸
眉头紧锁
```

宋应星：（低声自语）传统纺纱，锭子只转不上下……

他放下笔，另取一张纸重新画过

宋应星：用凸轮控制纱线输送节律！

他飞速画图，眼睛发亮

宋应星：（独白）珍妮纺纱机的核心是八个锭子同时旋转，通过齿轮组保证转速一致……关键是纱线张力要均匀


小翠：少爷，这位吴姑娘说是从苏州城里来的……

吴卿云：（拱手）宋公子，家父与令尊曾是旧识听闻宋公子如今继承父业，在纺织机上颇有研究，特来拜访。

**【场景3】宋家院中（日·1分50秒）**

```
画面：吴卿云蹲在模型旁，仔细观察结构
宋应星警惕地看着她
```

吴卿云：（指着模型）这个设计……一个人能同时纺八根纱？

宋应星：正是。

吴卿云：（震惊）八根？（抬头看宋应星）你可知这意味着什么？

宋应星：效率提升八倍。

吴卿云：（微微一笑）我听父亲说过，令尊当年是军中第一工匠……没想到，公子继承了这份手艺。

宋应星：（有些意外）吴姑娘认识家父？

吴卿云：（轻声）小时候见过一面……令尊给我父亲修过织机，父亲至今念念不忘。

她看着眼前的纺纱机，若有所思

吴卿云：（低声）有点意思……

她转身走向门口，在门槛处顿了顿，回头看了宋应星一眼，微微一笑，转身离去

### 第7集：投产

**【时长】约3分钟**


**【场景2】宋家后院炉旁（日·1分钟）**

**【场景3】宋家纺织房（日·1分30秒）**

```

宋应星、小翠、宋母三人围着机器
```

宋应星：（深吸一口气）第一次试车。

小翠：（紧张地盯着）转了！
