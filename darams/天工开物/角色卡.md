## 【角色卡】宋知行（男主）· `CHAR-001`

### 基础信息
| 字段 | 内容 |
|------|------|
| **角色 ID** | `CHAR-001` |
| 姓名 | **宋知行**（避历史人物宋应星；寓意「知行合一」） |
| 年龄 | 27 岁（外表），实为现代机械工程硕士穿越 |
| 身份 | 将门遗孤之子 → 天工坊主 → 工部额外委官（无品级，专司纺织与火器改进） |
| 性格标签 | 沉稳、专注技术、感情迟钝、经世致用 |

### 外貌特征
- 身高体型：175cm，清瘦有力量感
- 发型发色：明代束发，乌黑整齐
- 面部特征：剑眉、眼神沉静专注
- 服装风格：破旧布衣 → 工匠长袍 → 无品级官服（简洁，非高官蟒袍）
- 配色：靛蓝、灰、黑

### 性格详解
- 核心：古人躯壳里的现代机械思维；技术决策时偶有 0.5 秒现代闪回（全剧 ≤6 次）
- 习惯：炭笔绘图、拇指食指「卡尺」手势测零件
- 语气：沉稳简洁；偶说「效率」等词后改口「工效」
- 标志道具：父亲遗留精铁大锤，锤柄刻「匠心独运」

### 经典台词
1. "三日后，我亲自登门还债。再有人踏入宋家一步——犹如此砖。"
2. "机巧之道，万变不离其宗。纺纱与射击，皆在「传动」二字。"
3. "若为名利，臣早将图纸售于商贾。"
4. "机器还没跑热，仗就来了。"
