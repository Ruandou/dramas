## 一、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| **角色** | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| **形象** | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可 |
| 场景 | `SCENE-###` | `SCENE-002` | 布景 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 道具 | `PROP-###` | `PROP-001` | 精铁大锤 |

- 编号**只增不删**；弃用标 `deprecated: true`。  
- 新建角色：先 `资产/角色索引.md`，再建 **`L01` 基础形象**于 `资产/形象索引.md` + `角色卡.md`。  
- 新建换装/阶段：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。

### 1.1 形象 ID 与基础 / 衍生

| 后缀 | 名称 | 要求 |
|------|------|------|
| **L01** | 基础形象 | 完整定妆 Prompt（脸、体型、发式、默认服装）；全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | **必须** `based_on` 本角色 `L01`；Prompt 只写差异，并含 `same face as CHAR-xxx-L01` |

**出图流程**：定稿 `L01` 参考图 → 衍生形象用图生图 / 角色一致性模型 → 禁止跳过 L01 直接生成 L02。

## 二、分镜中的引用语法

### 2.1 场景列

必须使用场景 ID，禁止只写模糊地点：

```markdown
| 镜号 | 场景 | … |
| 3 | `SCENE-001` | … |
```

同一镜内换场：拆成两镜，或备注 `SCENE-001 → SCENE-002`。

### 2.2 角色列与形象列

分镜表字段见 [`分集剧本/_模板.md`](./分集剧本/_模板.md)（含 **shot_id、时长、模式、运镜**）。

| 列 | 填写 | 说明 |
|----|------|------|
| **角色** | `CHAR-001` | 逻辑角色；对白、表演归属 |
| **形象** | `CHAR-001-L01` | 本镜视觉；出图读此 ID |
| **时长** | `4`–`6` 或 `skip` 填 `-` | → Seedance `duration` |
| **模式** | `i2v` / `i2v_ref` / `t2v` / `skip` | → `content[]` 结构 |
| **运镜** | 固定镜头、镜头推近… | → `content[].text` |

- 多人：角色列 `CHAR-001`,`CHAR-004` · 形象列 `CHAR-001-L01`,`CHAR-004-L01`  
- 画外音：角色列 `CHAR-009`(VO) · 形象列 `-`  
- 仅一张脸的角色：形象列可写 `-`（工具默认解析为 `L01`）  
- 群演：`CHAR-GRP-01` / `CHAR-GRP-01-L01`

### 2.3 对白中的角色

对白行首标注说话人 ID：

```markdown
**CHAR-001**：三日后，我亲自登门还债。
**CHAR-004**(哭腔)：少爷，家里只剩一贯钱了……
```

### 2.4 解析约定（工具/AI 流水线）

| 模式 | 含义 |
|------|------|
| `` `CHAR-001` `` | 必填，链接到角色索引 |
| `` `SCENE-002` `` | 必填，链接到场景卡片 |
| `【SCENE-002】` | 场景标题行（分场剧本用） |
| `@CHAR-001` | 与反引号等价，**分镜表统一用反引号** |

## 五、与 AI 出图/视频的衔接

1. 分镜 **`场景`** → `场景卡片.md` → `SCENE-###`  
2. 分镜 **`形象`** → `形象索引.md` → `角色卡.md` 内该 **L##** 的 Prompt  
3. **L01**：用「基础 Prompt」生成 Character Sheet（正面全身，白底）  
4. **L02+**：`based_on` 指向 L01 参考图 + **delta Prompt**（仅服装/道具/妆效/伤痕）  
5. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01  
6. 分镜 **`角色`** 列仅用于对白表，不参与出图 Prompt 拼接

## 六、年代与美术

1. **服饰、场地**须符合 [`资产/年代美术规范.md`](./资产/年代美术规范.md)；戏内年月见 [`历史年表.md`](./历史年表.md)。  
2. 分镜 **场景** 必须引用 `SCENE-*`，且该场景卡片含 **年代**（`era`）字段。  
3. 分镜 **形象** 必须引用 `CHAR-*-L##`，服装阶段与角色卡 L01/L02+ 一致。  
4. **穿越闪回**仅 `SCENE-004`；导出/API 文本**不得**对闪回镜追加「无现代物品」（见年代规范第五节）。  
5. 新建 `SCENE-021+`：先写布景 + `era`，再写分镜。  
6. 扩写前可运行：`python3 script/validate_era.py`

## 七、有声段落（Seedance 2.0 · 默认）

详述：[`docs/Seedance2_有声段落流水线.md`](./docs/Seedance2_有声段落流水线.md) · 声音：[`资产/声音卡.md`](./资产/声音卡.md)

1. **提交单位**：`EP##_segments.yaml` 中每条 `segment_id`（约 10–12 秒），非一镜一任务。  
2. **音频**：`generate_audio: true`；对白与 **voice_prompt** 写在 `api.text`；试点可不挂 `reference_audio`。  
3. **画面**：段落仅用 `looks/` + `scenes/`；不依赖镜级首帧。  
4. **一段一落音**：单段主说话人 ≤2；长对手戏拆成 `SEGxxa` / `SEGxxb`。  
5. **音色文案**：同一角色跨段 **voice_prompt 全文一致**（如宋知行：「成年男性，27岁，沉稳偏低，语速中等，短句干脆」）。  
5.1 **旁白**：时间线、集末第三人称钩子统一 **`NARR-001`**（见 [`资产/声音卡.md`](./资产/声音卡.md)）；`segments.yaml` 的 `voice_prompts.NARR-001` 与 `api.text` 内旁白句**逐字相同**；勿用「沉稳男声」或男主声线念钩子。  
6. **验收**：试跑段（如 EP01 SEG04b + SEG06b）跨段耳听；**SEG02 + SEG07** 旁白跨段耳听；漂移再补 `assets/voices/*_ref.wav`。  
7. **成片**：`assets/generated/EP##/` 下 `EP##-SEG*.mp4`；集级可选 `script/ffmpeg_concat_episode.sh`，**不用剪映**。  
8. **段落时长（API）**：`duration_sec` 对 **fast** 只能 **4–12**（硬限制）。  
9. **合理分段（制片）**：  
   - **一条 API = 一段可拍的戏（约 4–12 秒信息密度）**，不是「一镜一条」。  
   - 分镜表里某镜自然时长 **&lt; 4 秒**（旁白、字卡、闪回 0.5–2 秒、`skip`）：**并入同场景相邻段**，在 prompt 里写为「镜头 N（2 秒）…」，**不要**单独开段并把 API 时长硬设为 4 秒（会多生成无效画面/时长，同样浪费）。  
   - 拆段边界：场切换、主说话人切换、情绪断点；不要按每个 `shot_id` 机械切。  
   - 提交前：`python3 script/storyboard_submit_segments.py EP## --check-only`（会提示「建议合并」的薄段）。

### 7.10 道具转移与肢体动作（防错清单）

适用：抄道具、挥武器、递交信物等 **「谁碰什么」** 明确的镜（如 EP01 S16–S18 抄锤）。  
案例：[`assets/generated/EP01/trial_notes.md`](./assets/generated/EP01/trial_notes.md)（锤变大、打手误抄锤）。

#### 常见模型错误

| 现象 | 原因 |
|------|------|
| 道具尺度漂移 | 远景小、近景大；prompt 写「大锤」；无 `PROP-*` 参考图 |
| 配角先动手 | 上一镜配角对白，下一句「抄起/挥向」未绑 **图1 主角**；两男同框动作归属模糊 |
| 段内跳切不连贯 | prompt 写成镜头清单，各镜各画，不保证同一把道具、同一人 |

#### 分段原则（先于 prompt）

- **同一场戏、同一道具动作链** → **一条 segment**（如 S15–S18），勿拆成 a/b 两条 API 任务。  
- 对白镜与动作镜在同一 segment 时：**对白者 ≠ 动作者** 必须在下一句写清（例：图2 嘲讽 → **图1** 抄锤）。  
- 单段 **≤1 句对白**；复杂肢体段尽量少人同框。

#### `api.text` 写法（强制）

1. **段首「角色分工」**（早于镜头列表）：谁可碰道具、谁 **禁止**（例：仅图1 宋知行可握锤；图2 打手双手不得拿锤）。  
2. **每镜绑 `图N` + 服装色**：用 `图1`/`图2`，不用泛称「男主」「打手」；`content_roles` 顺序与全文一致（**图1 = 动作主角**）。  
3. **道具锁定**：可比对尺度（锤头 ≈ 人头、木柄齐腰）；禁止堆「大锤」；写「同一把、勿因近景放大」。  
4. **因果链叙事**，非 Excel 清单：  
   `图2 嘲讽 → 图1 看墙角锤（无人碰）→ 图1 独自抄起 → 图1 挥向图2`  
5. **关键镜重复约束**：抄起、挥击镜再写一次「图1 双手握柄 / 图2 不伸手」。

#### 参考图

| 资产 | 路径 | 用途 |
|------|------|------|
| 定妆 | `assets/looks/CHAR-*-L01.png` | 脸与服装 |
| 场景 | `assets/scenes/SCENE-*.png` | 空间 |
| 道具 | `assets/props/PROP-*-*.png` | 尺度与造型锚点（见 [`assets/props/README.md`](./assets/props/README.md)） |

高难动作（抄锤、挥击）：可对对应 `shot_id` 另做 **镜级首帧**（仅主角握道具），再段落生成；成本多一步，角色最稳。

#### 提交前检查（人工，约 1 分钟）

- [ ] 段首是否有 **角色分工 + 对手禁止碰道具**？  
- [ ] 每句「抄起/挥/递」是否带 **图N**？对白说话人是否被误写成动作者？  
- [ ] 道具动作链是否 **未拆段**？`duration_sec` 是否 4–12？  
- [ ] `content_roles` 图1 是否为 **剧本上的动作者**？  
- [ ] 有 `PROP-*` 时是否已出图并挂入 `content_roles`？

#### 下载后验收（再 concat 前）

只审三类：**谁拿道具、道具比例、说话人**；有问题 **只重跑该 segment**，勿整集重烧。

#### `segments.yaml` 模板片段（抄锤类）

```yaml
api:
  text: |
    【图1】宋知行·男主（靛青布衣）【图2】恶仆打手（深灰短褐）【图3】SCENE-002
    角色分工：仅图1可碰锤；图2禁止握锤/抄锤。
    道具：全程一把锤，锤头≈人头、木柄齐腰，禁止变大。
    图2近景对白「……」图1在后景，无人碰锤。
    图1看墙角同一把锤（无人拿）；图1独自抄起；图1挥锤擦图2头皮砸门框。
    …
content_roles:
  - { file: CHAR-001-L01, role: reference_image, label: 图1 }
  - { file: CHAR-GRP-01-L01, role: reference_image, label: 图2 }
  - { file: SCENE-002, role: reference_image, label: 图3 }
```
