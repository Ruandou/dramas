## 目标流水线

```
分镜 EP##_*.md
    → shots.yaml（镜级，已有）
    → segments.yaml（段落，待建）
         speakers + voice_refs + 多镜头 prompt
    → Seedance API（有声 + reference_audio）
    → assets/generated/EP##/EP01-SEG04.mp4 …
    →（可选）ffmpeg concat → EP##_full.mp4
    → 任务归档 assets/generated/EP##/tasks.json（方案 A，见 assets/TASKS.md）
```

### 分段原则（比 API 下限更重要）

| 做法 | 说明 |
|------|------|
| **推荐** | 同场景多镜合并为 **4–12 秒** 一段；prompt 内分配「镜头1（4秒）…镜头2（2秒）…」 |
| **避免** | 仅 2–3 秒内容的镜（S09 时间旁白、短闪回）**单独成段**且 `duration_sec: 4` —— API 会拍满 4 秒，节奏空、费用空 |
| **API 下限** | fast 最短 4 秒是**平台限制**；不满足时应**合并分镜**，不是把薄内容撑到 4 秒 |

示例：EP01 已将原 `SEG02b`（仅 S09 旁白）并入 `SEG02`（S07–S09，12 秒一条）。

## 声音一致性（路线一）

**试点（当前）**

- 每段 `api.text` 内嵌 `voice_prompt` + 对白，例如：`对白（宋知行，成年男声沉稳偏低）：「放开她。」`  
- **不提交** `reference_audio`  
- 验收：SEG04 + SEG06（宋知行）跨段耳听  

**补锚点（漂移时）**

- `assets/voices/CHAR-xxx_ref.wav` + segment 挂 `reference_audio`（见声音卡）  

**制片**：一段一落音；多人长对白拆段

## 道具与动作段（防尺度漂移 / 角色绑错）

详 **[`制片规范.md` §7.10](../制片规范.md#710-道具转移与肢体动作防错清单)**。摘要：

| 要做 | 不要做 |
|------|--------|
| 抄锤/挥武器等 **整条动作链一条 segment** | 对白段与抄道具段拆成两次 API |
| 段首写 **图1 可碰 / 图2 禁止碰** | 只写「抄起大锤」不绑图号 |
| 每镜 `图N + 动词`；服装区分两男 | 镜头1/2/3 清单式罗列 |
| `PROP-*` 参考图 + 固定比例（锤头≈人头） | 堆「精铁大锤」、无道具图 |
| 下载后审 **谁拿道具** 再 concat | 有问题整集重烧 |

EP01 范例：`EP01-SEG05` · 道具图说明 [`assets/props/README.md`](../assets/props/README.md)

## 风险

| 风险 | 缓解 |
|------|------|
| 跨段音色漂移 | reference_audio + 固定锚点文件；试跑对比 |
| 多镜跳切 | 段内 ≤3–5 镜；同场景同 refs |
| 口型不准 | 减少段内台词密度；关键台词单独成段 |
| 时长非法 | `duration_sec` 须在 **4–12**（fast）；`--check-only` 拦截 |
| 薄段浪费 | 镜级自然时长合计 &lt;4s 却单独成段 → `--check-only` **警告合并**（勿硬凑 4s） |
| **道具变大 / 配角误动作** | §7.10：分工句、图N 绑动作、`PROP` 参考图、动作链不拆段 |
