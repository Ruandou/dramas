## 1. 目录约定（只认本剧 `assets/`）

```
darams/天工开物/assets/
├── looks/              # 定妆（段落 reference_image）
├── scenes/             # 场景空景
├── props/              # 道具参考（可选，如 PROP-001 大锤）
├── voices/             # 声音锚点（可选）
├── tasks_seedream.json # Seedream 出图任务
├── tasks_jimeng_*.json # 即梦（若走 volc-jimeng）
├── tasks_kling.json    # Kling（若用）
└── generated/
    └── EP01/
        ├── EP01-SEG01a.mp4   # 段落成片（与 segments.yaml 的 segment_id 同名）
        ├── EP01-SEG01b.mp4
        ├── …
        ├── EP01_full.mp4     # 集级顺接（ffmpeg -c copy）
        ├── concat_list.txt     # 上次拼接列表（脚本生成）
        ├── tasks.json          # 本集 Seedance 任务（方案 A，与 mp4 同目录）
        └── trial_notes.md      # 试跑/验收备忘（可选）
```

| 类型 | 命名 | 谁生成 |
|------|------|--------|
| 段落 | `EP##-SEGxx.mp4` | `storyboard_submit_segments.py --download` |
| 集级 | `EP##_full.mp4` | `script/ffmpeg_concat_episode.sh EP##` |
| 任务 | `tasks.json` | 提交/下载时自动写入 `project_task_archive` |

**禁止**：向 `generated/` 写入占位条、纯色测试，或与正式 `EP##-SEG*.mp4` **同名** 覆盖（真素材难恢复）。实验输出用 `_scratch/` 或改名，勿占 segment 正式名。

**Git**：`*.mp4` 已 ignore，**不进仓库**；进 Git 的是 `EP##_segments.yaml`、`tasks.json`、文档。

## 3. 标准流程（一集）

### 3.1 提交前

```bash
python3 script/storyboard_submit_segments.py EP01 --check-only
```

- 定妆/场景文件齐全  
- 每段 `duration_sec` 在 **4–12**（fast）  
- 薄镜已并入邻段（见制片规范 §7.9）  
- 道具/动作段符合 §7.10（抄锤等）

### 3.2 生成段落（可单段重跑）

```bash
# 只跑一条（修 C 段抄锤等）
python3 script/storyboard_submit_segments.py EP01 \
  --segment EP01-SEG05 --submit --wait --download

# 全集（慎用，扣费）
python3 script/storyboard_submit_segments.py EP01 --submit --wait --download --skip-existing
```

落盘：`assets/generated/EP01/EP01-SEG05.mp4`，并更新同目录 `tasks.json`。

### 3.3 拼集级成片

```bash
bash script/ffmpeg_concat_episode.sh EP01
# → assets/generated/EP01/EP01_full.mp4
```

顺序来自 **`分集剧本/EP01_segments.yaml`** 的 `segment_id` 列表，不是磁盘上文件排序。

### 3.4 下载后验收（再 concat 前必做）

```bash
ls -lh assets/generated/EP01/EP01-SEG*.mp4
```

| 检查项 | 正常 | 异常 → 动作 |
|--------|------|-------------|
| 单段体积 | 多数 **数 MB** | **数 KB** → 勿 concat，重下或重跑该段 |
| 镜数对齐 | 与 `segments.yaml` 条数一致 | 缺段 / 多余旧 `SEG05a` → 删列表外文件或重跑 |
| 剧情 | 谁拿道具、对白、尺度 | 有问题 → **只重跑该 segment** |

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 \
  assets/generated/EP01/EP01_full.mp4
```

表头 `duration_min: 3` 是目标；**当前分镜+段落合计约 1.5–2 分钟** 属规划问题，需 **加分镜/加段**，不是多拼一次能拉长。

## 4. 任务与成片对照

```bash
python3 ../../mcps/volc-ark/scripts/project_task_archive.py list \
  --project-root . --episode EP01
```

`tasks.json` 字段：`task_id`、`segment_id`、`status`、`local_mp4`、`video_url`（如有）。

丢文件时：用 `task_id` 调 MCP `ark_seedance_download` 或 CLI `ark_seedance_video.py download`（URL 约 24h 有效）。

## 5. 修订与版本习惯

| 操作 | 做法 |
|------|------|
| 修某段剧情/穿帮 | 改 `EP##_segments.yaml` → 只 `--segment` 重跑 → 再 `ffmpeg_concat` |
| 保留旧版对比 | 复制为 `EP01-SEG05_old.mp4`，**不要**改正式 segment 文件名 |
| 废弃段落 | 从 yaml 删除；磁盘旧 mp4 可手动删，避免误写入 concat |
| 试跑记录 | `generated/EP01/trial_notes.md`（声音、抄锤等问题） |

---

## 6. 时长规划（制片）

| 层级 | 文件 | 作用 |
|------|------|------|
| 镜级 | `EP##_shots.yaml` | 自然时长合计（有效镜约 80–90s） |
| 段落 | `EP##_segments.yaml` | API `duration_sec` 合计（约 100s） |
| 成片 | `EP##_full.mp4` | 顺接后实际秒数 |

要做 **~3 分钟/集**：在 `EP##_*.md` / `shots.yaml` **增加镜或加长关键段**，再拆成更多 4–12s 的 segment，而不是提高 concat 次数。

---

## 7. 与其它目录的边界

| 目录 | 用途 |
|------|------|
| `configs/seedance_requests/` | dry-run 请求 JSON（含 base64，gitignore） |
| `assets/keyframes/` | 镜级旧流程首帧（段落流程不依赖） |
| 仓库 `video/ark_tasks/` | **遗留**；新任务只用本剧 `assets/**/tasks*.json` |

错嫁等其它剧路径不同，**不要**把天工段落 mp4 写到 `video/generated/` 或错嫁 `素材/generated/`。
