# 场景卡片（SCENE-*）

> 分镜引用：`` `SCENE-###` `` · 语法见 [`../制片规范.md`](../制片规范.md)  
> **年代 / 布景约束**：见 [`年代美术规范.md`](./年代美术规范.md)

## 字段模板（新建 SCENE 必填）

| 字段 | 说明 |
|------|------|
| **年代** | `era`：`ming_tianqi` · `ming_chongzhen_court` · `ming_miao_village` · `modern_flashback_only` |
| **布景** | 具体道具清单 |
| **场景 Prompt** | 英文空景，`no people`，含 **Ming dynasty** 等地域词（闪回除外） |
