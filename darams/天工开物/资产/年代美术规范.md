## 二、服饰分层（按身份）

出图、分镜「形象」列须对应 [`形象索引.md`](./形象索引.md) 的 **L##**；换装只加 L02+，脸与 L01 一致。

| 身份 | 形制要点 | 配色 | 年代禁忌 |
|------|----------|------|----------|
| **工匠 / 庶民**（宋知行 L01、打手、街坊） | 明代交领、束发（顶髻 + 木簪）；布衣宽袖；布履 | 靛蓝、灰褐、黑 | 禁西装、领带、拉链、运动鞋、棒球帽、牛仔裤 |
| **织造千金**（吴卿云） | 明代闺秀高髻 + 玉簪；绸缎襦裙、披帛可选 | 淡紫、藕荷、白 | 禁深V、露背、露肩、网文仙侠风；**覆盖**全局流程「女性深V」 |
| **丫鬟 / 女技师**（小翠） | 双髻或简单发髻；棉布襦裙 | 浅蓝、灰绿 | 同上；禁现代校服、短裙 |
| **将门遗孀**（宋母） | 朴素发髻；褪色靛青长衫 | 灰、靛青 | 禁华丽凤冠、清代旗装 |
| **商人 / 债主**（曹德源） | 明代富商深色袍、腰带、钱袋 | 深褐、黑 | 禁清代马褂立领、西式怀表链特写 |
| **太监**（崔掌班） | 明代宦官灰黑袍；无清代顶戴花翎 | 灰、黑 | 禁把清代蟒袍、补子当明代用 |
| **权阉**（魏忠贤） | 戏剧化紫黑袍；**Ming Chongzhen era eunuch minister** | 紫、黑 | Prompt 须带 **Ming**；禁清代官帽、辫子 |
| **秦淮 / 书坊**（董小婉） | 明代歌姬 / 后期素雅书坊装 | 白、淡粉 | 禁唐代齐胸过度暴露、现代晚礼服 |
| **苗寨**（红玉） | **Miao ethnic Ming era** 猎装、银饰、猎刀 | 红、蓝 | 与汉装场景区分；禁现代运动装 |
| **工部委官**（宋知行 L03） | **无品级**简素官服；无蟒袍、无高阶补子 | 深青、黑 | 禁明清混淆的「红袍进士」「一品蟒袍」 |

**L02+ 规则**：Prompt 只写与 L01 的服装 / 道具 / 伤痕差异；须含 `same face as CHAR-xxx-L01`。

## 三、场地与布景

分镜 **场景列** 必须写 `` `SCENE-###` ``，详情见 [`场景卡片.md`](./场景卡片.md)。新建场景必填：

| 字段 | 要求 |
|------|------|
| 内外 / 时段 | 内/外、日/夜/黎明 |
| 布景 | 具体道具清单（木床、纺车、铁砧…） |
| **年代** | `era: ming_tianqi`（苏州民居 / 街市）或 `era: ming_chongzhen_court`（京城宫廷） |
| 场景 Prompt | 英文空景，`no people`，含 **Ming dynasty** / **Suzhou** 等 |

### 3.1 区域速查

| 区域 | 应有元素 | 禁止 |
|------|----------|------|
| **苏州** 宋家 / 院落 | 青砖院、木窗纸、手摇纺车、铁砧、蚊帐木床 | 玻璃幕墙、路灯、汽车、电线杆 |
| **苏州** 街市 | 木铺面、街坊、简易招牌（无清晰汉字） | 霓虹、英文店招 |
| **京城** 午门 / 大殿 | 见 `SCENE-014`–`016`；红墙金瓦、明代宫廷 | 清宫戏典型雕栏过度、太和殿牌匾清晰文字 |
| **苗寨** | 竹楼、缫丝工具 | 现代塑料大棚 |

### 3.2 新建场景标签

| `era` 值 | 含义 |
|----------|------|
| `ming_tianqi` | 天启年间苏州及江南 |
| `ming_chongzhen_court` | 崇祯年间京城宫廷 |
| `ming_miao_village` | 明代背景苗寨 |
| `modern_flashback_only` | **仅** `SCENE-004` 类穿越闪回 |

## 四、穿越闪回白名单

现代画面**仅**允许下列形式；与 [`改造方案`](../短剧剧本_天工开物_36集_改造方案.md) 2.3 节频次一致。

| 场景 ID | 内容 | 时长 | 提示词后缀 |
|---------|------|------|------------|
| **`SCENE-004`** | 运动手表、键盘、图书馆珍妮机图、实验室虚影等 | ≤0.5–1s，叠化 / 虚焦 | 用 **闪回后缀**（见下），**禁止**「无现代物品」 |

**全剧穿越符号上限**（编剧须登记集号）：

| 符号 | 上限 |
|------|------|
| 电子表 / 现代残影闪回 | ≤6 次 |
| 图纸叠加阿拉伯数字 / 公式 | 重大突破时，约 4 次 |
| 卡尺手势 | 3 次 |
| 现代词卡顿（效率→工效） | ≤5 次 |

**分镜写法**：闪回镜场景列写 `` `SCENE-004` ``（可叠 `` `SCENE-001` `` 等古代底景）；模式可用 `t2v` 或 `i2v` 叠化。

## 五、AI 提示词后缀（Seedance / 即梦）

| 类型 | 后缀（中文可并入 text） |
|------|-------------------------|
| **明代主戏**（默认） | `明代苏州，天启年间，古风写实，电影感竖屏9比16，无现代物品，无清晰汉字` |
| **闪回**（`SCENE-004` 或画面含「闪回」） | `flashback overlay, soft blur, 0.5 second cut, cinematic, vertical 9:16, no readable text` — **不含**「无现代物品」 |

导出脚本 [`storyboard_to_seedance.py`](../script/storyboard_to_seedance.py) 按场景 ID 自动选择；手工写 prompt 须遵守上表。

## 六、统一 Negative Prompt

**英文**（复制到 Seedream / Seedance / 即梦）：

```
modern objects, smartphone, wristwatch, smartwatch, glasses, sunglasses, zippers,
baseball cap, sneakers, neon sign, English text, watermark, logo, cartoon, anime,
low resolution, deformed hands, extra fingers, deep V-neck, off-shoulder, exposed back
```

**中文**（可选）：

```
现代物品，手机，手表，眼镜，拉链，运动鞋，霓虹灯，英文，水印，卡通，动漫，
低清晰度，畸形手，多指，深V，露肩，露背
```

## 七、扩写 / 出图前检查（3 条）

- [ ] 每镜 **场景** 在场景卡片存在，且 `era` 非 `modern_flashback_only`（闪回镜除外）
- [ ] 每镜 **形象** 的 L## 服饰符合本集戏内阶段（如 L01 破旧布衣 vs L03 官服）
- [ ] 闪回仅用 **`SCENE-004`**，且 API text **无**「无现代物品」

本地校验：`python3 script/validate_era.py`
