# 声音卡（CHAR-* · 音色锚点）

> **版本**：v1.0 · 2026-05-20  
> **策略**：**路线一** — Seedance `generate_audio: true` + `reference_audio`；全剧不换锚点文件。  
> **画面**看 [`形象索引.md`](./形象索引.md) / 定妆；**声音**看本表 + `assets/voices/`。

---

## 使用规则

### 试点阶段（当前）：**仅提示词，无 reference_audio**

- 段落 `api.text` 里写清 **`voice_prompt` + 对白原文**（见下表「EP01 试点」）。  
- **不**要求 `assets/voices/*_ref.wav` 已存在；提交体**不**挂 `reference_audio`。  
- 验收：同角色跨 2 段（建议 SEG04 vs SEG06）耳听；若音色漂明显，再进入「补锚点」阶段。

### 补锚点阶段（漂移不达标时）

1. 每个**有对白的主角色**至少一条参考干声：`assets/voices/{CHAR-ID}_ref.wav`（或 `.mp3`）。  
2. 参考音频：**10–20 秒**、无 BGM、无混响、单说话人、情绪中性偏本剧常用。  
3. 提交段落 API 时：`content[]` 挂 `role: reference_audio`，并与 `voice_prompt` 一致。  
4. **一段一落音**：一个 segment 主说话人 ≤2；长对手戏拆段，避免单条里 4 人轮流长台词。  
5. **画外 VO**（如 `CHAR-009`(VO)）：与出镜可共用同一 `CHAR-009` 锚点；若仅画外，仍挂该角色 reference。  
6. 群演 `CHAR-GRP-*` 可共用模板音，不必每人一条。  
7. **跨集不得更换** `_ref` 文件；换音色视为换演员，须新开 `CHAR-xxx-v2_ref` 并注明剧情原因。

### 制作参考干声（任选其一）

| 方式 | 说明 |
|------|------|
| 真人录 | 读下方「锚点台词」2–3 句，导出 48kHz mono WAV |
| 一次性 TTS | 仅用于生成锚点，不进入成片；选定后固定，不再改 voice |
| 试跑截取 | 某次满意的 Seedance 段落提取对白轨（风险：首段质量绑定全剧） |

## 字幕 + 旁白（字卡镜）

- **对白段**：角色配音 + 画面简体底字幕（与引号一致）。  
- **字卡镜**（如 S09/S26）：**NARR-001 念旁白 + 画面简体字幕同句**（声画字幕一致）。  
- **无对白段**（SEG01a）：无旁白、无字幕。

## 与 segments.yaml 的字段（计划）

```yaml
speakers: [CHAR-001]
voice_refs:
  CHAR-001: assets/voices/CHAR-001_ref.wav
api:
  text: |
    … 对白（宋知行，男声沉稳）：「放开她。」
```

脚本已支持：`storyboard_submit_segments.py` / `ark_seedance_video.py segments` 读取 `voice_refs` 并挂 `reference_audio`（文件存在时）。
