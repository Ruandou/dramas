## 立项一句话

明末机械硕士，用一台八锭纺车还清赌债，却把「传动」做成了连发火铳与蒸汽流水线——他要的不是当圣人，是让织工的手少长一层茧。

## 全季结构（1–36 集）

### 前半段（1–30 集）·绝境到赐名

**主线**：纺纱机 → 水力织机 → 阉党博弈 → 连珠铳 → 魏忠贤倒台 → 赐名「天工开物」→ 蒸汽机试车。
**第 30 集转折**：辽东急报（机器未跑热，仗已至）。
**感情线**：吴卿云唯一女主；董小婉、红玉功能性盟友，第 29 集分工明确。

| 章       | 集数  | 一句话                         |
| -------- | ----- | ------------------------------ |
| 绝境求生 | 1–5   | 穿越、还债、开业、首抓         |
| 商业萌芽 | 6–10  | 牢狱、水力机被夺               |
| 势力博弈 | 11–15 | 秦淮情报、东林、崔掌班收网     |
| 绝境联盟 | 16–20 | 苗寨、劫狱、火器萌芽           |
| 反击前夜 | 21–25 | 残图进京、董小婉重伤、夜袭工坊 |
| 终极对决 | 26–30 | 魏倒、赐名、蒸汽、军情         |

### 后半段（31–36 集）·工业黎明

**主线**：炼钢 → 标准化产线 → 山海关 → 蒸汽运输车 → 决战 → 五年后彩蛋。

详见改造方案「第十章」及 [`历史年表.md`](./历史年表.md)。
