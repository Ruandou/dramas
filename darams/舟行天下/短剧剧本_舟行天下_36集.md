## 一句话简介

现代航母舰船工程师穿越到明朝，成为被流放的造船世家遗孤。凭借超前千年的船舶知识，他打造无敌舰队，开辟海上贸易帝国，在权谋与海战的风浪中，携多位红颜逆袭人生。

## 世界观设定

- **时代背景**：明朝永乐年间，郑和下西洋之后，航海贸易蓬勃发展
- **核心矛盾**：朝廷虽然下西洋，但民间航海仍被限制；沿海世家垄断造船与贸易
- **三大势力**：
  - 朝廷（支持开海 vs 保守派）
  - 沿海世家（控制船坞、港口、贸易）
  - 海上势力（海盗、走私商、倭寇）
- **主线**：男主从一艘小船起步，逐步垄断海上贸易，对抗沿海世家，最终获得皇家支持

### 第1集：渔家女

**【时长】约3-5分钟**

**【场景1】现代·深海潜器内（日）**

```
画面：深潜器在漆黑的海底缓缓下潜，仪表盘显示深度3000米
音效：金属嘎吱声、压力警报
```

林海（28岁，现代航母工程师，穿潜水服）：稳住！目标深度到了。

同事：林工，脐带缆出问题了吗？动力在下降！

林海：启动备用电源。我去看看——

画面：深潜器剧烈晃动，海水涌入舱门

林海：（推开同事）你先走！我来断后！

同事：林工！

林海：（按下紧急上浮按钮）活下去……替我把数据带回去……

画面：深潜器爆炸，火光在海底绽放

**【场景2】明朝·押送船舱内（夜）**

```
画面：昏暗的船舱，手腕被铁链锁住
```

林远舟（26岁，古装，虚弱地睁开眼）：（内心独白）这是……哪里？

记忆闪回：现代画面与原身记忆交融——他穿越到了明朝，成了被流放的林家独子

原身记忆：父亲是郑和宝船首席工匠，被权贵诬陷流放，郁郁而终

押送官（门外）：明天就到岭南了，这小子活着也是受罪。

另一人：周家交代了，路上"出点意外"很正常。

林远舟：（内心独白）周家……灭我林家的周家！

**【场景3】押送船甲板（深夜·风暴）**

```
画面：狂风巨浪，船身剧烈摇晃
```

押送官：稳住！把货物绑好！

林远舟：（悄悄解开绳索）老天爷帮我。

闪电划过，照亮海面——前方有礁石

押送官：糟了！要撞礁了！

画面：船只撞上礁石，海水涌入船舱

林远舟趁乱跳入海中，在闪电中看到远处有火光——一个小渔村

**【场景4】小渔村·海滩（黎明）**

```
画面：晨曦，海浪拍打着沙滩
```

苏若雪（22岁，渔家少女，皮肤微黑，眼神明亮，正在补渔网）：（看到海滩上的黑影）咦？

她走近，发现浑身湿透昏迷的林远舟，脖子上挂着一枚玉佩

苏若雪：（扶起他）喂！你醒醒！

林远舟：（微弱睁眼）我……在哪里……

苏若雪：这里是虾角村。你怎么会在海里漂着？

林远舟：（内心独白）虾角村……我记得这个名字，是父亲曾经提过的地方，有座废弃船坞。

苏若雪：你能走吗？先跟我回家换身衣服。

**【场景5】苏若雪家（日）**

```
画面：简陋但整洁的渔家小院，墙上挂着航海图
```

苏若雪翻出一套旧衣服给林远舟换

苏若雪：你是从哪里来的？看你的玉佩……（拿起玉佩端详）这纹路……

林远舟：（警觉）怎么了？

苏若雪：（摇头）没什么。只是想起我爷爷以前提过一种类似的工艺……

门外传来苍老的声音：若雪，是谁来了？

苏若雪：爷爷，是个漂流到海滩的年轻人。

**【场景6】苏若雪爷爷房间（日）**

```
画面：老人躺在病床上，形容枯槁
```

爷爷看到林远舟的玉佩，猛地坐起

爷爷：这是……林家的信物！你……你是林家什么人？

林远舟：（警觉）您怎么认识这玉佩？

爷爷：（激动）林家……我年轻时在林家船坞当工匠！你父亲……林大师……他还好吗？

林远舟：（沉默片刻）我父亲……已经过世了。

爷爷：（老泪纵横）过世了……林大师……是我们连累了你啊！

林远舟：什么意思？

爷爷：（喘息）当年周家陷害林家……我……我有话要告诉你……

画面：爷爷剧烈咳嗽，吐血

苏若雪：爷爷！

爷爷：（紧紧抓住林远舟的手）周家……欠林家一条命……秘图……在我船坞的……

话未说完，爷爷昏死过去

**【转场】**

```
画面：林远舟站在海边，看着远处的海面
```

林远舟：（内心独白）周家……不管你是谁，这个仇，我林远舟记下了。

苏若雪走来，递上一碗鱼汤

苏若雪：爷爷醒了一会儿，一直念叨要见你。你……到底是什么人？

林远舟：（接过碗）我是谁不重要。重要的是，从今以后，我要让欠林家的人，一笔一笔还回来。

**【爆点】苏若雪的爷爷认出林远舟的玉佩，那是林家当年的信物**

**【本集完】**

### 第2集：爷爷的遗愿

**【时长】约3-5分钟**

**【场景1】苏若雪家·爷爷房间（晨）**

林远舟守在床边，爷爷缓缓睁眼

爷爷：是你……林家的孩子……

林远舟：您别说话，先养伤。

爷爷：（摇头）我时间不多了。有些事……必须告诉你。

苏若雪端药进来，爷爷摆手拒绝

爷爷：若雪，你先出去。我有话单独和他说。

苏若雪犹豫片刻，出门将门带上

爷爷：（艰难地从枕下摸出一个油布包）拿着……这是林大师当年交给我的……郑和宝船的秘图……

林远舟打开油布包，里面是一张泛黄的图纸，画着复杂的船体结构

爷爷：林大师当年给我这张图，说是为防万一……让我替他保管。我一直藏了二十年……

林远舟：（看着图纸，内心独白）这是……水密舱的设计图！比我想象的还要精妙！

爷爷：林家被灭门……都是周家搞的鬼……他们觊觎林家的造船秘技……勾结倭寇……灭了林家满门……

林远舟：周家……我记住了。

爷爷：（抓紧他的手）孩子……周家势大……你不能硬碰……先活下去……

**【场景2】渔村船坞（日）**

```
画面：破败的船坞，杂草丛生
```

林远舟在废墟中找到爷爷说的船坞，里面堆满旧物

苏若雪跟来：这是我爷爷以前工作的地方。他总说自己是林家的徒弟。

林远舟：（发现角落一条旧渔船）这船……

苏若雪：爷爷的心头宝。出海坏了就一直扔在这儿。

林远舟蹲下检查船体，用手指敲打木板，测算吃水量

苏若雪：你懂船？

林远舟：（微微一笑）略懂。

**【场景3】船坞内（日）**

```
画面：林远舟开始用现代知识检修渔船
```

他指挥几个渔民调整船舵角度、重新计算帆布面积

渔民甲：这位公子真懂船？

渔民乙：他说这舵叶角度改过，撑风能多走三成路。

苏若雪在旁边看着，眼神复杂

**【场景4】苏若雪家（夜）**

```
画面：爷爷弥留之际，握着林远舟和苏若雪的手
```

爷爷：若雪……爷爷走后……你要照顾好自己……

苏若雪：（哭泣）爷爷……

爷爷：（看向林远舟）林家孩子……若雪她……是个好孩子……你们要……互相照应……

林远舟：（郑重）爷爷放心，我会照顾好她的。

爷爷：（微笑）周家……欠林家的血债……你要讨回来……但……不要让若雪卷进来……她……

话未说完，爷爷安详离世

**【场景5】村口（日）**

```
画面：村民为爷爷办丧事，林远舟披麻戴孝
```

苏若雪：爷爷说你是好人。他不会看错人的。

林远舟：我会证明给他看的。

一渔民跑来：不好了！周家的人来了！说是要征用这片海滩！

**【爆点】周家的人已经打听到林远舟的下落，正在赶来**

**【本集完】**

### 第3集：海盗女王

**【时长】约3-5分钟**

**【场景1】村口（日）**

```
画面：几个穿着华丽的家丁，为首的是周家管事
```

周家管事：这是周家的地盘，三天内全部搬走！

村民甲：我们祖祖辈辈住在这里！

周家管事：（冷笑）周家说这里是风水宝地，要建码头。不搬？强拆！

林远舟：（走出人群）这片海滩是村民祖产，周家凭什么征用？

周家管事：（打量林远舟）哟，还有个多管闲事的。你谁啊？

苏若雪：（拉住林远舟）别冲动，他们人多。

周家管事：（看到林远舟的玉佩，眼神一变）你……等等，你这玉佩哪来的？

林远舟：（藏起玉佩）与你无关。

周家管事：（低声）这小子有问题。回去禀报少爷！

**【场景2】海边悬崖（日）**

```
画面：林远舟站在悬崖边，看着远方的海面
```

苏若雪跑来：你刚才太冲动了。周家在这一带势力很大。

林远舟：躲是躲不过的。周家既然盯上我，早晚要来。

苏若雪：那你打算怎么办？

林远舟：（看向海面）先壮大自己。他们要来，就让他们有来无回。

远处海面上，出现几艘悬挂骷髅旗的船只

苏若雪：（变色）糟了！是海盗！

**【场景3】渔村海滩（日）**

```
画面：十余艘海盗船包围渔村
```

海盗们跳下船，挥舞刀枪

海盗喽啰：东海王旗下，搜刮财货！识相的乖乖交出来！

村民们惊恐逃散

林远舟：（挺身而出）且慢！

喽啰头目：（打量林远舟）你是什么人？

林远舟：（观察海盗船）看你们的船……船身设计巧妙，吃水量浅却载重多。这种工艺，不是普通海盗能有的。

喽啰头目：（大笑）有点眼力！我们是东海王的人！

林远舟：（内心独白）东海王……我记得这是沿海最大的海盗势力。但他们的船……这种设计风格……

**【场景4】海盗船·船长室（日）**

```
画面：林远舟被押上旗舰，却意外看到舱内的布置
```

林远舟看到墙上的造船图纸，大吃一惊

林远舟：（内心独白）这图纸的风格……是林家的！这艘船是用林家图纸造的！

舱门打开，一个英姿飒爽的女子走进来

慕容青璇（23岁，海盗女王，眼神凌厉）：你就是那个多管闲事的？

林远舟：（盯着她）这艘船……谁给你造的？

慕容青璇：（冷笑）你管得着吗？

林远舟：这艘船用的是林家图纸。二十年前林家被灭门，这些图纸流落何处，你告诉我！

慕容青璇：（眼神一变）你怎么知道林家？你……你到底是谁？

**【场景5】船长室（夜）**

```
画面：两人对坐，气氛凝重
```

林远舟展示玉佩：我叫林远舟。林家唯一的血脉。

慕容青璇：（猛地站起）林家！你……你是林家的人？

林远舟：（盯着她）这艘船用林家图纸所造，你和东海王是什么关系？

慕容青璇：（苦笑）东海王……是我父亲。他曾受过林家的恩。

林远舟：什么意思？

慕容青璇：二十年前，东海王还是个年轻渔民。林家给他一艘船，让他发展势力。他发誓有朝一日要报恩……可还没等到那天，林家就被周家灭了。

林远舟：（沉默）……

慕容青璇：（眼眶泛红）周家！他们不仅灭了林家，还勾结倭寇，杀了东海王！我父亲临终前让我发誓——找到林家后人，替他们报仇！

林远舟：（内心独白）原来如此……

慕容青璇：（单膝跪地）林公子，青璇愿率东海舰队，助你讨伐周家！

**【爆点】慕容青璇的旗舰竟是用林家祖传图纸造的战舰——东海王曾受林家大恩**

**【本集完】**

林远舟：走了。但她会回来的。

```

```

## 第二章：奠基（7-12集）

### 第7集：船行首秀

**【时长】约3-5分钟**

**【场景1】船坞工棚（日）**

林远舟在工棚里展示他的"秘密武器"，工匠们围得水泄不通。

林远舟拿出一个奇怪的装置——一个密封的铜管，里面装着一根玻璃管，管中有水银。

工匠甲：（疑惑）林公子，这是什么？

林远舟：（解释）这叫"风雨镜"。可以提前半天预测风暴。

工匠们面面相觑，不相信。

林远舟：（指着玻璃管中的水银）当水银上升，说明空气潮湿，气压降低——风暴要来了。水银下降，说明天气晴好。

工匠甲：（抬头看天）现在万里无云，哪来的风暴？

林远舟：（微笑）今天午后必有风暴。信不信？

**【场景2】午后·海上（突然）**

几个时辰后，天色骤变。乌云压顶，狂风大作。

其他渔船纷纷返航，只有林远舟的船稳稳当当。

林远舟：（下令）收主帆，挂三角小帆，利用侧风稳稳靠岸。

他的船在惊涛骇浪中如履平地。

渔民们：（在岸边惊恐地看着）那船……怎么这么稳！

**【场景3】船坞工棚（夜）**

风暴过后，工匠们对林远舟的态度一百八十度大转弯。

工匠甲：（跪地）林公子，请收我为徒！

林远舟扶起他：（微笑）不必多礼。我只是用了一些"格物致知"的道理。

工匠乙：（疑惑）什么道理？

林远舟：（拿起一块竹片）看好了。他在竹片上画了一个直角三角形，标注三个顶点。

林远舟：（解释）这是"勾股定理"——直角三角形斜边平方等于两直角边平方之和。用这个原理，我可以精确计算船舵的受力角度，让船转向时省力一半。

工匠们听得目瞪口呆。

**【场景4】船坞（日）**

林远舟展示他设计的另一个装置——一个刻着密密麻麻刻度的铜盘。

林远舟：（举起铜盘对准太阳）这是"量天尺"。配合这个口诀："上弦量高，下弦量远"，可以精准算出船只离岸边的距离。

他让工匠们实测，用肉眼看对岸模糊不清，但通过"量天尺"测量，工匠们发现误差不超过十丈。

工匠们：（彻底服了）这简直是神仙手段！

林远舟：（微笑）不是神仙，是数学。

**【场景5】船坞（日）**

林远舟还展示了一样东西——用螺纹铁钉连接的船板。

传统船板用木钉或绳索绑扎，林远舟的船板却用铁钉紧紧咬合。

工匠甲：（尝试拔铁钉）这……这钉子怎么拔不出来？

林远舟：（解释）这叫"螺纹钉"。钉子有螺纹，像蜗牛壳一样旋转进去，与木头咬合，比木钉牢固十倍。

他拿来两片木板，一片用传统木钉，一片用螺纹钉，让工匠们用斧头砍。

木钉板一砍就裂，螺纹钉板却完好无损。

工匠们：（彻底震惊）这不是造船，这是在施法术！

林远舟：（大笑）不是法术，是物理。

**【场景6】海边（黄昏）**

夕阳西下，林远舟站在海边，看着自己建造的船。

苏若雪走来：（感慨）你这些本事……真的是家传的？

林远舟：（看向远方）若雪，我告诉你一个秘密。

苏若雪：（认真听着）

林远舟：（轻声）我不是你们这个时代的人。我来自几百年后。

苏若雪：（震惊）什么？你……你在说什么？

林远舟：（微笑）我知道你不会信。但没关系，总有一天你会明白。

苏若雪：（拉住他的手）不管你来自哪里，我只知道——你是我的人。

林远舟：（感动）若雪……

**【场景7】林远舟船坞（夜）**

数日后，赵婉儿的马车停在门口。

赵婉儿：（微笑）林公子，你的船队最近名声大噪。我特意来看看。

林远舟：（拱手）赵姑娘过奖了。

赵婉儿：（认真）我听说你能用一块镜子预测风暴，还能用数学算距离？我不信。

林远舟：（微笑）不信可以测试。

赵婉儿：（彻底服了）林公子，你是神仙下凡吗？

### 第8集：商战开启

管事：那个姓林的抢了我们三成生意！盐市的商人都跑去他那里进货了！

周子轩：（拍桌）什么？那个流放的罪民，也敢和我周家抢市场？

管事：少爷，他的盐比我们便宜一成，还送货上门。商人们都去他那里了。

周子轩：（冷笑）调人，去砸他的船坊！

周家打手气势汹汹地闯入，正要动手。

打手们被押走。

林远舟：（对赵婉儿点头）多谢赵姑娘相助。

赵婉儿：（微笑）我说过，赵家的人脉，你尽管用。

**【场景5】扬州酒楼（日）**

林远舟和赵婉儿在雅间对饮。

赵婉儿：（放下酒杯，正色）不过你要小心。周子轩不会善罢甘休。

林远舟：（点头）我知道。

赵婉儿：（低声）他还有个弟弟叫王思远，比他更难对付。

林远舟：（眼神一凝）王思远？

赵婉儿：（点头）此人心思缜密，野心极大。他和周子轩同母异父，表面称兄道弟，暗中却想吞并周家。

林远舟：（内心独白）敌人的敌人，未必是朋友。但可以利用。

### 第9集：王思远的阴谋

**【时长】约3-5分钟**

**【场景1】王思远宅邸（夜）**

月光下，一个穿白衣的年轻公子在对月独饮。

王思远（26岁，眉清目秀，眼神却阴沉）：（放下酒杯）林远舟此人，有点意思。

侍从低声：公子，周少爷派人来催了，说要您帮忙对付那个姓林的。

王思远：（冷笑）帮忙？他周子轩只会打打杀杀，哪懂谋略。（站起身）林远舟此人，船快、脑子活，而且他的船型和当年林家的一模一样。

侍从：（低声）公子怀疑他是林家后人？

王思远：（微笑）林家灭门时，我王家也分了一杯羹。林家老号的图纸，我见过。（把玩扇子）此人若真是林家遗孤，那就有意思了。

侍从：（疑惑）可他是周家的仇人，和咱们王家有什么关系？

王思远：（冷笑）关系大了。我虽是王家公子，却是庶出。在王家，我说话没什么分量。（眼神阴沉）我需要自己的势力，需要拿得出手的功劳。林远舟的造船技术，正是我所需要的。

王思远：（站起身）明日备轿，我亲自去会会他。用他的技术，加上我的谋略，周家……哼，早晚是咱们的。

一顶小轿停在船坞前。王思远下轿，四处打量。

他看到新建的船只和船坞布局，眼神微变。

王思远：（内心独白）这船型和郑和宝船有几分相似……果然是林家传人。

林远舟：这位公子是……

王思远：（拱手）在下王思远，久仰林公子大名。

林远舟：（眼神一凝）王家的公子？

王思远：（微笑）正是。听说林公子的船队，比周家的还快。在下特来拜访，想谈一笔生意。

林远舟：（冷笑）王家和周家不是姻亲吗？王公子此来，有何贵干？

王思远：（凑近低声）姻亲是表面。实不相瞒，王家早就想吞并周家的产业，只是一直没找到机会。如今林公子横空出世，正是天赐良机。

两人对坐，气氛微妙。

王思远：（微笑）我可以帮林公子扳倒周子轩。但事成之后，周家的产业，我要七成。

林远舟：（内心独白）七成？这人心真黑。

林远舟：（沉吟片刻）王公子胃口不小。但周家也不是软柿子，王公子凭什么觉得能吃掉他？

王思远：（得意）林公子有所不知。周子轩的父亲年事已高，周家后继无人。周子轩虽有野心，却无谋略。（凑近低声）而且……我注意到林公子的船型，和当年林家的一模一样。林公子是林家后人吧？

林远舟：（眼神一凝）你怎么知道？

王思远：（微笑）林家灭门时，我王家也参与了瓜分。（冷笑）你我合作，各取所需——林公子报灭门之仇，我王家吞周家产业。双赢的买卖，林公子意下如何？

林远舟：（沉吟片刻）王公子的条件，我可以考虑。但七成太多，五五分成。

王思远：（犹豫）这……

林远舟：（起身）王公子慢慢考虑。我林远舟不急。

王思远：（咬牙）成交！

林远舟：（内心独白）账本……这是个有用的情报。先让他们狗咬狗，我坐收渔翁之利。

**【场景4】苏若雪家（夜）**

林远舟回到苏若雪家，苏若雪迎上来。

苏若雪：（担忧）那个王家公子来做什么？

林远舟：（冷笑）他想和我合作对付周家。

苏若雪：（皱眉）赵姑娘说他心术不正。

林远舟：（点头）我知道。但我可以利用他。他想要周家的产业，我想要周家灭亡。各取所需，何必拒绝？

苏若雪：（担心）万一他反咬你一口？

林远舟：（拍了拍她的肩）放心。我早有准备。

**【爆点】林远舟决定将计就计，利用王思远对付周子轩**

### 第10集：扬州柳如是

青楼门口车马如龙，龟公正在招呼客人。

房间布置典雅，墙上挂着诗词字画。一个容貌清丽的女子正在抚琴。

柳如是（20岁，容貌清丽，气质脱俗）：（打量林远舟）公子说能帮我赎身？不知有何条件？

林远舟：（直视她）柳姑娘心里清楚。周子轩的未婚妻，沦为青楼女子，换作是我，也不会善罢甘休。

林远舟：（微笑）在下林远舟。周家的仇人。

两人对坐，气氛凝重。

林远舟：（低声）柳姑娘这情报从哪来的？

柳如是：（微笑）林公子不必多问。醉花楼是江南最大的情报集散地，我自然有我的门路。（顿了顿）还有一件事——王思远来找过你吧？

林远舟：（眼神一凝）你怎么知道？

柳如是：（冷笑）他在楼里打听你的消息，被我的人盯上了。他表面来找你合作，其实他早就知道周家船坞密室里藏着那本走私账本。他想借你的手拿到账本，再反咬你一口。

林远舟：（眼神一凝）他倒是打得好算盘。

柳如是：（冷笑）但他不知道，那本账只是周家的罪证。周子轩手里还有一本更致命的——朝中大臣受贿名单。那是他保命的东西。

林远舟：（点头）所以要先下手为强。

柳如是：（打量林远舟）林公子打算怎么对付周家？

林远舟：（微微一笑）让他们自相残杀。

柳如是：（会心一笑）有意思。我帮你。

**【爆点】柳如是竟是周子轩的未婚妻，被迫流落青楼**

### 第13集：郡主招揽

**【时长】约3-5分钟**

**【场景1】江南某港口（日）**

清晨的港口薄雾弥漫，林远舟的船队正在卸货。突然，一艘华丽的皇室画舫缓缓驶入港口，气派非凡。

林远舟：朝廷的人？来这里做什么？

林远舟正和工匠们一起研究一艘新型战船的图纸。

工匠甲：（惊叹）公子，这船舵的设计……我从未见过！

林远舟：（解释）这是改良后的方向舵，操控更灵活，适合海战。

工匠乙：（指着图纸）还有这炮位布局……

林远舟：（微笑）传统炮位只能侧舷射击。我设计的炮位，可以全方位射击，没有死角。

船员匆匆跑来。

船员：（气喘吁吁）公子，朝廷的船来了！

林远舟收起图纸，眼神一凝。

林远舟：（内心独白）朝廷？来得正好。

**【场景3】港口码头（日）**

朱嫣然下船，林远舟在码头迎接。

朱嫣然：（环顾四周）林公子的船坞虽然简陋，却比我见过的其他船坞更有章法。

林远舟：（微笑）郡主过奖。请移步船坞，在下有一件东西想请郡主过目。

**【场景4】船坞工坊（日）**

林远舟拿出一个精致的船模，邀请朱嫣然坐下观看。

他将船模放入水缸中，用尖锐的簪子刺穿其中一个舱室。

林远舟：（指着）看，水只在破损的舱室中，不会蔓延到其他舱室。这就是郑和宝船失传百年的"水密舱"技术。

朱嫣然：（震惊）水密舱？我听说过这个传说，但从未见过实物！

林远舟：（微笑）郡主，这只是第一层。让我为郡主一一拆解。

他从怀中取出一张图纸，上面密密麻麻画满了线条和标注。

林远舟：（展开图纸）郡主请看。这艘战舰，我设计了十二项独家技术。

他一根根竖起手指，一一列举。

林远舟：第一，水密舱壁。用隔板将船底分为六个独立密封舱。即使三舱进水，船依然漂浮。传统船只，一舱进水就沉。

朱嫣然瞪大了眼睛。

林远舟：第二，龙骨结构。我用"蜂窝梁"原理——将主龙骨设计成空心六边形结构，重量减轻四成，强度却增强三倍。

他拿起一根空心竹子演示。

林远舟：（掰断竹子）看，实心木棍很容易折断。但空心六边形的竹子，强度却大得多，而且轻得多。

朱嫣然拿起竹子尝试，果然折不断。

林远舟：第三，舵效比。我用"伯努利原理"优化舵叶角度，让船转向时受到的水流阻力减少一半，转向速度提升两倍。

他用扇子在水面上模拟水流。

林远舟：第四，火炮布局。传统战船只能侧舷开火。我设计的是"十字交叉炮位"——船头船尾各两门，两侧各四门。敌船无论从哪个方向来，都在我们的火力覆盖范围内。

朱嫣然：（倒吸一口凉气）这……

林远舟：（微笑）还有第五——"定风龙骨"。我在船底加了一个侧翼结构，利用侧风产生的下压力，提高船在风浪中的稳定性。简单说，风越大，船越稳。

他拿出手绘的示意图。

林远舟：第六，舰船吃水线。我根据"阿基米德原理"，精确计算了船体浮力中心与重心 的位置关系。让船在满载时依然保持最佳航行姿态。

他一口气说出十几个参数，每个都用几何图形和数学公式解释。

林远舟：第七，主桅设计。我用"结构力学"计算最优的桅杆高度与帆布面积比例，让升帆速度提升一倍。

朱嫣然：（彻底折服）林公子，你这脑子到底是怎么长的？

林远舟：（笑了笑）郡主过奖。这不是什么神仙法术，只是"格物致知"——研究物体本质规律的道理罢了。

朱嫣然：（目光闪烁）林公子，你这项技术……太子殿下一定会很感兴趣。

林远舟：（内心独白）这些技术，随便拿出一项都足以震惊当世。这才是真正的"降维打击"。

**【场景5】画舫密室（日）**

两人在密室对坐，气氛凝重。

朱嫣然：（低声）林公子可知道，朝廷即将讨论"海禁"存废？

林远舟：（眼神一凝）海禁？

朱嫣然：（点头）保守派想重启海禁，限制民间航海。但太子殿下支持开海。

林远舟：（内心独白）太子……这是站队的机会。

朱嫣然：（直视他）林公子，我需要一艘比郑和宝船更厉害的战舰。若你能做到，皇室会全面支持你。

林远舟：（沉吟）全面支持？

朱嫣然：（点头）包括帮你扳倒周家的残余势力，以及……对付东厂。

林远舟：（眼神一凝）东厂？

朱嫣然：（叹息）周子轩逃了，他知道自己在劫难逃，已经投靠了东厂。

林远舟：（拳头紧握）东厂……

林远舟：（伸出手）成交。

慕容青璇：（皱眉）东厂权势滔天，怎么找证据？

林远舟：（看向远方）周子轩的账本，就是证据。只要拿到那本账，东厂也保不住他。

柳如是：（低声）我让人去打探消息。

慕容青璇：（大喊）小心！

林远舟：（扶住她）青璇！

画面：周子轩葬身火海。

### 第18集：东厂阴影

**【场景1】林远舟船坞（日）**

清晨，平静的船坞突然被打破。数十名东厂番子将船坞团团围住，气势汹汹。

东厂档头：（环顾四周）听说林公子的船队，日进斗金啊。不如……交由东厂打理？

林远舟：（眉头微皱）公公厚爱，只是在下一个小小船坊，恐怕入不了公公的眼……

东厂档头：（皮笑肉不笑）三日。三日后咱家来听消息。（转身离去）

林远舟：（沉吟）东厂虽然权势大，但也不是铁板一块。他们内部也有派系之争。

夜深了，烛光摇曳。柳如是冒着暴露身份的风险来找林远舟。

林远舟和柳如是密谈。

### 第19集：皇位之争

**【时长】约3-5分钟**

**【场景1】林远舟船坞（日）**

平静的船坞突然被打破。朝廷官员带人宣读圣旨。

林远舟：（大声）各位放心，我不会丢下你们。

工匠们安静下来，看着林远舟。

林远舟：（坚定）无论发生什么，这个船坞不会易主。我林远舟说到做到。

苏父：（叹气）东厂权势滔天，你是斗不过他们的。不如……先避避风头？

苏若雪：（担忧）那怎么办？

林远舟：（目光坚定）只有一个办法——找更大的靠山。

林远舟：（沉吟）无敌战舰……

朱嫣然：（直视林远舟）林远舟，我要你选边站。太子，还是汉王？

赵婉儿：（抬头）什么？

赵婉儿：（沉默片刻）娘，我不是为了还债才帮他。

赵母：（欣慰）我知道。但无论如何，我们确实欠林家一个交代。

林远舟：（看向柳如是）如是，你等了二十年，现在时机到了。

柳如是：（点头）周家已经倒了，但幕后主使永乐帝还在。我要让天下人知道真相。

**【爆点】柳如是的身世揭开——她是前朝公主的遗孤，手中有圣旨原件**

赵婉儿：（微笑）青璇妹妹还是这么英姿飒爽。

柳如是：（轻笑）婉儿姐姐风采依旧。

朱嫣然：（淡淡一笑）各位……别来无恙。

**【场景3】林远舟旗舰（日）**

五位女子齐聚。

林远舟：（环视众人）各位，我有一件事要宣布。

五女齐声：什么事？

林远舟：（认真）我林远舟，此生只娶苏若雪一人为妻。

苏若雪：（感动落泪）远舟……

其他四女面面相觑，神色复杂。

林远舟：（继续）但你们四位，都是我的家人。若雪是我的妻子，你们就是我的姐妹。

慕容青璇：（抱拳）我早就说过，我只要你这个人。不做妻子，做个并肩作战的战友也好。

赵婉儿：（微笑）你放心，赵家的生意我会继续支持。

柳如是：（轻笑）我的情报网，随时为你所用。

朱嫣然：（淡淡一笑）皇室那边，有我。

**【爆点】林远舟宣布只娶苏若雪一人，但四女决定以姐妹身份相待**

**【本集完】**

### 第35集：大婚之日

**【时长】约3-5分钟**

**【场景1】海国侯府（日）**

林远舟和苏若雪大婚，十里红妆。

宾客盈门，朝中文武百官都来道贺。

司仪：高堂在上，新郎新娘行礼！

林远舟和苏若雪拜堂。

苏若雪：（含泪微笑）远舟，我们终于成亲了。

林远舟：（握住她的手）若雪，从今以后，你是我的妻子。

**【场景2】婚宴（日）**

四女一起敬酒。

慕容青璇：（举杯）祝你们百年好合。

赵婉儿：（举杯）早生贵子。

柳如是：（举杯）白头偕老。

朱嫣然：（举杯）永结同心。

林远舟和苏若雪一一回敬。

**【场景3】洞房（夜）**

林远舟和苏若雪独处。

苏若雪：（靠在他怀里）远舟，我好幸福。

林远舟：（亲吻她额头）我也是。

突然，一封信从窗外射入。

林远舟：（取下信）这是……

信上写着：朱嫣然郡主在和亲途中逃婚，下落不明。

林远舟：（眉头紧锁）出事了。

**【爆点】大婚之日，朱嫣然逃婚**

**【本集完】**

### 第36集：舟行天下（终章）

**【时长】约3-5分钟**

**【场景1】某渔村（日）**

林远舟找到逃婚的朱嫣然。

朱嫣然：（苦笑）你怎么找到我的？

林远舟：（微笑）你的情报网虽厉害，但我的情报网也不差。

朱嫣然：（低头）我不想嫁给边疆王。那是政治婚姻。

林远舟：（叹息）你逃婚，会引发边疆动荡。

朱嫣然：（抬头，眼眶泛红）我知道……所以我来找你。

林远舟：（疑惑）找我？

朱嫣然：（坚定）带我走。去看看你的海上帝国。

**【场景2】渔村（晨）**

林远舟带着朱嫣然出海，路上遇到苏若雪。

苏若雪：（微笑）我就知道你会来找我。

林远舟：（尴尬）若雪，我……

苏若雪：（抱住他）不用解释。我们说好是一家人。她的事，就是我们的事。

**【场景3】旗舰（海上）**

五位女子站在甲板上，看着远方的舰队。

林远舟：（站在船头）从一艘小渔船，到今天的百艘舰队……这条路，我走了三年。

苏若雪：（靠在他身边）这只是开始。

林远舟：（点头）这只是开始。

旁白：一个大航海时代，即将开启。而这一切，都从一艘小渔船开始……

**【彩蛋】**

**【场景】未知岛屿（日）**

林远舟的舰队在航行中发现一座无名岛屿。

船员：侯爷，岛上发现了一些奇怪的金属物品！

林远舟上岛查看，发现一堆现代化的机械残骸——那正是他前世深潜器的残骸。

林远舟：（震惊）这是……我的深潜器？

他捡起一块残骸，陷入沉思。

旁白：穿越不是偶然。这片海域，正是连接两个时空的枢纽……

**【全剧终】**

## 创作说明

本剧本以"造船出海"为核心主题，融合了：
- **穿越爽文**：现代知识降维打击古代
- **多女主**：船娘、海盗女王、富商千金、才女、郡主
- **商战**：期货、饥饿营销、商业联盟
- **海战**：火攻战术、炮舰配合
- **权谋**：皇位争夺、东厂阴谋
- **情感**：多条感情线交织

每6集一个章节，节奏紧凑，爆点密集，适合短剧改编。
