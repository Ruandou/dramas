# 《我租的女友，真把我当老公了》制片规范

> v1.0 · 对齐 [`超雄重生1995/制片规范.md`](../../超雄重生1995/制片规范.md)

## 三文件改稿顺序

1. `短剧剧本_…_36集.md`（剧情源）
2. `剧本/EP##/EP##_*.md`（分镜 · 含运镜/画面/对白）
3. `EP##_shots.yaml`（逐镜 · api/assets/return_last_frame）
4. `EP##_segments.yaml`（API 提交 · 4–12s/段）

校验：`python3 script/validate_rentgf_ep.py EP##`

## EP01 标杆（试拍模板）

| 项 | 标准 |
|----|------|
| 分镜 md | ~220 行，32 镜，13 段对照表 |
| shots.yaml | 每镜 api + return_last_frame |
| segments.yaml | emotion 对白 + 逐镜 api.text |
| 裸素材 | **134s** → 剪成 2–2.5 分钟 |
| 定妆 | `assets/seedream_EP01.yaml` |

详见 [`剧本/EP01/README.md`](剧本/EP01/README.md)。

## 现代剧差异（相对超雄）

- **允许**：smartphone、笔记本电脑、现代室内
- **禁止**：1990 年代 CRT/翻盖机等（见各集 `negative_prompt`）
- **输出**：短剧默认 `assets/generated/EP##/`，勿覆盖正式用户素材目录

## ID 规则

与超雄相同：`CHAR-###` · `CHAR-###-L##` · `SCENE-###` · `EP##-S##` · `EP##-SEG##`
