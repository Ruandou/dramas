# assets · 我租的女友

> **v2.0**（2026-05-25）对齐 [`超雄重生1995`](../../超雄重生1995/剧本/_模板.md) 体量：每集 **~26–28 镜 / 11 API 段 / ~105–120s 裸素材**，剪成 **2–2.5 分钟** 成片。

## 目录

```
assets/
  looks/           CHAR-001-L01.png …
  scenes/          SCENE-001.png …
  keyframes/EP##/  可选首帧（i2v_ref 连镜）
  generated/EP##/  EP##-SEG*.mp4, tasks.json, concat_list.txt
```

## 生成顺序

1. **Seedream** 按 `角色卡.md` / `资产/场景卡片.md` 出定妆与场景  
2. 落盘路径与 `EP##_segments.yaml` 中 `assets.*_urls` 一致  
3. **Seedance** 按 **11 段/集** 提交（须用户授权扣费）  
4. `ffmpeg -f concat -i concat_list.txt -c copy EP##_full.mp4`
