# 《我租的女友，真把我当老公了》短剧剧本（36集）

## 项目信息

- **类型**：都市 / 恋爱 / 情绪 / 春节档
- **集数**：36 集 × 2–3 分钟
- **叙事节奏**：交易开始 → 她过于认真 → 秘密揭开 → 情感抉择
- **一句话**：男主租女友回家过年，合同写「演七天」——她带行李、见父母、学他家规矩， **比真媳妇还像媳妇**。

---

## 核心设定

| 项 | 内容 |
|----|------|
| **平台** | 「年伴」租赁 APP，合同： **7 天假扮情侣，禁止肢体亲密，日结** |
| **男主程野** | 29，沪漂产品经理，被催婚；前女友跟了有房同事 |
| **女主沈听** | 26，租赁方派单； **合同外** 自带围裙、记程母忌口、改口叫「妈」 |
| **秘密（第 10 集后揭）** | 她前段婚姻 **假结婚办户口** 被男方家控制；这次想借「见家长」练 **脱身剧本**——后来 **真动了心** |
| **基调** | 女频情绪为主，男频可看「谁更真」； **不 NTR，不虐到毁三观** |

## 分集大纲（第 1–36 集）

### 第一章：合同（1–6 集）· 春节前

**第1集《下单》** — 程野年伴下单；沈听上门对合同， **带行李箱**。  
**第2集《高铁》** — 她记他过敏、占靠窗；程野：「演戏而已。」  
**第3集《到家》** — 程母做饭；沈听进厨房打下手， **自然得像来过**。  
**第4集《改口》** — 饭桌上程母夹菜；沈听：**「谢谢妈。」** 程野喷饭。  
**第5集《周琳》** — 偶遇前女友；沈听挽手， **台词像真情侣**。  
**第6集《她值得》** — 陆城名字后一夜；亲戚贬沈听「租的」，程野 **第一次当众挡**：「她值得。」

### 第二章：七天（7–12 集）· 春节

**第7集《祭祖》** — 沈听学本地规矩；程父点头。  
**第8集《亲戚》** — 催婚亲戚；沈听帮程野挡酒。  
**第9集《夜谈》** — 程母问：「真处多久了？」沈听看程野。  
**第10集《秘密》** — 陆城电话；沈听脸色变；程野听见「假结婚」。  
**第11集《解释》** — 沈听坦白：「我练脱身，不是练骗你爸妈。」  
**第12集《第七天》** — 合同到期；沈听收拾行李，程母哭。

### 第三章：返沪（13–18 集）

**第13集《返城》** — 高铁，沈听退红包；程野追下车。  
**第14集《老莫》** — 平台扣款纠纷；沈听被威胁 **补违约金**。  
**第15集《同居》** — 程野短租多一间给她暂住； **各睡各** 。  
**第16集《陆城》** — 陆城上门；程野第一次动手。  
**第17集《保护令》** — 沈听申请；程野陪跑材料。  
**第18集《分手合同》** — 沈听：「我不租了。」程野：「我也没租你。」

### 第四章：认真（19–24 集）

**第19集《入职》** — 沈听真找工作，脱离年伴。  
**第20集《程母来沪》** — 妈突击；见两人分房， **反而放心**。  
**第21集《周琳2》** — 周琳求复合；程野拒。  
**第22集《听》** — 沈听电台兼职；程野默默投流。  
**第23集《告白》** — 程野：「七天不够。」沈听：「我怕认真了你会退。」  
**第24集《在一起》** — 无盛大表白， **超市牵手**。

### 第五章：婚史（25–30 集）

**第25集《离》** — 陆城拖不离婚；沈听起诉。  
**第26集《程野证》** — 程野出庭陈述 **租赁关系→真实交往** 时间线。  
**第27集《判离》** — 胜诉；沈听空落。  
**第28集《求婚》** — 程野小城求婚， **没戒指有围裙**（callback 厨房）。  
**第29集《妈点头》** — 程母：「第一次我就喜欢这姑娘。」  
**第30集《年伴关》** — 老莫公司被查；程野举报灰色合同。

### 第六章：老公（31–36 集）

**第31集《登记？》** — 沈听恐婚；程野：「不催。」  
**第32集《新春节》** — 再以 **女友** 非租赁回家。  
**第33集《改口2》** — 沈听正式改口；程父敬酒。  
**第34集《工作》** — 沈听 offer 外地；程野：「你去，我跟。」  
**第35集《留下》** — 沈听选留下； **「这次不是合同。」**  
**第36集《下单2》** — 程野删年伴 APP；沈听：「要不……真结？」程野：「等你想好了再说。」—— **开放式 HE**。

**钩子**：沈听回房，手机又亮——陆城：**「假结婚的事，你爸妈知道了吗？」** 沈听 **删信息**，手抖。

## 制作备注

- **详细对白**：第 1–36 集已齐；EP01–05 另有 Seedance 分镜管线（`剧本/EP##/`）。
- 春节场景 1–12 集集中，利于 **春节档投流**。
- EP06 大纲由《红包》改为《她值得》（红包情节已并入 EP05）。
- 沈听「太认真」要有 **现实动机**（脱身练手→真心），避免纯恋爱脑。
- 老莫/陆城线 **轻量**，主情感 **程野×沈听×程母** 三角温暖。
- EP36 开放式 HE；程母彩蛋可剪进 **第 36 集** 片尾或单独 **彩蛋条**。
