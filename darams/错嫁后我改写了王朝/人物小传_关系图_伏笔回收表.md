# 《错嫁后我改写了王朝》人物小传、关系图与伏笔回收表

## 一、人物小传（核心角色）

## 1) 沈知微（穿越后：沈晚）
- 年龄感：24-27
- 表层标签：冷静、聪明、嘴硬、执行力强
- 深层动机：先活命，再掌控命运；最终从“求生”转为“建新秩序”
- 角色弧线：
  - 前期：被迫入局（替嫁、保命）
  - 中期：主动破局（证据链、布局反制）
  - 后期：定局者（参与朝纲重塑）
- 关键能力：急救医学、伤痕时序判断、心理博弈、信息整合
- 软肋：对“被抛弃”高度敏感（触发第17集误会）
- 高光场：
  - 第6集宴上封喉（点破太子隐疾）
  - 第23集御前验伤（证据反杀）
  - 第28集偏殿救王（生死级执行）

## 2) 萧承渊（肃王）
- 年龄感：28-32
- 表层标签：冷面、克制、战神、寡言
- 深层动机：为边军与旧部讨回公道，阻断东宫恶政
- 角色弧线：
  - 前期：试探女主（不信任）
  - 中期：与女主结盟（共享命门）
  - 后期：愿以交兵权换法治（从“将”到“治”）
- 关键能力：军阵指挥、朝堂压强、危机判断
- 软肋：旧伤与慢毒后遗症（第20、27-28集）
- 高光场：
  - 第18集刑场截杀（公开立场）
  - 第34集交兵权逼判（政治成熟）

## 3) 萧景珩（太子）
- 年龄感：30上下
- 表层标签：温雅、会说理、重礼法
- 深层动机：夺位即正义，失败皆可牺牲
- 角色功能：主要对抗方、舆论操盘者、制度漏洞利用者
- 常用手段：伪令、伪证、切割、借刀
- 崩塌节点：
  - 第30集密诏被拆
  - 第31集与皇后反目
  - 第34集废黜

## 4) 皇后
- 年龄感：45+
- 表层标签：慈威并存、重宫规
- 深层动机：以“稳定后宫”之名控制储位与财权
- 角色功能：终极幕后、东宫母体权力来源
- 常用手段：司药局、内侍体系、后宫规制压人
- 崩塌节点：
  - 第30集幕后曝光
  - 第34集冷宫赐死

## 5) 谢砚
- 年龄感：26-30
- 表层标签：理性、克制、专业
- 深层动机：为父昭雪，为旧案收尾
- 角色功能：中后期关键证据桥梁与专业协同
- 高光节点：
  - 第13集档库救援
  - 第26集补齐财证链
  - 第33集终审补证

## 6) 沈明珠
- 年龄感：22-25
- 表层标签：精致、骄矜、现实
- 深层动机：求生与家族体面
- 角色功能：从对立者转“被胁迫中间层”
- 转折节点：
  - 第15集倒戈交易
  - 第16集交出通敌信样本

## 二、人物关系图（文本版）

- 沈知微 <-> 萧承渊：互利同盟 -> 生死共担 -> 并肩治世（主CP）
- 沈知微 <-> 萧景珩：智斗与证据战（持续高压对抗）
- 沈知微 <-> 皇后：宫规压制与药理反制（女主核心外部压迫）
- 沈知微 <-> 谢砚：专业协作与证据互补（稳态盟友）
- 沈知微 <-> 沈明珠：替嫁仇怨 -> 现实交易 -> 有限合作
- 萧承渊 <-> 萧景珩：储位竞争、兵权博弈（兄弟对局）
- 太子 <-> 皇后：利益共同体 -> 危机切割 -> 母子反目
