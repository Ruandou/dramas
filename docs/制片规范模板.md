# 短剧制片规范模板（通用）

> **版本**：v1.0 · 2026-05-29
> **用途**：复制到 `dramas/<剧名>/制片规范.md`，按 `{占位符}` 填入剧名相关内容

---

## 一、ID 命名规则

| 类型     | 格式                              | 示例              | 用途                             |
| -------- | --------------------------------- | ----------------- | -------------------------------- |
| **角色** | `CHAR-###`                        | `CHAR-001`        | 对白、关系、选角（谁）           |
| **形象** | `CHAR-###-L##`                    | `CHAR-001-L01`    | 出图、妆造、分镜视觉（长什么样） |
| 群演     | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 通用脸型一套即可                 |
| 场景     | `SCENE-###`                       | `SCENE-002`       | 布景                             |
| 分集     | `EP##`                            | `EP01`            | 分集文件                         |
| 道具     | `PROP-###`                        | `PROP-001`        | 关键道具                         |

- 编号**只增不删**；弃用标 `deprecated: true`。
- 新建角色：先 `资产/角色索引.md`，再建 **`L01` 基础形象**于 `资产/形象索引.md` + `角色卡片.md`。
- 新建换装/阶段：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`。

### 1.1 形象 ID 与基础 / 衍生

| 后缀     | 名称     | 要求                                                                                |
| -------- | -------- | ----------------------------------------------------------------------------------- |
| **L01**  | 基础形象 | 完整定妆 Prompt（脸、体型、发式、默认服装）；全剧面部一致性的**唯一锚点**           |
| **L02+** | 衍生形象 | **必须** `based_on` 本角色 `L01`；Prompt 只写差异，并含 `same face as CHAR-xxx-L01` |

**出图流程**：定稿 `L01` 参考图 → 衍生形象用图生图 / 角色一致性模型 → 禁止跳过 L01 直接生成 L02。

**本剧衍生形象表**（按需填写）：

| 角色    | L01（基础）    | L02+（衍生示例）         |
| ------- | -------------- | ------------------------ |
| {角色A} | {基础服装描述} | {衍生1描述}、{衍生2描述} |
| {角色B} | {基础服装描述} | {衍生1描述}              |

## 二、目录结构

```
{剧名}/
├── 资产/
│   ├── 角色卡片.md              # 外貌/Prompt 详情（含 CHAR ID）
│   ├── 角色索引.md            # CHAR-* 主表（角色卡片详情可链入）
│   ├── 形象索引.md            # L## 形象主表
│   ├── 场景卡片.md            # SCENE-* 主表
│   ├── 道具卡片.md            # PROP-* 主表
│   ├── 声音卡片.md              # 音色/TTS 配置
│   └── {年代/美术规范}.md     # 如有特殊时代/视觉约束（可选）
├── 剧本/
│   ├── README.md
│   ├── _模板.md
│   ├── EP01_{集标题}.md
│   └── …
├── assets/
│   ├── generated/           # AI 生成成品（禁止写入占位）
│   │   └── EP##/
│   ├── looks/               # 角色定妆参考图
│   ├── scenes/              # 场景参考图
│   ├── props/               # 道具参考图
│   └── voices/              # 音色参考
├── docs/
│   └── {专项文档}.md        # 如：术语表、年代规范、流水线文档等
├── script/                  # 自动化脚本
├── 制片规范.md              # 本文件
├── 短剧剧本_{剧名}_72集.md  # 主剧本纲要
└── 人物小传_{剧名}.md       # 可选
```

**约定**：

- **纲要**在 `短剧剧本_{剧名}_72集.md` 维护剧情。
- **可拍分镜 + 对白**一律在 `剧本/EP##_*.md`，并带 CHAR/SCENE 引用。

## 三、工作流顺序（必读 · 防不同步）

### 3.1 修改顺序

改台词、场次、字幕/旁白策略时**严格按层向下**，**禁止**先改 `segments.yaml` 或 `shots.yaml` 再回头补剧本。

| 顺序  | 层           | 文件                        | 写什么                                                                          |
| :---: | ------------ | --------------------------- | ------------------------------------------------------------------------------- |
| **1** | **主剧本**   | `短剧剧本_{剧名}_72集.md`   | 集纲、每场剧情、对白要点、钩子                                                  |
| **2** | **分集剧本** | `剧本/EP##_*.md`            | 可拍分镜表：`shot_id`、画面、**对白/备注**、CHAR/SCENE/形象、时长/模式/运镜     |
| **3** | **机器可读** | 同目录 `EP##_shots.yaml`    | 从分集 md 导出，勿手改 yaml 当源                                                |
| **4** | **段落 API** | 同目录 `EP##_segments.yaml` | 按 md 镜号合并为 segment；`api.text` 对白/字幕/旁白与 **第 2 步引号内字面一致** |
| **5** | **其它**     | 声音卡片、年代规范、assets/   | 仅在前几步定稿后随需更新                                                        |

**Agent / 人工自检**（改完第 2 步后）：

- [ ] 主剧本该集对白要点已与分集表一致（或注明「分集为准」并只改分集）
- [ ] 未单独改 `segments` 而 md 未动

**单集真相源**：拍什么、说什么 → **`剧本/EP##_*.md`**；主剧本为纲，segments 为 API 展开，**不是**编剧起点。

## 四、分集文件头（YAML）

每集文件顶部：

```yaml
---
episode_id: EP01
episode_title: { 集标题 }
duration_min: { 2-3 }
season: S1
scene_ids: [SCENE-001, SCENE-002]
character_ids: [CHAR-001, CHAR-002]
look_ids: [CHAR-001-L01, CHAR-002-L01]
prop_ids: [PROP-001, PROP-002]
seedance_defaults:
  model: doubao-seedance-2-0-fast
  ratio: "9:16"
  resolution: 720p
  duration_sec: "8-10"
  generate_audio: true
---
```

**字段说明**：

| 字段                | 说明                            |
| ------------------- | ------------------------------- |
| `episode_id`        | `EP##` 格式                     |
| `episode_title`     | 集标题                          |
| `duration_min`      | 目标时长（分钟），一般 2–3 分钟 |
| `season`            | 固定 `S1`（全 72 集为第一季）   |
| `scene_ids`         | 本集涉及场景 ID 列表            |
| `character_ids`     | 本集涉及角色 ID 列表            |
| `look_ids`          | 本集涉及形象 ID 列表            |
| `prop_ids`          | 本集涉及道具 ID 列表            |
| `seedance_defaults` | Seedance 生成默认参数           |

### 4.1 Segment 拆分规则（强制）

> 通用硬约束：Seedance 等视频生成 API 对单段时长有上限，超长 segment 无法生成。任何剧目复制本模板时**不得**删除或放宽本节。

| 约束             | 值                | 说明                                                                                |
| ---------------- | ----------------- | ----------------------------------------------------------------------------------- |
| 单 segment 时长  | **4–12 秒**       | 超过 12 秒的 segment 无法被 AI 生成，**必须**拆分                                   |
| 理想时长         | 与 `{duration_sec}` 一致 | 与上方 `seedance_defaults.duration_sec`（如 `8-10` / `10-12`）保持一致     |
| 每 segment 镜头数 | 1–3 镜            | 不超过 3 个镜头                                                                     |
| 最小叙事单位     | 1 个完整 beat     | 每个 segment 必须构成完整叙事节拍（有动作起止、有情绪弧）                           |

**关键区分（务必分清）**：

- **场景（SCENE-###）** = **空间单位**（地点不变 = 同一场景）。
- **Segment（SEGxx / SEGxxa-b）** = **AI 生成单位**（一次视频 API 调用），受 4–12 秒硬限制约束。
- 同一场景**可以**包含多个 segment；segment **不得**跨场景（场切即断段）。

**拆分原则**：

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）。
2. **不得**在连续动作进行中切断 segment（动作未完成不切段）。
3. 每个 segment 结束时应有自然停顿点（台词说完、动作完成、表情定格），便于后期拼接与字幕对齐。
4. 相邻 segment 之间允许轻微画面跳接（时间/角度微变），但不应有逻辑断裂；跨段保持道具/服装/姿态连续。

**分集剧本（`剧本/EP##_*.md`）中的标注要求**：

- 每个 SEG 后标注：`> ⏱ Segment时长：Xs ｜ 镜头数：N`（X ∈ [4, 12]）。
- 同场景续接段使用 `**（续）**` 标记，**不重复**写场景头（SCENE / 时间 / 地点）。
- `EP##_segments.yaml` 中 `duration_sec` 必须落在 **4–12** 区间；超出即视为违规，必须回到第 2 步分集 md 重新拆段。

**自检清单（提交 `EP##_segments.yaml` 前）**：

- [ ] 所有 segment 的 `duration_sec` 是否都在 4–12？
- [ ] 是否存在跨场景的 segment？（必须断段）
- [ ] 是否存在切断对白或连续动作的拆点？
- [ ] 单 segment 内主说话人是否 ≤ 2，镜头数是否 ≤ 3？

## 四B、集数配置档案（Episode Profile）

> **用途**：根据剧目定位选择预设档案。所有 Agent 从本节获取集数、时长、分段等参数，**禁止**硬编码。
> **选择方式**：在 `制片规范.md` 文件头添加 `episode_profile: standard-72`（或其他档案名）即可生效。

```yaml
# ═══════════════════════════════════════════
# 预设档案：standard-72（DEFAULT）
# 适用：常规竖屏短剧，72集×90s，总时长≥100min
# ═══════════════════════════════════════════
standard-72:
  episode_count: 72
  duration_range_sec: [75, 120]        # 标准集 75-100s，EP01 可至 120s
  first_episode_duration_sec: 120
  segments_per_episode: [6, 10]
  shots_per_episode: [8, 12]
  segment_duration_sec: [4, 12]        # Seedance API 硬限制，不可更改
  three_zone_timing:
    standard_ep_90s:
      hook_sec: 15
      substance_sec: 55
      cliffhanger_sec: 20
    first_ep_120s:
      hook_sec: 20
      setup_sec: 30
      substance_sec: 50
      cliffhanger_sec: 20
  total_duration_min: 100              # 全剧总时长下限（分钟）

# ═══════════════════════════════════════════
# 预设档案：compact-60
# 适用：快节奏短剧，60集×90s，总时长≥90min
# ═══════════════════════════════════════════
compact-60:
  episode_count: 60
  duration_range_sec: [75, 120]
  first_episode_duration_sec: 120
  segments_per_episode: [6, 10]
  shots_per_episode: [8, 12]
  segment_duration_sec: [4, 12]
  three_zone_timing:
    standard_ep_90s:
      hook_sec: 15
      substance_sec: 55
      cliffhanger_sec: 20
    first_ep_120s:
      hook_sec: 20
      setup_sec: 30
      substance_sec: 50
      cliffhanger_sec: 20
  total_duration_min: 90

# ═══════════════════════════════════════════
# 预设档案：extended-100
# 适用：长线剧集，100集×75s，总时长≥100min
# ═══════════════════════════════════════════
extended-100:
  episode_count: 100
  duration_range_sec: [60, 90]         # 标准集 60-75s，EP01 可至 90s
  first_episode_duration_sec: 90
  segments_per_episode: [5, 8]
  shots_per_episode: [6, 10]
  segment_duration_sec: [4, 12]
  three_zone_timing:
    standard_ep_75s:
      hook_sec: 12
      substance_sec: 45
      cliffhanger_sec: 18
    first_ep_90s:
      hook_sec: 15
      setup_sec: 25
      substance_sec: 35
      cliffhanger_sec: 15
  total_duration_min: 100
```

**字段说明**：

| 字段 | 说明 |
| --- | --- |
| `episode_count` | 全剧总集数 |
| `duration_range_sec` | 单集时长区间（秒）；EP01 可用上限 |
| `first_episode_duration_sec` | 第一集最大时长（秒），用于加长 Hook + Setup |
| `segments_per_episode` | 每集 segment 数量区间 |
| `shots_per_episode` | 每集有效镜头数区间 |
| `segment_duration_sec` | 单 segment 时长硬限制（Seedance API） |
| `three_zone_timing` | 三段式节奏分配（Hook / Substance / Cliffhanger） |
| `total_duration_min` | 全剧总时长下限（分钟） |

## 六、AI 出图/视频衔接

### 6.1 出图流程

1. 分镜 **`场景`** → `资产/场景卡片.md` → `SCENE-###`
2. 分镜 **`形象`** → `资产/形象索引.md` → `角色卡片.md` 内该 **L##** 的 Prompt
3. **L01**：用「基础 Prompt」生成 Character Sheet（正面全身，白底）
4. **L02+**：`based_on` 指向 L01 参考图 + **delta Prompt**（仅服装/道具/妆效/伤痕）
5. 多角色同框：按形象 ID 顺序合并；每人脸对应其 `L##`，禁止混用别角 L01
6. 分镜 **`角色`** 列仅用于对白表，不参与出图 Prompt 拼接

### 6.2 角色一致性规则

- 每个角色 **L01** 生成后，所有后续出现必须使用该 L01 作为 reference_image
- 衍生形象仅改变服装/状态，面部特征锁定为 L01
- 同集多角色：每人独立 L01 → 拼合时按角色顺序排列参考图

### 6.3 场景一致性规则

- 每个场景 **SCENE-###** 生成参考图后，后续同场景必须使用该参考图
- 同场景不同角度：用同一参考图做 img2img 变体，禁止重新生成

### 6.4 资产变体解析规则

资产变体规则是跨阶段的全局约定，scene-writer、segment-builder 等角色均遵守本节定义。

#### 场景变体（时段 / 天气）

当 scene-prop-designer 为同一场景生成了多张时段/天气变体参考图时（如 `SCENE-001.png`、`SCENE-001-night.png`、`SCENE-001-dawn.png`、`SCENE-001-rain.png`）：

- **基础版本**：`SCENE-###`（无后缀）默认对应**日间**版本，即 `assets/scenes/SCENE-###.png`。
- **变体版本**：附加时段/天气后缀，如 `SCENE-001-night` 对应 `assets/scenes/SCENE-001-night.png`。
- **分集剧本中**：在镜头表「场景」列引用时附加变体后缀（如 `SCENE-001-night`）；未附加后缀时默认引用日间基础版本。
- **segments.yaml 中**：`refs.scene_id` 写基础 ID（`SCENE-001`），`assets.scene_urls` 中映射到实际变体文件路径。

#### 形象变体（服装 / 造型）

当 character-designer 为同一角色生成了多套造型（如 `CHAR-001-L01`、`CHAR-001-L02`、`CHAR-001-L03`）时：

- **分集剧本中**：在镜头表「形象」列引用本段实际使用的形象 ID。
- **不同 Segment 可引用不同造型**——以匹配剧情需要（如换装、受伤、身份转变）。
- **segments.yaml 中**：`assets.look_urls` 映射到该 Segment 实际使用的形象 ID 和文件路径。
