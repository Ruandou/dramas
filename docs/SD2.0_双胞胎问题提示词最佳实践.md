# Seedance 2.0  双胞胎问题提示词最佳实践

## 解法概述

**核心解法逻辑：在提示字中在每次一提及人物时强调 人物名称+ 人物入参的****Asset API****，让模型对人物形象保持一致性理解**

## 提示词总结

> 例如：@图1为李明参考（图1是李明不同角度的图片，视频中只能出现1位李明）

> 例如：张三@图1 把一个橘子递给李四@图2

> 例如：注意！视频全程不要在同一画面中复制相同人物，不要多人同脸。画面中严格只有x个人物



**注：**以上解法在人物较多时可能会失灵，Plan B为将双胞胎画面截图，使用seedream5.0-lite图生图传入图片和提示词“去掉xx人物”（可以描述下人物外貌），然后将生成的图片作为关键帧重新生视频。

## 一、Badcase背景

在利用 Seedance 2.0 进行视频内容生成时，一个典型且棘手的问题是 **“双胞胎”或“多人同脸”** 现象，常见为单个角色被无故复制成多个分身。此问题通过提示词调优可显著降低生成双胞胎概率，但不是100%避免。
