## 文字生成

Seedance2.0支持在 T2V/I2V/R2V/V2V等场景下生成常用文字。
模型能根据情境**自动匹配合适的**风格与颜色，也支持在提示词中**指定**文字的颜色、风格、出现方式、出现时机、出现位置。
编写时请优先使用**常用字**，避免**生僻字与特殊符号，**以确保最佳呈现效果。
