# 动画微短剧（漫剧）内容创作建议

> 来源：巨量引擎短剧创作者中心（2026年5月8日更新）
> 原文：https://bytedance.larkoffice.com/wiki/OwNuwK03ziHuuvkr3wjcP7Ltn0W

---

## 原则性要求

1. 全剧立意导向（主线剧情、核心情节、人物塑造、结局走向）不可脱离正向叙事，需传递向善、良好的价值观，杜绝低俗恶俗媚俗
2. 作品不能宣扬违背法律要求、伦理道德、公序良俗或不符合社会主流价值观的情节桥段、镜头画面、台词语言

---

## 一、内容题材合规及分级备案要求

| 类别           | 要求                                                                                                                                                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **重点微短剧** | 特殊题材或总投资≥300万元，由广电总局统一备案公示管理和成片审查，需登录"重点网络影视剧信息备案系统"申报。特殊题材：涉及政治、军事、外交、国家安全、统战、民族、宗教、司法、公安等 |
| **普通微短剧** | 总投资100万(含)~300万元且一般题材，应报省级以上广电主管部门进行规划备案和成片审查                                                                                                |
| **其他微短剧** | 总投资<100万元且一般题材，由平台负责内容审核把关与版权核定，定期报属地省级广电主管部门备案                                                                                       |

---

## 二、禁止宣扬不良价值观

| 场景                     | 定义                                   | 创作建议                                                                                         |
| ------------------------ | -------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **宣扬不择手段获取财富** | 使用非法或不道德手段获取财富，且未批判 | **严格避免**：1. 正面人物为获取钱财危害他人生命且未批判；2. 美化非法借贷/放贷/欠债/逃债/借贷返现 |
| **放大贫富阶级矛盾**     | 极端化情节制造贫富矛盾或阶级对立       | **严格避免**：1. 展现贫富阶级歧视/阶级对立；2. 富人通过金钱左右他人生死                          |
| **夸大财富作用**         | 过度宣扬金钱的决定性作用               | **避免过多展现**：1. 为钱财泯灭伦理纲常；2. 富人欺凌贫穷者；3. 表达金钱无所不能                  |
| **财富设定夸张离奇**     | 经济逻辑严重脱离现实                   | **避免过多展现**：1. 无节制消费挥霍；2. 特写镜头聚焦昂贵商品/金钱/消费场景                       |
| **性别物化**             | 将角色价值窄化为依附价值               | **避免过多展现**：对单一性别严重物化获得收益                                                     |

## 三、禁止宣扬暴力仇恨

| 场景             | 定义                                   | 创作建议                                                                                                                                              |
| ---------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **宣扬极端复仇** | 刻意美化极端暴力复仇手段，淡化其危害性 | **严格避免**：1. 极端残暴复仇/虐待情节；2. 复仇对象为血亲/灭门灭族；3. 惩治远超所受伤害；4. 现代背景下暴力违法复仇；5. 为达目的不择手段、无视他人生命 |
| **宣扬教唆犯罪** | 现代非架空场景下美化严重犯罪行为       | **严格避免**：1. 正面人物主观自发严重犯罪；2. 过度细节展示违法犯罪过程                                                                                |
| **过度冷漠报复** | 因琐事对他人采取极端报复或冷漠行为     | **避免过多展现**：1. 无端危害他人展现人性阴暗面；2. 看轻他人利益对正向手段持否定态度；3. 自轻自贱出卖肉体/人格；4. 密集展示帮派斗殴/黑社会内容        |

---

## 四、禁止宣扬封建迷信

作品核心应**破除迷信、提倡科学精神**，禁止传播迷信思想。

| 场景                 | 定义                                 | 创作建议                                                                                              |
| -------------------- | ------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| **宣扬封建邪祟文化** | 通过传播迷信糟粕传达恐怖惊悚氛围     | **严格避免**：1. 涉及重度封建迷信元素相关画面/详细语言描述；2. 正面人物不符合时代背景宣扬封建迷信糟粕 |
| **现代法术逆天改命** | 在现代科学场景下宣扬利用法术改变命运 | **严格避免**                                                                                          |

---

## 五、画面质量要求

- 使用AI工具创作时，需注意**生成内容质量、画风一致性、剧情连贯性**
- 避免出现其他平台水印/备案号、非官方渠道广告/推广引流/二维码/无关水印

---

## 六、漫剧信息（剧壳）创作建议

### 书名&简介

书本信息呈现的IP名同样适用。

**需避免**：

1. 宣扬拜金炫富等不良价值观
2. 宣扬出轨等不良婚恋观
3. 对违法犯罪行为进行正向表述
4. 不当关联社会敏感话题、煽动群体对立、饭圈引战、造谣抹黑公众人物
5. 涉及种族/地域/民族/性别歧视的侮辱性言论
6. 色情低俗或性暗示内容
7. 夸张离奇博眼球表述
8. 【热播】【爆款】【强推】等营销信息
9. 【误传】【测试】【废弃】等与实际剧情无关的内容
10. 罗列热门剧/演员，或拉踩/强行关联热剧蹭热
11. 内容不完整、不通顺、错别字等影响阅读
12. 描述内容与实际剧情不一致
13. 标点符号滥用（仅限逗号、感叹、冒号、问号、双引号）

### 封面

**需避免**：

1. 低俗色情元素及观感
2. 恐怖惊悚画面或引人不适的元素
3. 非正当婚恋/情感关系人物亲密互动
4. 酗酒/吸烟等不良行为
5. 非正当身份持枪画面
6. 版权方、广告、外链等推广引流信息
7. 【热播】【爆款】【强推】等营销字段
8. 改编/角色信息出现错误、低质、截断不完整
9. 封面片名缺失、过小、信息截断不完整、与实际片名不一致
10. 主体缺失、五官异常截断/缺失、抠图粗糙、黑框马赛克、拉伸压缩变形、模糊等影响画面完整度或美观度
