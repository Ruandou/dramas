# 爆款短剧制作工艺拉片

> **用途**：4 部真实上线短剧成片的**制作工艺**拆解（剪辑节奏/调色/打光/构图/字幕/出场卡），供 Seedance 提示词设计、`segment-builder` 分段时长预算与后期合成规范参考。
>
> **方法与边界**：`ffmpeg` scene 检测（阈值 0.35，仅计硬切，柔化转场略少算）统计剪辑节奏；高清抽帧比对工艺。剧情分析不在本文范围——**剧情/节拍以剧本语料为准**（见 60 部语料基准），视频只看制作。
>
> **样本**：黑莲花上位手册（古装宫斗 120 集）、栀栀复栀栀（都市虐恋 72 集）、撕夜（重生复仇 74 集）、家里家外（年代家庭 79 集，川渝方言）。均为 720×1280 (9:16) 25fps。外部资料包成片，仅作校准，不纳入项目资产。

---

## 一、剪辑节奏（EP01 实测）

| 剧 | 时长 | 硬切数 | 平均镜长 ASL | 节奏定位 |
|----|------|--------|-------------|----------|
| 黑莲花 | 96s | ~38 | **2.5s** | 爽剧快切 |
| 撕夜 | 319s | ~110 | **2.9s** | 爽剧快切 |
| 栀栀 | 156s | ~24 | 6.2s | 情绪慢镜 |
| 家里家外 | 214s | ~29 | **7.1s** | 电影感长镜 |

**结论**：强冲突爽剧段落 ASL 压至 **2.5–3s**；情绪文戏/精品向放宽至 **5–7s**。
→ 可直接作为 `segments.yaml` 单镜时长预算参考：冲突镜 2–4s、情绪镜 5–8s，避免全片匀速。

## 二、画面工艺

| 维度 | 观察结论 | Seedance/Seedream prompt 关键词 |
|------|----------|--------------------------------|
| 调色 | 黑莲花=青橙冷暖对撞（暖宫灯 vs 冷雪夜）；栀栀=都市夜低调冷调+霓虹暖点；撕夜=灵堂冷白高调；家里家外=年代暖琥珀低饱和 film 调 | `teal-orange color grade` / `cool night tones with warm neon accents` / `warm amber period film look, desaturated` |
| 打光 | 普遍 **practical 光源**（宫灯/车灯/窗光）+ 侧逆光/伦勃朗塑形，暗部压得住——低成本高级感的核心 | `practical warm lantern light` / `rim light` / `low-key lighting, deep shadows` / `soft window light` |
| 景别 | **竖屏特写为王**：特写/近景占绝对主导，全景仅用于建立与转场 | `close-up` / `medium close-up`；建立镜头才用 `wide establishing shot` |
| 景深 | 大光圈浅景深虚化背景，突出人脸，顺带提高背景一致性容错 | `shallow depth of field, bokeh background, 85mm lens look` |
| 构图 | 中心偏上构图、底部留字幕安全区；**前景遮挡**（纱帘/栏杆/宫灯/树枝）造纵深 | `foreground occlusion, shooting through gauze curtain` / `centered composition, headroom for subtitles` |
| 运镜 | 高角度俯拍（压迫/死亡镜头）、前景穿越、手持跟随；配快切制造紧张 | `high-angle overhead shot` / `handheld tracking` / `slow push-in` |
| 氛围 VFX | 黑莲花全程飘雪、栀栀雨夜反光——氛围粒子是情绪放大器 | `falling snow` / `rain, wet reflections` / `drifting embers` |

## 三、字幕规范（后期烧录层）

- **位置**：底部居中，**字幕中心约 72% 高度**（字幕块底边距画面底部约 25%，720×1280 下约 320px），避开播放器底部 UI 与互动按钮区（爆款实测）。
- **字体**：白色黑体（sans-serif）中粗，**细描边/轻阴影**保证亮暗背景均可读（雪地亮背景实测清晰）。
- **排布**：单行为主，短句 4–12 字，与台词节奏同频；长句应在源头（剧本）拆短，烧录工具超 14 字自动折行仅为兜底。
- **标点**：画面字幕**近零标点**（爆款实测：句号/叹号/问号/省略号/破折号均删，句中停顿用空格，如「来人 扒了她的衣服」）；烧录层自动清理，SRT 保留原标点供 TTS 断句。
- **语种**：国内版纯中文；出海版才叠双语。
- → 落地：`burn_subtitles.py` 统一按此规格烧录，对齐配音 SRT。**严禁**让 Seedream/Seedance 生成画面文字（乱码/繁体风险，见项目 On-Screen Text Prohibition 规则）。

## 四、人物出场字幕卡（overlay 层）

四部剧共性版式：**姓名醒目（大/粗白字）+ 身份或与主角关系（小字）**，极简无边框，首次登场配静镜停留 **~1–1.5s**。

| 剧 | 版式 | 示例 |
|----|------|------|
| 黑莲花（古装） | 竖排：头衔小字上 + 姓名大字下 | 护国公府二小姐／**宋昭** |
| 栀栀（都市） | 竖排：姓名大字 + 关系小字列 | **孙倩**／江晚栀表妹 |
| 撕夜（都市） | 姓名 + 身份/关系 | **江晴雪**／江家大小姐·继姐 |
| 家里家外（年代） | 竖排古典风：单位职务 + 姓名 | 冷冻机二分厂车间组长／**蔡晓艳** |

**核心洞察**：出场卡的真正功能不是"报名字"，而是**锚定与主角的关系**（表妹/未婚夫/继姐/嫂子）——一张卡秒建关系网认知，比台词自我介绍高效。**四部实测均为竖排卡**（竖屏两侧负空间天然适配竖排；早期对栀栀"横排"的判断系误读，已更正），横排仅作可选项。

→ 落地建议：
1. 出场卡为**后期 overlay**，不进 AI 生成画面；
2. 模板字段=`姓名（大）+ 关系或头衔（小）`，关系**以主角为锚点**表述，且**≤7 字**（爆款实测：表妹/昭仪/江家大小姐/前任未婚夫，都是短词锚定关系，不写简介）；
3. `scene-writer` 在角色首次登场镜头标注 `name_card: 姓名/关系`，`segment-builder` 传递至后期合成清单，保证每个角色首镜自动挂卡；
4. **挂卡时机**：对准角色**清晰露脸**的镜头（非开门/背影/环境铺垫镜），宜静镜或慢推；**停留 ≥2s（默认 2.5s，爆款实测）**，挂卡镜头总时长应 ≥3s。

## 五、速查：一镜 prompt 组装示例

> 古装冷宫夜戏特写（黑莲花风格）：
> `close-up, low-key lighting, practical warm lantern light with rim light, teal-orange color grade, shallow depth of field with bokeh background, falling snow, foreground occlusion through gauze curtain, high contrast, 9:16 vertical composition with headroom for subtitles`

组装顺序建议：**景别 → 打光 → 调色 → 景深 → 氛围粒子 → 前景/构图 → 竖屏留白**。
