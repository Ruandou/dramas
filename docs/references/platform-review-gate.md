# 平台审查门控清单

> 本文档整合所有平台审核标准，供流水线各 agent 在创作和审核环节引用。

## 一、红线清单（P0 — 零容忍，发现即删除）

### 1. 政治类

| 禁止内容 | 说明 |
|----------|------|
| 损害国家形象 | 丑化国家机关、公职人员形象 |
| 歪曲历史事实 | 篡改重大历史事件、抹黑英雄人物 |
| 危害国家统一 | 涉及领土主权、民族分裂 |
| 煽动对立情绪 | 挑拨民族关系、地域歧视、阶层对立 |
| 违反宗教政策 | 宣扬宗教极端、邪教内容 |

### 2. 暴力类

| 禁止内容 | 说明 |
|----------|------|
| 血腥暴力细节 | 特写伤口、血液喷射、肢体分离 |
| 虐待展示 | 详细展示虐待过程（含动物虐待） |
| 教唆犯罪 | 展示犯罪手法细节、提供可模仿操作步骤 |
| 美化暴力 | 将暴力行为塑造为"酷"或"正义" |
| 校园暴力美化 | 将校园欺凌浪漫化或轻描淡写 |

### 3. 色情类

| 禁止内容 | 说明 |
|----------|------|
| 裸露/性行为 | 任何程度的裸露或性行为画面 |
| 性暗示过度 | 过分露骨的性暗示镜头或台词 |
| 未成年相关 | 任何涉及未成年人的情色内容 |
| 性骚扰美化 | 将性骚扰行为塑造为"霸道""浪漫" |
| 物化身体 | 以展示身体为目的的无剧情镜头 |

### 4. 违法类

| 禁止内容 | 说明 |
|----------|------|
| 涉毒内容 | 展示吸毒过程、美化毒品 |
| 赌博教唆 | 展示赌博技巧、美化赌博 |
| 诈骗手法 | 详细展示诈骗流程和技巧 |
| 非法集资 | 宣传传销、非法金融活动 |
| 侵犯隐私 | 偷拍、跟踪等行为作为正面手段 |

## 二、高风险灰区（P1 — 必须修改）

### 1. 价值观偏差

| 灰区内容 | 风险点 | 处理方式 |
|----------|--------|----------|
| 主角"法外开恩" | 以暴制暴、私刑正义 | 必须有法律后果或反思，不能把私刑当正义 |
| 金钱万能论 | 用钱解决一切问题 | 核心冲突靠智慧/情感/正当手段解决 |
| 封建糟粕 | 包办婚姻、重男轻女当正面 | 可以展示但必须批判，不能美化 |
| 拜金主义 | 嫌贫爱富、唯金钱论 | 反派可以拜金，主角必须展示正确价值观 |
| 阶级羞辱 | 贫富歧视、富人碾压穷人 | 禁止以金钱左右他人生死或尊严 |
| 职场PUA美化 | 将职场压迫美化为"磨练" | 主角应反抗不合理待遇 |
| 极端复仇 | 报复手段超出合理范围 | 惩治不能远超所受伤害，禁止美化暴力复仇 |
| 不择手段获取财富 | 非法/不道德手段获取财富且未批判 | 正面人物不得为钱财危害他人 |

### 2. 关系类问题（含红果平台特别要求）

| 灰区内容 | 风险点 | 处理方式 |
|----------|--------|----------|
| **非合意亲密行为** | 强吻、强行带走、限制自由 | **红果硬性要求：禁止"霸总强吻"等非合意亲密**，改为双向确认 |
| 年龄差恋爱 | 年龄差距过大 | 确保双方成年，避免暗示权力不对等 |
| 三角恋处理 | 美化劈腿/出轨 | 出轨方必须承担后果 |
| 师生恋 | 权力关系不对等 | 极度敏感，建议避免 |
| 家暴情节 | 展示家暴但无后果 | 必须有反抗、法律介入、惩罚 |
| 性别物化 | 将角色价值窄化为依附价值 | 避免对单一性别严重物化 |

### 3. 暴力仇恨（巨量引擎特别强调）

| 灰区内容 | 风险点 | 处理方式 |
|----------|--------|----------|
| 复仇对象为血亲 | 灭门灭族式复仇 | 严格避免 |
| 现代背景下暴力复仇 | 非架空场景的违法复仇 | 严格避免，必须通过合法途径 |
| 过度冷漠报复 | 因琐事极端报复 | 避免展现人性阴暗面为主的内容 |
| 帮派斗殴 | 密集展示黑社会内容 | 避免过多展现 |

## 三、低风险灰区（P2 — 建议优化）

| 灰区内容 | 风险点 | 处理方式 |
|----------|--------|----------|
| 恐怖氛围 | 过度惊吓、阴暗画面 | 用悬疑气氛替代直接惊吓 |
| 赌博情节 | 以赌博作为剧情工具 | 赌博者必须付出代价 |
| 迷信内容 | 算命、做法等超自然元素 | 可作文化元素，不能作为解决问题手段 |
| 奢侈消费 | 过度展示奢华生活 | 适度展示，不以炫富为核心卖点 |
| 医疗情节 | 不专业的医疗处理 | 涉及医疗内容要基本准确 |
| 现代法术逆天改命 | 科学场景下宣扬法术改命 | 严格避免，可用架空设定规避 |
| 财富设定夸张离奇 | 经济逻辑严重脱离现实 | 避免无节制消费挥霍的特写镜头 |

## 四、正向价值要求（P3 — 必须体现）

### 核心正向价值（每剧至少体现 2-3 个）

| 价值观 | 要求 |
|--------|------|
| 善有善报 | 好人最终得到好结果 |
| 正义必胜 | 邪不压正，坏人必受惩罚 |
| 自强不息 | 通过正当努力改变命运（红果：冲突靠智慧/情感解决） |
| 家庭和睦 | 家人之间的爱与支持 |
| 诚信守诺 | 信守承诺、诚实做人 |
| 法治精神 | 在法律框架内解决问题 |
| 男女平等 | 尊重每个人的独立人格（红果：女主必须有独立人格和专业能力） |
| 社会责任 | 个人成功回馈社会 |

### 红果平台正向价值硬性要求

- 女性角色必须展现**独立人格**和**专业能力**，不能完全依附男主
- 核心冲突通过**智慧/情感**解决，而非财富或暴力
- 传递**自力更生、正义、性别平等**的正面信息
- 禁止美化不成比例的报复行为

### 结局价值观要求

| 结局类型 | 价值观要求 |
|----------|------------|
| 大团圆 | 善有善报，坏人受到惩罚 |
| 开放式 | 正面力量占上风，留有希望 |
| 悲剧式 | 引发反思，传递警示意义 |
| 反转式 | 最终反转必须指向正面 |

### 反面教材处理原则

- 可以展示恶行（用于激发观众愤怒/同情）
- 恶行**必须**得到惩罚（善恶有报）
- 不能将恶行美化或合理化
- 受害者不能"感谢"施害者
- 主角复仇手段不能比反派更恶劣
- 结局必须传递正面信息

## 六、题材特定审查要点

| 题材 | ❌ 禁止 | ✅ 正确做法 |
|------|---------|------------|
| **战神归来** | 随意动用军事力量处理私事；军衔/军装不规范；暗示军人凌驾法律 | 军人身份带来责任和纪律，不是特权 |
| **霸道总裁** | 强吻/强行带走/限制自由当浪漫；用金钱控制感情；女主无独立人格 | 尊重对方意愿，双向奔赴，女主有自我 |
| **甜宠** | 跟踪偷拍当"深情"；替女主做所有决定当"保护"；吃醋暴力当"在乎" | 健康恋爱：信任、沟通、尊重边界 |
| **家庭伦理** | 全面丑化一方；忍耐家暴为"美德"；净身出户当"大度" | 展示健康家庭关系处理方式，法律意识 |
| **重生穿越** | 利用未来知识违法（如股票）；现代价值观全盘否定古代；无挑战开挂 | 保留历史尊重，主角成长要有代价 |

| **悬疑探案** | 详细展示可模仿犯罪手法；美化罪犯；主角使用非法手段取证 | 法律框架内解决问题，正义通过合法途径实现 |

## 七、平台审核重点关注

### 标题/简介合规（13 项）

1. 禁止宣扬拜金炫富等不良价值观
2. 禁止宣扬出轨等不良婚恋观
3. 禁止对违法犯罪行为进行正向表述
4. 禁止不当关联社会敏感话题、煽动群体对立
5. 禁止涉及种族/地域/民族/性别歧视的侮辱性言论
6. 禁止色情低俗或性暗示内容
7. 禁止夸张离奇博眼球表述
8. 禁止【热播】【爆款】【强推】等营销信息
9. 禁止【误传】【测试】【废弃】等无关内容
10. 禁止罗列热门剧/演员蹭热度
11. 内容不完整、不通顺、错别字
12. 描述内容与实际剧情不一致
13. 标点符号滥用（仅限逗号、感叹号、冒号、问号、双引号）

### 封面合规（10 项）

1. 禁止低俗色情元素及观感
2. 禁止恐怖惊悚画面
3. 禁止非正当婚恋关系亲密互动
4. 禁止酗酒/吸烟等不良行为
5. 禁止非正当身份持枪画面
6. 禁止版权方/广告/外链推广信息
7. 禁止【热播】【爆款】等营销字段
8. 角色信息不得错误/低质/截断
9. 片名不得缺失/过小/截断/不一致
10. 主体不得缺失/五官异常/抠图粗糙/变形模糊

### 审核节奏

| 审核维度 | 说明 |
|----------|------|
| **前 3 集审核最严** | 决定是否通过，不允许前 3 集有任何 P0/P1 内容 |
| 付费卡点 | 不允许用低俗内容作为付费钩子 |
| 整体价值导向 | 全剧传递的核心信息必须正面 |

### 高频退回原因

- 标题含"禁忌""出轨""复仇"等敏感词
- 封面图过度暴露或暗示
- 前 3 集出现过激冲突（打斗、吵架过于激烈）
- 台词含脏话、人身攻击
- 反派行为过于真实具体（可被模仿）
- 结局没有正面收束
- 涉及真实品牌/机构/人物未授权
- 背景音乐未获授权

### 画面质量（AI 生成特别注意）

- 确保生成内容质量、画风一致性、剧情连贯性
- 避免出现其他平台水印/备案号/非官方渠道广告/二维码

## 十一、合规处理优先级速查

| 优先级 | 动作 | 包含内容 |
|--------|------|----------|
| **P0 立即删除** | 零容忍 | 政治敏感、色情内容、教唆犯罪、未成年相关 |
| **P1 必须修改** | 不改不放行 | 价值观偏差、暴力过度、性骚扰美化、法外开恩、非合意亲密、阶级羞辱 |
| **P2 建议优化** | 优化后更安全 | 表现手法偏激、奢侈消费、迷信元素、医疗不准确 |
| **P3 锦上添花** | 正向加分 | 增加正面价值表达、强化法治、补充社会责任、展示健康关系 |
