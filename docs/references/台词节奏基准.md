# 台词节奏基准（Dialogue & Rhythm Baseline）

> **版本**：v2.2-corpus60（2026-07-29；v2.0 台词/微观节奏 + v2.1 宏观节奏与 standard-86 档案 + v2.2 切镜节奏）
> **地位**：scene-writer / script-reviewer 台词与节奏数值的**单一真相源**。两个 agent 中的具体数字均以本文件为准；改数字必须**先改本文件**，再同步两端（顺序不可反）。
> **证据出处**：`docs/真实爆款台词与节奏数据_2026-07-28.md`（14 数据源，重点 §12 六十部爆款语料实测：60 部 / 4,507 集 / 62,149 台词块）。

---

## 一、计数口径（统一定义，统计与审核共用）

| 术语 | 定义 |
|------|------|
| **句** | 以句末标点（。！？!?…）切分的台词句 |
| **发言块** | 单角色一次连续发言（被他人台词或动作行打断前的全部句子） |
| **spoken line 三分类** | 对白（角色间实际对话）/ 独白（`[内心]`、`[低声·自语]`、`[自语]`、`[喃喃]`、OS）/ 旁白（`旁白`、VO、画外音）。出声自语归独白，不算对白 |
| **台词字数密度** | 全集台词总字数（含对白+独白+旁白，不含动作行/画面描述）÷ 总时长分钟数 |
| **对白占比** | 对白行数 ÷ 全部 spoken lines 行数 |

## 二、阈值设计原则

1. **底线**（FAIL 线）= 语料真实分布**最低值**减去解析口径误差（±2-3pp）；不设在中位数（否则半数真实爆款不及格，门控失效）
2. **理想**（满分锚点）= 语料**中位数邻域**（爆款典型区间）
3. **双锚制**：真人爆款语料只锚**说话风格**（对白占比/句长/块长/反 AI 模式）；**密度不锚真人语料**——AI 剧表演短板导致语音需近满铺（真人剧语音仅覆盖约 50-70% 时长），密度锚挂靠 **TTS 物理口径**（名义语速 5 字/秒 = 300 字/分钟）
4. **指标是「入场券」非「胜负手」**：现象级《家里家外》全部指标落在典型分布正中间——合规带内不加分，出带才扣分，禁止指标内卷

## 三、权威数值表

### 3.1 说话风格（锚真人爆款语料）

| 指标 | 硬门槛 | 理想/满分锚 | 语料依据 |
|------|--------|------------|----------|
| **对白占比** | ≥85%（听心声/读心题材 ≥65%） | ≥95% | 中位 95.9%，最低 87.5%；豁免：EP01 穿越确认 ≤2 段 |
| **单句字数** | 上限 ≤30 字 | 全集中位落 8-15 字（中位 >18 = 书面腔，触发精简重写） | 中位 11，P90≈30 |
| **发言块长度** | 对白块 ≤3 句（推荐 1-2）；独白块 ≤2 句 | 全集块长 P90 ≤2 句 | 主流 1 句/块，P90=2-3 |
| **说话角色数** | ≥2 人/集 | 理想带 3-5 人/集 | 中位 4，爆款子集 3-6 |
| **同开头 2 字重复** | ≤2 次/集 | — | 实测中位 1-2（天然吻合） |
| **感叹号** | ≤10/集 警戒；>15 扣分 | 女频慢节奏典型 0-1 | 中位 3.5；男频爆款中位 5-6、p90 12-13 |
| **直述情绪（我+程度词+情绪词）** | ≤1/集 | 0 | 60 部爆款全部 ≈0（AI 特有病，零容忍） |
| **开场首句** | 全剧 ≥90% 集数以对白开场 | — | 实测中位 96.5% |

### 3.2 密度（锚 TTS 物理口径，名义语速 5 字/秒）

| 指标 | 数值 | 含义 |
|------|------|------|
| **台词字数密度硬带** | **[210, 330] 字/分钟** | 底线 210 = 70% 铺满（更低即 AI 剧空镜风险区）；上限 330 = 快语速满铺（5.5 字/秒） |
| **理想带** | **240-300 字/分钟** | 80-100% 铺满（AI 剧默认往满铺打） |
| 90s 集 | ≥315 字（理想 360-450） | Rule 20 换算 |
| EP01 120s | ≥420 字（理想 480-600） | Rule 20 换算 |
| 75s 集 | ≥262 字（理想 300-375） | Rule 20 换算 |
| 每有对白段 | ≥2 句 | Rule 24（90s 底线集 315 字 ÷10 段 ≈2.9 句，≥3 会使底线集无法合规） |
| 句密度 | 换算参考值（≈字数÷句长中位 11），不作门控 | 受断句风格干扰 |

> 对照：真人爆款 ≈145-190 字/分钟，在 AI 带外下方——AI 剧密度系统性高于真人剧（双锚制）。

### 3.3 节奏保持（高密度防「匀速机关枪」）

| 机制 | 要求 |
|------|------|
| **句长波形** | 连续 ≥5 句同长度档（全≤8字或全≥20字）= 单调，必须打破；每 SEG 至少一次「短句连发→长句收束」或反向波形 |
| **呼吸点预算** | 全集 0-30% 非语音时长必须**集中投放在 2-3 个战略点**（高潮前蓄力/反转后余韵/唯一静音段视觉锤），禁止均匀撒布；位置标注在「本集制作备注·节奏」 |
| TTS 语速分层 | 高潮 +10% / 抒情 −10%（制作备注建议字段；**已落地** 2026-07-28：本地链 tts_batch_edge.py 支持 --rate + 行级 [rate:±X%]；Seedance 链由 segment-builder 在声音描述追加语速文字/段级 tts_rate 透传） |

## 四、宏观节奏基准（standard-86，v2.1 新增）

> 证据：归档 §13（L1 编剧自标注 + L2 全语料逐集曲线）+ §13.4（时长/集数）。适用于 story-architect / script-reviewer 高阶评审。

### 4.1 默认档案 standard-86（用户裁决 2026-07-28，三线共振）

| 项 | 值 | 依据 |
|----|-----|------|
| 总集数 | **86**（EP01 120s + 85×90s ≈ 129.5 分钟） | 平台四政策收敛 120 分钟门槛 + 剧本政策长篇≥80集 + 语料实测（74% 爆款≥120min、集数中位 80、IQR 75-95） |
| 单集参数 | 与 standard-72 完全一致（EP02+ 75-100s 理想/75-120 合规，EP01 90-120s；段数 6-10/EP01 10-12；台词 v2.0 全部不变） | 单集层已验证，仅扩容集数 |
| 大纲文件名 | `短剧剧本_<剧名>_86集.md` | — |
| standard-72 | 保留为历史档案（旧项目 episode_profile 自治，不回溯） | 用户裁决：旧项目忽略 |

### 4.2 四阶段边界（86 集，保持 15/30/35/20% 比例）

| 阶段 | 集数范围 | 集数 |
|------|---------|------|
| 起势期 | **EP1-13** | 13 |
| 攀升期 | **EP14-39** | 26 |
| 风暴期 | **EP40-69** | 30 |
| 决战期 | **EP70-86** | 17 |

（求和 13+26+30+17=86 ✓；决战期禁引新角色线：**EP70 后**）

### 4.3 宏观节奏实测锚（语料 §13）

| 指标 | 基准值 | 实测依据 |
|------|--------|----------|
| 付费/留存卡点锚 | **卡一 EP8-12、卡二 EP27-31（绝对位置，不随集数缩放）、卡三 EP60-65**；总量 8-10 个、最小间隔 6 集不变 | L1 编剧自标注聚簇（[8,10]/[9,10,29,30]/[11,12,28]/[12,29,31]） |
| 小高潮间隔 | **每 3-6 集**（实测中位 4，IQR 3-6，n=752） | L2 强度峰 k=0.5 |
| 大高潮间隔 | **每 5-9 集**，最大允许间距 **10 集**（实测中位 7-9，n=237） | L2 强度峰 k=1.5 |
| 集末钩子 | 每集必有（真值背书：拆解笔记逐集标卡点，间隔中位 1） | L1 |
| 窗口期新角色 | 窗口期（前~15%）新角色密度 ≈ 收束期 3×；决战期（EP70+）不引新角色 | L2 新角色曲线 [2.71→0.88] |

### 4.4 钩子类型基准（语料 §14 拉片，v2.1 补录 2026-07-28）

> 证据：无双 94 集 + 家里家外 73 集（LLM 集尾标注，置信中）+ 南音再许 63 集（编剧自标真值）。适用 story-architect 钩子分布规则 / reviewer 高阶 2。

| 指标 | 基准值 | 实测依据 |
|------|--------|----------|
| 类型多样性 | **任意连续 10 集窗口 ≥3 种（硬）、≥4 种理想**；题材锁定段（长对峙）可豁免至 2 种需标注 | 男频长对峙段锁死 CRI/REV，原「15集窗口4/5种」过严 |
| 同类型连用 | **≤3 集（4+ 连不合格）** | 爆款存在 3 连，4+ 连罕见；同时修复 architect(≤3)↔reviewer(≤2) 存量打架 |
| 题材主导配比 | 男频复仇 CRI+REV ≈70%；家庭情感 EMO ≈35-40%；甜宠 甜蜜/性张力 ≈35% | 三部拉片分布 |
| **温情落点例外** | 家庭/年代题材每 8-12 集允许一次「情感余韵收束」（OS 金句/温情定格）替代悬念钩，不计无钩子扣分；非家庭题材滥用或频率 >1/8 集 = 不合格 | 家里家外 EP34/38/44/73 集尾 OS 升华（兼传播金句位） |
| 卡点形态 | 集末钩优选「一句台词定格」形态 | 南音再许 19 处自标卡点多为台词原句 |

## 五、切镜节奏基准（v2.2 新增 2026-07-29）

> 证据：爆款成片机械拉片（`scripts/corpus_cut_rhythm.py`，ffmpeg 场景检测阈值 0.3 保守口径）：4 部已验证爆款（家里家外/撕夜/栀栀复栀栀/黑莲花上位手册）**全量 345 集 / 13,005 镜**；抽样 40 集→全量结论漂移 <10%，数据收敛。归档 §15。

### 5.1 真人爆款成片实测（参照系）

| 指标 | 实测值 |
|------|--------|
| ASL（平均镜头时长）中位 | **2.2s**（p75 3.4 / p90 5.4 / p95 7.4） |
| >8s 长镜占比 | **4.4%**；>10s 仅 2.7% |
| 每集切镜 | 中位 25-40 次（90-150s 集） |
| 开场 15s vs 正片 | **无差异**（2.2 vs 2.2s）——钩子靠内容不靠碎剪，不单独定开场切镜规则（防过度工程） |
| 越新越爆越快 | 黑莲花（最爆）ASL 2.0s、>8s 仅 1.0% |

### 5.2 AI 制作映射（规则值）

> Seedance 段（4-12s）是生成单位非剪辑单位；**段内多镜已生产验证**（2026-06 全楼/前任弟弟项目：prompt 写 2 镜/段 → 实渲染 4.9-5.9 切/段，有效 ASL 1.6-1.9s 直逼真人；帧目检确认为真切镜非误报）。失败形态：1 镜=1 段=10-12s 一镜到底（真人 p97 稀有事件当默认值）。

| 规则 | 值 | 依据 |
|------|-----|------|
| 单镜（剧本镜头表）时长带 | **理想 3-6s**；>8s 须标注长镜理由（情绪凝视/运镜调度）；**>10s 禁止** | 真人 >8s 仅 4.4%、>10s 2.7%；Seedance 渲染时自由加切会把有效 ASL 拉到 ~2s |
| 段内镜数 | **段 ≥8s 必须 ≥2 镜（典型 2-3）**；段 4-7s 可 1-2 镜；对话段强制反打（景别/机位变化） | 段内多镜已验证；唯一例外：静音视觉锤段可单镜但 ≤8s |
| 每集镜头数（standard-86） | **EP02+ [16,30]，EP01 [20,36]**（段数 6-10/EP01 10-12 不变 × 2-3 镜/段，API 成本不变） | 90s÷均镜 4.5s≈20；原 [8,12] 均镜 7.5-15s 系旧规范强制的慢节奏 |
| segment-builder 门控 | 单镜 >8s 无理由标注 → WARN；>10s 单镜段 → suspected_static 报告 | — |

## 七、适用范围与追溯

- 本基准自 v2.0 起适用于**新写作的集**；历史剧本不回溯重审
- 计数口径由「行」切换为「句/字数」；跨版本比对时注意口径代差
- 题材分档：听心声/读心类对白占比底线 65%；奇幻/脑洞类块密度天然偏低（世界观靠画面展示），密度审核按字数带不受影响
