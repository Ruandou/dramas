# 台词节奏基准（Dialogue & Rhythm Baseline）

> **版本**：v2.0-corpus60（2026-07-28）
> **地位**：scene-writer / script-reviewer 台词与节奏数值的**单一真相源**。两个 agent 中的具体数字均以本文件为准；改数字必须**先改本文件**，再同步两端（顺序不可反）。
> **证据出处**：`docs/真实爆款台词与节奏数据_2026-07-28.md`（14 数据源，重点 §12 六十部爆款语料实测：60 部 / 4,507 集 / 62,149 台词块）。

---

## 一、计数口径（统一定义，统计与审核共用）

| 术语 | 定义 |
|------|------|
| **句** | 以句末标点（。！？!?…）切分的台词句 |
| **发言块** | 单角色一次连续发言（被他人台词或动作行打断前的全部句子） |
| **spoken line 三分类** | 对白（角色间实际对话）/ 独白（`[内心]`、`[低声·自语]`、`[自语]`、`[喃喃]`、OS）/ 旁白（`旁白`、VO、画外音）。出声自语归独白，不算对白 |
| **台词字数密度** | 全集台词总字数（含对白+独白+旁白，不含动作行/画面描述）÷ 总时长分钟数 |
| **对白占比** | 对白行数 ÷ 全部 spoken lines 行数 |

## 二、阈值设计原则

1. **底线**（FAIL 线）= 语料真实分布**最低值**减去解析口径误差（±2-3pp）；不设在中位数（否则半数真实爆款不及格，门控失效）
2. **理想**（满分锚点）= 语料**中位数邻域**（爆款典型区间）
3. **双锚制**：真人爆款语料只锚**说话风格**（对白占比/句长/块长/反 AI 模式）；**密度不锚真人语料**——AI 剧表演短板导致语音需近满铺（真人剧语音仅覆盖约 50-70% 时长），密度锚挂靠 **TTS 物理口径**（名义语速 5 字/秒 = 300 字/分钟）
4. **指标是「入场券」非「胜负手」**：现象级《家里家外》全部指标落在典型分布正中间——合规带内不加分，出带才扣分，禁止指标内卷

## 三、权威数值表

### 3.1 说话风格（锚真人爆款语料）

| 指标 | 硬门槛 | 理想/满分锚 | 语料依据 |
|------|--------|------------|----------|
| **对白占比** | ≥85%（听心声/读心题材 ≥65%） | ≥95% | 中位 95.9%，最低 87.5%；豁免：EP01 穿越确认 ≤2 段 |
| **单句字数** | 上限 ≤30 字 | 全集中位落 8-15 字（中位 >18 = 书面腔，触发精简重写） | 中位 11，P90≈30 |
| **发言块长度** | 对白块 ≤3 句（推荐 1-2）；独白块 ≤2 句 | 全集块长 P90 ≤2 句 | 主流 1 句/块，P90=2-3 |
| **说话角色数** | ≥2 人/集 | 理想带 3-5 人/集 | 中位 4，爆款子集 3-6 |
| **同开头 2 字重复** | ≤2 次/集 | — | 实测中位 1-2（天然吻合） |
| **感叹号** | ≤10/集 警戒；>15 扣分 | 女频慢节奏典型 0-1 | 中位 3.5；男频爆款中位 5-6、p90 12-13 |
| **直述情绪（我+程度词+情绪词）** | ≤1/集 | 0 | 60 部爆款全部 ≈0（AI 特有病，零容忍） |
| **开场首句** | 全剧 ≥90% 集数以对白开场 | — | 实测中位 96.5% |

### 3.2 密度（锚 TTS 物理口径，名义语速 5 字/秒）

| 指标 | 数值 | 含义 |
|------|------|------|
| **台词字数密度硬带** | **[210, 330] 字/分钟** | 底线 210 = 70% 铺满（更低即 AI 剧空镜风险区）；上限 330 = 快语速满铺（5.5 字/秒） |
| **理想带** | **240-300 字/分钟** | 80-100% 铺满（AI 剧默认往满铺打） |
| 90s 集 | ≥315 字（理想 360-450） | Rule 20 换算 |
| EP01 120s | ≥420 字（理想 480-600） | Rule 20 换算 |
| 75s 集 | ≥262 字（理想 300-375） | Rule 20 换算 |
| 每有对白段 | ≥2 句 | Rule 24（90s 底线集 315 字 ÷10 段 ≈2.9 句，≥3 会使底线集无法合规） |
| 句密度 | 换算参考值（≈字数÷句长中位 11），不作门控 | 受断句风格干扰 |

> 对照：真人爆款 ≈145-190 字/分钟，在 AI 带外下方——AI 剧密度系统性高于真人剧（双锚制）。

### 3.3 节奏保持（高密度防「匀速机关枪」）

| 机制 | 要求 |
|------|------|
| **句长波形** | 连续 ≥5 句同长度档（全≤8字或全≥20字）= 单调，必须打破；每 SEG 至少一次「短句连发→长句收束」或反向波形 |
| **呼吸点预算** | 全集 0-30% 非语音时长必须**集中投放在 2-3 个战略点**（高潮前蓄力/反转后余韵/唯一静音段视觉锤），禁止均匀撒布；位置标注在「本集制作备注·节奏」 |
| TTS 语速分层 | 高潮 +10% / 抒情 −10%（制作备注建议字段，segment-builder 联动属后续项） |

## 五、适用范围与追溯

- 本基准自 v2.0 起适用于**新写作的集**；历史剧本不回溯重审
- 计数口径由「行」切换为「句/字数」；跨版本比对时注意口径代差
- 题材分档：听心声/读心类对白占比底线 65%；奇幻/脑洞类块密度天然偏低（世界观靠画面展示），密度审核按字数带不受影响
