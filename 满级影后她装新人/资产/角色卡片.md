| 性格核心 | 克制 |
| 外在欲望 | 在星耀娱乐内部找到十年前陷害自己的铁证，在金像奖舞台上揭露真相 |

| 视觉锚点 | 清冷骨相美、眼神有故事感；L01 练习生高马尾+学生装（伪装），L02 长发披肩优雅影后（真实） |
| 主角原型 | 隐身者（Hidden Identity）+ 逆袭者（Underdog） |
| 痛点命中 | ① 被冤枉/被误解却无力自证的委屈感；② 在职场中被迫隐藏实力的压抑感 |

**语言画像（Speech Profile）**

| 维度 | 描述 |
|------|------|
| 词汇层级 | 高（专业术语偶现），装傻时故意降到低（"啊？""我不太懂哎"） |
| 句式偏好 | 短句反问为主，装傻时长句碎碎念；真实身份时句式精准如手术刀 |
| 口头禅/标志表达 | 「有意思。」（冷淡中带审视）；「是吗？」（反问式回应） |
| 情绪表达方式 | 内敛→爆发型。平时克制，关键时刻一击致命。情绪低落时沉默不语而非倾诉 |
| 禁用词 | 绝不会说"求求你"、"帮帮我"等示弱词汇；装傻时会说但语气明显刻意 |
| 参照原型 | 甄嬛后期的从容锋利 + 苏明玉的隐忍克制 |
| 对白权力模式 | 操控型（manipulative）——装傻时伪装迎合，真实身份时精准打击 |
| 信息密度 | 高——每句含多重信息，一个反问可以传达质疑+暗示+威胁 |
| 沉默策略 | 被触动真心事时沉默，观众应感受到十年隐忍的重量；沉默时眼神比语言更有力 |
