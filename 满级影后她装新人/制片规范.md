## 三、ID 命名规则

| 类型 | 格式 | 示例 | 用途 |
|------|------|------|------|
| 角色 | `CHAR-###` | `CHAR-001` | 对白、关系、选角（谁） |
| 形象 | `CHAR-###-L##` | `CHAR-001-L01` | 出图、妆造、分镜视觉（长什么样） |
| 群演 | `CHAR-GRP-##` / `CHAR-GRP-##-L01` | `CHAR-GRP-01-L01` | 每个不同角色独立 ID + L01 |
| 场景 | `SCENE-###` | `SCENE-001` | 布景 |
| 道具 | `PROP-###` | `PROP-001` | 关键道具 |
| 分集 | `EP##` | `EP01` | 分集文件 |
| 镜头 | `EP##-S##` | `EP01-S03` | 集数-镜号 |

### ID 分配规则

- 编号**连续、不跳号**
- 新建角色：先在 `资产/角色索引.md` 登记 `CHAR-###`，再由 character-designer 建 `L01` 基础形象
- 新建换装/阶段形象：**只加 `L02+` 衍生形象**，并写明 `based_on: CHAR-xxx-L01`
- 群演分级：有名字+跨 segment 出现→独立 CHAR-###；纯背景无台词→CHAR-GRP
- 群演按需创建，不设数量上限
- 同一 CHAR-GRP-## 可跨集复用，但不同视觉角色不可共用同一 ID

### 形象层级结构

| 后缀 | 名称 | 说明 |
|------|------|------|
| **L01** | 基础形象 | 全剧面部一致性的**唯一锚点** |
| **L02+** | 衍生形象 | 必须 `based_on` 本角色 `L01`；禁止跳过 L01 |

| 顺序 | 层 | 文件 | 写什么 |
|:---:|---|---|---|

## 七、分段规则

### 分段（Segment）规则 —— AI 生成单位

| 约束 | 值 | 说明 |
|------|-----|------|
| 单 segment 时长 | **4–12 秒** | Seedance fast 硬限制；超出必须拆分 |
| 理想时长 | 8–10 秒 | 一条 API = 一段可拍的戏 |
| 每 segment 镜头数 | 1–3 镜 | 不超过 3 个镜头 |
| 最小叙事单位 | 1 个完整 beat | 每个 segment 必须构成完整叙事节拍 |
| 每集段落数 | 6–10 段 | EP01 可至 10 段（120s），EP02+ 为 6–10 段（75–100s） |
| 每集镜头数 | 8–12 镜 | 对应每集 6–10 段 × 1–3 镜/段 |

### Episode Profile

| 集类型 | 时长 | 段落数 | 镜头数 |
|--------|------|--------|--------|
| EP01（加长首集） | 120s | 8–10 段 | 10–12 镜 |
| EP02–72（常规集） | 75–100s | 6–10 段 | 8–12 镜 |

### 拆分原则

1. **不得**在对话中间切断 segment（一句台词必须落在同一段内）
2. **不得**在连续动作进行中切断（开门、摘道具等动作链一条 segment）
3. 拆段边界：场景切换、主说话人切换、情绪断点
4. 单段主说话人 ≤ 2；长对手戏拆成 `SEGxxa` / `SEGxxb`
5. 分镜表里某镜自然时长 < 4 秒 → **并入同场景相邻段**

### 关键区分

- **场景（SCENE-###）** = 空间单位（地点不变 = 同一场景）
- **Segment（SEGxx）** = AI 生成单位（一次 Seedance API 调用）
- 同一场景**可以**包含多个 segment；segment **不得**跨场景

## 八、分集剧本格式规范

> 分集剧本（`剧本/EP##/EP##_*.md`）是单集的**真相源**，所有后续文件必须从此导出。

- 对白格式：`**CHAR-###**[情绪]：「台词」`；无对白写 `（无对白，[音效]）`

## 十、音色规范

> voice_prompt 权威来源为 `资产/声音卡片.md`（P0）。

### 语音描述格式

```
「[性别]，[年龄]岁，[音色特征]，[语速]，[情绪基调/说话习惯]」
```

### 旁白与音效

- 旁白角色不分配 CHAR-ID，写为「旁白」，voice_prompt 独立定义
- 分集剧本镜头表中标注音效（如 `掌声雷动`、`紧张弦乐`、`快门声`）
- Seedance `generate_audio: true` 合成基础环境音；特殊音效后期叠加
- 本剧特殊音效需求：综艺节目欢呼/掌声、颁奖典礼音乐、快门声、手机铃声、雨声（民宿段落）

## 十一、年代/题材约束

### 必须体现元素

- 现代都市场景（高楼、玻璃幕墙、城市夜景）
- 娱乐圈专业场景（训练室、片场、颁奖典礼、综艺录制棚）
- 智能手机、社交媒体界面（虚化处理）
- 时尚穿搭（练习生青春风、明星高定、日常休闲）
- 综艺舞台灯光与氛围

### 禁止出现元素（结构性 negative_prompt）

- 古装/历史元素（本剧为纯现代都市题材）
- 明显的品牌 LOGO（避免侵权）
- 未成年人不宜内容
- 暴力血腥画面
- 政治敏感元素
- 过度暴露的服装
- 吸烟/酗酒美化

## 十二、内容合规参数

### 题材合规等级

**C 级（低风险）**：现代都市甜宠/娱乐圈题材，无敏感历史/政治/宗教内容，无暴力血腥场景。

### 本剧特定红线

1. 不得出现对娱乐圈真实人物/公司的影射（所有公司名、人名必须虚构）
2. 不得美化潜规则/权色交易（本剧虽有相关情节，但必须明确为"被陷害/被冤枉"的反面教材）
3. 不得出现过度暴露的服装或暗示性镜头
4. 网络暴力/人肉搜索情节不得提供具体操作方法
5. 不得出现对特定地域/群体的歧视性描述

### 灰区处理策略

| 灰区 | 处理策略 |
|------|---------|
| 潜规则/权力骚扰 | 作为反面情节呈现，明确受害者立场，不提供细节描写 |
| 网络暴力/舆论攻击 | 呈现受害者痛苦，强调正义最终到来，不渲染暴力细节 |
| 商业阴谋/陷害 | 聚焦真相揭露和正义伸张，阴谋手段不过度细化 |
| 身份欺骗（化名潜入） | 动机设定为追求真相/正义，非恶意欺诈 |

### 正向价值锚点

1. **真相与正义**：十年冤案终获平反，真相不会永远被掩埋
2. **个人奋斗**：靠实力说话，不依赖他人上位
3. **行业进步**：从个人复仇升华为推动行业公正机制建设

### 平台审核重点提示（前 3 集）

- **EP01**：闪回中的"丑闻"不得具体描写色情/违规内容，用模糊画面+文字暗示
- **EP02**：伪造身份档案情节需注意不展示具体伪造技术/证件制作过程
- **EP03**：练习生选拔中的竞争场景不得出现霸凌/体罚等过激行为
